# 选用旧世代数据的条件

这些对照取自基于 v21.1、标签后 23 个提交的参考快照内的四套可选备份。以下均要求显式选择有效的同世代基础与形态数据，依赖登记项合法、较早调用正常，无插件覆写。只在这些前提内推导；文件名、Generation 字段或目录存在均不会自动切换机制世代。混合不同世代的资料仍待实际验证。

- 基础记录的身份、出现、顺序与默认形态取所选数据。继承的名称来自基础记录，不能拿相邻形态的别名替代。
- 第五至第八世代配对样本内，863 项形态到基础的绑定均指同世代的对应物种。当前基础加备份形态、或当前形态加备份基础只是带条件的另一种输入。
- 种族值、努力值产出、成长与初始亲密度取对应版本记录；第六至八世代各有 48 个 Mega 目标对应 46 个基础。不可预设所有 Mega 与基础 HP 相等。重算与条件 HP 写回取决于具体输入。
- 依保存身份与所选形态按顺序查询性别和特性列表，强制性别、已解析的特性缓存、特性索引分别保留各自行为。
- 成长率、基础经验、EV 和亲密度经现有六条曲线以及相应分配、资格与 Shadow 暂存过程消费。初始亲密度可超过 255；后续失败前缀另算。
- 等级招式、学习器与蛋招式保留给定顺序与重复项；编译属性去重与重置招式时对最新出现的招式去重是不同操作。
- 蛋组、孵化步数、香与后代列表以及有序祖先共同决定首个前身、香判定与幼体后代抽选。直接生成或领取与孵化周期的相容门分开；满队后已完成的前缀保留。
- 标志按所选版本与顺序、不区分大小写进行对应检查。母先于父检查永恒之石，动态形态读取可提交母方状态；对子代显式设相同形态仍可触发行为。默认四季鹿未带作者样本中新增的母系继承标志。
- 进化前向资料按该版本的有序条目取值。复数进化属性中的条目排在可重复的单数属性之前。首个前身、None、反向前身排除及目标形态的优先级按[基础进化](../spec/creatures/basic-evolution.md)判定；当前 460 条边并不证明旧版数值相同。实际扫描到的第一个真结果仍受入口守卫约束。
- 属性、身高、重量与标志按简化形态取值；正常动态形态读取可能提交变化。图像、影子与别名选择分别受其原始键和性别限制，像素表现未执行。
- 所需石匹配或已知所需 Mega 招式即可满足候选条件。原始回归的物种处理器按当前持物给出目标形态。返回非空值时具有原始回归资格，返回值还须与保存形态相等才视为当前已处于该状态。第五世代样本无 Mega 条目，仅限制该选定数据集。
- 区分原始字段缺席、显式空值、登记默认值与随后实际对象中的值。编译、启动、加载、在线对象变更与存档 17 项对象的归属有各自的失败前缀。

字段和具体样例见[备份作者数据的字段合同](backup-author-fields.md)。对应个体状态观察见[个体状态与跨域兼容边界](../spec/creatures/item-identity-and-related-compatibility.md)。
