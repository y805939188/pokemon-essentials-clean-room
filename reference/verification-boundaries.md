# 验证范围与缺口

## 参考版本的证据边界

范围以基于 Essentials v21.1、标签后 23 个提交的参考快照为准。[有限运行观察](observation-limits.md)另列有记录的隔离执行。以下按功能说明未知范围与补证条件。不同机器、插件、数据组合、完整发行工程的运行结果需分别验证。

### L01 地图和完整工程

参考快照缺少完整地图、公共事件、系统与图块数据库、启动配置和工程资源。真实 NPC、道馆、发奖及完整示例流程的可达性未观察。

验证这些流程需要版本与内容可核对的完整工程、隔离的兼容宿主及相应资源。

### L02 图形和音频

参考快照缺少完整的图形和音频资源。可读的两个标记位图各为 8 × 8 像素，每幅 64 像素，共 128 像素。实际加载、动画帧、坐标量化、混音、叫声与听感均未验证。

验证时需提供对应的资源和图形或音频宿主，分别记录请求与宿主的实际输出。

### L03 原生执行

已知执行范围限于 Mac 上的隔离 Ruby 检查。随附 Ruby 3.1 的游戏在兼容 Windows、RGSS 或 mkxp 宿主中的运行，以及 .NET 工具的运行，均未验证。

进一步验证需要可用的授权宿主、资源、受控输入输出和隔离方案。

### L04 Game和运行库

原生机器码的完整控制流、实际使用的版本、后端和分派仍未知。导入、导出、定义名及只确认身份的原生元数据只能定位材料。

具名的机器码或版本问题需要目标宿主或可安全恢复的对应证据，验证范围取决于具体问题。

### L05 可读内嵌程序

GPU编译、采样、精度、实际接线和像素颜色未知；不要求未来复用宿主/GPU/Ruby类层级。

补证条件为目标GPU/宿主、完整素材和已绑定程序选择链。

### L06 animmaker

图像/XML库空矩形/编码/错误格式化/文件失败及实际输出未运行；≤96文档不是验证门，扩展名不保证PNG，失败不保证回滚。

补证条件为可用.NET兼容宿主及准确依赖库、受控输入/输出目录。

### L07 extendtext

Windows API真实返回、实际尺寸、精确周期、目标进程所有权、自动启动和运行库启动余部未知。

补证条件为Windows兼容隔离目标窗口与真实API观察；不将未检查返回当成功。

### L08 字体

Font.exist/字宽/hinting、字节码执行和真实UI视觉未知；资源轮廓解析不替渲染。

补证条件为准确目标字体宿主、显示输入和字形/尺寸观察。

### L09 soundfont

原生接受/异常guard处理、合成及声音未知；不把结构完整解析称格式全部合规或采样器等价。

补证条件为目标音频宿主和受控SF2加载/合成/观察。

### L10 序列化

读取和解码没有执行序列化对象或启动原生加载。各语言的全部翻译质量也未验证。

验证加载需要隔离的原生加载器和对应语言材料。语言质量另需逐项审校。

### L11 动态扩展和配置

任意插件/表达式/外部覆写、无界输入、配置全部笛卡尔组合及调度未穷尽。

补证条件为新增具名插件/配置/事件材料与输入域可恢复相应有限范围。

### L12 外部状态和服务

真实网络/生产账号/外部服务、真实用户保存往返和打包档案未验证；exit0或空串不能证明业务成功。

补证条件为明确授权的隔离替代服务/存档/档案及真实输入输出；不使用生产状态。

### L13 纯元资料

许可材料只用于确认身份。文件标识、历史检查结果和导航能定位已查材料。游戏规则与运行结果分别依其行为证据判断。

若出现会影响游戏规则的新材料，须针对其具体版本确认覆盖范围。

### L14 执行与工具元数据缺口

背包与所有者的早期隔离检查只取得管道末端的退出码。钓鱼的部分检查缺少当时的起始读取记录或时间，部分工具检查缺少独立的标准输出、标准错误或时间记录。后续采集无法补回这些原始记录。

若要复测同一范围，应先确定输入与依赖，再分别记录该次执行的起止时间、标准输出、标准错误和底层退出码。原有记录仍保留各自的限制。

## 原生呈现与持久化

原生控制流和平台后端、字体虚拟机与活跃字体、HRTF 观察窗口外的分派、控制器 RWops 与设备桥接、着色器私有头与外层选择、SF2 后端的完整语义均未确认。缺少完整工程及 messages_game.dat。备份世代、带类型的加载与复制、默认值、恢复前缀与 Map051 的设置均有具名前提，实际素材可达性待证。当前没有实际像素、发声、墙钟时序、真实存档往返或回放证据。

## 跨领域验证

下列预期检查仍待实际运行。应记录实际采用的目标版本、格式、配置与平台。

- 捕获。菜单/目标许可、登记扣球与取消。随机消费、目标移除、经验触发及终局。接收队列、图鉴/命名/队伍/盒子、还原、异常前缀。
- 战斗道具。NPC资源与玩家背包区分、目标/效果家族。登记扣物、执行复检、退款残留、再次撤销及容量异常。状态写穿、行动占用、下一命令与终局清理。
- 逃跑。查询/尝试/强制入口差异、拘束与必逃。尝试计数、随机消费、失败行动占用。原始结果、世界包装返回、漫游持久与终局还原。
- 战中成长。经验/EV接收、逐级升级及HP/能力/PP刷新。学招暂停、替换/放弃、继续回合。捕获成长、Shadow暂存、战后进化与异常前缀。

AI 策略评分和实际战斗查询的资格、宿主输入与多媒体表现、特殊玩法、作者工具及旧格式的兼容范围仍待核实。
