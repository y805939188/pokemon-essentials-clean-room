# 适用范围与证据等级

以下限制适用于参考快照 R（Essentials v21.1 标签后 23 个提交）的静态事实、内容样本与推导案例。涉及发行版的差异以对应章节明确标注的版本为准。独立实现要求在对应主题的“可移植”章节中说明。历史参考函数的隔离观察按其原测试环境、输入与输出单列。

## 如何解释一个案例

- 来源静态事实记录已检查的条件、状态或数据。“已定位”“静态确认”“数据样本确认”属于不同读法。字符串匹配、阅读统计与行为覆盖分别计量。
- 推导向量给出输入、前提和预期。运行实现时应单独记录实现、版本、实际输出和异常。素材存在、渲染、时间、容量和宿主回调均须满足该案例的前提。
- 兼容档案保留内容标识、顺序、部分提交和异常。数据键的大小写、符号和必要 ASCII 字符参与比较。语言、内部数据结构、类层级、宿主和战斗引擎由实现方选择。
- 发现证据不足时，保留原前提与未决项。独立实现采用不同规则时应标明所选模式。

## 跨章节的限定

- 同一测试目录中的 ID 以所在的案例族定位。UI 目录的两套 T01–T21 及 T06b／T25b／T34b 保留原次序和各自前提。
- 伙伴捕获、场内／终局持物还原与漫游个体的持续性分别按捕获、参战与终局正文判断。A/B 持物先后按[伙伴参战时的一次终局恢复](behavior-sequences.md#chain-1-伙伴捕获持物存储)及 CP20、CP21、CX40 的各自前提读取。
- 大会预算与伙伴资格、编辑缓存与编译快照、示例对平衡等级的消费、空重学列表、A23／A31／A33 及 BP 显示各有自己的前提。PT41–63 的六种音乐请求和引子记忆只约束请求层。
- 工程转换中六族捕获体均不跨 LF。独立合法完整的调用行可被命中并整字段重写，从而丢失周边普通行。外围空白 LF 是另一种输入。
- 已列的可选兼容政策按具体章节选择。历史回归计数、静态目录条目及隔离工具运行均不证明真实宿主输出或完整游戏运行。

跨域数据与测试还可按[参考资料目录](README.md)或[静态案例目录](../vectors/README.md)查找。
