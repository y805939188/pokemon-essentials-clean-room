# 名人堂登记、快照与浏览

**独立实现规则 · V1-09**　WP65／WP67-B

原版[名人堂规格](lifecycle-presentations-and-history.md)区分登记、演出和浏览，并记录了空历史在特定配置下进入浏览会失败。独立实现保留届数和保留条目是两种状态的区别，浏览不得因两者不同而失败。

- 只有明确确认的冠军剧情分支有登记资格；普通胜利或通用胜场计数本身不授权登记。登记时取队伍展示值的快照（含蛋），后续队伍改名、升级、替换或浏览均不改既有历史；展示不持有可操作的成员引用。
- 每次合法登记递增届数。正上限超额时每次只去掉最旧一届；负上限不裁剪；上限为零且原来为空时，届数递增但不保留条目。降低上限不等于立刻清空，单次登记最多删除一届。
- 从未登记与已登记但无可浏览条目应可区分。采用届数为入口条件时，后一种情况显示空历史并可正常退出。登记不自动保存、不启动片尾；真实存档与冷读必须单独验证。
