# 语言切换与事件输入

**独立实现规则 · V1-07**　WP08／WP17／WP65

保持原版[本地化](../core/localization.md)、[消息和输入](messages-windows-input.md)、[菜单与继续](title-load-options-pause-and-pc.md)各自的模式边界。独立实现规则：语言刷新已经打开的导航时保留语义选项、焦点与已有设置；已开始的事件请求保持本次作者文本、进入时初值与结果规则。框架编辑提示可使用新语言；不能用提示重绘覆盖编辑内容。自由文本取消还原进入时原文；键盘命名允许空值时取消返回空值，要求最小长度时拒绝取消；字符网格的删除不是整个命令取消。只覆盖具名输入模式，不宣称实体输入法、媒体或所有平台已验证。

静态验收用例见[可移植向量](../../vectors/portable.json)。对应编号为 V1-07-A, V1-07-B, V1-07-C。
