# 作者内容身份、属性与旧档迁移

**独立实现规则 · V1-06**　WP03／WP04／WP10／WP19

参考的[内容标识](../core/content-identity-and-schema.md)、[作者数据装载](../core/pbs-lifecycle.md)及[原版迁移](../core/migration-failure-recovery.md)不改。以下是独立框架的规则：

- 持久物种身份以作者内容标识及形态为准，战斗引擎名只是映射。作者编译必须明确指定输入并核验输出身份；缺作者输入、错参数或意外编译到样例，不能用成功退出码充当作者内容已生效。
- 在 Gen 8 标准属性域里：省略取固定规则的默认属性，显式空列表归为一般属性，重复按属性身份去重，不随意截断合法列表。静态内容用于图鉴或平时摘要；临时战斗属性不回写静态内容或持久成员。
- 旧档迁移依赖明确映射。缺映射、内容不匹配或输入无效应拒绝并保留原档，不猜未知物种、不从别的计数推造旧档历史。内容重编译与玩家档迁移是两件事。Stellar 等未来属性的跨层一致性、旧格式之间的二进制互通均不在此承诺内。

静态验收用例见[可移植向量](../../vectors/portable.json)。对应编号为 V1-06-A, V1-06-B, V1-06-C, V1-06-D。

## 作者内容的暂存、安装与只读使用

**独立框架的静态行为。** 本节适用于从作者输入生成正式内容、可选安装到 MZ 工程以及随后读取该内容的入口。这里的预期来自实现和测试定义，本次未运行编译器、安装器、游戏或测试。

1. **选择输入和目标。** 调用者须给出作者源目录、一个尚不存在的暂存目录和预期内容 ID。游戏目录可省略，省略时只暂存。路径须是无 `..` 分量的绝对路径；缺项、空值、重复项、未知选项或源清单 ID 不符都被拒绝。暂存目录的已存在父目录先解析为真实位置，再比较目录的相等与包含关系。暂存目录不得与工具目录、作者源目录或游戏目录相等、相互包含；游戏目录与工具目录也互不包含。作者源目录与游戏的安装子目录互不包含。合法的暂存父目录别名可使用；别名落入禁用目录仍被拒绝。
2. **安装前检查。** 指定游戏目录时，须有且仅有一个有效的 MZ 工程标记和普通文件 `data/System.json`。标记可改名，扩展名大小写不限；文件至多 128 字节，去除尾部空白后须为 `RPGMZ`、一个空格和三段十进制版本号。已存在的安装目录必须是真实目录，最终文件 `data/framework/content.json` 必须尚不存在；悬空符号链接也占用这个名称。源目录顶层以 `.json` 结尾的输入须为普通文件。身份、现有输出或路径检查失败时不创建暂存目录。即使没有物种，也要在创建暂存目录前确认指定的战斗数据依赖可用、版本匹配、自定义格式与当前构建字节一致。
3. **核对两份完整产物。** 依次编译、按同一来源检查编译件、生成内容清单。编译件的模式须为正的安全整数、内容 ID 等于预期值、输入摘要与内容身份均具备所需格式，战斗数据版本匹配。清单模式为 1，其内容 ID、输入摘要和物种数分别与编译件一致。有物种时清单记录相同的战斗数据版本，零物种时该字段为 `null`。随后从相同的显式源独立再生成编译件和清单，分别逐字节比较完整文件。字段检查通过而任一文件的其他内容或字节不同，仍拒绝安装。
4. **发布与失败边界。** 只暂存时保留编译件和清单。安装时再检查游戏目标，仅将已核对的完整编译件发布到空目标，清单留在暂存目录。目标在发布前被占用时，已有文件保留。发布后读回并核对字节，成功结果分别给出两份产物的摘要和是否已安装。编译失败或独立再生成不一致时，安装阶段尚未开始；暂存目录可能已建，先前成功的暂存产物可能保留。发布后读回失败没有删除已发布目标的回滚步骤。
5. **消费者只读。** 正式入口分别检查读取、JSON、模式和内容装配。失败时报告相应错误，不用测试样本替代。全部检查成功后，消费者取得与输入隔离的正式内容。尝试修改嵌套招式或遭遇表，以及事后修改原输入，都不能改变其他消费者读到的正式值。重新从相同的已安装内容加载，读到的玩法数据仍等价。保存或安装玩家状态时，须使用当次状态与当时适用的招式资料核对，包括成员或外部输入已被修改及正式内容已被替换的情况。

[作者安装与只读内容的静态输入及预期](../../vectors/portable-framework-cases.json)中，INSTALL-01 至 INSTALL-04 覆盖选择输入、只暂存、工程标记与路径别名，INSTALL-05 至 INSTALL-09 覆盖依赖、发布、整份清单比较及失败前缀，INSTALL-10 至 INSTALL-12 覆盖正式加载、共享快照和玩家状态校验。
