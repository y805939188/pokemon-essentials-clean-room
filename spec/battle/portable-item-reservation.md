# 道具预留、消费与退还

**独立实现规则 · V1-01**　WP40／WP42

原版 [WP40](commands-obedience-and-action-order.md) 与 [WP42](growth-end-of-round-and-battle-outcomes.md) 已记录：某些执行期资格失败会退回道具但保留选择身份，正常终局可能据该身份再退一次。这是参考行为，不是未来实现必须复制的规则。

改良：对每笔已成功预留的可消耗道具，正常结清只能是「消费一次」或「归还一次」，两者互斥。执行拒绝后已归还，终局不得再归还；效果已消费、后来呈现失败也不据此归还。登记前被拒绝的请求不曾预留，不扣也不补。测试必须穿过执行拒绝再到正常收尾，不能只观察第一次退款。

静态验收用例见[可移植向量](../../vectors/portable.json)。对应编号为 V1-01-A, V1-01-B, V1-01-C。
