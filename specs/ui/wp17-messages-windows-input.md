## 1. 目的、范围与非目标

**目的**：描述通用交互的行为规则——消息文本如何进入/格式化/逐字显示/确认/关闭，选项与数量输入的来源/取消/边界，按键与文字输入的入口/编辑/确认/取消，以及这些交互与解释器/地图/输入刷新之间的状态交界。后续包据此判断"某交互何时阻塞、返回什么、取消是什么结果"，而不是各自重新追踪消息组件。

**范围**（WP17 自身声明范围，extraction-plan 第 2.1 节 (a) 类）：

1. WP17-A：消息与基础窗口（文本进入、替换、控制标记、逐字显示、确认/暂停、窗口样式与时机；绘制标记目录见附表 [wp17-draw-text-tags](wp17-draw-text-tags.md)）。
2. WP17-B：选项（来源、初始选择、取消策略、结果编码、内嵌选项）。
3. WP17-C：数量输入（范围/位数/初值/取消值/夹限/确认与取消）。
4. WP17-D：按键与文字输入（按键语义、重复、文字入口/编辑/长度/删除/确认/取消）。
5. WP17-E：状态交界（解释器等待、地图更新、输入刷新、临时标记恢复）。
6. F05-05、F05-06 中属于 WP17 部分的状态更新。

**非目标**：

- 不推断全部界面支持鼠标或输入法；鼠标/宿主文字事件接口存在不等于支持（8/12 节如实登记）。
- 不提取专门界面（队伍/背包/战斗/商店等）的领域 UI 与领域写入（相应后续包）；交易、命名后的领域写入只追踪到本包交界。
- 不重复 WP08（本地化与占位符主规则，引用）、WP13（事件命令语义与推进，引用）、WP15（资源选择与缺失，引用具体入口）。
- 不运行游戏或任何参考脚本；不执行输入；不修改 `reference/`；不设计 UI 组件类层级。

## 2. 概念与术语

- **消息窗口**：由 `pbCreateMessageWindow` 创建的文本窗口（逐字显示、位置/皮肤可配）；创建/销毁时维护 `message_window_showing` 全局标记（7.1）。
- **控制标记**：消息文本中以 `\` 开头的显示/行为指令（3.2 目录）。**`\1` 是暂停控制符**（显示中暂停等待确认），不是本地化占位符——WP08 的占位符是 `{1}` 等形式（引用，勿混）。
- **绘制标记**：绘制层以 `<...>` 表示的格式指令（附表 [wp17-draw-text-tags](wp17-draw-text-tags.md)；识别集合 21 个，实际处理 19 个，pg/pog 识别但无动作）。
- **逐字显示（letterbyletter）**：按 textspeed 逐字出现的显示状态（busy）；确认键的行为按 3.3 四态区分，不能笼统称"快进"。
- **宿主提供 vs 参考层定义**：`Input.trigger?/repeat?/press?/triggerex?/repeatex?/gets/text_input/mouse_*` 由宿主（MKXP）提供；参考层只定义按键别名（USE=C、BACK=B、ACTION=A、JUMPUP=X、JUMPDOWN=Y、SPECIAL=Z、AUX1=L、AUX2=R）与 F8 截图钩子。
- 影响域编号 Dxx 见 module-map；证据状态五档定义见总览第 7 节。

## 3. WP17-A：消息与基础窗口

### 3.1 文本进入与替换（`011_Messages.rb:405–476`，本轮逐行阅读）

消息文本在显示前依次处理（顺序敏感）：

- `\sign[文本]` → 展开为 `\op\cl\ts[]\w[文本]`（签名窗组合）。
- `\\` → 字面反斜杠（内部 `\5`）；**`\1` → 暂停控制符**（3.2 的 `\!` 同一字符；WP08 占位符 `{1}` 在本地化层，引用，不混用）。
- `\n[1–8]` → RMXP 角色名（兼容，存在时）；`\pn` → 玩家名；`\pm` → 格式化金钱；`\n` → 换行。
- `\[8 位十六进制]` → `<c2=...>` 绘制标记；**该 8 位输入分前后两半：前 4 位正文色、后 4 位阴影色（各 15 位 RGB）**，不是单个 RRGGBBAA 值（附表引用）。
- `\pg`按本人性别、`\pog`按相反性别选择文本色：男→男/女，女→女/男；未知性别或无玩家时两者移除。随后 `\b`/`\r` 展开配置男/女正文与阴影组合（默认男正文48,80,200，女正文224,8,8，两者阴影208,208,200；这与普通颜色色板不同）；绘制 `<pg>/<pog>` 的识别无动作是另一入口。
- `\b`/`\r` → 男/女文本色标记。
- `\w[皮肤名]` → 换窗口皮肤；**`\w[]`（空名）把 windowskin 置为 nil**（皮肤赋值不补回默认皮肤；窗口按无皮肤状态绘制，具体输出未运行验证）。
- `\c[N]` → 皮肤色板第 N 色（按皮肤明暗取色）。
- `\v[N]` → 变量值（递归展开至无变化）。
- `\l[N]` → 行数（≥1，影响窗口高度与位置）。
- 系统消息框（message_frame）非 0 时文本前缀亮色，否则按皮肤明暗取默认色。

### 3.2 消息控制标记目录（`011_Messages.rb:478–680`，本轮逐项核对）

| 标记 | 行为 |
| --- | --- |
| `\f[名]` | 显示图片窗（**直接用 `Graphics/Pictures/`**） |
| `\ff[名,索引]` | 显示头像窗（**先 `Graphics/Faces/` 后回退 `Graphics/Pictures/`**；按**四列**切取 96×96——源码不保证 4×4 共 16 格，也无索引上限校验） |
| `\g` / `\cn` / `\pt` | 显示金钱/代币/战斗点小窗（goldskin 皮肤，与消息窗对角摆放） |
| `\op` | 消息窗滑入出现（0.5 秒，自屏幕外到顶/底） |
| `\cl[SE]` | 特殊关闭：播 SE 后滑出（0.5 秒） |
| `\wu` / `\wm` / `\wd` | 窗口位置上/中/下（即时重摆） |
| `\ts[N]` | 文字速度改为 N/80 秒每字（空参数为 0=即时） |
| `\.` / `\|` | 等待 0.25 / 1 秒 |
| `\wt[N]` / `\wtnp[N]` | 等待 N/20 秒（wtnp 不暂停并自动继续） |
| `\^` | 不暂停，自动继续 |
| `\!` | 暂停点（逐字显示中暂停，等确认；与 `\1` 同控制符） |
| `\se[名:音:调]` / `\me[...]` | 播放 SE/ME（文首 SE 在显示前播放） |
| `\ch[变量,取消值,选项…]` | 内嵌选项：显示后弹选项，结果写变量（WP13 引用）。**两个字段解析规则不同**：变量号经 `pbCsvPosInt!`（数字形式检查，**接受 0**）；取消字段经 `pbCsvField!` 后转整数（**可为负数或 0，非数字文本转为 0**）。引号校验按实际拒绝条件（开引号字段后须跟逗号或结尾，否则才抛异常；仅开引号后耗尽输入不必然触发） |

### 3.3 逐字显示、确认与四态（WP17-R02 修订）

**显示状态**（`005_SpriteWindow_text.rb:160–215, 360–445, 578–617`）：

- `letterbyletter` 时逐字出现（busy）；`textspeed` 为每字秒数（玩家选项映射：慢 4/80、中 2/80、快 1/80、即时 0；配置默认 2/80）。`waitcount` 按运行时长（uptime，WP06 引用）倒计时；**计时等待有自身守卫**（等待未到期时显示更新整体挂起，到期后清零继续）。
- **暂停**：`\!`/`\1` 暂停点显示暂停箭头并等待（`pausing`）；`startPause/stopPause` 控制暂停箭头（4 帧动画）。

**确认键（USE/BACK）按四态区分**（`011_Messages.rb:641–647` 与组件 `resume`，376–387 行）：

| 状态 | 按 USE/BACK 的结果 |
| --- | --- |
| 显示中且**非暂停**（正文本延迟逐字出现） | 仅调用 `resume`——**不推进字符、不改速度**，显示随后仍按计时继续（**不能写成"按键立刻显全文"**） |
| 显示中且**暂停**（pausing） | 解除暂停（暂停中先播决定音），继续逐字显示 |
| 计时等待中 | 由计时守卫决定（到期自动继续；`\wtnp`/`\^` 另设自动恢复） |
| 显示完毕（且出现动画已结束） | 结束本条消息 |

- **`skipAhead` 是另一入口**（立即推进字符；已有战斗消息消费者）：本包只登记该能力存在于组件层，**不把它的效果套给通用消息入口**；战斗 UI 归后续包。
- **自动继续**：`\wtnp`/`\^` 在 waitcount 归零后自动恢复并继续。
- **特殊关闭**：`\cl` 在消息结束后播 SE 并滑出。
- **出现/结束音效**：无起始 SE 且逐字显示时播决定音。

暂停箭头4帧，每帧3/20=.15秒；开始显示先指定帧0，随后正常更新相位按floor(uptime/.15)模4，播放开始不重置时钟。uptime=.35开始显示为帧0，随后同一时刻更新为帧2。停止隐藏。列表上下箭头、背包左右箭头及摘要导航箭头8帧，每帧2/20=.1秒，更新相位floor(uptime/.1)模8；uptime=.35为帧3。有效素材、已播放及正常更新为前提，可见门仍由各消费者决定。

**自动行满暂停**：逐字显示且可见两行时，普通文本 `A\nB\nC` 在B后、第三行换行前自动插入暂停；确认解除后按名义.1秒滚动一行再推进C。显式暂停符并非唯一来源；即时非逐字模式不承诺同一自动暂停。可见行数由窗口内容高度/行高决定，三行可见是邻近对照。

## 4. WP17-B：选项（`011_Messages.rb:721–802`、`005_SpriteWindow_text.rb:855–935, 1056–1280`）

- **来源**：选项数组（作者内容）；窗口自适应宽高（每列等宽，光标箭头图按皮肤明暗取色）。
- **初始选择**：`defaultCmd` 指定初始索引。
- **结果编码**：确认（USE）→ 当前索引（0 起）。
- **取消策略**（`cmdIfCancel`）：**> 0 → 取消返回 cmdIfCancel − 1**（相当于"第 N 项作为取消项"）；**< 0 → 取消返回该负值本身**；**= 0 → BACK 无效（不可取消）**。**取消不能笼统等价为 false**。
- **nil 与空数组的对照（WP17-R03 修订）**：`pbShowCommands` 对 **nil 立即返回 0**；**空数组 [] 仍建窗并进入输入循环**——零条目不进行光标移动（移动守卫跳过），正常初始化且默认索引 0 时 **USE 返回 0**、BACK 按取消策略、未输入时继续等待。不能把 [] 与 nil 合并。
- **内嵌选项**：`\ch` 结果写变量并请求地图刷新；解释器命令 102/402/403 的分支语义归 WP13（引用，本文不重复）。
- **带帮助选项**（`pbShowCommandsWithHelp`）：随光标切换更新帮助文本；取消策略同上。
- **确认包装**：`pbConfirmMessage` = [Yes, No] 取消按 No（返回 2 → 结果 1 → false 语义）；`pbConfirmMessageSerious` = [No, Yes] 取消按 No（默认 No）。

## 5. WP17-C：数量输入（`011_Messages.rb:55–206`、`005_SpriteWindow_text.rb:624–730`）

### 5.1 参数对象（ChooseNumberParams；WP17-R03 修订）

- **范围**：`setRange(min, max)`（min > max 时 max = min）；`setMaxDigits(N)`（≥1）改为位数模式——范围变为 ±(10^N − 1)；`setNegativesAllowed` 允许负号，否则负的最小值和最大值分别夹到0。
- **两个初值入口不同**：`setDefaultValue` 设初值并**清除已设取消值**；`setInitialValue` 设初值但**保留取消值**——调用顺序影响可观察结果。
- **初值夹限**：读取初值时**夹到当前范围**（越界初值被夹限）。
- **取消值不夹限**：`setCancelValue` 设置的取消值**不做范围夹限**——取消（BACK）按原值返回（可越界、也可与合法确认值相同，调用者不能总凭数值区分取消）；未设取消值时取**夹限后的初值**。

全负范围[−9,−3]、禁用负号时有效范围[0,0]，初值−6夹0、正常USE返回0；允许负号的对照保留[−9,−3]、初值−6。显式取消值仍不夹限，不能由这个确认前提推广所有出口都0。

### 5.2 数字编辑窗口（Window_InputNumberPokemon）

- 逐位编辑：左/右移动位光标（循环），上/下增减当前位（0–9 循环）；符号模式时首位为 +/− 切换。
- 初值写入：非数值按0；有符号时保留正负号、幅值限10^位数−1，无符号时原数值夹到0与位数上限之间，不先取绝对值。两位无符号−12得数值0/文本00，有符号−12得−12；两位−123分别0/−99。

### 5.3 确认与取消（pbChooseNumber）

- 确认（USE）：数值在范围内 → 决定音并返回该值；**越界 → 蜂鸣音并继续等待**（不返回）。范围 [3,3] 时确认只能返回 3，**但 BACK 仍返回取消值**（不夹限），"只能返回 3"不覆盖全部返回路径。
- 取消（BACK）：取消音并返回**取消值**（不夹限；未设时为夹限后的初值）。
- 返回值即结果编码（无单独"已取消"标记；取消值可与合法值相同）。
- 解释器命令 103 的桥接（数字入变量）归 WP13（引用）。

## 6. WP17-D：按键与文字输入

### 6.1 按键语义与重复（`001_Technical/004_Input.rb`、宿主层；WP17-C01 同步）

- **参考层**：按键别名映射（第 2 节）；F8 触发截图；`Mouse.getMousePos` **默认仅在鼠标位于窗口内时返回坐标**（否则 nil）；**显式 `catch_anywhere=true` 可绕过该窗口内守卫**（已有调试编辑器静态调用）——接口存在不等于界面支持鼠标。
- **宿主提供**（MKXP 交界，未运行验证）：`Input.update` 刷新；`trigger?`（按下沿）、`press?`（按住）、`repeat?`（按住重复）、`triggerex?/repeatex?`（物理键名）、`Input.gets`（宿主文字输入串）、`Input.text_input=`（开关宿主文字输入）、`mouse_x/mouse_y/mouse_in_window`。
- **更新机会**：各交互循环的更新次序按入口不同（7.2）；每个交互正常结束后再次 `Input.update` 防止多余触发残留。

### 6.2 文字输入入口（`025_UI_TextEntry.rb` 全文；WP17-R04 修订：按模式分列）

- **模式选择**：`pbEnterText` 按玩家选项 `textinput`（1=键盘，其余=光标）选择场景；包装入口：`pbEnterPlayerName`（显示玩家行走图）、`pbEnterPokemonName`（显示宝可梦图标与性别符号）、`pbEnterNPCName`、`pbEnterBoxName`（存储箱图标）。
- **maxlength 不是跨模式统一保证**：**初始内容不被截短**（两种命名场景与自由文本均如此；`maxlength=` 只存上限不改既有文本），确认只查最小长度——超长初值可直接确认返回。

| 入口 | 初值 | 插入 | 确认 | 取消 |
| --- | --- | --- | --- | --- |
| 键盘命名（PokemonEntryScene，USEKEYBOARD） | 不截短 | `Input.gets` 逐字插入，**超长拒绝新增** | RETURN 且长度 ≥ minlength 时返回文本 | **ESCAPE 仅在 minlength = 0 时允许（返回空串）** |
| 光标命名（PokemonEntryScene2） | 不截短 | USE 插字符：**满长时先删末字再插入**并自动跳到 OK | OK 且长度 ≥ minlength 时返回文本（**先播确认 SE 再判长度，不足时不退出、无蜂鸣**） | **无独立取消结果**（BACK 映射为删除，结果总是当前文本） |
| 自由文本（pbFreeText/pbMessageFreeText，6.3） | 不截短 | 同键盘（超长拒绝新增） | RETURN 返回编辑后文本 | **ESCAPE 返回原输入文本（编辑作废）** |

- **光标场景其余行为**：13×5 字符网格，4 组字符集（大写/小写/变音/符号，含 ♂♀ 与符号）；SPECIAL 或模式键切组（带切换动画与音效）；BACK 删字符；**自动切小写组的判定是"当前第一组且插入后光标位置为 1"**（不是验证插入字符一定为大写字母，第一组也含数字）。
- **通用约束**：`maxlength` 字符上限（插入侧约束，见上表模式差异）；`minlength` 确认下限。

### 6.2.1 光标导航、字符身份与同轮优先序

字符区为5行×13列，r=0…4、c=0…12；控制行为 UPPER、lower、accents、other、删除、OK。字符区 LEFT/RIGHT 在同一行回绕，跳过当前组五行都为空格的整列；第12列始终保留可达。上下移动不跳过空格；首行UP/末行DOWN按下表到控制，控制UP去末行、DOWN去首行。

| 跨字符区边缘的列 | 控制 | 控制返回字符区代表列 |
| --- | --- | --- |
| 0、1 | UPPER | 0 |
| 2、3 | lower | 2 |
| 4、5 | accents | 4 |
| 6、7 | other | 6 |
| 8、9、10 | 删除 | 9 |
| 11、12 | OK | 11 |

控制RIGHT按 UPPER→lower→accents→other→删除→OK→UPPER 循环，LEFT逆序。大写A的UP→UPPER，再UP→末行首列0；UPPER的DOWN→A。J的RIGHT跳过整空第10列到逗号；末行9的RIGHT也到第11列，但该格是可达空格，不能把当前行所有空格都跳过。

兼容字符数据（每单元一行13字符，`·`仅为表内空格记号，不是输入字符；以下精确空格和符号身份参与导航，未来UI无需沿源窗口结构）：

### 6.2.2 非正上限的入口与失败阶段

总入口不预先拒绝或归一化0/负上限。正常资源、基础UI、无插件、min=0/max=0/初空时：键盘模式可开场，RETURN返回空串；插入因上限0被拒。光标模式先分配UI并创建选项光标，首次淡入回调先更新字符组位图，随后把文本光标夹到[0,max−1]=[0,−1]，按该逆序区间的有效裁决发生参数错误；在下划线/叠层/普通精灵更新以及主输入循环之前，用户还不能选择OK。正常结束步骤未到达，本地无统一确保清理；外层恢复、错误显示和资源实际释放未证。

光标max=−1同阶段遇[0,−2]；键盘负上限不启用插入容量守卫，初空可追加A并随后RETURN得A。min=1/max=0初空的键盘RETURN不满足确认条件、ESCAPE不满足取消条件，不能返回；这不等于光标初始化错误。邻近正上限max=1/min=0的光标可开场，ACTION定位OK后下一轮USE返回空串。若未来兼容范围排除非正上限，必须明示排除，不声称在这些输入等价；不得把源失败改写为统一安全空输入。


### 6.2.3 命名预览的帧合同

玩家/NPC行走预览在两种命名模式均使用4×4图的第一方向行四帧，单格宽=图宽/4、高=图高/4，整轮.5秒；存储箱预览为 `Graphics/UI/Naming/icon_storage` 横向四帧、单格高为整图高，整轮.4秒。相位按全局运行时钟，不以开场重置；有效128×128行走图、128×32箱图，uptime=.2秒时分别帧1/帧2、均32×32。解析缺失时预览图可为空，不能从加载界面的其它消费者推断其成功。读取存档预览交其他批次，不以本地贡献替代其验收。

## 7. WP17-E：状态交界（WP17-R05 修订：按入口分列）

### 7.1 等待与阻塞

- **解释器局部等待**：`message_waiting` 是**该解释器自己的**等待标记（WP13 引用）；命令 101 在自身同步消息调用前后维护它——**该解释器**在消息显示期间不执行后续命令。
- **全局显示标记**：`message_window_showing` 由消息窗创建/销毁维护，作为**部分入口的守卫**（如命令 101/104 在其为真时返回 false 不执行）——**它不是"任何解释器的一切命令都停止"**：另一解释器获得更新机会且自身无等待时，仍可执行合法命令（如全局开关赋值）；尝试显示新文本才有入口守卫。
- 选择/数字/文字在消息显示完毕后弹出（WP13 命令 101 的合并规则引用）。

### 7.2 地图更新机会（按入口）

- `pbUpdateSceneMap` 自身有前提：**须为地图场景且未处于淡出状态**。
- 各交互循环的调用位置不同：**数量输入循环**先微更新再更新组件；**普通选项循环**的微更新在按键出口检查之后；**自由文本编辑循环没有内建 `pbUpdateSceneMap`**（只能由额外调用/传入块提供）。菜单中地图事件/公共事件的更新差别归 WP13（引用）。不能写成所有交互都有固定的共同更新顺序。

### 7.3 输入刷新与临时标记

- 每个交互正常结束后 `Input.update` 防止触发残留传入下一交互。
- `Input.text_input` 进入开启/退出关闭、`message_window_showing` 创建置位/销毁清除——**这些清理只位于正常出口**：传入块或组件中途抛错会绕过本地关闭与 dispose（无 ensure 保护）；外层淡出包装（`pbFadeOutIn`）的 ensure 负责淡出状态与视口，**不负责该输入开关**。正常清理 ≠ 异常保证，局部可证后果如实登记，不保证顶层所有异常恢复。
- **资源与缺失**：皮肤/图片/图标资源按 WP15 具体入口引用（pbResolveBitmap 缺失 nil 等），不概括为"所有缺失都返回 nil"。
- **抛错路径**：`\ch` 的 CSV 解析按 3.2 的实际拒绝条件抛异常（沿解释器异常分层，WP07/WP13 引用）；取消/失败的领域写入归相应后续包。

## 9. 边界、失败与未知

- 选项 nil → 立即返回 0；空数组 [] → 建窗循环（零条目不移动光标，USE 返回索引 0，BACK 按取消策略）。
- 数字初值越界 → 夹限；范围 min > max → max = min；确认越界 → 蜂鸣继续等待。
- 显式取消值不夹限：可与合法值相同或越界（范围 [3,3] 确认只返回 3，BACK 仍返回取消值）。
- setDefaultValue 清除取消值、setInitialValue 保留（顺序敏感）。
- 文字：初始内容不被截短（超长初值可直接确认）；键盘/自由文本超长拒绝新增，光标场景满长先删再插。
- 文字 minlength = 0 时键盘场景 ESCAPE 返回空串；minlength > 0 时 ESCAPE 无效；光标场景 OK 长度不足时先播确认 SE 不退出（无蜂鸣）。
- `\ch` 解析：变量号接受 0；取消字段可为负/0/非数字转 0；引号校验按实际拒绝条件抛异常（WP07/WP13 引用）。
- 中断清理：text_input/消息标记/组件 dispose 只保证正常出口（异常路径绕过，7.3）。
- 消息窗资源失败按WP15 §5.1分入口：头像两目录都未解析到时nil交给动画位图入口明确报错；已消费内嵌图像按直接加载边界传播异常，不能统一写无图或保持现状。正常出口与顶层异常恢复继续分开。
- 宿主输入（重复延迟、文字事件、鼠标）行为未运行验证；栈式绘制标记未闭合的跨调用残留未逐调用验证（附表引用）。

| 键盘场景取消 | minlength=0，按 ESCAPE | 返回空串；minlength>0 时 ESCAPE 无效 |
| 自由文本取消 | 编辑后按 ESCAPE | 返回原文（编辑作废） |
| 另一解释器 | 解释器 A 显示消息中，解释器 B 有更新机会且自身无等待 | B 仍可执行合法命令（如全局开关赋值）；B 尝试显示新文本时被入口守卫拒绝 |
| 自由文本无更新块 | pbFreeText 循环一帧 | 无内建 pbUpdateSceneMap（地图侧更新只能由额外调用/传入块提供） |
| 传入块抛错 | 进入自由文本编辑（text_input 开启）后传入块抛错 | 本地 text_input 关闭与 dispose 不保证到达（无 ensure）；淡出包装的 ensure 不负责该开关 |
