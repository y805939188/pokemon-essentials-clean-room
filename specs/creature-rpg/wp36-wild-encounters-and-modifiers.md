## 1. 目的、范围与非目标

**目的**：定义"从踩步/转向或主动请求到是否开战"的完整普通遭遇链——遭遇数据（地图×版本、类型目录、PBS 文本约束）、类型选择与时段回退、步进触发概率与加速器、多方修正（地图级/首队员道具与特性/驱虫剂/雷达直通）、候选选择与等级决定、生成期修正（持有物/闪光/性别/性格/病毒/钩子）、开战交接与状态清理；供场地能力（WP59）、钓鱼（WP60）、漫游/雷达（WP37）、捕获/战斗（WP38/WP39/WP42）与图鉴（WP62）引用。

**范围**（WP36 自身声明范围，extraction-plan 第 2.1 节 (a) 类）：

1. WP36-A：遭遇数据——地图×版本键、版本回退、类型目录（26 项/6 类）、PBS 格式与编译器校验、步骤概率缺省来源。
2. WP36-B：触发——步进/转向入口与抑制条件、机会判定（地形/冲浪/洞穴）、类型选择与时段细分回退、触发概率公式与步数宽限/累加器、双打判定。
3. WP36-C：选择与等级——候选偏好过滤（特性）、多次掷取最大、等级区间与取整、等级修正（特性/黑白哨）。
4. WP36-D：生成修正——持有物概率、闪光重掷、性别/性格倾向、病毒、创建钩子与示例修正目录。
5. WP36-E：开战交接——pbEncounter/步进路径的返回、`$game_temp.encounter_type` 生命周期与消费者、清理。
6. F10-01/F10-02 中属于 WP36 部分的状态更新。

**非目标**：

- 不定义漫游个体与雷达连锁状态机（WP37；本包只登记替换点与接口）、Safari/捕虫大会会话（WP53）。
- 不定义战斗启动细节（WP39）、捕获（WP38）、战后结算与再遭遇抑制（WP42）。
- 不重定义队伍/箱子集合口径（WP25）、个体生成字段与派生（WP18–WP21、WP19 引用）。
- 不展开真实 Demo 地图的遭遇编排（U01）；不运行参考选取器/表达式。

## 2. 概念与术语

- **遭遇数据（Encounter）**：以"地图 ID + 版本"为键的一组表；每表含若干**遭遇类型**与各自的**步骤概率**；类型表内为若干**槽位**（权重, 物种, 最低等级, 最高等级）。
- **遭遇类型（EncounterType）**：**26 项**；每项有**类**（:land/:cave/:water/:fishing/:contest/:none）与**缺省触发概率**（供 PBS 省略概率时使用）。
- **版本（encounter_version）**：玩家全局的遭遇版本号（缺省 0）；查询"地图×当前版本"不存在时回退到该地图的版本 0。
- **步骤概率与累加器**：基础概率来自该地图该类型的 PBS 行；未中时把基础值累加到 `chance_accumulator`，下次步进时折算进概率；驱虫剂活动时该次不累加（且清零）。
- **步数宽限（min steps）**：距上次成功遭遇的步数不足时，额外先做一次"放大掷"；两个阶段都登记。
- **首成员口径（术语）**：**首非蛋成员**（排除蛋、**允许濒死**）与**首位可战斗**（另排除濒死）是两个查询，都**不是队伍数组首项**；本包按各处实际用法引用（§4.2/§4.3/§5/§6）。
- **双打遭遇**：一次触发可能生成两个个体进入双打（条件见 §4.4）。
- **生成钩子**：生成个体后、开战前触发的 `on_wild_pokemon_created`（以及选择物种时的 `on_wild_species_chosen`）事件钩子，供示例/插件修正。

## 3. WP36-A：遭遇数据与类型目录（静态核对）

### 3.1 数据键、版本回退与枚举反例

- 编译登记键 = **`地图ID_版本号`的符号**（注册按该符号 id 存放）；`get(map, version)`：**按符号精确命中，未命中时回退版本 0**；`exists?` 为精确判定（**不存在"全部查询都回退"的泛化**）。
- **枚举的固定快照反例**：`each_of_version(v)`（v>0）在"是否产出该地图版本 0"的检查中**使用了错误形状的键（数组 vs 符号）**，正常编译数据下该检查永不命中——因此**即使同地图已有版本 v 的表，枚举 v 仍会先产出其版本 0、再产出版本 v**（同一地图出现两次，不是择一）。静态对照：地图 5 同时有 0/1 版时——`get(5,1)` → 1 版；`each_of_version(1)` → 先 0 版后 1 版；仅 0 版时枚举 1 → 仍产 0 版；`v=0` 枚举 → 无上述重复。PBS 的 `[005]` 与 `[005,1]` 为具名样本。**不修 reference、不把该反例传播成"单次查询也错误"、不提前展开图鉴。**
- 版本写入先校验整数；同值立即返回，不重装、不清宽限步数。异值先更新版本，仅在地图与遭遇上下文都存在时装载当前地图：装载重置宽限步数和表/步骤概率，保留累加器。异值但缺上下文只写版本。调试确认同值也适用该早退（WP73 交界）。
- 静态对照：当前版本 1、宽限步数 4、累加器 210、地图与合法遭遇上下文存在；确认 1 → 表不重读、步数仍 4、累加器 210；确认 2 → 装载、步数 0、累加器仍 210。非整数在同值比较前拒绝。

### 3.2 PBS 文本格式（`PBS/encounters.txt`）

```
[地图ID]            或 [地图ID,版本号]   # 段头；同一组合重复出现 → 编译错误
类型名[,概率]                              # 开始/替换该类型槽；概率省略/空值按下述继承规则
  权重,物种,最低等级[,最高等级]           # 槽位行（缩进非必需，以"数字+逗号"开头识别）
```

- 段头的地图 ID、版本按十进制整数前缀转换：无可转换前缀则为 0；版本省略则为 0。例如 [005tail,1tail] 对应地图 5、版本 1，[junk] 对应 0、0；转换后的同一地图×版本重复节仍拒绝。遇到下一段头时先合并/登记前一节，再检查新节是否重复；重复节错误不回滚此前登记，错误发生时尚未到最终数据档案保存。
- 槽位行在已有类型且行以数字紧接逗号开头时识别；权重和等级必须为正整数字面值（0 拒绝），等级在 1..最大等级（100）、最低 ≤ 最高；最高省略/空值 = 最低；物种必须已登记。负权重不进入数字开头的槽分支，随后按类型行校验失败，不能说与零权重同阶段失败。
- 编译处理：**同物种且同等级区间**的槽位合并（权重相加）；随后按"权重降序、物种名升序"排序。物种/类型/等级格式由编译期校验（未定义类型 → 编译错误）。
- 非空概率字段按十进制整数前缀转换（例如 70tail → 70、junk → 0），不套用槽位的正整数校验。概率省略/空值：同节该类型已有概率则保留，否则取类型目录默认。重复类型声明会丢弃该类型旧槽、重新接收其后槽，独立于概率继承：同节先 Land,70＋PIDGEY 权重100/L5，再 Land（省略概率）＋RATTATA 权重100/L5 → 仅 RATTATA 槽，概率仍70；独立 Land,junk → 概率0。

### 3.2.1 登记、文件与当前地图生效层

当前地图在装载时取得步骤概率与类型槽的独立快照。直接地图数据查询读取登记数据；步进机会、类型、概率与当前地图候选选择读取快照。编辑/保存/调试编译不自动广播刷新快照，不能把注册或文件变化写成当前地图立即生效。

| 操作（初态：登记/数据档案/文本/快照的 Land 概率均21） | 登记/数据档案/文本 | 当前地图快照 |
| --- | --- | --- |
| 编辑当前登记 Land 概率到0，尚未保存 | 登记0；数据档案和文本仍21 | 仍21 |
| 确认保存，相关文件操作成功 | 登记0、数据档案0；反写文本为 Land（省略第二字段） | 仍21 |
| 从编辑态取消、重新载入原数据档案21成功 | 登记恢复21；数据档案/文本未保存 | 仍21 |
| 从保存后的 Land 无概率文本成功重编译 | 登记和数据档案恢复默认21；文本仍无第二字段 | 不因编译自动刷新 |
| 编辑保存为0后，版本同值写入 | 保持已保存登记0 | 仍旧21；步数/累加器不变 |
| 编辑保存为0后，异值版本或地图进入实际装载，所选版本回退命中这条记录 | 按装载时登记读取0 | 更新0；宽限步数0、累加器保留 |

0→省略→21 是文件往返的语义损失，不是快照缺陷；本表不执行编译、转换或读档，也不保证某一步必定开战。

### 3.3 遭遇类型目录（26 项）

| 类 | 类型 id | 缺省触发概率 |
| --- | --- | ---: |
| land | Land、LandDay、LandNight、LandMorning、LandAfternoon、LandEvening | 21 |
| land | PokeRadar | 20 |
| cave | Cave、CaveDay、CaveNight、CaveMorning、CaveAfternoon、CaveEvening | 5 |
| water | Water、WaterDay、WaterNight、WaterMorning、WaterAfternoon、WaterEvening | 2 |
| fishing | OldRod、GoodRod、SuperRod | 无（0） |
| none | RockSmash | 50 |
| none | HeadbuttLow、HeadbuttHigh | 无（0） |
| contest | BugContest | 21 |

- 类语义：移动的陆地汇总包含 land 与 contest 的非空表；洞穴/水汇总分别为 cave/water。雷达许可使用的「普通陆地」查询仅含 land，排除 contest（WP37）。fishing 由钓鱼流程直接请求（WP60）；none 类由场地能力请求；contest 的会话与预算归 WP53。
- **触发概率为 0 或未定义的类型**在步进触发处一律被拒（§4.2 首道门），因此 fishing/Headbutt 等不会被走路触发。

### 3.4 机会判定与类型选择

- **机会判定** `encounter_possible_here?`：冲浪中 → 真；当前脚下地形为冰 → 假；本地图有**洞穴类**遭遇 → 真（洞穴不看单个地格）；有**陆地类**遭遇且脚下地形标记"可野生遭遇" → 真；否则假。
- **类型选择** `encounter_type`（每次触发前计算，时间取当前）：
  1. 冲浪中 → Water 族按时间细分（§3.5）。
  2. 否则：若本地图有陆地遭遇且脚下地形可遇 → 先看捕虫大会（在大会中且有 BugContest 表 → 该类型），否则 Land 族按时间细分；若仍未得 → 若本地图有洞穴遭遇 → Cave 族按时间细分；否则空。
  3. 结果为**空**则本次不触发。
- **时段细分回退**（单类型函数）：先按谓词挑"基础+Morning/Afternoon/Evening"（**昼间且细分类型存在时优先**），否则"基础+Day"（存在才用）；夜间用"基础+Night"；若夜间类型**未定义**则再退回基础类型；全部不存在 → 空。类型必须以该地图已定义为准（无表不选）。

### 3.5 时段输入

- 时段谓词与边界完全引用 WP59 §3.2（morning 5–10、day 5–20、afternoon 14–17、evening 17–20、night 20–5）；昼间与细分重叠时**细分优先**（morning > afternoon > evening 的判定顺序即代码顺序）。

## 4. WP36-B：触发（步进/转向/请求）

### 4.1 入口与抑制

- **步进入口**：迈步计数按非负31位回绕（新值=(旧值+1) mod 2147483648；2147483647→0，非饱和钳制；WP06）→ 触发全部 `on_player_step_taken` 处理器（含 WP59/WP35 的钩子）→ 触发 `on_player_step_taken_can_transfer`（若被处理则终止）→ **若本次步进由事件触发（eventTriggered）或处于菜单中 → 跳过战斗检查**；否则 `pbBattleOnStepTaken(驱虫剂活动)`；随后复位 `$game_temp.encounter_triggered`。
- **转向入口**：玩家原地转向也调用同一检查（非菜单时）——转向可触发遭遇。**标记去留按转向发生的上下文分两路（GR-011）**：普通移动所作转向（移动入口以"保留标记"参数调用转向）把本次标记留给同次移动入口的消费门（WP12 §4.1：为真时跳过该次移动/触碰/碰撞，方法末尾清标记）；**独立转向**（默认参数路径）在通知后清标记，不为下一次独立移动保留本次拦截。
- **主动请求入口**（绕过步进机会与概率门，见各族）：碎岩（RockSmash 类型，先查触碰概率）、摇树（HeadbuttLow/High，摇树概率见 WP59 §5.5）、甜味（当前类型直取）、钓鱼（OldRod/GoodRod/SuperRod，WP60 流程）。
- `$game_system.encounter_disabled`：事件命令 136（参数 0=禁用）可整段禁用触发；触发函数首查。

### 4.2 触发概率（算法，按行为描述）

`encounter_triggered?(类型, 驱虫剂活动, 由步进触发)` 依次：

1. 类型不存在 → 抛参数错误；`encounter_disabled` → 假；无玩家 → 假；**DEBUG 且按住 Ctrl** → 假。
2. 该类型无步骤概率或为 0 → 假；该类型无表 → 假。
3. **雷达摇晃草丛直通**：为真（跳过下两步）；否则：
4. 基础概率 = 该类型步骤概率（浮点）；最小步数 = `clamp(8 − 概率/10, 0, 8)`。
5. **修正（按序）**：由步进触发时——**概率 +=（累加器 ÷ 200 的整数商）**（先整数除、再与概率相加；正常 PBS 数据下步骤概率与累加器均为整数，故加数是非负整数而非小数）；骑自行车 → 概率 ×0.8。地图级：降遭遇（黑哨旧效果）→ 概率 ÷2、最小步数 ×2；升遭遇（白哨旧效果）→ 概率 ×1.5、最小步数 ÷2（降优先）。首队员道具/特性（**道具优先于特性**）：洁净符/纯净薰香 → ×2/3、×4/3；否则特性——恶臭/白烟/飞毛腿/（若启用扩展）穿透 → ÷2、×2；雪隐（**当前世界天气类别 = 冰雹**）→ ÷2、×2；沙隐（**沙暴**）→ ÷2、×2；虫之预感 → ×1.5、÷2；发光/沙穴/无防守 → ×2、÷2。雪隐/沙隐读取世界天气类别（WP59 §4.1 引用）。**次序**：累加折算与自行车修正发生在**地图级与道具/特性修正之前**（正文、不变量与批末检查保持一致）。
6. **步数宽限与放大掷**（仅由步进触发且 `step_count < 最小步数`）：`step_count += 1`；做一次放大掷——**通过阈值 = 修正后概率×5 ÷（该类型基础步骤概率 + 累加器÷200 的整数商）**（分子用修正后概率、分母用基础值+整数折算）；`rand(100) ≥ 阈值` → **假，本次结束**；否则**落回下一步再做常规掷**。
7. **常规掷**：`rand(100) < 概率` → 真；否则（仅步进触发）：**累加器 += 该类型基础步骤概率**；若驱虫剂活动 → 累加器清零；返回假。
- **"未中"分两类**：宽限放大掷拒绝 → **不累加**（在累加之前返回）；宽限通过、常规掷失败 → 才累加（且仅步进入口）。场景必须写明前提。
- **重置入口（全部；不保留"仅驱虫剂清零"的穷尽说法）**：`reset_step_count` **同时清步计数与累加器**——直接调用者：冲浪开始/结束（WP59 §5.3）、战斗开场动画与战斗启动前置交界（只记录直接调用，不展开战斗结算）；**装图/版本装载只重置步计数与表、保留累加器**。
- 静态向量（整数折算法）：基础 21、无其它修正——**A=21/189/210 → 概率 21/21/22**（21÷200=0；189÷200=0；210÷200=1）。放大阈值：21×5/21=5；5×5/5=5；2×5/2=5。最小步数：21→5.9、5→7.5、2→7.8、50→3.0。**宽限第一掷失败 → A 不增**；经过宽限且常规掷失败 → A += 21。
- **由步进触发才累加/宽限**；转向与主动请求按各自入口的调用参数执行（转向调用同以"步进"参数为真——静态记录）。

### 4.3 允许判定 `allow_encounter?(候选, 驱虫剂活动)`

1. 候选为空 → 假；**雷达摇晃草丛直通** → 真（不查驱虫剂）。
2. **驱虫剂**：活动的口径为 `$PokemonGlobal.repel > 0`；目标口径由配置 `REPEL_COUNTS_FAINTED_POKEMON` 二选一——真：**首非蛋成员**（含濒死）；假：**首位可战斗成员**。若该成员等级 > 候选等级 → **累加器清零**、假。
3. **威吓/锐利目光**：**首非蛋成员**具备且候选等级 ≤ 该成员等级−5 时，50% → 假。
4. 否则真。

### 4.4 双打判定 `have_double_wild_battle?`

- 强制单打标记 → 假；Safari 中 → 假；有伙伴训练家 → **真**；可战斗成员数 ≤1 → 假；脚下地形标记"双打遭遇" → 30% → 真；否则假。

### 4.5 步进入口全程（PBattleOnStepTaken）

1. 前置早退链：可战斗成员数 = 0 → 返回；机会判定（§3.4）为假 → 返回；类型为空或触发（§4.2）为假 → 返回。**早退不一定到达末尾的 force_single 复位**（静态边界）。
2. 写 `$game_temp.encounter_type`；选择候选（§5.1）；触发 `on_wild_species_chosen` 钩子。
3. `allow_encounter?`（§4.3）为真时：需要双打则再选第二候选（并再触发选择钩子）→ `WildBattle.start(候选[,第二候选], can_override: true)`；**调用正常返回后**（不取决于战斗启动的布尔结果）清 `encounter_type`、置 `$game_temp.encounter_triggered = true`——该标记的直接消费者是同次普通移动入口的移动门（WP12 §4.1：为真时跳过本次移动/触碰/碰撞，末尾清标记；GR-011）。
4. 无论结果：`$game_temp.force_single_battle = false`。
- 若 `allow_encounter?` 为假（如驱虫剂挡住）：`encounter_type` **保留**（不清理）——静态边界记录。
- **强制移动/地图解释器运行时**：普通步进入口在**计数与事件链之前分流**（转 `on_step_taken` 后返回），**不走通常的步数增量和 on_player_step_taken 链**——遭遇链不会以本次步进为输入。

## 5. WP36-C：候选选择与等级

### 5.1 当前地图选择 `choose_wild_pokemon(类型, chance_rolls=1)`

1. 类型校验、取表；空表 → 空。
2. **偏好过滤（“首非蛋成员”特性）**：引火→火（需扩展配置+类型存在+50%）、收获→草（同前）、避雷针→电（同前）、磁力→钢（类型存在+50%，**不看扩展配置**）、静电→电（类型存在+50%，**不看扩展配置**）、引水→水（需扩展配置+存在+50%）；命中则**筛出含该属性的槽位**（筛空则不筛，保留原表）。
3. 按权重降序排序；总权重 = Σ权重。
4. **掷取**：做 `chance_rolls` 次 `rand(总权重)`，**取最大 r**（多次掷提升稀有槽命中）；沿排序表用 r 递减定位槽位。
5. **等级**：`rand(最低..最高)`（含端点）；随后首非蛋成员 HUSTLE（活力）/PRESSURE（压迫感）/VITALSPIRIT（干劲）→50%取最高等级；GUTS（毅力）不属于该集合且不消耗这次能力百分掷；地图级黑白哨新效果——降等级：等级 − rand(1..4) 钳制 ≥1；升等级：等级 + rand(1..4) 钳制 ≤最大等级（降优先）。

### 5.2 指定地图选择（捕虫大会其它参赛者）

- `choose_wild_pokemon_for_map(地图, 类型)`：查"地图×当前版本"的静态表（无则空）；单次掷、无偏好/无等级特性/无哨修正；等级 `rand(最低..最高)`。

## 6. WP36-D：个体生成与修正（`pbGenerateWildPokemon(物种, 等级, 漫游?=假)`）

1. 以物种+等级创建个体（WP18–WP21 创建默认与派生引用）。
2. **持有物**：读取物种的野生持有物三档；基础概率 [50, 5, 1]；**首非蛋成员**复眼/超幸运（后者需扩展配置）→ [60, 20, 5]；若三档同物 → 恒取第一档；按掷值落档后从该档**随机采一枚**。
3. **闪光重掷**：次数 = 背包持有闪耀护符 ? +2 : 0；若启用 `HIGHER_SHINY_CHANCES_WITH_NUMBER_BATTLED`——按图鉴"对战次数"分档（<50→0；50–99 概率 15‰ 加 1；100–199 概率 20‰ 加 2；200–299 概率 25‰ 加 3；300–499 概率 30‰ 加 4；≥500 概率 30‰ 加 5）；次数 >0 时循环：已闪光停止，否则清闪光缓存并重掷个体号（与蛋的重掷同构，WP34 引用）。
4. **病毒**：`rand(65536) < 病毒概率` → 给予（毒株随机 1–15，统计 +1；WP61 前向）。
5. **性别/性格倾向（“首非蛋成员”，允许濒死；术语见 §2 与 §6 表头）**：**迷人身躯**且目标**非单性别**——首成员为**雄性**：2/3 强制**雌性**、其余 1/3 强制**雄性**；首成员为**雌性**：2/3 强制雄性、其余 1/3 强制雌性；首成员**无性别**：**不执行这两种赋值**（分支列表完整，非"不命中则保留默认"）。**同步**（非漫游个体；需扩展配置或另掷 50%）→ 性格=首成员性格（**改写已派生缓存**，WP19 引用）。
6. 记录初始形态（形态函数存在时），触发 `on_wild_pokemon_created` 钩子（示例目录见 §6.1）。
7. 返回个体（未入队；开战由调用方发起）。

### 6.2 队伍平衡等级（独立数学合同）

输入为传入队伍的全部成员等级 l₁..lₙ，包含蛋与濒死成员，不先按可战斗资格过滤；最大等级记为 M（默认100）。空输入或等级和 S=0 时直接返回1（零等级和为人工输入边界）。否则 μ=S/n，人口标准差 σ=√(Σ(lᵢ−μ)²/n)，初始占比 pᵢ=lᵢ/S。权重按占比分段：pᵢ<0.5 时 wᵢ=max(pᵢ−σ/M,0.001)，pᵢ≥0.5 时 wᵢ=min(pᵢ＋σ/M,0.999)。以 W=Σwᵢ 归一，加权均值 a=Σ(lᵢwᵢ)/W；将 a 四舍五入到整数（正数半值向上），先限制不低于1，再加2并限制不超过 M：平衡等级=min(max(round(a),1)＋2,M)。

固定静态对照：M100、[5,5] → σ0、权重各0.5、平衡等级7，示例缩放7−4＋0..4 → 3..7；[10,50] → σ20、权重0.001/0.999、加权49.96→50→52，缩放48..52。空队伍→1；人工[0,0]→1；[100,100]→100（加2后上限约束）。此处集中提供可供 WP77 等消费者引用的数学规则，未修改其责任文件或执行算术/行为向量。

## 7. WP36-E：开战交接与状态生命周期（按入口分列）

- **禁用开关**：`encounter_disabled` **只在触发检查**（§4.2 第 1 步）读取——**登录的主动请求路径（`pbEncounter`）不读它**，也不调用机会/驱虫剂允许判定。各族对照：碎石请求**先过触发检查**（因此受禁用影响）；摇树/甜味/钓鱼的主动请求**不受该开关约束**（静态边界；钓鱼引用遵循本节，不复写）。
- `$game_temp.encounter_type`：步进入口在开战前写入；**清理只在开战调用正常返回后**执行（不取决于战斗启动的布尔结果）；`allow_encounter?` 拒绝时保留（§4.5）。
- `pbEncounter(类型, only_single=true)`（钓鱼/摇树/碎石/甜味调用）：
  1. 写 `encounter_type`；选第一候选；触发物种钩子。
  2. **第一候选为空 → 返回 false**（**类型值保留、原 force_single 不复位**——静态边界）。
  3. 不强制单打且双打条件成立 → 选第二候选（再触发钩子）；**第二候选为空 → 返回 false**（同上保留）。
  4. 否则 `WildBattle.start(候选[,第二候选], can_override: true)`；**调用正常返回后**清 `encounter_type`、复位 `force_single_battle`、返回 `true`（**即使战斗启动返回假，也执行清理并返回真**）。
  - **甜味以 only_single=false 调用**（可双打），其余为单打默认。
- `$game_temp.encounter_triggered`：仅用于当次标记——**生产端仅为步进/转向检查链在开战调用正常返回后的置真步骤**（§4.5）；**主动请求包装（pbEncounter，§7）本身不写该标记**：其开战调用正常返回后只清 encounter_type、复位 force_single_battle 并返回 true——初始标记为假时包装返回后仍为假；原值为真且无其他写入时，包装也不会自行清掉（GR-011 v2）。**直接消费者为同次普通移动入口的移动门**（WP12 §4.1：为真时跳过该次移动/触碰/碰撞并在方法末尾清标记）；独立转向默认路径在通知后清标记，步后入口在其自身末尾清标记。
- `$game_temp.force_single_battle`：正常路径复位；**更早的前置拒绝不一定到达复位点**（§4.5 第 1 步）；漫游/雷达设置（WP37 引用）。
- **生命周期终态（按入口分列；早退，静态）**：
  - 步进触发检查假 → 无写入（§4.5 第 1 步早退；不下探后续分支）。
  - **pbEncounter**（主动请求）：第一或第二候选为空 → **返回 false**，已写类型与**原 force_single 保留**；开战调用正常返回（含战斗启动返回假）→ 清类型、force_single=false、**返回 true**。
  - **步进入口**：已到达 allow 拒绝阶段 → 已写类型保留，但方法末尾仍执行 force_single=false；开战调用正常返回 → 清类型、置 encounter_triggered、force_single=false（**不套用 pbEncounter 的 true 返回合同**——方法与末项赋值同值、为假，不作布尔合同提取）。
  - **更早的步进前置拒绝**按 §4.5 第 1 步早退前提，不泛化为"所有拒绝都清理"。
- 两入口**不共用同一张终态表**；**"正常返回后清理"不等于"战斗成功后清理"**。
- 战斗启动本身（阵容、规则、环境）归 WP39/WP45/WP53 前向；本包只固定"已发起调用"与上述临时状态；**调用 ≠ 实际战斗成功**。

## 8. 规则与不变量

1. 数据键"地图×版本"、版本查询回退 0、重复定义编译错误；每表类型独立、步骤概率缺省来自类型目录。
2. 步进触发的三道前置门（可战斗成员/机会判定/类型非空）+ 概率门（§4.2）；主动请求入口按各族自己的前置（不经机会判定与概率门）。
3. 类型选择严格"已定义才选"；时段细分优先于 Day/Night 基础，night 未定义回退基础；无表不选。
4. 概率链的修正按固定顺序应用（累加折算与自行车在地图级与道具/特性修正之前）；**清除累加器**发生在：`reset_step_count`（冲浪起止/战斗交界）、驱虫剂挡下、驱虫剂活动时未中；**装图/版本装载保留累加器**；累加只在"步进触发且**经宽限后**常规掷未中"发生（**宽限放大掷拒绝不累加**）。
5. 闪光/病毒/性别/性格等生成期修正不改候选选择；选择期修正（偏好过滤/哨）不改生成期概率。
6. 双打判定的优先次序：强制单打 > Safari > 伙伴(真) > 成员数(假门) > 地形 30%。
7. encounter_type 生命周期与清理按 §7；拒绝路径保留值。
8. 所有等级取整为整数区间均匀（含端点）；偏好过滤失败不产生空表（保留原表）。

## 9. 边界与失败

- 无表/空表按阶段区分：冲浪使机会判定为真，即使无任何表；随后 Water 类型为空则步进拒绝。非冲浪、无 land/contest/cave 非空表时机会为假。仅 BugContest 非空且允许陆地遭遇的非冰地形、大会进行中 → 机会真、类型 BugContest；不预设后续概率通过。请求自己的类型无表才无法选候选；无 land/cave/water 不排除独立合法 OldRod 表（正常开战调用返回时主动包装返回真）。
- 禁用：`encounter_disabled` **只在触发检查层**否决（含雷达：步 3 直通位于禁用检查之后）；**主动请求路径不受该开关约束（§7）**。
- 强制移动/地图解释器运行时：普通步进在计数前分流，本次步进不进入遭遇链（§4.5）。
- DEBUG+Ctrl：仅抑制触发（搭配调试穿透移动，WP12 引用）。
- 驱虫剂挡住：`allow_encounter?` 拒绝后**累加器清零**；`encounter_type` 保留（§7）。
- 候选空：`pbEncounter` 早退——**类型保留、原 force_single 不复位**（§7 终态表）。
- 版本回退：支持版本回退的数据读取在当前版本表缺失时落到版本 0；版本号异值且必要上下文存在时装载当前地图表；**枚举反例见 §3.1**（不传播到单次查询）。
- 宽限：**放大掷拒绝不累加**；宽限通过、常规掷失败才累加（§4.2）；概率被修到 0 → 阈值 0 → 放大掷必假。
- 偏好过滤后空表：保留原表（过滤无效，不影响可得性）。
- 等级钳制：哨效果钳制到 1..100（升等级上限=最大等级）；区间取整含端点（单等级行 min=max）。
- 双打第二择空：`pbEncounter` 返回假、不开战（第一候选不消耗，状态保留见 §7）。
- 真实地图编排、概率分布抽样验证与开战集成：运行未决（U01/运行范围）。
