# WP13 附表：解释器命令兼容矩阵

本附表是 [wp13-map-events-npc-followers](wp13-map-events-npc-followers.md) 的取证附件（WP13-C 验收物）。
范围为固定基线 `S/003_Game processing/004_Interpreter_Commands.rb`（1180 行）中解释器命令分派（`execute_command`，11–119 行）与全部 `command_NNN` 定义。移动路线命令有独立分派，见 [wp13-move-route-matrix](wp13-move-route-matrix.md)，不在本表。

分类：**有实现**（有实际行为逻辑）／**空操作**（`command_dummy`，跳过且无效果）／**标记**（按设计无操作的流程标记）／**未分派回退**（不在分派表中的任意代码 → 返回 true 跳过并继续）。命令名称只作行为定位，不是未来框架的命令 API。完整业务语义（如战斗/商店/菜单流程）归相应领域包。

**控制结果列口径**（WP13-R02 修订）：区分"启动效果后继续"（调用生效、立即执行下一条，不等效果完成）、"等待 X 后继续"（解释器进入对应等待状态）、"分支执行"（按条件跳转）、"index 推进"（命令体自身改变 @index 的特殊情况）。返回 true 只表示继续执行下一条，不代表业务成功。

## 1. 分派与回退规则

- `execute_command`：到达命令列表末尾 → `command_end`（清除列表与跟随者覆盖；主解释器且事件 ID 有效时解锁事件）。
- 命令代码在分派表中 → 调用对应 `command_NNN`。
- 命令代码不在分派表中（`else` 分支）→ 返回 true，跳过并继续下一条（`@index += 1`）。
- **续行消费**：401（文本续行）由 101 在命令体内消费（169–178 行）；655（脚本续行）及相邻 355 由 355 合并执行（1168–1175 行）。"未单独分派"不等于无作用——这两类代码是上游命令的数据延续，正常流程中不会直接到达默认分派分支。
- 脚本命令（355）的异常：SystemExit/Reset 原样抛出，其他异常按事件错误处理（`003_Interpreter.rb:138–146` 及后续）。
- 命令返回 false 时解释器本轮停止（`003_Interpreter.rb:131–134`）；返回 true 时外层 `@index += 1`。

### 2.2 连续选项、取消与一次性改写
