## 1. 目的、范围与非目标

### 1.1 目的

从作者（游戏制作者）视角规定战斗动画的**制作、组织、交换与关联**能力：

- 战斗动画编辑器（debug 菜单「Battle animation editor」）：逐帧逐单元编辑、区间批量工具、音画时序、预览播放、单项 `.anm` 导入导出、保存与缓存失效。
- 动画组织器（「Battle animation organiser」）：集合内动画的排序/插入/删除与保存。
- 批量导入导出（「Import/Export all battle animations」）：`Animations/` 目录级别的整套交换。
- 辅助制作工具 `animmaker.exe`（仅文档陈述边界）与 `animmaker.txt` 的 XML 输入格式。
- 动画与招式/公共命名的**关联合同**（命名约定 → 编译产物 → 播放查找），只规定编辑器侧可见的命名与编译输入输出。

### 1.2 范围（A～F）

- **A 进入/离开与环境恢复**：入口、屏幕尺寸/缩放因子切换、BGM 停止与恢复、退出确认与缓存失效。
- **B 集合与动画管理**：动画列表（载入/重命名/删除/容量）、图样表与 hue、焦点位置、动画命名对关联的意义。
- **C 帧与单元编辑**：画布直接操作（鼠标/键盘全映射）、单元属性对话框、帧操作（复制/粘贴/清空/插入/删除/帧数）。
- **D 区间与路径工具**：复制帧区间、清空区间、补间、单元批改、整幅滑动、定义路径（平滑曲线/自由手绘）、音画时序五类。
- **E 预览与播放合同**：编辑器内预览（用户侧/对方侧）、与战斗播放器共享的逐帧应用合同、时序播放。
- **F 交换与兼容**：单项 `.anm` 导入导出、组织器、批量导入导出、旧格式转换、素材缺失与失败行为、辅助工具文档边界。

### 1.3 非目标

- 不规定战斗中动画的完整播放语义（属 WP67-A 已通过范围）；本包只登记编辑器预览与播放器的**共享逐帧合同**及命名关联的**编译侧输入输出**。
- 不重提取 WP72（debug 菜单框架、窗口/命令基础设施、安全复制与导入导出保护不对称）、WP73-A（编辑器通用框架、分配/复制工具函数）、WP15（RTP 资源解析）、WP17（消息/窗口/输入）、WP04（编译器生命周期）；这些以依赖身份引用。
- 不运行编辑器/播放器/批量工具，不验证实际画面、音频或文件写入效果；不反编译或启动 `animmaker.exe`；demo 素材缺口如实登记为未验证。
- 不设计未来 API 或类体系；正文按行为组织，审计名（方法/常量/路径）仅作 traceability 标识。

## 2. 概念与术语（实现中立）

- **动画集合**：有序动画槽序列，槽位从 0 起编号；有「当前选中槽」游标。**构造默认 1 个动画**（新建集合与容量下限 1 只约束对应入口；组织器删除可达 0 项、缩容后游标可越界——见 §7.1／§12，「至少一项」不是全局不变量）。持久化于 `Data/PkmnAnimations.rxdata`，运行期缓存于全局临时数据（WP04/WP73-A 同款缓存模式）。
- **动画**：命名实体＝名字＋图样表名（无扩展名）＋色相（0–359）＋焦点位置默认值＋有序**帧**序列（至少 1 帧）＋**时序项**列表。`id` 为兼容字段（本工具链新建/导入一律 −1，表示「非 RPG Maker XP 动画」）；`speed` 为惰性元数据（默认 20，编辑器无编辑入口，播放侧未消费——见 §10.4）。
- **帧**：常规可编辑/可渲染的单元槽序列（槽 0–59 共 60 个常规槽；「重编号」可把单元换到第 60 号存储槽——数据存在但没有对应渲染，见 §4.5）。新建帧自带两个**个体单元**：槽 0＝使用者（图案 −1、焦点＝使用者、锁定），槽 1＝目标（图案 −2、焦点＝目标、锁定）。
- **单元（cel）**：25 项语义属性的集合（按语义描述，不绑定存储布局）——X/Y 坐标、XY 缩放（百分比）、角度（0–359 度）、镜像、混合方式（0/1/2）、可见性、图案号（≥0 为图样表单元；−1＝使用者立绘、−2＝目标立绘）、不透明度、混合色（RGBA）、色调（RGB 偏移＋灰度）、闪烁色（RGBA）、锁定、优先级（0 最后/1 最前/2 焦点后/3 焦点前）、焦点（1 目标/2 使用者/3 双方/4 全屏）。新建单元默认：缩放 100、角度 0、不镜像、混合 0、可见、不透明 255、各色/色调/闪烁 0、优先级 1、不锁定。
- **时序项（timing）**：帧号＋五型之一——0 播放音效（名/音量/音高）；1 设置背景（图或抹除＋位置/不透明/混色）；2 渐变背景（时长＋可选位置/不透明/混色各项）；3 设置前景（同 1）；4 渐变前景（同 2）。新建默认音量 80、音高 100、时长 5，可选各项默认「不参与」（nil）。
- **图样表**：单张 PNG，按 192×192 单元格、每行 5 格编图案号（0 起）；编辑器条带按 96×96 缩略显示、5 格一屏。
- **剪贴板**：编辑器私有，带类型键（帧/单元两种）；写入时整体序列化快照，读出时反序列化为新对象——多次粘贴互不影响，也不与源共享。
- **关联命名合同**：动画名前缀 `Move: 招式名` / `OppMove: 招式名`（对方侧变体）经编译映射到招式；`Common: 名称` 供战斗侧按名查找公共动画（见 §15）。
- **交换格式 `.anm`**：单个动画的序列化压缩文本（可移植）；**不是**整个集合的快照。
- **`Animations/` 目录**：批量交换单位；每个子目录一套（`.anm`＋图样＋音效）。

## 3. 进入、离开与环境恢复（A）

### 3.1 入口

- debug 菜单 `main → editors_menu`（「Other editors...」）下四项：Battle animation editor／organiser／Import all／Export all（`002_Debug_MenuCommands.rb:1266–1305`；菜单框架与门属 WP72）。编辑器与组织器经淡出淡入过渡进入（WP16）。
- 编辑器进入序列（`pbAnimationEditor`，`005:1157–1170`）：停止 BGM；读取动画集合缓存（`pbLoadBattleAnimations`——**已有缓存优先**：缓存非空直接返回缓存对象；缓存为空且数据文件存在才载入文件**并写入缓存**；缓存为空且文件不存在则返回 nil 且不写缓存）；随后按**读取结果**分两支：**(a) 读取到有效集合**（非 nil 且首槽非空）→ 编辑对象即该（缓存）集合；**(b) 读取结果为 nil 或首槽为空** → 在本入口**新建临时默认集合**（1 个动画、1 帧、图案表名为空串）——该临时集合只替换本入口的局部引用、**不写回运行缓存**（缓存里仍是原内容）。屏幕尺寸加宽加高各 288 像素、缩放因子强制为 1；进入主循环。
- 离开序列：屏幕尺寸与缩放因子恢复（后者取系统设置值）；地图 BGM 按地图配置自动恢复。

### 3.2 退出确认与缓存失效（核心取消语义）

主循环中 BACK 触发**两道独立确认**（`005:994–1002`）：

1. 「Save changes?」——是：把整个集合写入 `Data/PkmnAnimations.rxdata`；否：不写。
2. 「Exit from the editor?」——是：**清空集合运行缓存**并退出主循环；否：返回编辑（第 1 道的选择不撤销——若已保存则已落盘）。

组合语义：保存＋退出＝落盘并失效缓存；不保存＋退出＝未落盘的改动对后续读取不可见（下次读取以文件为准）；保存＋不退出＝已落盘且继续编辑；不保存＋不退出＝仅内存态。

**编辑对象与可见性按进入分支与列表操作分列**（R01 修订——不再概括为「编辑全程作用于全局缓存对象」；v3 再按缓存内容细分前提）：

- **有效缓存复用**（分支 a）：编辑直接作用于缓存集合对象——未保存的改动对同一会话内读取同一缓存的其它路径（如同会话战斗播放）可见，直到缓存失效或落盘。
- **临时新建＝缓存为空且无文件**（分支 b1）：编辑作用于本入口的临时集合 T；**保存前**同会话其它缓存读取仍得 nil（缓存空、无文件）。**保存落盘后**：缓存仍为空但文件已存在——**下一次读取即触发载入并写入缓存**（无需失效）——其它路径自此看到 T 的保存内容；**首次重载所得是从磁盘读出的新对象**，与编辑器仍在编辑的临时对象 T **再度分离**（对 T 的后续改动不进新读取所得对象；再次保存会更新文件，但此时缓存已持有首次重载对象——读者仍看它，直到某次失效后再读才取新内容）。
- **临时新建＝缓存/载入结果首槽为空**（分支 b2，v3 补）：例如磁盘保存了首槽为空的集合 C（组织器保存 0 项集合即可形成）——载入后**缓存就是非空对象 C**；编辑器另建临时集合 T 不会改掉缓存：同会话其它读取**返回 C 而非 nil**；编辑器里选保存＝是、退出＝否把 T 写到磁盘，**缓存仍为 C，下一次读取仍返回 C**；直到退出或其它明确失效后，后续读取才从磁盘取得 T 的保存内容。
- **槽替换后画布脱离**（§7.1 删除/替换、缩容）：列表把某槽换成新动画后**不重新载入画布**——画布仍持有并编辑**已被移出集合的旧动画对象**；此时保存序列化的是集合（该槽已是新内容），旧对象上的后续改动**不进保存内容**。从列表重新 Load 才把画布绑回集合成员。
- **缓存失效**（退出?是／组织器保存／批量导入／全局清理）：只把缓存引用置空、改变**后续读取**的来源；不撤销、不回滚任何已发出对象的既有改动。

### 3.3 资源清理与位图缺失分型（R07 修订）

主循环结束后释放画布/窗口/视口，并清空 RPG 图像缓存（`RPG::Cache.clear`）。画布位图的缺失结果按三支分型（`008_AnimatedBitmap.rb`／`001_RPG_Cache.rb` 本轮新增全文证据）：

- **空图样表名**：画布入口直接判空名 → 位图置 nil（不经加载）。
- **普通缺图/加载错误**：底层位图访问的异常被图形封装捕获 → 回退为 **32×32 空白占位位图**（非 nil）——「有位图」门仍判定成立，空白处**可以**新增单元（图案源区落在占位图上，视觉结果未知）。
- **特殊帧数命名（`[N]`/`[N,D]` 前缀）或加载路径抛出**：异常上抛至画布载入的捕获 → 位图置 nil（禁止空白处新增单元）。

demo 缺失素材目录的事实保留（§19-15），但**素材缺失本身不等于入口不可达或位图必为空**：普通 UI/图样素材经占位路径仍可能让编辑器打开并允许编辑——实际可视结果与失败形态未运行验证。WP15 资源合同按引用，未逐入口验证的部分不作统一结论。

## 4. 画布交互与单元直接编辑（C-1）

画布＝战斗背景图＋64 像素边框偏移的编辑区；当前帧各单元按逐帧合同渲染；另有当前帧单元编号角标、锁定挂锁角标与**上一帧残影**（蓝色编号、仅当前帧号 >0 且上一帧对应槽非空时显示）。

### 4.1 鼠标

- **左键点空白处**：若画布位图非 nil（图样表已设置且加载未落入 nil 分支——普通缺图回退占位图也算「有位图」，见 §3.3）→ 在当前帧第一个空槽新增单元（图案＝条带当前选中图案号、焦点＝动画默认焦点位置）并开始拖拽（锁定单元不进入拖拽）；位图为 nil 则不加。**满 60 常规槽时静默失败**（无消息）。**坐标基准（R14 修订）**：新增存入的是**鼠标点 − 64 边框**的动画坐标；画布显示统一为存储坐标＋64——故新增单元显示在点击点。
- **左键点单元**：命中即选中（编号黑框）；多单元重叠时后命中者优先（按槽序扫描，命中测试对非 ALT 取 64×64 盒、ALT 按下取含缩放/镜像的**透明像素级**测试）；点中即开始带偏移拖拽（锁定单元可选中但不拖拽）。
- **拖拽**：松开后停留在末位置；无越界钳制（可拖出画布）。
- **右键帧滑杆区**：帧菜单（复制帧/粘贴帧/清空帧/插入帧/删除帧，见 §6.1）。
- **右键其它位置**：单元菜单（属性/剪切/复制/粘贴/删除/重编号/路径外推，见 §4.3、§8.6）。

### 4.3 单元剪贴操作

- 复制/剪切以类型键「单元」写入剪贴板（剪切＝复制后按 §4.4 删除门删除）。
- **粘贴单元**：类型键不符或无空槽→无操作；否则放入当前帧第一个空槽，**强制解锁**，图案 −1/−2 时绑定使用者/目标立绘，成为当前选中。**坐标基准（R14 修订）**：粘贴直接存入**鼠标点原值**（不减边框）；画布显示统一为存储坐标＋64——同一鼠标点新增与粘贴的落点相差 (64,64)：新增存 (mx−64, my−64) 显示在点击点；粘贴存 (mx, my) 显示在 (mx+64, my+64)。
- 帧剪贴（类型键「帧」）：粘贴帧＝整帧替换当前帧内容（含两个体单元位）。

### 4.4 单元删除门与清空重置（R04 修订）

**删除门的判断帧**：锁定与可删检查读取的是**编辑器当前帧**的同号槽——直接操作当前帧时判断与写入同帧（一致）；区间清空/滑动对**其它目标帧**写入时，守卫仍读当前帧（见 §8.2／§8.5——不能把「各目标帧按自身保护」当全局不变量）。

**可删守卫的完整分支**（按序适用）：

1. **当前帧或当前同号槽不存在（空槽）→ 直接放行**——不读图案、不计数：目标槽（若存在）被清除，**即使目标槽自身锁定或是其所在帧的最后个体也不例外**（守卫永不改读目标帧）。
2. 当前槽存在且**锁定** → 不可删。
3. 当前槽存在、未锁、图案 <0 且当前帧内同图案单元数 ≤1（**当前帧最后一个该图案个体**）→ 不可删。
4. 当前槽存在、未锁、（普通图案 ≥0，或同图案个体数 >1）→ 可删。

直接操作当前帧时，第 2–4 支即通常表述的「删除门两条件」（未锁定＋每个体种类至少保留一个——最后的使用者/目标单元不可删）。清空时不可删单元不删除而是**重置**：覆盖缩放/混合/可见性/角度/镜像/不透明/混色/色调/闪烁/优先级为新建默认值；**保留 X/Y 坐标、图案、焦点与锁定标志**（重置不含解锁）。

### 4.5 重编号与交换（R06 修订）

单元菜单「Renumber...」仅当当前槽 ≥2 可用；对话框滑杆范围 2–60、默认当前槽；确认后与目标槽**交换两槽内容**并把选中切到目标槽；目标 <2、与自身相同或取消（返回 −1）→ 无操作。槽 0/1 永远不参与重编号。

**可输入编号、存储结果与可显示范围分开**：滑杆上限 60、交换不检查上界——换到第 60 号槽的单元**数据存在**（槽序列随之延长）、选中号也可指向它（TAB 按帧的实际槽数循环可达），但**常规渲染与播放只覆盖槽 0–59**：画布无对应角标/精灵，播放器同样跳过无精灵槽。第 60 号槽上的单元仍可被键盘编辑（角度/缩放/移动照常写入）——只是不可见。

对**克隆副本**编辑：取消/ESC 弃副本（原单元不变）；OK 把 **11 个直接取值控件**的值写入克隆并原位替换原单元内容（两个颜色/色调子入口的值由各自子对话框 OK 先行写入克隆）。原位替换＝在原属性对象上逐元改写——**插入帧共享同一单元对象的另一帧会同步看到改动**（§6.1 联动条款）。

| 控件 | 范围 | 默认 |
| --- | --- | --- |
| Pattern 滑杆 | −2…1000 | 现值（−1 使用者、−2 目标、≥0 图样号） |
| X / Y 滑杆 | −64…576 / −64…448 | 现值 |
| Zoom X / Y | 5…1000 | 现值 |
| Angle | 0…359 | 现值 |
| Opacity | 0…255 | 现值 |
| Blending | 0…2 | 现值 |

**预览的实际效力（R16 修订——不再宣称全部即改即显）**：右侧单精灵预览位置固定（X/Y 改动不在预览体现）；每次应用后预览层级被强制重置到预览窗之上——**优先级与焦点的改动无法经此窗口观察最终效果**（焦点定位在此入口不执行，优先级算出的层级被覆盖）。实际可预览：图样（含 −1/−2 个体立绘绑定）、缩放、角度、不透明度、混合方式、镜像。

## 6. 帧操作与帧数（C-3）

### 6.1 帧菜单（右键帧滑杆）

| 项 | 行为 | 边界 |
| --- | --- | --- |
| Copy Frame | 当前帧整帧（常规槽）写入帧剪贴板（序列化快照，读出即新对象） | 无 |
| Paste Frame | 类型键为「帧」时整帧替换当前帧 | 键不符无操作 |
| Clear Frame | 当前帧按 §4.4 删除门清空（可删→清槽；不可删→重置默认） | 无 |
| Insert Frame | 在当前位置插入**当前帧槽序列的浅副本**——见下方联动条款 | 帧号越界无操作 |
| Delete Frame | 删除当前帧；删的是末帧时当前帧号 −1；选中单元清空 | **仅剩 1 帧时拒绝**（静默） |

**三种复制/粘贴的可观察独立性（R03 修订）**：

- **Insert Frame**：只复制帧的槽序列容器——插入帧与原帧**引用同一批单元属性对象**。此后在任一帧**编辑属性**（属性对话框原位改写、键盘角度/缩放/移动），两帧同步变化（联动）；而**槽位级操作不联动**：在其中一帧删除/新增/交换某槽，另一帧对应槽不变。
- **Copy Frames 区间复制／Paste Last**（§6.2/§8.1）：逐槽克隆属性值——复制后两帧属性**相互独立**。
- **剪贴板帧/单元粘贴**（§4.3）：序列化快照——与源完全独立。

### 6.2 帧数与导航

- 帧滑杆（「Frame:」）：范围 1…当前帧数，**构造时初值即钳入**（1 帧动画下界＝上界＝1、初值 0 构造完成即为 1）；改值即切当前帧。
- 总帧数按钮（「Total Frames: N」）：打开帧数对话框——滑杆 1…1000、默认当前帧数；OK 调整帧序列长度（**缩短直接截断末尾帧**，扩长逐帧新建带双个体单元的帧）；Cancel/BACK 无操作。缩短后当前帧号越界则钳到新末帧并同步滑杆。
- 上一帧复制（侧栏「Paste Last」）：当前帧号 >0 时把上一帧逐槽克隆覆盖当前帧（属性独立，同上）。

## 7. 动画集合管理（B）

### 7.1 动画列表（「List of Animations」）

打开时**先把所有 nil 槽就地填充为新默认动画**（就地修改的是列表收到的那一份集合对象：分支 (a) 即缓存集合——含取消路径也留在缓存里；分支 (b1/b2) 则是本入口的临时集合——含取消路径也只留在临时对象中，不进入缓存），再显示「序号 名字」列表，初始选中集合游标。

- 底部「Total Animations:」滑杆 1…2000＋「Resize Animation List」按钮：点击**立即**调整集合长度（扩长填默认动画；缩短弹栈截尾）并重建列表——**无确认、无独立取消**（不载出即仅内存）。**缩容游标语义（R02 修订）**：游标越界时被置为**新长度值本身**（合法末位是新长度 −1）——列表窗口不会自动修正该越界选中号（窗口索引写入与常规更新均不钳制）：**不导航直接 Load/Rename 会把空值传给下游**（载入空动画在画布入口即失败、重命名读空名即失败——均属未保护路径，静态推导、未运行）；**Delete 在恰好等于新长度的选中号上确认时＝在尾部追加一项**（写入点紧接现有末尾——集合长度 +1、原槽原样、**不留 nil 空洞**；若另有选中号严格大于长度的兼容输入则属另一前提，会有空洞，不套用于本路径）；先用方向键导航（取模回绕）可恢复有效选中再操作。
- Enter（USE）对当前槽三选：**Load Animation**（画布载入该动画并置集合游标＝该槽，关闭列表）；**Rename**（改名对话框，§7.2）；**Delete**（确认后**以新默认动画替换该槽**——不是置 nil，槽位不塌缩；**替换后不重新载入画布**——画布仍持有并继续编辑已被移出集合的旧动画对象，保存时该槽内容已是新动画，旧对象的后续改动不进保存内容；重新 Load 才把画布绑回集合成员——R01 修订）。
- BACK：关闭列表，不载入（画布/游标不变；nil 填充已发生）。

### 7.2 重命名

文本框预填现名；启用文本输入模式；OK 或回车＝写回并刷新列表项；Cancel/ESC＝弃。名字是关联合同载体（§15）——`Move:`/`OppMove:`/`Common:` 前缀在编译/播放侧有特殊意义，编辑器本身不校验。

### 7.3 图样表与色相（「Set Animation Sheet」；R08 修订）

列出 RTP 各路径 `Graphics/Animations/` 下 `*.png`（仅 PNG）；右侧预览窗随选择即时刷新；色相滑杆 0–359 默认 0 且即调即预览。USE 确认（列表非空）：动画记录图样表名（去扩展名）与色相，画布与条带换绑新位图。BACK：不改（原名/原色相/原位图保持）。

**空列表分型（R08 修订——不再称「USE 无效」）**：选择器每轮先把当前列表项送入预览窗刷新；**空列表时当前项为空值，预览窗刷新在拼接文件名处即失败**（该处无空值守卫）——失败发生在进入选择器后的预览刷新，先于任何 USE/BACK 分支（未保护路径，静态推导、未运行；画布载入的异常捕获不覆盖此选择器自身路径）。对照：列表有项时 BACK 正常无改动退出。

### 7.4 焦点位置（侧栏「Cel Focus...」）

四选菜单（User/Target/User and target/Screen），现值带 [X] 标记；选择经兼容映射（User→2、Target→1、User and target→3、Screen→4）写入动画默认焦点位并刷新画布；取消（返回 −1）不改。该默认值用于：新建单元的焦点、属性对话框焦点缺省、批改焦点缺省。

### 7.5 条带（图案选择）

5 格缩略（96×96）＋左右箭头；点格选中（红框）即定当前图案号；箭头单击滚 ±1 格、按住 >0.75 秒滚 ±3 格；起点钳 [0, 图样表总格数]（起点可等于总数，此时显示空槽区）。图案号布局：每行 5 格、每格 192×192。

## 8. 区间与路径工具（D-1）

全部区间对话框共享：帧号输入为 1 基滑杆（范围 1…当前帧数），单元号为 0 基滑杆（0…59）；Cancel/BACK 一律无改动关闭；OK 才执行。

### 8.1 复制帧区间（Copy Frames...；R05 修订）

首帧（默认 1）、末帧（默认末帧）、目标位（默认当前帧 +1）。区间包含两端：**首＝末＝单帧也复制 1 帧**；真正不复制的是**源首＝目标位**或**反向区间（末 < 首）**。重叠安全：目标在源区间之后→**从尾向首**逐帧复制；目标在源之前→从首向尾。**目标越尾**：超出当前帧数的目标帧被逐帧跳过（不扩帧），仍在范围内的部分照常写入（部分完成）。逐帧逐槽克隆（属性独立，同 §6.1 区间复制条款）。

### 8.2 清空区间（Clear Frames...；R04 修订）

对 [首, 末] 逐帧清空：每帧逐槽按**完整可删守卫**处理（可删→清槽；不可删→重置默认，保留字段见 §4.4）。**守卫帧与写入帧分开**：可删判断读取的是**编辑器当前帧**的同号槽，不是正被清空的目标帧。守卫按 §4.4 四支适用——**前置空槽支**：当前帧或当前同号槽不存在（空槽）时**直接放行清槽**（不读图案、不计数；目标槽即使锁定或是其所在帧最后个体也被清除）；**只有当前槽存在时**才应用「未锁定＋普通图案或同图案个体数 >1」两条件。对照组：当前帧槽 2 **空**（当前帧仅默认槽 0/1）、目标帧槽 2 锁定→**目标被清槽**；当前帧槽 2 **未锁且为普通图案**、目标帧槽 2 锁定→目标被**清槽**；当前帧槽 2 锁定、目标帧槽 2 未锁普通→目标只被**重置**；当前帧槽 2 **未锁但是当前帧最后一个该图案个体**、目标帧槽 2 锁定普通→目标**保留并重置**（原锁定/图案/坐标/焦点保留）。若**当前帧本身在区间内且先于其它帧被清空**，后续帧的判断读到的已是当前帧被改后的状态——被清空的槽变为空槽即落入前置放行支（被重置的槽仍存在、按存在槽的条件判断）（按区间升序逐帧作用）。滑动（§8.5）只有锁定一门，不与清空共用本条款。

### 8.3 补间（Tweening...；R10 修订）

起始帧（默认 1）、结束帧（默认末帧）、首末单元槽（默认 0…59）、三组属性勾选（Pattern／Position-Zoom-Angle／Opacity-Blending，默认全不勾）。

- **起始 ≥ 结束 → 直接关闭、零改动**。
- 对每列单元：起止两帧该槽**缺一即整列跳过**；中间帧该槽为空→新建单元（默认属性）并**强制写入全部三组**（无视勾选），非空则只写勾选组。
- 插值（独立数学）：帧 k（0…帧距）处属性值＝起始值＋（差值 × k ÷ 帧距）；**结果保留输入的数值类型**——两端为整数时按整数除法向负无穷取整（0→3 跨 2 帧中点＝1），任一端为实数（定义路径重采样等路径可产生实数坐标）则按实数运算保留小数（0.0→3.0 中点＝1.5）。帧距＝结束−起始。这里说的是动画属性数值本身，不推断宿主最终像素量化。
- 结束后画布重绘。不触碰时序项与未勾选属性（除新建单元被强制写三组外）。

### 8.4 单元批改（Cel Batch...；R17 修订）

帧区间＋单元槽区间；**11 个可选取值项**（Pattern/X/Y/ZoomX/ZoomY/Angle/Opacity/Blending/Flip/Priority/Focus，各自带勾选框，默认全不勾）。**只作用于已存在单元**（不新建）；勾选项写新值、未勾不动；焦点经兼容映射写回。OK/USE 执行，Cancel/BACK 弃。

### 8.5 整幅滑动（Entire Slide...；R04 修订）

帧区间＋X/Y 偏移（各 −500…500，默认 0）：区间内每帧逐槽平移非空单元——**锁定判断同样读编辑器当前帧的同号槽**（§8.2 同一守卫条款）：当前帧未锁的槽，目标帧锁定单元也被平移；当前帧锁定的槽，目标帧未锁单元也被跳过。

### 8.6 定义路径（Q 或单元菜单「Extrapolate Path...」；R09 修订）

前提：有选中单元。帧数滑杆 2–500（默认 20）；OK 时若当前帧＋帧数超出动画长度则先扩帧（新帧带双个体单元），再把路径点序列的 X/Y 逐帧写入**当前选中槽**（缺失槽位新建单元，图案取该单元当前图案、焦点取动画默认；只写 X/Y 两属性）。Cancel/BACK 弃。

- **Define Smooth Curve**：4 个控制点（两端红色、两中间黑色）；端点未放置前中间点不可拖；两端点就位后自动生成 1/3、2/3 处中间点并显示 30 个路径采样点；拖动控制点实时重算 Catmull-Rom 曲线（三段式：端点重复取端）。BACK 退出定义——**若已显示路径线，仍生成路径**（与「取消即弃」直觉相反，如实登记）。
- **Define Freehand Path**：先等待首次按下开始记录（此阶段 ESC＝整体取消→空路径对象），记录阶段逐点采样（与末点相同不重复记），松开左键或 ESC 结束（**此阶段 ESC 不取消**——保留已绘点）。
- **三套取样/端点合同（R09 修订——不再混用）**：
  - **初次曲线**：按曲线直接取 N 个参数采样点（步长 1/(N−1)，实数坐标，**含首末两端点**）。
  - **初次手绘**：先按弧长等距重采样为 N＋2 个候选点并**取整到像素**；OK 写入只用**前 N 个**——末端点通常不写入（直线 0→12、N＝4 时写入 0、3、6、9，不写 12）。
  - **改帧数后重采样**（已存在路径再调帧数滑杆）：对既有路径按弧长重取 N＋2 个点、**实数坐标不取整**；OK 写入所用的就是这组实数点（仍只取前 N 个——与初次手绘的取整路径不同，写入值可含小数）。
- 路径数学（独立定义）：点列弧长参数化，pointOnPath(t) 取累计弧长 ≥ t×总长的首个非零长段内线插（零长段跳过）；t∉[0,1] 或帧数 <0 属定义域错误（编辑器滑杆保证 2–500）。**未定义路径（path 未生成）OK 门不通过；空路径对象（首阶段 ESC 产生）能通过 OK 门**——先按帧数扩帧、再在取第一个点时失败（**扩帧已发生并保留在内存动画中**；失败形态未运行验证，不补兜底承诺）。

## 9. 音画时序（D-2；侧栏「SE and BG...」）

列表＝该动画全部时序项文本（格式见下）＋5 个「Add:」入口；底部帧号滑杆（1…帧数，默认当前帧 +1）。

- **Set Frame**：把选中既有项移到滑杆帧（帧号 −1 存储）并刷新文本。
- **Delete Timing**：删除选中项并修正列表索引。

### 9.1 音效子对话框（pbSelectSE）

文件列表＝RTP `Audio/SE/Anim/` 下 wav/ogg/mp3/wma（去重、大小写不敏感排序），首项「[Play user's cry]」。Volume 0–100（新建默认 80）、Pitch 20–250（新建默认 100）。「Play Sound」试听（**未选文件时无效**）；「Stop Sound」停止。OK：记录文件名（去扩展名；选叫声项则名＝空串）＋音量＋音高，返回真；Cancel/BACK：返回假。

### 9.2 背景/前景图形子对话框（pbSelectBG；用于类型 1/3；R11 修订）

文件列表＝RTP `Graphics/Animations/` 下 png/gif（去重、大小写不敏感排序）。**抹除项的序号错位（R11 修订——不再保证其为首项）**：特殊文案「[Erase background graphic]」先插入序号 0 并记下「抹除序号＝0」，随后**整个列表（含该文案）一起排序**而抹除序号保持 0——**无冲突的唯一条件是排序后抹除文案实际仍在序号 0**（明确无冲突夹具：目录仅含 `bg.png` 时文案居首、选择行为正常）。错位与否则取决于**所有项与该文案的实际排序关系**，数字开头只是其中一类反例：`0bg.png`（数字在文案第二字符之前）；`[2]fx.png`（首字符同为 `[`、第二字符 `2` 排在文案第二字符 `E/e` 之前）；`!bg.png`（`!` 排在 `[` 之前）——这些情况下序号 0 变成真实文件，**选序号 0 被当作抹除（名置空串）、选真正的抹除文案反而按普通文件名记录**。文案经本地化时按实际（本地化后）文案参与比较。滑杆：X/Y −500…500（默认现值或 0）、Opacity 0–255（**默认现值或 0**——新建项不调整即为 0，播放时不可见，如实登记）、RGBA 各 0–255（默认现值或 0）。OK 写入并返回真；Cancel/BACK 返回假。

## 10. 预览播放（E）

### 10.1 入口与构成

侧栏「Play Animation」（用户侧视角）/「Play Opp Anim」（对方侧视角——交换使用者/目标槽位与翻转前提）。预览在与编辑器同画布内进行：临时双立绘（使用者背面/目标正面调试图）＋动画播放器实例（与战斗同类的逐帧播放器，编辑模式偏移 +64,+64）；播放期间隐藏编辑角标与残影，结束后恢复并释放播放器。

### 10.2 逐帧应用合同（与战斗播放器共享；WP67-A 的编辑侧引用）

- 帧率硬编码 **20 帧/秒**（动画 `speed` 元数据默认 20 但**未被消费**——编辑器无入口、播放器不用，登记为惰性字段）；非循环，播完自止。
- 每帧：全单元槽先隐，再按帧内非空单元逐个应用——图案 −1/−2 绑定使用者/目标位图、≥0 绑定图样表 192×192 源区（行 5 格）；混合/角度/镜像/不透明/缩放（百分比÷100）/混色/色调、源点居中、坐标写入。**可见性（R13 修订——删除「编辑模式下半透显示」）**：逐帧应用直接把精灵可见设为「可见标志＝1」；源中一个看似「编辑模式半透」的分支是永假比较（布尔与数值比等），不会命中——编辑画布与预览播放器（后者不传编辑标志）都按隐藏路径处理标志 0 的单元。数据可见标志与不透明度是两个独立属性。
- 焦点定位：焦点＝目标→坐标＋（目标当前中心−目标焦点常量）；焦点＝使用者同理；焦点＝双方→按源线段（双焦点常量）到目标线段（双立绘当前中心）的**线性变换**重定位，且源线段与目标线段 X 方向相反且图案 ≥0 时镜像取反；焦点＝全屏→不偏移。优先级：0→最底、1→最前、2→焦点立绘之后、3→焦点立绘之前（焦点双方/全屏时按默认层）。
- 时序播放：到达帧号触发——音效按名播放（名空且使用者有个体时放其物种叫声；**编辑器预览的使用者是占位无个体→叫声项静音**）；设置型图形/抹除即时生效（图形位图或纯色板，不透明与混色应用）；渐变型记录旧值后在时长内线性插值（只处理参与项）。

### 10.3 预览≠保存

预览不产生任何数据改动；播放中的画面效果（含时序设置的背景/前景）随播放器释放消失。

## 11. 单项导入导出（F-1；`.anm`）

### 11.1 导出（侧栏「Export Anim...」）

自由文本输入文件名（空初值、上限 32 字符）；**空名＝取消**（静默）。否则名＋`.anm` 写入游戏目录：内容＝**当前选中动画**（仅单个）的压缩序列化文本。写异常→「Couldn't save…」消息；成功→两条消息（已保存到游戏目录／文本可移植）。导出**不是**集合保存（不影响 rxdata 与缓存）。

### 11.2 导入（侧栏「Import Anim...」）

列出 RTP 各路径下 `*.anm`；USE 选择：读出并解码——非动画对象或解码失败→「invalid or could not be loaded」消息并**回到列表**（可再选或 BACK）；成功则置 `id` −1、执行旧格式转换（§14.1）、**替换当前选中槽**（仅内存；集合游标不变）。随后检查图样表文件存在性：缺失→警告消息（「will load anyway」）但照常载入画布。BACK：不改。导入结果同样只随 §3.2 保存确认落盘。

## 12. 动画组织器（F-2；「Battle animation organiser」）

- 集合不存在或首槽空→「No animations exist.」并直接返回（不改任何数据）。
- 列表「序号: 名字」（nil 槽显 `???`）；帮助窗注明操作：Z+Up/Down 交换、Z+Left 删除、Z+Right 插入（命令窗口合同属 WP72/WP17 基础设施）。
- 交换上/下：边界内互换相邻两槽并重列；删除：移除该槽（游标钳入）后等待 0.2 秒；插入：在该位置插入新默认动画后等待 0.2 秒。**全部仅内存**，直到退出确认。**删除可达 0 项（R02 修订）**：删除不受最少一项限制——从 1 项集合删除后集合为 0 项；退出时选 Yes 会**照样保存 0 项集合**（无最小长度拦截）。「至少一项」只约束构造与容量滑杆，不是全局不变量（§2）。

## 13. 批量导入导出（F-3；`Animations/` 目录）

### 13.1 批量导出（「Export all battle animations」；R15 修订）

整体有兜底保护（WP72 保护不对称先例的沿袭）：任一处异常→打印诊断＋「The export failed.」消息结束（**已写出的部分文件保留，不回滚**）。

1. 建 `Animations/` 目录（已存在忽略）；集合不存在→「There are no animations to export.」结束。
2. 逐动画处理，**跳过 nil／0 帧／无名**动画；目录名＝动画名（非单词字符替换为 `_`）；写 `<目录>/<安全名>.anm`（单动画压缩文本）。**`.anm` 写出的确认与覆盖（R15 修订）**：`.anm` 直接写文件、**不经任何确认**（不走安全复制的内容比较/覆盖询问）——不同动画名经安全化得到**同名目录/文件**时（如 `A-B` 与 `A+B` 同为 `A_B`），后处理的 `.anm` **直接覆盖**先前的；即使后续资源复制弹出覆盖询问或被拒，已写入的 `.anm` 不受影响。
3. 资源随行：图样表名非空→经 RTP 解析图像路径并**安全复制**（§13.3）；时序项中类型 0（含缺省型）且名非空→经 RTP 解析音频路径安全复制；类型 1/3 且名非空→图像安全复制。
4. 完成消息（全部导出到 Animations 目录）。

### 13.2 批量导入（「Import all battle animations」）

**无整体兜底**（与导出的不对称是已确认行为）：仅 `.anm` 解码有单点保护。

1. 收集 `Animations/` 一级子目录（跳过 `.`/`..`）；无→提示性消息结束（不写任何数据）。
2. 集合＝按载入语义取得（**缓存非空即用缓存——即使首槽为空也不另建**；仅缓存为空且无文件时才新建默认集合）；逐目录：先把目录内**音频**（wav/ogg/mp3/mid/wma——按文件名末 3 字符判定且大小写各试一次；**`midi` 模式因按末 3 字符比较永不命中，`.midi` 文件实际不复制**，如实登记）与**图像**（png/gif，同法）安全复制到 `Audio/SE/Anim/`、`Graphics/Animations/`——**资源复制发生在 `.anm` 校验之前**，目录无合法 `.anm` 时资源仍已复制。
3. 逐 `.anm`：解码失败或非动画对象→**静默跳过**（无消息）；合法则：分配槽位（§13.4）；名空→取目录基名；`id` 置 −1；旧格式转换（§14.1）；图样表在目录与 RTP 图像路径均不存在→**图样表名清空**；各时序项名在目录与 RTP 音频路径均不存在→**该项名清空**（两处「缺失文件清单」聚合在清空后收集、且从未展示——死聚合，如实登记）；写入分配到的槽。
4. 全部目录处理后：写 `Data/PkmnAnimations.rxdata`＋清集合缓存＋完成消息。**批量导入在非空目录分支的末尾无条件写集合文件**（无「Save changes?」环节）；注意它**不是唯一**不经确认的写出路径——批量导出的 `.anm` 与资源文件同样不经保存确认（§13.1／§16 按文件类型分列）。

### 13.3 安全复制合同（继承 WP73-A 已通过证据，不重新推导）

源不存在→不复制；目标不存在→复制；目标存在且同尺寸同内容→**不复制**（静默跳过）；目标存在且内容不同→**确认覆盖**（是才覆盖）；复制以读取字节整体写入（可选第三参数改目标路径）。

### 13.4 槽位分配合同（继承 WP73-A 已通过证据）

从槽 1 起扫描（**槽 0 永不分配**）：首个 nil 槽→用之；首个「准空」槽（1 帧、帧内恰 2 单元、无名）→用之；都没有→**把集合长度调整为 10 并返回调整前长度**（原长度 >10 时多出的槽被截断且不恢复；WP73-A 动画空槽分配条款）。

## 14. 旧格式转换与失效入口（F-4）

### 14.1 动画旧格式转换（导入即转）

转换判定：任一帧任一单元**焦点属性缺失**即视为旧格式。转换内容：优先级缺失补 1；槽 0→焦点＝使用者、坐标＝使用者焦点常量；槽 1→焦点＝目标、坐标＝目标焦点常量；槽 ≥2→焦点取动画焦点位（缺省 4），且动画焦点位为目标时坐标叠加（目标焦点常量 X、Y−2）。单项导入（§11.2）与批量导入（§13.2）对每个 `.anm` 都执行；返回是否发生了转换。

### 14.2 全量转换入口（死入口登记）

`pbConvertAnimsToNewFormat`（`004:128–146`）：提示→逐动画转换→有转换才写 `PkmnAnimations.rxdata`＋清缓存→报告转换数。**全脚本检索无任何调用者**（无菜单项）——登记为存在但不可达的入口，不推断其菜单归属。

### 14.3 RMXP 动画转换（已停用）

`pbConvertRPGAnimation`（RPG Maker XP 动画→本格式）仅在编译器注释块中被引用（`002_Compiler_CompilePBS.rb:1283–1293` 整段注释）；`ArrayCountSlider`（`002:589–598`）构造体引用了其词法作用域中不存在的名字——两者均登记为**定义存在、当前不可达**，不作行为承诺。

## 15. 招式/公共动画关联与编译侧合同（F-5；只登记交界；R12 修订）

- **命名→映射**：编译动画阶段（WP04 生命周期内）**每次从空映射重建**：扫描集合，名按 `Move:`／`OppMove:` 前缀匹配——**匹配规则先消费冒号后的前导空白**（`Move:TACKLE`、`Move: TACKLE`、`Move:   TACKLE` 捕获同为 `TACKLE`），**捕获后缀中的尾随/内部空白则保留**（`Move: TACKLE ` 带尾随空格→带入标识、查无此招式）；标识查找区分大小写（`GameData` 符号查找合同，`001_GameData.rb:76–122`），后缀能解析为已注册招式才记入——`Move:`→用户侧映射、`OppMove:`→对方侧映射；**同侧重复名后槽覆盖前槽**。注意**显示名与注册标识不是一回事**（查找按注册标识）；`Common:` 查找按精确拼接、**不继承这种空白跳过**。

## 17. 共享控件与窗口合同（本包新见的编辑控件族；R10／R17 修订）

- **侧栏构成**：13 个功能按钮＋2 个空行，共 15 个控制位（索引 0–14；空行无行为）。
- **按钮**：按下捕获、**松开在框内才算触发**（按下后移出松开＝不触发）。
- **滑杆**：左右箭头，单击 ±1、按住 >1.5 秒 ±5、>3 秒 ±10；到界箭头灰显。**三个时点分开（R10 修订）**：①**构造/赋值当时即把值钳入 [min, max]**——依次设置下界/上界/当前值时每次赋值都执行钳制，**上下限相等也钳**（无 min<max 前提）；②周期更新中另有「下界 < 上界且当前值越下界才钳」的补充条件——它不取代①的构造/赋值合同；③**向下取整只在箭头操作后执行**——合法范围内的小数初值（如 1.5）不点箭头不会因打开窗口而被取整。
- **可选滑杆**：勾选框＋滑杆复合；未勾选时值＝「不参与」（nil），滑杆禁用。
- **文本滑杆**：选项数组索引式（同滑杆时序）；选项文本宽度按最长项缓存。
- **文本框**：光标闪烁（0.35 秒周期）、左右移动、退格/删除删光标前字符、字符插入光标处；启用期间宿主文本输入模式开、退出关。
- **复选框**：触发即翻转。

## 19. 边界、失败与未知汇总（按 AGENTS.md 第 9/10 要素）

1. 空/初始（按缓存内容三分，§3.1/§3.2）：缓存为空且无文件→新建临时默认集合（不写回缓存；**保存前**其它读取仍 nil，**保存后下次读取即触发磁盘载入**、所得新对象与编辑器临时对象再度分离）；**缓存/载入结果首槽为空**（如 0 项保存形成的集合 C）→编辑器同样另建临时集合，但**缓存仍是 C、其它读取返回 C**，保存不写缓存、失效后读取才取新内容；有效缓存→直接编辑缓存集合。**两个相关入口各自带前提（R01 修订——不再附无条件结果）**：组织器按**载入结果**拒绝——没有集合对象或**首槽为空**（含 0 项、含首槽空但后槽有效）都拒绝进入；已有有效缓存时**不会仅因文件不存在而拒绝**（门在载入结果而非文件存在性，§12）。批量导出**仅在载入结果本身不存在时**报「无动画可导出」；**0 项集合对象不触发该提示**——进入遍历、跳过空项，在其余环境操作正常时显示导出完成（§13.1；两入口的 0 项对照见 M33）。
2. 位图缺失三支（§3.3）：空图样名→位图 nil、禁加单元；普通缺图/加载错误→32×32 空白占位、**仍可加单元**；特殊帧数命名或加载抛出→nil。
3. 满槽：新增单元静默失败；粘贴单元静默无操作（§4.1/§4.3）。
4. 末帧保护：仅 1 帧时删除帧静默拒绝（§6.1）；**「至少一项」仅约束构造与容量滑杆**——组织器可删至 0 项并照样保存、缩容后游标越界待导航恢复（§7.1/§12）。
5. 个体单元保护与**守卫帧**：可删守卫读**编辑器当前帧**同号槽——**当前帧/同号槽为空直接放行**（目标槽即使锁定或是其帧最后个体也被清除）；仅当前槽存在才应用「未锁定＋普通图案或同图案个体数 >1」两条件；区间清空/滑动对目标帧写入但守卫不变——「各目标帧按自身保护」不成立（§4.4/§8.2/§8.5）。
6. 补间：起≥终零改动；端点缺列跳过；中间空槽新建并强制三组；整型插值向负无穷取整、实数插值保留小数（§8.3）。
7. 复制区间：首＝末复制 1 帧；源首＝目标或反向（末<首）不复制；目标越尾逐帧跳过、范围内部分写入、不扩帧（§8.1）。
8. 路径：三套取样/端点合同（初次曲线含端点/初次手绘取整取前 N/改帧数实数不取整）；曲线 BACK 于已显示路径线后仍生成路径；自由绘制首阶段 ESC＝空路径对象、记录阶段 ESC＝保留已绘点；空路径 OK **先扩帧再于取点失败**（扩帧保留，未运行）（§8.6）。
9. 时序：渐变编辑全不勾选按 OK＝无效（无提示）；新建图形设置默认不透明 0（播放不可见，需作者自调）；音效未选文件不可试听；**抹除文案排序后不一定在序号 0**（数字开头文件名使序号错位，§9.2）。
10. 预览：叫声静音（占位个体无物种叫声）；可见标志 0 的单元按隐藏处理（无半透分支）；speed 惰性（§10.2）。
11. 单项导入坏数据→消息并回列表；缺图警告照常载入；导出写失败有消息；**图样表选择器空列表在预览刷新先失败**（先于 USE/BACK，§7.3/§11）。
