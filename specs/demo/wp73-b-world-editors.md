## 1. 目的、范围与非目标

**目的**：固定世界编辑器的规则合同——**每个世界/资源编辑器读什么输入、坐标/地形/遭遇/指标如何校验、取消时是否仍写入、编辑何时生效（内存/`.dat`/PBS 三层）、数据与地图/图块组资源的关联如何核验、无资源时哪些操作不可确认**。后续包据此判断"某次世界编辑实际落到了哪一层、改了哪份文件"。编辑器实现是作者行为要求的参考，不作为未来编辑器的布局或交互设计模板。

**范围**（WP73-B 自身声明范围）：

1. 地图连接可视化编辑器（`pbConnectionsEditor`/`MapScreenScene`）：画布与邻居递归摆放、增删图、拖拽、连接数据生成（邻接判定与对称去重）、保存与取消。
2. 地图元数据编辑器（`pbMapMetadataScreen`/`pbEditMapMetadata`——同 `001_EditorScreens.rb`，WP73-A 已读全文）：属性框架复用与即时落盘。
3. 地形标签编辑器（`pbTilesetScreen`/`PokemonTilesetScene`）：图块组载入、标签设置（含自动图块整组语义）、保存与宿主提示。
4. 遭遇编辑器（`pbEncountersEditor`/`pbEncounterMapVersionEditor`/`pbEncounterTypeEditor`——同 `001_EditorScreens.rb`，WP73-A 已读全文）：集/类型/槽三层编辑与退出确认。
5. 指标编辑器（`SpritePositioner`/`SpritePositionerScreen`）与全量自动定位（`pbAutoPositionAll`）：单项定位/阴影尺寸/单体自动定位/全量自动定位的算法与落盘。
6. 无效图块修复（`pbDebugFixInvalidTiles`——WP72 已读全文，本包主责其合同）：全地图扫描、有效性判定、写 0 与地图文件保存。

**非目标**：

- 不提取内容编辑器（WP73-A 主责：训练家类型/训练家战斗/道具/物种/全局与玩家元数据/地区图鉴——本包复用其属性框架与列表器合同并引用）；不提取动画工具（WP74）、编译器全集与文件更名/转换（WP75）；不展开遭遇/地图/地形/指标的**数据语义**（WP36/WP11/WP12/WP15/WP16 主责——本包只固定编辑行为与文件层）。
- 不重提取已通过规则：PBS 编译/反写（WP04）。同批待审合同不展开：属性框架与列表器（WP73-A §3/§5，同批待审）、GameData 三层持久（WP73-A §2，同批待审）、调试入口（WP72 §8.3，同批待审——含归属更正：本包为其 WP73-B 归属的主体）。
- 不运行编辑器/编译器/反序列化、不写 PBS/.dat/地图/图块组文件、不操作真实存档、不调整宿主界面、不设计未来编辑器布局或 API。

## 2. 概念与术语

- **三层持久模型（继承 WP73-A §2）**：内存 `DATA`/运行缓存层 → `.dat` 保存层 → `Compiler.write_*` PBS 反写层。本包各编辑器的落点：**连接**＝退出确认时 `save_data` 写 `Data/map_connections.dat`＋`Compiler.write_connections`＋清工厂缓存；**地图元数据**＝确认即 `register`＋`save`＋`Compiler.write_map_metadata`；**地形标签**＝退出确认时 `save_data` 写 `Data/Tilesets.rxdata`＋替换运行 `$data_tilesets`＋**重启 RMXP 提示**；**遭遇**＝退出确认时 `GameData::Encounter.save`＋`Compiler.write_encounters`，否则 `load` 丢弃；**指标**＝退出确认时 `GameData::SpeciesMetrics.save`＋`Compiler.write_pokemon_metrics`，否则 `load` 丢弃；**修复图块**＝逐图立即保存（无总确认）。 **遭遇还须区分当前地图快照**：注册／档案／PBS 的四阶段往返与快照消费者见 §6.4–§6.5；保存或注册重载均不自动重装当前地图。**指标反写不是无条件更新全部 PBS**：实际路径、记录省略和重载／重编译区别见 §7.5，按保存时集合判定。
- **小地图与画布**：`createMinimap`（`006_Map renderer/004_TileDrawingHelper.rb:164`——WP16 引用）生成每格 4 像素的地图缩略图；连接编辑器以**网格对齐（坐标向下取整到 4 的倍数）**摆放缩略图；**画布上的图只是编辑会话内的摆放**——删掉画布上的图不删连接数据本身，连接数据由**生成算法**按当前画布重算（§3.3）。
- **连接数据形态**：原始连接为**边＋坐标**形式（`[图1, 边1, 坐标1, 图2, 边2, 坐标2]`——N/S/E/W 边经 `MapFactoryHelper.getMapConnections` 惰性装载时换算为坐标对并**过滤尺寸为 0 的无效图**——`004_Game classes/005_Game_MapFactory.rb:383–420`）；编辑器生成的连接为**相对坐标差**形式（`[参照图, 0, 0, 目标图, dx, dy]`，dx/dy 为缩略图坐标差除以 4——即地图格数差）。
- **邻接判定（B-R01 修订）**：坐标单位为地图格（缩略图像素差 ÷4）——**x 差等于对方图宽或己方图宽取负，或 y 差等于对方图高或己方图高取负**即视为邻接（边贴边的**单轴条件**）：**不检查另一轴重叠**——错轴也可成邻接（两张 10×10 图放在像素 (0,0) 与 (40,400)：横差满足条件即成邻接，纵向并未对齐）。**逐节点回退**：仅某图没有任何直接邻接时，才回退与（非自身的）第一个画布图建立连接——**两组各有邻居时不补跨组连接，不保证全图连通**（两对各自相邻且相互远离的图可保留两个连通分量）（`003:226–247`）。
- **对称去重**：新连接与既有连接**完全相同**或**镜像对称**（两端互换且坐标差取负）时不重复添加（`003:200–219`）。
- **地形标签的自动图块语义**：图块 ID < 384（每行 8、每自动图块 48）时**设置整组 48 个标签**；≥384 时设置单个标签（`002:163–169`）。**TILESET_START_ID = 384**。
- **指标（metrics）**：每物种×形态的显示参数——**back_sprite [x,y]**（我方背后位）、**front_sprite [x,y]**（对方正面位）、**front_sprite_altitude**、**shadow_x**、**shadow_size**（0＝无，编号对应 `Graphics/Pokemon/Shadow/<编号>` 图形）；**自有阴影图形**（`Graphics/Pokemon/Shadow/<物种>_<形态>` 或 `<物种>`）存在时 **shadow_size 不可编辑**（§6.3）。持久于 `species_metrics.dat`（`010_SpeciesMetrics.rb:14`）。 非零形态查询可惰性登记新指标，复制基础数值但缺省空来源后缀；编辑预览先读当前登记，而保存／重载不广播已有战斗布局重新定位（§7.5）。
- **底部探测（自动定位算法，B-R08 修订）**：从位图底行向上找到**首个 alpha>0 像素**所在行（全透明位图返回 0）——bottom；非负坐标公式为**向下取整的整数除法**：**y = (位图高 − bottom − 1) / 2 向下取整**（正面位再 +4；例：高 32、底部行 24 → 背面 3／正面 7；全透明高 32 → 15／19）。**缺图与透明图分开**：缺图由调用方分支处理（§7.4 矩阵）；透明图按公式退化计算。写字段按单体/全量分列（§7.4）（`004:4–41, 138–155`）。
- **资源关联核验**：**有资源才能确认的操作**——地形标签编辑要求 `Data/Tilesets.rxdata` 可装载（编辑器直接 `load_data`，WP04/WP10 边界）；指标编辑的**预览**要求对应物种/形态图形存在（缺失时预览为空——**预览回落不等于全部操作安全**：单项定位/阴影尺寸按数值编辑仍可进行，**单体自动定位直接读两位图高度——缺图可失败（与全量缺图跳过分开，不以可手改数值推断全部操作可安全完成，B-R08）**）；**自有阴影图形存在时阴影尺寸编辑被拒绝**；**无资源时**小地图/预览仅显示层回落。
- **已通过边界（必须继承，不重开）**：WP04、WP11、WP12、WP15、WP36、WP16、WP59、WP61（`d84dff78`）、WP53（`75fc4db7`）、WP37（`d032f5b7`）、WP65、WP67-A/B、GR-001～016、WP23-N01。**同批待审依赖（引用其合同，不作通过结论——BATCH-R03）**：WP73-A（属性框架/列表器/三层持久/选择器）、WP72（调试入口与工具归属）——**当前身份见登记清单，不沿用 v1 短哈希**。

## 3. 地图连接可视化编辑器（`003_EditorScreens_MapConnections.rb` 全文）

### 3.1 打开与画布（`003:567–578, 308–344`）

- **打开**：屏幕尺寸**宽高各 +288**（临界段 `pbCriticalCode`——`003_Errors.rb:76` 引用），结束后恢复原尺寸与缩放因子；初始图：当前图（无当前图取系统编辑图 ID，再缺省 1）居中摆放并**递归摆放全部邻居**（按既有连接偏移 ×4 递归——`003:165–191`）。
- **画布元素**：每图一个缩略图精灵（网格对齐）；选中框（红色描边跟随选中图）；底部"D: Help"提示行；帮助窗（D 键——按键清单）。
- **既有连接装载**：`MapFactoryHelper.getMapConnections`（惰性、含坐标换算与无效图过滤——§2）；**克隆入会话数组**（去两端完全重复项——`003:332–337`）。

### 3.2 编辑操作（`003:384–544`）

- **A 键（Add map）**：地图列表（MapLister——WP73-A 引用）选图 → 居中放入画布（网格对齐）＋置顶 → **立即重算连接数据**（§3.3）。
- **S 键（Go to map）**：选图 → **先重算当前画布连接数据**（保存当前成果入会话数组）→ 清画布 → 以新图为根重新摆放（含邻居递归）。
- **DEL 键（Delete map from canvas）**：画布图数 >1 且有选中 → 从画布移除该图（**只移出画布——连接数据不因此删除**；下次重算时被移出的图不再参与）。
- **单击**：选中（红框、置顶、标题行显示图名）＋开始拖拽（**拖拽落点同样网格对齐**）；**双击（0.5 秒内）**：打开该图的**地图元数据编辑**（§4——WP73-A 属性框架复用）。
- **拖动画布空白**：记录各图位置后整体平移（网格对齐）；**方向键**：全画布 4 像素步进平移。
- **D 键**：帮助窗（USE/BACK 关闭）。

### 3.3 连接数据生成与保存（`003:221–285, 546–562`）

- **生成算法（B-R01/R02 修订）**：克隆会话连接数组 → **画布少于两图时直接返回克隆**（**0/1 图分支：不执行任何删除——旧连接全部保留，包括触及画布图的**，B-R02）→ 至少两图时：**删除所有触及画布图的旧连接** → 对每个画布图求**直接连接集**（对画布内每个其它图：缩略图坐标差 ÷4 后，**x 差等于对方图宽或己方图宽取负，或 y 差等于对方图高或己方图高取负**即邻接——**单轴条件、不检查另一轴重叠**；**一个都没有时才回退连接画布首个其它图**——逐节点回退、不保证全图连通）→ 逐对生成 `[参照图, 0, 0, 本图, dx, dy]`，**经对称去重**后追加。
- **保存**：BACK → **"Save changes?" 确认** → `save_data` 把生成结果写入 `Data/map_connections.dat`＋`Compiler.write_connections`＋**MapFactoryHelper.clear（清工厂连接缓存）**＋会话数组替换为生成结果；**不确认 → 按三种状态分开（B-R03）：连接会话数组本身不序列化；`GameData::Encounter.load` **只重载遭遇数据**（未保存的遭遇内存改动丢弃）；**地图元数据不重载**——双击进入并已确认保存的元数据改动**保留**（连接取消不能撤销）；共享嵌套对象（如地图尺寸数组）的未保存变化**也不由遭遇重载恢复**（与 WP73-A 的 A-R04 同步——保留这个不对称现象，不补统一事务）**；随后 **"Exit from the editor?"** 确认才退出（否则回到画布）。
- **边界**：生成只覆盖**画布上的图**——不在画布上的既有连接原样保留（克隆里未触及部分）；**不校验生成连接的图是否存在/有资源**（装载期过滤由 MapFactoryHelper 负责，WP11 引用）。

## 5. 地形标签编辑器（`002_EditorScreens_TerrainTags.rb` 全文）

- **打开**：屏幕**高 ×2**（结束后恢复）；**载入 `Data/Tilesets.rxdata` 全量**（`load_data`——反序列化边界，WP04/WP10 引用）；初始图块组 1。
- **显示**：每行 8 块 ×32 像素；**首行为自动图块行**（每自动图块 48 块）；覆盖层显示**非 0 标签数字**；右侧 400% 放大当前块＋标签名（`GameData::TerrainTag` 存在则显示 `编号: 名称`，否则只显示编号）；品红衬底。

### 7.5 保存时记录集合、PBS 路径与消费者

确认指标保存先写 `Data/species_metrics.dat`，随后才反写 PBS。输出路径只由**反写开始时已登记的非零形态指标记录**的来源后缀去重产生：空后缀选 `PBS/pokemon_metrics.txt`，后缀 s 选 `PBS/pokemon_metrics_s.txt`。只有基础形态（0 形态）不会产生任何指标 PBS 路径；已选路径只写同后缀记录。非零形态的背面位置、正面位置、正面高度、阴影横移、阴影大小五组值都等于当时基础形态值时，省略该形态节，**但其后缀路径仍已选中**。基础记录不受这项等值省略规则影响。省略单个形态不等于不打开整个文件；未选旧路径不因此删除或改写。

以下是合法物种与文件的人工／配置静态对照，不声称已验证默认样本。保存时登记仅含所列记录，无额外查询、插件、外部修改或其他相关旧 PBS 记录；所有指定读写和随后编译成功。A、B、D 为五组完整指标值，A 与 B 不同，D 与两者不同；例如只把背面 x 从 A 的 0 改为 B 的 4，D 为 8，其余组保持相同。s 与 t 是不同非空来源后缀。PBS 原基础记录为 A，文件编译前提包含合法基础记录。

| 保存时登记集合 | 成功档案保存 | 实际 PBS 路径与输出 | 从档案重载 | 从相关 PBS 成功重编译／随后查询 |
| --- | --- | --- | --- | --- |
| 仅基础记录，后缀 s，指标 A→B；保存前未查询非零形态 | 保存基础 B | 无指标路径；旧 s 文件保持 A（原不存在则仍不存在） | 基础 B | 以存在的旧 s 文件重编译，基础回到 A |
| 基础 B 与非零形态 D 同后缀 s，五组值有差异 | 保存两条记录 B／D | 选 s；基础 B 与非零 D 均输出 | 两者保留 | 两者按输出重建为 B／D |
| 基础 B 与非零形态 B 同后缀 s，五组值相等 | 保存两条显式记录 | 仍选 s；输出基础 B，省略非零形态节 | 仍有显式非零 B | 仅重建基础 B；以后查询缺失非零形态才复制 B 新建记录，新记录后缀为空 |
| 基础 B 仅后缀 s，非零 D 仅后缀 t，无其他非零记录 | 保存 B／D | 只选 t、输出 D；旧 s 文件仍 A | 基础 B／非零 D | 从旧 s 与新 t 成功编译，基础 A／非零 D；基础可与档案不一致 |

**等值必须在保存时判断**：若原基础与非零形态都为 A，仅把基础改成 B 后保存，即使修改前两者相等，保存时已不同，非零 A 不可按旧等值省略。同后缀时基础 B 与非零 A 均输出；若五组仍全部相等则走表中省略对照。

**查询可先改变集合**：首次查询合法但尚无指标记录的非零形态，会在登记中建立该形态；基础不存在时先建立默认基础指标，再复制其五组指标，两组坐标随后可独立修改。新形态的来源后缀缺省为空，**不继承基础的来源后缀**。浏览形态预览、阴影查询和自动定位都可到达这一查询，因此不能用进入编辑器之前的文件／记录数推断保存路径。例如只有后缀 s 的基础 B，预览缺失非零形态后，它以 B／空后缀登记；随后执行保存会选择默认指标路径，即使该形态因等值被省略，也不会因此选择基础的 s 路径。仅浏览但没有确认的指标改动，不会因此强制出现保存提示；正常关闭的重载分支会丢弃未落盘的新登记记录。

**消费者分开**：编辑器参数调整先改变登记值并刷新自己的预览，此时尚未保存文件；BACK 恢复所编辑参数后也刷新预览。预览按基础位置重新应用当前指标，坐标偏移尺度为 2。普通战斗中已经完成布局的精灵在设置位图／重新定位时取指标，所读普通逐帧更新不重新应用指标；保存、档案整体重载或 PBS 重编译本身都不广播重新定位。直接查询在重载后看到档案值，并不保证已有布局同时变化。不得把这一边界扩大成所有显示者都永不刷新。

**部分失败**：若档案已成功保存 B，随后某个 PBS 打开／写入失败，档案的 B 不回滚；已经完成的 PBS 写入也没有总回滚保证。失败文件究竟未打开、已截断还是部分写入取决于失败时点，不能统一预测为旧内容。反向对照是正常不保存退出：重载原档案、PBS 不写；它与“已保存档案后反写失败”不同。两种情况均不虚构已有战斗布局的热更新或宿主异常画面。

## 8. 无效图块修复（`003_Debug_MenuExtraCode.rb:668–739`；WP72 已读全文，本包主责合同）

- **范围**：**全部地图**（`Compiler::MapData`——WP75 引用）的**全部图块层**与**全部事件页图形**。
- **有效性判定（B-R09 修订——三分支）**：**仅正数 1–383** 走自动图块名检查（对应自动图块名非空才有效）；**0 与至少 384 均走通行表项是否存在**（ID 0 的表项存在——**普通空图块有效：不能把合法空白地图预测为每图都被改写**；≥384 且表项缺失才判错）（`pbCheckTileValidity`——tilesets 数据引用，WP04/WP12 边界）。

## 10. 边界、失败与未知

- **取消语义汇总**：连接——BACK 确认才序列化＋清缓存（否则**遭遇重载**——§3.3 如实登记）；地图元数据——确认即落盘；地形——BACK 确认才写 Tilesets.rxdata；**未保存直接 No 且 Exit Yes 才会话丢弃（首次未保存分支）**；**保存后运行对象与会话对象同一——继续编辑后再 No 只不写文件、运行内存保留新值**（§5 三分支，B-R06）；遭遇——BACK 确认才 save＋反写（否则 load 丢弃全部含删除）；指标——退出确认才 save＋反写（否则 load 丢弃）；修复图块——**逐图立即保存**（无取消路径）。
- **拒绝/回退**：连接——**仅某图没有任何直接邻接时才回退连接画布首个其它图**（逐节点回退——两组各有邻居时不补跨组连接，B-R01）；遭遇——同（图,版本) 存在检查（新建/复制/改图/改版/改类型）、类型全用消息；指标——自有阴影图形拒绝 shadow_size 编辑；修复——无错误只提示。
- **不校验项（如实登记）**：生成连接不验证图存在性（装载层过滤）；地形标签**可选集合＝已注册 ID**（未注册的旧值只按数字显示、不能任意输入，B-R05）；指标编辑的预览对缺图仅显示层回落（除 §7.3 具名拒绝）——**但单体自动定位直接读两位图高度：缺图可失败（与全量缺图跳过分开，B-R08——不以可手改数值推断全部操作可安全完成）**；自动定位对全透明位图按向下取整公式退化计算（透明图 ≠ 缺图）。
- **异常路径（B-R08 v4）**：**预览/列表的图形装载失败仅显示层回落（精灵位图为空）；单体自动定位直接读两位图高度——缺图可失败**（不是所有图形失败都仅显示回落，§7.4）；`pbCriticalCode` 包裹连接编辑器的屏幕尺寸变更（恢复在临界段内）；**不虚构事务回滚**——逐图保存与逐对象覆写按实际登记。
- **未知/未证**：编辑器运行表现与宿主窗口行为；素材存在（WP15/U01）；demo 入口可达性（WP77/U01）；`Compiler::MapData` 读写地图的完整合同（WP75 主责——本包只引用调用点）；连接数据的运行时消费细节（WP11 主责）。
