## 1. 目的、范围与非目标

**目的**：定义战斗内"个体进出场"与"逃跑/被阻止"的完整要求：主动换人与替补（含濒死替补）的资格与次序；出场→清理/保留→替补绑定→入场通知的写入顺序；场上 Shift 位置移动与替补换人的分工；拘束/阻止与逃跑判定（概率、尝试计数、成功失败反馈）；无合法替补、重复选择、目标变化等边界的实际分支。

**范围**（WP41 自身声明范围）：
1. WP41-A：换人资格（换入/换出/组合检查、取消、登记）。
2. WP41-B：换人执行（召回→替换→入场通知与入场效果；清理与保留）。
3. WP41-C：濒死替补与回合末替补流程；对侧提示与"连锁"。
4. WP41-D：Shift 位置移动（资格/执行/结果与目标指向）。
5. WP41-E：逃跑与拘束（能力/道具/招式路径；概率与计数）。
6. WP41-F：拖出/强制换出类招式（有界族）。

**非目标**：
- 不定义命令阶段与顺序（WP40）、回合末与终局完整结算（WP42）、入场特性/道具/隐患的完整效果族（WP44/WP45/WP48/WP50 只引用具名族）、换入个体的成长/学习（WP30/WP42）、捕获后接收（WP38）、个体形态变更域（WP21/WP22）。
- 不定义队伍界面（WP67-A）；不运行参考代码。

## 2. 概念与术语

- **换入个体**：候选加入场上席位的队伍成员（按"参与个体数组"的队伍内下标标识）。
- **换出**：当前席位个体离场（清理 + 保留规则见 §4）。
- **替补**：因濒死等在某席位重新派出个体（回合末流程与招式强制换出的统称）。
- **Shift（位置移动）**：同一业主的两个场上席位互换——与"换人"（个体变更）不同。
- **拖出（drag）**：由招式强制目标以**随机**合法成员替换并继续战斗（不消耗其行动）。
- **拘束（trapping）**：阻止换出/逃跑的场上状态族（招式状态、特性/道具、全场封锁）。
- **某次尝试计数（runCommand）**：同场战斗内逃跑尝试的累计数，用于提高成功率。
- **目标指向效果**：效果记录"指向某个席位索引"的一族（着迷、锁定、束缚…）；位置交换时必须重映射（具名清单归 WP39 §5 登记，本包给出结果要求）。

## 3. WP41-A：换人资格

### 3.1 换入资格（`pbCanSwitchIn?`，可静默或界面提示）

逐条拒绝：下标越界/空；**蛋**（"蛋不能战斗！"）；**非本业主的个体**（"你不能用你的宝可梦交换 {owner} 的！"——业主不一致即为越权）；**濒死**（"没有体力战斗了！"）；**已在场上**（"已经在战斗中了！"）。通过则真。
- **负下标**：仅换入查询直接返回真，作为空候选查询／取消路径的哨兵值；**组合查询并不因此直接通过**，仍会做重复选择与换出检查（§3.3）。UI 取消与登记另行处理，界面请求登记时拒绝负下标；不得把这个查询结果当成“已合法选入的成员”。

### 3.2 换出资格（`pbCanSwitchOut?`）

按序：濒死直接通过（濒死者不触发拘束）；**确定性脱身**（特性族/道具族触发即通过；开启更多属性效果时幽灵属性直接通过）——先于拘束判定；**场内拘束状态**（束缚/**黑色目光（MeanLook）**/下颚锁/章鱼桶锁/扎根/背水一战/妖精锁等聚合判定）→"不能换下！"；**对侧特性/道具抓取**（逐个存活对侧，具名消息"{对方}的{特性/道具}阻止了交换！"）。

### 3.3 组合检查与登记（`pbCanSwitch?` / `pbRegisterSwitch`）

组合查询依次检查：1. 换入资格；2. **同侧重复选择**：本侧已有席位登记 `SwitchOut` 到同一下标 → “已经被选中。”拒绝；3. 换出资格。全过只返回资格通过，**查询本身不登记**；登记入口再次调用组合检查，通过后才写入换人动作及候选下标。
- **分层**：①**仅换入检查**（`pbCanSwitchIn?`）——随机拖出候选、宽松替补选择使用；②**组合检查**（`pbCanSwitch?`＝换入＋重复选择＋换出）——用于直接完整资格查询、严格队伍界面和登记入口；**不登记的界面也可执行组合检查**；③**界面许可**——`canSwitch` 只影响普通可取消队伍 UI 的“Switch In”按钮，直接查询不读此开关；④**登记**——写选择前再次做组合检查；⑤**实际替换**（§4/§6）——不重新调用组合检查。
- **重复选择检查**（组合层的一部分）：本侧已有席位登记 `SwitchOut` 到同一下标 → "已经被选中。"拒绝。

### 3.4 界面与取消

- 队伍界面路径：`canCancel` 控制能否取消；普通模式的“Switch In”按钮还要求候选可战斗，且 `canSwitch` 为真或界面不可取消。**按钮许可不替代选中后的资格检查**；查看摘要不产生选择。
- **检查强度与是否登记正交**：选中候选后，`checkLaxOnly=true` 只检查换入资格；为假则检查组合资格。通过后，`shouldRegister=false` 只返回候选、不写 SwitchOut；为真才拒绝负下标并调用登记入口（该入口再次组合检查）。中途替换选择 UI 可在不登记的情况下使用严格检查；不能由“不登记”推导“只检查换入”。命令期换人可取消返回命令小循环；强制替补按各自入口决定取消许可。
- **命令期换人连招**：选择时不做执行；实际召回发生在攻击阶段（WP40 §5.1 第 5 步）——**执行链不重新调用组合检查**（追击打断是独立流程；已登记换人不会因对手先入场的抓取特性在执行时被否决）；其余非濒死/追击前提照常。

## 4. WP41-B：换人执行与出入场次序

### 4.1 召回与替换（`pbRecallAndReplace` → `pbReplace`）

1. **召回演出**：濒死者跳过召回演出；否则播放召回。
2. **换出清理**：换出者的"换下时"能力钩子（含原始天气终结检查）先执行。
3. 单席位布局（本侧 1 席）→ 先显示整队阵容行（界面）。
4. **替补消息**（非随机替换时）按"持有者口径"：玩家拥有者按对手血量四档问候；非玩家按"{业主}派出了{个体}！"（幻觉特性时用队伍末位合格个体的名字——WP39 登记）。
5. **个体绑定**（`pbReplace`）：新个体 `pbInitialize(个体, 队伍内下标, 接力?)` —— 效果清零/接力子集应用与招式映射见 WP39 §6.1；**队伍顺序数组互换**（换入下标与换出下标，供幻觉等顺序相关规则）。
6. **派出**（`pbSendOut`）：入场形态钩子 → 演出 → 每席位重置命令界面下标、登记"见过"、标记"已使用于战斗"——**该标记的写入定位是"侧＋侧内场上位置"**（按派出席位换算记录位；单打席位 0 对应记录位 0），**不是被派出个体的队伍下标**：同一席位先后换入的不同个体都写同一记录位（GR-013；读取侧在正常终局按队伍下标逐个读取，见 WP42 §6 共同次序——两端不是同一下标口径，不能把该记录当作可靠的"某个体是否实际参战"事实）。
7. 可选按该席位重算行动顺序（配置）。

### 4.2 入场通知与效果（`pbOnBattlerEnteringBattle`）

按**当前速度顺序**（仅速度排序变体）处理每个入场席位：
1. **参与登记**：记录"曾参与"，并按持有物刷新"金钱翻倍"类场地标记。
2. 暗影个体入场消息。
3. **位置效果消费**：该**席位**上残留的"治愈之愿/新月舞"类位置效果在此消费（回复/治疗/回满 PP；世代分支的空消费条件见源）。
4. **入场隐患**（按侧）：隐形岩（属性相性折算 1/8 族）、撒菱（层数分母 8/6/4）、毒菱（毒属性吸收/中毒或剧毒，厚底靴免疫）、黏黏网（降速一级）——各自附带道具回复检查等具名后续。
5. 若因隐患濒死：濒死结算→经验结算→裁判→跳过其余步骤。
6. 入场形态检查；**Primal 还原**（WP40 §7.2）；持续能力检查（复制等）；**入场特性**（具名触发族）；原始天气终结复查；**入场道具**（气球消息等）；持有物触发检查与状态治愈能力检查。
7. 处理完毕后按速度序检查"半血以下/掉档"类退出效果（应急退出/逃之夭夭/逃脱按键族）触发——只触发一个具名族的说明见源。
- **与命令期换人的差异**：命令期换人路径在此之前由攻击阶段步骤先行清理全场的半血/掉档标记（源具名说明：避免中和气体结束连锁触发逃脱按键，故该重置提前）；`skip_event_reset` 参数承担该差异。

### 4.3 清理与保留（跨 WP 引用）

- **保留**：个体持久数据（HP/PP/状态/等级等）随个体本身；战斗临时效果按 WP39 §6.1 的清零/接力子集规则处理；道具经换下时钩子（如检查回报）与 WP20 的持有物状态口径引用。
- **形态（普通换下与濒死/战后分开；不统一解除）**：普通换下调用具名离场钩子族（`pbAbilitiesOnSwitchOut`）：换下时特性触发、**离场形态钩子**（`getFormOnLeavingBattle` 族，如天气形态回退）与原始天气终结；**没有统一的 Mega/Primal 解除**——**存活原始盖欧卡/固拉多普通换下不解除原始形态**（其形态登记仅有 `getPrimalForm`，无通用离场回退）。**显式解除仅发生在濒死与战斗善后**（WP39 §7.4）。**入场 Primal Reversion 是"进入原始形态"，与"解除变身"不得混称**。该钩子内把战斗副本 HP 置 0（"视为濒死"用于中和气体/紧张感收尾）**不代表持久 HP 归零**（维持 WP39-R03 分层）。
- **队伍顺序**：仅换人路径交换顺序数组；Shift 不交换顺序数组（同个体在场，只换席位）。

## 5. WP41-C：濒死替补与回合末流程

### 5.1 回合末替补（`pbEORSwitch`）

1. 先裁判：任一方全灭→决定非 0 时（`favorDraws` 差异）提前返回；否则裁判未决继续。
2. 循环扫描**所有濒死席位**（每轮重扫，直到无新替换）：
   - 无任何可换入者（换入资格全员失败）→ 该席位保持不变（不报错）。
   - **对方/伙伴席位**：野生个体不能换；AI 选择替换（接口调用）；**单打·训练家·玩家侧（开启换人风格）且对方是替换方**时，先向玩家出示"{对方}即将派出{名字}。你要换宝可梦吗？"（幻觉名字用末位）；玩家确认→先换玩家席位（记录已换，避免同轮重复提示）；再执行对方替换。
   - **玩家侧（训练家战斗）**：由业主选择替换（AI 控制时 AI 选择）。
   - **玩家侧（野生战斗）**：先问"使用下一只宝可梦吗？"；拒绝则尝试逃跑判定（`pbRun(席位, true)`：返回值 ≤0 视为切换，>0 为逃跑成功结束战斗；**替补路径跳过幽灵/必逃/拘束整组——§7.1**）；确认/切换→选择替换并执行。
3. 每轮实际发生替换后，对**本轮所有换入席位**执行一次入场通知（§4.2）；过程可连锁（新入场因隐患濒死→下一轮继续）。
- **消息次序**：召回（非濒死者）→ 换下清理 → 阵容行（单席位）→ **替换消息** → 绑定 → 派出 → 入场通知。
- **对侧提示限制**：仅"单打（玩家侧 1 席）＋训练家战斗＋对侧替换＋玩家席位未濒死且本轮未换＋有可换入者＋玩家席无暴走效果"才出示；双打及以上**没有**该提示（静态边界）。

### 5.2 多人/多濒死

- 每轮循环只处理"仍濒死且可换"的席位；**同时多名濒死**按席位顺序逐个处理，每轮结束后统一做入场通知。
- 野生侧尺寸无关替补（野生不能换）。
- 伙伴席位属"对方侧分支"？不——伙伴属玩家侧但**非玩家拥有**：替换由其业主（伙伴）选择，走"非玩家拥有者"路径（AI 接口），不受玩家提示影响。

## 6. WP41-D：Shift 位置移动

- **资格**（WP40 已给选择门）：双打及更小不可用；本侧 3 席时中位不可用、1 席不可用；换位对象须**同一业主**（业主映射引用 WP39）；界面仅在可 Shift 时显示按钮。
- **执行**（攻击阶段，按行动顺序）：
  1. 确定换位对象：2 席→"隔一位"位；3 席→非中位者与中位（2/3 号）互换。
  2. 互换席位上的个体对象与**选择槽**，并由场景交换立绘位置。
  3. **目标指向效果重映射**：对全场的具名"指向索引"效果，把指向 A/B 的改为另一个——**有界十项**：着迷、**忍耐目标（BideTarget）**、反击目标、镜反目标、锁定位置、**黑色目光（MeanLook）**、下颚锁、章鱼桶锁、天空摔投、束缚者（TrappingUser）。**明示例外**：吸血种子不换（HP 归属位）；灭亡歌使用者无需调整（只用于判定侧别）。
  4. 消息："横移过去！"（2 席）/"移到中央！"（3 席）。
  5. **行动代价**：本次行动标记为"已行动"（该席本回合不再执行）；**取消该席的多回合计数**（源：Shift 分支显式取消多回合与反击计数，非 Hyper Beam 回复段）；不消耗对方的行动。
  6. 位置不改变业主、队伍段、目标邻近关系定义（邻近按位置表；交换后邻近关系随之改变——具名近邻对表引用 WP39 §4.2）。
- **与替补换人的分工**：Shift 不触发入场钩子/隐患/入场特性（个体未离场）；替补换人触发全部出入场流程。命令资格与时机（WP40）不变。

## 7. WP41-E：逃跑与拘束

### 7.1 三种入口与守卫分层（不共享同一资格）

- **查询 `pbCanRun?`（只读）**：训练家战斗→假；`canRun` 为假且非对方席位→假；幽灵（更多属性效果）/必逃特性/必逃道具→真（先于拘束）；拘束聚合或对侧抓取→假。（招式"用户逃离"类用此查询做失败检查。）
- **普通执行 `pbRun(席位)`（duringBattle=false；玩家命令期、敌侧调用）**：守卫按序——①对方席位分支（训练家→0；野生→登记 `Run` 并返回 -1，无玩家式判定）→ ②调试菜单（取消→-1、改写结局→1、未生效→0）→ ③训练家分支（游戏内"无法逃跑"→0；设施→确认弃权→1/0）→ ④`canRun` 假→0 → ⑤**`!duringBattle` 组**：幽灵/必逃特性/必逃道具（**确定性成功**→1）/拘束/抓取（拒绝→0，各自消息）→ ⑥**计算段**（§7.2）。
- **替补执行 `pbRun(席位, true)`（回合末"不用下一只"路径）**：仍经过 ①–④ 的门（对方分支/调试/训练家/`canRun`），但**跳过整个 ⑤ 组**（幽灵/必逃特性/必逃道具/拘束/抓取均不参与）→ 直接计算段。**替补不能沿用普通路径的幽灵/必逃确定性成功**。
- **术语**：拘束聚合（`trappedInBattle?`，与换出共享）=束缚状态、**黑色目光（MeanLook）**、下颚锁（双向检查）、章鱼桶锁、扎根、背水一战、妖精锁（全场）；确定性脱身先于拘束；对侧抓取的消息为"用{名}阻止了逃跑！"，必逃道具为"{个体}用{道具}逃走了！"。
- **调试**：调试+Ctrl 出现结局选择菜单（胜/负/平/逃/捕获[仅野生]/取消）；**取消返回 -1**（决定不变，但命令期调用者会因此停止本回合其余玩家选择——WP40-R02 消费）；非取消改写决定并返回 1。
- **差异声明**：查询与两种执行**不是同一资格集合**；"三入口共用守卫"不成立。逃跑与换出共享多数判别但有独立消息/失败面；逃跑无"对侧提示/更换对手"分支。

### 7.2 逃跑判定（整数；仅野生且到达计算段）

- **计数时点**：`runCommand` 只在**到达计算段且非 duringBattle** 时 +1；**确定成功与更早拒绝（含替补）都不增**；**替补执行使用既有累计数**。
- **速度**：读取**未经 `pbSpeed` 修正的战斗副本速度值（`Battler.speed`）**——它**不等于**"保证不变的个体原值"：变身等可改写战斗副本速度，以**当前值**计算。
- **判定**：我方更快（>`对侧最快`）→ `rate=256`；否则 `rate = ⌊我方速度 × 128 ÷ 对侧速度⌋ + 尝试数 × 30`（整数除法向下取整；加成固定 30）。
- 判定：`rate ≥ 256` 或 `随机(256) < rate` → 成功：音效＋"成功逃走了！"、决定置 3、返回 1；否则"没能逃走！"、返回 -1。
- **返回语义**：-1 失败（普通路径已消耗本次行动）；0 未尝试（继续）；1 成功（决定 3 以结束战斗）。**消费方分别登记**：玩家命令期（WP40 §3.3）与替补路径（§5.1 第 2 步）。

### 7.3 逃跑的出口与终局边界

- 逃跑成功只写"决定 3"；**完整终局清理（金钱、成长、世界回调）归 WP42**。玩家弃权（设施）同理只置决定与消息。

## 8. WP41-F：拖出/强制换出与相关招式族（有界）

以下为**招式直接造成换人/随位/逃跑效果**的有界族（效果值/命中归 WP43 与本族文件；本包只固定换人行为）：
- **用户逃离**（Teleport 旧世代）：仅当自身可逃且（野生时无同伴）→"逃走了！"、决定置 3。
- **用户换出·变化招**（Teleport 新世代）：野生→按逃离判定（失败则招式失败）；非野生→须有可换入者否则失败；招式末（`pbEndOfMoveUsageEffect`）执行"回到{业主}！"→追击→选择替换→换出（清选择：替补本回合不行动）→入场通知。
- **用户换出·伤害招**（急速折返/伏特替换/快速折返）：在"已造成伤害、未濒死、对侧未全灭、目标未因其它原因换出、有可换入者"前提下执行同一末段；**忽略拘束（不检查换出资格中的拘束族）**（源注释具名）。
- **撤退射击类（降低目标攻/特攻后换出）**：后段可能根据尚存魔法外衣／反弹效果标记改变换出候选，但仍要求外层实计击数>0、候选存活、有合法后备等。普通单目标被反射时原路径实计0击；反回可降原使用者阶级，后段仍拒换人。完整入口及具名对照见[WP47-B §2.1／§8、S07](wp47-b-switching-control-and-item-changes.md)，不推广为所有反射都不能换出。
- **接力棒**：须有可换入者否则失败；换出时按**接力路径**把已声明子集效果再应用（WP39 §6.1）——**接力效果全集尚未在本包列明，具名前向**（完整清单随效果族 WP42/WP44/WP50 等），不声称"完整明示子集"；末段执行换出+入场。
- **强制换出·变化招（吼叫/吹飞）**：在**失败检查阶段**拒绝的情形——目标吸盘（受模式破坏者影响）、扎根、唯一野生且可逃但等级高于使用者、非野生但队内无可换入者 → **招式失败**；否则唯一野生低等级 → **结束战斗（决定 3）**；非野生 → 末段由**随机**合法成员替换（不消耗其行动、清选择、入场通知）。
- **强制换出·伤害招（龙尾/圆圈投掷）**：**不共用上述失败检查**——伤害照常发生；其**野生终局分支**（主要效果时当前替身耐久为0或本招绕替身、唯一存活野生、canRun真、等级不高于使用者）→ **决定 3**；条件不满足 → **不换出（也不使整个伤害招失败）**。**该野生终局分支没有吸盘/扎根门**；吸盘/扎根（吸盘受模式破坏者影响）只在**后续非野生拖出分支**检查。**不得把训练家拖出门移植到伤害族野生终局**。本击刚破替身也可满足野生的当前耐久门；非野生末段另拒本击substitute吸收标记，详[WP47-B S03](wp47-b-switching-control-and-item-changes.md)。
- 具名族对应：Circle Throw（圆圈投掷）／Dragon Tail（龙尾）属伤害族；**打落（Knock Off）不属于该族**。
- 已正确保留：合法候选、至多一次替换、清选择与入场通知。
- **拘束类**（捆绑族/**黑色目光族**/章鱼桶锁/下颚锁/妖精锁）：登记状态（持续时间/使用者/指向）与阻止换出/逃跑；具体数值与回合末伤害归 WP44/WP42；本包登记"阻止"入口与解除条件（换出者离场时相关指向被清——WP39 §6.1）。
- **追击（Pursuit）**：作为对"换出者"的打断在攻击阶段执行（WP40 §5.5）；命中加成（切换时威力×2、必中）本包登记，数值归 WP43。
- **强制拖出的取消面**：被拖出者不消耗行动，清空其本回合选择（"替补本回合不行动"同族）；**无合法替补非报错**——招式侧先失败（吼叫族），或入场路径静默放弃（末段 `newPkmn < 0` 返回）。

## 9. 规则与不变量

1. 换人=个体变更（触发出入场全套）；Shift=席位互换（不触发出入场）。
2. 换入资格五拒绝（越界/空、蛋、越权、濒死、已在场）；换出资格先"确定性脱身"后"拘束"；对侧抓取具名。
3. 登记路径唯一（`SwitchOut` 选择槽）；拖出/回合末替补不经登记、直接执行且**不消耗被换入者行动**。
4. 执行次序固定：召回→换下清理→阵容/消息→绑定（效果清零/接力）→派出（入场钩子）→入场通知（速度序）→可选重算顺序。
5. 入场通知内隐患/位置效果按具名次序；隐患濒死→立即结算并跳过余项；退出效果族最后统一检查。
6. 回合末替补循环直到无新可换；同轮所有换入者统一入场通知；对侧提示仅在单打训练家战斗成立。
7. 逃跑判定使用**未修正速度**与整数除法的 `rate`、`+30/次` 尝试累计；成功仅置决定 3。
8. 逃跑与换出共享判别族但有独立消息；丢弃"带同伴的野生个体不能逃"等条件只按其分支持有（逃离招式野生无同伴条件）。
9. Shift 后须重映射目标指向族（吸血种子除外）；行动计为已行动并取消多回合计数。
10. **拖出路径的随机替换**（`random=true` 接口）为**均匀选取合法集**；**回合末/AI 替补走"选择最佳"接口**（评分策略归 WP51）——**不承诺统一均匀选择**；无合法集时不报错（返回 -1 放弃）。

## 10. 边界与失败

- 无合法替补：回合末保持原位；招式侧按各族先失败；末段返回放弃。
- 重复选择同一下标：同侧其它席位的检查拒绝（"已被选中"）。
- 已濒死个体被换入：拒绝（"没有体力"）；蛋：拒绝。
- 越权（换别的业主的个体）：拒绝且具名消息。
- 拖出目标在招式结算中变化（濒死/替身/不受影响/已换）：末段逐目标跳过；本次只能**至多替换一个**（首个成功者后 break）。
- 强制换出对吸盘/扎根：变化族在失败检查阶段拒绝并给出失败消息；伤害族只在**非野生拖出末段**按目标状态跳过，野生终局分支不添加这两道门（§8）。
- Shift 中位/单人：资格直接拒绝；业主不同拒绝。
- 逃跑按 §7 三入口分层：普通执行的游戏内训练家战斗拒绝，设施可确认弃权；普通野生路径的幽灵／必逃特性／道具先于拘束，替补执行跳过整组。普通执行到达计算段后随机不中会消耗行动，后续普通尝试到达计算段再加计数；查询与替补不套用这份普通路径摘要。
- 调试逃跑菜单取消保持决定不变，但返回 -1；命令期消费者停止本轮其余玩家选择（WP40 §3.3），不声称所有状态都不变。
- 未运行确认：所有概率、菜单取消链、多打实况。
