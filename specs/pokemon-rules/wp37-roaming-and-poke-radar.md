## 1. 目的、范围与非目标

**目的**：固定漫游宝可梦与 Poké Radar 的规则合同——**状态有哪些、何时初始化与推进、何时可遇见或被替换、战斗结果如何写回、连锁如何开始/继续/中断、哪些入口取消哪些状态**。后续包据此判断"某漫游条目何时出现、某草丛摇动意味着什么、某战斗结束后连锁还在不在"，而不是各自重新追踪两份主文件。

**范围**（WP37 自身声明范围，extraction-plan 第 2.1 节 (a) 类）：

1. WP37-A：漫游配置、状态与初始化——条目身份、启用开关、路线图、当前位置、未生成/已有持续个体/已终结、终结是否捕获、本次待用的遭遇选择、再次遇见限制；持久与暂态分列；首次/惰性/重复进入的写入。
2. WP37-B：漫游位置推进与可遇见判定——地图进入通知的真实触发条件（名字比较）、推进算法（邻接/额外随机候选/空候选）、可遇见判定的全部门（再次遇见限制、伙伴、雷达状态、25% 门、位置与同名同区域、方式允许）。
3. WP37-C：漫游遭遇替换与跨战斗存续——替换钩子所在位置、首次生成与复用持久个体、强制单打与下一战 BGM、各战斗结果对状态/终结原因/再次遇见限制的影响、重置入口的实际条件。
4. WP37-D：雷达使用、充能与摇动草丛——许可门的真实顺序（地形/遭遇表/骑车/调试/电量）、使用与连锁数据保留、四环几何与有效性、普通/剧烈/闪光表现与概率、无有效草丛、计步充能条件。
5. WP37-E：雷达候选、闪光与连锁延续——雷达专属表与普通表回退、权重与等级、连锁继续概率的完整输入、三件事分开（草丛成为闪光/个体标闪光/连锁继续）、延续失败的有限改选、战后更新。
6. WP37-F：取消、事件顺序、保存与跨域边界——全部取消调用者及各自清理范围、漫游与雷达钩子的注册/调用次序、持久全局记录与临时状态分列、demo 可达性保留。

**非目标**：

- 不定义普通遭遇算法（候选层/触发率/双打/Repel，WP36 主规格）、战斗终局与结算（WP42）、捕获接收（WP38）、逃离许可（WP41）、创建/覆盖入口通用合同（WP39）、钓鱼（WP60）、场地招式（WP59）。
- 不定义个体生成全部修饰（WP36/WP19 主规格；本包只登记漫游/雷达特有分支）。
- 不运行游戏/战斗/UI、不操作真实存档、不播放音频、不调整宿主界面、不编译/转换、不设计未来 API 或把参考类组织当作未来模块。

## 2. 概念与术语

- **漫游条目（roamer entry）**：配置数组的一条——`[物种, 等级, 开关编号, 遭遇方式, 战斗 BGM(可选), 专属路线图(可选)]`；**配置存在不等于 demo 中开关已被打开**（开关状态是运行时数据，U01）。
- **漫游状态（持久，全局元数据）**：`roamPokemon[i]`（**nil=未生成/已重置；宝可梦对象=已有持续个体；true=已终结**）、`roamPokemonCaught[i]`（终结原因：true=被捕获、false=被击败）、`roamPosition[i]`（当前所在地图 ID）、`roamedAlready`（当前地图上已遇到过漫游的标记）、`roamEncounter`（本次待用的漫游选择；战斗中清空）、`pokeradarBattery`（雷达剩余充能步数）。**持久 ≠ 已落盘**——落盘只经保存流程（WP09）。
- **暂态**：`roamer_index_for_encounter`（本次待遇条目下标）、`poke_radar_data`（连锁数据：[物种, 等级, 连锁数, 摇动草列表, 上次捕获标记]）、`force_single_battle`（强制单打标记）——均在临时对象上，不随存档持久。
- **路线图（area map hash）**：键=地图 ID、值=可推进到的地图 ID 数组；单条目有专属图时覆盖全局图（`pbRoamingAreas`）。默认全局图共 **10 张地图**（键 5、21、28、31、39、41、44、47、66、69），**每图各有其余 9 图作普通邻接**（R01 修订：区分 10 图集合与每图 9 条邻接；1/32 额外随机候选仍从全部 10 个键中取、**可能抽中当前图**）。
- **惰性初始化**：`roamPosition[i]` 为 nil 时，各消费点（推进、可遇见判定）就地从该条目路线图的键中随机取一个写入——**首次初始化没有独立入口**。
- **雷达连锁（chain）**：`poke_radar_data` 存在即连锁中（chain count >0 时数据[2]>0）；**草丛成为闪光（摇动草的稀有度=2）、生成个体标闪光（生成钩子按格赋值）、连锁继续（概率判定）是三件事**。
- **取消（cancel）**：清空 `poke_radar_data`（临时连锁）的统称；**各取消调用者只清临时连锁，不动电量/统计/最长纪录**——除非另行注明。
- **已通过边界（必须继承，不重开）**：**GR-011（已关闭）**——步进、转向、主动请求是不同入口；主动请求包装本身不写遭遇触发标记，普通移动转向和独立转向的清理也不同；**GR-013（已关闭）**——WP42 与 WP41 的参战标记及正常终局合同按当前已批准字节引用。本包不为漫游/雷达补"所有请求统一写标记"的规则。
- 影响域编号 Dxx 见 module-map；证据状态五档定义见总览第 7 节。

## 3. WP37-A：漫游配置、状态与初始化

### 3.1 条目与路线图配置（`001_Settings.rb:175–213`）

- **条目结构**：每个漫游条目为六元配置——物种标识、等级、Game Switch 编号（**>0 时开关为 ON 才漫游/可遇见**；≤0 恒启用）、遭遇方式（0=草地/洞穴步行/冲浪（陆地类+水）、1=草地/洞穴步行（陆地类）、2=冲浪（水）、3=钓鱼、4=水基（冲浪+钓鱼））、战斗 BGM（可选，非空才写下一战 BGM）、专属路线图（可选，覆盖全局 `ROAMING_AREAS`）；全部条目按配置数组（`ROAMING_SPECIES`）的下标索引（R13 修订：数组字面写法改行为文句，配置名保留作审计标识）。
- **默认数据样本**：LATIAS（Lv.30、开关 53、方式 0、"Battle roaming"）、LATIOS（同前）、KYOGRE（Lv.40、开关 54、方式 2、无 BGM、专属 4 图路线）、ENTEI（Lv.40、开关 55、方式 1）。全局 `ROAMING_AREAS` 为 **10 张地图的邻接表（每图 9 条普通邻接，R01 修订）**。
- **遭遇方式与当前遭遇类型的映射**（`pbRoamingMethodAllowed`）：**方式 0**=陆地类或水（land/cave/water）、**方式 1**=仅陆地类（land/cave）、**方式 2**=**仅水（water，不含钓鱼）**、**方式 3**=**仅钓鱼（fishing）**、**方式 4**=水基（water＋fishing）；捕虫大会不属任一。**类型来源分开（R02 修订）**：该判定**重新按玩家当前位置查询遭遇类型**（冲浪走 Water 分支、陆地地形走 Land、否则 Cave——**查询可能返回空**），**不读取主动请求保存在临时状态中的类型**（钓竿/击掌/甜香等主动请求把请求类型另存临时字段后触发同一候选钩子，两类来源按入口分列）。**空查询边界**：流程走到方式查询而位置查询为空时，严格类别解析在该处失败——**不能推导普通遭遇安全保留**（不虚构回退）。**方式配置是数据、当前类型是运行时状态**——两者按上表匹配，不按注释推定，也不写成"方式 2 一律禁止钓鱼请求"（冲浪玩家发起主动钓鱼时位置查询得 Water、方式 2 仍可通过）。

**默认 KYOGRE 专属普通邻接（完整四键）**：

| 当前地图 | 普通邻接候选 |
| --- | --- |
| 2 | 21、31 |
| 21 | 2、31、69 |
| 31 | 2、21、69 |
| 69 | 21、31 |

合法默认 KYOGRE、开关54开、当前位置2、路线非空；1/32附加候选门未通过时下一图只可能21或31，各1/2，无普通2↔69边。附加门通过时，另从四键均匀加入一个候选再按次数加权，可能加入2或69；此分支与普通邻接分开，不证明 Demo 打开过开关54。

### 3.2 状态机与初始化

- **状态三分**：**未生成**（`roamPokemon[i]` 为 nil——尚无持续个体；重置后也回到此态）、**已有持续个体**（宝可梦对象——首次遭遇时生成并复用）、**已终结**（`true`——被击败或被捕获后；`roamPokemonCaught[i]` 记录终结原因）。
- **初始化路径**：`roamPokemon`/`roamPokemonCaught` 数组惰性创建；`roamPosition` 惰性创建并按物种存在的条目随机填图（`pbRoamPokemon`），或单条目惰性填图（`pbRoamPokemonOne`/遭遇判定处）；**不存在"建档式"首次初始化入口**——所有首次写入都是就地惰性完成。
- **重置入口的实际条件**（`pbResetAllRoamers`）：逐条目检查——**仅当该条目已终结（`roamPokemon[i]` 为终结占位）且终结原因（`roamPokemonCaught[i]`）为被捕获时，才把该条目恢复为未生成（可再遇）**；**被击败未捕获的条目（终结且原因为非捕获）不被动**。**注释与实现不一致**（注释称重置"被击败未被捕获"的漫游，实现门却是"已终结且已捕获"——按实现如实登记，不按注释概括成"全部复活"或"全部清空"）。当前基线**无正常脚本调用者**（调试/事件潜在调用归 U01；不据此断言功能不存在）。
- **辅助入口 `pbRandomRoam(index)`**：把指定条目位置随机重置为其路线图中的任一图（无正常调用者，单列）。

## 4. WP37-B：漫游位置推进与可遇见判定

### 4.1 地图进入通知与推进（`005_Overworld_RoamingPokemon.rb:44–103`）

- **触发条件（on_enter_map）的真实输入与充分早退条件（R11 修订）**：处理器仅在**以下条件全部成立**时才早退（不推进、不清 `roamedAlready`）：地图信息表可载入 **且** 旧地图 ID 为正 **且** 旧条目存在 **且** 旧条目的**原始名称**存在 **且** **旧原始名等于当前解析显示名**（当前名来自地图元数据等解析，两种名字来源分开）。**任一前置缺失（旧 ID 为 0、旧条目缺失、旧名缺失、两侧名字不等）→ 全体推进并清 `roamedAlready`**——无法证明同名时不保持旧状态。配置对照：两张图的解析显示名同为"Route A"，但旧信息表原始名是"Internal A"——比较不相等，**仍推进**（普通对照：旧原始名与新解析名相等才不推进）。**再次遇见限制的写入入口只有三类**（本推进、战后写回、具名调试分支——**三类入口，不按源码写点计数**，具名调试分支内含多个写入处）——**没有按日重置**（"当天"表述删除；经过午夜本身不清该标记）。
- **全体推进（pbRoamPokemon）**：先惰性初始化位置（§3.2），再逐条目推进。
- **单条推进（pbRoamPokemonOne）**：开关关闭（>0 且 OFF）或物种不存在 → 不动；取路线图键集（**键集为空 → 直接返回**）；当前图缺失 → 惰性随机填图；取当前图的邻接表——**当前图不在路线图键中（邻接表为 nil）→ 直接返回、不推进**；邻接候选全部入列；**1/32 概率额外加入一个全图随机候选（可与邻接候选重复——重复项按入选次数加权）**；从候选中随机选一写入位置。

### 4.2 可遇见判定（`005_Overworld_RoamingPokemon.rb:135–186`；`003_Overworld_WildEncounters.rb:340–373`）

- **替换钩子位置**：普通遭遇选择钩子（`on_wild_species_chosen`）上注册——**在雷达连锁钩子之前执行**（注册次序：012_Overworld 先于 013_Items；§8）。每次触发先清 `roamer_index_for_encounter`。
- **前置门（任一不满足 → 保留普通遭遇）**：`roamedAlready`（本图已遇）；伙伴在场；**雷达连锁数据存在**；**75% 概率跳过（即 25% 通过）**。
- **逐条目门**：物种存在；开关启用；**未终结**（条目状态不是终结占位）；位置（惰性初始化）；**位置判定**——在当前地图，或**同名同区域**（该位置的城镇图区域与当前区域相同 **且** 按 ID 解析的图名等于当前图名——两个条件同时成立，缺元数据或区域不一致即排除）；**遭遇方式允许**（§3.1 映射）。全部通过 → 候选 `[条目下标, 物种, 等级, BGM]`。
- **选择与写入**：候选空 → 保留普通遭遇；否则**随机取一候选**：写 `roamEncounter`（本次待用选择）、`roamer_index_for_encounter`、**下一战 BGM**（仅当条目配置了非空 BGM）、**强制单打标记**、并把遭遇的物种/等级替换为该条目。
- **双打抑制**：强制单打标记使双打判定为否（`have_double_wild_battle?` 引用）——漫游/雷达替换遭遇恒为单打。

## 5. WP37-C：漫游遭遇替换与跨战斗存续

### 5.1 覆盖开战与持久个体（`005_Overworld_RoamingPokemon.rb:188–228`；`001_Overworld_BattleStarting.rb:354–373`）

- **覆盖钩子（on_calling_wild_battle）**：公开开战包装在单一敌方且允许覆盖时触发；**已被其它钩子处理（handled 非空）→ 不动**；无待用漫游选择或无本次暂态条目关联 → 不动；两者都有才把处理结果设为漫游战斗的返回。**正常替换链**：步进/主动请求 → 普通候选 → 漫游钩子替换（§4.2）→ 公开包装 → 覆盖钩子 → 漫游战斗。**被其它钩子先处理、提前拒绝、异常未到清理点不与正常返回合并**（handled 机制如实登记）。
- **覆盖门静态对照**：人工既有状态、持久待用选择非空、本次条目关联为空，直接传入合法现成个体并允许单敌覆盖、跳过候选通知；此前无覆盖处理、非 Safari/大会、无插件且普通核心正常返回 → 漫游不写处理结果，继续普通核心。相同夹具补有效条目关联 → 可进入漫游覆盖；待用选择为空也不覆盖。普通候选钩子先清关联，成功替换时同时建立选择与关联；不把人工不一致夹具推为所有读档后步行的自然状态。
- **公开生成与持续首次生成/复用分开**：以物种/等级候选发起公开单敌包装时，先按普通生成规则生成本次临时个体（包括创建通知及其它生成副作用），之后才派发覆盖。条目无持续个体时再按传入个体的物种及当时等级生成持续个体，执行漫游生成规则并发创建通知；该规则只跳过「同步」性格复制，野外道具、闪光重抽、病毒与其它修饰照常。已有持续个体则战斗复用它，但候选来源的公开包装仍先生成临时个体。直接传入合法现成个体时公开包装保留它、不再执行这一临时生成；持续个体已有时此入口没有新的生成。

## 6. WP37-D：雷达使用、充能与摇动草丛

### 6.1 许可门与使用（`005_Item_PokeRadar.rb:18–58`）

### 6.2 摇动草丛（`005_Item_PokeRadar.rb:60–111`）

- **四环几何**：以玩家为中心的第 i 环（i=0..3，内到外）各随机取 1 格——环为边长 (2i+3) 的正方形边框：上边段（含左上起点）、左右边段、下边段，在第 i 环边框格中**均匀随机抽取**（第 i 环边框共 8×(i+1) 格；独立坐标例：i=0 时共 8 格、边长 3 的正方形边框）。**出图或地形无效（非陆地遭遇/不显示摇草）的格直接跳过**——每环至多 1 格，总数 0～4。
- **稀有度**：每格 25% 为剧烈（1）、否则普通（0）；**连锁存在时**（连锁数 >0）额外判定闪光（2），概率按独立数学定义（R12/R13 修订：设闪光基准常数 c=SHINY_POKEMON_CHANCE、链长 L）：**基数 B=⌊65536/c⌋**（首次整数除法**向下取整**）；**分母 D=max(B − 200×min(L, 40), 200)**；**阈值 T=⌈65536 / D⌉**（转实数**向上取整**）；**概率 P=T/65536**，以 0..65535 均匀整数小于 T 判定——**三个量分列，不是同一等式**（默认 c=16、L=40：B=4096、D=200、T=328、P=328/65536≈0.5%；配置变体 c=100、L=1：B=655、D=455、T=145——漏首次向下取整会错得 144）。**无连锁不执行此判断**；连锁长度只影响闪光摇草概率，不影响环几何。
- **无有效草丛**：四格全无效 →（`showmessage` 为真时）"The grassy patch remained quiet..." → **取消连锁**。
- **表现**：按稀有度播对应摇动动画（普通/剧烈/闪光动画 ID 取自配置，默认 1/5/6——WP15 引用，素材存在性未证）→ 写入摇动草列表（连锁数据中）→ 等待 0.5 秒。

## 7. WP37-E：雷达候选、闪光与连锁延续

### 7.1 候选选择（`005_Item_PokeRadar.rb:123–156, 161–208`）

- **非连锁开始使用（连锁数 =0）**：雷达专属遭遇查询（`pbPokeRadarGetEncounter`，审计名）——**只有剧烈/闪光草（稀有度 >0）才查雷达专属表**：当前地图+遭遇版本的 `:PokeRadar` 表存在且**通过步概率门**（以 0..99 均匀整数小于该表步概率判定）→ 按权重随机一条、等级在范围内随机；**未命中步概率门、表不存在或表为空 → 回退普通表**：普通遭遇选择（`choose_wild_pokemon`，审计名；WP36 引用：重抽次数 = 稀有度+1——普通草 1 次、剧烈 2 次、闪光 3 次，多次取最大值偏向稀有项）。**雷达专属选择与普通重抽不是同一算法，不混用**。**空候选边界（R04 修订）**：回退的普通表为空/缺失时返回空候选，**随后读取其物种/等级处失败**——不虚构回退结果。
- **连锁中的遭遇（连锁数 >0，在摇动草上）**：先取该格稀有度 → **继续判定**：连锁继续分按独立数学定义（R13 修订：设环号 r∈{0,1,2,3}、链长 L、上次捕获标记 k∈{0,1}）：**继续分 K = 58 + 10×r + ⌊min(L, 40)/4⌋ + 10×k**（链长修正项为整除下取整）——**闪光草（稀有度=2）必定继续**；否则以 0..99 均匀整数小于 K 判定（K 可超 100——按实际比较规则，超界即恒真）。继续：遭遇=连锁数据的物种/等级、强制单打。
- **延续失败的有限改选（R04/R05 修订）**：判定失败 → 进入至多 100 次普通表重抽循环，**两道门分开**：**循环提前停止门只看物种**——某次重抽（或初始候选本身）物种与连锁不同即停（初始候选已经异种时 0 次重抽）；**同物种不同等级不停止循环**、继续消耗剩余次数。**循环结束后的最终判等门看物种与等级同时相等**——最终候选与连锁物种等级全同 → **无法断链、继续连锁（强制单打）**；不同 → **断链（取消连锁数据）**。**空候选边界（R04）**：普通表为空/缺失时重抽返回空候选，**随后读取其物种/等级处失败**——**不会到达最终判等、强制单打或取消分支**（真实 100 次耗尽与空候选异常分开；零链取候选的回退消费同样在该读取处失败——§7.1 同步）。**不能把"尝试改选"写成"必定改成不同物种"**。

### 7.2 闪光三件事（`005_Item_PokeRadar.rb:84–90, 210–221`）

1. **草丛成为闪光**：摇草时按 §6.2 概率把该格稀有度标为 2（显示闪光摇动动画）。

3. **连锁继续**：稀有度=2 的摇动草使继续判定**必定通过**（§7.1）——三者分别负责显示、个体属性与连锁走向，不互相推出。

### 7.3 战后更新（`005_Item_PokeRadar.rb:223–237`）

- **战斗结束钩子（on_wild_battle_end）**：连锁数据存在且结果为**击败（1）或捕获（4）** → 连锁数据更新：物种/等级 = 本次战后通知的物种/等级（参数来源见§5.1，可能与实际参战等级不同）、**连锁数 +1**、最长连锁统计取大、**上次捕获标记按"本次结果是否为捕获"置真或置假**；随后**静默重摇草丛**（不显示"remained quiet"消息——但若重摇无有效草丛仍取消连锁，§6.2）。

- **持久（全局元数据，随存档保存，WP09 引用）**：`roamPokemon`（含持续个体对象）、`roamPokemonCaught`、`roamPosition`、`roamedAlready`、`roamEncounter`（虽为"本次待用"但字段在全局元数据上——**战斗中即清空，保存只能存到其当前值**）、`pokeradarBattery`。**普通当前版本载入与版本迁移分开（R09 修订）**：标记格式转换属于 **v20 版本门的迁移**（仅对更旧保存版本执行；普通当前版本载入**不执行**该转换）——转换逐项处理：空项跳过、旧整数标记的个体转换格式、已是新格式的跳过；**漫游数组中的终结占位（非个体）在被读取标记处失败**——有界人工迁移反例（版本 19 存档、此前容器均满足前置，漫游项依次为空/旧标记个体/终结占位）：前两项可跳过/转换，到占位时报错，**不能声称全部漫游标记更新成功或已写回**（不是实际旧存档运行结果；不承诺异常事务回滚；WP10 迁移合同不重开）。
- **不持久（临时对象）**：`poke_radar_data`（连锁全部内容）、`roamer_index_for_encounter`、`force_single_battle`。**保存并不天然保存全部连锁**——连锁在保存/载入后不存在；**不把内存字段变化写成已经落盘**（没有运行存档恢复，只写静态可证的持久边界）。
- **demo 可达性保留**：漫游开关事件、雷达获取事件、调试工具的实际地图接点与调用链归 U01/WP77；没有脚本调用者不等于功能不存在（§3.2 的重置入口同此）。

### 8.4 调试路径（单列，非用户流程）

- **调试漫游画面**（`002_Debug_MenuCommands.rb:494–498`＋`003_Debug_MenuExtraCode.rb:379–548`；R08 修订：按输入列门、写入和不写入）：
  - **状态显示**：逐条目（ROAMING/CAUGHT/DEFEATED/NOT ROAMING）。
  - **逐条 USE**：**选中条目行即响应（不要求条目已启用，R08 修订）**——状态循环首分支恰好处理关闭的开关：**开关编号 >0 且开关关闭 → 打开该开关（未漫游 → 漫游）**；其后依次为：漫游 → 已击败（终结、原因非捕获）→ 已捕获（原因捕获）→ **仅当开关编号 >0 时**回未漫游（开关置 OFF、清条目与原因）；**开关 ≤0 的条目停在已捕获、再次 USE 无该末分支**。**USE 不写 `roamedAlready`**。

  - **CTRL+ACTION**：**同受 ACTION 外层门（条目启用且未终结）——被该门挡住时不切位置（R08 修订）**；通过时**只把位置在当前图与 nil 间切换**——**不清 `roamedAlready`**。
  - **USE 与 CTRL+ACTION 的关闭开关对照（R08 修订）**：选默认 KYOGRE（开关 54 关闭、其它调试容器合法）——按 **USE**：开关 54 被打开（条目转为漫游）、`roamedAlready` 不变；按 **CTRL+ACTION**：被外层门挡住、不切位置。
  - **全体命令**（"[All roam to new locations]"、"[Clear all current roamer locations]"）：**仅在条目列表非空的执行分支**分别全体推进/全部位置清 nil，并清 `roamedAlready`；空列表只蜂鸣。

## 10. 边界、失败与未知

- **空路线/缺当前位置**：路线图键集为空 → 单条推进直接返回；当前图不在键中（邻接表 nil）→ 不推进；无邻接候选时不写位置（§4.1）。
- **无可遇见条目**：开关全关/全终结/位置全不匹配/方式全不允许 → 候选空、保留普通遭遇（§4.2）。
- **换图早退的充分条件（R11 修订）**：换图时**仅当 §4.1 的完整充分早退条件全部成立**（信息表可载＋旧地图 ID 为正＋旧条目存在＋旧原始名存在＋旧原始名＝当前解析名）才不推进且不清 `roamedAlready`；**任一前置缺失或两侧名字不等 → 全体推进并清该标记**——"同名不同 ID"只在上述充分条件意义上不推进，不是无条件承诺（含旧 ID 0／缺信息分支）。可遇见判定另有"同名同区域"通道（§4.2）。
- **首次即终结后**：被击败未捕获的条目在当前基线**没有正常复活路径**（重置入口只覆盖已捕获条目且无正常调用者，§3.2）。
- **改选两道门与空候选（R04/R05）**：循环提前停只看物种（同种异级不停）、最终判等看物种与等级全同（§7.1）；**空候选在读取处失败**（不到达最终判等/继续/取消分支）；雷达专属表步概率门未命中/无表 → 普通表回退（回退亦受空候选边界）。
- **战后重摇无有效草丛**：静默取消连锁（§7.3）；**上车成功立即取消**（已骑车重复上车早退，§8.1）。
- **覆盖竞争**：`on_calling_wild_battle` 已被处理时漫游不再覆盖（§5.1）；异常未到清理点时 `roamEncounter`/暂态下标的残留按字段生命周期处理（§8.3，不虚构清理保证）。
- **未证的异常清理**：战斗中异常中断（脚本错误）时暂态字段与强制单打标记的清理未逐项验证；demo 可达性具名保留（U01/WP77）。
