## 1. 目的与范围

定义一次已经走到计算阶段的招式怎样从当前战斗输入得到类型相性、是否命中、是否会心、计算伤害和计划扣除量。用户可见结果包括无效、未命中、会心、相性提示、替身受伤、留存 1 HP 与实际 HP 变化；消息的完整演出合同仍归 WP67-A。

自身范围：**A** 当前输入／本次类型与类别；**B** 基础相性与核心直接包含的修正；**C** 普通命中数值及调用层短路；**D** 会心门；**E** 普通伤害核心、内建修正与舍入；**F** 计算结果到吸收／计划损失／HP 提交的边界，已读特殊分支及测试向量。

不提取所有招式或特性／持有物家族，不定义 AI 预测，也不把普通公式套给所有伤害。WP46 负责特殊伤害、多击、反伤／吸取完整族，WP47-A 负责类型／类别／调用等招式变更完整族，WP48／50 负责完整数值处理器，WP49 负责阶段触发，WP42 负责完整回合末／终局。它们的进入点和复核条件见 §11；本核心直接写出的规则在本稿列明，不以这些前向包代替。

## 2. 概念、输入与输出（WP43-A）

| 输入 | 读取语义 | 输出／限制 |
| --- | --- | --- |
| 等级、攻防数值 | 当前场上战斗副本；可因变身／刷新而不同于持久个体 | 不重新按 IV／EV／Nature 计算，引用 WP19；此计算不写回持久攻防 |
| 物理／特殊类别 | 默认按招式类别数据；旧配置按本次有效类型所属类别，类型缺省按物理 | 变化类由招式的变化分类判断；部分招式覆盖类别选择 |
| 当前防御／特防 | 奇妙空间生效时交换读取这两个原数值 | 不交换防御／特防的阶级标签；持续来源归 WP45 |
| 类型 | 当前类型去重，燃尽移除火；羽栖移除飞行，若因此全空则临时补一般；请求完整类型时再加入不重复的额外类型 | 不把个体的前两类型视为战斗硬上限；类型移除／添加生命周期归 WP47-A／WP44 |
| 招式 | 原始类型、类别、威力、命中、附加概率、标志；实际效果可提供本次替代值 | 显示属性不保证就是本次计算值；未知效果与合法零威力不合并为同一情况 |
| 状态／阶级／环境 | 用户、目标、两侧、全场和位置的当前有效输入；能力／道具是否生效由其查询决定 | 此处“无修正”的测试前提必须明确，未知处理器不当作乘数 1 |
| 随机 | 各自具名有限整数抽取：命中 0..99、会心 0..分母−1、伤害波动 0..15 | 不承诺所有随机入口统一或可回放；不在自检运行抽样 |

奇妙空间下的读取值须与调试输入和当前菜单显示分开。非变身在场成员的原防御/原特防为 100/200、空间期限正时，战斗读取及初次菜单分别是防御 200、特防 100。只把防御菜单项输入 300：当前菜单防御显示 300，战斗防御仍 200、特防变 300；关闭该子菜单再进入才显示防御 200/特防 300。独立的特防项输入 400 对照：当前菜单特防显示 400，战斗防御 400、特防 100，重新进入显示 400/100。无空间时同名输入与读取一致。向量止于该子菜单，不执行重置、不推进回合、不经过战斗调试总退出的刷新；完整调试工作流仍归开发工具规格。

主要输出分开保存：本次类型相性；资格未受影响／保护／反射等标志；本击未命中及原因；会心标志；**计算伤害**、**计划 HP 损失（含替身）**、跨击累计损失；实际 HP／替身耐久变化。计算阶段可能消费已存储的命中强化标记、触发道具处理器等，不能统称只读查询。PP 是否扣除由 WP40 决定；正常后段未命中／无目标不自动退 PP。

## 3. 本次类型与相性（WP43-A/B）

### 3.1 本次攻击类型

基础为招式数据类型，允许招式特例与使用者有效特性修改。随后若电类型存在，全场等离子浴把一般改为电；使用者输电状态再把当前类型改为电；这两步都会清除先前“特性改类型的威力强化”标记。无类型保留为无类型；它没有 STAB，基础相性返回中性。挣扎和混乱自伤是具名无类型分支，不能用一般类型免疫代替。

### 3.2 基础合成与异常数据

每一个**防守类型**的数据给出受哪些攻击类型克制、抗性或免疫：分别贡献 2、1/2、0，未列出的贡献 1。当前实现检查冲突数据时优先克制，再抗性，再免疫；不自行以免疫优先修复非法重叠数据。普通多类型相性是每个当前有效防守类型贡献的乘积；空类型集合为中性。数据基础定义与个体类型来源不同，WP19 不定义本战斗乘积。

当前 `PBS/types.txt` 为 18 个常规类型加 QMARKS 伪类型，QMARKS 未列克制／抗性／免疫，因而在此表为中性；Shadow 分支是可选类型／领域输入，不能由当前基础类型文件缺项推导整个项目不存在暗影支持。类型未知时沿数据解析失败处理，不能当作中性。

### 3.3 核心内建相性修正

| 条件 | 作用层与结果 |
| --- | --- |
| 某单类型原本免疫，目标有效标靶 | 该类型贡献改为 1，其他类型继续参与 |
| 胆量或目标被识破，防守类型为幽灵且原本免疫 | 该幽灵贡献改为 1 |
| 奇迹之眼且防守类型为恶、原本免疫 | 该恶贡献改为 1 |
| 目标有效天气为强风，飞行类型原本被克制 | 只把飞行的克制贡献改为 1；不消除其他类型弱点 |
| 目标已接地，飞行防守类型对地面 | 飞行贡献改为 1；其余类型继续合成 |
| **地面攻击、目标当前含飞行且有效黑色铁球** | 整体提前返回中性 1，**不再合成其他类型**；区别于普通接地修正 |
| 非 Shadow 分支，目标沥青射击且攻击为火 | 合成结果再乘 2；原本为 0 仍为 0 |
| 攻击类型为 Shadow | 暗影目标 1/2，非暗影目标 2；不走普通防守类型与沥青射击合成 |

相性 0 的正常伤害招式在首发成功检查被判无效，不进入普通伤害公式；不能用公式最终最小值 1 反向推导“免疫也受 1 点”。特性免疫比类型免疫更早，地面浮空、恶系对恶作剧之心、粉末与替身等另有资格门，主时序引用 WP40 §5.3。变化招式不会普遍因类型相性 0 失败，具体效果另有查询。

已读例外：冷冻干燥对水的单类型贡献直接为 2；飞身重压对每个防守类型另乘飞行基础相性；击落／千箭齐发族对地面→飞行可直接给中性并允许击中飞空目标；天空摔族对飞行整体返回无效。这里只定义这些计算替代点；其整招动作、命中与状态生命周期交 WP46／47-A。

## 4. 命中合同（WP43-C）

### 4.1 命中之前与调用层短路

资格拒绝、保护、特性／类型免疫在命中随机之前分别处理。每击成功检查中：蓄力回合可提前通过；锁定对应目标可提前通过；招式自己的每击覆盖（如毒系剧毒）可提前通过。之后检查半无敌／天空摔投目标；无防守、未来攻击标记或帮助类允许越过相应半无敌阻挡，但**这一步本身不等于通用命中计算返回真**。半无敌仍阻挡时，`skipAccuracyCheck` 不能在后面补救；未被阻挡时，该标志真才跳过普通命中。

普通与挣扎的标志、特殊非挣扎及普通起始多回合续招的区别继承 WP40 §5.2／§5.4，不再统一叫“特殊使用必中”。没有独立的命中计算调用，就不会消费普通命中阶段的强化标记或抽取该随机值。

### 4.2 普通命中数值

前提：未在上述层返回，且使用普通命中家族。

- 目标意念移物计数正值→通过；踩踏变小标志且世代≥6→通过；本次基础命中值为 0→通过。它们早于普通修正收集。
- 修正收集先用用户特性、用户盟友特性、目标特性（受模式破坏者阻断），再用户／目标道具；随后重力使命中倍率乘 5/3，已存储的命中树果强化使其乘 1.2 并清该标记；识破／奇迹之眼只把**正**闪避阶级归零。若修正后基础命中变为 0，直接通过，但已进入收集的标记消费仍发生。
- 命中阶级和闪避阶级各自夹到 −6..+6；它们的百分基值分别独立计算。定义
  \(a(s)=1+s/3\)（s≥0），\(a(s)=3/(3-s)\)（s<0）。
  命中百分数＝对 \(100a(s_a)\) 乘命中修正后四舍五入；闪避百分数同理，再至少取 1。
- 对通常的整数基础命中 q，阈值为“q 倍命中百分数除以闪避百分数”的**整数商**；不是先相减阶级，也不先把两倍率合并后只舍入一次。抽取 r∈{0,…,99}，仅 r<阈值命中。阈值不钳为 100；≥100 的普通路径保证成功。
- 亲密效果开、内部战斗、目标玩家拥有、亲密档 5 且目标非 Mega 时，命中门改为 r<阈值−10。处于原阈值内但不在新阈值内者另标“亲密回避”；其它落空仍是普通落空。提前返回的必中路径不再应用此减 10。

四舍五入在本稿正值向量中指最近整数、恰半向上。参考使用浮点计算；独立有理数向量验证所列数学值，不承诺任意扩展处理器的浮点边界完全等价。

### 4.3 命中特例与已发现上游简写冲突

雷电／暴风读取**目标**有效天气：晴／大日照基础命中 50，雨／大雨为 0，其余回到数据；暴风雪在目标有效冰雹天气为 0。实用伞可能使该目标看到无晴雨，不能直接读全场存储天气替代。普通一击必杀分支用基础命中加双方等级差作百分阈值，另有目标等级更高／结实的失败前门；冰系一击必杀分支对非冰使用者的专用阈值减 10；目标资格必须带入口条件：原定义拒绝冰目标；默认条款模块加载后且无后续覆盖时，OHKO 条款假不再仅因冰类型拒绝，仍查等级／结实，条款真拒绝。资格通过不保证命中或击倒；AI 的独立冰目标拒绝和估计不是实际战斗入口。这些路径不走普通阶级／命中修正，完整伤害家族归 WP46。

**新证据交界 N01（2026-09-27首审 CONFIRMED；上游实际修订及传播已于2026-09-27有限复审CLOSED）**：WP40旧§5.3曾将无防守概括为一方持有即命中；本轮按独立确认更正该简写。本快照每击调用层只据无防守放开半无敌；真正把普通基础命中设为 0 的目标方处理器受模式破坏者门控制。反例：用户模式破坏者生效且无无防守，目标有效无防守，普通非特殊调用 q=70，双方阶级 0、无其它修正且未命中锁定等提前门；目标处理器被跳过，r=70 应未命中（r=69 命中）。本稿原反例和分层规则已获支持；本轮定点更正WP40该句及邻接未来攻击／帮助的同层职责，旧报告留史，不重开旧12项。源与影响：成功检查 :542–576、计算 :126–154、特性 :1111–1115／1149–1153；影响普通命中与特殊家族，不否定已关闭的 WP40-R03。WP48 完整家族提取时再次核对；本批边界材料保留这一已确认反例，实际上游修订与直接传播已于2026-09-27有限复审CLOSED。

## 5. 会心门（WP43-D）

1. 目标侧幸运咒语有效时直接否。否则收集会心等级：用户特性→目标特性（模式破坏者可阻断）→用户道具→目标道具；处理器给出负值会阻止后续处理并最终禁止会心。
2. 未禁止时，招式强制会心／禁止会心覆盖；再检查大于 50 的强制标记、用户磨砺，均可直接会心。否则高会心标志＋1，加聚气等级；暗影超频且**招式原始类型**为 Shadow 时再＋1。
3. 当前新机制分母表按等级 0/1/2/≥3 为 **24/8/2/1**；旧机制 0/1/2/3/≥4 为 **16/8/4/3/2**。超过表尾夹到最后一档，不外推负等级。分母 1 直接成功，不抽取；否则整数抽取为 0 才通常会心。
4. 开亲密效果、内部战斗、用户玩家拥有且亲密档 5，并且**目标不是 Mega**时，抽取 1 也成功并写亲密会心标志。这里检查的是目标 Mega 状态，与命中亲密分支的目标条件及其它亲密效果不能混推。

会心每击单独计算，正常每击重置后重写。新机制伤害倍率为 1.5，旧机制 2；使用的是新会心开关，不直接用世代名称替代。会心不保证穿过资格／类型免疫，也不能绕过幸运咒语或更早的禁止处理器。

## 6. 普通伤害核心（WP43-E）

### 6.1 数值与阶级

默认物理读取用户攻击及攻击阶级／目标防御及防御阶级；特殊读取特攻／特防对应项。定义战斗主能力阶级倍率 \(g(s)=1+s/2\)（s≥0）、\(g(s)=2/(2-s)\)（s<0），合法阶级 −6..+6。先乘阶级并向下取整；会心忽略攻击端的负阶级与防御端的正阶级，但保留有利的攻击正阶级／防御负阶级。

目标纯朴有效且未被模式破坏者忽略时，攻击阶级不应用；用户纯朴有效时，防御阶级不应用。它们只在相应侧替代阶级计算，不统一清双方阶级记录。特殊选值已读：扑击用用户防御和防御阶级作为攻击输入，后续仍接攻击修正；欺诈读目标的相应攻击输入；精神冲击族读目标防御而非特防；无视防御／特防／闪避阶级族把相应阶级输入归零。怪异空间仍作用于原数值读取。

部分招式选择物理／特殊类别或在计算前夺取阶级；本稿登记该输入替代面，完整效果归 WP44／WP47-A。只有实际被选择的输入参与本次公式，不能为了测试方便始终使用物种原始能力。

### 6.2 舍入阶段与边界

变化招不做此计算；普通路径确认画皮／结冻头吸收后只把计算伤害记为 1 并返回，不再抽会心／伤害波动。其真实损失见 §7。

对其余普通伤害，以 L 为当前等级、P 为本次威力、A/D 为上节得到的攻击／防御整数，分别收集威力、攻击、防御、最终伤害四个倍率。把 P、A、D 各自乘对应倍率后**各四舍五入一次，至少为 1**。随后：

- 等级系数是 2L/5 加 2 后的整数下界。
- 等级系数×修正威力×修正攻击除以修正防御，取整数下界；再除以 50 取整数商，再加 2，得到基础伤害 B。
- B 乘收集后的最终倍率，只在末尾四舍五入，至少为 1，得到计算伤害 C。

不在每个最终倍率之后逐次取整；没有按目标 HP 截断 C，也没有在普通核心另设伤害硬上限。HP 截断、留 1、替身由下一阶段负责。直接调用核心且相性输入为 0 时最小值仍会为 1，但正常调用已在资格层拒绝，二者不混写为对局结果。越界或非数值的外部直接写入不在合法输入合同内，不能声称核心自动校验所有值。

### 6.3 修正进入点与核心内建项

处理器可能乘、覆盖倍率或写标记，因此下列阶段顺序有意义；完整处理器内容待 WP48／50，不把未知项预设为中性。

## 7. 伤害状态、实际损失与特殊路径（WP43-F）

每次招式重置跨击累计与首发标志；每击只重置本击伤害／会心／吸收／留存等，不重新清除已确定的相性和全部首发状态。先对各有效目标判断吸收，算 C，再确定计划损失，之后统一调用 HP 提交；动画与伤害提示不是判定已经写回的唯一证据。

| 分支 | 计划损失／提交 |
| --- | --- |
| 他人招式且替身存在、不忽略替身 | 优先吸收：损失至多替身剩余耐久；累计损失可包含替身损失；只减替身，不减个体 HP |
| 无替身吸收，普通路径画皮／结冻头条件成立 | 本击 C=1，而计划直接 HP 损失为0；画皮后续换形，世代≥8另扣总HP的1/8整数商；结冻头换形，不把这个后续效果算成普通公式直接伤害 |
| 普通受击 | 先将损失至多截为当前HP；会致命时按非致死招→挺住→其余留存条件处理，最终损失至少0 |
| 非致死或挺住 | 致命时减去原计划中的1点，留下1HP；不要求满HP |
| 其余留存分支 | 参考先要求截断后损失等于总HP（正常即满HP）：依次结实（可被模式破坏）、气势披带、气势头带10%、亲密留存。**本快照头带／亲密留存也位于这个满HP分支内**，不得套百科改成任意HP |
| 亲密留存 | 开关开、内部战斗、玩家拥有、目标非Mega；亲密档0..5的概率0/0/0/10/15/25%，实际抽取命中才留1 |
| 真正 HP 提交 | 计划损失>0且非替身才走HP减少与WP20／WP39写回；计算伤害不直接等于实际损失。气势披带的道具消耗在后续提示处理，不能因“先算完”推导道具未消耗 |

固定伤害家族直接给本击数值、至少1并强制非会心，不走普通威力／攻防／STAB／波动公式，但仍经过正常资格、吸收与HP限制相关调用。混乱自伤采用无类型物理威力40、禁止会心、无普通随机波动，使用者与目标同为自己；直接提交HP损失并进行相关濒死／道具检查。不能把它说成“只按裸攻防、所有其它核心修正无效”。挣扎为无类型物理威力50、基础命中0，状态／服从入口仍按WP40，不等于跳过一切检查；反伤完整族交 WP46。

附加效果概率交界：鳞粉可先归零；外部正概率参数优先，否则数据概率；大于100者直接保留；符合世代／环境例外门时天恩或己方彩虹使概率×2（两者同时存在也只一次）；DEBUG Ctrl可改100。实际调用先受强行排除且要求计算伤害非零，再按0..99抽取。额外畏缩入口对本来就带畏缩的招式返回0，鳞粉可阻断；恶臭／王者之证／锐利之牙满足时10%，天恩或彩虹变20%；不对濒死或替身目标执行。具体效果提交归WP44，完整持有物／特性注册族归WP48/50。
