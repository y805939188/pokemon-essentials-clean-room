# 跨功能边界场景

以下 12 个静态期望分别列明起始条件和可观察结果。依赖固定的抽样值或具名数据时保留原输入。均未执行。参见[相关行为](../reference/cross-domain-contracts.md)。

<a id="shadow-content-p"></a>
### 暗影样本的量表与招式顺序（SHADOW-CONTENT-P）

**输入** WP23 附表§3.1、有效样本定位BUTTERFREE。

**期望** 可查量表4000、配置招顺序SHADOWRUSH/SHADOWMIST；这是样本内容证据，不是只存在性。

<a id="shadow-activation-n"></a>
### 只给样本时的启用边界（SHADOW-ACTIVATION-N）

**输入** 同样可查四文本和样本全集，未给默认顶层对应记录或编译产物。

**期望** 不能推断实际载入/启用、编译成功或真实Demo；U06仍未知。此反例只给 Gen5–8 目录身份，不能据此推出具体字段值。后续样本见[旧世代资料](../reference/generation-data-compatibility.md)。

<a id="friend-p"></a>
### 同一周期内两名成员独立抽样（FRIEND-P）

**输入** 普通步前127，两名非蛋/存活成员且友好未满；达到周期，给定逐成员独立抽样0/1。

**期望** 只有第一名消费成长友好规则，第二名不动；循环后计数0。反向独立1/0仅第二名变化。

<a id="friend-n"></a>
### 未到周期和无可用成员（FRIEND-N）

**输入** 步前126；另独立夹具步前127且空/全蛋/全濒死队伍。

**期望** 前者步后127，无抽样、不复位；后者周期消费后计数0，无成员数值变化。不能共用一个概率门。

<a id="friend-shadow-n"></a>
### 暗影阶段阻止友好变化（FRIEND-SHADOW-N）

**输入** 周期达到、有效Shadow阶段≥4成员抽样0，其它前提同友好P。

**期望** 该成员命中仍被Shadow友好门阻止；计数照常归0。抽样命中不等于每个个体都会改变。

<a id="weather-same-p"></a>
### 同天气的显式重建与地图连接（WEATHER-SAME-P）

**输入** 旧图存在、异图、旧Rain/power60/duration7，新图抽样得Rain；显式重建显示且无连接后写。

**期望** 类型同，进入通知不写局部0；duration7保留。对照合法连接边缘同输入：进入通知仍跳过，随后连接调用者独立写20。

<a id="weather-type-p"></a>
### 天气类型变化时的局部写入与连接后写（WEATHER-TYPE-P）

**输入** 旧Rain、异图有效，新类型Storm，其它前提正常。

**期望** 进入通知局部Storm/power9/duration0；无连接后写保持0，合法连接后另为20。正值只选固定渐变，不是20秒。

<a id="weather-gates-n"></a>
### 同图、无旧图与渐变守卫（WEATHER-GATES-N）

**输入** 分别同图刷新、旧地图0/不存在；另合法异图但显示正在渐变，或同类型仅强度变化。

**期望** 前两者不重掷；正在渐变守卫不打断；类型同单强度改不触发该显示刷新。不得把局部写序列推广为任意换图。

<a id="facility-inprogress-p"></a>
### 进行中提交空队伍与取消（FACILITY-INPROGRESS-P）

**输入** 会话进行中，原快照O、玩家P、报名R；直接提交空列表。

**期望** 报名/玩家队伍立即同时为空，整体返回假；原快照O不改。对照nil取消：报名/玩家/原快照均保留，不提交。

<a id="facility-start-p"></a>
### 空报名列表开始时保存原队伍（FACILITY-START-P）

**输入** 开始前玩家P、报名为空列表，合法轮次/名单等前提成功。

**期望** 先按引用将P写原队伍字段，再把玩家替换为空列表；决定0仍请求保存。只有开始写原快照。

<a id="facility-cancel-n"></a>
### 存在与缺少快照时的取消（FACILITY-CANCEL-N）

**输入** 存在原快照O时取消；另取消无快照。

**期望** 前者恢复玩家O、整体重置；后者不恢复玩家；两者均不保存/不刷新地图。

<a id="facility-end-p"></a>
### 设施会话结束时的顺序与保存门（FACILITY-END-P）

**输入** 结束有原快照O：分别进行中决定0/非0；另未开始且字段空。

**期望** 先无条件写玩家为原字段；进行中才重置/刷新，决定0不保存、非0保存；未开始字段空先将玩家置空后返回，不保存。
