# 注册道具、空值和假值

前提为基于 v21.1、标签后 23 个提交的参考快照，登记数据有效、无覆写、每例独立从给定旧值开始。下表是静态推导，尚未执行。

| 写入或查询输入 | 预期及最先可观察的失败 |
| --- | --- |
| 写入已登记的 POTION 身份（文本或符号标识）或当前道具记录 | 正规化为 POTION 身份，读取返回登记记录；普通设施、AI 与招式资格的其余条件保持原义。 |
| 持有有效道具，再写合法格式但未登记的文本或符号身份 | 查询不到登记项；提前结束，不改旧值。 |
| 写入空值 | 保存为空；具体道具为空；不指定身份的持物查询为假。 |
| 写入字面假值 | 保存原始假值；直接读身份为假；不指定身份或查询参数为空时返回真。具体道具查询以及指定任一非空身份的查询在验证保存的假值时抛参数异常，早于比较。 |
| 写入其他不支持的非空真值 | 参数验证抛错；保留旧值。 |
| 持合法道具，查询参数为字面假值 | 成功读出道具记录并比较，结果假；没有前一假持物用例的读取异常。 |

参见[个体状态与跨域兼容边界](../spec/creatures/item-identity-and-related-compatibility.md)。
