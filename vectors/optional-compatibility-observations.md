# 可选兼容对照

在基于 v21.1、标签后 23 个提交的参考快照中，下列案例是静态推导。是否要求目标实现复现这些精度仍属项目选择；表中所有案例均未运行。

| 样例 | 前提与操作 | 预期和失败前缀 |
| --- | --- | --- |
| 技能效果身份 | 合法攻击力 40 的物理招式或攻击力 0 的变化招式。分别令合法效果名在登记环境中无对应绑定、命中可构造的普通效果 None，或命中有值但不可构造的 CRITICAL_HIT_RATIOS。登记的属性、目标与 PP 有效，没有插件覆写。 | 名称缺失时走未实现的回退，变化技用招失败、物理技仍可进入共用伤害；None 走已知普通效果。CRITICAL_HIT_RATIOS 已绑定数组值，两类均在请求构造时发生未定义方法异常，早于本次直接转换的 PP 与伤害提交。外层调用若已扣除 PP、写入使用历史或取用随机数，这些先行变化各按其调用入口保留。不可构造例的有界前提与目标兼容选择仍待验证。 |
| Shadow 经验栏 | 合法的非蛋 Shadow 成员，未满级且无插件覆写，当前经验占本级一半，资源、类型与绘制依赖正常。 | 信息页呈现心量而不写经验文字，但仍请求宽 64 的经验条；满级跳过，进度 0 请求宽 0。同经验的普通成员显示经验文字并按 128 像素满宽比例请求经验条。返回键正常关闭，本次绘制不写经验。此前的动态形态或缓存提交可保留，实际像素与后段失败后的宿主恢复未验证。 |
| 盒子暂持与预览 | 普通整理模式，P=X、Q=Y，两成员可移动且预览不同，从 P 拿起 X；对照只移动游标与成功向 Q 交换。 | 只移动游标或切盒会跳过导航引发的像素化，继续预览 X。成功交换后 P 空、Q=X、暂持 Y，重新开始预览像素化，下一刷新请求 Y。返回键只提示正持有成员，已交换状态保留。实际像素未验。 |
| 设施回放起始地形 | 同版普通对战塔，合法单打、双方队伍、非调试跳战，准备设 Electric 且开场无特性/物品覆写。 | 实时场地 Electric、时限 −1；记录的 18 项属性不含当前/默认地形与地形时限。同版通常回放重新建立 None/0 场地，当前天气与时限可恢复、默认天气和默认地形不恢复。未设置开场地形且天气亦未派生地形时，两侧正常初值为 None/0。显式设置 None 得到的 None/−1 属于另一个输入。当前天气为 Rain/−1 时可恢复该值。准备或记录失败可能没有回放产物，保留已到达的前缀。 |
| 旧设施身份与版本 | 默认模板索引 137 的 FARFETCHD 配 STICK、RELAXED、三 EV 标签及 SLASH/KNOCKOFF/SWORDSDANCE/AGILITY；索引 249 的 CRAWDAUNT 配 PERSIMBERRY、ADAMANT、HP/DEF/SD 与 BUBBLEBEAM/VICEGRIP/KNOCKOFF/PROTECT。 | 现行登记表和先行编译正常，且无外部补充 STICK/VICEGRIP 时，137 的物种、性格和招式保留，持物为空。成功实例化时无持物，成功写回时持物字段为空。249 的 VICEGRIP 消失且不改为 VISEGRIP，余三招按原序紧排，写回第四栏空。LEEK 与 VISEGRIP 为不同标识，处理器提到旧名也不会登记别名。显式换有登记的第五世代资料，137 保 STICK、249 四招均保留。余故障按编译前缀处理。 |
| 默认字体 | 首次读取正文名称前未缓存，系统默认 Power Green。宿主只报告 Power Green 不可用而 Power Green Small 及其他候选可用。 | 默认正文得到空名；不自动跨字号选字体。宿主若报告 Power Green 可用，默认正文选用该名。显式设置按序检查给定名及嵌套的候选序列，取首个可用名，无命中才查询本档默认。真实存在性检查抛错不能按空名成功处理。 |
| 影子尺寸零 | 合法物种无专用影子、ShadowSize 0，仅通用 Shadow/0 可解析。 | 请求数值 0 对应资源，可得位图；该资源缺失则无匹配。尺寸 2 且对应资源有效则请求 2，有专用影子时优先。资源选择不授实际可见像素，编辑取消另行处理。 |
| 满槽经验闪光 | 有经验条，动画已达到目标且当前经验达本级上限，无闪光计时、依赖正常。 | 先写计时、停止先前音效并请求播放对应音效，再向框及未释放的子精灵请求 (64,200,248,192)。未到目标继续填充；未满不请求满槽闪光；已有计时不足 0.2 秒继续等待。未显示经验条的框按原有规则立即结束。局部失败保留前缀，听感与像素未验。 |

动画作者工具一般 N 点逐次以浮点步进，端点可能有位级误差；默认点数的值须按对应动画合同核对。位级复现政策未选，实际像素未验。
