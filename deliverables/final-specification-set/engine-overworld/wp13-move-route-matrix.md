# 移动路线命令矩阵（净化正文；批次 3 附）

分类：Engine/Overworld Integration（移动路线命令兼容）。本附表为《地图事件、NPC 与跟随》的移动路线命令正文，覆盖移动路线的独立分派。**移动路线命令与主事件命令是两套分派**，主事件命令矩阵（同批《解释器命令兼容矩阵》）不代表本表，本表也不代表主事件命令全集。全部内容为静态证据；无运行确认。

## 1. 分派与推进规则

路线来源：事件页的固定路线、设定移动路线命令对角色设置的强制路线、跟随者/系统内部的路线。命令代码为路线列表项的代码，参数随代码不同。

- 每帧（且非跳跃/移动中）处理路线：从当前路线索引开始，最多遍历剩余命令一次。「本帧」表述以获得实际更新/调用机会为前提。
- **0（路线结束）**：路线设为重复 → 索引归 0 继续；否则——若是强制路线 → 恢复被接管前的原路线与索引并清除强制标记；停止计时归零，本帧结束。**强制路线的恢复在此发生**。
- **1–14（移动/跳跃）**：执行一次移动尝试后**本帧结束**。推进规则：可跳过 || 移动中 || 跳跃中 时索引＋1——**按运动/跳跃状态判断，不按坐标是否变化**：
  - 可跳过路线：被阻挡也推进到下一条。
  - 不可跳过路线：**移动/跳跃已进入运动状态（移动中/跳跃中为真）才推进**。注意玩家受阻碰撞会设置移动计时，移动中取决于该计时存在——**不可跳过的玩家路线撞墙且无事件触碰成功时，即使坐标不变也会推进索引**；普通非玩家事件受阻且未进入运动时，索引停留、下帧重试同一命令。
- **15–26（等待/转向）**：执行后索引＋1，**本帧结束**。
- **27 及以上（状态/脚本，45 命中下述三前缀时例外）**：正常执行后索引＋1 且**不结束本帧**（同帧可连续执行多条，直到遇到 0–26 或遍历完）。
- **空路线边界**：仅含终止项的路线列表（size ≤ 1）在分派开头直接返回，**不会执行到代码 0 的恢复分支**——被设为强制路线的空路线不会因此恢复原路线或清除强制标记；无外部状态改变时，解释器的路线等待仍可被其阻塞。
- 15（等待）参数 n 的单位为 **1/20 秒**，按单调时间等待 n/20 秒；0 无额外正时长，但本条仍推进并结束本帧，1＝0.05 秒，20＝1 秒。到时须再获路线更新机会，不等于固定帧数。45（脚本）先求值、成功返回后才检查下述字面前缀，异常时不到索引推进/前缀判定，调用层呈现未运行确认。
- **45 的兼容字面与边界**：某行行首以 `move_random_range`、`move_random_UD`、`move_random_LR` 之一开头，大小写准确且前面无空白/接收者，则正常求值后索引＋1 并结束本帧。检查的是**原串行首前缀**，不是语义等价调用或完整方法名：合法、正常返回的更长后缀也可匹配；同样移动但前加空格、`self.` 或包进其他表达式不匹配时仍同帧继续。不得靠改写字面扩大/缩小兼容域。

## 3. 口径

- 本表按固定源码逐项核对移动路线分派，非 AST 分析；对角固定分解、多格前缘、接近/远离的中心主轴与备用轴见 WP12 §4.3，不附加路径求解保证。
- 「被阻挡时是否推进」只描述路线索引行为；通行判定本身归地形运动规格（引用）。
