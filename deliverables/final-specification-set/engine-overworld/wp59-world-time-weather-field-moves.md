# 世界时间、天气与场地能力（净化正文；批次 3）

分类：Engine/Overworld Integration（时间与天气的宿主集成）＋Pokémon Rules（场地能力的许可与结果）。本文件定义世界层的环境输入与能力改变世界的条件——实时时钟的读取方式与时段/日期/季节判定、世界天气的数据/应用/显示管线与配置输入、场地能力（登记族、入口、徽章/状态/地形资格、确认、效果与返回）以及与其他子系统的调用边界。全部内容为静态证据；**无运行确认**（真实时钟、地图切换、天气演出与场地能力实际会话均未运行验证——见 `../scope-statement.md`）。

## 1. 目的与范围

**目的**：供遭遇、树果与钓鱼、战斗环境映射、跨域进化与事件/调试引用世界层的环境输入与能力规则。

**范围**：① 时间与日历——时钟读取入口与刷新时点、五个时段判定、星期/月/季节、月相/星座、明暗（tone）计算与缓存、消费者目录；② 世界天气——天气数据（9 种＋类别）、地图输入与概率、进入地图时应用、显示管线（渐入/粒子/屏幕色调/风暴闪光）、事件命令入口、消费者与边界；③ 场地能力登记与入口——能力可用条件、12 个已登记族目录、三个 UI 使用入口、直接工具与界面能力流程分层；④ 各族资格/确认/效果/返回——徽章/功能门、队伍招式查找、地形/状态/朝向/换乘限制、转移与状态写入、统计计数、失败与取消语义。

**非目标**：不定义战斗内天气（战斗天气数据、招式/特性召唤与持续回合——完整环境规则归战斗环境规格；本文件只登记「世界天气与战斗天气是两套标识」）；不定义遭遇表选择/权重/修正、漫游/雷达、树果/钓鱼流程、逐步被动效果；不重定义步数、移动、地形标签、载具、转移与事件解释器主规则（引用）；不定义真实 Demo 事件可达性、宿主时钟/媒体表现与调试入口真实会话。

## 2. 概念与术语

- **实时时钟**：当前唯一时间源，直接返回宿主系统时间（每次调用即取）；无独立「游戏内时间」状态、不随存档保存、不随帧推进；是插件可覆写的扩展点。
- **时段（time of day）**：由小时数直接判定的五个谓词（morning/day/afternoon/evening/night）——**非互斥覆盖**：某些小时同时属于多个谓词，且有小时不属于任何细分谓词（§3.2）。
- **世界天气**：地图/事件设定的「意图」（屏幕天气类型/强度/时长）与显示层（天气渐入与粒子）的组合；与战斗天气是**两套独立标识**。
- **场地能力（field ability / hidden move）**：用招式标识区分在世界中使用的能力族；可用资格、可选确认和执行效果分别判定。身份与各阶段结果是合同，不规定注册表、回调表或函数组织。
- **直接工具入口**：供地图事件直接请求的能力入口，自行检查资格、确认、表现并返回结果；与菜单/快捷使用路径并行，检查集合及副作用不一定相同。
- **使用入口**：①暂停菜单→队伍画面（选个体招式→资格→确认→返回地图执行）；②快捷菜单（已登记物品/秘密之力式列表，逐个做静默资格检查）；③地图事件直接调用直接工具。

## 3. 时间与日历（静态核对）

### 3.1 时钟读取

- 实时时钟返回宿主当前时间；调用点包括：明暗色调刷新、地图事件自开关计时、病毒每日计数、换装形态的 3/5 日窗口、虫虫大会 24 小时限制、战斗背景时段、遭遇表时段输入、树果植物。
- 无「上次保存时间」参与常规读取；无游戏内时间流速/暂停概念；时间倒退仅影响本地比较（§7）。

### 3.2 时段判定（小时边界）

| 谓词 | 成立区间（小时） |
| --- | --- |
| morning | 5 ≤ h < 10 |
| day | 5 ≤ h < 20 |
| afternoon | 14 ≤ h < 17 |
| evening | 17 ≤ h < 20 |
| night | 20 ≤ h **或** h < 5 |

- 边界向量（静态）：h＝5 → morning＋day；h＝9 → morning＋day；h＝10/13 → 仅 day（不属 morning/afternoon）；h＝14/16 → afternoon＋day；h＝17/19 → evening＋day；h＝20/23/0/4 → night。**h＝10–13 与各细分谓词不重合**——实现不得把五个谓词当成互补分区。
- 谓词接受可选时间参数（缺省取当前）；供跨包引用（进化、形态、战斗背景、遭遇表）。

### 3.3 星期、月份与季节

- 星期：0=Sunday…6=Saturday；星期/月/季节辅助返回当前值是否属于候选集合（空集合为false）。指定变量号>0时独立写当前本地化名字；地图存在才请求刷新。变量0不写/不为该写入请求刷新；写名字不代表匹配成功。
- 月份：1–12；名称表（全称/缩写）为固定文本。
- 季节：`(month − 1) % 4` → 0＝Spring、1＝Summer、2＝Autumn、3＝Winter；因此 1/5/9 月为春、2/6/10 为夏、3/7/11 为秋、4/8/12 为冬（**按月份号取模，不是自然历**）；「是否为秋」为 Autumn 别名；事件辅助同样可写变量并触发刷新。
- 固定谓词：「是否为春/夏/秋/冬」（写变量＝0，即不写）。

### 3.4 月相与星座（辅助计算；完整规则）

**月相（0–7：新月/娥眉月/上弦/盈凸/满月/亏凸/下弦/残月）**——实现无关的完整算式：

1. 取宿主时间分量（年、月、日、小时、分钟、秒）；**日内项＝（小时×60＋分钟×60＋秒）÷ 86400**——注意**小时与分钟都乘 60**（不是把小时折算成秒）；因此**同日 01:00 与 00:01 给出相同的日内项**（固定快照特征）。
2. **整数日（完整数学定义，可独立计算）**：设 y、m、d 为年/月/日；先作**年调整** `y′＝y − ⌊(12 − m) ÷ 10⌋`（1–2 月**按上一年**计，其余月份不变；例：2026 年 1／2 月的调整年为 2025）。整数日 `J₀＝⌊365.25 × (4712＋y′)⌋＋⌊((m＋9) mod 12) × 30.6＋0.5⌋＋d＋59`（两个 ⌊·⌋ 分别向下取整；`＋0.5` 在第二项的取整括号内）。**世纪修正（精确门）**：仅当 `J₀ > 2,299,160` 时，`J₀ ← J₀ − (⌊(⌊y′ ÷ 100⌋＋49) × 0.75⌋ − 38)`；**修正先于日内项加入**（门值与被减式均按上式）。随后 `J＝J₀＋日内项`。
3. 相位分数 `v＝(J − 2451550.1) ÷ 29.530588853`；**负值回绕作用于相位分数小数化之后**：`v ← (v − ⌊v⌋)＋(v < 0 ? 1 : 0)`——先取小数部分（得 [0,1)），再仅当**原 v 为负**时加 1；此时结果落在 [1,2)，`ag＝v × 29.53 ≥ 29.53` 必然超过全部 8 个阈值 → 返回 0（新月）；正常现代日期 v 为正，回绕项不生效。
4. `ag＝v × 29.53`；对**固定 8 个阈值**（1.8456618033125、5.5369854099375、9.2283090165625、12.9196326231875、16.6109562298125、20.3022798364375、23.9936034430625、27.6849270496875）**从前往后逐项比较，`ag ≤ 阈值`（含等号）时返回该项索引（0–7）**；全部超过 → 返回 0（回绕到新月）。
- **注释中的「UTC」是注释语义**：不代表代码执行了时区归一（按宿主原始时间分量计算）。

**星座（0–11：白羊→双鱼）**——按「月＋日」匹配**固定 12 行区间表（全表）**：0 白羊 3/21–4/19；1 金牛 4/20–5/20；2 双子 5/21–6/20；3 巨蟹 6/21–7/20；4 狮子 7/23–8/22；5 处女 8/23–9/22；6 天秤 9/23–10/22；7 天蝎 10/23–11/21；8 射手 11/22–12/21；9 摩羯 12/22–1/19；10 水瓶 1/20–2/18；11 双鱼 2/19–3/20。**匹配规则**：按表序逐行检查两条件——`(月＝起始月 且 日 ≥ 起始日)` 或 `(月＝结束月 且 日 ≤ 结束日)`，**首先命中的行返回其索引**；全部不命中 → 返回默认 0（白羊）。**固定快照的日期空档**：**狮子座区间 7/23–8/22 生效，而 7/21 与 7/22 不命中任何区间** → 返回默认 0（白羊）；7/20 命中巨蟹（索引 3）、7/23 命中狮子（索引 4）。
- **派生**：opposite＝（sign＋6）mod 12；partners＝（sign＋4，sign＋8）mod 12；complements＝（sign±1）mod 12。
- 不按通用天文/占星常识修正上述快照行为。

### 3.5 明暗（tone）与缓存（层级精确）

- **明暗度**：0=全夜、255=全日；当日分钟数超过720则镜像，取255×t/720整数商，06:30=138、12:00=255。
- **色调**：四通道（红、绿、蓝、灰）按本小时与下一小时独立插值，下一小时mod24、分钟比例m/60。缓存使用单调时间≥30秒刷新门，重算取宿主日历时间；默认数据如下。
- **关闭开关时的行为**：配置 `TIME_SHADING` 关闭时，取色调接口**返回既有缓存**——**只有冷缓存（尚未初始化）才建立零色调**；若此前开启时已算出**非零缓存**，关闭后**仍返回该非零缓存**（不是「关闭即零」）。冷缓存与非零缓存分别登记。
- **应用的层级**：日夜色调应用接口在「场景不是地图」时**直接返回、不写对象色调**（不会清零）；仅在「场景＝地图 且 配置开启 且 地图元数据 outdoor」时套用缓存的色调，否则**显式置零**——「**室外地图才随时间偏色**」仅在地图场景内成立；该判定同时被战斗背景的时段选择引用（§3.6）。

Rain/Storm 强度 60 的普通雨滴分别为 (−600,2400)/(−3600,3600)，基础色调分别为 (−30,−30,−30,10)/(−45,−45,−45,10)。资源标识不同不证明未读位图的像素必不同。雨类从 0 起奇数索引使用最后一张水花资源，偶数索引使用其余三张循环；水花不套普通雨滴速度。

水花重置时寿命从 0.30 至 0.49 秒（步长 0.01）抽取，位置重新选取、透明度设 255。随后普通更新在剩余寿命 <0.2 秒时透明度 255，否则 0；寿命到期的更新先重置并返回，不能把同次重置也当成普通隐藏更新。例：重置寿命 0.40 时可见；下一次剩余 0.30 时隐藏，剩余 0.19 时可见。普通水花不漂移。

Snow 的普通位移之外：横向增量再加基础横向增量×相对屏幕高度比例/3，以及从 {2,1,0,−1} 抽样的系数×基础横向增量/8；纵向增量再加六槽 {2,1,1,0,0,−1}（按粒子从0起的索引 mod 6）系数×基础纵向增量/10。相对高度取粒子位置相对摄像机的屏幕纵坐标除以屏幕高度。

仅稳定 Storm 请求随机白闪：颜色 (255,255,255,230)、持续请求单位从 {40,60,80} 抽取；下次间隔从 0.5 至 6.0 秒（步长 0.5）抽取。渐变中不请求此闪光，HeavyRain 不进入该分支。Sun 的附加强度 u 按每帧 ±s×帧间隔/0.8 推进；旧值超过 s 或低于 0 后翻向（可能越界），附加 (u,u,u/2,0)。0.8 秒是名义半周期参数，不能承诺精确连续周期。上述请求不证明实际媒体播放；既有固定渐变阶段合同保持。

### 4.2 数据输入与约束（三层分开）

- **PBS 文本**：地图元数据字段 `Weather = <天气id>,<概率>`；天气 id 必须存在；概率按「正整数或 0」格式校验——**编译器不设上限**（>100 语义＝恒真）。
- **编辑器**：属性选择器**可**选 :None、也**可**取消——**两者的属性设置都返回 nil**（编辑缓冲值变为 nil、以「-」展示）；概率为 0–100 的数字选择。该 nil 只是**编辑值**：仅当属性列表最终由**外层保存**路径提交时，才用编辑缓冲重建并登记地图元数据；外层不保存（取消属性列表）→ 原记录保留。因此「选 None」并保存后等价于**清除该字段**（无天气），**不是「保留原值」**。
- **运行时判定**：进入地图时以 0–99 抽样 < 概率才采用该天气，否则保持 :None——概率 0 → 不可能；100 → 必中；缺失字段 → :None。

### 4.3 应用管线（进入地图时）

1. 仅在**旧地图存在且与当前不同**（真实转移）时触发；同图刷新不重掷。
2. 默认新天气＝:None；若当前地图元数据有天气且以 0–99 抽样 < 概率 → 取该类型。
3. **与当前世界天气类型相同则跳过**（不产生渐入/重置；同类型仅改强度不会经显示层刷新，见 §4.5）。
4. 否则局部写类型、power9（强度60）、duration0。真实连接边缘跨图在进入通知后另写duration20，显示后读正值并选择既有固定渐变；显式跨图转移重建显示且无这次连接后写时保持0。因此局部0不等于任意换图最终立即。正在渐变时守卫阻止打断，类型相同/旧图0等跳过门保留；20不是20秒。
- 天气意图（类型/强度/时长）只存在于屏幕状态；显示层每帧只在意图**类型** ≠ 显示类型时启动渐入——**意图强度/参数的单独变化不会触发该显示刷新**。
- **无自动过期**：世界天气一旦设定，**没有计时器使其自行结束**；改变只能来自下一次转移（重掷）或事件命令（§4.4）。

### 4.4 事件命令入口

- 解释器命令 236（设定天气效果）：参数＝（类型, power, duration）→ 直接写天气意图；power 0–9 映射意图强度 `(p＋1)×6`（6–60）。**duration 的语义按消费者实际行为登记**：`＝0` 走立即切换；**正数只用于「选择渐入路径」**——正值大小**不参与**渐入计时（渐入按显示层的固定分段时间线推进，§4.5），**名义结束阈值与 duration 数值无关**（None→非 None 对照下名义约 3 秒）。命令可在任意地图使用、不看元数据、不重掷概率（事件责任）。
- 调试菜单可读写战斗天气（战斗环境规格；与本节世界天气不同源）。

### 4.5 显示层（行为摘要，非渲染实现）

- **渐入由类型差异触发**：仅当意图类型 ≠ 显示类型才渐入；同一类型仅改意图强度时该路径不被调用，**显示强度不随之更新**（静态边界；不对 0/9 做算术映射代替消费者效果）。
- **固定分段时间线**：渐入按固定分界常量推进（旧平铺淡出→旧色调段→旧粒子衰减→新粒子/新色调/新平铺的固定先后），**正值 duration 不改变各段长度**；渐入**结束还要求旧粒子全部不可见**（等待旧粒子自然消亡），「名义结束时间」以分段常量与起始天气偏移（0/1/2 段）推算——None→非 None 对照下名义约 3 秒；实际帧边界保留（运行未决）。
- 每帧：粒子系统上限 60；粒子按数据速率移动、出界重置（雨/雪按方向从屏幕右/上重生）；平铺层在旧色调段后换层且随摄像机原点滚动（跨地图连接有偏移）；雨的水花索引特殊。
- 风暴闪光、太阳脉冲、雪摆动和水花按§4.1参数与特殊更新；雾只覆盖平铺层，既有固定渐变阶段保持。
- 世界天气显示随地图摄像机坐标更新偏移；不规定实例数或对象归属。

### 4.6 消费者与交界

- 遭遇率/等级修正与「按天气类别降遭遇」的特性（遭遇规格引用类别）；
- 树果自动浇水（树果规格；`:Rain` 类别）；
- 进化方法按天气类别检查（进化规格）；
- 回复/驱散类场地招式的「天气阻挡」：**甜味（SweetScent）在当前世界天气 ≠ :None 时被拒**（§5.4）——本文件自己的交界；
- 战斗天气映射为独立系统（战斗环境规格）；本文件只固定「世界天气标识与战斗标识不通用」。

### 5.4 返回值、异常与取消（分阶段登记；不给统一全域保证）

**返回值形式（静态分类）**：

1. **显式布尔**：直接工具（砍树/潜水/冲浪/力量/头槌/碎石/瀑布/飞行检查）在资格失败/取消/拒绝路径返回 `false`，正常执行路径返回 `true`。
2. **无值（nil）**：甜味在**世界天气 ≠ :None** 时**无值返回**（阻塞分支没有返回值）；正常无遭遇时以消息结束、亦无显式布尔。
3. **内部末值（非固定布尔）**：**HEADBUTT的界面效果不保证固定布尔返回**，其返回即回调最后表达式的值（随分支可能是消息调用结果或统计数值等）；**SWEETSCENT的界面效果固定返回 `true`**（即使内部被天气阻挡）；**FLY 执行响应在目的地原本存在时忽略内部工具的返回值**（外层仍 `true`）。入口直接传递效果返回结果。
4. **异常**：**HEADBUTT 摇树效果在「执行时再次取面向事件仍为空」时直接访问其坐标——抛异常**，没有安全失败消息；此前统计可能已＋1。
5. **失败前写入**：HEADBUTT 执行响应**先增统计再执行效果**；FLY 的内部工具在无可用个体时**清除目的地并返回 false**（外层已忽略）。

- **确认取消**：按族实际存在确认的形态——**直接工具内的确认**（CUT/DIVE/HEADBUTT/ROCKSMASH/STRENGTH/SURF/WATERFALL 等）取消 → 包装返回 false，已发生的只有提示消息；**分派确认（仅 DIG/TELEPORT）**取消 → 执行效果 不执行；统计（CUT/ROCKSMASH/HEADBUTT 等）只在确认后＋1。
- **部分写入顺序**（不承诺事务）：SURF 先置 `surfing＝true` 再跳步；WATERFALL 先置标志再逐帧推进；DIVE 的转移块内一次写入两个旗标；FLY/TELEPORT/DIG 的写入在淡出块内完成后清逃生点。
- **甜味天气阻挡**：世界天气非 :None → 立即**无值返回**（无红屏、无遭遇），在取遭遇类型之前；**不**把「消息出现/效果调用/实际成功」混成同一结果。

### 5.5 摇树概率（独立算术；数据/私有 ID 输入）

1. `a＝(ev_x＋⌊ev_x/24⌋＋1) × (ev_y＋⌊ev_y/24⌋＋1)`；`a＝(a×2 ÷ 5) % 10`（整数运算）。
2. `b＝玩家公开 ID % 10`。
3. 概率档：`a＝＝b → 8/10`；否则 `a>b 且 |a−b|<5` 或 `a<b 且 |a−b|>5` → `5/10`；其余 → `1/10`。
4. 以 0–9 抽样 < 档位 → 成功：档位＝1 → :HeadbuttLow；否则 :HeadbuttHigh（进入对应遭遇表）。
- 静态向量（(x,y) → a）：(10,10) → 8；(0,0) → 0；**(23,23) → 中间量 24×24＝576 → ×2＝1152 → ÷5＝230 → %10＝0**（最终档输入 a＝0 不变）。a＝8 时：b＝8→档 8；b∈{4,5,6,7}→档 5；其余→档 1。a＝0 时：b＝0→档 8；b∈{6,7,8,9}→档 5；其余→档 1。

### 5.6 共同场地演出与调用者边界

合法个体、图片/叫声资源可读取、正常图形时钟、地图场景且非淡出遮蔽、无中断时：展开 0.25 秒 → 从右滑入中央 0.4 秒（到中央请求叫声）→ 中央停留 0.75 秒 → 向左退场 0.4 秒 → 收拢 0.25 秒；演出期间有图形、输入和地图更新机会，正常完成返回 true。无个体直接调用共同演出立即返回 false。阶段时间均为名义参数，不是实测总耗时；共同演出 false 不承诺全部效果调用者安全回退，有些调用者随后取个体名称，直接工具与 FLY 的空个体处理另列。

表以目标有效、转移正常返回、回调不改变位置/状态为前提；不把四族统一成保留方向或统一朝下。FLY 目的地存在但没有可用个体时，内部工具清目的地并返回 false，既有外层 true 差别保持。

**瀑布实际启动门**：玩家面朝上，且面向地形为瀑布或瀑布顶，才增加上溯统计、置 ascending_waterfall=true、through=true；门不成立不启动。直接工具在徽章/成员/确认通过后仍可返回 true，即使启动门未过；菜单资格只查徽章与面向瀑布，不查朝向，效果亦可 true 但未启动。向右面向瀑布为 true/无启动对照；向上面向瀑布顶时直接确认工具可启动、菜单拒绝、普通交互仅描述。后续逐步推进及状态恢复引用移动规格。

### 5.8 逃脱点生产与洞穴演出

洞穴进入先写逃脱点，再演出；洞穴退出先清逃脱点，再演出。记录为当前图、身后一格、相反方向。图31、玩家(10,8)时：上→(31,10,9,下)，下→(31,10,7,上)，左→(31,11,8,右)，右→(31,9,8,左)。DIG/逃脱绳使用记录方向；身后格有效是前提，生产入口不保证其有效，洞穴包装本身不执行地图转移或证明 Demo 事件可达。

合法屏幕对象与正常场景下，洞穴演出有 15 层矩形：屏幕宽高为 W/H，水平内缩单位 a=(W/2−12)/15，垂直内缩单位 b=(H/2−10)/15；第 k 层（0–14）边界为 (ka,kb,W−2ka,H−2kb)，由外到内覆盖。第一段名义 0.4 秒：进入灰阶从 255 向 0，退出反向；第 k 层从 k×0.4/15 秒才开始自身 0.4 秒颜色推进并夹住端点，所以不保证全部层在第一段末已到终色。

随后请求进入时屏幕 RGB 色调 (−255,−255,−255)、退出时 (255,255,255)，持续参数 0；第二段名义 0.4 秒把黑/白覆盖透明度 0→255。之后请求屏幕色调恢复为 (0,0,0,0)、持续参数 8，再名义等待 0.1 秒；恢复是请求，不保证 0.1 秒内已完成。演出有图形/输入更新机会，没有地图更新承诺；正常结束释放演出资源。颜色/几何/请求是静态合同，实际素材、渲染、宿主时序与 Demo 均未验证。

## 6. 规则与不变量

1. 时间无游戏内状态：每次读取取宿主时间；时段谓词可由调用方传入时间（缺省当前）；五个细分谓词**不构成互补分区**。
2. 季节只由月份 `(m−1) % 4` 推导；不读取日期。
3. 明暗色调缓存 30 秒；**关闭 TIME_SHADING 时色调接口返回既有缓存**（冷缓存才为零；此前已算出的非零缓存关闭后仍非零），明暗度函数仍可用；日夜色调应用接口在非地图场景**直接返回、不清对象色调**，地图色调只应用于室外地图的地图场景（§3.5）。
4. 世界天气意图（类型/强度/**渐入标志**）作为当前世界显示意图保留；显示层**只在类型不同时**渐入（同类型强度变化不触发该刷新）；**无自动过期**；power 语义 0–9 → 意图强度 6–60；**duration 仅分 0/正数两义**（§4.4/§4.5）。
5. 进入地图的天气重掷只在真实转移触发一次：默认 :None、概率判定、相同**类型**跳过；PBS 概率无编译器上限；**编辑器：None/取消→编辑值 nil，外层保存才提交（保存即清字段）**。
6. 能力按招式身份区分；资格判定与执行效果均可用才有可用能力；未支持的WHIRLPOOL等会在入口被筛除，不规定注册表或执行响应结构。
7. 各入口按相同徽章资格规则判定；调试模式与徽章号 < 0 恒真；计数/特定徽章配置切换「计数 vs 特定徽章」语义；DIG/HEADBUTT/SWEETSCENT/TELEPORT 不受徽章门。
8. 界面能力流程的效果层不重复资格检查；直接工具自带检查；两者的世界副作用差异按 §5.3 表登记（CUT/ROCKSMASH 最显著）。
9. 冲浪、潜水、瀑布升降、闪光、治疗点与逃脱点的领域状态/保存归属保持；力量使用与遭遇修正按地图重置并可保存，统计全局累计。这里规定状态生存期，不规定全局对象或地图容器结构。
10. 场地能力对遭遇系统的同步点（SURF 开始/结束重置步计数；HEADBUTT/ROCKSMASH/SWEETSCENT 请求遭遇；遭遇规格引用）。

## 7. 边界与失败

- 时间倒退（宿主时钟回拨）：日期比较「不同日」即可触发每日效果（病毒每日、事件过期判定以时间戳差为准）；本文件不作因果保证，按比较语义登记。
- 时段边界：h＝10–13 无细分谓词命中；h＝20 同时满足 day 的补集与 night（day＝20 起为假、night＝20 起为真）。
- 天气：概率 0 与缺失均得 :None；同图不重掷；转移到「无天气字段」的地图会**清除**原有天气（默认 :None）；事件命令可无视元数据设定任意类型/强度。
- 天气演出期间再改天气：显示层渐入中再次渐入被忽略（进行中的渐入不打断），意图值更替要在其渐入完成后才被采纳（渐入守卫先行返回）。
- 徽章：所需编号超出已定义徽章数时，特定徽章资格按假值处理（缺失视为假值）；计数模式下 badge_count 与具体徽章数量无关（可达 0–8＋）。
- 能力别名缺失：未注册招式在快捷列表**可见位置**被静默筛除（不报错）；调试模式只绕开**被检查函数内**的徽章检查与「缺省个体时查找队伍会招式者」门，**不绕过快捷菜单的收集条件**（逐个体要求「非蛋且掌握对应招式」——即使调试模式，若没有任何非蛋会 FLY 成员，FLY 不会进入候选），也不绕地形/状态/事件名条件（§5.1 第 2 条）。
- DIG/TELEPORT/FLY 成功且正常返回的清点按§5.7顺序；失败/回调改写不补事务保证。有效地图场景/显示、map_changed为真且新图announce_location为真时，地点窗仍按WP16§5.5的前图同名与NO_SIGNPOSTS禁配对规则抑制或请求。FLY目的地尚未清除时延迟守卫优先；曾延迟的窗在清除后重启计时，正常更新的消息或换图处置门保持。
- SURF 基线坐标：`surf_base_coords` 与 `ending_surf` 跨帧存在；仅由步后钩子消费；中断（如转移）时的残留按转移流程重置（地图拓扑引用）。
- 摇树：面向事件在确认与执行之间消失 → **执行路径在再次取事件后为空时直接访问坐标 → 抛异常**（统计可能已＋1，无安全失败消息；§5.4）。
- 返回形式分级：显式布尔／无值／内部末值／异常／失败前写入（§5.4）——不给统一全域保证。
- 同类型强度：稳定天气仅改 power → 意图变化但显示刷新不触发（§4.5）。
- 编辑器：选 None/取消只改编辑值；不保存不提交，保存则字段被清（§4.2）。
- 所有「真实地图/事件可达性」与宿主媒体表现：运行未决（U01）。
