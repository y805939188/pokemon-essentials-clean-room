# 随机地牢（净化正文；批次 3）

分类：Engine/Overworld Integration。本文件描述随机地牢的行为规则——什么输入决定一次生成、布局/房间/通道如何被约束、种子如何被消费、事件与玩家如何被摆放、空间不足或绘制失败时发生什么。全部内容为静态证据；**无运行确认**（未运行地牢生成，未验证实际地图与可达性，U01/U05——见 `../scope-statement.md`）。

## 1. 目的与范围

**目的**：回答「生成的地图必须提供什么行为」，供后续实现构建随机地牢生成，而不追踪任何特定生成器结构。

**范围**：① 生成触发与输入域（触发条件、参数/图块集/种子/屏幕尺寸输入）；② 布局生成规则（节点图样、迷宫连接、房间、通道、连通性检查）；③ 图块化与装饰（墙体推断、错误修复/重绘、装饰、图块选择）；④ 事件与玩家摆放（摆放约束、重试、失败结果）。

**非目标**：不验证真实地图可达性与实际生成结果（U01）；不把「相同 seed 跨实现一致」写成保证（U05）；不提取地图元数据全部字段语义（只登记地牢标记的门控作用）；不提取迷宫/地牢的玩法流程、奖励与 Demo 可达性；不运行生成器或设计未来生成算法架构。

## 2. 概念与术语

- **节点（node）**：地牢网格的逻辑单元；一张地图被划分为 节点列数 × 节点行数 的网格，每个节点占 单元宽 × 单元高 个图块。
- **可访问节点**：被节点图样选中的节点，参与迷宫连接。
- **房间（room）**：节点内一块矩形地面；**通道（corridor）**：连接相邻节点的固定宽度地面带。
- **墙体推断**：按地面 8 邻域位掩码查表得出墙图块类型；无法直接确定的组合进入错误修复。
- **重绘（redraw）**：布局/墙体阶段发现不可接受结果时，放弃本轮并重新生成（不重新播种）。
- **图块集映射（dungeon tileset）**：把布局符号（地面/墙/装饰）映射为实际图块 ID 的数据定义，含大网格对齐、双层墙等选项。
- **地牢参数（dungeon parameters）**：按（区域, 版本）索引的生成参数集。

## 3. 生成触发与输入域

### 3.1 触发条件与时机

- 生成由**地图建立通知**驱动：当地图元数据的地牢标记为真时，在地图建立阶段生成并**就地改写**该图的宽度、高度与图块数据。
- 因此生成发生在地图重建链内（显式传送重建、读档恢复重建、新游戏重建等均经此通知）；边缘切图不重载当前图，不触发重新生成。
- 改写后该图以生成尺寸与内容参与后续加载/显示/通行；元数据其余字段语义归资源规格。

### 3.2 输入域

| 输入 | 来源与回退 | 作用 |
| --- | --- | --- |
| 地牢参数 | 数据类宽容查询：先查「区域_版本」键，未命中回退「区域」键，再未命中**新建默认参数实例**（双键回退，内容身份规格） | 生成参数全集（§3.3） |
| 地牢图块集 | 数据类宽容查询：按整数 ID；**未命中回退首个已注册条目** | 布局符号 → 实际图块映射与绘制选项（§3.4） |
| 区域/版本 | 全局持久值（默认 none／0），由作者脚本写入 | 选择参数集 |
| 种子 | 三级来源，见 §3.5 | 决定本次生成的随机序列 |
| 屏幕尺寸 | 宿主画面宽高 | 决定地图边缘缓冲区（画面半宽/半高格数，向上取整） |
| 地图自身事件 | 待生成图的事件集合（名称中含 ASCII `size(w,h)` 声明的多格事件，数字、逗号和括号内部无空格，大小写不敏感） | 摆放阶段的输入；全角括号不匹配，未匹配时 1×1 |

### 3.5 种子来源与消费点

- **三级来源**：参数集固定种子 → 全局待播种子字段 → 系统新种子，取第一个非空。
- **消费规则**：确定种子后先**无条件清空待播种子字段**，再重播全局随机序列（无论种子来自哪级，对后续所有随机消费者有副作用）。下述空节点/密度失败到达时，该字段已消费；大网格奇数参数的构造失败发生在此之前。
- **消费点**（按生成顺序）：迷宫起点抽取、方向重洗、额外连接抽取、房间抽取、房间尺寸/中心、通道偏移、装饰密度判定与坐标、图块随机选取（含变体）、事件/玩家摆放的房间与坐标抽取、失败重试时的再次抽取。
- **重绘不重新播种**：同一轮生成内，布局/墙体失败后的重绘继续消费当前随机序列（§4.4）。
- **不保证**：相同 seed 在不同实现/版本/参数组合下产生相同地图（U05）；本文件只记录输入来源与消费顺序，不写跨实现一致不变量。

## 4. 布局生成规则

### 4.1 尺寸推导

- 初始缓冲 Bx＝⌈画面宽/64⌉、By＝⌈画面高/64⌉。大网格时**先**把奇数 Bx 加 1，**再**仅当此时 Bx 仍奇数才给 By 加 1。正常整数下第二门不成立，By 原值保留；不是两轴各自调偶。例如 576×448 给初始 (9,7)，实际为 **(10,7)**。
- **大网格奇数参数调整：意图与首次失败分层**：缓冲区之后、地图尺寸换算之前，构造对大网格对齐**意图**写回参数——奇数单元宽 −1、奇数单元高 −1、奇数通道宽度调整（为 1 则＋1 成 2，其余奇数 −1）。但**标准参数对象只声明这三个字段的读取入口，没有任何写入入口**（无插件覆写/扩展的前提；参数类全文与其引入模块均无写回机制）：首个命中的奇数字段在**首次写回即报错**（无对应方法的错误），构造中断——既得不到已调整尺寸，也进入不了生成。失败时点：**待播种子的清空与播种在生成内、地图宽高/图块数据的重写在生成之后的回调中，二者此时尚未发生**。PBS 正整数模式与参数专用校验均不拒绝奇数输入（编译只查重复区域/版本）。参考缺陷保留：不得替标准参数对象补写入入口使它「正常」，也不以「自动调整后正常生成」描述该路径。
- 地图尺寸逐轴分支：输入**≥20 直接作为地图图块尺寸**，不调偶；输入 <20 才换算「节点数×单元尺寸＋2×对应缓冲」，并在大网格且换算结果奇数时＋1。大网格直接输入 21 保持地图 21，但下面的可用尺寸为 20。
- 可用尺寸＝地图尺寸（大网格对齐时奇数则 −1）；可绘制区＝可用尺寸 − 两侧缓冲。
- 可绘制区宽或高为负：**生成直接返回**（布局保持清空状态，全为虚空），后续图块化与摆放仍执行（§4.4/§6 的失败路径）。

### 4.2 迷宫与房间

1. **可绘制区小于一个单元**（宽或高 < 单元尺寸）：整个可绘制区绘为房间地面，结束布局；**不登记房间矩形候选**，初次生成仍无法摆放。
2. **节点网格**：可绘制区按整除划分为 节点列 × 节点行；按节点图样标记可访问节点（未识别图样按 full 处理）。
3. **迷宫连接**：从可访问集合随机取起点，按随机方向序深度优先连接可达部分；不是无条件保证所有图样形成连通树。**可访问集合为空时，空抽样后读取起点坐标即失败**，在房间派生/零房间退化之前，种子已消费而原地图尚未重写。例如 2×2 节点配 `antiring` 无起点。
4. **额外连接**：对尚未连通的有效相邻节点登记 **A→B 与 B→A 两个候选记录**，从记录中不放回抽取（不足请求数则取全部）。抽中二者都打通同一条无向边，第二个不会再增一条边；请求 2 不保证两个不同连接，亦不得先去重改变抽样。2×2 连通生成树若只余一条闭边，其两个方向都抽中时仅增一条不同边。
5. **房间派生**：可房间集合＝可访问节点∩可房间图样。请求数 max(⌊N×概率/100⌋,1)，不放回抽样受 N 上限约束，实际数 min(N,请求数)。例如 N＝25、概率＝70 为 17，N＝1 即使概率大于 100 也仅 1。**实际数 0 才整区绘房间地面**，不登记矩形；不能救前一步的空可访问集合失败。
6. **逐节点绘制**：按连接图样画通道（固定宽度、居中；随机偏移时在约束内随机偏移；大网格对齐调整奇偶）；房间节点画随机尺寸/位置的房间矩形（尺寸在最小/最大域内随机，中心在单元中心 ±2 内随机，整体被夹在缓冲与可用区边界内）。

**九种图样的数值定义**：有效节点坐标 0≤x<Nx、0≤y<Ny；分别用于可访问集合及可房间筛选，同一谓词。表中的 ⌊ ⌋ 是整数下取整，斜线宽度为严格差值 <2。

| 图样 | 保留节点的充要条件 |
| --- | --- |
| full / 未识别 | 全部有效节点 |
| no_corners | 不同时满足 x 在最左/最右且 y 在最上/最下 |
| ring | x 为 0 或 Nx−1，或 y 为 0 或 Ny−1 |
| antiring | 0<x<Nx−1 且 0<y<Ny−1 |
| plus | x＝⌊Nx/2⌋ 或 y＝⌊Ny/2⌋；4 列和 5 列的竖线都在 x＝2 |
| diagonal_up | abs(x+y−Ny+1)<2 |
| diagonal_down | abs(x−y)<2；(1,0) 保留，(2,0) 不保留 |
| cross | 上述两条斜线谓词任一为真 |
| quadrants | 同时排除「左右边缘且 2≤y<Ny−2」及「上下边缘且 2≤x<Nx−2」，其余保留 |

**房间与通道几何**：房间每轴从最小…最大闭区间均匀取整数（最大≤最小时取最小）。大网格下奇数尺寸若不大于半个单元则＋1，否则−1；例如单元 10 中尺寸 5→6、9→8。中心每轴为 ⌊单元尺寸/2⌋ 加 −2…2 的整数，左上位置＝单元原点＋中心−⌊房间尺寸/2⌋；大网格先对奇数位置＋1，再夹入缓冲内界，不在夹取后再次调偶。普通成功绘制的矩形才登记为候选。

通道偏移初值每轴为 ⌊(单元尺寸−通道宽)/2⌋。随机偏移启用时，令 v＝通道宽（大网格先取 ⌊v/2⌋）；仅 v>1 才取整数 r∈[0,v−1]，偏移 r−⌊v/2⌋，大网格再乘 2；然后大网格奇数偏移＋1。开启的北/南通道为宽 c 的竖带，分别从单元顶部到偏移+c、从偏移到单元底；西/东为高 c 的横带，分别从左沿到偏移+c、从偏移到右沿。被关闭的边不绘对应带。

### 4.3 连通性检查

- 布局完成后做泛洪检查：以第一个地面图块为起点泛洪；**没有任何地面 → 重绘**；存在未被泛洪覆盖的地面 → 重绘。即保证（每次通过的布局）地面全连通。

### 4.4 墙体推断、错误修复与重绘

- 对地面 8 邻域中的虚空格按下表判断墙型；下墙 **12 种中已含 4 种内墙**，上层对应。双层墙再以墙为邻接依据推断上层；下层邻接按最上非空布局是否地面判断，上层按第一墙层是否墙判断，不能混用。
- **错误修复**：仅两种邻接组合（掩码 34 与 136，即对角两地面夹一格）进入修复分支——按具体邻接状态改写内墙/外墙/通道；分支均不命中时**置重绘**（布局整轮重来）。
- 映射表无对应项的其他组合：置重绘并抛出「无法解决」错误（静态路径；正常生成中仅 34/136 被标记为错误，该分支为防御性）。
- **重绘循环无次数上限**：布局/墙体阶段可因连通性或墙错误反复重来，直到通过为止（仅受随机序列终将产生可用布局约束；不运行验证其终止性）。

**完整墙邻接合同（256 输入的压缩决策表）**：邻接掩码按 N/NE/E/SE/S/SW/W/NW 分别计 1/2/4/8/16/32/64/128。设 H＝⌊掩码/16⌋、L＝掩码 mod 16。表格给出各 L 集合的结果；同一 H 行的其余 L 全为 0。数字 1/2/3/4/6/7/8/9 为外墙，11/13/17/19 分别为内墙 1/3/7/9；上层换对应上墙名。0 在掩码 0 或上层表示虚空，非零掩码的下层表示通道；−1 进入错误修复。这是兼容输入输出数据，不规定查表实现。

**候选的重绘生命周期**：重绘清布局三层，**不清已登记房间矩形**。因此通过后的候选集合可能含前轮矩形，摆放入口又不复查当前格地形（§6.1）。只能作「给定已存在的旧矩形与当前非地面位置，抽中且尺寸/间距满足仍可接受」的条件向量，不据此编造实际种子或运行中确曾放在墙上。

### 4.5 装饰

- 均以图块集是否登记对应装饰为前提（未登记则跳过该装饰）：
  - 地面斑块：按单元遍历，按概率在随机中心点半径内播种，再做平滑（孤立斑块按平滑率回填通道、密集地面按平滑率成斑）。
  - 1×1 地面装饰：按密度随机散布于地面。
  - 2×2 地面装饰（坑）：按密度选取四格全为房间地面的位置。
  - 1×1 / 2×2 虚空装饰（岩/缝）：按密度散布于虚空。
  - 墙顶：在指定墙型上方的第二层绘制。

四类密度是**整数除法的分母**。设原地图 W/H、可用尺寸 Uw/Uh、可绘制尺寸 Dw/Dh、密度 d>0；尝试次数与抽样域如下，落点检查失败只损耗一次尝试，不补足装饰数量。

| 类别（处理先后） | 尝试数 | 随机坐标与许可 |
| --- | --- | --- |
| 2×2 地面 | ⌊Dw×Dh/d⌋ | x∈[0,Dw−1], y∈[0,Dh−1] 后加缓冲；四格最上非空布局均须恰为房间地面（通道/斑块不替代） |
| 1×1 地面 | ⌊Uw×Uh/d⌋ | x∈[0,Uw−1], y∈[0,Uh−1] **再加缓冲**；底层恰为房间/通道且第一墙层无下墙才许可（斑块不算）；此项不另加有效范围门，抽样可超可绘制区，不能擅自改为 Dw/Dh 域 |
| 2×2 虚空 | ⌊W×H/d⌋ | x∈[0,W−2], y∈[0,H−2]；四格最终布局均为虚空 |
| 1×1 虚空 | ⌊W×H/d⌋ | x∈[0,W−1], y∈[0,H−1]；最终布局为虚空 |

若 d＝0 且对应非空装饰映射已登记、前阶段通过，则在该项计算次数时**除零失败**，已消费种子但尚未改写原地图宽高/图块，也未摆放；不是「密度 0 不生成」。映射未登记则整项跳过，可避开这个除法；其他装饰阶段不因此自动通过。

斑块按完整单元数遍历，概率比较为整数 [0,99] 抽样小于配置；中心为该单元内均匀整数，处理中心±半径的**正方形闭域**，中心±1 的 3×3 符合地面门时必落斑，其余另按概率。平滑依次读四个正邻：斑块有 0 邻即回填通道，1 邻按 2×平滑率回填；非斑地面有 ≥2 邻按邻数×平滑率变斑。布局在处理途中可改变，不假定同步整图平滑。墙下斑块开关决定读底层还是最上非空布局。墙顶只在其正南第一墙层为外墙 2/内墙 1/内墙 3 时写第三层。

## 5. 图块化

- 布局符号 → 实际图块：房间/通道归为地面；无 → 图块 0；忽略 → 跳过（2×2 装饰的占位）；2×2 装饰按四格写偏移图块。
- 每类符号从图块集登记的 ID 列表中**随机选取**；自动图块（ID < 384）按邻接关系取变体；大网格/大墙/大地面选项按坐标奇偶加偏移；北墙正北有墙时加变薄偏移。
- 地图的宽度、高度与三层图块数据被改写为生成结果（§3.1）。

## 6. 事件与玩家摆放

### 6.1 摆放约束

- 候选房间：房间矩形宽/高须**严格大于** 事件宽/高＋1（即四周至少留 1 格，不贴墙——防止堵通道）。
- 单次尝试：随机候选矩形＋房内随机位置；宽 rw、高 rh、事件 w/h 时，左上内偏移分别在整数 [1,rw−w−1]、[1,rh−h−1] 均匀抽样。对每个新占格 p、每个已占格 q，须 **max(abs(px−qx),abs(py−qy))≥2**；即两轴差同时小于 2 才拒绝。两个 1×1 在 (5,5)/(7,5) 可通过，在 (5,5)/(6,6) 拒绝；不是两轴都必须≥2。
- 判定只检查候选矩形尺寸与占格间距，**不再查当前位置的最终地面、通行位或墙图块**。可见地面≠已登记候选；重绘保留的旧矩形仍参与抽取，不自动修正。
- 单事件最多 1000 次尝试；成功则登记占格，返回房间内的位置（多格事件取其底行左格）。
- 无合格房间或尝试耗尽 → 返回失败。

### 6.2 整体摆放与失败结果

- 顺序：每轮先逐个摆放地图全部事件（支持 ASCII `size(w,h)` 多格），再摆放玩家（1×1）。
- **事件摆放失败**：任一事件摆放返回失败 → 置整体失败标记，整轮（事件＋玩家）重来，**最多 100 轮**；100 轮后失败标记仍为真 → **抛出「无法把所有事件和玩家放进房间」异常**（在地图建立通知内抛出，沿重建调用链传播）。
- **玩家摆放失败（参考快照行为，如实登记不修参考）**：玩家摆放返回失败时**不置整体失败标记**，直接进入下一轮。若每轮事件都成功而玩家连续 100 轮无法摆放，循环结束时失败标记仍为假——**不进入最终异常分支**，回调正常结束：事件位置保留最后一次成功摆放的结果，玩家传送暂存坐标**保留旧值**（本轮未写入新位置）。
- 玩家摆放成功时：位置写入传送暂存（生效路径归地图转移链）。
- 即：最终异常保证仅适用于**事件失败**路径；玩家失败路径的可观察结果为「静默结束＋事件已摆放＋玩家坐标未更新」。**每轮开始重置失败标记，最终是否抛异常由最后一轮的标记决定**——先前某轮失败不保证最终异常。

## 7. 默认行为与配置变体

- **基线默认**：无地图默认是随机地牢（须元数据标记开启）；默认参数为 §3.3 表；种子按三级来源（默认无固定种子 → 系统新种子，每次进入重新生成）。
- **支持但未默认启用**：固定种子（参数固定种子或待播种子字段，可复现同一次生成——单次会话内，不跨实现保证）；9 类节点/房间图样；大网格对齐与双层墙等地牢图块集选项。
- **配置/数据关联**：地牢参数/图块集作者内容（编译生命周期）；地牢地图元数据标记（资源规格）；区域/版本/待播种子全局持久值（存档目录交叉）。
- **未验证组合**：真实图块集下的实际地图外观与可达性（U01）、各参数组合边界（极小地图、极端密度）、固定种子复现范围（U05）。

## 8. 边界、失败与未知

- 可绘制区为负 → 生成提前返回（全虚空布局），图块化照做；摆放阶段**按事件集合分流**：事件集合为空时仅尝试玩家，无房间每次返回失败但**不置失败标记**，重试耗尽后**不抛异常**（玩家暂存坐标保留旧值）；至少有一个普通事件时该事件摆放失败置标记，重试耗尽后按 §6.2 抛异常。
- 可绘制区小于单元 → 整区房间地面（不生成迷宫/通道，也不登记候选）；绘图通过不保证能摆放。
- 非空可访问集合、实际房间数 0 → 整区房间地面，不登记候选；空可访问集合则已在起点读取失败，不到此退化。
- 布局不连通或无地面 → 重绘（无次数上限，§4.4）。
- 墙错误不可修复 → 重绘；映射表外组合 → 重绘并抛错（防御性静态路径）。
- 事件摆放 100 轮失败 → 抛异常（沿重建链传播）。
- 玩家摆放 100 轮失败（事件均成功）→ **不抛异常**：回调静默结束，事件位置保留、玩家暂存坐标保留旧值（§6.2，参考快照行为）。
- 图块集/参数身份未命中 → 回退（首个图块集／默认参数实例），不报错。
- 大网格对齐＋奇数单元宽/高或奇数通道（标准参数对象，无插件覆写/扩展）→ 构造生成上下文时首次写回因无写入入口即报错；待播种子清空/播种与地图宽高/图块重写均未到达（§4.1，参考缺陷保留）。
- 装饰未登记 → 跳过；装饰图块列表为空 → 写图块 0。
- 对应装饰存在且密度 0 → 生成除零，种子已消费、地图重写/摆放尚未到达；四类密度分列（§4.5）。
