# 资源匹配、资源访问及声音（净化正文；批次 3）

分类：Generic Kernel（内容→资源匹配）＋Engine/Overworld（资源访问与音频宿主）。本文件描述「数据内容 → 媒体资源」的匹配规则、资源访问层的行为（路径解析、缓存、缺失归一）与音频层的行为（四类音频、切换/暂停/恢复/记忆、地图自动播放、叫声）。全部内容为静态证据；**无运行确认**（媒体文件实际存在与播放结果未验证，资源缺口 U01——见 `../scope-statement.md`）。

## 1. 目的与范围

**目的**：回答「某内容应显示/播放什么、缺失时发生什么」，供后续实现构建资源解析与音频，而不追踪任何特定路径组织。

**范围**：① 资源身份与路径解析（图像/音频/数据文件的查找与候选扩展名）；② 内容到资源的变体选择与回退（物种图鉴/战斗图/图标/脚印/影子/蛋、训练家图、道具图标）；③ 缓存与位图访问（共享、使用有效期、分入口失败）；④ 音频行为（BGM/BGS/ME/SE 播放/停止/淡出、暂停/恢复/记忆、地图自动播放与夜间变体、叫声、系统音效）。

**非目标**：不承诺任何具体媒体文件存在或可播放（U01）；目录命中不等于完整支持；不提取地图绘制/精灵渲染、消息/窗口/输入、HTTP/文件层失败归一（引用）、战斗内音频/图形的特殊规则（只登记共享入口）。

## 2. 概念与术语

- **资源解析**：把逻辑路径（可缺扩展名）解析为实际文件路径；图像候选扩展名为 .png/.gif（其余停用），音频候选为 .wav/.ogg/.mp3/.midi/.mid/.wma。
- **变体回退**：按内容属性（形态/性别/闪光/暗影）逐位降格查找，直到命中存在的文件或穷尽。
- **播放状态**：系统记录的「正在播放的 BGM/BGS」（含暂停位置），与实际音频输出分开——文件缺失时可登记请求而不交付该曲目的宿主播放请求；这不证明当时声道静音。
- **夜间变体**：地图 BGM 在夜晚优先使用 `名称_n`（存在时）。

## 3. 资源身份与路径解析

### 3.1 解析层规则

- **图像解析**：输入路径去图像扩展名后，在各搜索路径下依次尝试 .png、.gif（.jpg/.jpeg/.bmp 停用）；全部未命中返回 **nil**（另一入口则回退返回原输入）。
- **音频存在性**：广义存在性检查六后缀.wav/.ogg/.mp3/.midi/.mid/.wma及字面路径；专门SE解析固定Audio/SE前缀，只追加.wav/.ogg/.mp3/.wma四后缀及检查字面路径。
- **搜索路径**：绝对路径直接使用；相对路径沿宿主搜索路径（当前实现仅当前目录）；加密包经数据层加载检查（文件层规格引用）。存档目录按宿主系统数据目录（存档规格引用）。
- **数据文件存在性**：有加密包时以首字节读取为准，否则规范化路径后查文件系统。
- **失败归一**：资源解析层失败返回 nil（不抛异常）；文件字节读取层的失败归一（nil/空结果）按文件层规格（引用，不重复）。

### 3.2 与内容身份的衔接

- 资源文件名以内容的**符号 ID 字符串**为基名（如物种 ID、训练家类型 ID、道具 ID）；内容身份的查找/回退规则归内容身份规格，本文件只登记「身份 → 文件名」的映射与降格。

## 4. 内容到资源的变体选择与回退

### 4.1 物种图像

**通用降格（战斗图前/后、图标）**：候选因素按位降格——**闪光（同级闪光目录 ↔ 普通目录）→ 暗影（暗影后缀 ↔ 无）→ 性别（雌性后缀 ↔ 无）→ 形态（形态号后缀 ↔ 无）→ 物种（物种 ID ↔ `000`）**。按上述优先级逐项尝试所有组合（最多 32 种），返回第一个存在的文件；全部未命中返回 **nil**（位图入口随之返回 nil）。

| 资源 | 路径基 | 回退链 |
| --- | --- | --- |
| 战斗图（前/后） | 战斗图目录（前/后） | 通用降格（含同级闪光目录）；nil 兜底 |
| 图标 | 图标目录 | 通用降格；nil 兜底 |
| 蛋图/蛋壳裂纹/蛋图标 | `Graphics/Pokemon/Eggs/` | 形态 → 物种 → `000`/`000_cracks`/`000_icon`（**通用候选也经图像解析，全缺失时同样可 nil**） |
| 脚印 | `Graphics/Pokemon/Footprints/` | 形态 → 物种；nil 兜底 |
| 影子 | `Graphics/Pokemon/Shadow/` | 形态 → 物种 → **按物种指标的 shadow_size 通用影子（`Shadow/N`）** |

- **形态前提按入口拆分**：**前图/后图/图标入口没有形态数据前置**——通用降格直接组合候选路径查找，未登记形态但基础物种图存在时仍可命中（候选穷尽才回 nil）。**蛋、脚印、影子、叫声入口先按（物种, 形态）查询形态数据**：**形态键未命中时回退基础物种键**——基础物种记录存在即返回该记录（**不返回 nil**），随后这些入口仍先尝试所请求形态的资源、再尝试基础物种资源（影子另有按指标的通用影子分支）；只有**查询整体为 nil**（基础物种也不存在）时，脚印/影子/叫声在数据守卫处返回 nil，蛋类继续走 `000` 通用候选（该候选同样经图像解析，全缺失时也可 nil）。
- **个体入口**：按个体的物种/形态/性别/闪光/暗影状态取图；物种登记了个体位图回调时对位图再做个体级修改（形态规格交界，登记入口不展开）。
- **位图访问**：战斗图/图标经动画位图访问层（图标取图后去动画），文件缺失返回 nil。

兼容资源身份：普通前/后/图标分别为 `Graphics/Pokemon/Front/`、`Graphics/Pokemon/Back/`、`Graphics/Pokemon/Icons/`；闪光分别为其同级 `Front shiny/`、`Back shiny/`、`Icons shiny/`（名称含空格），不是普通目录下的 `shiny/`。

### 4.2 训练家图像

| 资源 | 路径与回退 |
| --- | --- |
| 角色图 | `Graphics/Characters/trainer_类型ID`；不存在返回 nil |
| 战斗前图 | `Graphics/Trainers/类型ID`；玩家版加 `_套装号` 后缀——**先查带套装后缀，未命中回退无后缀** |
| 战斗后图 | `Graphics/Trainers/类型ID_back`（玩家版先查 `_套装号_back`） |
| 城镇地图图标 | `Graphics/UI/Town Map/player_类型ID`（玩家版先查套装后缀） |

训练家图像入口先要求类型已登记；未登记类型即使同名媒体文件存在，也不因此越过类型门。玩家装束与基础资源的已有独立回退保持。

### 4.3 道具图标

- 空输入 → `Graphics/Items/back`；未知道具 → `Graphics/Items/000`（**固定兜底**）。
- 常规：`Graphics/Items/道具ID`，未命中时——机器类（HM/TM/TR）按 `machine_hm|machine_tr|machine_招式类型` 再按 `machine_招式类型`（非 TM）降格；最终回退 `000`。
- 队伍持有图标：邮件按 `icon_mail_道具ID`、其他按 `icon_item_道具ID`（`Graphics/UI/Party/`），未命中回退 `icon_mail`/`icon_item` 通用图。

## 5. 缓存与位图访问

- **缓存键**：相同路径与色相的有效访问可共享位图内容；已释放结果不能继续当有效命中。
- **使用有效期**：资源在仍有使用者时保持有效，复制内容与原图隔离；不规定具体内存管理机制。
- **空文件名**：返回 32×32 空白位图（不读盘）。
- **图块切取**：图块访问由资源、图块身份、色相与所需尺寸确定切片内容；相同有效内容可以复用，不规定缓存容器或键的表示。
- **缓存清空**：场景切换时由宿主缓存层整体清理（地图拓扑规格显示层重建处的清空调用点，引用）；本文件不规定淘汰策略。
- **失败边界**：分入口按下表区分解析 nil、缓存空白及动画/内嵌图像异常；损坏媒体与宿主输出未证。


### 5.1 位图访问的分入口失败

前提是正常宿主位图接口；缺失文件导致的宿主加载异常按明示条件分析，实际像素与损坏媒体未运行。

| 入口/输入 | 静态结果或失败阶段 |
| --- | --- |
| 图像解析候选全部缺失 | 返回 nil；这是解析结果，不等于后续访问安全。 |
| 直接缓存访问，空文件名 | 创建 32×32 空白位图，不加载命名文件。 |
| 直接缓存访问，非空文件名 | 未有有效缓存结果且宿主对缺文件抛普通加载错误时，本入口没有捕获，异常传播；不能推空白结果。已有有效缓存命中不发生这次加载。 |
| 普通非前缀动画包装，非空文件名 | 包装在外围捕获上述缓存加载的普通异常，改用 32×32 空白；这是该包装的保证，不是直接缓存的保证。 |
| 动画位图输入 nil | 在入口明确报错，不归一为空白。 |
| 文件名前缀 `[帧数]` 或 `[帧数,帧时长]` | 路由到独立条带加载路径；非正帧数、尺寸不满足等按其校验报错，该路径加载异常没有普通非前缀动画包装的同一捕获保证。 |
| 消息头像的两目录都未解析到（例如 `\ff[missing,0]`） | nil 随后交给动画位图入口，明确失败；不能写为一律无图。 |
| 被消费的内嵌 img/icon | 缺省尺寸测量或真正绘制时直接加载位图；假定宿主缺失加载抛错，则异常传播。单独/文尾未消费标记另按 WP17 附表。 |

直接消费者例：已选中的 `SnakeSquares` 过渡传入正时长、背景截图满足、并到达共享 `Graphics/Transitions/black_square` 加载时，若未有有效缓存结果且正常宿主对该缺图抛加载错误，异常在后续无图判定前传播，不得套普通动画包装的空白保证。有效共享图是该加载成功的反向对照，不保证其余演出阶段或实际像素。具名初始化异常也不由调用层的宿主收尾重试捕获，沿战前过渡正文§5/§7的既有异常边界。

缓存命中可能共享位图内容：仍在使用者中对共享内容的改动可见；复制结果的内容变化与原图隔离。使用期间应保持资源有效，最后使用结束后可释放；缓存清空的已定位场景边界保留，不规定引用计数、对象包装、初始计数或永久标记实现。

## 6. 音频行为

### 6.1 播放入口与失败边界

- **参数解析**：解析器支持 `文件名`、`文件名:音量`、`文件名:音量:音调`，缺省两参 100；两字段第二项是音量，不是音调。`Theme:70:120` 解析为 70/120，`Theme:120` 为 120/100。一般播放入口接收字符串时未显式覆盖的参数用 100，故字符串 Theme:70:120 直接播放交付 100/100；预解析音频记录交付 70/120。显式覆盖各自独立：记录中未覆盖项保留，字符串中未覆盖项用 100。消息 SE/ME 先解析为记录，保留嵌入参数。
- **实际播放前提**：正常系统入口在相应文件存在时才向宿主交付请求；缺失 BGM/BGS 仍登记所请求曲目，SE/ME 不交付缺失文件。登记和宿主请求分开，均不证明实际发声。默认 BGM 覆盖时，宿主曲目可与逻辑登记不同。
- **音量缩放**：BGM/ME 按玩家选项音乐音量、BGS/SE 按音效音量百分比缩放。
- **默认 BGM 覆盖**：设置了默认 BGM 时一切 BGM 请求改播默认曲（状态登记仍按请求）。
- **帧重置**：BGM/BGS/ME 播放或停止后做画面帧重置。

### 6.2 切换、暂停/恢复与记忆

| 状态/动作 | 请求、登记与后继结果 |
| --- | --- |
| BGM 停止/淡出 | 主通道的播放登记均清空；未暂停时位置也归零，已暂停时保留所记位置。无默认 BGM 覆盖时才向宿主请求停止或淡出；秒数转毫秒向下取整。 |
| BGM 零时长暂停 | 先查询位置（查询失败按 0），保存位置并置暂停标记；暂停本身不停止宿主、不清播放登记。正时长暂停先淡出并清登记，再保存所查位置及暂停标记。 |
| BGM 暂停中的播放/停止/淡出 | 播放可替换逻辑曲目登记，停止/淡出仍清登记；三者都不覆盖暂停位置。恢复入口仅在暂停标记为真时将给定曲目从所记位置交付播放，随后位置归零、清暂停标记；解除暂停入口不重播。 |
| BGS 暂停/恢复 | 零时长暂停立即停止，正时长暂停淡出；均清播放登记后置暂停标记。仅暂停中恢复才重播给定曲目并清标记，不保存或恢复播放位置。 |
| 记忆与回播（247/248） | 记忆当前登记的曲目；后续对同一登记曲目内容的原位修改会改变已记内容，不能承诺独立快照。回播重新按当前音量选项交付；另行取得当前曲目的副本与记忆入口不同。 |
| 音效选项改写 BGS | 当前 BGS 请求音量 80 已记忆；音效选项改为 50 时先把登记音量改成 50，记忆随之变 50，再暂停/恢复。宿主请求音量是 50×50%=25；后续 248 仍请求 25，不能按旧 80 推 40。前提：文件存在、选项回调正常。 |
| 提示切换 | 当前无登记，或目标名称/音调不同：请求淡出、替换待播目标；仅原来没有待播计时时建立计时，延迟为当次淡出秒数×0.6。后续提示不重置在途起点/延迟。到期更新先清延迟；只有当前没有 BGM 登记才交付最新目标，否则不播放、不重试。待播目标内容并不因此清空。当前名称/音调相同则立即交付播放。 |

例如 t=0 提示 B/淡出 1 秒，t=0.3 提示 C/淡出 2 秒：保留 t=0 起点和 0.6 秒延迟，首个到期更新尝试 C。若 t=0.5 已直接播放 D，到期只清延迟，D 保持，没有后续重试。音量不同而名称/音调相同不满足上述差异门。上述均为逻辑及请求合同，实际发声、位置精度与宿主失败继续未证。

### 6.3 地图自动播放与夜间变体

- **自动播放**：地图元数据自动 BGM/BGS 为真时按地图 BGM/BGS 播放；两种入口——直接播放（读档恢复用）与提示切换（转移用）。
- **夜间变体**：夜晚且 `名称_n` 存在时改用 `名称_n`（时间来源引用）。
- **传送淡出**（在新图自动播放执行之前的预淡出阶段）：两条差异分支**各自带门，仅名称不同不足以触发**——**BGM 分支**：当前已有 BGM 播放登记、目标图自动 BGM 开启且登记曲名与目标图解析曲名（含夜间变体）不同 → 请求 BGM 淡出 0.8 秒；**BGS 分支**：当前已有 BGS 播放登记、目标图自动 BGS 开启且登记 BGS 名与目标图 BGS 名不同 → **调用的同样是 BGM 淡出**：向宿主请求 BGM 通道淡出 800 毫秒并清空 BGM 播放登记，**本分支没有 BGS 淡出，BGS 播放登记保持**（参考快照行为，如实登记，不修参考；BGS 淡出另有独立入口，不在此分支；BGS 分支成立**不额外要求 BGM 分支成立**）。任一分支在播放登记缺失或目标对应开关关闭时均不请求淡出；两者均无播放登记时整个预淡出直接返回。前提：系统存在、无默认 BGM 覆盖（否则宿主淡出请求被跳过、状态清空仍发生）。
- **冲浪 BGM**：转移自动播放时，冲浪中且元数据登记冲浪 BGM 则改播冲浪曲（冲浪状态引用）。

### 6.4 叫声与系统音效

- **物种叫声**：叫声候选为 `Audio/SE/Cries/物种ID[_形态][后缀]`；形态未命中回退物种，带后缀候选缺失时可再回标准叫声。蛋、无有效物种/文件或音调≤0 的时长入口返回 0。内部读取失败可得 −1，但公开音频时长入口将负值夹到 0，不能向调用者承诺 −1。时长先查给定路径，再查 .wav/.mp3/.ogg；分别按固定来源的 WAV/MP3/Ogg 格式读取规则，不能写为只支持 Ogg或任意 MP3 都可解码。有效 WAV 数据长度 176400、字节率 88200 时为 2 秒；叫声音调 50 时估计 4 秒。音调为正时用文件秒数×100/音调；叫声播放异常被捕获，真实输出未证。
- **系统音效**：光标/决定/取消/蜂鸣优先用系统数据登记的音效，未登记且默认文件名存在时用默认文件（音量 80）；关闭菜单音仅按默认文件存在与否。

逻辑开战/胜利/捕获与训练家引子选曲沿已接受 WP24 §5.4 的六入口表及 PT41–63；它们只规定曲目请求和交付前记忆。这里的播放参数、选项缩放、默认覆盖与恢复位置不能由该选择表反推。普通训练家数组的后项空文本会落地图回退，直接类型辅助保留空文本；后者在固定脚本文本中仅定位定义，动态/插件消费者未证。

### 6.4.1 音频时长的格式边界

前提是文件可正常打开和读取；只记录固定文本的识别分支，不执行媒体解析，也不保证宿主解码。公开入口优先取字面路径，只有该路径不存在才依次查.wav/.mp3/.ogg；已有文件内部识别失败不会继续换后缀。公开层只夹负的数值结果，不承诺捕获所有文件或损坏数据异常。

| 文件识别/输入 | 内部时长结果与公开边界 |
| --- | --- |
| WAV固定布局 | RIFF后要求WAVE、紧随fmt块及随后data标识；字节率非零时取data字节数/字节率。标识不符或字节率0返回−1，公开为0；不能外推任意附加块布局均支持。 |
| Ogg | 无识别页面，或新逻辑流不是版本0的Vorbis识别包时返回−1，公开为0；正常数据的页面终位置与读取速率决定估计值，真实播放秒数未测。 |
| MP3后备识别 | 只扫描固定帧头及有限码率/频率组合，未匹配可保留−1；不能承诺全部MP3版本/编码方式，或损坏输入都有安全数值。 |
| 多后缀并存 | 字面路径存在但不识别时公开0；即使旁边.wav有效也不继续。字面不存在且有效.wav存在才取其时长。 |

## 7. 默认行为与配置变体

- **基线默认**：图像候选 .png/.gif；音频候选六种扩展名；物种图像按 §4.1 降格；道具/蛋有固定兜底图；BGM 按地图自动播放（含夜间变体）；音量按玩家选项缩放。
- **支持但未默认启用**：物种个体位图回调（形态规格）；默认 BGM 覆盖；系统数据登记的 UI 音效；邮件专用图标。
- **配置/数据关联**：对话/菜单窗口皮肤（事件命令 131 引用）；音乐/音效音量玩家选项；地图元数据 BGM/BGS/自动播放字段与全局元数据冲浪/骑行 BGM；系统数据的四种 UI 音效。

## 8. 边界、失败与未知

- 图像解析全未命中 → nil（位图入口 nil）；另一入口回退原输入。
- 形态查询与资源缺失三分：**形态键未命中但基础物种存在** → 查询回退基础记录，蛋/脚印/影子/叫声可命中基础物种资源；**查询整体为 nil**（基础物种也不存在）→ 脚印/影子/叫声在数据守卫处 nil，蛋类走 `000` 通用候选；**文件候选全未命中** → 各入口按自身解析规则回 nil（蛋的 `000` 通用候选也不例外）。前/后图/图标不受形态查询约束（按候选路径继续查找，穷尽才 nil）。
- 道具图标未知 → `000`；空输入 → `back`。
- 音频文件缺失：BGM/BGS 仍登记请求，但不交付该曲目的宿主播放；SE/ME 不交付缺失文件；叫声 nil 不请求播放；叫声播放异常被捕获。上述不证明此前输出已停止。
- 暂停位置查询失败按 0 记录；恢复时从头播放该位置之前的内容不可考（静态）。
- 空文件名的缓存位图为 32×32 空白。
- §5.1 以外的损坏媒体和宿主加载行为。
