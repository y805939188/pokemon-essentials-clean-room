# 战前过渡（净化正文；批次 1）

分类：Engine/Overworld Integration（主）、Combat Requirements（交界）。本文件描述世界画面进入战斗场景**之前**的过渡行为：特殊过渡的注册与选择、资源条件、默认效果选择、演出阶段与固定目标时长、正常返回边界。**与战斗内开场分开**——后者是战斗场景创建之后的开场序列（训练家排列/野生入场/闪光公共动画），选择输入、资源条件与完成点均不同。全部内容为静态证据；素材是否存在（当前快照图形目录缺失）与实际帧呈现/墙钟耗时未运行验证（见 `../scope-statement.md`）。

## 1. 目的、输入与分类

- **目的**：进入战斗前在世界画面上播放一段过渡演出，结束时画面应为黑屏，随后让位给战斗场景；战斗结束后由同一包装恢复世界画面。
- **包装行为**：进入即置战斗进行中标记；建立最上层画面叠加（遮盖次序最高，不规定具体容器结构）；暂停当前背景音乐/音效，若存在已记忆音乐则恢复其位置，随后播放战斗音乐（未指定时取野生战斗音乐）；判定位置；执行特殊选择或默认选择；让位给战斗场景；返回后恢复先前音乐/音效、清除已记忆音乐与其位置、清空四类下一战预置（下一战音乐/胜利音乐/捕获音效/下一战背景）、遭遇计步重置；以 **0.4 秒**目标从黑屏回褪到世界画面（按已过时间占 0.4 秒的比例递减不透明度，每帧推进世界画面更新），结束画面叠加并清除战斗进行中标记。
- **让位行为**：执行战斗场景期间，世界画面的可见表示按既有缓存与刷新语义让位；正常返回时世界画面恢复呈现——本条只约束可见表示的去留与恢复（含缓存清理与帧重置的行为意义），**不规定任何集合必须先销毁再构造的生命周期**（对象组织方式见审计）。黑屏交接、时序、正常返回恢复与「异常路径不保证完整恢复」的合同不受影响。

**输入及其作用**：

| 输入 | 取值与作用 |
| --- | --- |
| 过渡类别 | **调用方提供的过渡选择类别**：0＝野生、1＝训练家、2＝双打野生、3＝双打训练家。**它是调用方传给过渡选择的类别，不能从真实战斗类型或音乐类型反推**——普通野生链按对手队伍数给 0/2，普通训练家链按是否单打给 1/3；设施挑战与回放调用仅传音乐、省略本参数时采用**默认类别 0**（参考行为：其过渡走类别 0 的默认选择，不改成训练家特殊演出）。类别决定特殊注册资格与默认效果选择表的分支 |
| 对手上下文 | 随调用侧不同：普通训练家链传训练家列表；普通野生链传野生个体列表；设施挑战/回放调用省略本参数，使用默认空上下文。**「恰好 1 名对手」（列表长度）与「训练家战类别」（类别奇偶）是两个独立条件**——类别 3 且 2 名对手时，要求单名的注册不满足、允许多名的注册可满足；资格条件的类型检查先于对手读取（默认类别 0 时五组资格在类型检查处即不成立） |
| 位置 | 0＝室外、1＝室内、2＝洞穴、3＝水域；判定顺序：冲浪或潜水 → 水域；否则遭遇类型为钓鱼 → 水域；否则当前有可洞穴遭遇 → 洞穴；否则地图元数据非户外 → 室内；否则室外。位置决定默认选择表的列与闪屏颜色（洞穴视同夜间） |

| 资源可用性 | 特殊注册的资格以资源路径可解析（png/gif，含加密归档路径）为条件；资源不满足则落到后续候选或默认路径 |
| 玩家装束 | **只作用于玩家侧**：玩家条形图与玩家立绘各自独立先尝试装束变体、不可解析时各自回退类型基础资源；对手侧资源直接按对手类型选取，不查询装束变体 |

## 2. 特殊过渡注册表合同

- 每个登记项包含四项信息：名称、优先级数值、触发条件、演出体（逻辑组成；不规定存储布局或容器结构）。名称用于识别登记；注册不去重（同名可重复登记）。
- **撤销**：按名称移除——**移除全部同名项**；**查询**：按名称判定存在性；按名称取项时返回**登记序首个**匹配，无匹配返回空。
- **选择**：遍历按**优先级数值降序**排列的注册项，对每项以求值输入（过渡类别、对手上下文、位置）检查触发条件，**只执行首个满足条件者**，随后停止；没有命中才走默认选择。
- **同优先级不补造次序保证**：排序只比较优先级数值，未定义同优先级项的稳定次序——不得凭登记先后或实测顺序补造「同优先级谁先生效」的规则。
- 内置五组特殊注册（§3）；扩展可增删注册项（作者入口），本文件不断言注册表运行期不变。

## 4. 演出阶段

### 4.1 包装阶段

见 §1「包装行为」与「让位行为」。

### 4.2 核心演出

1. **前置闪屏**：次数由调用方给（默认 2；各特殊路径见 §3）；颜色规则——洞穴或夜间为黑、否则为白；每半次闪屏目标 0.2 秒（淡入后淡出计一次）。
2. **截图准备**：释放旧背景位图，把当前画面快照存入临时背景位图（供主过渡效果读取世界画面底图）。
3. **主过渡**：冻结画面、确保画面为黑，以 **25 个 1/20 秒单位**请求具名效果；通用换算 1.25 秒仅在效果无固定目标时长时生效（§5）。
4. **后置等待**：**0.1 秒**（秒单位；等待循环每帧推进图形、输入与世界画面更新）。

### 4.3 alternate_vs_trainer 自编排序列

不走核心演出。**资源选择按侧分开**：对手条形图与对手立绘**直接按对手训练家类型选取基础资源**（`vsBar_<对手类型>`、`vsTrainer_<对手类型>`），不查询装束变体；玩家条形图与玩家立绘**各自独立**先尝试装束变体（`vsBar_<玩家类型>_<装束>`、`vsTrainer_<玩家类型>_<装束>`），各自不可解析时**分别**回退类型基础资源（`vsBar_<玩家类型>`、`vsTrainer_<玩家类型>`）——两项允许一项用变体、另一项用基础资源（混合命中），且玩家侧回退规则不得套用到对手侧。演出序列：条图自两侧滑入（0.25 秒）→ 全白闪＋两声音效 → 条图滚动并让双方立绘入场（1.2 秒段）→ 再次全白闪＋音效 → 显示对决标志与双方名字 → 标志震颤（至 1.75 秒）→ 标志放大（至 2.5 秒）→ 渐黑（整段 2.8 秒）→ 释放全部自建呈现资源并确保画面为黑。该路径不读临时演出数据；玩家/对手名字直接绘制。

## 5. 时序合同（单位与固定目标时长）

- **单位区分**：过渡入口时长为 **1/20 秒单位**（取整）；特殊效果判定时换算为秒（÷20.0）；具名效果可声明**固定目标时长**，声明后**覆盖**传入时长；等待入口以**秒**为单位；以上均为静态目标时长，不是实测墙钟耗时。
- **完成条件**：效果以自身起始时刻计时，**计时达到目标时长即自行处置**；过渡调用在生效等待旗标下**阻塞至该处置完成**。
- **中断守卫先于旧过渡处置**：特殊判定**先检查中断旗标**——置位时**直接返回否**：本次调用不执行特殊判定内的在途旧过渡处置、不实例化具名效果，也不在本调用中阻塞等待特殊过渡（阻塞同样受该旗标限制）；随后由普通路径处理。**未置位时**才按既有路径先处置在途旧过渡再实例化。中断旗标在当前参考快照**未见赋值点**（如实登记，不推成扩展永不设置）；本调用未处置旧过渡**不等于**旧过渡此后永不更新或永不被后续清理。
- **特殊判定边界**：名称未命中任何具名效果（或中断守卫返回否）时，由普通宿主过渡以换算后的帧时长与原文件名执行。
- **异常重试条件**：底层宿主过渡调用的**首次异常由本层捕获**；**仅当该次调用使用的文件名非空**时，才以空文件名再调用一次——**文件名已空时不作第二次尝试**；第二次调用自身的异常**不再由本层兜底**。具名效果成功选中后，宿主收尾调用的文件名已被清空，因此该调用失败后也不承诺重试；**具名效果实例化阶段的异常不在此捕获范围内**。
- **零/负时长**：**实际被选中并进入具名效果初始化**且传入时长 ≤ 0 时，初始化即置已处置并早退——不呈现可见过渡、不进入阻塞等待；该早退只承诺到此路径，不补造后续保证。

## 7. 边界、排除与未验证

- **具名排除（实现细节类）**：像素坐标/尺寸、图像切分与遮罩模式、插值轨迹与逐帧参数、呈现/位图组织方式——不改变选择、资源条件、阶段目标时长与完成合同，不逐行提取。
- **正常返回边界**：§1 的临时信息清理（已记忆音乐、四类下一战预置、计步重置、战斗进行中标记）只在**正常返回**路径成立；异常路径不保证走完整清理，不补造全局恢复合同。演出临时数据由各特殊路径自身设置并在演出后清空；背景位图由后续截图准备或处置链释放。
- **资源与异常**：资格条件只查类型专属资源存在性；具名效果初始化还会加载共享图（对决标志件、黑色遮罩件等），加载阶段缺文件的异常不被调用层重试覆盖（§5），不补造回退；VSEliteFour 初始化的早退检查不含玩家立绘位图——如实登记，不推成必有回退。
- **未验证**：素材是否存在（当前快照图形目录缺失）、实际画面/帧率/墙钟耗时、注册表运行期改动、扩展注册的内容——全部保留待证；以上静态可读规则不依赖这些验证。

## 9. 依赖与配置

- **上游调用侧（交界）**：普通野生链（类别按对手队伍数给 0/2、对手上下文为野生个体列表）；普通训练家链（类别按是否单打给 1/3、对手上下文为训练家列表）；设施挑战与回放（仅传音乐——默认类别 0 与空上下文，参考行为不改写）；特殊模式（Safari/捕虫）均以本包装让位战斗场景；战斗内开场归战斗呈现范围。
- **依赖**：资源缓存与解析边界；转场命令与帧重置（本批《世界绘制与视觉过渡》§6）；计步重置交界（遭遇系统）；正常返回恢复合同（战斗结果系统）；钓鱼位置消费（钓鱼系统）；日夜判定消费侧（区域地图/时间系统）。
- **配置/数据**：战斗音乐默认取野生战斗音乐；特殊注册的名称/优先级/条件/演出体为作者扩展点。

2. 注册表运行期改动与扩展注册的内容（作者入口，未穷尽）。
3. 具名效果的逐帧呈现细节（像素级参数具名排除，见 §7）。
