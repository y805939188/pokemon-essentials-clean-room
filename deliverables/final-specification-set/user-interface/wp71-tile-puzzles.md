# Tile Puzzles（板块拼图小游戏）行为规格（净化正文；批次 14）

分类：user-interface（主）／demo-dx（玩法内容）／generic-kernel（随机输入接点）；性质：实现独立行为规格。

本稿为净化正文的一部分：按统一交接将批准输入 WP71《Tile Puzzles（板块拼图小游戏）》转写为独立行为文字，不含源文件路径、行号与脚本入口名（源定位集中登记于 `../../audit/source-traceability.md` 批次 14 条目）。范围 A～F：入口与棋盘参数、七模式状态和合法动作、输入与完成／取消返回、随机入口、初始化／打乱及已述资源／宿主边界；默认尺寸的固定推导、已述特殊尺寸反例、联动旋转不变量、合法构造与完成中断的场景。全部内容为静态证据；**无运行确认**（见 `../scope-statement.md`）；可解性与最终分布未被静态证明处如实保留。全尺寸可解性、完整随机分布、真实媒体／宿主输入／事件奖励保留；模式 3 末格空白漏扫、模式 6 非方形列端点、宽 1 导航等已述边界不修参考。

## 1. 目的、边界与可见流程

本稿逐项提取 Tile Puzzles 的实际模式、参数、合法动作、状态改变、打乱、完成与取消。**不按名称猜玩法**：全部结论来自对源文件的静态阅读（608 行全文，定位见追溯条目）。

**入口**：全局拼图入口（参数：模式, 棋盘, 宽＝0, 高＝0），经淡入淡出包装。**核心脚本内无调用者**（全脚本检索仅命中本文件；真实调用为事件侧，U01）。返回 true（完成）／false（中途退出）；**返回值之后发什么（奖励、开门等）是外部事件责任，不在本稿**。

**非目标**：不重做 WP68／WP69／WP70（不同工作包，本稿交付不代替其整合）；不定义事件奖励与可达性；不评估图片主题与媒体资源是否存在；不运行拼图或打乱生成器补证可解性。

## 2. 棋盘参数与状态模型（A、B）

### 2.1 参数

| 参数 | 取值 | 效果 |
| --- | --- | --- |
| 模式 | 1–7 | 模式选择（§3 目录）；**表外值未定义守卫**——按否则分支处理（打乱走模式 3/4/5 公共路径、不追加暂存区、不随机角度；输入循环中无任何模式专属动作，只能移动光标与 BACK 退出——静态边界，不补造玩法） |
| 棋盘 | 名字／编号 | 资源后缀：`bg{board}`（缺失回退 `bg`）、`tiles{board}`（必需，切图来源）、可选 `tiles{board}_1/_2/_3`（预渲染 90°／180°／270° 旋转图） |
| 宽／高 | >0 生效，0（或负）→ 默认 4 | 棋盘宽／高（格数）；块尺寸＝切图位图宽÷width、高÷height；块身份 0..(w×h−1) |

### 2.2 状态

| 状态 | 结构 | 说明 |
| --- | --- | --- |
| 块位置表 | 位置 → 块身份（0..w×h−1），空位为 −1 | 模式 1／2 长度 2×(w×h)：前段 w×h 为**棋盘格**（初始全 −1），后段 w×h 为**两侧暂存列**（初始为全部打乱后的块）；其余模式长度 w×h（无暂存区） |
| 角度表 | 块身份 → 0..3 | 模式 2／5 初始各 0–3 整数抽样，其余全 0；完成要求全 0 |
| 暂持块 | 块身份或 −1 | 仅模式 1／2；抓起／放下即与目标槽**互换**（同一动作） |
| 光标位置 | 位置号 | 初始：模式 3＝空白块所在格，其余＝0；方向键按模式边界规则移动（§4.1） |
| 选中态 | 布尔 | 模式 3–6：按住 USE 期间为真（每帧重算），决定方向键是滑块／换行还是移动光标；模式 1／2／7 无此态 |

屏幕坐标映射（静态记录）：棋盘格居中；模式 1／2 的暂存位置按**整数除法 宽÷2** 拆到屏幕左／右两侧（宽 5 → 左 2 格、右 3 格；宽 1 → 拆分点 0，全部在右侧、无左列——不是向上取整）。**完成判定**：前 w×h 个位置的块身份全部等于其目标身份（第 i 格为块 i），且全部角度为 0（模式 1／2 的暂存列不参与判定）。

## 3. 实际模式目录（C）

| 模式 | 棋盘与块 | 合法动作 | 打乱（初始化） | 完成 |
| --- | --- | --- | --- | --- |
| 1（遗迹拼图） | 棋盘＋两侧暂存列；全部块先放暂存列 | 方向键移光标（可越入暂存列）；USE＝抓起／放下（与槽内容互换） | 全洗牌（普通随机）；暂存列承载全部块 | 棋盘按序排满（角度恒 0） |
| 2（遗迹＋旋转） | 同 1 | 同 1；另 ACTION＝旋转（暂持时旋转暂持块，否则旋转光标下非空块，每次 −1 mod 4） | 同 1，再为每块随机角度 0–3 | 序＋角度全 0 |
| 3（Mystic Square，滑块） | w×h 格；最大编号块为**空白**（不绘制） | 方向键＝与相邻格滑动交换（光标随动）；无可行动作来自棋盘边（§4.1） | 洗牌＋**可解性复检**（§5.2） | 序（空白归末位）＋末块淡入揭示 |
| 4（相邻交换） | w×h 格 | 方向键移光标；**按住 USE**＋方向＝与相邻块交换（光标随动） | 全洗牌 | 序（角度恒 0） |
| 5（相邻交换＋旋转） | 同 4 | 同 4；另 ACTION＝旋转光标下单块（−1 mod 4） | 同 4，再随机角度 | 序＋角度全 0 |
| 6（Rubik 行／列移） | w×h 格 | 方向键移光标；**按住 USE**＋方向＝光标所在**整行或整列**向该方向循环移动一格（首尾回绕，光标不动）；**非方形棋盘的列端点折算有缺陷**（§9） | 从完成态随机执行 **5 次**整行／列移（非方形时该阶段即可触发同一缺陷） | 序＋角度全 0（角度恒 0） |
| 7（联动旋转） | w×h 格 | 方向键移光标；USE＝光标块**与全部有效相邻块**一起旋转（各 −1 mod 4） | 从完成态随机执行 **5 次**联动旋转 | 角度全 0（块位恒不动） |

旋转方向：每次触发该块角度值 −1（mod 4）；角度 2 时按两下、**角度 3 时按三下（3→2→1→0）**回到 0；连按四次复原。显示侧：有对应预渲染旋转图则贴图，缺该档（如只有 _1 没有 _2）则按角度整体旋转精灵（媒体差异不改规则）。

## 4. 合法动作与输入（D）

### 4.1 光标移动与边界

方向映射：上 8／下 2／左 4／右 6（**按下沿或重复**——按住方向键会持续移动／连续滑动或连续换行；抓起、旋转、完成确认均为按下沿单次）。边界（可移动方向查询）：上下按行越界拒绝；模式 1／2 的暂存列左列最左、右列最右拒绝外移，棋盘格与暂存列之间按整数除法 宽÷2 的折算位置互通（同一动作函数内确定的转移表；宽 1 时拆分点为 0，常规双侧导航不成立，可达性具名保留）；模式 6 在按住 USE 时**任何方向都可移**（换行没有边界拒绝——但非方形棋盘的列端点折算缺陷见 §9）。无可行动作时按方向键无任何效果（无蜂鸣）。

### 4.2 动作前置与状态改变

| 动作 | 前置 | 状态改变 |
| --- | --- | --- |
| 抓起／放下（1／2，USE） | 无（空槽也可互换） | 暂持块与光标槽内容互换；暂持块以红色调显示于光标处；完成态时该动作不可达（见 §6） |
| 滑动（3，方向键） | 目标相邻格在界内 | 光标槽与相邻槽块互换，光标随动 |
| 相邻交换（4／5，按住 USE＋方向） | 同 3 | 同上 |
| 行／列移（6，按住 USE＋方向） | 恒可 | 光标所在整行／列向该方向循环一格（淡出淡入呈现） |
| 旋转单块／暂持块（2／5，ACTION；2 亦可旋转光标下块） | 光标槽非空（暂持时无此限） | 目标块角度 −1 mod 4 |
| 联动旋转（7，USE） | 无 | 光标块＋界内相邻块角度各 −1 mod 4 |
| 退出（BACK） | 非完成序列中 | **立即返回 false**，局面不保存、无确认 |
| 完成确认（USE／BACK） | 完成判定后 | 返回 true |

## 5. 初始化、打乱与随机入口（E）

### 5.1 各模式打乱

- **1／4／5**：全洗牌排列（模式 1 置于暂存列）；**不排斥任何排列**——按构造必然可解（任意摆放／任意相邻交换序列可达），但**未排斥初始即完成**：模式 4／5 理论存在打乱后即完成态（概率 1/(w×h)!，角度另随机），主循环首帧即进完成序列。
- **2**：同 1 且每块 0–3 整数抽样角度；可解性同 1（单块独立可旋回）。
- **6**：完成态起随机 5 次行／列移（方向与位置均随机）；**方形棋盘**按构造可逆、可解（逆序反向操作即还原，解不唯一）；**非方形棋盘的列端点折算缺陷在打乱阶段即可发生**（§9 反例 TP21，无需真实 UI 输入），此时局面状态含棋盘外写入，可解性不作声明；5 次操作理论上可自我抵消回到完成态（未排斥，静态可能）。
- **7**：完成态起随机 5 次联动旋转；可解（对同组再旋三次即逆）；同样未排斥抵消后全 0。
- **3**：见 §5.2。

### 5.2 模式 3 的可解性复检（实际筛选与尺寸边界）

洗牌后按逆序数 parity 复检，不合格则重新打乱（递归直至通过）：**宽为奇数** → 逆序数须为偶（奇则重洗）；**宽为偶数** → 要求「逆序数奇偶 ≠ 空白所在行（自底向上计）奇偶」（相同则重洗）。逆序数统计排除空白块身份。初始即完成态不被该复检排斥（逆序数 0 可通过），故模式 3 也可能首帧即完成。

**该筛选的空白定位只扫到倒数第二格**：空白在末格时定位保持缺省值 −1，参与偶宽判定的「自底行数」按 高−(−1)＝高＋1 计算，而不是真实的 1。因此：

- **默认 4×4（偶宽偶高）**：高＋1＝5 与真实 1 同奇偶 → 判定不受影响；此尺寸下该筛选与标准 15-puzzle 可解判据等价（可复核，见 TP10／TP11）。
- **偶宽奇高（如 2×3）**：高＋1＝4（偶）与真实 1（奇）相反 → **判定反转**：已完成排列被拒重洗、不可解排列被接受（固定反例 TP19）。
- **单行／单列**：parity 判据不适用——滑动无法改变非空白块的相对顺序，即使筛选通过也可能不可解（TP20 的 5×1 例）；此类尺寸的可解性**未证明**。

综上：**撤回**「与标准判据一致／全尺寸唯一已证明的可解性保证」的表述——本稿实际保证的只有默认 4×4 尺寸的可复核结论；其它尺寸按实际筛选记录，分布与可解性未证明（不运行打乱或生成器补证，也不修参考算法）。

### 5.3 随机入口（WP06 接口一致性）

全部使用**普通随机**（整数抽样与全洗牌；无显式种子、无记录序列，WP06 同类）。重放不可证；跨实现分布不声明均匀。**步数、游戏统计均不涉及**——本活动不写任何统计字段、不读写步数（WP06 统计目录无本活动字段，已字面核对）；无计时、无移动计数、无计分。

## 6. 完成、取消与返回（F）

主循环每帧先判完成：完成 → 隐藏光标（模式 3 另将空白块以末块贴图淡入揭示；其余模式等待 0.5 秒）→ 等待 USE／BACK 按键 → **返回 true**。BACK（未完成时）→ **返回 false**，不弹确认、不保存任何局面；再次进入由事件重新调用并重新打乱。**完成序列中 BACK 不再退出**（只作为完成确认键）；抓起暂持块时按 BACK 同样直接退出（暂持随之丢弃，无持久副作用）。

## 7. 资源与宿主边界

- `bg{board}` 缺失 → 回退 `bg`；`tiles{board}` **必需**（直接构造位图；缺失时的宿主行为具名保留，未运行验证，WP15 引用）；`tiles{board}_1/_2/_3` 按档独立回退到精灵旋转。
- 光标图固定路径；箭头显示＝当前可移方向（每帧按模式与边界重算）；模式 3 光标不显示外框只显示方向箭头。
- 画面尺寸宽 512×高 384 的宿主约定（Graphics 宽高）；棋盘居中、暂存列贴边；tile 尺寸由位图与棋盘参数整除得到（**非整除时按整数除法切图**，静态记录）。
- 音效：移动／交换为「Tile Game cursor」SE（引用 WP15 资源入口，未运行）；无 BGM 控制。

## 8. 规则与不变量

1. 块位置表是唯一权威局面；画面只读它渲染；完成判定只查前 w×h 位置与全部角度。
2. 抓起／放下＝同一互换动作（无独立「空手抓起」与「满手放下」守卫）；暂持块不参与完成判定的位置要求之外。
3. 方向键的语义由「模式＋是否按住 USE」唯一决定（§4.2）；不存在任何菜单、文本或数量输入（WP17 仅提供按键别名与按下沿/重复语义）。
4. 可解性／分布保证按尺寸与模式分别限定：默认 4×4 的模式 3 有与标准判据等价的可复核筛选（§5.2）；其它尺寸的模式 3 按实际筛选记录（含末格空白漏扫反例）；模式 1／2／4／5 靠动作生成全集可达；**方形棋盘**的模式 6／7 靠可逆构造；非方形的模式 6 有列端点折算缺陷（§9）。
5. 无计分、无步数、无统计写入、无持久局面；返回 true／false 是唯一对外输出。
6. **模式 7 可达性的固定不变量（默认 4×4、行优先零基）**：取格集合 S＝{0,4,5,8,10,13,14,15}，16 个合法联动旋转组与 S 的交集格数分别为 2,2,0,0,4,2,2,0,2,4,2,2,2,2,4,2（全为偶数）；因此「S 内角度和的奇偶性」在每次联动旋转后不变——初始全 0 恒为偶。任何使该和为奇的角度分布（如「仅格 5 角度 1」）**不可能由初始化五次旋转或后续任意合法操作到达**（固定集合与算术，独立复核；不求解器、不运行生成器）。

## 9. 边界与失败

- 模式表外值：无动作可用（静态边界，§2.1）；宽／高 ≤ 0 → 默认 4；1×1 棋盘：模式 3 首帧即完成（空白即唯一块）；模式 1／2 的 1×1：抽象完成条件成立（棋盘一格放入唯一块即完成），但从入口抓取并放回棋盘的正常操作链在拆分点 0 下导航退化，可达性未证。
- **非方形棋盘的两个尺寸反例**（不修参考算式；异常后宿主呈现未验证）：
  1. **模式 6，宽 3、高 2，位置 0 向上移列**：列端点搜索按「(宽−1)×高」比较（方形时与「宽×(高−1)」相等，非方形不等），得到棋盘外位置 6；参与位置为 [6, 3]——有效格 3 被写入空值、原格 3 的块被写到棋盘外位置 6，不能当作合法整列轮转；该异常在打乱阶段即可发生（TP21）。
  2. **模式 1／2，宽 5**：暂存拆分点为整数除法 2（左 2／右 3），不是向上取整 3；宽 1 时拆分点为 0，不能假设常规双侧导航成立。
- 初始即完成：模式 3／4／5／6／7 均未排斥（§5）→ 打开即完成序列；模式 1／2 不可能（块必先在暂存列，判定要求棋盘整序）。
- 空槽旋转拒绝：**未暂持块时**，模式 2／5 对空槽按 ACTION 无效果（空槽不产生旋转，直接略过）；暂持块在手时即使光标槽为空，也旋转暂持块（§4.2 暂持优先，TP15 对照）。
- 资源缺失：背景回退；主切图缺失与音效缺失的宿主行为具名保留（WP15 引用，未运行）。
- 异常路径：动画循环均为确定时长的呈现循环；输入在动画期间被忽略（呈现层，不积压为动作）。

1. 事件入口、奖励与 demo 可达性（U01）；核心脚本无调用者（检索未命中 ≠ 不存在于事件侧）。

4. 宿主输入重复延迟与帧时序（WP17 同类保留）；动画时长为呈现参数，未逐帧验证。
5. 模式表外值与异常棋盘参数（负、超大、位图不整除）的真实组合未验证（静态边界已列）。
6. U01–U10、WP78→WP79→WP80 出口保留；本稿与 WP68／69／70 不互为替代。
