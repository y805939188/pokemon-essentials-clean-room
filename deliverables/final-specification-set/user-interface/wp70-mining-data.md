## 内容与来源边界

物品数据中 48 个物品身份全部存在；REVIVE／MAXREVIVE 在口袋 2，其余 46 项在口袋 1。这是静态文本证据，未编译／加载物品数据。默认两口袋均无限槽、每槽 999；正常逐件领取有新槽空间。修改容量后的拒收场景见主稿。
