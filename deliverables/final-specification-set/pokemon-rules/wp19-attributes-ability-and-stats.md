# 属性派生、特性选择与六项能力（净化正文；批次 5）

分类：Pokémon Rules（属性派生与能力数值）。本文件定义个体属性与能力数值的确定性规则——哪些值是固定配置、哪些是覆盖、哪些由随机身份派生、哪些由公式计算；数值域、上限、取整位置、重算触发与写回。全部内容为静态证据；**无运行确认**（见 `../scope-statement.md`；全部数值为静态推导＋自有算术核对，未执行参考代码）。

## 1. 目的与范围

**目的**：供成长、战斗计算、繁殖、图鉴、界面展示等规格统一引用属性/能力规则，不再各自追踪个体数据。

**范围**：① 属性派生——类型、性别、异色（含超级异色）、特性选择、性格（含计算用覆盖）；② 六项能力与培养参数——等级↔经验接口、个体值（IV）/上限覆盖、努力值（EV）、能力计算公式、重算触发与当前 HP 写回、特殊物种/分支与配置变体。

**非目标**：不定义成长曲线目录与经验获取/等级成长流程（本文件只登记等级↔经验换算接口及曲线标识来源）；不定义学习/替换、友好度变更、进化、繁殖遗传、战斗内临时修正（能力阶级、变身、场地、特性触发效果）、捕获率/图鉴/展示排序；不定义动态形态处理器、Mega/Primal、Shadow 的 EV/经验暂存（各归相应规格）；不复制任何公式源码——公式以数学表达给出。

## 2. 概念与数值分层

- **属性**：类型、性别、异色、特性、性格等「标识性差异」。
- **能力**：六项主能力——HP、物攻、物防、特攻、特防、速度；由基础值、个体值、努力值、等级、性格修正共同决定。另有战斗专用项（命中率/闪避率，只用于战斗，归战斗规格）。
- **数值分层**（统一分类口径）：

| 层 | 含义 | 实例 |
| --- | --- | --- |
| 固定/配置 | 来自物种内容或配置常量 | 基础能力值、性别比例、成长曲线标识、等级上限、异色判定阈值 |
| 覆盖 | 显式设置的替代值 | 计算用性格（「薄荷」覆盖）、个体值上限标记（Hyper 标记）、「禁用 IV/EV 计算」配置（视为 0） |
| 派生 | 由身份/其它字段确定性或按规则计算 | 性别、异色、特性索引、性格、等级（由经验）、六项能力 |
| 随机条件 | 创建时随机生成或按概率重试 | 个体编号、六项个体值初值、野生异色重试、传说满个体、猎场重掷 |

- **有效个体值**：计算能力时使用的个体值＝上限标记为真时取上限值 31，否则取存储值（「禁用 IV/EV」配置下两者都按 0）。
- **计算用性格**：显式覆盖存在时替代表现性格参与计算（展示仍可用原性格）。
- **重算**：按当前输入重算六项能力与当前 HP 调整（§5.6）。

## 3. 属性派生

### 3.1 类型

- 个体的类型列表来自其物种/形态记录（形态记录在编译时继承或覆盖类型），读取返回副本（修改返回值不影响个体）。
- 兼容读取：第一位类型直接取列表首项；第二位类型在列表只有一项时回落为首项（兼容入口带弃用提示，计划移除）。
- 成员判定：给定类型标识（符号/字符串/记录）先按内容身份语义解析为规范标识，再做「任一匹配」判定；未知标识按解析失败处理。
- 边界：内容约定常见 1–2 项，但数据/读取层**不设两项硬上限**——编译只做去重/去空、不截断；读取返回完整列表副本；成员判定覆盖整个列表；兼容的第一/第二类型读取只取前两项（单类型时第二项回落首项）。战斗中的临时类型改变不写回本字段（战斗规格边界）。

### 3.2 性别

- 值域：`0` 男 / `1` 女 / `2` 无性别。
- **单性别/无性别物种**（比例记录没有女性概率）：固定映射——「仅男性」系 → 0；「仅女性」系 → 1；「无性别」系 → 2。
- **比例物种**：读取存储值；未缓存时派生——
  1. 取个体编号的低 8 位（值域 0–255）；
  2. **低 8 位 < 女性概率** → 女（1）；否则男（0）。
- 女性概率配置表（比例标识 → 概率）：`1/8 → 32`；`25% → 64`；`50% → 128`；`75% → 192`；`7/8 → 224`。
- 设置入口：仅在物种非单性别时生效；`0/1` 直接设置，空值清除缓存（下次读取重派）；其它值忽略（无效果、不报错）。便捷「设为男/女」以 `0/1` 调用同一入口。
- 单性别物种上调用设置入口：直接无效果（不报错）。

### 3.3 异色与超级异色

- **判定**（首次读取时计算并缓存）：
  1. `a = 个体编号 ⊕ 拥有者编号`（32 位异或；拥有者编号取完整 32 位）；
  2. `b = a 的低 16 位`；`c = a 的高 16 位`；
  3. `d = b ⊕ c`；
  4. **异色** ⇔ `d < 阈值`；阈值＝16（机制世代 ≥6，默认世代 8）或 8（更早世代）。即概率 16/65536 ≈ 1/4096（或 8/65536）。
  5. **超级异色** ⇔ `d == 0`（同公式的**另一次独立计算**；与普通异色各自首次求值、各自缓存——普通异色查询不写超级缓存，反之亦然）。
- 设置入口：可直接写异色真假（写入后不自动重算）；「超级异色＝真」会强制异色为真；「超级异色＝假」**不清除**异色标记；此后普通异色缓存仍可被单独覆盖或清除——两缓存可并存任意组合（「d==0 ⇒ d<阈值」是数学蕴含，**不是**缓存状态的不变量）。
- 缓存失效：判定结果缓存于个体；个体编号或拥有者的改变**不自动**使缓存失效——需要重派时必须显式清除对应缓存再改输入；**两个缓存分别清除、互不影响**（野生异色重试流程即「先清普通异色缓存、再重掷个体编号、再读取」两步，归遭遇规格）。
- 边界：拥有者占位编号为 0 时仍按公式参与（异色与拥有者绑定，交接个体展示既有判定值）。

### 3.4 特性选择

- **索引**：0/1 为自然槽位；≥2 为隐藏槽位（第 n 个隐藏特性＝索引 n+2）。未缓存时按个体编号最低位派生：偶数 → 0，奇数 → 1。
- **解析顺序**（读取时；结果缓存）：
  1. 已有显式/缓存值 → 直接使用；
  2. 索引 ≥2：取「隐藏特性[索引−2]」；该槽位为空 → **索引回落**为个体编号最低位（0/1），继续第 3 步；
  3. 取「自然特性[索引]」；为空 → 取「自然特性[0]」；
  4. 两者均无（物种未定义特性）→ 结果为空。
- 设置入口：接受已存在的特性标识或空值（空值清除缓存、恢复派生）；未知标识忽略（无效果）。**不校验**该特性是否属于当前物种/形态（可形成覆盖值）。
- 索引设置入口接受任意整数（不校验范围）：负索引按容器语义取末项、≥2 且隐藏槽缺失时按第 2 步回落（静态推导）；设置时清除已解析特性缓存（索引即新写入值，保留待下次解析）。
- 派生读取：无参查询＝当前解析结果非空；带参查询＝当前解析结果与参数是否同一特性（比较语义接受符号/字符串/记录，引用内容身份语义）；「是否隐藏特性」＝索引 ≥2（**注意**：隐藏槽缺失回落自然特性时，该判定仍为真，与解析结果可能不一致——按行为记录）。
- 候选列表：返回「已定义的自然槽（0/1）＋已定义的隐藏槽（2+）」的（特性, 索引）对，跳过空槽。
- 物种/形态变更的缓存清理：物种设置清除特性缓存（索引保留）；形态提交入口清除缓存；简化形态写入**不清除**（见《动态形态与展示属性》）。
- 特性效果（战斗触发、野外效果等）归相应规格；本文件只定义「选到哪个特性」。

### 3.5 性格

- **派生**：未缓存时「索引＝个体编号 mod 25」，取登记顺序第索引项（登记顺序：HARDY, LONELY, BRAVE, ADAMANT, NAUGHTY, BOLD, DOCILE, RELAXED, IMPISH, LAX, TIMID, HASTY, SERIOUS, JOLLY, NAIVE, MODEST, MILD, QUIET, BASHFUL, RASH, CALM, GENTLE, SASSY, CAREFUL, QUIRKY），缓存结果。
- **修正表**：25 种里 5 种无修正，其余各为一项 +10%、一项 −10%；完整身份映射见下表，修正参与能力公式（§5.4）。
- 设置入口：接受已登记性格或空值；未知忽略。**若已设置计算用覆盖性格，则不触发重算**；否则设置后重算能力。
- **计算用覆盖（「薄荷」）**：接受已登记性格或空值（空值清除覆盖），设置后**总是**重算能力。计算用性格读取＝覆盖存在则覆盖，否则表现性格。
- 边界：无参的性格查询只检查**当前**表现性格缓存（不记录是否曾求值、也不触发派生）——缓存为空即为假：例如已有计算用覆盖时显式清空表现性格（该清空不触发重算，重算也不会填回），即使此前已求值；普通创建返回通常已为真。性格对 HP 无修正。

## 4. 等级与经验接口

- **等级读取**：缓存为空时按「成长曲线」由当前经验换算（换算为纯函数：给定经验 → 等级）；结果缓存。经验一旦写入即清除等级缓存。
- **换算函数**（接口语义，曲线目录归成长规格）：给定等级 n → 该等级最小经验 minExp（n）；给定经验 e → 最大档位 L 使 minExp（L） ≤ e < minExp（L+1）；e ≥ minExp（满级） → 满级。等级与经验界：minExp（1） = 0。
- **等级设置**：域 `[1, 等级上限]`（上限＝配置值，默认 100）；越界**报错**（提示含等级号）；成功时同时把经验写为该等级的最小经验并缓存等级。
- **经验设置**：直接写入并清除等级缓存（无钳制——副作用与钳制由调用者负责，如「经验累加」入口会把结果限制在 `[0, 满级经验]`，归成长规格）。
- **经验进度（展示用）**：满级 → 0.0；否则「（当前经验 − minExp（L））/（minExp（L+1） − minExp（L））」（浮点）。
- **边界（按行为记录，两入口分列）**：等级换算对非法等级（空/≤0）**返回一个错误对象**（调用方把它当数值使用才会失败）；经验换算对非法经验（空/负）**不返回错误对象**——其诊断文本引用了未定义的标识（该方法内可供读取的局部值只有参数本身），在文本求值阶段即发生名称解析错误。两者均为参考快照现状反例：记录行为、不修参考、不把反例当作未来实现必须保留的设计。

## 5. 六项能力与培养参数

### 5.1 数据分层与来源

| 输入 | 来源 | 责任 |
| --- | --- | --- |
| 基础能力值（六项） | 物种/形态记录 | 数据归个体/物种规格；计算使用归本文件 |
| 个体值（IV，六项） | 创建随机 0–31；后续按入口覆盖 | 本文件 |
| 个体值上限标记 | 默认空；外部设置 | 本文件（生效方式）；启用入口见 §8 未决 |
| 努力值（EV，六项） | 创建为 0；后续按入口增加/减少 | 本文件（域与上限）；分配流程见前向引用 |
| 等级 | 由经验换算（或显式设置） | 本文件接口；流程归成长规格 |
| 性格修正 | 由性格/计算用覆盖决定 | 本文件 |
| 禁用开关 | 配置（默认假） | 本文件（视为 0 的变体） |

### 5.2 个体值（IV）

- **域**：每项 0–31（上限常量 31）；创建时逐项均匀随机（0 至 31 含端点）。
- **存储**：六项键值的映射；**数据层本身不钳位**（任意写入原样存储）；已定位写入者均把值限制在域内（野生重掷、传说满个体、训练家数据、调试/编辑器范围）。存储应包含全部六项（计算入口不为缺失项兜底；缺失项进入算术会失败）。
- **有效值**：上限标记为真 → 31；否则存储值；「禁用 IV/EV」配置 → 0。
- **上限标记（Hyper 类）**：键值映射，默认空；语义＝「该项按 31 计算」；**仅**影响能力计算，不改写存储值、不影响展示中的原始 IV 排序/描述（展示入口按各自读取）。
- **特殊分支（生成侧，完整流程归遭遇规格）**：猎场/捕虫大会内野生个体最多重掷 4 次全项 IV 直至出现一项满值；传说/神话/究极异兽标记物种在世代 ≥6 配置下随机选 3 项设为满值；两者都触发重算。
- **未决**：正常游戏内设置「上限标记」的启用入口在核心脚本中未定位（检索未见写入者；接口存在但入口不明，见 §8）。

**原始 IV 的个性描述消费合同**：摘要以存储的六项 IV 选择描述，不读上限标记替代值、计算用性格或能力大小。并列最高时，以固定环序 **HP → 攻击 → 防御 → 速度 → 特攻 → 特防**，从个体编号 mod 6 的位置开始环扫，选首先遇到的最高项；相等的后续项不替换它。选中项的原始 IV mod 5 决定下表列。它与能力公式中 HP／攻击／防御／特攻／特防／速度的列序不同，不能借登记序号替代。性格文字／个性是否显示的 Shadow 阶段门及画面布局仍归 WP66A；此处提供数据合同供该消费者核对。

| 最高原始 IV 项 | 余数 0 的含义 | 余数 1 的含义 | 余数 2 的含义 | 余数 3 的含义 | 余数 4 的含义 |

### 5.3 努力值（EV）

- **域与上限**：单项 `0–252`、六项合计 `0–510` 是**培养/增量写入者**的保证（战斗获取、培养道具、调试等），**不是所有正常写入者的全称保证**——已批准的设施/工厂模板创建是正常入口例外：按「EV 总额 ÷ 努力项数」整数分配（2 项各 255、3 项各 170），不使用单项 252 常量夹限（GR-016；设施规格已按同一白名单批准范围记录该行为）。
- **存储**：六项键值的映射；创建为 0；数据层本身不钳位，上限由**培养/增量**写入入口的「按剩余空间夹限」模式保证——通用模式：「单次增量 → min（增量, 252 − 该项现值, 510 − 当前合计）」（战斗获取/道具/调试等入口一致）；**Shadow 暂存分支**先计入「已暂存 EV」并入总量、单项剩余按「252 − 当前值 − 已暂存值」夹限（归 Shadow 规格）；**设施/工厂模板创建不经该夹限模式**（直接按总量整数分配写入）。
- **计算使用**：`⌊EV / 4⌋` 进入能力公式（取整发生在这里；不足 4 点不产生增量）。
- **已定位写入者目录**（规则细节归各入口规格，本文件只登记上限模式与消费者；**除设施/工厂模板创建外**，以下均为 252/510 夹限模式）：
  - 战斗击败获取（病毒「已感染或已治愈」阶段使本次获取翻倍；另有持有物侧的获得修正入口；Shadow 成长暂存写入「暂存 EV」而非当前 EV）；
  - 培养道具（维生素类单次 +10；**默认配置（世代 8）不受 100/项限制**、仅守单项 252/总 510；「100/项封顶」是设置关闭（较早世代配置）的变体；工具函数形参默认不等于道具入口的默认实参；羽毛类小幅；EV 降低树果下调）；
  - 训练家数据（未给定 EV 时按等级推导：`min（⌊等级×3/2⌋, 85）`）；
  - **设施/工厂模板创建（正常入口例外，GR-016）**：逐项整数分配写入——对非空、由**互不重复的有效努力项**构成的模板，设总额为 E、项数为 n，每个指定项得 `⌊E/n⌋`（默认 E=510：2 项各 255、3 项各 170、4 项各 127）；新个体这些项合计 `n × ⌊E/n⌋`（仅当 n 整除 E 时等于 E），其余项仍为 0，**未分配余数不自动补到任一项**（无「合计恒为 E」保证；此公式不无条件推广到重复项配置，重复项目录未展开）；**不用单项 252 夹限**；默认数据即含双努力项模板（具名样本见审计）。调试。「禁用 IV/EV」配置下存储仍存在、仅计算视为 0（不能借配置把存储规范化）。
- **边界**：EV 修改后由写入者调用重算（§5.6）；EV 数值本身不影响经验/等级。

具名反向对照：固定默认设施模板第 5 行 **CATERPIE／FOCUSBAND／QUIRKY／HP,ATK／TACKLE,STRINGSHOT**，合法 L50、六项 IV31、默认 E510，普通设施/工厂创建正常返回后 HP 与攻击 EV 各 **255**，其余 0、总量 510；重算保留存储值，两个计算项均取 ⌊255/4⌋=63。培养道具仍受 252/510 额度门；不能将 WP28 的培养门写成所有正常写入入口的保证。生成器对含重复 EV 条目的规则另归 WP76，未由此二项样本扩张。

### 5.4 能力计算公式

**输入**：基础值 B（物种）、有效个体值 IV、努力值 EV、等级 L、性格修正 N、HP 特例与配置开关。所有除法为「整除下取整」（⌊·⌋），不存在四舍五入。

**HP 上限**：

```
若 B = 1（特例物种）：HP上限 = 1（与 IV/EV/L/配置无关）
否则：HP上限 = ⌊ ((2B + IV + ⌊EV/4⌋) · L) / 100 ⌋ + L + 10
```

**其它五项能力**（含性格修正；N ∈ {90, 100, 110}）：

```
内层 = ⌊ ((2B + IV + ⌊EV/4⌋) · L) / 100 ⌋
能力 = ⌊ ((内层 + 5) · N) / 100 ⌋
```

**性格修正 N**：以 100 为基准，对该性格的每项变化累加（+10 → 110，−10 → 90；无变化 → 100）。

**变体**：「禁用 IV/EV」配置 → 公式中的 IV 与 EV 都取 0（存储值保留，其它用途如展示/隐藏力量类判定仍读原值——后者归相应规格）。

**取整位置**（不变量）：① 先 `⌊EV/4⌋`；② 乘等级后整除 100 取整一次；③ 加 5 后乘性格修正再整除 100 取整一次。任何一步的取整顺序变化都可能改变结果（不可交换）。

**HP 特例**：基础 HP 为 1 的物种（经典特例「脱壳忍者」）恒为 1。

### 5.5 重算触发与当前 HP 写回

**重算动作**（单一入口，行为固定）：

1. 取当前基础值/等级/有效 IV/EV/计算用性格；计算六项。
2. 上限替代：新 HP 上限覆盖旧值；其余五项全部覆盖为计算值。
3. **当前 HP 调整**（唯一写回点，与持久 HP 规格衔接）：
   - 若当前 HP > 0：`新HP = max（当前HP ＋（新上限 − 旧上限）, 1）`；
   - 若当前 HP = 0：**仅当**上限增加时 `新HP = 新上限 − 旧上限`（>0）；否则保持 0；
   - 最终值再按持久 HP 的赋值规则钳到 `[0, 新上限]`。
   - 推论（静态）：已濒死个体在上限增加的重算中会被「复活」为增量值；上限不变或减少时保持濒死；存活个体的最小值为 1（不会因上限减少而被打成 0）。
4. 不改变输入值本身：经验值、招式与 PP、异常与计数、友好度、来源/拥有者、个体数值输入（IV/EV/性格存储）、个体标记。注意**缓存填充**不属于「修改输入」但会随读取发生：重算读取等级（缓存为空时按经验重派并写入）与计算用性格（无覆盖时求值并缓存表现性格）。

**触发点目录**（已定位；写入者的完整流程归各入口规格）：物种变更/形态变更（三入口）；性格设置/计算用性格设置（覆盖存在时表现性格设置不触发）；创建末尾（含形态复检后的二次）；等级/经验变化（升级逐级、经验糖果、设施等级调整）；EV/IV 变化（战斗获取、道具、遭遇重掷、传说满个体、训练家装载——写入者负责回调重算）；拥有者/形态/变身与战斗刷新（战斗初始化/刷新、伙伴注册、捕获后形态清理）；战斗退出上限钳制（不重算，仅钳 HP）。

### 5.6 特殊物种与分支

| 分支 | 行为 | 归属 |
| --- | --- | --- |
| 基础 HP = 1 的物种 | HP 上限恒 1 | 本文件公式特例 |
| 传说/神话/究极异兽 | 3 项满 IV（世代配置） | 遭遇规格（生成） |
| 猎场/捕虫大会野生 | IV 全项重掷 ≤4 次至出现满值 | 遭遇规格 |

| Shadow 的 EV/经验暂存 | 不进入当前 EV/经验（暂存字段） | Shadow 规格 |

## 6. 规则与不变量

1. 六项能力的唯一计算入口为 §5.4 公式；HP 特例（B=1）与配置变体是仅有的两处替换。
2. 取整顺序固定，结果对同一输入确定；无浮点参与。
3. 属性（性别/异色/特性索引/性格）由个体编号（异色另加拥有者编号）派生；派生结果缓存，缓存不因输入变化自动失效；**普通异色与超级异色是两个独立缓存**。
4. 性别的显式设置只接受 0/1/空值；单性别物种不可设；特性/性格的显式设置只接受已登记标识或空值，未知忽略。
5. IV 域 0–31、EV 单项 ≤252 且合计 ≤510——此为**培养/增量写入者**的保证；存储层不钳位、由写入者保证；**设施/工厂模板创建为已批准正常入口例外**（按总量整数分配，单项可达 255，GR-016）。
6. 上限标记只改变计算用量（31），不改存储；计算用性格只改变计算，不改表现性格。
7. 重算写回当前 HP 的规则唯一（§5.5.3）；重算不改变其它字段的**值**（但读取会填充等级/性格等缓存）。
8. 等级域 `[1, 上限]`，设置越界报错；经验换算不在写入时钳制。
9. 能力计算使用形态记录（简化形态）的基础值/属性；动态形态的取值时机由《动态形态与展示属性》定义。

## 7. 边界与失败

- 等级设置越界：报错（含等级号），状态不变。
- 经验换算非法输入（空/负）：**不返回错误对象**，在诊断文本求值阶段发生名称解析错误；等级换算非法输入（空/≤0）返回错误对象（§4，均为参考快照反例，不作未来要求）。
- 性别设置：单性别物种无效果；越域值（如 2、负数、字符串）忽略；无报错。
- 特性/性格设置为未知标识：忽略、不报错；特性设置不做物种归属校验（覆盖）。
- 特性索引显式设为任意整数：不校验（负值按容器语义取末项、≥2 缺隐藏槽时回落）。
- IV/EV 存储缺项或超出域（绕过写入者直接写入）：计算入口不兜底，缺项进入算术会失败；超域值按原值参与公式（行为静态推导，正常**培养/增量**入口不产生该状态；**设施/工厂模板创建可正常产生单项 255**——同样按原值参与公式，⌊255/4⌋=63 与 ⌊252/4⌋ 相同，GR-016）。
- 无参性格查询检查**当前**缓存（与是否曾求值、是否发生过清空无关：清空且保留覆盖时不重派）；「是否隐藏特性」与解析结果可能不一致。
- 超级异色置假不清除普通异色；普通异色缓存可被直接覆盖或清除，两缓存互不同步、可并存任意组合。
- 「禁用 IV/EV」配置下，依赖 IV/EV 的非计算用途（展示/特定判定）仍读原值——各消费者的读取口径不在本文件声称统一。
