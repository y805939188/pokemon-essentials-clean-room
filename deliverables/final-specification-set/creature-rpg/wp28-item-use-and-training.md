# 主动道具与培养/教学行为规格（净化正文；批次 9b）

分类：creature-rpg（使用资格/消耗与上下文分流）＋ Pokémon Rules（培养/教学数值语义）；性质：实现独立行为合同。

本规格为净化正文：按统一交接将批准输入 WP28《主动道具与培养/教学》转写为独立行为文字，不含源文件路径、类名、行号与证据 URL（参考与已读集中登记于 `../../audit/source-traceability.md` 批次 9b 条目）。文中保留的字段名、入口身份名、物品身份名与配置键均为数据标识，不构成未来实现的数据结构或接口模板。全部内容为静态证据；**无运行确认**（见 `../scope-statement.md`）。

## 1. 目的、范围与非目标

### 1.1 目的

定义「玩家主动使用道具」的完整边界——四类使用上下文（背包、野外、个体、战斗）的入口、资格、数量/目标选择、确认、效果、返回、关闭与消耗时机；处理器注册表的机制与覆盖目录；治疗/复活/PP、EV 与培养、经验糖果、机器/教学、进化道具与主要特殊道具族的资格与失败语义。

### 1.2 范围

1. 使用上下文分流：背包/野外/个体/战斗四类入口的可见性、资格、数量、确认、效果、返回、关闭与消耗时机。
2. 处理器注册表：注册家族、条件注册、复制（别名）、查找顺序、无处理器/未知目标的分支归属。
3. 主要效果族：治疗/复活/PP、EV 与培养（维生素/羽毛/降 EV 树果）、经验糖果、机器/教学、进化道具（引用 WP31）、主要特殊道具（形态/战斗用）的资格、效果、失败与消耗。
4. 交界登记：球库存与消耗（捕获判定引用 WP38/WP40）、持有效果（WP50）、学习主规则（WP30）、形态（WP21）、容器（WP27）。

### 1.3 非目标

- 不定义捕获计算与战斗投球合法性的完整规则（WP38/WP40；本规格只登记球的入口与消耗链）。
- 不定义被动持有效果与触发规则（WP50）；不定义战斗内时序/等待（WP42）与战斗界面完整交互（WP67-A）。
- 不定义学习/替换/遗忘/PP 增长的主规则（WP30、WP20；本规格定义使用资格与消耗，效果引用）。
- 不定义进化条件与提交（WP31；本规格定义道具入口的资格/消耗交界）。
- 不定义形态组合的完整规则（WP21）、树果种植（WP60）、邮件流程（WP64）、树果/覆盖物的收获消费（WP60）；不设计未来框架的道具效果 API。

## 2. 概念与术语

| 术语 | 定义 |
| --- | --- |
| 处理器 | 按物品标识或「条件类别」注册的效果过程；同一物品可分别注册于多个使用家族。 |
| 处理器注册表（10 个家族） | 使用文本、背包使用、野外确认、野外直用、个体使用、个体使用上限、战斗可否使用、战斗直用、战斗对个体、战斗对场上个体（§3）。 |
| 条件注册 | 以「类别名 + 条件过程」注册，对任何满足条件的物品生效（样本：进化石、球、机器）；查找时在直注册未命中后按注册顺序求值。 |
| 复制（别名） | 把某一物品已解析的处理器复制到其它物品标识（样本：POTION→BERRYJUICE；AWAKENING→CHESTOBERRY）。 |
| 使用上下文 | 背包（含队伍选择）、野外（大地图/快捷菜单）、个体（队伍界面）、战斗。 |
| 资格 | 界面是否提供入口（家族存在性）+ 使用时的可生效判定（处理器返回）。 |
| 消耗时机 | 入口层在处理器返回真后按物品消耗属性扣减（非战斗）；战斗在登记使用时即扣减、无效果时退回。 |
| 未命中分支 | 无对应家族处理器（入口不显示/默认放行）与物品数据缺失（数据层失败）分开归属。 |

## 3. 使用上下文分流

### 3.1 处理器注册表机制（静态核对）

| 家族 | 用途 | 查找顺序与触发 |
| --- | --- | --- |
| 使用文本 | 背包「使用」命令的自定义标签 | 直注册 → 条件注册 |
| 背包使用 | 背包内直接使用（含机器教学）返回 0/1/2 | 直注册 → 条件注册 |
| 野外确认 | 快捷菜单野外使用前的确认（默认真） | 无处理器视为真 |
| 野外直用 | 大地图直接使用返回真/假 | 无处理器返回「未找到」（−1） |
| 个体使用 | 对个体使用（数量， 个体， 界面）返回真/假 | 无处理器返回假 |
| 个体使用上限 | 数量选择上限（默认 1；受「一次多量」配置门控） | 取 max（结果， 1） |
| 战斗可否使用 | 战斗内资格（默认真） | 无处理器视为真 |
| 战斗直用 | 对场上/无目标使用（球、娃娃、护身） | — |
| 战斗对个体 | 对队伍成员（或招式）使用 | 无处理器返回假 |
| 战斗对场上个体 | 对场上个体使用（X 道具、笛） | 无处理器返回假 |

- 查找规则：直注册优先；未命中时按注册顺序对条件注册求值，首个条件为真者生效；类别名本身不参与物品匹配。
- 复制在复制时的已解析结果（含条件注册结果）到目标标识；此后两者独立。
- 无处理器归属：背包「使用」命令仅在 背包使用/野外直用/个体使用 三者至少一个存在（或机器且有队伍）时显示（引用 WP27）。「背包使用」缺失时背包仍可回退到「野外直用」执行（工具把野外效果的真/假折叠为 1/0 返回）；只有野外直用处理器的 Direct 物品即由此路径使用。快捷菜单的收集（已登记且仍持有）不重新要求野外处理器——登记门（野外处理器存在）属于 WP27 的三层规则，本规格不改变。战斗内「可否使用」无处理器默认放行。
- 未知目标归属：物品数据标识未知时由内容层处理（WP03 引用）；处理器集合中不存在的标识即未注册，无隐式兜底。

### 3.2 背包上下文

1. 命令可见性见 §3.1；「使用」文本可来自使用文本家族（样本：自行车显示「骑」/「下车」）。
2. 使用分派（按物品数据「野外使用」字段）：
   - 对个体（OnPokemon）：无可用个体的检查只统计玩家队伍中的非蛋成员（不含盒子）——只放行「队伍非蛋数 > 0」；检查通过后打开队伍选择（进化石先为每个成员标注「可/不可」，由 WP31 的检查计算）；选择后：空个体/蛋/超级模式下的非香类 → 跳过该次选择；数量选择（当「一次多量」开且上限家族给出 > 1；数量初值 1，持有数量只参与多量选择上限，不是独立前置守卫）；执行个体使用家族；返回真且物品为消耗品 → 扣减 qty 个；背包耗尽 → 提示「用完了最后一个」；返回假 → 提示由该次执行的具体分支/效果负责（包装没有「所有失败统一无效提示」），留在循环。
   - 循环返回值语义：按最后路径记录（本次会话最后选择的出口），不是「整段会话是否曾成功使用」的累计值——已成功使用一件后再取消 → 返回 0，但此前的效果与扣减已经发生。
   - 直接工具契约（与正常界面分开）：直接调用个体使用工具时没有独立的「库存为 0 即拒绝效果」守卫；移除结果也不检查。库存保证只存在于界面路径（数量上限与持有量取小）。
   - 野外直用/机器（Direct 或机器）：走「背包使用」家族；其缺失时回退「野外直用」家族执行（§3.1）；机器无招或无个体 → 提示；返回 1 → 按消耗属性扣减 1；返回 2 → 关闭背包（野外使用）；返回 0 → 无事发生。
3. 返回值：0 = 未使用、1 = 已使用、2 = 关闭背包到野外再使用（界面据此退出，引用 WP27）；按第 2 条「最后路径」语义取值，不是整段会话的累计成功值。

### 3.3 野外上下文

- 入口一（快捷菜单）：收集条件 = 已登记且仍持有（不重新要求野外处理器；登记门归 WP27 的三层规则）；使用前经野外确认家族（默认真；只有该菜单路径使用），确认通过后执行野外直用工具。
- 入口二（暂停菜单等）：背包退出后的登记物品野外调用直接走工具（不经确认家族）；两入口不合并为同一「登记＋确认」流程。
- 顺序与返回（两层分开命名）：内层家族把效果真/假折叠为 1/0、无处理器为 −1；外层工具处理提示与消费后返回 false（对应 −1）/ false（对应 0）/ true（对应 1）——只有 −1 由外层补「这里不能使用」；效果返回假（0）时外层 false、不消耗、不自动补同一提示（提示由效果自身负责）。
- 主要野外效果（样本）：驱虫喷雾（步数 100/200/250 + 步数计数减少；耗尽时提示并可直接选用同族另一件）、黑笛/白笛（遭遇等级或遭遇率方向，受配置）、甜蜜（调用香甜气息的普通遭遇入口；天气不允许或该处没有遭遇时可能不开始战斗，但物品效果仍返回真、入口层按其消耗属性扣减——「玩家期望结果未发生」不等于效果假）、离洞绳（回逃脱点；有同行者不可用；传送前取消载具；用后清除逃脱点）、圣灰（全队复活：无个体/无濒死 → 失败；淡出淡入内逐个治疗；成功才消耗）、自行车（上下车资格）、钓竿/地图/硬币盒（打开对应功能）、探测仪（搜索及响应见 §3.3-R01）、经验共享开关（背包内替换为「关」版本物品）。
- 登记用途限于野外快捷使用；登记/取消与图标归 WP27。

### 3.3-R01 探测仪：搜索、方向与三路响应

适用默认 ITEMFINDER，以及已登记且绑定相同效果的 DOWSINGMCHN／DOWSINGMACHINE；静态效果绑定不证明每个别名都已在内容数据中登记。有效玩家、当前地图、事件集合、自开关和道具记录是前提；提示、音效请求、等待、转向正常返回，期间无事件／插件回调改变玩家、地图、候选或库存。方向实际变化还以角色未锁定方向为前提；锁定时转向请求可不改方向，不补解除锁定的规则。真实地图／媒体／时序运行未知。

**候选及选择。** 输入只取当前地图事件，保留当前事件枚举次序。事件名称包含 `hiddenitem`（大小写不敏感的子串，不要求整名恰等于它），与玩家坐标差为 dx、dy，且 |dx|≤7、|dy|≤5，自开关 A（当前地图身份＋该事件身份）不为真，才是候选。窗口是矩形，不要求圆形距离或寻路可达；不检查其物品身份、事件页当前可见性、朝向或是否正可互动。|dx|=8 或 |dy|=6 各自排除；另一地图的近处事件不参与。取 Manhattan 距离 |dx|+|dy| 最小者，距离相同时保留枚举中最先的候选；不以事件 ID 排序、不随机选，也不以欧氏距离替代。

**共同次序。** 已进入探测效果后，使用次数 `itemfinder_count` 先 +1，再请求名为 Itemfinder 的音效，之后才搜索。以下三路正常结束都返回效果真（外层野外工具按 §3.3 折叠为 1／true）；无响应并非使用失败。正常默认 ITEMFINDER、DOWSINGMACHINE 内容是 Direct／KeyItem，按既有非消耗属性不扣背包数量；其它合法别名的消费仍由其实际内容属性和外层入口决定。资源故障／等待异常没有已证明的回滚，不声称必返回真或能撤销此前计数。

| 搜索结果 | 方向及等待请求（秒） | 消息输出与返回 |
| --- | --- | --- |
| 无候选 | 不请求转向；没有本效果的 0.2／0.3 秒等待 | 显示四组省略停顿，组间／末段前各有一次 0.5 秒文本等待请求（四次），随后告知「没有响应」；正常提示返回后效果真 |
| 目标在玩家脚下（dx=dy=0） | 每次先等 0.2 秒再请求向右转 90°，共四次；之后等 0.3 秒 | 告知「探测仪指向脚下」；效果真。无锁定／回调时，四转后恢复原方向；请求等待合计 1.1 秒，不保证真实帧时长 |
| 目标在邻近位置 | 先请求朝目标转向；若 \|dx\|>\|dy\|，dx<0 向左，否则向右；若 \|dx\|≤\|dy\|，dy<0 向上，否则向下；再等 0.3 秒 | 先提示「探测仪有响应」并含暂停标记，再提示「附近埋着道具」；效果真。水平／垂直分量相等选垂直方向 |

文字等待以参数／20 秒解释，所以四次等待参数 10 各对应 0.5 秒；文本速度、确认输入、宿主刷新可再增加真实显示时间。近处首条的暂停请求不等于固定秒数，两条消息完成后才返回。

**副作用边界。** 探测效果本身不调用道具获取、不主动移除／启动候选事件、不写自开关 A、不改事件坐标；仅有上述使用计数、音效／消息／等待／转向请求及外层既有消费。WP75 的隐藏道具作者转换会生成名称匹配事件，并在实际拾取成功后写 A，是独立上游／拾取路径；这里不运行转换，也不要求本轮提供真实地图。相同距离的外部枚举次序属于兼容观察输入，未来实现的集合组织自由，但不能把选择差异隐藏为同一规则。静态设计 U03-IF01…U03-IF11 见道具测试目录，全部 NOT_EXECUTED。

### 3.4 个体上下文（队伍界面）

- 队伍界面「使用」入口：先选物品——列表过滤为「可对个体使用」（个体使用家族存在或机器），排除超级模式非香类；机器再过滤（已掌握或不可兼容者不可选）；选择个体后执行个体使用家族（数量、界面对象）。
- 机器路径：确认「要教 X 吗？」→ 通用版学习入口（引用 WP30；配方含机器标记）→ 学会才扣减（消耗品）。
- 一般路径：数量选择（同 §3.2 规则）→ 执行 → 返回真且消耗品 → 扣减 qty；返回假 → 提示不消耗。
- 训练/教学计数：背包侧机器流程（教学选择包装）在学会时计「机器教学」、非机器时计「导师教学」（WP06 目录）；队伍侧机器使用路径（直接学习入口）未定位同类计数——差异按真实调用链登记，不放大为统一契约。

### 3.5 战斗上下文

1. 战斗物品清单按物品「战斗使用」分为1/2个体／招式、3场上个体、4球、5无目标。登记前效果家族存在性守卫仅覆盖1/2（战斗对个体）及3（战斗对场上）；其统一前置检查空个体／蛋、Embargo及超级模式非香类。4/5不经过此存在性或统一前置守卫；4仍需目标下标，5取使用者。各路径随后都须取得目标个体并过「可否使用」家族（未注册默认真），不能声称所有类型缺效果处理器均被拦截。
2. 资格：可否使用家族（默认真）在登记前求值；不通过 → 停留在菜单。
3. 登记即扣减：登记选择时即从背包扣减（消耗品）；无法扣减内部报错（静态断言）。登记前的统一前置（空个体/蛋、Embargo、超级模式非香类）只覆盖各自路径，不等于执行时全部守卫重跑。
4. 执行（攻击阶段按已登记的选择分派）——对个体/对招式 → 战斗对个体；对场上 → 战斗对场上个体；球 → 战斗直用（投球，引用 WP38）；无目标 → 战斗直用。分支顺序：① 对个体/场上/无目标路径执行前重新调用「可否使用」资格复检；② 复检不通过 → 提示「但没有效果！」并尝试退回已扣减物品，选择中的物品消费身份仍保留；③ 复检通过 → 调用效果，正常返回后清选择中的物品消费身份（已扣减保持；效果处理器返回值不决定退款，失败提示由效果/界面负责）；④ 所需场上目标不存在 → 提示「不能在这里使用」并尝试退回，同样保留物品消费身份。退款本身不清身份，也不登记已经退过一次的幂等保证；后续清理按 §3.5.1 分开。投球分支独立：执行并清选择，捕获未成功不等于退球（球判定与完整时序归 WP38/WP40）。退回时背包无法容纳 → 内部报错（静态断言）。
5. 球：无目标/对敌；使用耗掉本回合全部行动（登记前后均强制「先制行动」）；战斗投球的其他合法性检查（战斗禁用球、场上有多个对方、场上个体半无敌、背包与盒子全满、抢夺球条件）登记于本规格目录，完整规则引用 WP38/WP40。
6. 战斗使用不涉及数量选择（每次 1 个）。

### 3.5.1 执行退款后的残留与同轮终局

资格失败（家族 1/2/3/5）和家族 3 目标缺失的退回路径，保留已登记选择中的物品身份。正常终局撤销尚有身份的物品选择时，只按消费属性、业主及当时退款容量再次退回，不因执行时已退款而跳过。进入下一命令阶段则对可出示命令者直接清选择，不退款；正式失能也直接清选择。成功效果正常返回后已清物品身份者，后续撤销不再退物。这些行为分别沿 WP40 §4.2 与 WP42 §6.0，不能把失败退款解释成已完成全部选择清理。

静态默认例：普通内部野生 2v1、无伙伴，两名玩家场上使用者始终存活且可正常选择物品。同队非场上可战斗成员 T 缺 1 HP，无蛋/查封/超频，POTION 库存恰 2；两次登记时 T 都未满 HP，允许指向同一 T，无取消/换人/插件/重入。登记扣至 0；按物品顺序首件请求 20、实际补 1 至满并清其物品身份；次件复检因满 HP 失败，退款至 1、其物品身份仍在。唯一野生普通中毒、毒计数 0、当前 HP1，无毒疗/魔法防守/恢复或其它结局源，本轮合法非伤害行动不改变这条链；回合末毒伤使其正式失能并裁判胜利 1，正常终局再次撤销次件选择，库存 1→2。最终 T 满 HP、一次实际治疗、POTION2，治疗没有净库存消耗。

独立对照：仅让野生撑过回合末且无其它终局源，次轮命令开始直接清残留，库存保持 1；仅让第二使用者在终局前正式失能且无其它库存改变，其选择被直接清除，正常终局亦保持 1。仅把未执行选择正常取消则退回登记扣减，不能将其当作主例的第二次执行退款。每次退款都要求当时可加入：若执行退款或终局再次退款时容量门拒绝，局部内部报错，该次未加入；此前扣减、治疗或第一次退款不回滚，不保证后续继续收尾。默认例容量足够，有限容量/外部改变只作独立边界，未称默认背包自然必满。

这是固定参考的历史异常事实。未来独立实现保留重复退款或有记录地修正，留待用户在兼容性/实现阶段裁决；本规格不提供幂等修正实现。对应 U04-RF01–RF06 全部 NOT_EXECUTED，宿主输入、提示和演出未运行认证。

### 5.2 PP 与 PP 成长

主动 PP 补给只涵盖下表五种默认物品；LEPPABERRY（LEPPA）在此是场外／战斗背包主动使用，不是 WP50 的持有触发。两种上下文都先满足各自入口的通用门（§3），再判本表；**战斗要求目标非蛋且 HP > 0，非战斗没有这项存活门**，普通非蛋、非 Hyper 的濒死成员仍可从背包恢复 PP。此差异不扩大为所有道具的统一门，复活道具仍沿 §5.1。

| 物品身份／目标范围 | 非战斗资格（已过通用门） | 战斗资格（登记前） | 两上下文恢复量 |
| --- | --- | --- | --- |
| ETHER／所选招式 | 选择有效招式，且该招总 PP > 0、当前 PP 未满；不要求 HP > 0 | 先要求目标非蛋且 HP > 0，再要求相同选招与 PP 条件 | 所选招式 +10，封顶到总 PP |
| MAXETHER／所选招式 | 同 ETHER；不要求 HP > 0 | 同 ETHER（共用资格门） | 所选招式回满 |
| LEPPABERRY／所选招式 | 同 ETHER；不要求 HP > 0 | 同 ETHER（共用资格门） | 与主动 ETHER 同量：所选招式 +10 封顶 |
| ELIXIR／全部招式 | 至少一个有效招式总 PP > 0 且当前 PP 未满；总实际恢复量为 0 则失败；不要求 HP > 0 | 先要求目标非蛋且 HP > 0，再要求至少一个有效招式满足 PP 缺口条件 | 逐招 +10，各自封顶 |
| MAXELIXIR／全部招式 | 同 ELIXIR；不要求 HP > 0 | 同 ELIXIR（共用资格门） | 逐招回满 |

战斗中即使濒死目标有 PP 缺口，五种道具都在登记扣减之前拒绝：正常成员画面提交显示无效果并留在成员选择循环，未登记物品动作、库存与 HP／PP 均不变（WP40 §4.2、WP67-A §5.2–5.3）。单招三种取消招式选择也回成员选择，尚未登记、不扣库存；存活但所选招已满，或全招两种全部无可恢复 PP，同样不登记不扣减。登记通过才按 §3.5 扣 1；执行前资格仍保持时按本表恢复，原执行复检、退款与残留规则不变。

非战斗正常界面每次主动 PP 补给用 1 个：取消选招或无实际恢复则效果假、不消费；至少恢复 1 PP 才效果真，由外层扣 1。恢复本身不改变 HP，所以普通濒死目标在成功后仍 HP = 0，不能解释为复活。持久 PP 封顶与战斗同步沿 WP20 §5.4–5.5；AI 未提供招式索引的资格异常归 WP51，持有 LEPPABERRY 的选招、RIPEN 与消费归 WP50，均不套成本表的人工主动入口。对应 R4-U04-PP01…PP07 为静态向量，全部 NOT_EXECUTED。

- PPUP/PPMAX：需选择招式；招式总 PP ≤ 1 或提升计数已 3 → 失败；成功提升计数 +1/直接到 3（实际 PP 按 WP20 的派生规则体现）。
- 战斗版对队伍个体的 PP 回复需带上场个体同步（在场且未变身且招式一致时写穿，引用 WP20）。

### 5.3 EV 与培养（数值域与上限引用 WP19）

- 维生素（六种）：每次 +10；100 点阈值仅在世代 ≤ 7 生效（世代 ≥ 8 配置关闭该阈值）；始终受单项 252/总量 510 钳制。逐次应用，每次实际增加触发一次「维生素」友好变化。
- 羽毛（六种及其别名）：每次 +1；无 100 点阈值；仍受 252/510 限制；每次实际增加触发「羽毛」友好变化（WP30 引用）。羽毛与维生素共用数量三层结构（六种 FEATHER 各自注册数量上限家族、并复制给六种 WING 别名；上限处理器 →「一次多量」配置门 → 库存取小 → 数量选择 → 效果 → 按 qty 扣减），仅每份增量与阈值不同。
- 降 EV 树果（六种）：EV 按 10×数量一次合并减少并钳0，友好度逐份提升（WP30）。原始多量上限 = max（⌈该项当前 EV / 10⌉，按树果友好规则逐份模拟至255所需份数）；友好已255时后一项为0。模拟含获得地图、豪华球、安抚之铃加成（WP30 §7.2）。再过「一次多量」配置门：关则1，开则至少1；最后与持有量取小。EV0且友好255时效果失败。例：HP EV250、其余EV0、h255、POMEGBERRY25，默认多量开可选25，选25后EV0／h255／库存0；关则只用1，EV240／库存24。
- 三层分开（界面数量上限 / 效果实际应用 / 外层扣除）：效果辅助只返回布尔、不返回成功份数；正常界面先用上限家族限制可选数量（如仅能再增 20 EV 时维生素界面最大为 2）；外层在返回真时按传入的 qty 扣减——先成功后触限 → 已应用部分保留、整体返回真、按 qty（不是成功份数）扣减、不自动退差（不补回滚）。每次应用即时重算能力。
- 薄荷：当前用于能力的性格与目标相同 → 失败；确认（「可能影响能力」）取消 → 失败；成功仅改「用于能力的性格」并重算（表现性格不变，WP19 引用）。
- 能力胶囊/药膏：确认取消 → 失败；无第二/隐藏特性、已是隐藏特性或特例物种 → 失败；成功切换特性序号（胶囊在普通特性间切换、药膏改为隐藏特性）。
- 经验糖果：引用 WP30 的经验糖果入口：已满级或 Shadow →「没有任何效果」（不消耗）；数量 > 1 时先补 数量−1 次「维生素」友好变化（随后经验设置自身再触发 1 次，合计数量次）；各份经验合并为一次经验设置流（越级学招/进化检查各一次），不是逐份独立设置。钳制后非零经验差量先提示，再提交经验／友好／重算／刷新；同级变化也提示增减差量，按 WP30 §5.2 的等级门结束，不能写成仅跨级才提示。上限 = 按单位经验折算到满级所需次数。

- 稀有糖果满级分支：Shadow 拒绝；「满级可用」配置关或升级族无目标则效果假、不消费。配置开且有目标时，演出结束后效果返回真，包含动画中取消；等级／物种可保持，若动画内取消则取消统计+1，库存仍扣1；未取消走成功提交。糖果／个体／数量选择前取消则尚未进入该效果，不消费。已正确的 WP31 满级取消条款继续适用。

- 薄荷的计算用性格按 [WP19 §3.5 表 N](../pokemon-rules/wp19-attributes-ability-and-stats.md) 的完整25身份映射取五项修正，HP不修正；不重新设计性格表。合法 BULBASAUR 形态0、L50、IV全31／EV全0，无上限标记且禁用IV/EV关，表现性格HARDY、无计算覆盖：LONELYMINT确认成功后六项能力（HP／攻击／防御／特攻／特防／速度）为[120,75,62,85,85,65]；独立 BRAVEMINT 输入得[120,75,69,85,85,58]。表现性格仍HARDY；确认取消保持覆盖、能力和库存。

### 5.4 机器与教学

- TM/HM 不可消耗（重要物品，不入背包消耗路径）；TR 为消耗品（默认按非重要物品消耗）；数据字段界定三者（§8）。
- 教学流：选择个体（队伍界面过滤：蛋/超级模式非香类不合格；机器还要求未掌握且兼容）→ 确认 → 通用版学习（空槽直接学；满槽询问遗忘/放弃；机器且「保留旧 PP」配置时新招当前 PP 取旧招当前 PP 与总 PP 的较小值）→ 学会才扣减（统计按 §3.4 两入口分别登记：背包侧包装计统计、队伍侧未定位）；放弃/不可教 → 失败不消耗。
- 背包侧机器使用（野外直用/背包使用）：无可用个体（非蛋队伍为空）→ 提示；确认「要教给宝可梦吗」→ 队伍教学选择（每个成员标注 可学/已学/不可）；某一成员学会即结束并计统计；取消 → 返回 0 不消耗。
- 进化石：条件注册；Shadow 先拒；命中 → 不可取消的进化提交（WP31）；未命中 →「没有任何效果」；消耗在提交后由入口层执行。

- TR 最初招式记录按入口区分：背包机器使用经教学选择包装，成功后按招式身份去重追加到个体的最初招式记录，并计机器教学统计，再按消耗属性扣减；队伍 Item → Use 直接通用学习，成功消费但不追加最初记录、也不计该包装统计。已有记录不重复追加，取消／失败均不追加。身份取物品 FieldUse 与 Move，不凭名称猜测：默认 TM57 的 FieldUse=TR、Move=CHARGEBEAM。此记录随后由 WP30 §6.3 在配置开启时消费（存储规则见 WP20）。

### 5.5 战斗用与特殊道具（样本）

- X 攻击系（分档）：基础 X 攻击按配置升 2 阶（配置关 = 1 阶）；XATTACK2/3/6 分别固定 2/3/6 阶（同族其它属性同规则——普通版受开关、编号版固定数量），成功触发「战斗道具」友好变化。
- DIREHIT 系：集中于要害的计数已达标 → 失败；各档位独立注册（写 2/3 档对应计数）。
- MAXMUSHROOMS：资格检查攻击、防御、特攻、特防、速度五项，任一可升即可（不含命中）；执行时对各个可升项各 +1 并触发「战斗道具」友好变化。
- 娃娃系（无目标）：野生战逃跑成功；训练家战/不可逃跑 → 资格失败不消耗（登记前拦截）。
- 护身（GUARDSPEC）：读写的是白雾（Mist）侧状态（与「神秘守护」不是同一目标）；己方已有白雾 → 资格失败；成功设 5 回合并触发「战斗道具」友好变化。
- 笛：眠状态相关（红笛解着迷、黄笛解混乱、宝可梦之笛唤醒全场；音障特性免疫；无适用对象 → 失败）。
- 球：资格见 §3.5；投球动作与捕获计算归 WP38/WP40。
- 形态/融合道具：见 §5.6 有界使用表（本规格给出使用与库存输出；形态提交后的主规则引用 WP21）。

## 6. 规则与不变量

1. 入口层消耗：非战斗使用「处理器返回真 → 按物品消耗属性扣减」；战斗使用「登记即扣减、按资格复检/目标分支退回」（§3.5）。消耗属性 = 非重要物品且（数据未标注时默认消耗；重要物品永不消耗）。
2. 非战斗未命中／资格失败／选择或确认取消，且使用效果返回假时不扣减；已成功后再取消不撤销此前效果／扣减。稀有糖果满级分支是内层进化取消例外：已获升级族目标并进入可取消演出后，即使取消进化，使用效果仍返回真，外层照扣1；只阻止进化成功提交（WP31 §6），不阻止这次糖果消费。数量部分成功仍按传入 qty 扣减、不自动退差；战斗退款按 §3.5 的资格复检／目标分支，效果返回值不决定退款。
3. 数量：仅「一次多量」配置开且该物品注册了上限家族时提供数量选择；否则固定 1。战斗无数量。
4. 资格与效果分离：可否使用家族（界面/战斗前置）与使用家族（实际效果）可分别注册；同一物品在不同上下文可有不同家族组合。
5. 无处理器分支按上下文判定：非战斗入口可见性见 §3.1；战斗1/2/3有对应存在性守卫，4/5没有该全局保证。合法自定义无目标物品 I、BattleUse=Direct(5)、可消耗且非重要／非球／非抢夺物、各可用与效果家族均缺（含条件注册也不命中），内部战斗存活玩家使用者且库存1：Use可见、默认资格真、登记库存1→0；执行复检真，效果未找到无状态效果，仍清选择且不退款。把同物品改为1或3则登记前对应守卫拒绝，库存1保持。
6. 培养语义分工：100 点阈值只属于维生素（且按世代）；羽毛与战斗 EV 获得不受其限制。252/510 是培养／增量写入者从受限状态增加 EV 的额度门，不是存储或全部正常写入者的统一上限。见 [WP19 §5.3](../pokemon-rules/wp19-attributes-ability-and-stats.md)：设施／工厂模板直接按总额整除分配；默认 CATERPIE 的 HP、攻击两个互不重复努力项各255，总510，其余0；重算使用⌊255/4⌋=63，不把存储压回252。本文不运行模板生成或扩张重复项规则。
7. 前置分层：蛋（多数个体使用在入口或处理器拒绝；机器在入口过滤）、Shadow（进化石/糖果专用拒绝；通用学习拒绝，WP30）、超级模式（非香类个体使用被拒）。
8. 使用可能改变背包内的物品标识（具名效果）——融合工具组成功后替换（可用 ↔ 已用，§5.6）、经验共享开关野外使用后切换（EXPALL ↔ EXPALLOFF，§3.3）；形态类道具改形态（主规则引用 WP21），特性道具改特性序号，薄荷改「用于能力的性格」（WP19）；不保留「使用不改变物品种类」这类全局保证，实际状态按各具名效果与 §5.6 登记。
9. 统计：机器/导师教学、驱虫喷雾计数、进化相关统计分属 WP06/两包引用。
10. 战斗物品不触发「给予持有物」路径；被动持有效果与触发规则归 WP50。

## 7. 边界与失败

- 空队伍/无可用个体：个体使用与机器入口提示；圣灰提示「没有宝可梦」。
- 蛋与超级模式：入口过滤（个体使用家族多数不处理）；香类在超级模式例外。
- 满 HP／满 PP／无状态／未濒死是否拒绝取对应族及上下文：FULLHEAL族与FULLRESTORE战斗有仅混乱可用例外（§5.1），不是一律「无持久状态即不消耗」。
- 数量边界：上限家族返回0也经至少1处理，正常数量层取库存后按1进入效果；满级经验糖果失败，满级稀有糖果是否可进化及取消后的消耗另按 §5.3；「一次多量」关固定1。
- 部分成功：维生素/羽毛的中途触限 → 已应用保留、外层按传入数量扣减、不自动退差、返回真（静态；不补回滚）；羽毛每份 +1、多量与维生素同规则；树果 EV 一次合并、友好逐次。
- 战斗退回：复检不通过或目标缺失 → 退回；复检通过 → 效果返回值不控制退款；投球不因捕获失败退回；背包当时无法接收退款 → 内部报错，该次未加入；主例假定容量足够，不把容量门拒绝写成所有正常链均不可达（§3.5.1）。
- 直接工具边界：库存为 0 的直接调用没有独立拒绝守卫（界面路径才有数量上限保证）；移除结果不检查。
- 球的使用耗掉回合全部行动；训练家战与多对手场景的资格拒绝见 §3.5（完整规则引用 WP38/WP40）。
- 进化石在不可进化时「没有任何效果」且不消耗；可进化时演出不可取消（WP31）。
- 机器：已掌握/不可兼容/蛋/Shadow 在教学各阶段有拦截；TR 消耗、TM/HM 不消耗。
- 次数耗尽/背包无该物品：结算分支不再扣减并结束循环（背包上下文）。
- 未知物品标识由内容层处理（WP03）；合法物品缺处理器的结果按入口与类型分列（§6.5），不能统一写为不可用。
