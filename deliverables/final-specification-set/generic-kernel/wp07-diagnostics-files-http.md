# 诊断、文件与 HTTP（净化正文；批次 4）

分类：Generic Kernel（基础 I/O 与诊断）。本文件明确基础 I/O 的成功、失败与反馈——文件遍历/存在性/读写、HTTP 下载与提交、异常与错误的记录/提示/恢复分别在哪一层发生、以什么形式表现（异常、空结果、错误记录、用户提示）。全部内容为静态证据；**无运行确认**（见 `../scope-statement.md`）。

## 1. 目的与范围

**目的**：回答「某失败会如何呈现、能否被调用方区分」，供后续规格引用，而不追踪任何特定 I/O 包装的实现。

**范围**：① 文件访问层（遍历、存在性、读写、资源解析、保存目录）；② HTTP 下载/提交（GET/POST 分层、失败归一、响应使用与文件落盘）；③ 诊断与错误反馈（异常格式化、错误日志、调试日志、控制台、用户提示、调用前提）；④ 失败层次与边界（各层失败形式对照与共用面）。

**非目标**：不提取编译触发与编译失败副作用（《PBS 生命周期》）、插件错误机制（《通知、扩展与插件》，共用诊断面引用）；不提取资源选择与播放、神秘礼物等业务消费者、编辑器行为；不访问真实远端，不证明外部服务可用；路径与入口形状是参考侧取证记录，不是未来框架的文件/网络 API。

## 2. 概念与术语

- **文件访问层**：目录遍历、存在性探测、读写包装与资源路径解析（含加密归档感知）。
- **HTTP 包装**：下载（GET）与提交（POST）的薄封装及其失败归一。
- **诊断面**：异常格式化、错误日志文件、调试日志文件、控制台输出与用户提示的集合。
- **失败归一**：包装层把多种失败条件合并为同一返回值（空值/空字符串），调用方无法从中区分失败原因。
- **调用前提**：诊断函数的存在不等于所有模式下的全局保证；其实际生效取决于调用它的业务入口与模式（调试/非调试）。

## 3. 文件访问层

### 3.1 遍历与目录操作

- 目录列举（按过滤列举并排序）、递归整树列举、递归目录列举、逐级建目录、删除目标目录树（包括目标目录自身）。删除入口先删除递归列举的文件，再由内到外删除列举目录，最后删除目标根。对于存在的普通空目录 D，或仅含一个普通文件的 D，在权限允许、无隐藏残留/并发修改且所有调用成功时，最终 D 不存在、父目录仍存在。
- 删除入口不捕获操作异常，也没有撤回已删除条目的步骤；中途失败可留下部分删除。隐藏条目、链接及宿主差异未穷尽，不由“整树”一词保证任意输入都成功。翻译提取覆盖只删除列举文件并保留目标目录（《本地化》§6.2），与本删除入口分开。
- 带重音路径兼容的模式匹配；两个标记弃用的兼容包装（其弃用警告机制见 [wp07-deprecation-appendix](wp07-deprecation-appendix.md)）。

### 3.2 存在性与读写（逐入口的捕获集合、分支与返回形态）

| 入口 | 成功 | 失败形式（逐入口核对） | 分支差异 |
| --- | --- | --- | --- |
| 归档感知存在性探测 | 返回是否存在（加密归档感知，经一字节探测） | 不适用（布尔） | — |
| 首字节读取 | 非归档：返回文件首字节；归档：返回宿主原始读取结果 | 捕获文件缺失/参数无效/权限不足/**目标是目录**/宿主归档错误类 → **空值** | 非归档读 1 字节；归档分支直接返回宿主读取结果（形态不同） |
| 全文读取 | 返回文件全部内容 | 捕获文件缺失/参数无效/权限不足/宿主归档错误类 → **空值**；**不捕获『目标是目录』**——若为目录，异常不归一（可能向调用方传播） | 与首字节入口的捕获集合不同，不能互套 |
| 归档感知打开 | 打开文件 | 归一化路径后打开；失败行为未逐分支验证 | **非归档分支直接打开原输入**；仅归档分支先做路径归一化 |
| 可读性探测 | 文件可读且非空返回路径 | 否则空值 | — |

**失败归一的范围限定**：读取包装层对「文件缺失」与「读取失败/权限/目录错误」在**被捕获的异常集合内**归一为空值——但捕获集合按入口不同（『目标是目录』类只在首字节入口被捕获），调用方不能把「返回空值」一概当成「缺失」，也不能把未捕获异常当成空值（读取返回空值 ≠ 文件缺失；形如「读取结果或空表」的回退写法只捕空值返回，不证明文件缺失也回退——《内容身份、注册与 schema》同例）。

### 3.3 资源路径解析（资源路径候选与扩展名回退）

- 按扩展名候选查找（图像 png/gif；音频 wav/ogg/mp3/midi/mid/wma）；找不到时通用取路径入口返回原输入。
- 图像解析/音效解析：找到返回真实路径，找不到返回**空值**；位图名解析找不到则返回原输入。
- 资源路径枚举**始终产出本地根路径**（兼容性遗留；没有按打包归档切换的分支——归档行为在其他入口，不能嫁接到路径枚举）。
- 保存目录：宿主数据目录（OS 相关：Windows 为应用数据目录、Linux 为用户目录下 `.local/share`、macOS 为用户目录下 `Library/Application Support`）。

### 3.4 写入面（静态入口）

- 序列化保存（编译产物 .dat、插件预编译产物、地图登记、动画映射等，《PBS 生命周期》《通知、扩展与插件》引用）。
- 文件追加：`errorlog.txt`（异常日志，见 §5.1）、`Data/debuglog.txt`（调试日志，仅调试模式且内部版，见 §5.2）。
- HTTP 下载落盘（§4.1）：响应体写入指定文件。

## 4. HTTP 下载与提交（GET/POST × 基础/便利分层）

### 4.1 分层行为表

| 层 | 前置过滤 | 宿主调用 | 响应形态 | 非 200 | 成功写入 | 写入异常 |
| --- | --- | --- | --- | --- | --- | --- |
| GET 基础入口 | **无 http 前缀检查**——https 地址也被传给宿主（宿主实际协议能力未验证） | 宿主 GET（异常捕获仅包住该调用） | **非表结构响应原样返回**（非无条件空字符串） | 返回空字符串 | 指定文件名则写文件并返回空字符串；无则返回正文 | **可能向调用方传播**（写文件在捕获范围外） |
| POST 基础入口 | **仅 http:// 前缀检查**（当前实现下 https 被挡下；不由此断言 GET 同样拒绝） | 宿主 POST（异常捕获仅包住该调用） | 同上 | 返回空字符串 | 同上 | 同上（可能传播） |
| 便利入口（到字符串） | 同对应基础入口 | 调对应基础入口 | 返回数据 | 同基础 | 不适用 | 捕获调用范围中的普通异常 → 空字符串 |
| 便利入口（到文件） | 同对应基础入口 | 调对应基础入口 | 写文件 | 同基础 | **成功也返回空字符串**（不是「无返回值」） | 捕获调用范围中的普通异常（吞没） |

限定：无重试循环（层内深度参数未使用，不由此外推宿主内部策略）；外部服务可用性未验证；神秘礼物等业务消费者归其领域规格。

## 5. 诊断与错误反馈

### 5.1 异常与错误日志

- 异常类：**重启信号**（要求重启）、**事件脚本错误**（携带地图/事件定位的消息）。
- 异常消息组装：脚本超时 → 「脚本超时，游戏将重启」；文件缺失类 → 「文件 X 未找到」；回溯中的脚本段映射名称。
- 异常打印：格式化（版本、错误头配置项 `ERROR_TEXT`（默认为空，供第三方追加）、异常类、消息、10 行回溯（内部版 25 行））→ 追加写入 `errorlog.txt` → 打印完整消息（0.5 秒内按住 Ctrl 可复制）。**事件脚本错误是格式例外**：使用专用事件消息，省略普通异常类/回溯段。**日志写入未捕获失败**：若写错误日志本身失败，后续打印/复制提示**不能保证发生**。与插件错误输出同一模式（《通知、扩展与插件》引用同一诊断面）。
- 关键段包装：**重启信号/退出信号原样抛出**；其他异常打印；脚本超时额外抛重启信号（重启）。**原样传播仅限此类具体分支**（关键段包装、编译主流程等）：插件脚本执行入口的捕获包含重启/退出信号在内的全部异常，进入插件诊断/退出路径，不适用相同的原样重抛规则。

### 5.2 调试日志与控制台

- 调试日志：异常记录包装；累积日志（含 AI 调试带 `[AI]` 标记），仅**调试模式且内部版**时写入 `Data/debuglog.txt`。
- 控制台：调试模式输出窗口；标题/进度/错误/警告分级输出与着色；全局回显入口仅调试模式输出。
- 三层用户反馈：消息框（玩家可见）、控制台回显（调试输出，开发者可见）、错误日志/调试日志（文件，事后可查）——不同受众与持久性，不能混为一谈。

### 5.3 调用前提（诊断函数能力 ≠ 全模式保证）

| 模式/入口 | 异常路径 |
| --- | --- |
| 调试模式主流程 | 关键段包装：重启/退出信号原样抛出；其他异常打印（§5.1）；超时转重启信号 |
| 非调试主流程 | 直接调用主函数；其异常捕获仅针对脚本超时：**打印异常＋紧急保存后重抛**；普通异常按宿主未知行为处理，不能从异常打印函数的存在推出全模式日志保证 |
| 显式业务调用 | 编译器异常分支（《PBS 生命周期》）、插件脚本异常（《通知、扩展与插件》）等显式调用异常打印/插件错误输出 |
| 宿主未知行为 | 宿主对未捕获异常的显示：**未验证，不猜测** |

## 6. 失败层次与边界

| 层 | 失败形式 | 调用方可区分性 |
| --- | --- | --- |
| 文件读取包装 | 空值（在被捕获的异常集合内归一；『目标是目录』只在首字节入口被捕获） | 捕获集合内不可区分原因；未捕获异常不归一 |
| HTTP 包装 | 空字符串/空值（请求异常、非 200、成功空正文可同为空字符串；非表结构响应原样返回；基础写入异常可以传播，便利包装按其捕获范围处理） | 请求异常/非 200/成功空正文**不可区分**；仅基础写入异常与便利入口的捕获范围可区分；无重试 |
| 编译/内容错误 | 异常＋位置报告（文件/节/键/行）（《PBS 生命周期》） | 可定位文件/节/键/行 |
| 插件错误 | 输出＋直接终止进程（《通知、扩展与插件》） | 进程终止，无恢复 |
| 未捕获异常（调试） | 异常打印 → 错误日志＋打印；超时 → 重启信号 | 进程级处理；日志写入失败则后续输出不保证 |
| 未捕获异常（非调试） | 超时专门处理（打印＋紧急保存）；其余按宿主未知行为 | **未验证** |
| 调试日志 | 仅调试且内部版写调试日志文件 | 非用户反馈 |

边界：编译触发与失败副作用归《PBS 生命周期》；插件错误归《通知、扩展与插件》；资源选择/播放归《资源匹配、资源访问及声音》；神秘礼物下载归其领域规格；编辑器诊断归编辑器规格。**共享诊断函数或日志文件不意味着各层失败行为一致**——各层前提按本表分别成立。

## 7. 默认行为与配置变体

- **基线默认**：读取失败在捕获集合内归一空值；HTTP 基础入口失败归一空结果、写入异常可传播；调试模式异常经关键段包装处理；调试日志仅调试且内部版启用。
- **支持但未默认启用**：错误头配置项 `ERROR_TEXT`（供第三方追加的错误头内容，默认为空）；内部版 25 行回溯。
- **未验证组合**：HTTPS/代理/重试行为（无证据）；归档模式下的读取分支（无材料）；外部服务可用性；非调试模式普通异常的宿主表现。
- 参考快照行为、官方版本预期、未来目标分开标记；本文件只记录第一类。
