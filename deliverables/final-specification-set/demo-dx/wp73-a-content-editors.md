# 内容编辑器（物种/道具/训练家/元数据/图鉴列表）行为规格（净化正文；批次 15）

分类：demo-dx（主）／generic-kernel（数据目录 持久/编译反写交界）／user-interface（属性框架/列表器/选择器）；性质：实现独立行为规格。

本稿为净化正文的一部分：按统一交接将批准输入 WP73-A《内容编辑器》转写为独立行为文字，不含源文件路径、行号、脚本入口名与类名（源定位集中登记于 `../../audit/source-traceability.md` 批次 15 条目）。范围：属性编辑器框架与全部属性类型、训练家类型/训练家战斗/道具/物种/全局与玩家元数据/地区图鉴列表六个内容编辑器的输入、校验、取消、保存与反写合同；共享列表器与选择器。编辑器实现是作者行为要求的参考，不作为未来编辑器的布局或交互设计模板。全部内容为静态证据；**无运行确认**（见 `../scope-statement.md`）。

## 1. 目的、范围与非目标

**目的**：固定内容编辑器的规则合同——**每个内容编辑器读什么输入、按什么校验拒绝、取消时是否仍写入、编辑何时生效（内存/`.dat`/PBS 三层）、引用失效如何提示**。后续包据此判断「某次编辑实际落到了哪一层」，而不是各自重新追踪编辑器文件。

**范围**：1) 属性框架：属性列表编辑器的交互与保存提示合同；全部属性类型（数值/文本/布尔/枚举/列表/游戏数据引用/文件引用/地图坐标/复合结构）的输入、默认值、取消与格式化语义。2) 六个内容编辑器：训练家类型（＋新建）、训练家战斗（＋队伍属性与个体属性）、道具（＋新建）、物种、全局与玩家元数据、地区图鉴列表。3) 共享基础设施：列表器（图形/音乐/元数据/地图/物种/道具/训练家类型/训练家战斗）、选择器（物种/形态/类型/道具/特性/招式/球/数据目录 列表）、通用命令窗口与辅助工具（合法招式、文件安全复制、地图树）。4) 持久与反写：内存 运行登记数据 层 / `.dat` 保存与重载 / 编译器反写 PBS 三层的触发时机与取消丢弃语义。

**非目标**：不提取世界编辑器（WP73-B 主责：地图连接、地图元数据、地形标签、遭遇、指标与自动定位——同文件内的遭遇编辑器与地图元数据编辑器只登记归属）；不提取动画编辑器/组织器/导入导出（WP74——同文件内的动画组织器只登记归属）；不提取编译器全集与文件更名/文本抽取/工程转换（WP75）；不展开 数据目录 字段契约/编译校验全集（WP03/WP04 主责，本稿只引用编辑器调用点）。不重提取已通过规则：PBS 编译与反写生命周期（WP04）、个体/图鉴（WP18）、玩家/训练家（WP24）、背包（WP27）、物种/招式/特性数据语义（WP19/WP31/WP34）、遭遇数据语义（WP36）。同批待审合同不展开：调试入口（WP72，同批待审）。不运行编辑器/编译器/反序列化、不写 PBS/.dat/地图文件、不操作真实存档、不设计未来编辑器布局或 API。

## 2. 概念与术语

- **三层持久模型**：**内存 运行登记数据 层**（运行中的数据登记——所有编辑先落在这里）；**`.dat` 层**（保存入口把 运行登记数据 序列化写数据文件；重载入口从 `.dat` 整体重载并**丢弃内存改动**）；**PBS 文本层**（编译器反写族按 运行登记数据 重写对应 PBS 文件——WP04 引用）。**三类保存时机**（§4 逐项）：**逐条即时**（训练家类型/道具/物种/元数据——每次确认保存即注册＋保存＋反写）；**退出时确认**（训练家战斗/地区图鉴——编辑只动内存，退出时「Save changes?」确认才保存（＋反写），否则重载丢弃——**嵌套例外：训练家战斗新建流程中创建类型立即落盘并反写两份 PBS、可带出先前内存编辑；外层 No 只重载 `.dat`、不回滚已写 PBS**（§4.2，A-R01））；**子编辑返回决定**（嵌套属性编辑的「Save/Apply changes?」只决定该子结构是否回写进父编辑的编辑值）。
- **属性列表编辑器**：以「名称＝格式化值」逐行显示属性表；**USE** 调用该属性类型的设置入口并把**返回值直接赋给该槽**（设置入口的取消语义由各属性类型自定——多数返回旧值即不变，部分返回 空 即清空）；**ACTION** 对该槽**确认后重置为默认值（无默认值则 空）**（ReadOnly 除外）；**BACK** 结束编辑——带保存提示时给 **「Save changes?」Yes/No/Cancel**：Yes 返回真（调用方执行保存）、No 返回假（不保存）、Cancel 回到编辑；不带保存提示时**恒返回 空**（保存与否由调用方自行决定）。
- **属性副本与嵌套数据**：多数标量只改父编辑的局部值，父No丢弃；蛋招池进入时原地去重/排序、已有地图尺寸改宽可能共享同一数据，父No不撤销这些内存变化，档案不会因此自动写出。物种编辑取的是旧复数进化属性，该取值返回空，回落为空进化工作表；打开后父 No 不会发生旧稿声称的数字参数转文本。合法 A→B、B原有反向前身关系且终末的夹具：不编辑进化字段而保存 A，会用空表替换 A 的整进化列表（包括该记录的前身条目），注册与档案/PBS写出成功后 B 的旧反向关系仍留在当前注册/档案；没有即时全体反向关系重建。成功整批重新编译新 PBS 后才从新正向记录重建，B 的旧 A 前身消失。独立保留 C→D 数字参数的记录，PBS 写出使用实际单数 Evolution 属性，该导出分支才将相关嵌套参数转文本；不能归因于打开复数编辑字段。必要外部字段 Evolution 与旧编辑字段的兼容差异保留，源对象组织不作实现要求。
- **列表器与块循环**：列表器提供命令表/起始下标/取值/预览刷新；块循环中 **USE/ACTION 把选中值交给调用方处理**（编辑/删除），处理后重取命令表；**BACK 退出**。空表时直接返回取消取值结果。
- **ID 派生规则（新建类编辑器）**：名称 → é 转 e → 去掉非字母数字下划线 → 全大写；空 → 类型前缀＋序号（`T_%03d`/`ITEM_%03d`）；首字符非字母 → 加前缀；已存在 → 追加 `_1`…`_100` 去重；仍冲突 → 失败消息。
- **校验拒绝（不写入；A-R02 修订——可达性分开）**：训练家战斗编辑的校验分两级——**清空类型后属性返回空结果、外层立即结束该次编辑**（**不到错误消息**）；**名字为空与队伍为空**才分别给「Can't 保存…」消息并回到编辑；**改键冲突无唯一性拒绝**（先覆盖目标再删旧键——§4.2）；其它编辑器以属性类型自身范围与选择器约束为主（§3 表）。
- **引用失效的显示（A-R06 修订——分两型）**：**有保护**——Species/Item/Type/Move/Ability/TrainerType/SpeciesForm/数据目录选择 等格式化以存在性判定显示 **「-」**；**严格读取**——**球类选择、池内容格式化、训练家个体子编辑 格式化、天气与概率选择 格式化等直接取记录——**失效 ID 可抛异常**（人工/失效数据前提，不声称正常基线必然出错）；训练家图预览有局部保护回落空白，普通图形预览没有等价保证。**只影响显示或如实报错，不做级联清除**（§3.4）。
- **入口与可达性**：全部编辑器从调试菜单进入（WP72 入口表——调试门在调用侧；受限载入菜单同样可见）；脚本直接调用各独立入口走自身前提，不附加调试门。
- **已通过边界（必须继承，不重开）**：WP04（PBS 编译/反写/校验，含编译净化与值重铸引用点）、WP03（数据目录 字段契约/注册语义）、WP18/WP19/WP21/WP24/WP27/WP31/WP34/WP36（数据语义）、WP61/WP53/WP37、WP65、WP67-A/B、GR-001～016、WP23-N01。**同批待审依赖（引用其合同，不作通过结论——BATCH-R03）**：WP72（调试入口与工具归属——含归属更正：本稿为其 WP73-A 归属的主体）、WP73-B（世界编辑器——本稿为其复用遭遇槽属性的属主）。

## 3. 属性类型目录（按输入行为分组）

### 3.1 框架交互

- 逐行显示「名称＝格式化（当前值）」；描述窗跟随选中显示该属性说明。
- **USE**：把该槽当前值交给属性类型的设置入口，**返回值无条件赋回该槽**（各类型自行保证取消时返回旧值；返回 空 的类型即清空语义）。
- **ACTION**：非 ReadOnly 时**确认后重置**——有默认值写默认值、否则写 空。
- **BACK**：保存提示为真 → **「Save changes?」**：Yes＝返回真／No＝返回假／Cancel＝继续编辑；为假 → 直接结束且**返回 空**。

### 3.2 不可编辑与数值型

| 类型 | 输入 | 默认值 | 取消/边界 | 格式化 |
| --- | --- | --- | --- | --- |
| 不可编辑值 | 无（消息「此处不能编辑」） | — | 返回旧值 | 文本表示 |
| 只读值 | 无（消息「不可编辑」；ACTION 重置也豁免） | — | 返回旧值 | 文本表示 |
| 限位无符号数值（位数） | 数值（限位数、默认旧值或 0） | 0 | BACK返回夹限旧默认（如旧5返回5） | 文本表示 |
| 普通有界数值（上限） | 0–上限（旧值缺省 1） | 0 | BACK返回夹限旧默认（如旧7返回7），不清空 | 文本表示 |
| 可空有界数值（上限） | 0–上限、**取消 −1 → 空** | 空 | 取消即清空 | 值或「-」 |
| 非零有界数值（上限） | **1**–上限（旧值缺省 1） | 1 | 范围排除 0 | 文本表示 |

### 3.3 布尔/文本/枚举/列表型

- **普通是非确认**：确认询问（是＝真／否＝假）。**可空三态布尔选择**：True/False 选择，取消 → 空；显示 True/False/「-」。
- **通用文本**：自由文本（**最长 250**）；**限长文本（限长）**：限长文本。**道具名文本**：限长 30，默认「???」。
- **枚举选择（值表）**：枚举列表（取消保留旧值；默认 0）；另一常量名枚举入口在基线标注 **Unused**，不据此认定普通编辑器可达。
- **字符串集合编辑**：添加非空值，已存在只移动光标；可编辑或删除。字符串工作表去重包含当前项本身：单项非空 A 编辑后确认仍 A，或文本 ESC 返回旧 A，都命中自身并删除。Keep changes? Yes 将空表返回父槽，No 保留原集合；父保存门另算。修改为不与任何项相同的新值则保留修改项；空输入不进入这次非空去重。
- **双类型集合**：双类型槽——逐槽选类型后 **去重并去空**；**有变化且「Apply changes?」确认**才生效；默认 [NORMAL]。

### 3.4 游戏数据引用型（选择器取消＝保留旧值；失效显示分两型，A-R06）

- **单引用**：训练家类型选择、物种选择（**仅 0 形态**）、物种形态选择（含形态，显示 `名字_形态`）、类型选择（排除伪类型）、全表招式选择、物种招式选择（**合法招式优先**——物种升级/教授/蛋招并集排序在前，全招式表随后）、特性选择、道具选择、球类选择（球类子集）、可空性别选择（男/女，取消 → 空）、数据目录选择（按指定目录列出记录）。
- **物种招式预选**：物种招式选择把按名称排序的合法招式段放在按名称排序的全招式段前，重叠招式在两段各保留一次。默认在合法段非首位时保留该位置；在合法段首位时仍可能被全段的局部位置覆盖；仅在全段时也把全段局部位置直接当合并列表位置，不加合法段长度。夹具合法段 [A]、全段 [A,B,C]、默认 C，合并为 [A,A,B,C]，初始零基 2 实为 B，不移动确认返回 B；BACK 选择器返回空，父属性保留 C。必须先有合法物种，不能由默认值推定实际预选招式。
- **文件引用**：背景音乐文件选择／短音乐文件选择（音频列表器——**浏览时试听**、释放恢复原 BGM）、窗口图文件选择／人物图文件选择（图形列表器——**预览缩放显示**）；均取**去扩展名文件名**，取消/空保留旧值。
- **地图坐标**：选图/点选坐标取消保留旧值；附带朝向时四选2/4/6/8。区域图0个提示、1个直接使用、多个选择再点选。地图尺寸含宽与0/1有效格文字；未指定打开为宽0/空串，直接BACK也返回；实际进入宽数字框才限定1–30，原有共享尺寸父No不撤销内存改宽。
- **天气与概率**：天气类型列表 BACK 或选 None 返回空，父槽清空；选新类型 W2 后概率框 BACK 返回旧概率，没有独立取消哨兵，所以旧 W1/30 得 W2/30，而非空或 W1/30。正常确认 60 得 W2/60。返回先写父编辑槽，父 No 丢弃局部值、Yes 才按元数据保存链落盘；不由此断言当前地图已即时切换天气。

### 3.5 复合结构型（A-R05 修订——按子页是否询问分型）

- **无本页询问（BACK 直接返回给父页）**：**IV六维子编辑、EV六维子编辑、地图尺寸子编辑、训练家个体子编辑**——属性页关闭时**直接返回**（**没有本页「Save/No」选项**）；**已有IV/EV子结构可能共享，但返回还会把缺项补0**；**EV 超总额要求继续削减**（不能带着超限离开——这不是保存门，返回照样发生）。**父层是否落盘另算**（由父编辑的确认链决定）。
- **有明确保存询问（「Save/Apply/Keep changes?」）**：**基础能力子编辑、努力产出子编辑、字符串集合、双类型集合、数据池子编辑、升级招式子编辑、进化路径子编辑**——选 No 时**不把新编辑集合赋入父槽**（「确认才回写」只指新编辑集合）；**但池类进入时的原地去重/排序不被撤销**（§2 A-R04——有没有确认与有没有共享引用是两条独立条件）。
- **不与嵌套别名（§2 A-R04）混为一个事务**：无询问子页的返回值直接赋父槽；有询问子页选 No 时**不把新编辑集合赋入父槽**——**但入口对共享原集合的去重/排序仍保留**（A-R04 v4——新集合不赋回不等于父槽内容没有变化）；两者都**不直接等同落盘**。
- **基础能力子编辑**：各项 1–255（缺省 10）；保存确认才回写集合。
- **努力产出子编辑**：各项 0–255；**只保留 >0 的项**回写 `[stat, value]` 对。
- **IV/EV 六维子编辑**：按PBS顺序逐项，以可空有界数值输入；超EV总额要求继续削减。IV/EV 整字段未指定时，合法 L20 训练家按正常加载默认每项 IV10/EV30（无插件/钩子改写）。只打开相应子页立即 BACK，会把未指定变为显式六项 0；部分缺项或单项数值取消也在返回时补 0。子页没有本页 No，返回即赋父槽；父 No 仍不提交，父 Yes 注册后外层保存 Yes 才保存档案与反写，外层 No 重载。未打开且保持未指定是默认 10/30 对照。地图尺寸未指定打开即 [宽0,有效格空串]，直接 BACK 也返回它；宽数值框仅实际打开时限定1–30，不把未进入宽框的初始0改成1。
- **数据池子编辑**：蛋招、蛋群和特性三池均不允许重复条目。添加已存在的值只把光标移到该项；改为另一个已存在的值会删除当前项并移到已有项，选相同值或取消选择器则不改。可删除当前项。蛋群/特性保持手动顺序：ACTION+UP 在当前是数据项且后面有数据项时与后一项交换，ACTION+DOWN 在当前不是首个数据项时与前一项交换；添加入口不参与交换。蛋招工作表每次刷新按名称排序，换序后刷新仍恢复名称顺序。进入池页即对原集合去重，蛋招还先按条目标识排序；这些进入时的原地规范化即使后选 No 也保留。退出「Apply changes?」Yes 返回新条目标识列表，No 返回原集合，Cancel 留在子页；父页保存门另算。
- **升级招式子编辑**：等级＋招式对——**按等级排序**（同级才可换序）；添加（等级 0–最大、取消 −1；同等级同招式去重）；改等级/改招式（目标已存在时**删除本项**）；删除；退出 **「Save changes?」** 确认才回写。
- **进化路径子编辑**：每条由物种、方法与参数组成。添加依次选择物种、方法并编辑参数：被识别为道具、招式、物种、类型或特性引用的参数用对应选择器；无参数方法跳过。被识别为自由文本的参数最多250字符、去首尾空白，空结果为空；其余参数走0～65,535数值输入，非数值旧默认按0、BACK返回−1并变空，非空参数最终以文本返回。兼容方法ID **LocationFlag** 虽登记了文本参数类别，当前编辑入口实际走此数值路径，不能输入任意地区标志文字；不把登记意图当已实现、不修参考。可改物种、改方法、改参数或删除；改方法后参数重置为0，同方法与去重的先后限制见下一条。改动去重，命中已有路径会删除本项并移光标。退出「Save changes?」Yes 返回新路径表，No 返回旧表，父物种保存另门。参数显示无参数时省略、无法识别的枚举名仍按登记名显示、空值显示「???」。
- **进化工作表同值**：进化工作表的物种、方法、参数去重也包含正在编辑项；在本次会话新加一条合法记录，再确认相同物种/方法/参数会删除该项。同方法在参数重置为 0 前先按旧参数检测，所以不能假设同方法总会保留；实际换成未重复的新方法才把参数重置为 0。数值参数 BACK 返回 −1→空，跳过去重并保留项；不推所有取消删除。工作表 Save Yes 才接收新表、No 返回旧表，父物种保存与文件写出另外决定。
- **遭遇槽子编辑**（WP73-B 遭遇编辑复用）：`[概率(1–999), 物种/形态, 最低级, 最高级]`——新建缺省 `[20, 首个物种, 5, 5]`；**最低>最高时交换**；格式化 `概率, 名字[_形态] (Lv.a[-b])`。

## 4. 六个内容编辑器逐项合同

### 4.1 训练家类型（＋新建）

- **列表**：训练家类型列表（含 [NEW TRAINER TYPE] 项；预览图回落空白）。
- **USE（已有项）**：按编辑属性定义取各属性当前 PBS 值（空 且属性有默认值则先填默认）→ 属性列表（保存提示）→ **确认保存**：按 字段契约 形成登记记录（按外部节身份写ID）＋保留 `PBS文件后缀` → **注册＋保存＋训练家数据转换**（写训练家类型/训练家 PBS 并刷新类型名消息表）。**不保存**：内存与文件均不变（本次属性值丢弃）。

### 4.2 训练家战斗（＋队伍属性与个体属性）

- **列表**：训练家战斗列表（类型/名字/版本排序；预览训练家图＋队伍摘要文本）。
- **内存先行**：全部编辑/删除只改训练家 运行登记数据 并置 `已修改标记`；**退出时 `已修改标记` 且「Save changes?」确认 → 保存＋训练家数据转换；否则 `重载` 整体重载丢弃**。
- **USE（已有项，A-R02 修订）**：队伍属性设置——属性表：类型（训练家类型选择）、名字（通用文本）、**版本（0–9,999）**、败北台词、**最大队伍数个宝可梦槽**（训练家个体子编辑）、**8 个道具槽**（道具选择）；**校验可达性**：**清空类型后属性返回空结果、外层立即结束该次编辑**（**不到「未选类型」消息**）；**名字空与队伍空才回校验循环**（分别「Can't 保存. No name was entered.」／「…Pokémon list is empty.」）；通过 → 形成登记记录（队伍只收有物种的槽、道具只收非空槽、保留 `PBS文件后缀`）→ 注册；**改键冲突**：**改成已存在的（类型,名字,版本）键时先 注册 覆盖目标、再删旧键——无唯一性拒绝**（对照：A 改为已有 B 的键——内存只剩新 B、旧 A 删除；外层退出 No 仍可由 `.dat` 重载恢复）；**不得借新建 ID 去重逻辑推断编辑改键也去重**；置 已修改标记。
- **USE（新建项，A-R01 修订）**：先定义类型——**用现有**（列表）／**新建类型**（走 §4.1 新建流程——**该嵌套保存立即落盘**：注册＋保存＋转换反写两份训练家 PBS——**且会把先前仅在内存的训练家编辑一并带进 PBS**）／取消；名字（空 → 放弃）；**版本分配**（空闲版本分配——0–255 首个空闲，无 →「没有空间」消息）；新建训练家入口（save_changes 为假）**交互建队**：**首只必选**（循环直到选定——物种列表＋等级（1–最大、缺省 10））、**其后逐个「再加一只？」确认**（拒绝即结束——每只同样物种＋等级逐个选定）；随后编辑器自行形成登记记录 注册＋「已添加」消息＋已修改标记（**此步只动内存**）。**分层对照（A-R01）**：嵌套创建类型后中途放弃（名字取消/外层退出 No）——**类型文件与 PBS 反写已落盘保留**；外层退出 No 只重载训练家 `.dat`（内存编辑丢弃），**不回滚已写 PBS**；只用现有类型则全程无文件写入直到退出确认。
- **ACTION（已有项）**：严肃确认 → 运行登记数据 删除＋已修改标记＋消息（**文件层仍待退出确认**）。
- **训练家个体子编辑（单个宝可梦槽）**：物种（缺省 空）／等级（1–最大，**非零有界数值**）／昵称／形态（0–999）／性别／闪光／超级闪光／Shadow（可空三态布尔选择 三态）／**4 招式槽**（物种招式选择——**全空即野生招式表**，Z 键删除语义在说明中）／特性／特性位（0–99）／持有物／性格／IVs（同类 可空有界数值 子编辑）／EVs（**总额超 EV总额上限 循环要求削减**）／友好（0–255）／球（球类选择）；返回时**招式去重去空**；**物种为 空 → 整个槽返回 空**。
- **空物种招式分支**：新建空训练家个体槽，物种未选时四个招式字段已可选；选择任一招式先严格查该物种以生成合法招式，空物种导致本地失败，早于整槽结束时的无物种返回空守卫。不补自动禁用/提示修复，也不确定宿主异常画面。直接 BACK 结束空槽正常返回空；先选合法物种再开招式选择正常进入。失败前没有本次文件保存。

### 4.3 道具（＋新建）

- **列表**：道具列表（含 [NEW ITEM]；图标预览）。
- **USE（已有项）**：编辑属性定义 → 属性列表（保存提示）→ **确认保存**：字段契约 形成登记记录＋保留 suffix → **注册＋保存＋道具反写**（即时生效，无退出确认）。

### 4.4 物种

- **列表**：物种列表（**不含新建项**——`includeNew` 为假）。
- **USE（已有项）**：身高/体重以×10整数显示；保存时÷10回写，按字段契约形成记录、保留PBS后缀，合法参数按方法类型净化，再注册→档案保存→物种PBS写出→完成消息。物种编辑取的是旧复数进化属性，该取值返回空，回落为空进化工作表；打开后父 No 不会发生旧稿声称的数字参数转文本。合法 A→B、B原有反向前身关系且终末的夹具：不编辑进化字段而保存 A，会用空表替换 A 的整进化列表（包括该记录的前身条目），注册与档案/PBS写出成功后 B 的旧反向关系仍留在当前注册/档案；没有即时全体反向关系重建。成功整批重新编译新 PBS 后才从新正向记录重建，B 的旧 A 前身消失。独立保留 C→D 数字参数的记录，PBS 写出使用实际单数 Evolution 属性，该导出分支才将相关嵌套参数转文本；不能归因于打开复数编辑字段。必要外部字段 Evolution 与旧编辑字段的兼容差异保留，源对象组织不作实现要求。
- **ACTION（已有项）**：严肃确认 → 删除＋**立即 保存＋物种PBS写出**＋消息。

- **子编辑（单个图鉴，A-R08 修订）**：**进入先移除全部空项**再取编辑副本；条目列表（空 显示「----------」）；**Z+Up/Down 换序、Z+Right 插入、Z+Left 删除、D 清空**；点选条目：**Change species**（物种选择——**自动去除其它位置的同物种**保证唯一）、Clear、Insert、Delete；**退出返回全量去空、父层总是接收**——**子 No 也压空洞**（[A，空，B] 不作编辑选 No，主界面得到 [A,B]）；子 Yes 同理回写；**空表保存分支非终止**（删除末项直到末项非空——**空表没有终止条件：静态推导未运行**——空白新图鉴或清空全表后选 Yes 无法退出该循环，**不保证空表可正常保存**）；外层主界面仍有克隆与最终保存门（**外层 No 不写 `.dat`**）。

## 5. 共享基础设施

- **通用窗口**：小字体命令窗；一次性选择 USE 选定、BACK 取消，空表直接返回取消结果；块循环把 USE/ACTION 交给当前操作、BACK退出。删除尾项后光标保持在新命令数处，不钳到最后有效项，可见选中可能失效；不据静态读取推断像素表现。两键窗 USE 选定、BACK 返回约定的取消结果（可为正数或负数）。三键选择窗优先处理 SPECIAL 的专用请求；按住 ACTION 时 UP/DOWN 为重复触发请求，LEFT/RIGHT 为按下触发请求，实际换序/插删由各子编辑合同规定（数据池见§3.5，地区图鉴 RIGHT插入/LEFT删除见§4.6）。列表 ACTION 切换ID序/名称序，保持所选记录身份；按数据ID预选时匹配记录身份，按数字列表号预选时匹配该列表号。USE 返回可用的数据ID，否则返回列表号。
- **列表器**：图形文件列表（png/gif 扫描＋**预览缩放**、「无文件」消息）；音乐文件列表（wav/ogg/mp3/midi/mid/wma、**浏览试听、释放恢复原播放**）；元数据列表（全局/角色/新建三分）；地图列表（**地图树缩进显示**＋小地图预览；可选 [GLOBAL] 项返回 0）；物种列表（字母序、可选 [NEW SPECIES]）；道具列表（字母序＋图标）；训练家类型列表（字母序＋图像回落空白）；训练家战斗列表（类型/名字/版本三级排序＋训练家图与队伍摘要）。
- **选择器**：数据目录列表选择（按指定目录列记录，可附候选过滤条件）；物种列表选择（**只列 0 形态**）；物种形态选择（含形态 `名字_形态`）；类型选择（**排除伪类型**）；道具／特性／招式选择（全表）；物种合法招式选择（合法招式在前）；球选择（球类子集、**取消返回旧值**）。
- **工具**：合法招式计算（升级＋教授＋蛋招去重——WP34 引用）；文件安全复制（**存在且内容相同则跳过、不同则确认覆盖**——WP74 引用）；动画槽位分配（首个空槽/空动画位；**无空槽时集合调整为目标长度 10（不是增加 10 个槽位）并返回调整前长度**——**原长度超 10 时尾部被截断**；随后导入写到返回下标可重新扩展，但**被截断内容不恢复**（12 项均非空的集合：分配先截成 10、返回 12，写 12 号位时旧 10/11 号内容已丢失）——WP74 引用，A-R10）；地图树（按父子层级与地图顺序排序——WP11 数据引用）。

## 6. 生效时机与取消语义汇总（本稿核心问题）

| 编辑器 | 编辑落点 | 文件生效时机 | 取消路径 |
| --- | --- | --- | --- |
| 训练家类型（编辑/删除/新建） | 内存 注册 | **每次确认即** 保存＋训练家类型/训练家反写 | 属性列表选 No → 不写（标量槽位是本地副本——共享嵌套对象例外见 §2 A-R04） |
| 训练家战斗（编辑/删除/新建） | 内存 运行登记数据＋已修改标记 | **退出时确认才** 保存＋训练家类型/训练家反写——**嵌套例外（A-R01）：新建流程中创建类型立即落盘并反写两份 PBS（可带出先前内存编辑）** | 退出选 No → **重载 重载丢弃全部内存改动**（含删除）——**不回滚已写 PBS**；只用现有类型则全程无文件写入直到退出确认 |
| 道具（编辑/删除/新建） | 内存 注册 | **每次确认即** 保存＋道具PBS写出 | 属性列表选 No → 不写 |

| 全局/玩家元数据 | 内存 注册 | **每次确认即** 保存＋元数据PBS反写 | 同上 |
| 地区图鉴 | 独立编辑副本（子编辑进入先去空、退出全量去空——**子 No 也压空洞**，A-R08） | **退出时确认才** 持久化保存＋清缓存＋写地区图鉴数据 | 选 No → 克隆被弃；**空表保存分支非终止（静态推导未运行）——不保证空表可正常保存** |

| 无询问子结构（IV/EV/地图尺寸/训练家个体，A-R05） | **BACK 直接返回赋父槽** | 父层确认链决定 | **无本页 No 选项**（EV 超总额要求继续削减——不是保存门）；父层不保存则该次改动不保留（共享嵌套对象例外见 §2 A-R04） |

- **取消仍写入的情形（如实登记，A-R04）**：属性列表的 **ACTION 重置**与 **USE 赋值**在进入「Save changes?」之前就已写入**本地属性值**——多数槽位只影响内存副本；**但共享嵌套对象（蛋招池/已有地图尺寸；旧复数进化取值例外见§2）的原地操作不等待父层确认即可改变运行内存**（§2——**不写 `.dat` 但内存可变**）；真正落盘都经上表确认链或 §4 逐项即时链。**外层取消不撤回嵌套创建类型已写入的类型文件与 PBS**（§4.2 已具名）；**不保证整个被取消流程没有文件变化**——区分「取消动作是否新增写盘」与「取消整个流程后是否已有文件变化」（A-R01 v4）。
- **生效（运行时可见）**：成功注册后，直接登记查询可读新记录；档案保存和PBS反写仍是各自步骤，不是对所有消费者的即时广播。合法当前地图的Land快照原21，编辑并成功登记/保存0而不切图、不改版本、不显式重新装配时，直接登记查询读0、现有快照仍21；同版本赋值早退，不重新装配。改为另一版本且合法当前地图及遭遇上下文均存在时才重新装配当前地图，按WP73-B§6.1读取该版本的登记数据；保存、取消或调试Compile本身不等于装配。指标预览在后续刷新时重新读取，下一次实际布局按当时登记值应用；已布局的战斗精灵不因保存自动重新定位。PBS反写按当时运行登记数据写出，可能晚于档案保存改变内存参数类型或产生不同文本，所以档案/PBS/内存不保证相等；已写步骤遇后续失败不自动回滚。嵌套反写已完成而外层重载档案的对照仍见§4.2/§6。地区图鉴保存另外清临时缓存，让下次读取重新装载。

## 9. 边界、失败与未知

- **校验拒绝（A-R02/A-R03 分型）**：训练家战斗编辑——**清空类型后属性返回空、外层立即结束该次编辑（不到错误消息）**；**名字空与队伍空**才分别「Can't 保存…」回校验循环；新建 ID 冲突失败；新建训练家版本满（0–255 用尽）「没有空间」；训练家类型/道具新建的名称为空放弃（有缺省名时回落缺省）；新建道具**口袋返回 0 放弃**（**价格 BACK 返回 0 并继续创建——不是取消 −1 放弃**，A-R03）；进化路径子编辑 参数类型缺失时按 空 处理；EV 总额超限循环。**拒绝时不写文件**。
- **删除**：训练家类型/道具/物种的 ACTION 删除**立即落盘**（严肃确认后）；训练家战斗删除**待退出确认**；地区图鉴删除**无确认**（主界面即时）。
- **引用失效（A-R06 两型）**：**有保护的格式化显示「-」**（Species/Item/Type/Move/Ability/TrainerType 等）；**严格读取的格式化可抛异常**（Ball/池内容/训练家个体/天气——人工/失效数据前提，§3.4）；训练家图预览有局部保护回落空白，普通图形预览没有等价保证；**不做级联清除或自动修复**（失效引用保留在数据里，运行时语义归各数据主责包）。
- **异常路径**：目录缺失与已存在但为空分开：Windowskin 的 Graphics/Windowskins 或音乐 Audio/BGM 缺失时，在列文件的进入目录处失败，早于「没有文件」消息与正常释放；已建空目录才正常提示无文件并返回。原播放为空的合法夹具可直接定位此链；正常退出才恢复原 BGM，不推异常退出必恢复。训练家图预览有局部保护，失败回落空白；普通图形列表的位图预览没有等价保护，命名文件加载失败可传播。宿主最终呈现/清理未验证。 未知/只读属性按本类消息与返回旧值处理。逐条保存的注册/档案/PBS顺序不承诺事务回滚。
- **未知/未证**：编辑器实际运行表现与宿主窗口行为；素材存在与试听/预览（WP15/U01）；demo 中调试入口的默认可达性（WP77/U01）；PBS 反写与手工编辑并发时的外部一致性（WP04/WP75 边界）。
