# 世界编辑器（地图连接/地图元数据/地形标签/遭遇/指标）行为规格（净化正文；批次 15）

分类：demo-dx（主）／engine-overworld（地图/图块组/连接/小地图）／generic-kernel（登记、档案与文本编译交界）／user-interface（可视化画布/选择器）；性质：实现独立行为规格。

本稿为净化正文的一部分：按统一交接将批准输入 WP73-B《世界编辑器》转写为独立行为文字，不含源文件路径、行号、脚本入口名与类名（源定位集中登记于 `../../audit/source-traceability.md` 批次 15 条目）。范围：地图连接可视化编辑器、地图元数据编辑器、地形标签编辑器、遭遇编辑器（集/类型/槽三层）、指标编辑器与全量自动定位、无效图块修复的输入、校验、取消、保存与反写合同；资源关联核验与无资源边界。编辑器实现是作者行为要求的参考，不作为未来编辑器的布局或交互设计模板。全部内容为静态证据；**无运行确认**（见 `../scope-statement.md`）。

## 1. 目的、范围与非目标

**目的**：固定世界编辑器的规则合同——**每个编辑器读什么输入、坐标/地形/遭遇/指标如何校验、取消时是否仍写入、登记/档案/PBS 与当前消费者何时变化、数据与地图/图块组资源的关联如何核验、无资源时哪些操作不可确认**。后续包据此判断「某次编辑改了哪些文件，哪些读取方仍使用先前状态」。

**范围**：1) 地图连接可视化编辑器：画布与邻居递归摆放、增删图、拖拽、连接数据生成（邻接判定与对称去重）、保存与取消。2) 地图元数据编辑器：属性框架复用与即时落盘。3) 地形标签编辑器：图块组载入、标签设置（含自动图块整组语义）、保存与宿主提示。4) 遭遇编辑器：集/类型/槽三层编辑与退出确认。5) 指标编辑器与全量自动定位：单项定位/阴影尺寸/单体自动定位/全量自动定位的算法与落盘。6) 无效图块修复（WP72 入口引用，本稿主责其合同）：全地图扫描、有效性判定、写 0 与地图文件保存。

**非目标**：内容编辑器由 WP73-A 主责（训练家类型/训练家战斗/道具/物种/全局与玩家元数据/地区图鉴——本稿复用属性编辑与列表选择的行为合同）；动画工具归 WP74，编译器全集与文件更名/转换归 WP75。遭遇/地图/地形/指标的数据语义分别归 WP36/WP11/WP12/WP15/WP16；本稿固定编辑操作及保存、生效边界，并继承 WP04 的 PBS 编译/反写合同。WP73-A 的属性框架与选择器、WP72 的调试入口均为引用范围，不据此作其通过结论。不运行编辑器/编译器/反序列化、不写 PBS/.dat/地图/图块组文件、不操作真实存档、不调整宿主界面、不设计未来编辑器布局或 API。

## 2. 概念与术语

- **登记、文件与消费者**：登记数据、保存的 `.dat` 档案和反写的 PBS 是分别变化的状态，当前地图遭遇快照及已有战斗布局还须单列，不能概括为保存即热更新。**连接**＝退出确认时保存 `Data/map_connections.dat`、随后反写连接并清连接缓存；**地图元数据**＝确认属性后更新登记、保存档案、反写地图元数据；**地形标签**＝退出确认时写 `Data/Tilesets.rxdata` 并使运行图块组与会话共享当前内容，提示重启 RMXP；**遭遇**＝退出确认时先保存档案再反写 PBS，否则从档案重载登记（§6.4–§6.5）；**指标**＝有确认的指标改动且同意保存时先保存档案，随后按保存时记录集合选择 PBS 路径，否则重载登记（§7.5）；**修复图块**＝逐图立即保存，无总确认。文件顺序不构成总事务或消费者刷新保证。
- **小地图与画布**：小地图生成入口（WP16 引用）生成每格 4 像素的地图缩略图；连接编辑器以**网格对齐（坐标向下取整到 4 的倍数）**摆放缩略图；**画布上的图只是编辑会话内的摆放**——删掉画布上的图不删连接数据本身，连接数据由**生成算法**按当前画布重算（§3.3）。
- **连接数据形态**：原始连接为**边＋坐标**形式（`[图1, 边1, 坐标1, 图2, 边2, 坐标2]`——N/S/E/W 边经地图连接存取惰性装载时换算为坐标对并**过滤尺寸为 0 的无效图**）；编辑器生成的连接为**相对坐标差**形式（`[参照图, 0, 0, 目标图, dx, dy]`，dx/dy 为缩略图坐标差除以 4——即地图格数差）。
- **邻接判定**：坐标单位为地图格（缩略图像素差 ÷4）——**x 差等于对方图宽或己方图宽取负，或 y 差等于对方图高或己方图高取负**即视为邻接（边贴边的**单轴条件**）：**不检查另一轴重叠**——错轴也可成邻接（两张 10×10 图放在像素 (0,0) 与 (40,400)：横差满足条件即成邻接，纵向并未对齐）。**逐节点回退**：仅某图没有任何直接邻接时，才回退与（非自身的）第一个画布图建立连接——**两组各有邻居时不补跨组连接，不保证全图连通**（两对各自相邻且相互远离的图可保留两个连通分量）。
- **对称去重**：新连接与既有连接**完全相同**或**镜像对称**（两端互换且坐标差取负）时不重复添加。
- **地形标签的自动图块语义**：图块 ID < 384（每行 8、每自动图块 48）时**设置整组 48 个标签**；≥384 时设置单个标签。384 是两种图块处理的分界。
- **指标**：每物种×形态的显示参数——背面位置、正面位置、正面高度、阴影横移、阴影大小（0＝无，编号对应阴影图形）；PBS 对应数据名为 `BackSprite`、`FrontSprite`、`FrontSpriteAltitude`、`ShadowX`、`ShadowSize`，位置各含 x/y。**自有阴影图形**（按物种/形态命名）存在时，阴影大小不可编辑（§7.3）。档案为 `Data/species_metrics.dat`；查询可先惰性建立非零形态指标并带空来源后缀，输出路径／已有布局的消费边界见 §7.5。
- **底部探测（自动定位算法）**：从位图底行向上找到**首个 alpha>0 像素**所在行（全透明位图返回 0）——bottom；非负坐标公式为**向下取整的整数除法**：**y＝（位图高 − bottom − 1）÷ 2 向下取整**（正面位再＋4；例：高 32、底部行 24 → 背面 3／正面 7；全透明高 32 → 15／19）。**缺图与透明图分开**：缺图由调用方分支处理（§7.4 矩阵）；透明图按公式退化计算。写字段按单体/全量分列（§7.4）。
- **资源关联核验**：**有资源才能确认的操作**——地形标签编辑要求图块组数据可装载（编辑器直接数据装载，WP04/WP10 边界）；指标编辑的**预览**要求对应物种/形态图形存在（缺失时预览为空——**预览回落不等于全部操作安全**：单项定位/阴影尺寸按数值编辑仍可进行，**单体自动定位直接读两位图高度——缺图可失败（与全量缺图跳过分开，不以可手改数值推断全部操作可安全完成）**）；**自有阴影图形存在时阴影尺寸编辑被拒绝**；**无资源时**小地图/预览仅显示层回落。
- **已通过边界（必须继承，不重开）**：WP04、WP11、WP12、WP15、WP36、WP16、WP59、WP61、WP53、WP37、WP65、WP67-A/B、GR-001～016、WP23-N01。**同批待审依赖（引用其合同，不作通过结论）**：WP73-A（属性框架/列表器/登记、档案与文本持久/选择器）、WP72（调试入口与工具归属）——**当前身份见登记清单，不沿用 v1 短哈希**。

## 3. 地图连接可视化编辑器

### 3.1 打开与画布

- **打开**：屏幕尺寸**宽高各＋288**（临界段包裹，结束后恢复原尺寸与缩放因子）；初始图：当前图（无当前图取系统编辑图 ID，再缺省 1）居中摆放并**递归摆放全部邻居**（按既有连接偏移 ×4 递归）。
- **画布元素**：每图一个缩略图精灵（网格对齐）；选中框（红色描边跟随选中图）；底部「D: Help」提示行；帮助窗（D 键——按键清单）。
- **既有连接装载**：既有连接按需载入，含坐标换算与无效图过滤（§2）；编辑会话取得独立副本，并去除两端完全重复项。

### 3.2 编辑操作

- **A 键（Add map）**：地图列表（WP73-A 引用）选图 → 居中放入画布（网格对齐）＋置顶 → **立即重算连接数据**（§3.3）。
- **S 键（Go to map）**：选图 → **先重算当前画布连接数据**（保存当前成果为会话连接）→ 清画布 → 以新图为根重新摆放（含邻居递归）。
- **DEL 键（Delete map from canvas）**：画布图数 >1 且有选中 → 从画布移除该图（**只移出画布——连接数据不因此删除**；下次重算时被移出的图不再参与）。
- **单击**：选中（红框、置顶、标题行显示图名）＋开始拖拽（**拖拽落点同样网格对齐**）；**双击（0.5 秒内）**：打开该图的**地图元数据编辑**（§4——WP73-A 属性框架复用）。
- **拖动画布空白**：记录各图位置后整体平移（网格对齐）；**方向键**：全画布 4 像素步进平移。
- **D 键**：帮助窗（USE/BACK 关闭）。

### 3.3 连接数据生成与保存

- **生成算法**：先取会话连接的独立副本；**画布少于两图时直接保留该副本**（0/1 图分支不执行任何删除，旧连接全保留，包括触及画布图的连接）。至少两图时，删除所有触及当前画布图的旧连接；对每个画布图与每个其它画布图，按缩略图坐标差 ÷4 求直接邻接：**x 差等于对方图宽或己方图宽取负，或 y 差等于对方图高或己方图高取负**即邻接，**不检查另一轴重叠**。某图没有任何直接邻接时才回退连接画布首个其它图；不保证全图连通。按 `[参照图, 0, 0, 本图, dx, dy]` 的连接数据形式生成结果，完全相同或镜像对称的连接只保留一次。
- **保存**：BACK → **「Save changes?」确认** → 把生成结果写入 `Data/map_connections.dat`、反写连接、清连接缓存，并使会话后续使用该生成结果。**不确认时分三种状态**：连接会话成果不落盘；只从档案重载遭遇登记（未保存遭遇改动丢弃，当前地图遭遇快照不重装——§6.5）；地图元数据不重载，双击进入并已确认保存的元数据改动保留。共享嵌套内容（如地图尺寸）的未保存变化也不由遭遇重载恢复，不能补成统一事务。随后 **「Exit from the editor?」** 确认才退出，否则回到画布。
- **边界**：生成只覆盖**画布上的图**——未触及画布图的既有连接原样保留；**不校验生成连接的图是否存在/有资源**（装载期过滤归 WP11 的连接读取合同）。

## 4. 地图元数据编辑器

- **顶层**：起始地图 ID 仅用于地图列表预选；默认列表不带 GLOBAL 项，正常结果只返回地图，取消返回负值。选图后编辑该图元数据。内部存在全局元数据支路，但直接传 0 仍先进入地图选择器，普通实参不能由此绕过列表；**人工替换选择器结果为 0 属人工注入条件**。全局元数据正常入口是 metadata.txt 编辑器的 [GLOBAL METADATA] 项（WP73-A 引用）。
- **编辑**：图名取自地图信息；元数据不存在时先建立含该地图 ID 的初始记录。按属性列表编辑，**确认保存**后，将确认后的属性与原来源文件后缀登记为该图元数据，再保存档案并反写地图元数据；该保存无额外退出确认。嵌套属性的共享变化与父页是否保存分开（WP73-A 引用）。
- **从连接编辑器双击进入**时同此合同（保存即时）；连接取消只重载遭遇登记，不重载地图元数据、不撤销已保存元数据，共享嵌套内容的未保存变化也不恢复（§3.3）。

## 5. 地形标签编辑器

- **打开**：屏幕**高 ×2**（结束后恢复）；**载入图块组数据全量**（数据装载——反序列化边界，WP04/WP10 引用）；初始图块组 1。
- **显示**：每行 8 块 ×32 像素；**首行为自动图块行**（每自动图块 48 块）；覆盖层显示**非 0 标签数字**；右侧 400% 放大当前块＋标签名（地形标签数据存在则显示 `编号: 名称`，否则只显示编号）；品红衬底。
- **导航**：方向键（repeat）逐块、**JUMPUP/JUMPDOWN 半页**、ACTION 菜单（**Go to bottom／Go to top／Change tileset**——图块组列表切换）。
- **编辑**：USE → 标签列表（**脚本注册的标签**——本基线默认注册 ID 0–17，**不是 PBS 文件**；当前标签预选）→ 写入门比较**所选序号与旧标签 ID**——**默认连续 ID 时等效**；**自定义稀疏 ID（配置夹具）时序号与 ID 错位：可能跳过或冗余写入**（夹具例：注册 ID 0、2、5，旧值 2，选序号 2 代表 ID 5——门误判无需改变，旧值仍 2；不创建/修改 reference 配置）——写入时**自动图块（ID<384）整组 48 个同写；普通块单写**；随后刷新覆盖层。
- **保存与内存**：BACK → **「Save changes?」确认** → 把会话图块组数据写回 `Data/Tilesets.rxdata`，运行图块组改为与会话共享当前可变内容，并提示 **「为确保更改保留，请关闭并重新打开 RPG Maker XP」**（宿主数据双份语义——WP10/WP75 边界）。随后 **「Exit from the editor?」** 确认才退出。①首次未保存：Save No＋Exit Yes 丢弃会话，文件/运行数据不变；Save No＋Exit No 继续编辑、会话保留。②保存退出：文件与运行数据同更新。③保存后继续再放弃：后续会话编辑也改变共享的运行内容，再次 No 只是不写文件、不重载；标签 A→B 保存 Yes/退出 No，再 B→C 保存 No/退出 Yes，**文件 B、运行内存 C**。关闭时装配地图仍从运行数据取图块组，不重载文件。**宿主重启提示不立即撤销更改**。
- **关闭**：恢复地图装配、玩家居中、地图显示重建。
- **资源关联**：图块组来自 RMXP 工程文件 `Data/Tilesets.rxdata`，不是 PBS/.dat 游戏数据；可选地形标签来自已注册目录（WP12 引用），**没有 terrain_tags.txt 来源**。标签 ID 与名称只在显示时核验：存在才显示名称；未知旧值可显示数字，但可选集合仍是已注册 ID，不能由此任意输入。

## 6. 遭遇编辑器

### 6.1 集列表

- **列表**：全部遭遇集——显示 `地图ID[(v.版本)][: 图名]`（图名缺失省略）；**[Add new encounter set]** 在首。
- **新建**：地图列表（默认图）＋版本（0–999，取消 → 放弃）→ **已存在检查**（同图同版本 → 消息拒绝）→ 注册步数率与类型槽均为空的集，并定位光标。
- **已有项**：**Edit**（§6.2）／**Copy**（目标图＋新版本，冲突拒绝；复制步数率和各槽内容，使源集与副本后续编辑独立，保留来源文件后缀）／**Delete**（确认 → 删除登记中的该集）。
- **保存**：BACK → **「Save changes?」确认** → 先保存遭遇档案，再反写遭遇 PBS；否则从档案整体重载登记，含恢复删除。两分支均不重装当前地图快照。合法 0 的文件结果见 §6.4，登记与消费者的状态见 §6.5。

### 6.2 集内编辑

- **图 ID 行／版本行**：改图或改版本——目标（图,版本）冲突时消息拒绝；通过后不再以旧组合登记，改以新组合登记。这里编辑的是遭遇集标识，**并非全局当前遭遇版本的写入**，不因此刷新当前地图（§6.5）。
- **类型列表**：每个类型显示 `类型 (x槽数)`；**[Add new encounter type]** 从未用类型列表选择（全用 → 消息），新增步数率取该类型的默认触发率（WP36 引用），随后进 §6.3。
- **类型项**：**Edit**（§6.3）／**Copy**（目标未用类型，复制步数率与槽内容，后续编辑相互独立）／**Delete**（确认 → 同时删步数率与槽）。

### 6.3 类型内编辑

- **步数率行**：0–255（默认当前）。
- **类型行**：改为另一类型（**已被本集使用的类型排除**；当前预选）——步数率与槽整体迁移，不再以旧类型登记。
- **槽列表**：每槽显示 `概率, 名字[_形态] (Lv.a[-b])`（WP73-A 引用）；**[Add new slot]** 的缺省内容为权重 20、首个物种、最低及最高等级均 5；槽项 **Edit**（最低>最高时交换）／**Copy**（在其后插入独立副本）／**Delete**（确认）。
- **无总确认**：§6.2/§6.3 的改动即时进入遭遇登记，不更新当前地图快照。最终落盘由 §6.1 的退出确认决定；不确认保存则从档案重载登记，不能解释为恢复所有读取方或重新装图（§6.5）。

| Land 的步数率改为 0（默认 21） | 0 | 0 | `Land`，省略逗号及第二字段 | 21／21 |
| OldRod 的步数率为 0（默认 0） | 0 | 0 | `OldRod`，同样省略第二字段 | 0／0 |
| Land 的步数率为正数 70 | 70 | 70 | `Land,70` | 70／70 |

因此 0 是合法编辑值，登记和档案确实保存 0；但对默认非零的类型，反写省略概率使随后重编译恢复默认值。这是文件往返的语义损失，不能改述为保存时已变成 21，也不能推成所有默认零类型都会变成非零。成功重载档案直接取档案的 0，与从省略概率的 PBS 重编译不同。类型默认值与文本编译规则分别继承 WP36 和 WP04。

### 6.5 登记、文件与当前地图快照

当前地图装载时取得步数率与类型槽的独立快照；此后编辑登记中的步数率或槽不改该快照。直接地图数据查询读取当前登记数据；当前地图的类型检查、步进触发率和候选选择读取快照。候选选择不等于步进触发：非空槽可供候选选择，快照步数率为 0 时仍不能据此断言步进会触发。

下表各行是从具名前态进行的独立对照。初态为已进入地图 M、当前版本 v 的 Land 登记／档案／PBS／快照均为 21，槽合法非空；没有额外刷新、插件或外部修改，所述读写／编译均成功。除具名装载外，返回默认调试菜单及其淡入淡出包装不会额外重装遭遇。

## 7. 指标编辑器与自动定位

### 7.1 编辑器框架

- **打开**：战斗背景/双方底座/消息框位图＋双方宝可梦精灵位（战斗场景成员位引用——WP40/WP16）；物种未选时精灵隐藏。
- **物种选择**：全物种×形态列表（0 形态显示名、非 0 形态 `名字 (form N)`、字母序）；**浏览即预览**（切换即时重设精灵位图与阴影）；**BACK 取消**（清选择）、**USE 选定**。
- **主菜单**（五选项）：**Set Ally Position／Set Enemy Position／Set Shadow Size／Set Shadow Position／Auto-Position Sprites**。背面位置、正面位置、阴影尺寸中按 ACTION 确认才依次前进，循环为 **背面位置→正面位置→阴影尺寸→背面位置**；USE 确认留在当前项，阴影位置 ACTION 不结束也不前进，自动定位执行后回菜单且不轮转（§7.2–§7.4）。
- **保存**：退出时有已确认的指标改动，且同意 **「Some metrics have been edited. Save changes?」**，才先保存指标档案再按 §7.5 反写；否则从档案整体重载登记，丢弃未保存改动及未落盘的惰性新记录。保存／重载均不向已有普通战斗布局广播重定位。

### 7.2 单项定位（背面／正面／阴影位置）

- 选中精灵闪烁，信息行显示当前坐标；LEFT/RIGHT 三项均调 x，UP/DOWN 只调背面／正面的 y（阴影只有 x）。调整先改登记并刷新预览；USE 确认，有变化才登记为已确认改动，留在当前项；ACTION 只对背面／正面确认并前进，阴影位置的 ACTION 不结束编辑、不前进；BACK 恢复该项旧值并刷新预览。自动定位执行后回菜单、不轮转（§7.4）。

### 7.3 阴影尺寸

- **自有阴影图形检查**：按物种/形态命名的阴影图任一存在 → 提示该物种有自有阴影图形、阴影大小不可编辑，并返回。
- **可选阴影尺寸**：在没有物种/形态自有阴影的前提下，尺寸列表从0（None）开始，再从通用编号1逐一解析阴影资源；遇第一个无法解析的编号立即停止，只列此前连续存在的编号，不继续探测更大编号。旧尺寸在列表中时预选该项。浏览改变选择即改值并预览，USE确认，ACTION确认并前进，BACK恢复旧值。静态资源夹具均取旧尺寸0：1和3可解析、2不可解析时仅列0/1，3不被探测；1/2/3可解析、4不可解析时列0/1/2/3；1不可解析时仅0，不论更大编号是否存在。自有阴影仍拒绝编辑，真实媒体及宿主显示未验证。

### 7.4 单体与全量自动定位

- **单体（菜单 Auto-Position Sprites）**：直接读取两位图高度，按 §2 公式计算背面/正面的 y，正面再＋4；**缺图可失败，不保证静默保留**。任一 y 有变化或正面高度非 0 才写；只改背面 y、正面 y、正面高度＝0，x 与阴影不改；有变化登记为已确认改动并刷新预览。
- **全量（调试菜单 Auto-set pokemon_metrics，确认「确定要重定位全部精灵？」后执行）**：遍历全部物种×形态，每 5 秒保活界面；背面位图存在才把背面位置设为 x＝0、y＝§2 算法值，正面位图存在才把正面位置设为 x＝0、y＝算法值＋4。位图缺失的对应 x/y 不写；正面高度＝0、阴影横移＝0、阴影大小＝2 仍无条件覆写，含手工调值。指标查询可先建立非零形态记录。完成后立即先保存指标档案再反写 PBS，无二次确认；实际 PBS 路径与等值记录省略按完成时集合和数值判定（§7.5），不能从全量遍历推成全部 PBS 都更新。等待消息窗随执行显示。
- **资源关联**：全量自动定位的缺图侧 x/y 不写，正面高度/阴影横移/阴影大小仍无条件覆写。透明位图按 §2 的向下取整公式退化计算；全透明位图的底部探测为 0，y 为 （高−1)/2 向下取整，**透明与缺图分开**，不虚构资源校验。

### 7.5 保存时记录集合、PBS 路径与消费者

确认指标保存先写 `Data/species_metrics.dat`，随后才反写 PBS。输出路径只由**反写开始时已登记的非零形态指标记录**的来源后缀去重产生：空后缀选 `PBS/pokemon_metrics.txt`，后缀 s 选 `PBS/pokemon_metrics_s.txt`。只有基础形态（0 形态）不会产生任何指标 PBS 路径；已选路径只写同后缀记录。非零形态的背面位置、正面位置、正面高度、阴影横移、阴影大小五组值都等于当时基础形态值时，省略该形态节，**但其后缀路径仍已选中**。基础记录不受这项等值省略规则影响。省略单个形态不等于不打开整个文件；未选旧路径不因此删除或改写。

以下是合法物种与文件的人工／配置静态对照，不声称已验证默认样本。保存时登记仅含所列记录，无额外查询、插件、外部修改或其他相关旧 PBS 记录；所有指定读写和随后编译成功。A、B、D 为五组完整指标值，A 与 B 不同，D 与两者不同；例如只把背面 x 从 A 的 0 改为 B 的 4，D 为 8，其余组保持相同。s 与 t 是不同非空来源后缀。PBS 原基础记录为 A，文件编译前提包含合法基础记录。

| 保存时登记集合 | 成功档案保存 | 实际 PBS 路径与输出 | 从档案重载 | 从相关 PBS 成功重编译／随后查询 |
| --- | --- | --- | --- | --- |
| 仅基础记录，后缀 s，指标 A→B；保存前未查询非零形态 | 保存基础 B | 无指标路径；旧 s 文件保持 A（原不存在则仍不存在） | 基础 B | 以存在的旧 s 文件重编译，基础回到 A |
| 基础 B 与非零形态 D 同后缀 s，五组值有差异 | 保存两条记录 B／D | 选 s；基础 B 与非零 D 均输出 | 两者保留 | 两者按输出重建为 B／D |
| 基础 B 与非零形态 B 同后缀 s，五组值相等 | 保存两条显式记录 | 仍选 s；输出基础 B，省略非零形态节 | 仍有显式非零 B | 仅重建基础 B；以后查询缺失非零形态才复制 B 新建记录，新记录后缀为空 |
| 基础 B 仅后缀 s，非零 D 仅后缀 t，无其他非零记录 | 保存 B／D | 只选 t、输出 D；旧 s 文件仍 A | 基础 B／非零 D | 从旧 s 与新 t 成功编译，基础 A／非零 D；基础可与档案不一致 |

**等值必须在保存时判断**：若原基础与非零形态都为 A，仅把基础改成 B 后保存，即使修改前两者相等，保存时已不同，非零 A 不可按旧等值省略。同后缀时基础 B 与非零 A 均输出；若五组仍全部相等则走表中省略对照。

**查询可先改变集合**：首次查询合法但尚无指标记录的非零形态，会在登记中建立该形态；基础不存在时先建立默认基础指标，再复制其五组指标，两组坐标随后可独立修改。新形态的来源后缀缺省为空，**不继承基础的来源后缀**。浏览形态预览、阴影查询和自动定位都可到达这一查询，因此不能用进入编辑器之前的文件／记录数推断保存路径。例如只有后缀 s 的基础 B，预览缺失非零形态后，它以 B／空后缀登记；随后执行保存会选择默认指标路径，即使该形态因等值被省略，也不会因此选择基础的 s 路径。仅浏览但没有确认的指标改动，不会因此强制出现保存提示；正常关闭的重载分支会丢弃未落盘的新登记记录。

**消费者分开**：编辑器参数调整先改变登记值并刷新自己的预览，此时尚未保存文件；BACK 恢复所编辑参数后也刷新预览。预览按基础位置重新应用当前指标，坐标偏移尺度为 2。普通战斗中已经完成布局的精灵在设置位图／重新定位时取指标，所读普通逐帧更新不重新应用指标；保存、档案整体重载或 PBS 重编译本身都不广播重新定位。直接查询在重载后看到档案值，并不保证已有布局同时变化。不得把这一边界扩大成所有显示者都永不刷新。

**部分失败**：若档案已成功保存 B，随后某个 PBS 打开／写入失败，档案的 B 不回滚；已经完成的 PBS 写入也没有总回滚保证。失败文件究竟未打开、已截断还是部分写入取决于失败时点，不能统一预测为旧内容。反向对照是正常不保存退出：重载原档案、PBS 不写；它与“已保存档案后反写失败”不同。两种情况均不虚构已有战斗布局的热更新或宿主异常画面。

## 8. 无效图块修复（WP72 入口引用，本稿主责合同）

- **范围**：**全部地图**（编译器地图数据——WP75 引用）的**全部图块层**与**全部事件页图形**。
- **有效性判定（三分支）**：**仅正数 1–383** 走自动图块名检查（对应自动图块名非空才有效）；**0 与至少 384 均走通行表项是否存在**（ID 0 的表项存在——**普通空图块有效：不能把合法空白地图预测为每图都被改写**；≥384 且表项缺失才判错）（图块有效性检查——tilesets 数据引用，WP04/WP12 边界）。
- **修复**：无效图块 **写 0**（事件页图形 tile_id 同）；每图计数；**有改动的图立即调用地图数据保存入口逐图保存（无总确认）**；控制台逐图列出（图 ID/名称/错误数）。
- **完成反馈**：无错误 →「No invalid tiles were found.」；有错误 → 控制台汇总＋**「RMXP data was altered. Close RMXP now to ensure changes are applied.」**＋消息「错误数 N、跨地图数 M 已修复」＋「关闭 RPG Maker XP 以应用更改」（**宿主双份语义**——WP10/WP75 边界如实登记；执行期每 5 秒保活界面）。

## 9. 默认行为与配置变体

- **配置值（WP02 引用）**：`SCREEN_WIDTH/SCREEN_HEIGHT` 决定连接编辑器宽高各加 288、地形编辑器高度加倍；遭遇最大等级决定槽等级上限（WP36）。
- **数据文件层**：连接 `Data/map_connections.dat`；地图元数据 `Data/map_metadata.dat`；地形 `Data/Tilesets.rxdata`（RMXP 工程文件——WP10/WP75 边界）；指标 `Data/species_metrics.dat`；遭遇 `Data/encounters.dat`；修复图块涉及地图 `Data/MapNNN.rxdata`（WP75 边界）。指标 PBS 的默认／后缀路径只在 §7.5 条件下选择；遭遇 PBS 的零值省略与重编译默认值按 §6.4，不能由档案更新推断文本保真。
- **宿主重启语义**：地形标签与无效图块修复均提示**关闭/重开 RMXP 以应用更改**（工程文件与运行数据双份——如实登记，不虚构热同步）。
- **未验证组合**：编辑器实际运行表现、小地图/预览/战斗背景素材存在（WP15/WP16/U01）、demo 中入口默认可达性（WP77/U01）、连接生成后的实际通行表现（WP11 主责）。

## 10. 边界、失败与未知

- **取消语义汇总**：连接确认才保存并清连接缓存；否则只重载遭遇登记，元数据已保存及共享嵌套变化保留，当前地图快照不重装。地图元数据确认即保存。地形首次未保存需 Save No＋Exit Yes 才丢弃会话，保存后继续再 No 只不写文件，运行共享内容保留（§5）。遭遇退出不保存时从档案重载登记，含恢复删除，文件不写且快照不重装（§6.5）。指标无已确认改动或拒绝保存时从档案重载登记，含未落盘的新记录；与档案保存后 PBS 失败分开，已有战斗布局不因重载自动重定位（§7.5）。修复图块逐图立即保存，无取消路径。
- **拒绝/回退**：连接仅某图无任何直接邻接时才回退画布首个其它图；两组各有邻居时不补跨组连接。遭遇同（图，版本）冲突时新建/复制/改图/改版均拒绝，类型选择排除已用项、全用时提示。指标自有阴影图形拒绝阴影大小编辑；修复图块无错误只提示。
- **不校验项（如实登记）**：生成连接不验证图存在性（装载层过滤）；地形标签**可选集合＝已注册 ID**（未注册的旧值只按数字显示、不能任意输入）；指标编辑的预览对缺图仅显示层回落（除 §7.3 具名拒绝）——**但单体自动定位直接读两位图高度：缺图可失败（与全量缺图跳过分开——不以可手改数值推断全部操作可安全完成）**；自动定位对全透明位图按向下取整公式退化计算（透明图 ≠ 缺图）。
- **异常路径**：预览/列表的局部显示回落不能推成所有操作可安全完成；单体自动定位直接读两位图高度，缺图可失败。连接屏幕尺寸变更有恢复包装；正常返回的清理不能推广为任意异常也完成清理。遭遇与指标均先保存档案再反写，后续 PBS 失败没有档案或先前文件写入的总回滚保证（§7.5）。逐图保存与逐对象覆写保持实际部分状态。
- **未知/未证**：编辑器运行表现与宿主窗口行为；素材存在（WP15/U01）；demo 入口可达性（WP77/U01）；编译器地图数据读写地图的完整合同（WP75 主责——本稿只引用调用点）；连接数据的运行时消费细节（WP11 主责）。
