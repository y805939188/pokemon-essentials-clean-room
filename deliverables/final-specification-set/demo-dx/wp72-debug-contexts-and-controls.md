## 1. 目的、范围与非目标

**目的**：固定调试情境与控制的规则合同——**调试能力从哪些入口可达、各自可见性门是什么、每个命令读什么输入、写什么状态、给什么反馈、失败与取消走哪条路、即时效果与持久归属如何分层**。后续包据此判断「某个调试动作实际改变了什么」，而不是各自重新追踪调试菜单文件。

**范围**：1) A 调试入口、菜单可见性与交互——地图热键、暂停菜单命令、载入界面受限菜单、队伍/存储个体调试、构造测试战斗时的个体调试、战斗命令热键、战斗内成员/队伍入口；菜单框架的层级/返回/根取消/默认选中与刷新/命令返回值关闭语义；`受限可见标记` 三态、上下文情境筛选与可用处理器筛选。2) B 世界情境与会话状态控制——地图传送、开关/变量编辑、地图刷新、场地效果、寄养调试、漫游编辑、Safari/捕虫计数、遭遇版本、训练家重置、Exp All、战斗日志开关、片尾跳过、Shadow/净化室访问各入口。3) C 玩家、队伍、存储与背包操控——货币/徽章/图鉴与地区图鉴/跑步鞋/Pokégear/电话联系人/Box Link/角色/外观/名字/ID；治疗、添加个体、填/清盒子、示例队伍、蛋快速孵化、打开存储；加道具、填充/清空背包。4) D 个体诊断与编辑（非战斗）——HP/异常/治疗/濒死/Pokérus、等级/经验/EV/IV/个人 ID、友好/华丽六维、招式/PP/初始招式、物品/特性/性格/性别/物种/形态、闪光/球/缎带/昵称/所有权、丢弃许可、蛋、Shadow 与心量表、Mystery Gift、复制与删除。5) E 测试战斗及战斗内观察/编辑——普通/高级野生与训练家测试的构造与校验；战斗内双方在场者、速度顺序、队伍、训练家资源、Mega 配额、天气/场地/环境/时间/背景；场/阵营/席位/成员四层效果观察与编辑；成员 HP/状态/能力值/类型/招式/物品/特性/性格/性别/形态/物种/Shadow 的双层（原个体 vs 战斗当前）编辑。6) F 日志、持久性与后续工具边界——观察与修改分列；运行标志与调试标志共同门；临时战斗态/运行中持久对象/显式文件写出/编译输出分层；通往 WP73-A/B、WP74、WP75、WP76、WP64、WP77 的工具入口登记与归属。

**非目标**：不提取编辑器主体（WP73-A/B 主责）、动画编辑/组织/导入/导出（WP74）、文件更名/编译/文本抽取/工程与事件转换（WP75）、设施生成/模拟（WP76）、demo 事件编排（WP77/U01）。本稿只完整登记通往这些工具的**入口、条件、即时副作用和归属**，不宣布工具内部已完成。不重提取已通过规则：正常遭遇/捕获/结算（WP36/WP42/WP38）、战斗上下文（WP39/WP40）、AI 评分（WP51）、个体底层规则（WP18～WP23/WP25～WP35）、净化室合同（WP23）、漫游（WP37）、Safari/捕虫（WP53）、时间/场地（WP59）、野外被动与回程（WP61）、Mystery Gift 领域（WP64）。不运行参考实现/游戏/UI/测试战斗/随机模型/编译器/导入导出/保存转换，不操作真实存档，不访问网络，不设计未来 API。

## 2. 概念与术语

- **调试标志与运行内标志分层**：调试标志由宿主环境给定（测试运行语义；WP01/WP07 引用），是全部调试入口的总门；运行内标志是**运行中可切换的内部标志**——当前静态范围内唯一的写入者是调试菜单的战斗日志开关（§8.1），读取者是日志模块（与调试标志共同门）与异常打印长度选择。**两者独立**：入口可见性只看调试标志；日志输出要求两者同真。
- **菜单注册与可用筛选**：命令按可识别选项登记名称、父级、说明、条件及动作；**可用筛选**按排序键（缺省按注册序号）排序、逐个执行条件（无条件的调试主菜单注册项不设条件——调试门在**入口调用侧**，不在注册项上）；名称可为取值过程或静态文本。**`受限可见标记` 三态**：未设置（空）／显式真／显式假——**受限模式只排除显式假**（未设置与显式真都保留），§3.2。
- **命令菜单列表框架**：层级菜单——每个命令记录父级；列表给出当前层命令名；可下钻判定；取父级返回父层 ID 及当前层在父层中的下标（用于返回时恢复光标）；描述缺省回落「<No description available>」。**返回父级**（BACK 且存在父级：取消音效＋切回父层＋光标恢复到该层在父级中的位置）与**根取消**（BACK 且无父级：整体退出）分开；**效果返回值关闭语义**——个体调试菜单中效果返回真即退出整个调试菜单（复制/删除用此关闭）；地图调试菜单中地图传送项特殊——效果返回真才关菜单（先清理自身窗口/视口再转移，§4.1）。
- **原个体与战斗当前两层（R07 修订）**：战斗内编辑同时面对**原个体对象**（队伍/盒子中的持久数据）与**战斗当前状态**（在场派生层）。**写入器写穿**：在场对象的 **HP、状态、状态计数、道具、等级、形态**的写入器会**同步写回原个体**（状态写入器还重置相关计数并刷新场景——WP40 引用）；**战斗特性、能力阶段、能力值、类型、效果、Mega 配额等是战斗层**（不写回原个体）。各命令**按名选择写哪一层**（§7.4 逐项）；不存在「改了原个体就自动同步战斗层」或反向的通用保证；退出战斗调试后由战斗命令阶段执行一串**刷新后续处理**（§7.6），仅这些具名后续处理，不虚构全面重同步。**持久性推论**：写穿层的改动落在持久对象上（战后保留——WP39 生命周期引用）；战斗层改动随战斗结束消散。
- **情境筛选**：战斗个体调试菜单的命令带 原个体专用／在场专用／两种情境 用途——有在场对象时排除 原个体专用，无在场对象时排除 在场专用（在场成员与不在场队伍个体看到的命令集不同，§7.4）。
- **构造测试 ≠ 沙盒**：测试战斗走正常生成/战斗/捕获/结算入口（WP36/WP39/WP42 引用）——其真实副作用（图鉴登记、经验、拾取、传播、统计等）按正常规则成立；调试侧只负责候选构造与规则输入（可败、遭遇类型清空、人数布局）。
- **观察与修改分列**：仅展示（速度顺序、成员/队伍信息、效果当前值、寄养/漫游状态行）与写入（数值/开关/对象编辑）分开登记；观察行的「当前值」是读取时刻快照，不承诺实时刷新（各界面按自身刷新时机）。
- **持久归属分层**：**临时战斗态**（在场层与战斗设置——**按字段分层（R07 v3）：写穿层字段（HP/状态/状态计数/道具/等级/形态）落在持久个体上、按其后续正常生命周期演化（WP39/WP42 引用）；仅战斗层字段（战斗特性/能力阶段/能力值/类型/效果/Mega 配额等）随战斗结束消散——不声称所有在场编辑都消散**）；**运行中持久对象**（全局元数据/玩家/背包/存储/开关/变量/地图运行态上的改动——随存档保存的部分按 WP09 归属，其中临时字段为运行临时）；**显式文件写出**（动画导入导出、修复图块写地图文件、PBS 生成、编译、日志追加——各自的立即落盘语义按条登记）。**调试改变值 ≠ 正常事件调用 ≠ 会话重新初始化**；菜单效果完成后**不自动落盘存档**（保存由正常保存入口负责，WP09/WP10）。
- **已通过边界（必须继承，不重开）**：WP61（野外被动与回程——含 Pokérus 调试三动作合同与净化室惰性取用）、WP53（Safari/捕虫）、WP37（漫游）、WP23（Shadow/净化）、WP36/WP39/WP42/WP38（遭遇/战斗上下文/终局/捕获副作用）、WP24～WP28（玩家/存储/背包）、WP30（友好数值）、WP33/WP34/WP35（寄养/育种/孵化）、WP59（时间/场地）、WP64（Mystery Gift）、WP65（载入/暂停 UI 框架）、WP67-A/B、GR-001～016、WP23-N01。

- **层级原则**：菜单调用存在、入口要求调试标志、命令条件、父级可达、受限模式可见性是**不同层级**——不能因为效果处理器内部没有调试检查就宣称普通玩家可达（入口侧门已挡），也不能给所有直接调用统一补调试门（脚本直接调用各独立入口走各自前提，§10 有界前提）。
- **调试标志为假时**：地图 F9 不置标记；暂停/队伍命令不出现；载入界面与存储界面命令不加入；战斗 F9 分流不触发。**基线内没有非调试标志的调试菜单入口**（全脚本调用者检索）。

### 3.2 可见性三态与菜单交互

- **完整 vs 受限**：调试菜单的显示全部形参——为假时**只排除 `受限可见标记` 显式假**的条目；未设置（基线中 PBS 编辑器、其它编辑器、文件选项等菜单节点）与显式真（基线中无）都保留。**基线显式假的条目**：Field options…、Battle options…、Pokémon options…、Item options…、Player options… 五个顶层分组节点（其子项随父级不可达而整体不可见——可见性沿父级链，不是逐条打标）。
- **个体调试菜单的构造测试模式**：构造测试标志为真时同样**只排除 `受限可见标记` 显式假**——基线显式假的个体条目：**Set egg、Mystery Gift、Duplicate、Delete**（构造测试时这四项不出现；§6）。
- **交互合同（按菜单家族区分，R02 修订）**：USE——有子菜单则下钻（决定音效、光标归零）；无子菜单则调用效果；BACK——有父级返回父级（取消音效、光标恢复到当前层在父级中的下标）；无父级退出。**描述求值时机**：命令清单（含描述过程的求值）在**进入菜单时收集一次**——**下钻/返回父层只切换当前层与窗口命令名，不重新运行描述过程**（R02 v3 对照：进入一次菜单后往返层级，动态描述依赖值变化不触发重新求值）；光标移动只用已存文本刷新描述行，**不随光标移动重新求值**。**退出清理按家族分开**：地图调试菜单根退出带关菜单音效＋**淡出**＋释放窗口/视口；战斗调试菜单根退出为关菜单音效＋释放（**不走相同淡出链**）；特殊传送的整体关闭属于地图菜单（§4.1）。开关/变量页是**独立子屏幕**（§4.2——BACK 关闭子屏幕回到菜单，不算菜单内层级）。
- **命令返回值何时关闭菜单（R02 v3）**：**地图调试菜单**——普通效果返回值被忽略（菜单继续）；**仅地图传送项**（**仅存在于地图菜单**）的效果返回真时整体返回（其效果内部先完成自身窗口/视口清理与转移准备，§4.1）；**战斗调试菜单——普通效果返回值均被忽略，无特殊传送分支**。**个体调试菜单**——效果返回真即退出（基线中 Duplicate/Delete 返回真：编辑完成后整单关闭并回到底层界面）；取消在顶层且无父级时退出。
- **根取消不留副作用**：菜单框架本身不写游戏状态；所有状态写入都在各效果内（§4～§8 逐项）。

## 4. WP72-B：世界情境与会话状态控制

### 4.1 地图传送

- **目标选择**：地图选择列表默认定位在**默认图**（当前图 ID；无当前图时取系统编辑图 ID；再缺省 0）；取消 → 返回假（菜单继续、无写入）。
- **落点查找**：对目标图**最多 100 次随机尝试**——取随机坐标，要求严格可通行（含朝向 0 的通行判定与玩家占用语义，WP12 引用）且该格无非穿透且有图形的事件阻挡；**100 次失败则回退为一组纯随机坐标**（**不保证可通行**——不补安全落点保证）。
- **转移分支**：**当前是地图场景**——写转移参数（新图/落点/朝下）并调用玩家转移（正常转移链，WP11 引用）；**非地图场景**——取消载具、用地图工厂装配目标图、玩家落位朝下、地图更新与自动播放（音乐/BGS）。两分支最后都**请求地图刷新**；效果返回真——**调试菜单整体关闭**（先淡出、释放消息窗/精灵组/视口再执行转移）。
- **有界边界**：不补「异常回滚」或「必定成功换图」承诺；传送与正常事件传送共用底层，会话状态（跟随者/载具/临时标志）按正常规则演化，调试侧不额外复位。

### 4.2 开关与变量（独立子屏幕，模式 0/1）

- **开关页（模式 0）**：列出系统开关名表全部条目（名表长度−1）。前缀只识别行首小写 ASCII `s:`（冒号 U+003A），全角 `s：` 不进入表达式分支。取前缀后的原表达式，以左圆括号、左方括号、等号、小于号、大于号、英文句点或 ASCII 空格为分隔字符取得首片段，去其两端空白，再只移除开头的一个感叹号 `!`；这只用于资格判断，获准时仍求值完整原表达式，不求值处理后的片段。首片段的首字符是英文字母时：大写起始仅在该完整片段是已存在的兼容常量名称时许可；常量不存在或常量名称查询失败均不许可。小写起始仅在该完整名称不是事件命令解释器方法、也不是地图事件方法时许可；这两个方法名称查询的局部失败按未命中处理。首字符非英文字母则许可。未获许可不求值、显示空值标记 [-]；许可后的求值异常局部回落空值，成功真/假显示绿色 ON/红色 OFF。资格前处理不受这个求值救援保护：仅 `s:` 没有首片段，在去空白时局部 NoMethodError；`s:!` 去除感叹号后没有首字符，在后续字母判断时局部 NoMethodError，均早于求值、不能当作 [-]。真实宿主如何收口未验证。USE 只翻转当前 ID 的原始开关，随后立即重绘页面并按上述规则重新求值，重绘正常返回后才请求地图刷新；不编辑表达式文字。 合法名表和当前地图、原始开关1为假：许可的非字母表达式读取同ID时 USE 后原槽真、显示 OFF→ON；许可的独立常量真表达式前后均 ON。另设许可表达式只读取初始为假的地图刷新请求标记：USE 的即时重绘仍显示 OFF，之后标记才变真，不把请求后的值倒用于该次重绘。已存在的大写常量首片段获准、不存在的大写常量首片段拒绝；不属于两类事件方法的小写首片段获准，任一事件方法名称首片段拒绝；拒绝例显示 [-] 而不求值。首片段为 `!true` 时去一个 ! 后按 true 判断资格，但求值原 `!true` 得假；求值本身异常为 [-]。同字面全角 `s：` 按普通原槽假显示 OFF；仅 `s:` 与 `s:!` 各发生上述未捕获前处理局部失败。
- **变量页（模式 1）**：列出系统变量名表，空值显示「__」。LEFT/RIGHT数值±1（空先归0、夹±99,999,999）。USE按当前类型进入数值（最多8位/负号/同范围）或文本（250字符），其它类型不编辑。ACTION 按互斥顺序处理：0→空字符串，空字符串→0，其它数值→0，其它字符串→空字符串，其它类型不变；随后先重绘变量页，再请求地图刷新。连续两次从0得空串再0，从7得0再空串，从非空文字得空串再0；随后 USE 按当前类型进入数值或文本输入。LEFT/RIGHT及普通数值USE的分支先完成写值与刷新请求，再重绘，与ACTION的顺序分开。普通文本USE也先返回并写值、请求地图刷新，再重绘页面。
- **开关/变量上限**：包装类读写均限 **ID ≤ 5000**（读越界得 假/0，写越界忽略）。

## 10. 边界、失败与未知

- **取消约定（R03 修订）**：数值输入的取消返回值分两类——**显式设置取消值的入口**（BACK 返回该值：0/−1/当前值，调用方按约定处理）；**未设置取消值的入口**（**BACK 返回钳制后的默认值——与按 USE 接受默认值不可区分，调用方随后若无条件写入，状态仍可能改变**）。三个可达对照：①非战斗睡眠计数（默认 3、无独立取消值——**选 0 才取消；按 BACK 返回默认 3，仍赋予睡眠 3 回合**，§6.1）；②寄养「其它值」（以原计数为默认值、无独立取消值——**BACK 返回原计数后仍按 256−输入换算写入：计数 5 时 BACK 使计数变 251**，§4.4）；③所有权「设外来 ID」（以公开 ID 为默认值——**BACK 返回公开 ID 后仍执行完整 ID 合成：低半区 12、高半区 99 时 BACK 使两半区均 12**，§6.5）。普通独立选择取消不提交目标；寄养与遗迹石仍按§4写事件变量、请求地图刷新；传送取消 → 返回假菜单继续；测试战斗 BACK → 放弃集合（**已发生的生成/加载副作用不回退**，§7.1）。**不承诺任何确认对话框的默认选择**（除文中具名）；**不作全局「取消不写」保证**——以各入口逐项注明为准。
- **容量与拒绝**：队伍/存储全满（添加个体/复制/领取蛋/取出）；盒子满（复制入盒）；口袋容量 0/满（填充背包跳过）；物种数 > 存储容量（填盒部分完成＋附注）；满四招（Teach 提示）；最大等级（Set Exp 提示）；单形态（设形态提示＋重置确认）；单性别（设性别提示）；非 Shadow（心量表提示）；战斗层最大 HP 1（Set HP 拒绝）。**均按实际消息登记，不补事务撤销**。
- **直接调用的有界前提**：各独立入口可被脚本直接调用——**此时不走入口侧调试门**；其行为合同不变（菜单框架与效果逻辑相同），但**可达性结论只对 §3.1 入口成立**。
- **不写盘承诺**：除 §8.2 具名文件写出外，调试编辑**不触发自动保存**；临时字段改动不持久。
- **异常路径**：动画**导出**整体异常捕获 →「The export failed.」式消息；动画**导入**只有逐项解码局部回落（无整体兜底，R14）；效果编辑器遇未知值类型 → 抛异常（防御）；求值型开关显示异常 → 回落 空（「[-]」）。**不虚构其它异常兜底**。
- **未知/未证**：宿主两标志的实际环境与注入时机（WP01/WP07）；无视觉场景模拟内部（WP76）；各编辑器/工具内部（WP73-A/B、WP74、WP75）；demo 事件链与真实调试使用编排（WP77/U01）；随机源实际序列；批量填盒/填包的实际运行耗时。
