# 招式属性、目标与复制调用行为规格（净化正文；批次 11）

分类：combat-requirements ＋ pokemon-rules（F12-05 属性/目标/调用子范围）；性质：实现独立行为合同。

本规格为净化正文：按统一交接将批准输入 WP47-A《招式属性、目标与复制调用》转写为独立行为文字，不含源文件路径、类名、行号与证据 URL（参考与已读集中登记于 `../../audit/source-traceability.md` 批次 11 条目）。文中保留的效果身份名、物品/类型/物种身份名与配置键均为数据标识，不构成未来实现的数据结构或接口模板。全部内容为静态证据；**无运行确认**（见 `../scope-statement.md`）。

## 1. 范围与共同约束

A = 本次招式参数和当前场上类型；B = 命中、保护与时机；C = 目标选择、重定向、反射及抢夺；D = 复制/调用/递归与记录；E = 配置、失败和数据。可见结果含目标改变、类型提示、保护/失败、另一个招式被使用、招式槽替换及 PP 变化。本规格不设计未来 API 或继承结构，效果标识只供追溯。

WP40 为使用前置、两标志与 PP 唯一主规则；WP43 为普通命中/类型/伤害公式；WP44 为状态/阶级资格；WP45 为场域/位置/保护局部生命周期；WP46 为多击/固定伤害/恢复主合同。某族越过命中抽取不等于绕过目标免疫、保护或其它前门。输入为本次数据、当前场上身份/类型/状态、记录/目标索引、环境/场地、数据注册与配置；持久个体和临时招式副本分开。失败不回滚已发生扣 PP/记录/消耗，除非具名入口明确恢复。

配套数据附表 `wp47-a-attributes-targeting-calling-data.md`（本包一部分）：效果映射、调用排除表、携带物类型映射、自然之恩默认数据。行为正文和数据表共同足以给出具体输出；不要求实现者去源码补缺省值。

## 2. 当前类型与持久字段（A）

普通类型改变资格按原能力身份拒 MULTITYPE/RKSSYSTEM，不因胃液或模式破坏者自动准许。中央类型改变只写场上基础类型/额外类型并清燃尽/羽栖，不改持久物种类型；字符串类型替换为单类型并清额外，复制对象时复制其当前基础类型，若全空补一般，复制额外类型但去与基础重复者。重置回个体类型会清额外/燃尽/羽栖。换人初始化/接力子集沿 WP41，不泛化所有临时标记都同一清理。

### 3.2 觉醒力量的有序类型与旧代数值

按类型数据图标位置升序（同位置按登记序）列所有非伪、非一般、非 Shadow 类型。当前默认 17 种：格斗、飞行、毒、地面、岩、虫、幽灵、钢、火、水、草、电、超能、冰、龙、暗、妖精；该快照允许妖精。按 HP、攻击、防御、速度、特攻、特防次序，取各 IV 奇偶 0/1 并以 1、2、4、8、16、32 加权得 s ∈ 0..63；选零起索引 ⌊（种类数 − 1）× s / 63⌋。无候选等非法数据不补中性保证。

当前世代不以 IV 改数据威力。旧代 ≤ 5 实际累积威力位从 60 开始而非 0，四个高位预先为 1；因而最终中间值是 60 加 HP 的第二低位 0/1、加攻击第二低位的两倍，其它四项第二低位不会再增值；再按 30＋⌊40 × 中间值 / 63⌋ 取值。默认得到 68、68、69 或 70，不按通行「30～70」修正参考。此处只描述已读位意义与独立常数，不执行参考程序。

### 3.3 环境默认映射与附效

环境变类型（SetUserTypesBasedOnEnvironment）场地优先映射与 §3.1 相同；否则：无 → 一般；草/高草 → 草；流动水/静水/水洼/水下 → 水；洞穴 → 岩；岩地/沙地 → 地面；森林/森林草地 → 虫；雪/冰 → 冰；火山 → 火；墓地 → 幽灵；天空 → 飞行；太空 → 龙；究极空间 → 超能；未列环境退一般。目的类型不存在的回退依 §2，不采用自然之力的招式回退规则。

UseMoveDependingOnEnvironment（自然之力）默认 TRIATTACK；场地电/青草/薄雾/精神分别尝试 THUNDERBOLT/ENERGYBALL/MOONBLAST/PSYCHIC，身份不存在仍保留默认且不再改走环境分支。无相应场地时：草/高草/森林/森林草地世代 ≥ 6 ENERGYBALL 否则 SEEDBOMB；流动水/静水/水下 HYDROPUMP；水洼 MUDBOMB；洞穴世代 ≥ 6 POWERGEM 否则 ROCKSLIDE；岩/沙世代 ≥ 6 EARTHPOWER 否则 EARTHQUAKE；雪世代 ≤ 5 BLIZZARD、6 FROSTBREATH、≥ 7 ICEBEAM；冰 ICEBEAM；火山 LAVAPLUME；墓地 SHADOWBALL；天空 AIRSLASH；太空 DRACOMETEOR；究极空间 PSYSHOCK。尝试身份存在才换默认，默认 TRIATTACK 本身未先验证存在。实际初始化后对目标调用所选招式，沿 §6；不把旧世代「对自己」定义植入本快照。

EffectDependsOnEnvironment（秘密之力）初始化一次记录附效种类。场地优先：电麻痹，青草睡眠，薄雾特攻 −1，精神速度 −1；否则环境：草/高草/森林/森林草地睡；水域三种降攻击 1；水洼降速 1；洞穴畏缩；岩/沙降命中 1；雪/冰冰冻；火山灼伤；墓地畏缩；天空降速 1；太空畏缩；究极空间降防 1；其它麻痹。所有击后对存活、非 unaffected、非替身目标且 U 无有效 SHEERFORCE，抽一次经 WP43 附效机会，中央资格过才提交；不是亲子爱每击抽一次。

此效果声明「自带畏缩」的环境集合却是水洼/火山/天空（内部 6/10/12），实际畏缩结果是洞穴/墓地/太空（7/11/13）；因此额外畏缩资格会按前一集合处理，不能自行改成后者。显示动画通常按附效表借用招式；精神场地检查 CONFUSION 存在后给出的动画标识却是 CONFUSIO，保持具名媒体未决，不声称运行正常。动画默认 BODYSLAM；其它映射依次电 THUNDERSHOCK、草 VINEWHIP、薄雾 FAIRYWIND、水 WATERPULSE、水洼 MUDSHOT、洞 ROCKTHROW、岩沙 MUDSLAP、冰雪 ICESHARD、火山 INCINERATE、墓 SHADOWSNEAK、天空 GUST、太空 SWIFT、究极 PSYWAVE，各先查对应招式存在。

## 5. 目标选择、重定向与反射（C）

### 5.1 执行时目标构造

界面允许选择集合由 WP39/40 的目标数据与邻近规则约束；以下是执行者使用已登记预选的真实行为，不能额外补一套菜单检查。执行时先按本招与当前实际 U 查询动态目标类别，再据该类别构造列表；后续重定向入口再次查询，不能用原始数据中的目标身份替代本次结果。加目标共用拒不存在、倒下（位置招例外）、未经允许的自己、近距要求不符；按席位去重，但本身不额外检查敌我方向。

| 目标数据身份 | 预选失败后的构造/顺序 |
| --- | --- |
| NearAlly | 先尝试预选，失败则均匀随机近盟友 |
| UserOrNearAlly | 先允许自身的预选，失败补 U 自己 |
| AllAllies | 全同侧存活集合去 U，不限距离 |
| UserAndAllies | 先 U，再同侧其余存活者，不限距离；targets_all 标志假，不能由中文「全体」推出免戏法防守 |
| NearFoe／NearOther | 先预选并查近距；失败时预选席位为同侧则随机近盟友，其余随机近对手；不把错误预选必然校正为敌方 |
| RandomNearFoe | 均匀随机近对手，不采用预选 |
| AllNearFoes | 按存活对侧集合加入近对手 |
| Foe／Other | 先预选不查近距；失败按原预选同侧与否随机盟友/对手，不限距离 |
| AllFoes／AllNearOthers／AllBattlers | 依次全对手不限距/全存活且近者去 U/全存活含 U 不限距 |
| None／User／UserSide／FoeSide／BothSides 等 | 走本招自有构造；通常列表空，User 也不自动成为逐目标列表。反击/忍耐的自定目标在 WP46；全局或侧效果由主要效果处理 |

默认集合空时不补虚拟目标；num_targets > 0 且不支持空目标在后段失败，前 PP 已扣。只有本次查询的动态目标类别「单目标且可针对敌方」（num_targets = 1 且 targets_foe 真）、当前列表恰 1、非追击切换、非禁止重定向、非位置招，才进入以下层。邻近限制也取此次类别的远距许可。默认 CURSE 的原始目标为 User，但 U 当前有幽灵类型时，世代 ≥8 本次类别为 RandomNearFoe、旧代为 NearFoe，因此可以在这些门全过时被跟我来等重定向；非幽灵仍用原始类别。精神场地下接地使用者的广域战力本次类别为 AllNearFoes，即使当前只剩一个目标也不满足单目标门。龙箭在这些守卫后先扩展目标，再检查螺旋尾/坚毅，因此后两能力阻止重定向但不撤销已经扩展的龙箭目标；WP46 负责发射。

### 5.2 重定向与标记建立

RedirectAllMovesToUser：U 跟我来标记先 1，扫描盟友已有标记，逐步设成比合格最大值大 1；粉末标记招另设怒粉真。RedirectAllMovesToTarget：可反射，T 聚光灯先 1，再按 T 盟友同法排后。后建者通常标记更大；消费按较小正值优先，不按「最后使用吸引」推断。

消费顺序：聚光灯 → 跟我来/怒粉 → 避雷针 → 引水。前两类用速度序筛存活、未被天空摔投、对 U 异侧、满足近距，标记正且 < 当前候选强度（初值 100）才取；相同值保留先见。怒粉还要求 U 受粉末影响。找到即重建单目标并返回；没有因此立刻判定能否命中或是否保护。

能力吸引要求本次类型电/水；原首目标已有有效对应能力则不再改。否则速度序找非 U、非原首目标、能力有效且近距满足者，可为 U 盟友；不统一加模式破坏者或天空摔投门，显示后改列表并停。后续目标能力免疫另按 WP48 可被模式破坏者忽略，不把「吸引成功」当「免疫也成功」。CannotBeRedirected 跳整个重定向，PROPELLERTAIL/STALWART 是在龙箭扩展后返回，层次不同。

### 5.3 魔法外衣/反弹和抢夺

BounceBackProblemCausingStatusMoves 成功只设当前魔法外衣真。StealAndUseBeneficialStatusMove 置自身抢夺 1，再遍历当前存活全场逐步加至比其它现有值大；包含自己这次刚写的 1，不能保证最终最小标记一定 1。实际消费规则沿 WP40：可抢夺变化招中取最小正标记且 < 100、非天空摔投者，清选中者标记和预选目标，实际 U 与模式破坏者按接管者改；最初普通 PP 扣在接管发生之前。当前显示仍先说原使用者使用，原使用者失败标记真，不能把抢夺当双方各完整使用一次。

有目标的可反射变化招：更早逐目标失败/保护可能已拒；对侧且非半无敌 T 有魔法外衣则标反射并清外衣，有有效 MAGICBOUNCE 且模式破坏者假、未用反弹标志则标反弹并置该标志。无目标的可反射变化招另按速度序扫合格对侧，首个魔法外衣/反弹者接管。本轮尾清状态由 WP42。

反射后保留本招对象，以反射者为新 U、原 U 为预选，重选/重定向、查整招失败与目标资格，直接执行一击、跳过命中检查标记假；不重新做普通选择/扣 PP/本次初始化的完整外壳。未通过目标者被去掉，空目标分支另走本招空列表失败判断。每次反射调用不是通用无限递归，当前反弹标记阻重复；不能把外壳已显示成功推论反回的攻击必定提交。具体对侧变化和内层结束副作用沿 WP40/46 已审阶段。

## 6. 再次使用、复制与递归边界（D）

### 6.1 简单使用与记录

调用族通常构造 UseMove、无真实槽位（−1）、新招式 PP −1、给具名目标或默认 −1，以特殊使用真进入正常使用。初始跳过命中检查标记真（唯既有挣扎对象特例除外）；两标志分开，详 WP40。内层仍先查治疗封锁/重力/地狱突刺/有效讲究锁/封印/招式自有选择资格等，仍拒天空摔投、休息和设施特殊不可行动；随后才因跳过而跳过状态、服从和部分行动阻止。普通目标资格/保护/免疫仍跑，半无敌阻挡在跳过命中前仍可拒；不再普通扣被调用槽 PP 或压力。

梦话预选候选用特殊选择模式，可绕候选 PP 0 和定身/挑衅/无理取闹，但安可、治疗封锁、重力、讲究锁、封印和命令阶段突击背心等仍按真实门。它实际调用时不传原槽，因此候选 PP 不减少。其它调用族不一定先做同一候选筛选，可能选中后才在内层拒。

每个内层使用会开始行动、清下一行动期限标记，成功到记录点改 U 最近使用招/类型和全局最近招/使用者；只有非特殊使用才改最近普通招/原目标/movesUsed 集合。内层失败可能清最近使用记录、取消连用并结束行动；外层后续仍可继续，不自动恢复成调用前记录。这里的特殊标志不等于「不占任何状态写入」。号令/舞者各自保存/恢复字段的例外见 WP47-B/WP49，不把它们与普通调用统一。

### 6.2 调用族的候选与动作

| 身份 | 候选、拒绝和目标 |
| --- | --- |
| UseLastMoveUsed | 在本次使用计数阶段保存先前全局最近招，早于自己写全局记录；空、缺数据或排除效果失败。通过后全局主要效果调用该招，目标默认 −1，不沿用前招原目标 |
| UseLastMoveUsedByTarget | 绕替身；T 最近普通招存在、有数据且 CanMirrorMove 标记才准；实际调用这招并给 T 席位，外壳无动画。不从名字额外造整族黑名单 |
| UseMoveTargetIsAboutToUse | 绕替身；T 选择 UseMove/Shift 且尚未行动门过，再所选招式对象存在、伤害类、非其排除名单；执行先 U.MeFirst 真 → 默认目标简单使用该身份 → 正常返回后清假。WP43 普通 P ×1.5；内层失败不返外层 PP，异常不保证清假 |
| UseMoveDependingOnEnvironment | §3.3 选定身份，逐目标显示转成何招再调用，给原目标席位；选择数据不保证该招内层资格通过 |

完整排除标识及世代增量见附表；拒绝比较是效果字符串，不是任意招式名或继承族概括。当前名单有 ReduceAttackerMovePPTo0IfUserFaints，实际怨念实现身份是 SetAttackerMovePPTo0IfUserFaints：该条不会自动匹配真实怨念，不擅自「修复」数据。同理世代 ≥ 6 借助/梦话明列两回合排除表未包含后增的蓄力升特攻 Meteor Beam 身份，不能由「所有两回合」概括静默补排除。

递归主要靠具名名单、数据标记与局部状态阻断，不存在本轮已证的统一深度上限；挥指 1000 是候选抽取次数上限，不是调用栈限制。未来插件/未知数据会改变候选集合，本规格不承诺所有自定义循环能终止。

### 6.3 复制槽位

ReplaceMoveThisBattleWithTargetLastMoveUsed（模仿）和 ReplaceMoveWithTargetLastMoveUsed（写生）均绕替身；先拒 U 变身或当前已无本招槽；T 最近普通招数据须存在、U 不已拥有同身份、非本族排除且非 Shadow。没有真实玩家菜单选择/取消；多份相同本招槽只替换第一个。

模仿创建新招式并仅替换场上第一个本招槽，显示学习、检查招式变化形态；不改持久个体原槽。写生先把同一槽的持久招式换成新招，再换场上槽、显示、形态检查，形成持久写入；新招按数据初始化 PP/总 PP，不继承原本招已耗 PP 或 PP 提升。外壳普通 PP 此前已扣；模仿原槽的这次 PP 消耗与暂时复制后的 PP 分开。被复制结果并不马上执行；下次行动才能经普通选择使用。

模仿排除：挥指、挣扎、模仿、写生、变身五效果；写生只排自身写生及挣扎，完整源标识见附表。取消/失败发生在字段赋值前则保留槽；成功后后置形态异常没有本地回滚保证。全局学习/遗忘规则不是这两个战斗效果的通用替代。
