# 命令、特殊行动、服从性与行动顺序行为规格（净化正文；批次 10）

分类：combat-requirements（选择 → 登记 → 执行的条件与次序）；性质：实现独立行为合同。

本规格为净化正文：按统一交接将批准输入 WP40《命令、特殊行动、服从性与行动顺序》转写为独立行为文字，不含源文件路径、类名、行号与证据 URL（参考与已读集中登记于 `../../audit/source-traceability.md` 批次 10 条目）。文中保留的字段名、配置键与数据身份名均为数据标识，不构成未来实现的数据结构或接口模板。全部内容为静态证据；**无运行确认**（见 `../scope-statement.md`）。

## 1. 目的、范围与非目标

### 1.1 目的

定义一个战斗回合从「谁选什么」到「谁真正执行、按什么顺序执行」的完整要求：命令目录与控制权；选择、合法性与登记；撤销/重选；执行前复检与执行反馈；PP、物品库存与目标的检查写入分层；服从性与 AI 选择分离；优先级、速度与队列重排；Mega/Primal 的战斗侧资格与时机；Call 与 Shift 的选择语义。

### 1.2 范围

1. 命令阶段（目录、控制权、循环、撤销/重选、占满回合规则）。
2. 选择期合法性（招式可否选择的原因族；物品战斗使用分层；目标合法性；登记写入）。
3. 攻击阶段（阶段顺序、执行前复检、使用招式的完整检查序、失败前后消耗）。
4. 服从性（整数门与不服从分支）与 AI 分离。
5. 行动顺序（优先级、子优先级、速度、平局、重算与重排）。
6. Mega/Primal 战斗侧资格与时机；Call/Shift 的选择语义。

### 1.3 非目标

- 不定义招式效果值、伤害公式、命中公式细节（WP43）、效果族（WP44–WP50）、特性/道具修正族（WP48/WP50）、AI 评分（WP51/52）、换人执行与位置变更结果（WP41）、回合末与终局（WP42）、捕获公式与接收（WP38）、个体 Mega/Primal 完整域（WP22）、Shadow 完整生命周期（WP23）。
- 不定义界面演出（WP67-A）。

## 2. 概念与术语

| 术语 | 定义 |
| --- | --- |
| 选择（choice） | 每席位的行动决定，包含动作类型、该动作需要的招式/物品/替补身份及目标；排序还会确定供后续资格检查读取的招式优先级。动作身份 ∈ {None, UseMove, SwitchOut, UseItem, Call, Run, Shift}；不规定字段数量、固定槽位或容器表示。 |
| 控制权 | 玩家拥有的席位由玩家选择；AI 席位与「玩家侧 AI 控制」模式下由 AI 选择（本规格只调用 AI 接口，不定义其策略）。 |
| 登记 | 把选择写入选择槽的动作；登记 ≠ 执行——执行期按 §8 第 2 条的分族合同处理，换人执行不重新调用组合检查（WP41）。 |
| 占满回合 | 某些选择（逃跑、投球）一经确认，本回合不再为其余席位选择，（对逃跑）且阻止继续选择。 |
| 强制动作 | 多回合招式中途、已被动作锁定的席位等——命令不可选，直接沿用。 |
| 子优先级 | 同一招式优先级内的「最先/最后」微调（特性/道具）。 |
| 不服从 | 玩家拥有的高等级个体在服从门命中时改用其它动作/动作失效的规则族。 |

## 3. 命令阶段

### 3.1 回合的三阶段

命令阶段 → 攻击阶段 → 回合末（本规格只覆盖前两者中与选择/执行合同有关的部分；回合末归 WP42）。

### 3.2 命令阶段流程

1. 复选清空：可出示命令者的选择槽清零；不可出示者保留（多回合招式中途等）。
2. 只把「非负的未执行 Mega 登记」复位为 −1（登记值 ≥ 0 → −1；已用的 −2 保留——「每训练家一场一次」的资格不因命令阶段复位而跨回合回退）。
3. 玩家循环（按席位升序，仅玩家拥有席位）：跳过裁定/已登记/不可出示者；每席位进入小循环：
   - 主菜单返回：−1 取消（返回上一席位）、0 战斗、1 背包、2 宝可梦、3 逃跑/取消或 Call、4 Call、−2 调试菜单。
   - 逃跑仅对「本回合第一个被选择的席位」出示；选择后当场尝试（见 §3.3）——返回 −1/1 都停止本回合其余选择（−1 已消耗本行动）、返回 0 则撤销选择继续；对后续席位该格显示「取消」。
   - Call 仅当「暗影类型存在且为训练家战斗」时替代逃跑格（也被目标菜单模式表沿用）。
   - 被抓住（天空摔投）期间除「招式」外均拒绝并提示。
   - 成功登记会跳出小循环、保留选择（供攻击阶段使用）；取消点只在未成功退出的路径：战斗/背包/宝可梦/逃跑菜单返回失败或取消时，走小循环末尾的撤销（物品未用 → 退回；已登记 Mega → 撤销；清空槽位）。返回上一席位（−1）分支只撤销上一席位的选择；更新已选择席位记录后退出小循环，不额外对当前席位调用一次撤销。
   - 选择逃跑即当场尝试（见 §3.3）；调试结局菜单的取消也返回 −1，同样停止本回合其余选择（决定不变）。
   - 战斗结束（决定非 0）→ 立即停止全部选择。
4. AI 循环（同席位扫描，选择权非玩家或玩家侧 AI 控制）：调用 AI 默认命令接口；不读取本规格之外的 AI 评分。
5. 选择登记后的再次进入（同一小循环内重选）：先予撤销；重选覆盖。

### 3.3 各命令的登记语义（分族，不共用一个合同）

- 招式：合法性 → 登记 →（非单打）选择目标并登记目标；Mega 登记在战斗菜单内切换（−2，见本节 Mega 条目）；放弃 →（−1）取消。
- 背包：见 §4.2；登记即从库存扣除（部分物品）；可「占满回合」（投球）。
- 宝可梦：查看/换人入口（可取消）；换人登记的完整资格与执行归 WP41；命令阶段只登记 SwitchOut。
- 逃跑（玩家）：在命令阶段当场尝试（即时调用逃跑判定并消费返回值）：返回 0（不可尝试/被拒前门）→ 撤销选择、继续命令选择；−1（失败，已消耗本行动）或 1（成功，决定置 3）→ 停止本回合其余玩家选择。概率/守卫细则归 WP41，本规格只登记时点与返回消费者。敌侧野生：由对应调用者登记 Run 并返回 −1（无玩家式即时判定）；攻击阶段的「漫游必逃」（总是逃跑规则）是独立执行路径（按决定 3 结束）——不能从存在 Run 枚举推导「所有 Run 同义」。
- Call：登记 Call（无目标）。
- Shift：仅在可 Shift 为真时于战斗菜单内可选（−3）；登记 Shift 且撤销已登记的 Mega；实际位置交换结果归 WP41。
- Mega 登记：战斗菜单内切换（−2）——登记/取消/互换；登记后继续选招；取消整份选择或改选 Shift 会撤销。

## 4. 选择期合法性

### 4.1 招式可否选择（原因族）

在命令期与执行期共用同一检查（执行期以不打断消息呈现）；屏蔽族（每条都是独立拒绝，不得合并）：

- 招式被定身（非特殊使用）；
- 回复封锁＋回复类招式；
- 重力＋不可用招式；
- 喉锁＋声音类招式；
- 选择带：已记录招式与所选不同且（持有三种选择道具之一 或 特性大猩猩战术）——记录招式已不在招式表时先自清；
- 挑衅＋变化类招式（非特殊使用）；
- 折磨：上一招式与所选相同且未受指令（非特殊使用、非挣扎）；
- 封印：任一存活对侧个体已封印该招；
- 突击背心：只在命令期拒绝变化类招式（执行不拦），Me First 函数族除外（其数据为变化类却明确不被该背心条件拒绝）；
- 招式自有的「可否选择」附加条件（函数族）。

另有全表扫描版（任意招式可选否）供「能否出示战斗菜单」与自动选择判定（有可选项 → 真）。

### 4.2 物品选择与库存分层

- 可战斗使用类型（数据侧）：0 不可用；1 对个体；2 对个体招式；3 对场上席位；4 对对方（球）；5 无目标。
- 选择期：背包过滤要求类型非 0；类型1/2要求对个体效果存在、类型3要求对场上效果存在；类型4/5没有同样的效果存在门。各路径取得有效个体并通过战斗资格；无资格登记且未命中条件登记时默认允许（不等于任意未知物品可用）；登记即扣除（消耗品）：玩家 → 背包移除（移除失败报错）；非玩家 → 业主道具列表移除。投球占满回合（球类物品）。
- 非游戏内战斗（内部战斗标记假）→ 背包不可用（「此处不能使用物品。」）。
- 执行期（按战斗使用家族分列）：家族 1/2/3/5 的执行器各自再次调用「可在战斗使用」——失败 →「但没有任何效果！」并按持有者退回（玩家：可加入校验；非玩家：压回列表）；通过 → 触发对应效果并清选择数据。家族 4（球）执行器不通用复检/退款：直接触发球的战斗使用处理器并清选择（捕获未成功 ≠ 退球）。目标不存在（家族 3）→「但无法在这里使用！」后按失败退回。辅助前置（空/蛋/查封/超频非香气）属实际选择路径的调用点，不保证执行期全部重跑；资格复检通过后效果回调的返回值不决定通用退款（与已审 WP28 一致）。
- 合法配置的无目标消耗品 I、非重要/非球/非抢夺物、BattleUse=Direct(5)，所有效果/资格登记缺失且条件登记不命中，内部战斗存活玩家、库存1：正常菜单可显示Use、默认资格真；登记1→0，执行复检真但无效果，清选择，库存仍0且不退款。仅把同一数据的家族改1或3时，效果存在门先拒绝、库存1保持（与 WP28 §3.5/§6 一致）。
- 投球本身：本规格只闭合「命令资格与登记」；捕获判定/接收归 WP38。物品库存主规则引用 WP27；物品主动使用（含战斗入口的一致性）引用 WP28。不声称「所有执行路径逐条再查同一资格」——按上表分族。

### 4.3 目标合法性（登记期）

- 目标类型由招式的目标数据给出；单打外需选择目标（−1 取消目标 → 回到招式菜单）。
- 目标许可全表：近身友/含自身或近身友/全体友/自身及全体友/近身敌（含随机/全体近身敌）/敌/全体敌/近身其它（含全体）/其它——各自用对立关系与邻近关系判定；目标数为 0 的类型不参与。
- 光标初始位、候选文字、按钮态、确认登记和执行解析分开：近身友（NearAlly）的初选按非己同侧存活成员的席位序取第一名，异常边界中初选不保证邻近。正常3v3后续状态中使用者0存活、中央盟友2濒死且无后备、远端4存活时，4没有候选文字（不等同已濒死可选成员的空名称），成员/数据框可高亮4但按钮不呈选中态；USE仍登记4。保持布局与存活状态且正常到执行解析时，邻近资格拒远4，亦无近侧存活盟友兜底。2存活则先选2；无任何存活非己同侧成员才回自己0（与B033同类回退分开，不泛称无近邻即回自己）。真正邻近表仍沿 WP39，不修参考异常。近身敌按对面取序取近且活者；敌取该序活者；其它初指自己，界面呈现沿 WP67-A。

## 5. 攻击阶段

### 5.1 阶段顺序（一次攻击阶段内的固定次序）

1. 进入攻击阶段：全体存活席位回合计数 +1；成功状态清零；未选择「招式/换位/换人」的席位的余怨/怨恨效果清除；未选择对应招式的愤怒清除。
2. 整轮排序计算（全量）（§6）。
3. 子优先级提示消息（特性/道具的子优先级触发；只对最终认定为该来源者）。
4. Call 行动（按当前顺序）：逐一执行（每个 Call 计为「成功动作」，供踩踏暴怒类参考）。
5. 换人行动（按当前顺序）：提示召回 → 追击打断检查（见 §5.5）→ 清除全场的半血/掉档标记 → 实际替换＋入场钩子（执行细节归 WP41）。
6. 若战斗已结束 → 返回。
7. 物品行动（按当前顺序）：按使用类型调用对应执行器（§4.2）；结束后可选重算顺序（配置：速度变化后重算）。
8. 若结束 → 返回。
9. Mega 进化行动（按当前顺序，非野生、选择了招式且为登记席位的持有者）：执行变身（§7）。
10. 招式行动：先为未行动者播报蓄力消息；然后循环轮转：
    - （a）先出（标记 MoveNext 且可选）的未行动者；
    - （b）常规顺序中未被压后（Quash）的未行动者；
    - （c）压后者：世代 ≥ 8 单独一遍；更早世代按「压后等级」由小到大多遍执行；
    - 每次只执行一个席位；执行后如产生「先行推进」标记则从（a）重新轮转；全部执行完后检查是否仍有未行动的招式/换位者，若无则结束本阶段。
11. 单席位序：非濒死；野生·「漫游必逃」（总是逃跑规则）：可逃即显示逃跑消息并把决定置 3（占满其行动）；Shift：执行位置交换与「移到对面/中央」消息、取消多回合、记「本回合已动」；非招式行动：先/后回合清理直接返回；招式：使用招式（§5.2）→ 裁判 → 可选重算顺序。

### 5.2 使用招式（执行期完整检查序）

1. 两种标志分开：特殊使用标记（本次调用性质）与跳过命中检查标记（是否跳过后段检查）——后者在多回合分支改写之前按「调用时即为特殊使用且非挣扎」确定；因此多回合续招后来转特殊使用不会追溯打开后段豁免，挣扎按特殊调用但该标记仍为假。四类调用对照：

| 调用类 | 跳过命中检查标记 | 状态/服从等后段检查（§5.4 第 6–12 步） | PP |
| --- | --- | --- | --- |
| 普通命令/AI 选择 | 假 | 全跑 | 前置通过后扣（第 4 步） |
| 特殊调用（非挣扎：被调用招等） | 真 | 跳过 | 不扣 |
| 挣扎（特殊调用路径） | 假（选择槽 = 挣扎） | 全跑（睡眠/冰冻/混乱/麻痹/着迷照常） | 不扣 |
| 多回合续招 | 按原始调用时判定（通常原始为普通 → 假） | 全跑 | 不扣 |

2. Encore 跨回合改招：若本轮中途被安可且登记招与安可招不符、且被安可的新招当前可继续选择（检查对象是新招，不是原登记招）→ 改招并清目标。
3. 执行前复检（§5.4）；失败 → 记录失败、无条件清「最近使用招式/类型」，仅普通使用同时清「最近常规招式/目标」，特殊使用保留后一组、给对手经验结算机会（可能被反伤击倒）、取消多回合、结束该席位行动。
4. PP 扣除（前置已通过后先扣、再进入目标与后段判定）：非特殊使用且可扣时扣 1（如 5 → 4）；无 PP → 消息序列（「X 使用了 Y！」＋「但没有 PP 了！」）、失败标记、结束。注意：前置复检（第 3 步）失败不扣 PP；但无目标、后段阻挡者、招式自有失败均发生在扣 PP 之后——这些后段失败已消耗 PP（已扣 PP 不因这些失败回补）。
5. 战斗切换特性形态：坚盾剑怪——伤害招 → 刀剑形态；王者盾牌 → 盾牌形态（特性驱动，非道具）。
6. 计算本次属性；启动模式破坏者标志；登记/取消两回合蓄力；调用招式使用计数；节拍器道具计数（连续成功使用同招 +1，否则清零）。
7. 记录最近招式/属性/常规招式/目标与已用招式集；全局最近招与使用者（供清醒/自我淘汰条款）；成功状态置「假定失败」。
8. 使用者改写（抢夺）：可被抢夺的变化招，接管者 = 标记为正且数值最小者（标记自 1 起、后来登记者更大；扫描从上限 100 起逐步接纳更小值，跳过标记 0 与天空摔投者；相同有效数值保留先遍历者）；随后清其标记、清目标预选、模式破坏者按改写后的使用者重定。
9. 目标确定与重定向：按目标类型定位（预选目标合法性不通过时退回随机/全体分支）；重定向序：Spotlight ＞ 怒粉/跟我来 ＞ 避雷针/引水；换人中断（追击）上下文与「位置目标」招不参与重定向，拥有特性「螺旋尾/坚决」的使用者不参与；近身限定按目标数据。
10. 压力额外扣 PP（对逐个受压目标及「影响敌侧」招式）。
11. 阻挡者（鲜艳之躯/女王威严类）→「X 无法使用 Y！」、失败、取消多回合、结束。
12. 使用消息；抢夺消息（原使用者记失败）。
13. 招式自有失败检查 → 失败、取消多回合、结束。
14. 开始使用钩子与消息；自融解（冰）；火药（火属性＋粉末效果 → 伤害并失败）；原始天气压制（大雨熄火招/烈日蒸发水招 → 失败）；变幻自如/自由者变身属性（含诅咒目标特例重取目标）；快速蓄力招处理。
15. 目标空集处理：需要目标但全灭 →「但没有目标……」、失败；否则对每个目标做「首发成功检查」（§5.3）并标记不受影响者；对无目标变化招做魔法外衣/魔法反弹寻找。
16. 多击循环：每次一击执行命中处理（§5.3）；失败终止并回填「是否首击失败」；每击后检查用户濒死/睡眠冰冻/全目标濒死而终止。
17. 战后：成功状态更新与属性相性累计；多击消息；魔法外衣/反弹的反弹执行（对侧作为新使用者重新确定目标与命中）；招式每击后钩子；濒死统一结算；招式后通用效果（杯具、贝壳之铃等族，WP50 前向）。
18. 模式破坏者关闭；经验结算；竞技场上技能更新；暗影·超频触发（仅当该席位未被替换——选择非 None）；结束回合清理（选择带记录、蓄力残段、宝石已耗清空、甲壳陷阱/喙嘴…）；号令（Instruct）：消费时按当前最近使用招查找真实槽，以特殊使用 = false 的普通使用入口再次执行；实际前置通过才扣 PP，普通状态/服从/命中仍适用。正常返回恢复保存的已行动轮、原命令保留，不表示 PP、最近招或使用记录不变；具体前门与消费字段见 WP47-B；舞者：同招舞蹈类成功且非抢夺时，使其余舞者特性者依序「续舞」（临时标记防递归；不占行动、保留其原多回合计数）。
19. 裁判在合适点检查双方全灭（平局/胜负）；自爆类条款改写见 §8。

### 5.3 命中前/每击成功检查（与目标）

首发检查（每目标一次）：两回合蓄力期直接通过；招式自有对目标失败；精神场地＋优先招 →「精神场地保护」；工艺盾（变化招、非全体目标）；守卫族（全体护/快/广域，跳跃点：无视护罩特性＋接触招除外）；保护/王盾/尖刺盾/剧毒壁垒/障壁/垫子（各自附带接触反制：降攻、伤害 1/8、中毒、降防）；魔法外衣/魔法反弹（变化招、非半无敌、对敌）；特性免疫（先于属性免疫）；属性免疫（伤害招且相性无效）；恶属性对恶作剧之心加速招免疫；浮空对地面招（漂浮/气球/磁力/意念移物各具名）；粉末招式（草＋更多属性效果/防尘/护目镜）；替身（变化招、非无视替身）。

每击检查：蓄力期通过；锁定命中（锁定/心眼位）；招式覆盖；无防守、未来攻击标记或帮助类只在此层允许越过相应半无敌/天空摔投阻挡，不因此直接返回命中真；未获该豁免时，半无敌（天空/地下/水中/去除保护）不匹配 → 未命中，被天空摔投且非使用者且招式非击中飞行 → 未命中；跳过命中（跳过命中检查标记为真，按 §5.2 的调用分类）；命中计算（含反击/镜反）；未命中 → 按目标状态显示消息族（爱心回避/多目标「躲开了」/招式自定义/通用「攻击落空」）。

N01 局部校准（2026-09-27，独立首审已确认新证据）：普通命中入口的用户/目标无防守处理器可把基础命中设为 0，目标方处理器受模式破坏者门控制；普通命中数值和该门引用 WP43。普通非特殊调用、基础命中 70、双方命中/闪避 0 阶、用户模式破坏者有效且无无防守、目标有效无防守，排除其它提前门和修正时，抽取 69 命中、70 未命中；关闭模式破坏者则目标处理器可使普通命中通过。此结论不推广到所有特殊命中家族。旧「一方有即命中」的概括据新证据在本轮实际改写；既有两标志/PP 合同及旧 12 项关闭保留，实际修订及传播已于 2026-09-27 有限复审 CLOSED。

### 5.4 执行前复检与不服从触发点（序）

1. 招式可否选择复查（不通过 → 失败标记）。
2. 天空摔投中（无消息）→ 失败。
3. 破坏死光回复期（早于懒惰）：消息「必须回复！」；若特性懒惰则翻转懒惰标记；失败。
4. 战斗宫殿特殊通道（非普通命令）→「似乎无法使用力量！」、失败。
5. 跳过命中检查标记为真（特殊调用且非挣扎）→ 跳过第 6–12 步；为假（普通、挣扎、原始为普通的多回合续招）→ 依序执行 6–12。
6. 状态延续：睡眠计数递减/醒来或继续（非可睡用招 → 失败）；冰冻 20% 自解否则继续（可自融招免检）。
7. 服从检查（§5.6）。
8. 懒惰：翻转后若为「偷懒」→ 消息、失败。
9. 畏怯 → 消息、失败（并触发「畏怯时」特性）。
10. 混乱：计数递减/解除或 33%（世代 ≥ 7；更早 50%）自伤混乱伤害 → 失败。
11. 麻痹 25% → 失败。
12. 着迷 50% → 失败（显示着迷对象）。

### 5.5 追击打断

换人行动前：顺序表中满足「对换人者对立、本回合未动、登记招函数为追击、可命中换人者、可继续选择、非睡眠/冰冻、非天空摔投、非懒惰偷懒」的席位——若其（非野生）已登记 Mega 则先 Mega——把追击目标改为被换者并立即执行其行动；执行后若决定 > 0 或换人者已濒死则停止。

### 5.6 服从性（整数门，独立复算）

- 只对：玩家拥有、游戏内战斗、动作非招式不检查、多回合续招不检查。
- 临界等级 L = 10 ×（徽章数 + 1）；徽章 ≥ 8 → 取最大等级（等效无门）。
- 默认 ANY_HIGH_LEVEL_POKEMON_CAN_DISOBEY=false、FOREIGN_HIGH_LEVEL_POKEMON_CAN_DISOBEY=true，两者独立可配置，不由世代自动决定。触发条件：配置「任意高等级可拒绝」或「外来高等级可拒绝＋个体为外来」；且 当前等级 > L：a = ⌊（等级 + L）× 0–255 抽样 ÷ 256⌋；a ≥ L → 计入不服从。
- 超频不服从：暗影·超频中：非暗影招 → 0–99 抽样 < 20 才服从（暗影招与无招恒服从）。
- 任一计入 → 进入不服从分支：
  - 睡眠中且招可睡用（打鼾/梦话）→「无视指示继续睡」（动作终止，无 PP 损失前状态）。
  - b = ⌊（等级 + L）× 0–255 抽样 ÷ 256⌋；b < L →「无视指示！」：若不能出示战斗菜单 → 终止；否则从其它可继续选择的招中随机改用（无其它招 → 终止）；改用后仍消耗所选新招 PP 并按新招执行。
  - 否则：c = 等级 − L；r = 0–255 抽样；r < c 且可睡眠 → 自我入睡、终止；前一自我入睡门未命中且 r − c < c、非睡眠 → 混乱自伤、终止；再否则随机四选一拒绝消息（不肯服从/转过头去/偷懒磨蹭/装作没听见）、终止。
- AI 选择与服从分离：AI 只产生「合法选择」，服从性在执行期作用于玩家拥有席位；两者不共用随机源描述。

## 6. 行动顺序

### 6.1 排序输入

- 参与集合：现有席位（空位跳过）；每席位需要其身份、速度、招式优先级、特性/道具子优先级与最终子优先级、平局序。只规定比较输入及其来源，不规定七项条目或内部存储。
- 招式优先级：招式基础优先级 → 特性改写（先制类，WP48/WP50 提供具体族）；保存该行动的结果供精神场地/快守检查读取。
- 子优先级（仅招式与 Shift 选择计算）：特性族（如懒惰类）与道具族（先制爪/释迦果/迟钝尾/满腹香炉等）分别取子优先级；合并规则：若特性为 0 且道具有值、或特性为负而道具为正 → 采用道具并标记「道具来源」；否则若特性非 0 → 标记「特性来源」；两来源标记供提示消息。
- 平局序：全量计算时为随机洗牌序；每次全量计算重新随机——同一回合内多次调用（非全量）保持既有平局序稳定。

### 6.2 排序规则

按序比较：招式优先级（高者先）→ 最终子优先级（高者先）→ 空间（戏法空间）状态：开启时速度低者先、否则速度高者先（比较速度值）→ 平局序。

### 6.3 重算与重排时点

- 全量计算：攻击阶段开始时一次。
- 增量重算（不重全量、可传席位子集）：仅当以下触发且配置开启：速度变化后（物品执行完之后/每次单席位行动之后）——重读速度与「特性改变的招式优先级」，任一变化即重排；戏法空间状态与快照不一致 → 重排（快照在计算时捕获）。
- Mega 进化后：可选按「仅该席位」重算（配置）。
- 仅速度排序变体：供重定向/技能优先级等场合（按速度＋平局序，忽略招式优先级）。
- 已行动者在招式阶段被跳过但仍在序表中。

## 7. Mega/Primal、Call、Shift

### 7.1 Mega（与 Primal 分开）

- 资格（按序）：未关闭开关 → 个体有 Mega 形态 → 非野生 → 调试+Ctrl 的特例直通（位于前三项之后）→ 非天空摔投中 → 持有环（玩家——背包中任一「环」标志物品；非玩家——业主道具列表含环物品）→ 该训练家本场尚未使用（登记值 == −1）。资格在战斗菜单中显示（按钮状态：未按/已按）；资格、裸登记与执行分层（登记只写槽，执行在攻击阶段）。
- 预登记/取消：登记 = 按业主记录其席位；再次触发切换取消；取消整份选择或 Shift 会撤销；命令阶段开始复位残留；登记后仍可换招。
- 执行时机：攻击阶段第 9 步（换人/物品之后），按当前顺序对登记了 Mega 且选择招式者执行；执行后槽位置 −2（防止重复）；行动顺序可选重算。
- 执行内容：计数（仅玩家拥有者）；破解幻觉；消息族（烈空座特例 vs 通用「反应」）；换形并刷新；对耿鬼清意念移物标记；触发失去/获得特性。
- 次数与归属：每训练家每场一次（−1 → 席位 → −2）；不得把 Mega 的登记/次数门套给 Primal。

### 7.2 Primal（独立）

- 资格：非濒死；有 Primal 形态且未 Primal；无环、无开关、无次数登记、无野生限制（与 Mega 不同，静态对照）。
- 执行：动画特例（盖欧卡/固拉多两段）；换形刷新；消息；不写 Mega 登记槽，不影响行动顺序重算接口。

### 7.3 Call

- 登记：任何可出示命令的玩家席位可登记；菜单格仅在「暗影类型存在且训练家战斗」时出现（细节归 WP67-A）。
- 执行：视为成功动作（踩踏暴怒）。
- 结果分支（分开追踪）：暗影且超频中 → 解除超频并结算心量表「呼唤」（数值效果归 WP23）；暗影但未超频 →「但什么也没发生！」；非暗影且睡眠 → 治愈睡眠；否则若命中率可提升 → 升一段命中；否则「但什么也没发生！」。
- Shadow 完整生命周期（量表、净化）归 WP23；本规格只闭合战斗侧入口与结果分类。

### 7.4 Shift 选择

- 资格：任一侧 > 2 席；本侧 3 席时中位（具体两人中位）不可换、1 席不可换；换位对象与自身同一业主。
- 登记：把选择记为 Shift；实际执行在攻击阶段以「位置交换＋消息」完成（实际位置结果与前后状态归 WP41）；执行后取消多回合计数（与 WP41 交界）。

## 8. 规则与不变量

1. 命令阶段只为「可出示命令」的席位索取选择；不可出示者（强制动作）沿用既有选择且不消耗回合选择。
2. 登记 ≠ 执行：招式与物品执行器按各自分族做执行期复检（§5.2/§4.2）；复检失败按分族消费/退回（物品退还；前置失败不扣 PP、后段失败已扣）；换人执行不重新调用组合检查（见 WP41 分层）。
3. 一方选择不影响另一方选择的顺序（玩家先、AI 后），但决定结束会随时截断。
4. 玩家逃跑在命令阶段当场判定：−1/1 停止本回合其余玩家选择（−1 已耗行动）、0 撤销继续；投球占满回合；逃跑格仅第一个选择席位为「逃跑」。
5. 多回合续招使用替换后的招式并按特殊使用路径执行（不再扣 PP）；但跳过命中检查标记按原始调用判定、不追溯打开后段豁免（§5.2 表）；特殊使用不覆盖「常规招式」记录（按路径区分）。
6. 目标在登记期与执行期各判定一次；执行期重定向规则按优先级串行（Spotlight ＞ 粉/跟 ＞ 引）；位置目标与追击上下文免重定向。
7. 行动顺序由（招式优先级 → 子优先级 → 空间方向速度 → 平局序）决定；平局序每全量计算重抽；增量重算按配置触发。
8. 服从入口按跳过命中检查标记分层（§5.2/§5.4）：真则跳过该后段，假则在此前检查通过后进入服从检查；挣扎虽属特殊使用，该标志仍为假，不能仅凭特殊使用获得状态/服从豁免。服从检查自身对多回合、非招式、非游戏内或非玩家拥有的情况直接通过；其它情况按 §5.6 的等级/配置等前提判定。不服从随机为整数取样（256/100 面）；普通调用改用招仍扣该招 PP。
9. Mega 每训练家一场一次且需环与登记；Primal 无次数门/无环/无登记——两者不得共用资格描述。
10. Call 的四类结果按「暗影超频/暗影常态/睡眠/其它」分支；Shift 的执行结果与替补换人分离（WP41）。

## 9. 边界与失败

- 需要目标的招式在后段发现无目标：显示「但没有目标……」并失败。普通非特殊招前置已通过、PP = 5、无额外压力扣减时，已扣为 4，失败不回补；若前置已失败则尚未扣 PP。特殊调用与多回合的 PP 规则仍按 §5.2 分列。
- 招式在命令后被禁用/状态变化：执行期复检失败（消息以非打断呈现）、失败且可影响多回合取消。
- 携带选择带的记录招被替换出招式表：选择期自清记录。
- 无 PP 且被选择（外部改写或特殊路径）：消息后失败；特殊使用不扣 PP（总 PP ≤ 0 无限 PP 同理）。
- 抢夺夺取：原使用者记失败、抢夺者按新使用者执行；抢夺目标预选清除。
- 魔法外衣/反弹的无目标变化招：改为对反弹者执行；执行成功与否分别标记双方失败。
- 戏法空间开启/结束：重排；平局序不因重排重抽（非全量路径）。
- 战斗宫殿路径与调试动作（−2）不产生普通命令选择；调试回合达 100（调试）触发按时判定并中止（WP39 记录）。
- 超频只对非暗影招设 20% 服从门；被替换的席位不触发超频（选择为 None）。
- 白刃战类条款：自爆败者/平局改写属条款键消费（WP39 登记），本规格仅登记其改写点（自爆招失败路径与回合末骤死）。
- 未运行确认：所有随机器、菜单输入与战斗实况。
