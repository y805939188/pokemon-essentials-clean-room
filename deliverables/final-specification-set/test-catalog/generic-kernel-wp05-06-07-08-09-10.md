## IO：诊断、文件与 HTTP（IO01–IO15）

| ID | 输入／前提 | 推导预期 |
| --- | --- | --- |
| IO01 | https 地址调 GET 基础入口 | 传给宿主（无前缀检查；宿主协议能力未验证） |
| IO02 | https 地址调 POST 基础入口 | 被 http:// 前缀检查挡下（当前实现；不由此断言 GET 同样拒绝） |
| IO03 | 下载返回非表结构响应 | 基础入口原样返回（非无条件空字符串） |
| IO04 | 状态 200 后写文件报错 | 基础入口异常可能向调用方传播；到文件便利入口捕获（吞没） |
| IO05 | 状态 404 | 返回空字符串；指定文件名时不写文件 |
| IO06 | 读取目标是目录 | 首字节入口归一空值（捕获『目标是目录』类）；全文入口不归一（异常可能传播）——捕获集合按入口不同 |
| IO07 | 「读取结果或空表」形式的回退写法 | 仅在返回空值/假时回退；文件缺失是否触发未验证（返回空值 ≠ 文件缺失） |
| IO08 | 调试模式普通脚本异常 | 关键段包装打印并记录错误日志；超时转重启信号 |
| IO09 | 非调试模式普通脚本异常 | 按宿主未知行为（无全模式日志保证；未验证） |
| IO10 | 非调试模式脚本超时 | 打印异常＋紧急保存后重抛 |
| IO11 | 重启/退出信号到达关键段包装、编译主流程等分支 | 原样传播；插件脚本执行入口则经插件诊断/退出路径（捕获范围不同） |
| IO12 | 错误日志文件不可写 | 日志写入未捕获失败：后续打印/复制提示不能保证发生 |
| IO13 | 删除目录树入口；目标 D 是存在的普通空目录，父目录存在；权限允许、无隐藏残留/并发变化、所有调用成功 | D 本身删除，父目录保留；不能解释为仅清空内容。翻译覆盖 LZ12 是保留目录的反向入口 |
| IO14 | 同 IO13 的入口与成功前提，D 只含一个普通文件 f | 先删除 f，后删除 D；最终 f 与 D 均不存在，父目录保留 |
| IO15 | 删除目录树入口列举顺序已给定为 f1、f2；删除 f1 成功，删除 f2 因权限拒绝失败且未删除 f2，D 原含两普通文件 | 操作异常向调用方传播；f1 已删除，f2 和 D 尚在，不能保证回滚或继续删根。本例不执行文件删除 |

## LZ：本地化（LZ01–LZ17）

| --- | --- | --- |

| LZ08 | 明确为非地图节 `SCRIPT_TEXTS`（域 24），内容 `123`／`编号` 两行；输入可读且该节非空；完整编译对照还给定旧 .dat 存在且输出成功打开为覆盖写 | 首条纯数字 → 按数组解释；行数 2 不能被 3 整除 → 拒绝，未登记该节；完整编译对照中输出已在解析前截断，单文件解析入口本身不打开输出 |
| LZ09 | 明确为非地图节 `SCRIPT_TEXTS`（域 24），内容 `A123`／`编号` 两行，输入可读且节非空 | 按哈希解释：登记 `A123` 对应 `编号`（经逆归一化与键转换）；不因域 24 强制数组 |
| LZ10 | 明确为非地图节 `SCRIPT_TEXTS`（域 24），内容 `0`／`原文`／`译文` 三行，输入可读且节非空 | 按数组解释：索引 0 保存 `译文`；形态只由首条数字决定；内容索引 0 不等于 LZ17 的数字节头 0 |
| LZ11 | 各例明确为地图节 `Map005`，分别给两行 `123`／`编号`、三行 `0`／`原文`／`译文`，输入可读且节非空 | 两例识别为数组后都**立即**因地图节不允许数组而拒绝，早于行数检查；三行仍拒绝，是 LZ10 非地图节的反向对照 |
| LZ12 | 提取目标 D 及子目录存在，递归列举返回普通 txt/非 txt 文件；默认消息可用，确认替换且列举、删除、写入全部成功 | 删除列举的全部文件（不限 .txt）后写新译文文件；D 与原有子目录本身保留，先删后写非原子；与 IO13/IO14 删除目标根区分 |
| LZ13 | 候选语言 ≥2，载入菜单把 A 改选 B；已读存档数据有效且非空，设置对象和消息文件可用，写回成功 | 玩家语言和游戏消息切到 B；选项写入已读存档数据并直接写回文件，不经常规保存路径；与 LZ15/LZ16 作者导出区分 |
| LZ14 | 候选语言 ≥2，载入菜单把 A 改选 B；已读存档数据为空，设置对象和消息文件可用 | 可改变游戏语言和消息，但不写存档；判定依据是数据为空，不把文件存在性视为同一判定 |
| LZ15 | 当前游戏语言/消息集 A，作者候选 A/B；调试翻译提取选 B 后，在 core/game 问题取消，尚未进入导出器 | 当前玩家语言与消息集仍为 A；不创建、删除或重写导出文件。B 是导出目标参数，不是游戏语言切换 |
| LZ16 | 同 LZ15 的 A 与候选；选 B、core 并成功导出；默认 core 消息含至少一项，目标目录原不存在、所需材料可读且文件操作全部成功 | 建立 `Text_<B片段>_core/` 并输出作者文本；游戏语言/消息集仍为 A，不写玩家语言或游戏存档。不能用成功生成文本推成当前语言改变 |
| LZ17 | 单文件解析，独立三例非空节头分别 `1tail`／`0`／`SPECIES_NAMES`，均给内容 `A`／`B` 两行；输入可读且无合并冲突。完整编译失败对照还给定旧输出已成功打开为覆盖写 | 非零整数前缀先行：`1tail` 归编号 1、哈希登记成功；数字节头 `0` 拒绝，不登记该节；`SPECIES_NAMES` 常量归编号 1、成功。常量 `EVENT_TEXTS` 的编号 0 不因数字头 0 拒绝而失效；完整编译失败不恢复已截断输出 |

## SV：保存、启动、新游戏与继续（SV01–SV11）

| ID | 输入／前提 | 推导预期 |
| --- | --- | --- |
| SV01 | 无存档文件启动（普通路径） | 存档数据为空表；仍显示菜单（新游戏/选项/退出等；语言候选 ≥2 时含语言项） |
| SV02 | 调试模式＋无打包归档＋`SKIP_CONTINUE_SCREEN` 三门同时成立；各例已读存档数据分别为空/有效非空，前序准备成功 | 两例都跳过菜单；数据为空才走新游戏，有效非空走继续。三门本身不保证新游戏，也不能只凭文件存在性替代数据前提 |
| SV03 | 继续且 magic_number 一致、非 safesave | 按地图变更恢复（不重新设置地图） |
