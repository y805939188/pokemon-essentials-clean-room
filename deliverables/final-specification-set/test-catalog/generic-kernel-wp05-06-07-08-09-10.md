## IO：诊断、文件与 HTTP（IO01–IO12）

| ID | 输入／前提 | 推导预期 |
| --- | --- | --- |
| IO01 | https 地址调 GET 基础入口 | 传给宿主（无前缀检查；宿主协议能力未验证） |

| IO07 | 「读取结果或空表」形式的回退写法 | 仅在返回空值/假时回退；文件缺失是否触发未验证（返回空值 ≠ 文件缺失） |
| IO08 | 调试模式普通脚本异常 | 关键段包装打印并记录错误日志；超时转重启信号 |
| IO09 | 非调试模式普通脚本异常 | 按宿主未知行为（无全模式日志保证；未验证） |
| IO10 | 非调试模式脚本超时 | 打印异常＋紧急保存后重抛 |
| IO11 | 重启/退出信号到达关键段包装、编译主流程等分支 | 原样传播；插件脚本执行入口则经插件诊断/退出路径（捕获范围不同） |
| IO12 | 错误日志文件不可写 | 日志写入未捕获失败：后续打印/复制提示不能保证发生 |
