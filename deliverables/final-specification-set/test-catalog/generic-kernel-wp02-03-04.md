## B. 内容身份、注册与 schema（KR01–KR13）

| KR02 | 遭遇按版本枚举的存在条件：单一地图、正常编译的符号键表，枚举目标版本 2 | 已有 0、2 → 产出 0、2；仅 0 → 仅 0；仅 2 → 仅 2；均无 → 无；均不改变表内容 |

| KR05 | 指标副作用：已存在基础物种，缺失形态指标 | 查询创建并登记默认/克隆指标（注册表前后不同） |

| KR07 | 直接注册 vs 通用编译：同键两次直接注册；两个同名道具 PBS 节 | 前者替换；后者编译拒绝 "used twice" |

| KR10 | 未定义枚举引用：道具 Move 引用未定义值 | 通用枚举路径拒绝并提供位置（非特定类型专用错误） |

## C. PBS 生命周期（KL01–KL32）

| ID | 输入／前提 | 推导预期 |
| --- | --- | --- |
| KL01 | 提示开启但用户拒绝：PROMPT_TO_COMPILE=true，用户选否 | 不置全量标志；新鲜度等自动条件仍可判定编译 |
| KL02 | 普通编译中异常：清单已建立后异常 | 打印异常；尝试逐文件删除（不保证全部删除）；Hangup 转 Reset，其余转通用错误 |
| KL03 | 编译中 Reset/SystemExit：任意阶段 | 原样重抛；不诊断、不清理、不转换 |
| KL04 | 删除报系统调用错误：某文件删除失败 | 该错误被忽略，继续其余文件；不保证全部删除 |
| KL05 | PBS 缺失且早期失败：载入/反写在清单建立前失败 | 清理分支面对未建立清单；完整清理预期不成立 |
| KL06 | 空值与可选模式：`vevV` 第四位为空 | 该位为 nil；其余照常求值 |
| KL07 | 引号文本（非末字段）：`Flags` 为 `\"PokeBall\",Other` | 首值在检查区内：恰两个引号且两端为 `\"` → 去除包围标记 → `PokeBall`；球标志匹配成功 |
| KL08 | 引号文本（单值／末字段）：`Flags` 仅 `\"PokeBall\"` 或 `Other,\"PokeBall\"` | 末字段不进入检查区、初始双引号数恰为 2 时补查也跳过：包围标记与反斜线（真实字符 U+005C／U+0022）**原样保留**；存入带标记文本，球标志精确匹配失败——不得把分词内部有位置条件的去除概括成无条件去除 |
| KL09 | 引号文本（普通未包围）：`Flags` 为 `PokeBall` | 无引号分支：原样存入；球标志匹配成功 |
| KL10 | 有效道具的 Flags 完整值分别为 `\"Alpha,Beta\"` / `\"Alpha,Beta\",Other`；每端仅一个 U+005C 和一个 U+0022，无空白 | 前者合并耗尽，唯一标志仍为完整 `\"Alpha,Beta\"`（两个端点标记均保留）；后者首值在后续检查去标记，得到 Alpha,Beta 与 Other。合并本身不保证去标记；KL07–KL09 既有预期保持 |
| KL11 | 普通重复属性后值覆盖：同一节内 `Name` 两次（非 `^`） | 后值生效 |
| KL12 | `^` 属性累加：`^` 标记属性多行 | 多行累加为该属性的值列表 |
| KL13 | 通用未知属性：语法合法但不在该 schema 的属性 | 通用流程不消费、不报错 |
| KL14 | 新身份定义：合法且尚未登记的新道具 ID | 可登记为新记录 |
| KL15 | 重复身份：同 ID 的第二个通用节 | 拒绝 "used twice" 并提供位置 |
| KL16 | 未知引用：道具 Move 引用未定义招式 | 通用枚举路径拒绝并提供位置（与新身份定义不同） |
| KL17 | 被发现≠可编译：只有 moves_extra.txt 缺 moves.txt | 前者可被发现；编译前改写按固定路径打开后者失败 |
| KL18 | 主动导出与连接写出：调试菜单调用全量写出；某作者类无条目；某连接的地图已不存在 | 按实际条目后缀生成路径，无条目则无该路径；该连接被跳过不写出 |

## 使用说明

- 每条预期均为静态推导；实现方执行测试时，环境前提（素材、宿主行为）需按 `../scope-statement.md` 的未验证声明单独验证。
- 与正文规则的冲突按「先修订正文并记录问题」处理，不在目录中夹带语义变更。
