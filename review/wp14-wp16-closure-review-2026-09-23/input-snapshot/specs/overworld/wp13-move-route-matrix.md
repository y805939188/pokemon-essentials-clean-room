# WP13 附表：移动路线命令矩阵

本附表是 [wp13-map-events-npc-followers](wp13-map-events-npc-followers.md) 的取证附件（WP13-C 验收物，2026-09-19 按 WP13-R01 新增）。
范围为固定基线 `S/004_Game classes/006_Game_Character.rb` 中移动路线的独立分派（`move_type_custom`，428–550 行）。**移动路线命令与主事件命令是两套分派**，主事件命令矩阵（[wp13-interpreter-command-matrix](wp13-interpreter-command-matrix.md)）不代表本表，本表也不代表主事件命令全集。

路线来源：事件页的固定路线、209（设定移动路线）对角色设置的强制路线、跟随者/系统内部的路线。命令代码为路线列表项的 code，参数随代码不同。

## 1. 分派与推进规则

- 每帧（且非跳跃/移动中）处理路线：从当前路线索引开始，最多遍历剩余命令一次。"本帧"表述以获得实际更新/调用机会为前提。
- **0（路线结束）**：路线设为重复 → 索引归 0 继续；否则——若是强制路线 → 恢复被接管前的原路线与索引并清除强制标记；停止计时归零，本帧结束。**强制路线的恢复在此发生**。
- **1–14（移动/跳跃）**：执行一次移动尝试后**本帧结束**。推进规则：`skippable || moving? || jumping?` 时索引 +1——**按运动/跳跃状态判断，不按坐标是否变化**：
  - 可跳过（skippable）路线：被阻挡也推进到下一条。
  - 不可跳过路线：**移动/跳跃已进入运动状态（moving?/jumping? 为真）才推进**。注意玩家受阻碰撞（bump）会设置移动计时（`008_Game_Player.rb:121–127`），moving? 取决于该计时存在（`006_Game_Character.rb:348–350`）——**非 skippable 的玩家路线撞墙且无事件触碰成功时，即使坐标不变也会推进索引**；普通非玩家事件受阻且未进入运动时，索引停留、下帧重试同一命令。
- **15–26（等待/转向）**：执行后索引 +1，**本帧结束**。
- **27 及以上（状态/脚本）**：执行后索引 +1 且**不结束本帧**（同帧可连续执行多条，直到遇到 0–26 或遍历完）。
- **空路线边界**：仅含终止项的路线列表（size ≤ 1）在分派开头直接返回（`006_Game_Character.rb:427–445`），**不会执行到代码 0 的恢复分支**——被设为强制路线的空路线不会因此恢复原路线或清除 forcing；无外部状态改变时，解释器的路线等待（210）仍可被其阻塞。
- 15（等待）使用 System.uptime 计时；45（脚本）直接 eval，异常处理不在本层（脚本异常归解释器/调用方路径，WP07/WP13 主文档引用）。

## 3. 口径与静态场景

- 本表按固定源码逐项核对 `move_type_custom` 的 case 分派，非 AST 分析；各移动/转向命令的完整语义（如对角移动的分解、接近/远离玩家的寻路）以 `Game_Character` 相应方法为准，不在本表展开。
- "被阻挡时是否推进"只描述路线索引行为；通行判定本身归 WP12 主规格（引用）。

### 静态推导场景（未运行，待运行验证）

| 场景 | 输入 | 推导预期 |
| --- | --- | --- |
| 不可跳过路线：普通事件受阻 | 非 skippable 路线、普通非玩家事件、下一命令为移动、目标不可通行（未进入运动状态） | 路线索引停留，下帧重试同一移动命令 |
| 不可跳过路线：玩家撞墙 | 非 skippable 玩家路线、移动失败且无事件触碰成功（bump 置移动计时） | moving? 为真 → 即使坐标不变，路线索引仍推进到下一条 |
| 可跳过路线被阻挡 | skippable 路线，目标不可通行 | 路线索引推进到下一条（跳过被阻挡的移动） |
| 空强制路线 | 209 设置仅含终止项（size ≤ 1）的强制路线，随后 210 | 路线分派在代码 0 之前返回：forcing 不清除、原路线不恢复；无外部改变时 210 的等待可持续阻塞 |
| 强制路线结束 | 强制路线执行到代码 0 且非重复 | 恢复被接管前的原路线与索引，清除强制标记 |
| 重复路线 | 路线 repeat=true，执行到代码 0 | 索引归 0，从头继续 |
| 同帧多条状态命令 | 路线为 27（开关 ON）→ 29（速度）→ 1（移动） | 同一帧依次执行开关与速度，遇移动命令后本帧结束 |
| 随机移动脚本 | 45 脚本为 move_random_range(...) | 执行后索引 +1 且本帧结束 |
| 普通脚本 | 45 脚本为其他表达式 | 执行后索引 +1，不结束本帧（继续下一条） |
| 209 与 210 配合 | 事件命令 209 设强制路线 → 210 | 209 立即继续；210 使解释器等待全部强制路线结束（含本路线执行到 0 恢复） |
