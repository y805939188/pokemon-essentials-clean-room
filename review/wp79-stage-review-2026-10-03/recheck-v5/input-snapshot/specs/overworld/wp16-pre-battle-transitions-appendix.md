# WP16 附表：战前过渡（世界画面进入战斗前）

状态：**ReviewPending（WP79-R02 v5 有界补提取，2026-10-03；待有界复审）**。分类 Engine/Overworld Integration（主）、Combat Requirements（交界）。固定只读 commit `8c5911e4a4b07b07e832e4bb0d5d8859e88b4a9b`。全部静态读取；未运行参考、游戏、编译器、反序列化或行为模拟器；素材缺失与实际帧呈现/墙钟耗时按 U01＋G 系保留。

本附表承接世界画面进入战斗场景**之前**的过渡行为：特殊过渡注册与选择、资源条件、默认效果选择、演出阶段与固定目标时长、正常返回边界。**与 WP67-A §3.2 分开**——后者是战斗场景创建之后的战斗内开场（训练家排列/野生入场/闪光公共动画），选择输入、资源条件与完成点均不同；本附表不把 WP67-A §3.2 当作本文件过渡种类的合同。**正常返回后的音频恢复、下一战资源清理、遭遇计步与世界标记恢复继承 WP42 §7 已批准合同**，本附表只登记战前过渡自身的临时信息清理；钓鱼位置（WP60）与计步交界（WP36 §4.5）保持各自包的局部承接。

## 1. 目的、输入与分类

- **目的**：进入战斗前在世界画面上播放一段过渡演出，结束时画面应为黑屏，随后让位给战斗场景；战斗结束后由同一包装恢复世界画面。
- **主入口（审计名）**：`pbBattleAnimation`（可选音乐参数、战斗类别、对手数组）——包装：战前过渡 → 让位块（战斗场景）→ 返回恢复。核心演出入口 `pbBattleAnimationCore`；让位助手 `pbSceneStandby`（地图场景精灵集先销毁、缓存清理与帧重置、执行让位块、再重建——`002_Overworld_BattleIntroAnim.rb:51–57`）。
- **输入及其作用**：

| 输入 | 取值与作用 |
| --- | --- |
| 战斗类别 battletype | 0＝野生、1＝训练家、2＝双打野生、3＝双打训练家（来源 :59、:104–119 分支注释与调用侧 `001_Overworld_BattleStarting.rb:401` 按对手数给 0/2）。类别决定特殊注册资格与默认效果选择表的分支 |
| 对手数组 foe | 对手训练家数组；**「恰好 1 名对手」（数组长度）与「训练家战类别」（battletype 奇偶）是两个独立条件**——类别 3 且 2 名对手时，要求单名的注册不满足、允许多名的注册可满足（:198–267, 423–432） |
| 位置 location | 0＝室外、1＝室内、2＝洞穴、3＝水域；判定顺序：冲浪或潜水 → 水域；否则遭遇类型为钓鱼 → 水域；否则当前有可洞穴遭遇 → 洞穴；否则地图元数据非户外 → 室内；否则室外（:80–90）。位置决定默认选择表的列与闪屏颜色（洞穴视同夜间） |
| 日夜 | 白天/夜间分别使用不同的默认选择表（:103–121）；夜间影响闪屏颜色 |
| 资源可用性 | 特殊注册的资格以资源路径可解析（png/gif，含加密归档路径——`001_FileTests.rb:119–133`）为条件；资源不满足则落到后续候选或默认路径 |
| 玩家装束 | 玩家条形图/立绘按装束变体命名，变体不存在时回退无装束名（:229–232, 291–298） |

## 2. 特殊过渡注册表合同（`002_Overworld_BattleIntroAnim.rb:17–42`）

- 注册项为四元组：名称、优先级数值、触发条件、演出体。名称用于识别登记；注册不去重（同名可重复登记）。
- **撤销**：按名称移除——**移除全部同名项**；**查询**：按名称判定存在性；按名称取项时返回**登记序首个**匹配，无匹配返回空。
- **选择**：遍历按**优先级数值降序**排列的注册项，对每项以求值输入（战斗类别、对手数组、位置）检查触发条件，**只执行首个满足条件者**，随后停止；没有命中才走默认选择（:92–98）。
- **同优先级不补造次序保证**：排序只比较优先级数值，来源未定义同优先级项的稳定次序——不得凭登记先后或实测顺序补造「同优先级谁先生效」的规则。
- 当前快照内置五组特殊注册（§3）；扩展可增删注册项（作者入口），本附表不断言注册表运行期不变。

## 4. 演出阶段

### 4.1 包装阶段（`pbBattleAnimation`，:59–152）

进入即置战斗进行中标记；建顶层视口；暂停当前背景音乐/音效，若存在已记忆音乐则恢复其位置，随后播放战斗音乐（未指定时取野生战斗音乐）；判定位置；执行特殊选择或默认选择（§5）；让位给战斗场景块；返回后：恢复先前音乐/音效、清除已记忆音乐与其位置、清空下一战音乐/胜利音乐/捕获音效/下一战背景四类预置、遭遇计步重置（WP36 §4.5 交界）；以 **0.4 秒**目标从黑屏回褪到世界画面（按已过时间占 0.4 秒的比例递减不透明度，每帧推进世界画面更新），释放视口并清除战斗进行中标记。

### 4.2 核心演出（`pbBattleAnimationCore`，:154–188）

1. **前置闪屏**：次数由调用方给（默认 2；各特殊路径见 §3）；颜色规则——洞穴或夜间为黑、否则为白；每半次闪屏目标 0.2 秒（淡入后淡出计一次）。
2. **截图准备**：释放旧背景位图，把当前画面快照存入临时背景位图（供主过渡效果读取世界画面底图——`001_Transitions.rb:118` 的读取点）。
3. **主过渡**：冻结画面、确保视口为黑，以 **25 个 1/20 秒单位**请求具名效果（:185）；通用换算 1.25 秒仅在效果无固定目标时长时生效（§5）。
4. **后置等待**：**0.1 秒**（秒单位——`012_Overworld/001_Overworld.rb:527–536`，等待循环每帧推进图形、输入与世界画面更新）。

### 4.3 alternate_vs_trainer 自编排序列（:284–416）

不走核心入口：玩家与对手条形图素材按装束两级回退（先 `<类型>_<装束>`、无则 `<类型>`）；条图自两侧滑入（0.25 秒）→ 全白闪＋两声音效 → 条图滚动并让双方立绘入场（1.2 秒段）→ 再次全白闪＋音效 → 显示对决标志与双方名字 → 标志震颤（至 1.75 秒）→ 标志放大（至 2.5 秒）→ 渐黑（整段 2.8 秒）→ 释放全部自建精灵/视口并确保画面为黑。该路径不读临时演出数据；玩家/对手名字直接绘制。

## 5. 时序合同（单位与固定目标时长）

- **单位区分**（`001_Transitions.rb:18–35, 44–95, 106–165`）：入口时长为 **1/20 秒单位**（取整）；特殊效果判定时换算为秒（÷20.0）；效果类可声明**类级固定目标时长**，声明后**覆盖**传入时长（:115）；`pbWait` 的等待以**秒**为单位（`001_Overworld.rb:527–536`）；以上均为静态目标时长，不是实测墙钟耗时。
- **完成条件**：效果以自身起始时刻计时，**计时达到目标时长即自行处置**；过渡调用在生效等待旗标下**阻塞至该处置完成**（:31–35）。中断旗标（`_interrupt_transition`）在当前核心脚本**未见赋值点**（全 Scripts 检索仅有 :31/:45 两处读取——如实登记，不推成扩展永不设置）；中断旗标置位时特殊判定返回否、走普通淡出路径（:45）。
- **特殊判定边界**：判定前若已有在途过渡，先处置之（:47–50）；名称未命中任何具名效果时返回否，由普通淡出以换算后的帧时长执行（:25, 92）；调用层的异常重试**仅覆盖普通淡出调用**（以空文件名重试一次，:26–30）——不覆盖具名效果实例化阶段的异常。
- **零/负时长**：效果初始化时传入时长 ≤ 0 直接置已处置并早退（:111–114）——不呈现可见过渡、不进入阻塞等待；初始化早退不补造后续保证。

## 7. 边界、排除与未验证

- **具名排除（实现细节类）**：像素坐标/尺寸（条带位置、立绘落点、视口分区）、图像切分与遮罩模式、插值轨迹与逐帧参数、精灵/位图组织方式——这些不改变选择、资源条件、阶段目标时长与完成合同，不逐行提取。
- **正常返回边界**：§4.1 的临时信息清理（已记忆音乐、四类下一战预置、计步重置、战斗进行中标记）只在**正常返回**路径成立；异常路径不保证走完整清理，不补造全局恢复合同。演出临时数据（transition_animation_data）由各特殊路径自身设置并在演出后清空（:206–209, 233–236, 261–266）；背景位图由后续截图准备或处置链释放。
- **资源与异常**：资格条件只查类型专属资源存在性；具名效果初始化还会加载共享图（对决标志件、黑色遮罩件等），加载阶段缺文件的异常不被调用层重试覆盖（§5），不补造回退；VSEliteFour 初始化的早退检查不含玩家立绘位图（:1449–1458）——如实登记，不推成必有回退。
- **未验证**：素材是否存在（当前快照 `Graphics/` 缺失，U01）、实际画面/帧率/墙钟耗时（G 系）、注册表运行期改动、扩展注册的内容——全部保留待证；以上静态可读规则不依赖这些验证。
