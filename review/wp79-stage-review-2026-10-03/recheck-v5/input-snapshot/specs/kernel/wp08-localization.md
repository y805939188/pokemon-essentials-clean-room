## 1. 目的、范围与非目标

**目的**：描述文本如何分域、选择语言、提取/编译/载入、查找/替换和回退，以及作者翻译材料的输入输出。后续包据此判断"某段文本来自哪个域、缺译时显示什么、翻译何时生效"，而不是各自重新追踪消息系统。

**范围**（WP08 自身声明范围，extraction-plan 第 2.1 节 (a) 类）：

1. WP08-A：文本域与身份（文本域目录、存储形态、键归一化、真实消费者）。
2. WP08-B：语言配置与选择（配置、选择机会、主动与延迟载入、持久化）。
3. WP08-C：消息查找与回退（查找链、空译与异常边界、占位参数与格式化）。
4. WP08-D：作者翻译工作流（文本收集、提取、编译、写回与失败副作用）。
5. F02-05 中属于 WP08 部分的状态更新。

**非目标**：

- 不复制文本语料（不输出任何具体翻译文本）。
- 不提取字体、窗口绘制与所有 UI 页面的文本呈现（归 D05/D16 领域包）。
- 不提取核心消息的二进制格式细节（加载器行为未验证）。
- 不运行游戏或任何参考脚本；不修改 `reference/`。

## 2. 概念与术语

- **文本域（MessageTypes）**：按内容类别划分的文本集合，每个域一个整数身份。
- **默认消息**：随工程编译保存的基础文本（`Data/messages_core.dat`、`Data/messages_game.dat`）——用于**收集与导出**（作者工作流），不是运行查找的回退层。
- **语言消息**：当前所选语言的翻译文本（`Data/messages_<片段>_core/game.dat`）——运行查找的两层来源（先 game 后 core）。
- **数组域 / 哈希域**：按整数索引存储的域与按文本键存储的域；**域内身份形态按域而定**（如物种名/招式名为哈希键），不能由域编号推断。
- **回退**：查找未中时逐层下降的策略；空字符串是有效命中，**不触发**回退。
- 影响域编号 Dxx 见 module-map；证据状态五档定义见总览第 7 节。

## 3. WP08-A：文本域与身份

### 3.2 存储形态与真实消费者（WP08-R01 修订）

- **数组域**：按整数索引存储（`get(type, id)` 按键号查找）。
- **哈希域**：按文本键存储（`getFromHash(type, key)`），键经归一化（去首尾空白、压缩连续空白，`Translation.stringToKey`）。
- **物种名/招式名是哈希域**（不是数组索引例子）：编译以 `setMessagesAsHash` 写入（`002_Compiler_CompilePBS.rb:228, 377`），消费者按 real_name 文本查哈希（`008_Species.rb:225`、`005_Move.rb:67`）。通用数组查找接口（`get`）存在，但**不能由域编号推定域内身份形态**。
- **地图事件文本**：EVENT_TEXTS 按地图编号分桶，另有 **0 号共享桶**（公共事件文本与跨地图共用文本）；同一文本在不同地图中按各自地图桶分别登记，不预设统一字符串键。

## 4. WP08-B：语言配置与选择

- **作者配置**（WP02 词典）：`LANGUAGES` 声明候选语言列表（每条 = 显示名 + 文件名片段，对应 `Data/messages_<片段>_core/game.dat`）；默认为空（不提供候选）。
- **选择机会**（WP02 已核）：启动流程在候选 ≥ 2 且无存档时提供语言选择（`001_StartGame.rb:31–33`）；载入界面在候选 ≥ 2 时显示语言菜单（`016_UI/013_UI_Load.rb:307, 337`）；调试菜单另有语言切换。
- **主动加载 vs 延迟加载（WP08-R01 修订）**：主启动直接调用 `MessageTypes.load_message_files(片段)` **立即载入**（`001_StartGame.rb:31–33`），不是首次查找才加载；Translation 构造参数另支持延迟加载（`delayed_load_message_files`，首次查找时），两条路径分开。
- **持久化与直写（WP08-R03 修订，与 WP09 同步）**：选择保存在玩家系统选项（`$PokemonSystem.language`）；**载入菜单已有存档时切换语言会把选项写入该存档 Hash 并直接写回存档文件**（`016_UI/013_UI_Load.rb:334–342`）——这是**直接写档**，不经过正常 Game.save（WP09 主规格，引用）。无存档时切换不写档。
- **与 WP09 的交界**：语言属于**设置**（玩家选项），不属于游戏进度；设置与进度的保存/重置边界归 WP09 主规格，本文引用。

## 5. WP08-C：消息查找与回退

### 5.1 查找链（WP08-R01 修订：当前语言 game → 当前语言 core，不再查默认语料）

| 入口 | 查找链 | 未中结果 |
| --- | --- | --- |
| `get(type, id)`（数组域） | 当前语言 game[type][id] → 当前语言 core[type][id] | 空字符串 `""` |
| `getFromHash(type, key)`（哈希域） | 当前语言 game[type][key] → 当前语言 core[type][key] | **返回原文**（键为空/nil 时也返回原文；**不自动取默认语料**） |
| `getFromMapHash(map_id, key)`（地图事件文本） | 当前语言 game[map_id][key] → game[0][key]（共享桶） → 当前语言 core[map_id][key] → core[0][key] | 返回原文 |

用途分层（WP08-R01）：默认 core/game 用于**收集与导出**（作者工作流）；当前语言 core/game 由另一入口载入，用于**运行查找**。语言 game 覆盖语言 core 的同名译文（先查 game）。

### 5.2 空译与异常边界（WP08-R02 修订）

| 情形 | 行为 |
| --- | --- |
| 缺键/nil | 按 5.1 回退链处理（数组域空串、哈希/地图回原文） |
| **空字符串命中** | 空字符串是**有效命中**（真值判断），**直接返回空串，不触发回退**——空译不会被原文/核心译文替补 |
| 文件载入失败 | `load_message_files` 的 rescue 把语言/核心消息置 nil，效果同回退；**加载器仅检验外层为数组**，内层形态不符仍可能在查找处出错 |
| 查找结构异常 | 数据形态异常（如内层非预期类型）按 Ruby 常规异常传播，不被查找入口捕获 |
| 格式化异常 | `_INTL`/`_ISPRINTF` 的 rescue **只包住查找部分**；后续 sprintf 格式化在 rescue 之外，**格式化错误向外传播** |
| 地图包装的格式化 | `_MAPINTL`/`_MAPISPRINTF` **没有**同样的查找 rescue——其格式化/查找错误**均不被该包装捕获**（不能套用 `_INTL` 的捕获保证） |

### 5.3 占位参数

`_INTL` 在取回文本后把 `{1}`、`{2}` 等占位替换为参数值（字面替换）；`_ISPRINTF` 支持 `{1:d}` 形式的格式占位（按 sprintf 求值）；`_I`/`_MAPINTL`/`_MAPISPRINTF` 为地图事件文本的对应入口（先按地图回退链取文本，再替换占位）。查找失败时 `_INTL`/`_ISPRINTF` 回原文（见 5.2 捕获范围）。

## 6. WP08-D：作者翻译工作流

### 6.1 文本收集（编译流程末段，`gather_script_and_event_texts`，7–189 行）

- 从脚本（扫描 `_INTL("…")`/`_ISPRINTF("…")` 字面量）、提取的 .rb 文件、插件脚本、公共事件与各地图事件（Show Text 101/401、Show Choices 102、内嵌脚本 355/655、条件分支 111、移动路线 209）收集可翻译文本。
- 脚本文本入 SCRIPT_TEXTS 哈希域；公共事件文本入 EVENT_TEXTS 的 0 号共享桶；地图事件文本按地图编号入各自桶（仅非空时登记）。
- **Hangup 捕获后返回，已收集内容可能只是部分**（186–187 行）——进入收集函数不保证完整收集；其他未捕获错误按实际调用路径传播。
- 这是编译流程（WP04）末段调用，随后消息保存（`MessageTypes.save_default_messages`）。

### 6.2 提取（作者导出，`extract_text`，244–348 行）

- 从默认消息导出到 `Text_<语言>_core/` 或 `Text_<语言>_game/` 文件夹。
- **输出格式分形态**（`write_section_texts_to_file`，350–370 行）：**数组条目为索引/原文/译文三行**；**哈希条目为键/译文两行**——"每条两行"不覆盖所有形态。
- **覆盖与跳过**：目标文件夹已有文件时询问是否全部替换；拒绝则中止（不写）；确认则**删除 `Dir.all` 返回的全部文件**（不只 .txt）后重写。默认消息文件缺失时提示未找到并返回（不写）。
- 转义：特殊字符经 `normalize_value`/`denormalize_value` 转义（`\r \n \t \x01 [ ]` 与 `<<r>> <<n>> <<t>> <<1>> <<[>> <<]>>` 互换）。

### 6.3 编译（作者导入，`compile_text`，376–472 行）

- 把 `Text_<语言>/` 下全部 .txt 编译为 `Data/messages_<语言>.dat`。
- 节识别与**形态判别**：数字节号、MessageTypes 常量名、或 `MapNNN`（地图事件文本）决定节归属；**数组／哈希形态不按域固定，而由该节首条内容是否纯数字决定**（GR-002 查明）：首条内容匹配纯数字 → 按数组解释，随后要求内容行数为 3 的倍数（索引/原文/译文三元组），**Map 节一旦被识别为数组立即拒绝**（"can't be an ordered list"）；首条内容非纯数字 → 按哈希解释，随后要求行数为偶数（键/译文二元组）；非法节名、行数不符、索引非数字均报错（`compile_text_from_file` 的显式异常）。**由此，哈希导出（键/译文两行）中首键为纯数字的节在导入时被改判为数组**——例如首键 `123` 的两行内容因 2 不是 3 的倍数而被拒绝，即使它是导出端可合法产生的哈希条目。
- **先打开并截断输出，再扫描/解析输入**（379 行以覆盖模式打开输出文件）：输入目录或内容失败时**旧产物可能已被截断**；ensure 关闭文件不等于恢复旧文件。
- **真实菜单路径**（`002_Debug_MenuCommands.rb:1458–1476`）：从 `Text_*_*` 目录中选择，片段含 core/game 后缀（如 `english_core`），再生成对应 `Data/messages_<片段>.dat`——目录、语言名与输出文件名不是同一个参数。

### 6.4 写回与失败副作用（本包自立，不只引用 WP04/WP07）

| 步骤 | 可能的副作用 |
| --- | --- |
| 收集 | Hangup 后部分收集（6.1）；其他异常按调用路径传播 |
| 提取覆盖 | 确认后删除目标文件夹全部文件（不限 .txt）再重写（非原子） |
| 编译 | 先截断输出再解析：非法输入时旧 .dat 可能已被截断；ensure 关闭不恢复 |
| 语言切换直写 | 已有存档时把选项写入存档 Hash 并直接写回（4 节；无存档不写） |

## 7. 默认行为与配置变体

- **基线默认**：`LANGUAGES = []`（无候选语言）；默认消息随启动加载；无候选时无语言菜单/选择；查找按第 5.1/5.2 节入口分层（不是统一"回退到原文"）。
- **支持但未默认启用**：多语言候选（启动选择 + 载入菜单 + 按片段加载 + 载入菜单直写）；地图文本按地图分桶与共享桶；作者提取/编译工作流；Translation 的延迟加载构造。
- **配置/数据关联**：语言文件名片段与数据文件的对应关系（`messages_<片段>_core/game.dat`）；地图文本的地图编号依赖（缺失地图数据时地图事件文本可达性，U01）。
- **未验证组合**：多语言切换的运行效果、缺译/空译在各消费者的显示、提取/编译的真实往返、地图事件文本在缺失地图下的行为。
- 参考快照行为、官方版本预期、未来目标分开标记；本包只记录第一类。

## 8. 边界、失败与未知

- 消息文件缺失与查找结果：按第 5.1/5.2 节的入口分层处理，**不是**"整体回退到原文"——默认材料是否存在不决定当前已载入语言的命中结果；当前语言两层均未中时，数组入口返回空字符串，哈希/地图文本入口返回输入原文。文件加载异常、嵌套形态异常与格式化异常仍沿第 5.2 节的分层。
- 空译：直接显示空串（有效命中，5.2）；各消费者的空串显示效果归 UI 领域包。
- 占位参数缺失：`_INTL` 字面替换缺失参数时占位原样保留（推导，未运行）；`_ISPRINTF`/地图包装的格式化错误向外传播（5.2）。
- 编译输入非法（非法节名、行数不符、索引非数字）：显式异常（作者可见错误，具体呈现归 D18 调试面）；旧 .dat 可能已被截断（6.4）。
- 提取覆盖：拒绝替换请求时不写；确认后旧文件被删除再重写（非原子）。
- 地图事件文本在缺失地图数据下的可达性（U01）。
