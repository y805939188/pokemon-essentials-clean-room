# 静态测试目录：engine-overworld / WP16（批次 1）

本目录记录 WP16 两篇净化正文对应的静态推导场景。**全部为静态推导预期（输入 → 推导预期），未在任何引擎上执行，不是已执行测试**；可用于后续实现的测试设计。对应正文：《[世界绘制与视觉过渡](../engine-overworld/wp16-world-rendering-and-visual-transitions.md)》《[战前过渡](../engine-overworld/wp16-pre-battle-transitions.md)》。

## A. 世界绘制与视觉过渡（WR01–WR15）

| ID | 输入／前提 | 推导预期 |
| --- | --- | --- |
| WR01 | 玩家右移一格 | 画面整格左移一格＋亚格像素偏移；右侧新进入画面的区域及时呈现（检查可见投影，不检查内部对象复用） |
| WR02 | 当前图南侧有邻图 | 邻图按显示偏移投影到网格下缘，跨界处两图图块同屏 |
| WR03 | 传送到无连接地图 | 网格全量重绘、天气粒子偏移归零 |
| WR04 | 名为 `Sea[10]` 的自动图块 | 帧时长 10/20 秒，按运行时长同步换帧 |
| WR05 | 玩家桥状态 >0 且在桥图块上 | 桥图块 Z＝0（被角色覆盖关系按角色 Z 序），非反射分层 |
| WR06 | 静水地形旁玩家 | 静水反射：深水色、不透明、日夜着色开启时隐藏 |
| WR07 | 天气设置（正时长，无在途淡入）：当前无在途过渡、目标类型不同——设 Rain、强度 1、时长 1 与时长 20 | 均通过守卫进入固定阶段淡入（阶段不随传入数值缩放）；粒子上限 12 |
| WR08 | 天气设置（零时长，无在途淡入）：目标类型不同——设 Rain、强度 1、时长 0 | 通过守卫后走立即切换分支（上限 12 立即生效） |
| WR09 | 天气设置（零时长，有在途淡入）：正在 None→Rain 过渡中，再请求 Snow、时长 0 | 本次淡入被「正在淡入」守卫拒绝：旧目标与当前过渡继续；屏幕保留 Snow 请求，后续全局更新按类型比较重新判断（不推定立即生效或永久丢弃） |
| WR10 | 同类型强度变化：天气已稳定为 Rain、上限 12，再设 Rain、强度 5 | 屏幕记录的类型/上限已更新；天气对象入口不再被调用（类型未变），可见粒子上限不能据源码保证刷新（参考快照行为） |
| WR11 | 下雨中边缘跨图到相连地图 | 天气粒子按连接偏移平移保持连续 |
| WR12 | 户外图、`TIME_SHADING` 开、18:30 | 按 18 点与 19 点色调各半插值着色；`regulartone` 事件除外 |
| WR13 | 显式传送至另一图 | 全景/雾/事件/玩家/天气/图片等可见内容按新图全部重建呈现；图块集资源在使用者变化后按有效期规则保持或可被释放（检查可见状态，不检查对象销毁或引用计数机制） |
| WR14 | 传送至当前图另一坐标 | 可见内容同样按当前图全部重建呈现 |
| WR15 | 启动震动：力度 5、速度 8、时长 1 | 主显示层 X 偏移按周期位移，最大 ±12.5 像素 |
| WR16 | 显示偏移变化 6 个子像素单位 | 画面位移 1 像素（4 个子像素单位）＋亚格 2 个子像素单位（0.5 像素）的偏移呈现；换算比例 4:1，不足 4 的余量按亚格偏移 |

## B. 战前过渡（BT01–BT16）

| ID | 输入／前提 | 推导预期 |
| --- | --- | --- |

| BT02 | 单名训练家战：60 组资源缺失、50 组资源齐备 | 60 组资格不成立 → 执行 50 组；50/40 均不成立 → 默认选择表 |

| BT04 | 双打训练家战（类别 3、2 名对手） | vs_trainer/vs_elite_four/alternate 三组因对手数不满足；vs_admin/rocket_grunt 可满足 |
| BT05 | 双打训练家战：仅第 2 名对手有 `rocket_<类型>` 资源 | vs_admin 以第 2 名的 [类型, 名字] 为演出数据（首个资源命中者） |
| BT06 | vs_elite_four 路径：玩家装束变体资源不存在 | 玩家精灵名回退为无装束形式；不影响对手侧资源条件 |
| BT07 | 冲浪中且当前有可洞穴遭遇 | 位置＝水域（冲浪优先于洞穴判定）；钓鱼遭遇类型同理优先 |
| BT08 | 白天室外训练家战 vs 夜间同条件 | 默认效果 TwoBallPass vs SpinBallSplit；白天室内野生为 DiagonalBubbleTL、夜间为 DiagonalBubbleBR；双打训练家恒 FourBallBurst |
| BT09 | 各特殊路径 | 闪屏次数：vs_trainer 1、vs_elite_four 0、vs_admin 0、rocket_grunt 2、默认路径 2；洞穴或夜间闪黑、否则闪白 |
| BT10 | VSTrainer 路径资源齐备、正常初始化 | 主过渡固定 4.0 秒目标（非 25 单位的通用换算 1.25 秒）；前置 1 次闪屏（每半次 0.2 秒）、后置 0.1 秒等待分段；完成点＝计时达 4.0 秒自行处置并解除阻塞 |
| BT11 | 时长 ≤ 0 的过渡请求且实际被选中并进入具名效果初始化 | 初始化即处置并早退——无可见过渡、不进入阻塞；中断未置位时在途旧过渡被新判定先处置 |
| BT12 | 战斗正常结束返回 | 恢复先前音乐/音效、清除已记忆音乐与四类下一战预置、计步重置、0.4 秒回褪、战斗进行中标记清除；异常路径不保证同等清理 |
| BT13 | alternate_vs_trainer 路径：玩家条形图装束变体存在、玩家立绘装束变体缺失 | 玩家条形图用装束变体、玩家立绘回退类型基础资源（两项独立回退，允许混合命中）；对手条形图/立绘仍直接按对手类型选基础资源——玩家侧回退规则不得套用到对手侧 |
| BT14 | 中断旗标置位且有在途旧过渡 | 特殊判定直接返回否——本次调用不处置在途旧过渡、不实例化具名效果、不阻塞等待特殊过渡；不承诺旧过渡此后永不更新或永不被后续清理 |
| BT15 | 宿主过渡调用首次异常：a) 该次文件名非空；b) 该次文件名已空 | a) 本层捕获并以空文件名再调用一次（第二次异常不再由本层兜底）；b) 不作第二次尝试；具名效果成功选中后的宿主收尾调用（文件名已空）失败后也不承诺重试；具名效果实例化阶段的异常不在本层捕获范围内 |
| BT16 | 设施挑战/回放调用（仅传音乐，省略类别与对手上下文） | 采用默认类别 0 与默认空对手上下文——五组特殊注册资格在类型检查处即不成立，过渡走类别 0 的默认选择；类别是调用方输入，不从音乐或实际战斗类型反推（参考行为，不改成训练家特殊演出） |
