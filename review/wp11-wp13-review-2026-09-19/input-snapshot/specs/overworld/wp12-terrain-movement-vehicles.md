## 1. 目的、范围与非目标

**目的**：描述地形能力、通行判定、玩家移动与载具状态的行为规则——什么地形允许什么移动、走跑骑行冲浪潜水如何进入/退出/保持、碰撞与移动成功/失败分别发生什么。后续包据此判断"某位置能否进入、某状态何时改变、移动会触发什么"，而不是各自重新追踪运动逻辑。

**范围**（WP12 自身声明范围，extraction-plan 第 2.1 节 (a) 类）：

1. WP12-A：地形能力与通行判定目录（地形标签能力表、通行判定链）。
2. WP12-B：移动与运动状态（走/跑、跳跃/滑行、强制路线、普通与强制移动入口）。
3. WP12-C：载具与水上运动（骑行、冲浪/潜水、瀑布、上下车/水状态转换）。
4. WP12-D：许可与领域边界（守卫、许可输入、领域交界）。
5. F04-02、F04-03 中属于 WP12 部分的状态更新。

**非目标**：

- 不提取具体徽章、场地招式资格/效果的完整规则（WP24/WP59 等适用包）。
- 不提取事件/NPC/跟随规则（WP13 主规格）、地图拓扑/转移（WP11 主规格）、地图绘制/渲染（WP16）。
- 不把当前通行算法当成未来寻路或碰撞架构模板。
- 不运行游戏或任何参考脚本；不修改 `reference/`。

## 2. 概念与术语

- **地形标签（TerrainTag）**：图块/位置上的一组能力标记（可冲浪、瀑布、冰面、桥、深草、必须步行等），硬编码注册（18 个）。
- **通行判定**：由图块通行位（passages）、优先级、地形能力、事件阻挡、玩家阻挡共同决定的移动许可。
- **运动状态**：玩家当前的移动模式（步行/跑步/骑行/冲浪/潜水/冰滑/瀑布上下），影响速度、外观与移动规则。
- **载具状态**：`$PokemonGlobal` 的 surfing/diving/bicycle 标记（及 ice_sliding、bridge 等辅助状态）。
- **强制路线**：事件/系统接管玩家移动的状态（`move_route_forcing` 或 `$PokemonGlobal.forced_movement?`），此时普通输入不生效。
- 影响域编号 Dxx 见 module-map；证据状态五档定义见总览第 7 节。

## 3. WP12-A：地形能力与通行判定目录

### 3.1 地形标签能力表（`010_Data/001_Hardcoded data/011_TerrainTag.rb`，本轮逐行阅读）

| 标签 | 关键能力标记 |
| --- | --- |
| None(0) | 无（未识别/回退默认） |
| Ledge(1) | ledge（岩架；跳下可过、走上不可过） |
| Grass(2) | 草沙沙、野外遭遇、战斗环境 Grass |
| Sand(3) | 战斗环境 Sand |
| Rock(4) | 战斗环境 Rock |
| DeepWater(5) | 可冲浪、可钓鱼、可潜水、战斗环境 MovingWater |
| StillWater(6) | 可冲浪、可钓鱼、战斗环境 StillWater、显示倒影 |
| Water(7) | 可冲浪、可钓鱼、战斗环境 MovingWater |
| Waterfall(8) | 可冲浪、瀑布主体 |
| WaterfallCrest(9) | 可冲浪、可钓鱼、瀑布顶 |
| TallGrass(10) | 深草、野外遭遇、双打遭遇、战斗环境 TallGrass、**必须步行** |
| UnderwaterGrass(11) | 野外遭遇 |
| Ice(12) | 战斗环境 Ice、冰面、**必须步行或跑步** |
| Neutral(13) | **忽略通行性** |
| SootGrass(14) | 草沙沙、野外遭遇、战斗环境 Grass（煤灰草，供拾灰事件引用） |
| Bridge(15) | 桥 |
| Puddle(16) | 战斗环境 Puddle、显示倒影 |
| NoEffect(17) | 无效果 |

复合能力：`can_surf_freely = can_surf && !waterfall && !waterfall_crest`（非瀑布水域）。

### 3.2 通行判定链（本轮逐行阅读 `004_Game_Map.rb:142–268`、`006_Game_Character.rb:237–303`）

按入口分层，**不能用一个"可通行"布尔概括**：

| 层 | 规则 |
| --- | --- |
| 图块通行位 | 目标图块在目标方向被禁（方向位）或全向被禁（0x0f）→ 不可通行；优先级为 0 的图块不受事件阻挡 |
| 事件阻挡 | 目标位置有非 through 事件且具名图形 → 不可通行（多格角色按占格全部检查） |
| 玩家阻挡 | 目标位置为玩家且具名图形 → 不可通行 |
| 地形-水 | 当前位于非瀑布水域（can_surf_freely）时，**只能移动到其他非瀑布水域**（否则不可通行） |
| 地形-冰 | 目标为冰面 → 不可通行（步行时；滑行按 4.2） |
| 地形-岩架 | 面朝岩架 → 跳下可过（jumpForward(2)），走上不可过 |
| 地形-桥 | 不在桥上（bridge == 0）时忽略桥图块；在桥上（bridge > 0）时按桥图块通行位判定 |
| 冲浪 | 冲浪中，非瀑布水域图块（can_surf 且非 waterfall）可通行 |
| 骑行 | 必须步行（must_walk）或必须步行或跑步（must_walk_or_run）地形上不可骑行 |
| 玩家通行（playerPassable?） | 玩家专用层：桥/冲浪/骑行/忽略通行性/通行位按上表综合 |
| 严格通行（passableStrict?） | 任一方向有任何通行位非零 → 不可通行（用于跟随者） |
| 调试穿透 | $DEBUG 且按住 Ctrl 时玩家可通行（限玩家） |
| 跨图 | 目标超出当前图但 validLax? 内 → 按地图工厂的跨图通行判定（WP11 主规格） |

## 4. WP12-B：移动与运动状态

### 4.1 移动入口与结果（本轮逐行阅读）

| 入口 | 行为 |
| --- | --- |
| 普通移动（`move_generic`，`008_Game_Player.rb:141–177`） | 转身；面朝岩架则跳下（jumpForward(2)+跳音+计步）并结束本步；瀑布顶且向下则进入下瀑状态（through=true、waterfalls_descended+1）；可移动则记录初位、前移、按距离累计步数/距离统计、increase_steps；不可移动则尝试事件触碰，否则碰撞（碰撞音、bump_count+1、记录初位、bumping=true） |
| 跳跃（`jump`，`006_Game_Character.rb:767–787`） | 转向主方向；占格全部可过才跳；记录跳点、跳距、跳峰；计步；落点变化才累计距离 |
| 输入处理（`update_command_new`，`008_Game_Player.rb:431–458`） | 强制移动时按当前方向 move_forward；否则按方向键输入：持续同向（≥0.075 秒）则移动，换向则先转身 |
| 步后触发（`update_event_triggering`，同文件 543–554） | 步完成后：跟随者转身 → 远距事件检查 → 同位事件检查 → `pbOnStepTaken`（WP06 计步主规格，引用） |
| 碰撞（`bump_into_object`，同文件 121–128） | 碰撞音（非强制路线时）、bump_count+1、记录初位、bumping=true |

### 4.2 运动状态机（本轮逐行阅读 `set_movement_type` 与 `update_move`/`update_stop`）

| 状态 | 进入前提 | 速度/外观 | 退出/切换 |
| --- | --- | --- | --- |
| 步行（walking） | 默认 | 速度 3 | 默认状态 |
| 跑步（running） | can_run?：有跑鞋（或冲浪/骑行中）、非碰撞/菜单/战斗/消息/解释器、非跳跃、非必须步行地形 | 速度 4；BACK 键按 runstyle 切换 | 条件不满足时回步行 |
| 骑行（cycling） | `$PokemonGlobal.bicycle = true`（`pbMountBike`） | 速度 5（跳 3）、骑行外观与 BGM | `pbDismountBike` 或 `pbCancelVehicles`（目的地不可骑行时） |
| 冲浪（surfing） | `$PokemonGlobal.surfing = true` | 速度 4（跳 3）、冲浪外观、上下浮动动画 | `pbCancelVehicles(cancel_swimming)` 或水上岸流程（`pbEndSurf`） |
| 潜水（diving） | `$PokemonGlobal.diving = true` | 速度 3、潜水外观 | 同上 |
| 冰滑（ice_sliding） | `$PokemonGlobal.ice_sliding` 或当前地形为冰 | 速度 4、步行外观 | 离开冰面 |
| 瀑布下（descending_waterfall） | 瀑布顶向下移动触发 | 速度 2、through=true、冲浪外观 | 到底后清理 |
| 瀑布上（ascending_waterfall） | 攀瀑流程（WP59 交界） | 速度 2、冲浪外观 | 到顶后清理 |
| 停止态（*_stopped） | 菜单中停止或载具更新时 | 保持对应外观、恢复基础速度 | 重新移动时 |

状态保持/清理：跨图转移时 `transfer_player` 取消载具（可选保留游泳）；`pbUpdateVehicle` 按当前标记恢复外观（`008_Game_Player.rb:575–585`）；`pbCancelVehicles` 按目的地决定是否清除骑行标记（`pbCanUseBike?`：always_bicycle/can_bicycle/outdoor_map 任一允许）。

## 5. WP12-C：载具与水上运动

### 5.1 骑行（`pbMountBike`/`pbDismountBike`/`pbCancelVehicles`，同文件 587–615 行）

- 上车：`bicycle = true`、`cycle_count += 1`、恢复骑行外观与 BGM、音效、取消雷达连锁。
- 下车：`bicycle = false`、恢复步行外观、按地图自动播放音乐。
- 转移时清理：显式传送默认取消载具（可选保留游泳）；目的地不可骑行时清除骑行标记。

### 5.2 冲浪与潜水（状态标记与通行联动）

- 冲浪：状态标记 `$PokemonGlobal.surfing`；冲浪中按 3.2 的水域通行规则移动；外观为冲浪图块并带上下浮动；上/下岸由 `pbEndSurf` 流程处理（与通行/地形联动）。
- 潜水：状态标记 `$PokemonGlobal.diving`；潜水目标地图由地图元数据的 dive_map_id 指定（WP15/WP59 交界）；潜水外观、速度 3。
- 水上遭遇：冲浪/潜水状态下的水域遭遇按遭遇表（WP36 主规格）；`surf_count`/`dive_count` 累计（WP06 统计）。

### 5.3 瀑布（本轮逐行阅读）

- 下瀑：瀑布顶（WaterfallCrest）向下移动触发：`descending_waterfall = true`、`through = true`、`waterfalls_descended += 1`、速度 2、冲浪外观（`move_generic`，`008_Game_Player.rb:154–157`）。
- 上瀑：攀瀑流程的资格与效果归 WP59（场地招式领域）；状态标记 `ascending_waterfall`，速度 2。

## 6. WP12-D：许可与领域边界

| 守卫/输入 | 本包记录的行为 | 领域交界 |
| --- | --- | --- |
| 跑鞋（has_running_shoes） | 无跑鞋且非冲浪/骑行时不可跑（4.2） | WP24（玩家资源） |

## 7. 默认行为与配置变体

- **基线默认**：步行速度 3、跑步速度 4（需跑鞋）、骑行速度 5、冲浪速度 4、潜水速度 3、瀑布速度 2；地形按 3.1 能力表；通行按 3.2 判定链。
- **支持但未默认启用**：`FIELD_MOVES_COUNT_BADGES` 的徽章许可模式（WP02 词典，具体判定归 WP59）；调试穿透（$DEBUG+Ctrl）。
- **配置/数据关联**：`runstyle` 跑步切换方式（玩家选项）；`BADGE_FOR_*` 的场地招式徽章门槛（WP02 词典，归 WP59）；地图元数据的骑行/潜水/户外标记（WP15/WP59 交界）。
- **未验证组合**：真实地图的通行/滑行/上下水流程（U01）、动画/媒体结果（资源缺口）、跟随者在各状态下的完整行为（WP13）。
- 参考快照行为、官方版本预期、未来目标分开标记；本包只记录第一类。

## 8. 边界、失败与未知

- 不可移动时：先尝试事件触碰，否则碰撞（4.1）；碰撞不改变位置（仅音效/计数/标记）。
- 岩架跳下：占格全部可过才跳；失败按普通不可移动处理（碰撞）。
- 下瀑后：through=true 的状态清理时机（到底后）未逐分支验证。
- 上/下岸流程（`pbEndSurf`）的完整条件与失败分支（WP59 交界）。
- 动画/媒体结果（资源缺口）：跳跃尘、冲浪浮动、载具 BGM 的播放未验证。
- 多格角色的占格判定在各状态下的组合（未逐状态验证）。
