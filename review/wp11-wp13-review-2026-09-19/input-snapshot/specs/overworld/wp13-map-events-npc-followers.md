## 1. 目的、范围与非目标

**目的**：描述地图事件（事件页选择、条件、触发方式、启动/等待/结束、公共事件、并行/自动运行）和 NPC/跟随（NPC 移动/互动、训练家感知、跟随者生命周期与转移限制）的行为规则，以及解释器命令的兼容范围——哪些命令有实现、哪些有差异、哪些是空操作、哪些未处理。后续包据此判断"某事件何时启动、命令会产生什么效果、跟随者如何行动"，而不是各自重新追踪事件系统。

**范围**（WP13 自身声明范围，extraction-plan 第 2.1 节 (a) 类）：

1. WP13-A：事件页与触发（页选择、条件、触发方式、启动/结束）。
2. WP13-B：解释器运行（更新循环、等待/恢复、公共事件、并行/自动运行、深度限制）。
3. WP13-C：解释器命令兼容矩阵（见附表 [wp13-interpreter-command-matrix](wp13-interpreter-command-matrix.md)）。
4. WP13-D：NPC、训练家感知与跟随（NPC 移动/互动、感知、跟随者生命周期与转移限制）。
5. F04-04、F04-05 中属于 WP13 部分的状态更新。

**非目标**：

- 不复制具体 Demo 事件的收费、奖励、剧情结果（缺失材料，U01/U08）。
- 不把方法存在当实现、把 return 值当业务成功、把搜索未中当不存在；不执行脚本命令、不移植 Ruby 解释器。
- 不承诺标准 RMXP 命令全兼容（以附表的实际分派/实现为准）。
- 不提取战斗内事件/命令的行为（归战斗包）。
- 不运行游戏或任何参考脚本；不修改 `reference/`。

## 2. 概念与术语

- **事件页（page）**：事件的一组条件与内容；按从后向前顺序选择第一个条件全部满足的页。
- **触发方式（trigger）**：事件启动条件（0=动作键、1=玩家接触、2=事件接触、3=自动运行、4=并行处理）。
- **启动（starting）**：事件被标记为待运行；由触发检查或自动运行触发。
- **公共事件（common event）**：全局事件，trigger 1=自动运行（主解释器执行）、trigger 2=并行处理（自有解释器）。
- **解释器（interpreter）**：逐条执行事件命令的循环；支持等待（消息/移动/计时）、子解释器（公共事件调用）与深度限制（100）。
- **命令兼容**：命令在分派中的状态（有实现/空操作（command_dummy）/标记/未分派回退）。
- **跟随者（follower）**：由 FollowerData 描述、以 Game_Follower 实例随行的角色；阻止地图传送与载具使用。
- 影响域编号 Dxx 见 module-map；证据状态五档定义见总览第 7 节。

## 3. WP13-A：事件页与触发

### 3.1 事件页选择（`004_Game classes/007_Game_Event.rb:197–258`，本轮逐行阅读）

- 页按**从后向前**遍历：第一个条件全部满足的页成为当前页——开关 1/2 为 ON、变量 ≥ 指定值、自开关为 ON（`switchIsOn?` 支持开关名为 `s:` 前缀的脚本条件）。
- 无满足页（new_page 为 nil）：事件不可见、可穿透、无触发与命令列表。
- 页内容决定图形/移动类型/速度/频率/路线/方向/穿透/触发/命令列表；触发为 4（并行处理）时创建自有解释器。
- 自开关与临时自开关（`tsOn?/tsOff?/setTempSwitchOn/Off`）影响页与冷却判定（`cooledDown?/cooledDownDays?`：过期且临时自开关 A 为 OFF 时通过，否则标记刷新）。

### 3.2 触发与启动（本轮逐行阅读）

| 触发方式 | 行为 |
| --- | --- |
| 动作键（0） | 玩家在同位或面前按互动键时启动（`pbCheckEventTriggerFromDistance`/`check_event_trigger_here`/`check_event_trigger_there`，`008_Game_Player.rb:284–389`） |
| 玩家接触（1） | 玩家移动到事件位置或事件移动到玩家位置时启动（`check_event_trigger_touch`，`007_Game_Event.rb:142–158`） |
| 事件接触（2） | 事件与玩家同位且可穿透时启动（`check_event_trigger_auto`，同文件 186–195 行） |
| 自动运行（3） | 每帧自动启动（`check_event_trigger_auto`） |
| 并行处理（4） | 每帧由自有解释器执行（`refresh` 创建，`update` 驱动） |
| 感知（名称模式） | 事件名含 `sight(N)`/`trainer(N)` 时按距离与朝向检查（`check_event_trigger_after_turning/after_moving`，同文件 160–184 行；`pbEventCanReachPlayer?`/`pbEventFacesPlayer?`） |

启动后：非自动/非并行事件被锁定并清除启动标记；自动运行公共事件（trigger 1 + 开关 ON）由主解释器启动（`setup_starting_event`，`003_Interpreter.rb:54–78`）。

## 4. WP13-B：解释器运行

### 4.1 更新循环与等待/恢复（`003_Interpreter.rb:84–136`，本轮逐行阅读）

| 阶段 | 行为 |
| --- | --- |
| 冻结防护 | 每 100 次循环刷新画面一次 |
| 地图失联 | 当前图与解释器地图不同且无连接 → 忘记事件 ID（终止当前事件） |
| 子解释器 | 先更新子解释器（公共事件调用），结束才回到父解释器 |
| 消息等待 | 消息显示中不执行命令 |
| 移动等待 | 任一事件/跟随者/玩家处于强制移动路线时不执行命令；全部结束后清除等待 |
| 上岸等待 | 玩家上岸流程中不执行命令 |
| 计时等待 | wait_count 计时未到不执行命令 |
| 菜单调用 | 暂停菜单将打开时不执行命令 |
| 无命令时 | 主解释器尝试启动下一个待启动事件（公共事件 → 地图事件 → 自动运行公共事件） |
| 深度限制 | 公共事件调用深度 > 100 时提示并退出 |

### 4.2 结束与恢复

- 命令列表执行完（index 到末尾）→ `command_end`：清除命令列表与跟随者覆盖，事件结束。
- 脚本命令异常：`execute_script` 的异常按类别处理（SystemExit/Reset 原样抛出，其他进入事件错误处理路径，`003_Interpreter.rb:138–146` 及后续）。
- 事件在地图切换/失联时终止（4.1）；公共事件并行处理按开关状态刷新（`Game_CommonEvent.refresh`，`009_Game_CommonEvent.rb:40–47`）。

## 6. WP13-D：NPC、训练家感知与跟随

### 6.1 NPC 移动与互动

- NPC（事件角色）按页的移动类型/速度/频率/路线移动（`007_Game_Event.rb` 的移动与更新规则，同文件 274–301 行）；超出屏幕范围（约 2 格缓冲）的事件不更新（`should_update?`，260–272 行）。
- 训练家感知：事件名含 `sight(N)`/`trainer(N)` 时，在玩家移动后按距离 N 与朝向检查并启动（`check_event_trigger_after_turning/after_moving`，同文件 160–184 行）；名含 `counter(N)` 时按面向与距离检查（`pbEventFacesPlayer?`）。
- 训练家事件由战斗入口调用（`001_Overworld_BattleStarting.rb`，WP39 交界）；战斗后 NPC 的状态（再启动/再战）归 WP63/WP24。

### 6.2 跟随者生命周期与转移限制

- **加入**：`FollowerFactory.add_follower(event, name, common_event_id)` 登记 FollowerData（原始地图/事件/外观/名称/可选公共事件覆盖）；`remove_follower_by_event/by_name/remove_all` 移除（`011_Game_FollowerFactory.rb:76–139`）。
- **实例化**：Game_Follower 按 FollowerData 创建（`010_Game_Follower.rb:1–40`）；可穿透跟随（`move_through` 临时穿透）。
- **移动/更新**：玩家移动后跟随者依次移动（`followers.move_followers`）、转向（`turn_followers`）、更新（`followers.update`）；地图转移时 `map_transfer_followers`。
- **转移限制**：`can_map_transfer_with_follower?` 与 `can_ride_vehicle_with_follower?` 仅在跟随者数为 0 时为真——**有跟随者时，地图传送（飞空/瞬移等）与载具使用被阻止**（`008_Game_Player.rb:42–48`；调用点 `004_Overworld_FieldMoves.rb` 与 `013_Items`）。
- **持久化**：跟随者数据在 `$PokemonGlobal.followers` 中持久保存（WP09 登记）；`dependentEvents` 为弃用旧格式（WP10 转换）。
- 跟随机制是事件级跟随（事件角色随行），**不自动等同于完整"跟随宝可梦"系统**（其完整规则归后续适用包）。

## 7. 默认行为与配置变体

- **基线默认**：事件页按从后向前选择；触发按 3.2 方式启动；解释器按 4.1 更新循环执行；命令按第 5 节兼容矩阵；跟随者按 6.2 生命周期与限制。
- **支持但未默认启用**：开关名为 `s:` 前缀的脚本条件开关；调试穿透（$DEBUG+Ctrl，WP12 引用）；`SKIP_CONTINUE_SCREEN`（WP02 词典）。
- **配置/数据关联**：`GRASS_ANIMATION_ID` 等动画 ID（WP02 词典）；`SHINY_WILD_POKEMON_SWITCH`、`FATEFUL_ENCOUNTER_SWITCH` 等开关（WP02 词典）；公共事件与开关/变量的配置（作者内容）。
- **未验证组合**：具体 Demo 事件的收费、奖励、剧情结果（U01/U08）；缺失地图/事件材料下的完整事件流程；并行/自动事件在地图切换中的全部边界。
- 参考快照行为、官方版本预期、未来目标分开标记；本包只记录第一类。

## 8. 边界、失败与未知

- 无满足页：事件不可见/可穿透/无触发（3.1）。
- 解释器失联：地图不同且无连接 → 事件终止（4.1）。
- 深度超限：公共事件调用 > 100 层 → 提示并退出（4.1）。
- 脚本异常：SystemExit/Reset 原样抛出；其他异常按事件错误处理（4.2）。
- 空操作命令：18 个 command_dummy 命令被跳过且无效果（第 5 节）；调用方（事件作者）若依赖这些命令将无可见效果——兼容性限制如实登记。
- 缺失地图/事件材料：具体 NPC 对话、事件页、任务流程、商店库存、奖励和可达性无法确认（U01/U08）。
