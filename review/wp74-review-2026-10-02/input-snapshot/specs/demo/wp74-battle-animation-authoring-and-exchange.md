# WP74 规格：战斗动画制作与交换（动画编辑器／组织器／单项与批量导入导出）

分类：**Demo / Developer Experience**（作者工具）；动画数据模型与缓存部分标 **Generic Kernel**；预览播放与战斗侧的关联合同标 **Combat Requirements**（只登记接口要求，不规定战斗实现）；宿主窗口/输入行为标 **User Interface** 与 **Engine / Overworld Integration**。
状态：**ReviewPending（A～F 具名静态范围，待统一 review）**——不自行标 Reviewed、不宣称通过。

## 1. 目的、范围与非目标

### 1.1 目的

从作者（游戏制作者）视角规定战斗动画的**制作、组织、交换与关联**能力：

- 战斗动画编辑器（debug 菜单「Battle animation editor」）：逐帧逐单元编辑、区间批量工具、音画时序、预览播放、单项 `.anm` 导入导出、保存与缓存失效。
- 动画组织器（「Battle animation organiser」）：集合内动画的排序/插入/删除与保存。
- 批量导入导出（「Import/Export all battle animations」）：`Animations/` 目录级别的整套交换。
- 辅助制作工具 `animmaker.exe`（仅文档陈述边界）与 `animmaker.txt` 的 XML 输入格式。
- 动画与招式/公共命名的**关联合同**（命名约定 → 编译产物 → 播放查找），只规定编辑器侧可见的命名与编译输入输出。

### 1.2 范围（A～F）

- **A 进入/离开与环境恢复**：入口、屏幕尺寸/缩放因子切换、BGM 停止与恢复、退出确认与缓存失效。
- **B 集合与动画管理**：动画列表（载入/重命名/删除/容量）、图样表与 hue、焦点位置、动画命名对关联的意义。
- **C 帧与单元编辑**：画布直接操作（鼠标/键盘全映射）、单元属性对话框、帧操作（复制/粘贴/清空/插入/删除/帧数）。
- **D 区间与路径工具**：复制帧区间、清空区间、补间、单元批改、整幅滑动、定义路径（平滑曲线/自由手绘）、音画时序五类。
- **E 预览与播放合同**：编辑器内预览（用户侧/对方侧）、与战斗播放器共享的逐帧应用合同、时序播放。
- **F 交换与兼容**：单项 `.anm` 导入导出、组织器、批量导入导出、旧格式转换、素材缺失与失败行为、辅助工具文档边界。

### 1.3 非目标

- 不规定战斗中动画的完整播放语义（属 WP67-A 已通过范围）；本包只登记编辑器预览与播放器的**共享逐帧合同**及命名关联的**编译侧输入输出**。
- 不重提取 WP72（debug 菜单框架、窗口/命令基础设施、安全复制与导入导出保护不对称）、WP73-A（编辑器通用框架、分配/复制工具函数）、WP15（RTP 资源解析）、WP17（消息/窗口/输入）、WP04（编译器生命周期）；这些以依赖身份引用。
- 不运行编辑器/播放器/批量工具，不验证实际画面、音频或文件写入效果；不反编译或启动 `animmaker.exe`；demo 素材缺口如实登记为未验证。
- 不设计未来 API 或类体系；正文按行为组织，审计名（方法/常量/路径）仅作 traceability 标识。

## 2. 概念与术语（实现中立）

- **动画集合**：有序动画槽序列，槽位从 0 起编号；集合至少含 1 个动画；有「当前选中槽」游标（调整容量时若越界则钳到新长度内）。持久化于 `Data/PkmnAnimations.rxdata`，运行期缓存于全局临时数据（WP04/WP73-A 同款缓存模式）。
- **动画**：命名实体＝名字＋图样表名（无扩展名）＋色相（0–359）＋焦点位置默认值＋有序**帧**序列（至少 1 帧）＋**时序项**列表。`id` 为兼容字段（本工具链新建/导入一律 −1，表示「非 RPG Maker XP 动画」）；`speed` 为惰性元数据（默认 20，编辑器无编辑入口，播放侧未消费——见 §10.4）。
- **帧**：固定容量（60 槽）的单元槽序列。新建帧自带两个**个体单元**：槽 0＝使用者（图案 −1、焦点＝使用者、锁定），槽 1＝目标（图案 −2、焦点＝目标、锁定）。
- **单元（cel）**：26 元属性向量——X/Y 坐标、XY 缩放（百分比）、角度（0–359 度）、镜像、混合方式（0/1/2）、可见性、图案号（≥0 为图样表单元；−1＝使用者立绘、−2＝目标立绘）、不透明度、混合色（RGBA）、色调（RGB 偏移＋灰度）、闪烁色（RGBA）、锁定、优先级（0 最后/1 最前/2 焦点后/3 焦点前）、焦点（1 目标/2 使用者/3 双方/4 全屏）。新建单元默认：缩放 100、角度 0、不镜像、混合 0、可见、不透明 255、各色/色调/闪烁 0、优先级 1、不锁定。
- **时序项（timing）**：帧号＋五型之一——0 播放音效（名/音量/音高）；1 设置背景（图或抹除＋位置/不透明/混色）；2 渐变背景（时长＋可选位置/不透明/混色各项）；3 设置前景（同 1）；4 渐变前景（同 2）。新建默认音量 80、音高 100、时长 5，可选各项默认「不参与」（nil）。
- **图样表**：单张 PNG，按 192×192 单元格、每行 5 格编图案号（0 起）；编辑器条带按 96×96 缩略显示、5 格一屏。
- **剪贴板**：编辑器私有，带类型键（帧/单元两种）；写入时整体序列化快照，读出时反序列化为新对象——多次粘贴互不影响，也不与源共享。
- **关联命名合同**：动画名前缀 `Move: 招式名` / `OppMove: 招式名`（对方侧变体）经编译映射到招式；`Common: 名称` 供战斗侧按名查找公共动画（见 §15）。
- **交换格式 `.anm`**：单个动画的序列化压缩文本（可移植）；**不是**整个集合的快照。
- **`Animations/` 目录**：批量交换单位；每个子目录一套（`.anm`＋图样＋音效）。

## 3. 进入、离开与环境恢复（A）

### 3.1 入口

- debug 菜单 `main → editors_menu`（「Other editors...」）下四项：Battle animation editor／organiser／Import all／Export all（`002_Debug_MenuCommands.rb:1266–1305`；菜单框架与门属 WP72）。编辑器与组织器经淡出淡入过渡进入（WP16）。
- 编辑器进入序列（`pbAnimationEditor`，`005:1157–1170`）：停止 BGM；读取动画集合缓存（`pbLoadBattleAnimations`——文件不存在或无缓存时结果为 nil）；若集合不存在或首槽为空，**新建默认集合**（1 个动画、1 帧、图案表名为空串）；屏幕尺寸加宽加高各 288 像素、缩放因子强制为 1；进入主循环。
- 离开序列：屏幕尺寸与缩放因子恢复（后者取系统设置值）；地图 BGM 按地图配置自动恢复。

### 3.2 退出确认与缓存失效（核心取消语义）

主循环中 BACK 触发**两道独立确认**（`005:994–1002`）：

1. 「Save changes?」——是：把整个集合写入 `Data/PkmnAnimations.rxdata`；否：不写。
2. 「Exit from the editor?」——是：**清空集合运行缓存**并退出主循环；否：返回编辑（第 1 道的选择不撤销——若已保存则已落盘）。

组合语义：保存＋退出＝落盘并失效缓存；不保存＋退出＝**内存编辑随缓存失效丢弃**（下次读取以文件为准）；保存＋不退出＝已落盘且继续编辑（缓存内容即文件内容）；不保存＋不退出＝仅内存态。**编辑全程作用于全局缓存对象本身**（无独立副本）——退出前未保存的改动对同一会话内读取该缓存的其它路径同样可见（例如同会话战斗播放），直到缓存失效。

### 3.3 资源清理

主循环结束后释放画布/窗口/视口，并清空 RPG 图像缓存（`RPG::Cache.clear`）。进入时若图样表名为空或位图加载失败，画布位图为 nil（不中断进入；只是禁止空白处新增单元，见 §4.1）。

## 4. 画布交互与单元直接编辑（C-1）

画布＝战斗背景图＋64 像素边框偏移的编辑区；当前帧各单元按逐帧合同渲染；另有当前帧单元编号角标、锁定挂锁角标与**上一帧残影**（蓝色编号、仅当前帧号 >0 且上一帧对应槽非空时显示）。

### 4.1 鼠标

- **左键点空白处**：若画布有位图（图样表已设置且加载成功）→ 在当前帧第一个空槽新增单元（图案＝条带当前选中图案号、焦点＝动画默认焦点位置、坐标＝点击点）并开始拖拽（锁定单元不进入拖拽）；无位图则不加。**满 60 槽时静默失败**（无消息）。
- **左键点单元**：命中即选中（编号黑框）；多单元重叠时后命中者优先（按槽序扫描，命中测试对非 ALT 取 64×64 盒、ALT 按下取含缩放/镜像的**透明像素级**测试）；点中即开始带偏移拖拽（锁定单元可选中但不拖拽）。
- **拖拽**：松开后停留在末位置；无越界钳制（可拖出画布）。
- **右键帧滑杆区**：帧菜单（复制帧/粘贴帧/清空帧/插入帧/删除帧，见 §6.1）。
- **右键其它位置**：单元菜单（属性/剪切/复制/粘贴/删除/重编号/路径外推，见 §4.3、§8.6）。

### 4.2 键盘（对当前选中单元）

| 键 | 行为 | 约束 |
| --- | --- | --- |
| TAB | 循环选中当前帧下一个非空单元槽 | 不在拖拽中 |
| DELETE | 删除当前单元 | 受 §4.4 删除门 |
| P | 打开单元属性对话框（§5） | 有选中单元 |
| L | 锁定/解锁切换 | 无其它门 |
| R / E | 角度右旋/左旋 10 度，模 360 | 无范围拒绝 |
| 小键盘 + / − | XY 缩放同步 ±10 | 钳 [10, 1000] |
| 方向键 | 移动 8 像素；按住 ALT 为 1 像素 | 锁定单元不移动 |
| Q | 定义路径（§8.6） | 有选中单元 |
| F5 | 帮助文本 | — |
| BACK | §3.2 双确认 | — |

帮助文本（F5 与侧栏 Help）写「ALT 为 2 像素」，**实际为 1 像素**——文档与行为不一致，如实登记（以行为为准）。

### 4.3 单元剪贴操作

- 复制/剪切以类型键「单元」写入剪贴板（剪切＝复制后按 §4.4 删除门删除）。
- **粘贴单元**：类型键不符或无空槽→无操作；否则放入当前帧第一个空槽，坐标取粘贴点，**强制解锁**，图案 −1/−2 时绑定使用者/目标立绘，成为当前选中。
- 帧剪贴（类型键「帧」）：粘贴帧＝整帧替换当前帧内容（含两个体单元位）。

### 4.4 单元删除门（不变量）

满足全部才可删：未锁定；且若图案 <0（个体单元），当前帧内同图案单元数 >1——**每个体种类至少保留一个**（最后的使用者/目标单元不可删）。清空帧/清空区间时，不可删单元不删除而是**重置为新建默认值**（坐标/焦点保留——重置只覆盖 §2 默认值清单中的属性）。

### 4.5 重编号与交换

单元菜单「Renumber...」仅当当前槽 ≥2 可用；对话框滑杆范围 2–60、默认当前槽；确认后与目标槽**交换两槽内容**并把选中切到目标槽；目标 <2、与自身相同或取消（返回 −1）→ 无操作。槽 0/1 永远不参与重编号。

## 5. 单元属性对话框（`pbCellProperties`，C-2）

对**克隆副本**编辑：取消/ESC 弃副本（原单元不变）；OK 把全部 12 组值写回并原位替换原单元内容。右侧实时预览（图样/缩放/角度/不透明/混合/镜像/优先级/焦点即改即显；**X/Y 不参与预览**——预览位置固定）。

| 控件 | 范围 | 默认 |
| --- | --- | --- |
| Pattern 滑杆 | −2…1000 | 现值（−1 使用者、−2 目标、≥0 图样号） |
| X / Y 滑杆 | −64…576 / −64…448 | 现值 |
| Zoom X / Y | 5…1000 | 现值 |
| Angle | 0…359 | 现值 |
| Opacity | 0…255 | 现值 |
| Blending | 0…2 | 现值 |
| Flip | False/True | 现值（0/1） |
| Priority | Back/Front/Behind focus/Above focus | 现值（0–3） |
| Focus | User/Target/User and target/Screen | 由存储值经兼容映射（存储 1→Target、2→User、3→User and target、4→Screen；缺省取动画焦点位，再缺省取 4） |

- **Set Blending Color**：RGBA 四滑杆各 0–255，现值默认；子对话框内预览即时，OK 才写入克隆，Cancel 弃。
- **Set Color Tone**：RGB 偏移各 −255…255、灰度 0–255；同样 OK 才写入。
- 焦点/优先级写回使用反向映射（User→2、Target→1、User and target→3、Screen→4）。
- 滑杆族通用行为（§17 控件合同）：箭头单击 ±1、按住 >1.5 秒 ±5、>3 秒 ±10；值越界即钳；初值越界在首次刷新时钳入范围。

## 6. 帧操作与帧数（C-3）

### 6.1 帧菜单（右键帧滑杆）

| 项 | 行为 | 边界 |
| --- | --- | --- |
| Copy Frame | 当前帧整帧（60 槽）写入帧剪贴板 | 无 |
| Paste Frame | 类型键为「帧」时整帧替换当前帧 | 键不符无操作 |
| Clear Frame | 当前帧按 §4.4 删除门清空（可删→清槽；不可删→重置默认） | 无 |
| Insert Frame | 在当前位置插入**当前帧的副本**（逐槽克隆；`true` 哨兵值不克隆） | 帧号越界无操作 |
| Delete Frame | 删除当前帧；删的是末帧时当前帧号 −1；选中单元清空 | **仅剩 1 帧时拒绝**（静默） |

### 6.2 帧数与导航

- 帧滑杆（「Frame:」）：范围 1…当前帧数，初值经首次刷新钳入；改值即切当前帧。
- 总帧数按钮（「Total Frames: N」）：打开帧数对话框——滑杆 1…1000、默认当前帧数；OK 调整帧序列长度（**缩短直接截断末尾帧**，扩长逐帧新建带双个体单元的帧）；Cancel/BACK 无操作。缩短后当前帧号越界则钳到新末帧并同步滑杆。
- 上一帧复制（侧栏「Paste Last」）：当前帧号 >0 时把上一帧逐槽克隆覆盖当前帧。

## 7. 动画集合管理（B）

### 7.1 动画列表（「List of Animations」）

打开时**先把所有 nil 槽就地填充为新默认动画**（仅内存，含取消路径也会留在缓存集合中），再显示「序号 名字」列表，初始选中集合游标。

- 底部「Total Animations:」滑杆 1…2000＋「Resize Animation List」按钮：点击**立即**调整集合长度（扩长填默认动画；缩短弹栈截尾；游标越界钳入）并重建列表——**无确认、无独立取消**（不载出即仅内存）。
- Enter（USE）对当前槽三选：**Load Animation**（画布载入该动画并置集合游标＝该槽，关闭列表）；**Rename**（改名对话框，§7.2）；**Delete**（确认后**以新默认动画替换该槽**——不是置 nil，槽位不塌缩）。
- BACK：关闭列表，不载入（画布/游标不变；nil 填充已发生）。

### 7.2 重命名

文本框预填现名；启用文本输入模式；OK 或回车＝写回并刷新列表项；Cancel/ESC＝弃。名字是关联合同载体（§15）——`Move:`/`OppMove:`/`Common:` 前缀在编译/播放侧有特殊意义，编辑器本身不校验。

### 7.3 图样表与色相（「Set Animation Sheet」）

列出 RTP 各路径 `Graphics/Animations/` 下 `*.png`（仅 PNG）；右侧预览窗随选择即时刷新；色相滑杆 0–359 默认 0 且即调即预览。USE 确认：动画记录图样表名（去扩展名）与色相，画布与条带换绑新位图。BACK：不改（原名/原色相/原位图保持）。**列表为空时 USE 无效**。

### 7.4 焦点位置（侧栏「Cel Focus...」）

四选菜单（User/Target/User and target/Screen），现值带 [X] 标记；选择经兼容映射（User→2、Target→1、User and target→3、Screen→4）写入动画默认焦点位并刷新画布；取消（返回 −1）不改。该默认值用于：新建单元的焦点、属性对话框焦点缺省、批改焦点缺省。

### 7.5 条带（图案选择）

5 格缩略（96×96）＋左右箭头；点格选中（红框）即定当前图案号；箭头单击滚 ±1 格、按住 >0.75 秒滚 ±3 格；起点钳 [0, 图样表总格数]（起点可等于总数，此时显示空槽区）。图案号布局：每行 5 格、每格 192×192。

## 8. 区间与路径工具（D-1）

全部区间对话框共享：帧号输入为 1 基滑杆（范围 1…当前帧数），单元号为 0 基滑杆（0…59）；Cancel/BACK 一律无改动关闭；OK 才执行。

### 8.1 复制帧区间（Copy Frames...）

首帧（默认 1）、末帧（默认末帧）、目标位（默认当前帧 +1）。重叠安全：目标在源区间之后→**从尾向首**逐帧复制；目标在源之前→从首向尾；首末相等或区间长度 ≤0 无操作。逐帧逐槽克隆（同 §6.1 Insert 的克隆规则）。

### 8.2 清空区间（Clear Frames...）

对 [首, 末] 每帧执行 §4.4 清空（可删清槽、不可删重置默认）。

### 8.3 补间（Tweening...）

起始帧（默认 1）、结束帧（默认末帧）、首末单元槽（默认 0…59）、三组属性勾选（Pattern／Position-Zoom-Angle／Opacity-Blending，默认全不勾）。

- **起始 ≥ 结束 → 直接关闭、零改动**。
- 对每列单元：起止两帧该槽**缺一即整列跳过**；中间帧该槽为空→新建单元（默认属性）并**强制写入全部三组**（无视勾选），非空则只写勾选组。
- 插值（独立数学）：帧 k（0…帧距）处属性值＝起始值＋（差值 × k ÷ 帧距），整数除法按宿主语言向负无穷取整；帧距＝结束−起始。
- 结束后画布重绘。不触碰时序项与未勾选属性（除新建单元被强制写三组外）。

### 8.4 单元批改（Cel Batch...）

帧区间＋单元槽区间；12 项可选属性（Pattern/X/Y/ZoomX/ZoomY/Angle/Opacity/Blending/Flip/Priority/Focus，各自带勾选框，默认全不勾）。**只作用于已存在单元**（不新建）；勾选项写新值、未勾不动；焦点经兼容映射写回。OK/USE 执行，Cancel/BACK 弃。

### 8.5 整幅滑动（Entire Slide...）

帧区间＋X/Y 偏移（各 −500…500，默认 0）：区间内每帧所有**未锁定**非空单元坐标平移。

### 8.6 定义路径（Q 或单元菜单「Extrapolate Path...」）

前提：有选中单元。帧数滑杆 2–500（默认 20）；OK 时若当前帧＋帧数超出动画长度则先扩帧（新帧带双个体单元），再把路径点序列的 X/Y 逐帧写入**当前选中槽**（缺失槽位新建单元，图案取该单元当前图案、焦点取动画默认；只写 X/Y 两属性）。Cancel/BACK 弃。

- **Define Smooth Curve**：4 个控制点（两端红色、两中间黑色）；端点未放置前中间点不可拖；两端点就位后自动生成 1/3、2/3 处中间点并显示 30 个路径采样点；拖动控制点实时重算 Catmull-Rom 曲线（三段式：端点重复取端）。BACK 退出定义——**若已显示路径线，仍生成路径**（与「取消即弃」直觉相反，如实登记）。
- **Define Freehand Path**：先等待首次按下开始记录（此阶段 ESC＝整体取消→空路径），记录阶段逐点采样（与末点相同不重复记），松开左键或 ESC 结束（**此阶段 ESC 不取消**——保留已绘点）；随后按弧长等距重采样为帧数个点（取整到像素）。
- 路径数学（独立定义）：点列弧长参数化，pointOnPath(t) 取累计弧长 ≥ t×总长的首个非零长段内线插（零长段跳过）；t∉[0,1] 或帧数 <0 属定义域错误（编辑器滑杆保证 2–500）；平滑采样产生 帧数＋2 个候选点并按时标截用。**空路径（首阶段 ESC）按 OK 属未保护输入**——静态推导会失败（无兜底），具名登记、未运行验证。

## 9. 音画时序（D-2；侧栏「SE and BG...」）

列表＝该动画全部时序项文本（格式见下）＋5 个「Add:」入口；底部帧号滑杆（1…帧数，默认当前帧 +1）。

- **Set Frame**：把选中既有项移到滑杆帧（帧号 −1 存储）并刷新文本。
- **Delete Timing**：删除选中项并修正列表索引。
- **USE 于 Add 行**：新建对应类型时序项并打开子对话框；子对话框确认（返回真）才把帧号写入并追加（列表重排，Add 行移尾）；子对话框取消→不新增。
- **USE 于既有项**：按类型重开对应子对话框编辑（0→音效、1/3→图形设置、2/4→渐变编辑）；取消＝保持原值。
- BACK：离开时序列表（改动已作用于内存动画）。

### 9.1 音效子对话框（pbSelectSE）

文件列表＝RTP `Audio/SE/Anim/` 下 wav/ogg/mp3/wma（去重、大小写不敏感排序），首项「[Play user's cry]」。Volume 0–100（新建默认 80）、Pitch 20–250（新建默认 100）。「Play Sound」试听（**未选文件时无效**）；「Stop Sound」停止。OK：记录文件名（去扩展名；选叫声项则名＝空串）＋音量＋音高，返回真；Cancel/BACK：返回假。

### 9.2 背景/前景图形子对话框（pbSelectBG；用于类型 1/3）

文件列表＝RTP `Graphics/Animations/` 下 png/gif（去重排序），首项「[Erase background graphic]」（选它＝名置空串＝抹除图形）。滑杆：X/Y −500…500（默认现值或 0）、Opacity 0–255（**默认现值或 0**——新建项不调整即为 0，播放时不可见，如实登记）、RGBA 各 0–255（默认现值或 0）。OK 写入并返回真；Cancel/BACK 返回假。

### 9.3 背景/前景渐变子对话框（pbEditBG；用于类型 2/4）

Duration 0–50（默认现值，新建 5）；X/Y/Opacity/R/G/B/A 七项**可选滑杆**（勾选框默认按现值是否非空）。**OK 仅当至少一项勾选**才写入（时长＋勾选项新值，未勾项写「不参与」）并返回真；全不勾按 OK＝不写入、返回假（无提示）。Cancel/BACK 返回假。

### 9.4 时序项文本格式（列表显示）

`[帧号]` 前缀＋类型描述：音效含名/音量/音高；图形设置含名/混色（缺省显 `-`）/不透明/坐标；渐变含 `@时长` 与参与项（未参与不显示）。

## 10. 预览播放（E）

### 10.1 入口与构成

侧栏「Play Animation」（用户侧视角）/「Play Opp Anim」（对方侧视角——交换使用者/目标槽位与翻转前提）。预览在与编辑器同画布内进行：临时双立绘（使用者背面/目标正面调试图）＋动画播放器实例（与战斗同类的逐帧播放器，编辑模式偏移 +64,+64）；播放期间隐藏编辑角标与残影，结束后恢复并释放播放器。

### 10.2 逐帧应用合同（与战斗播放器共享；WP67-A 的编辑侧引用）

- 帧率硬编码 **20 帧/秒**（动画 `speed` 元数据默认 20 但**未被消费**——编辑器无入口、播放器不用，登记为惰性字段）；非循环，播完自止。
- 每帧：全单元槽先隐，再按帧内非空单元逐个应用——图案 −1/−2 绑定使用者/目标位图、≥0 绑定图样表 192×192 源区（行 5 格）；混合/角度/镜像/不透明/可见（编辑模式下不可见单元半透显示）、缩放（百分比÷100）、混色、色调、源点居中、坐标写入。
- 焦点定位：焦点＝目标→坐标＋（目标当前中心−目标焦点常量）；焦点＝使用者同理；焦点＝双方→按源线段（双焦点常量）到目标线段（双立绘当前中心）的**线性变换**重定位，且源线段与目标线段 X 方向相反且图案 ≥0 时镜像取反；焦点＝全屏→不偏移。优先级：0→最底、1→最前、2→焦点立绘之后、3→焦点立绘之前（焦点双方/全屏时按默认层）。
- 时序播放：到达帧号触发——音效按名播放（名空且使用者有个体时放其物种叫声；**编辑器预览的使用者是占位无个体→叫声项静音**）；设置型图形/抹除即时生效（图形位图或纯色板，不透明与混色应用）；渐变型记录旧值后在时长内线性插值（只处理参与项）。

### 10.3 预览≠保存

预览不产生任何数据改动；播放中的画面效果（含时序设置的背景/前景）随播放器释放消失。

## 11. 单项导入导出（F-1；`.anm`）

### 11.1 导出（侧栏「Export Anim...」）

自由文本输入文件名（空初值、上限 32 字符）；**空名＝取消**（静默）。否则名＋`.anm` 写入游戏目录：内容＝**当前选中动画**（仅单个）的压缩序列化文本。写异常→「Couldn't save…」消息；成功→两条消息（已保存到游戏目录／文本可移植）。导出**不是**集合保存（不影响 rxdata 与缓存）。

### 11.2 导入（侧栏「Import Anim...」）

列出 RTP 各路径下 `*.anm`；USE 选择：读出并解码——非动画对象或解码失败→「invalid or could not be loaded」消息并**回到列表**（可再选或 BACK）；成功则置 `id` −1、执行旧格式转换（§14.1）、**替换当前选中槽**（仅内存；集合游标不变）。随后检查图样表文件存在性：缺失→警告消息（「will load anyway」）但照常载入画布。BACK：不改。导入结果同样只随 §3.2 保存确认落盘。

## 12. 动画组织器（F-2；「Battle animation organiser」）

- 集合不存在或首槽空→「No animations exist.」并直接返回（不改任何数据）。
- 列表「序号: 名字」（nil 槽显 `???`）；帮助窗注明操作：Z+Up/Down 交换、Z+Left 删除、Z+Right 插入（命令窗口合同属 WP72/WP17 基础设施）。
- 交换上/下：边界内互换相邻两槽并重列；删除：移除该槽（游标钳入）后等待 0.2 秒；插入：在该位置插入新默认动画后等待 0.2 秒。**全部仅内存**，直到退出确认。
- 退出（BACK/取消键）：三选「Save changes?」Yes/No/Cancel（默认 Cancel）——Yes＝写 `Data/PkmnAnimations.rxdata`＋清集合缓存＋「Data saved.」后离开；No＝**不写盘直接离开**（内存改动随缓存保留或随后失效）；Cancel＝返回继续。

## 13. 批量导入导出（F-3；`Animations/` 目录）

### 13.1 批量导出（「Export all battle animations」）

整体有兜底保护（WP72 保护不对称先例的沿袭）：任一处异常→打印诊断＋「The export failed.」消息结束。

1. 建 `Animations/` 目录（已存在忽略）；集合不存在→「There are no animations to export.」结束。
2. 逐动画处理，**跳过 nil／0 帧／无名**动画；目录名＝动画名（非单词字符替换为 `_`）；写 `<目录>/<安全名>.anm`（单动画压缩文本）。
3. 资源随行：图样表名非空→经 RTP 解析图像路径并**安全复制**（§13.3）；时序项中类型 0（含缺省型）且名非空→经 RTP 解析音频路径安全复制；类型 1/3 且名非空→图像安全复制。
4. 完成消息（全部导出到 Animations 目录）。

### 13.2 批量导入（「Import all battle animations」）

**无整体兜底**（与导出的不对称是已确认行为）：仅 `.anm` 解码有单点保护。

1. 收集 `Animations/` 一级子目录（跳过 `.`/`..`）；无→提示性消息结束（不写任何数据）。
2. 集合＝缓存或新建默认集合；逐目录：先把目录内**音频**（wav/ogg/mp3/mid/wma——按文件名末 3 字符判定且大小写各试一次；**`midi` 模式因按末 3 字符比较永不命中，`.midi` 文件实际不复制**，如实登记）与**图像**（png/gif，同法）安全复制到 `Audio/SE/Anim/`、`Graphics/Animations/`——**资源复制发生在 `.anm` 校验之前**，目录无合法 `.anm` 时资源仍已复制。
3. 逐 `.anm`：解码失败或非动画对象→**静默跳过**（无消息）；合法则：分配槽位（§13.4）；名空→取目录基名；`id` 置 −1；旧格式转换（§14.1）；图样表在目录与 RTP 图像路径均不存在→**图样表名清空**；各时序项名在目录与 RTP 音频路径均不存在→**该项名清空**（两处「缺失文件清单」聚合在清空后收集、且从未展示——死聚合，如实登记）；写入分配到的槽。
4. 全部目录处理后：写 `Data/PkmnAnimations.rxdata`＋清集合缓存＋完成消息。**批量导入是唯一不经确认直接落盘的动画交换路径**（无「Save changes?」环节）。

### 13.3 安全复制合同（继承 WP73-A 已通过证据，不重新推导）

源不存在→不复制；目标不存在→复制；目标存在且同尺寸同内容→**不复制**（静默跳过）；目标存在且内容不同→**确认覆盖**（是才覆盖）；复制以读取字节整体写入（可选第三参数改目标路径）。

### 13.4 槽位分配合同（继承 WP73-A 已通过证据）

从槽 1 起扫描（**槽 0 永不分配**）：首个 nil 槽→用之；首个「准空」槽（1 帧、帧内恰 2 单元、无名）→用之；都没有→**把集合长度调整为 10 并返回调整前长度**（原长度 >10 时多出的槽被截断且不恢复；WP73-A 动画空槽分配条款）。

## 14. 旧格式转换与失效入口（F-4）

### 14.1 动画旧格式转换（导入即转）

转换判定：任一帧任一单元**焦点属性缺失**即视为旧格式。转换内容：优先级缺失补 1；槽 0→焦点＝使用者、坐标＝使用者焦点常量；槽 1→焦点＝目标、坐标＝目标焦点常量；槽 ≥2→焦点取动画焦点位（缺省 4），且动画焦点位为目标时坐标叠加（目标焦点常量 X、Y−2）。单项导入（§11.2）与批量导入（§13.2）对每个 `.anm` 都执行；返回是否发生了转换。

### 14.2 全量转换入口（死入口登记）

`pbConvertAnimsToNewFormat`（`004:128–146`）：提示→逐动画转换→有转换才写 `PkmnAnimations.rxdata`＋清缓存→报告转换数。**全脚本检索无任何调用者**（无菜单项）——登记为存在但不可达的入口，不推断其菜单归属。

### 14.3 RMXP 动画转换（已停用）

`pbConvertRPGAnimation`（RPG Maker XP 动画→本格式）仅在编译器注释块中被引用（`002_Compiler_CompilePBS.rb:1283–1293` 整段注释）；`ArrayCountSlider`（`002:589–598`）构造体引用了其词法作用域中不存在的名字——两者均登记为**定义存在、当前不可达**，不作行为承诺。

## 15. 招式/公共动画关联与编译侧合同（F-5；只登记交界）

- **命名→映射**：编译动画阶段（WP04 生命周期内）扫描集合：`OppMove: 招式名`→对方侧映射、`Move: 招式名`→用户侧映射（名按招式数据解析，存在才记）；任一映射变化才写 `Data/move2anim.dat` 并重写集合文件（`002_Compiler_CompilePBS.rb:1272–1320`）。
- **播放查找**（WP67-A 域，引用不复述）：用户侧先取用户映射，对方侧先取对方映射（命中标记不翻转）再回退用户映射；命中编号可叠加连击序号；未命中按招式类型/类别默认表回退，再回退 `TACKLE`；公共动画按 `Common: 名称` 精确名查找。
- 编辑器侧可见事实：**改名即改关联**（重命名对话框不校验前缀）；动画在集合中的**槽号即关联值**——组织器换序/删除/插入会改变既有映射指向，需重编译才更新 `move2anim.dat`。

## 17. 共享控件与窗口合同（本包新见的编辑控件族）

- **按钮**：按下捕获、**松开在框内才算触发**（按下后移出松开＝不触发）。
- **滑杆**：左右箭头，单击 ±1、按住 >1.5 秒 ±5、>3 秒 ±10；写入即钳 [min, max]；初值越界首次刷新钳入（min<max 才钳）；到界箭头灰显；数字取整（floor）。
- **可选滑杆**：勾选框＋滑杆复合；未勾选时值＝「不参与」（nil），滑杆禁用。
- **文本滑杆**：选项数组索引式（同滑杆时序）；选项文本宽度按最长项缓存。
- **文本框**：光标闪烁（0.35 秒周期）、左右移动、退格/删除删光标前字符、字符插入光标处；启用期间宿主文本输入模式开、退出关。
- **复选框**：触发即翻转。
- **列表窗口/弹出菜单/确认/自由文本输入**：WP72/WP17 已通过基础设施，本包只登记调用点。
- **失效-重绘模式**：控件族与画布单元角标均为「标脏→刷新→清脏」。

## 19. 边界、失败与未知汇总（按 AGENTS.md 第 9/10 要素）

1. 空/初始：无集合文件→新建默认集合（§3.1）；组织器拒绝进入（§12）；批量导出报「无动画可导出」（§13.1）。
2. 画布无位图（图样表空名或加载失败）：不中断进入；空白处不可加单元；其余编辑可用（§3.3/§4.1）。
3. 满槽：新增单元静默失败；粘贴单元静默无操作（§4.1/§4.3）。
4. 末帧保护：仅 1 帧时删除帧静默拒绝（§6.1）；集合容量下限 1、动画帧数下限 1（§2）。
5. 个体单元保护：删除门 §4.4；清空帧/区间时重置而非删除。
6. 补间：起≥终零改动；端点缺列跳过；中间空槽新建并强制三组（§8.3）。
7. 复制区间重叠：双向安全；首末相等无操作（§8.1）。
8. 路径：曲线 BACK 于已显示路径线后仍生成路径；自由绘制首阶段 ESC＝空路径、记录阶段 ESC＝保留已绘点；空路径按 OK 未保护（静态推导失败，未运行）（§8.6）。
9. 时序：渐变编辑全不勾选按 OK＝无效（无提示）；新建图形设置默认不透明 0（播放不可见，需作者自调）；音效未选文件不可试听（§9）。
10. 预览叫声静音（占位个体无物种叫声）（§10.2）。
11. 单项导入坏数据→消息并回列表；缺图警告照常载入；导出写失败有消息（§11）。
12. 批量导入：`.midi` 不复制（末 3 字符判定）；资源先复制后校验；坏 `.anm` 静默跳过；缺资源字段清空且清单不展示；分配截断不恢复；结束无条件落盘（§13.2–§13.4）。
13. 死入口/死代码：全量转换无调用者；RMXP 转换整段注释；`ArrayCountSlider` 不可达；缺失文件清单死聚合；`speed` 惰性（§14/§10.2）。
14. 文档差异：帮助文本「ALT 2 像素」与实际 1 像素不一致（以行为为准）（§4.2）。
15. **素材缺口（未验证）**：demo 无 `Graphics/UI/Debug/`（编辑器启动所需箭头/角标/立绘/背景图缺失——启动素材缺失，静态推断无法正常进入，具体失败形态未运行验证）、无 `Graphics/Animations/`、无 `Audio/SE/Anim/`、无 `Data/PkmnAnimations.rxdata`、无 `Data/move2anim.dat`、无 `Animations/` 目录。全部运行表现（画面/音频/实际写入）保持未知；demo 事件可达性归 WP77。
16. 宿主/素材相关不确定：RTP 多路径枚举顺序对同名文件的影响（WP15 合同内）；`pbListWindow`/`pbCommands3` 细节（WP17/WP72 合同内）。
