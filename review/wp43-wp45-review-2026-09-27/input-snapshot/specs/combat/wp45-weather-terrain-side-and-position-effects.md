## 1. 目的、范围与非目标

定义战斗的持续环境与作用位置：哪些效果属于全场、某侧或具体席位；何时建立／替换／拒绝重复；暂不生效与被删除怎样区分；持续多少个实际处理时点；换人、Shift、失能和提前清除后状态属于谁。

自身范围：**A** 默认来源、天气／场地的建立和有效查询；**B** 生命周期、临时覆盖、压制、自然到期和直接移除；**C** 全场13／阵营22／位置9项参考效果记录的有界作用域和局部生命周期目录；**D** 入场危害、侧交换、屏障清除、位置恢复／延迟攻击的移交；**E** 局部期限与已审／批内计算、状态的交界及静态向量。

目录记录是行为作用域，不要求未来使用数组、类、继承或参考的数值编号。随成员变化的临时状态不全部归本包：WP44拥有异常／阶级，WP41拥有替换／拘束，WP47拥有类型／特性／行动控制完整族，WP46拥有特殊伤害／多击／恢复完整族。全场的金钱记录只在此说明生存期和写入，完整结算交WP42；不因此宣告WP42、WP46–50或AI已启动／完成。

## 2. 域与状态模型

- 天气名录：无、晴、雨、沙暴、冰雹、大日照、大雨、强风、暗影天空（9项含无）。战斗场地名录：无、电气、青草、薄雾、精神（5项含无）。地图环境、地图地形标签和战斗场地是不同输入。
- 天气／场地各有**默认来源、当前存储值、当前期限**。初始化为无／无／0；指定默认来源会同时设置当前值和期限−1。正期限是可递减，−1不按普通计数到期，0表示计时已尽；默认来源不是一个暂停后继续倒数的栈。
- 全场效果影响双方；侧效果由目标所属侧读取，不随某一只换下消失；位置记录留在指定交错席位，不跟创建者或当前占位者走。成员自己的状态随该成员与其替换规则变化，不能仅因记录名相似就归入位置。
- 输入包括创建规则、世界天气类别与配置、当前成员有效性、来源招式／能力／道具、当前计数和目标；输出包括域状态、期限、有效查询值、触发通知、HP／PP／异常变化及消息。没有消息不能推出状态没变。

## 3. 世界输入、默认与有效天气（WP45-A）

### 3.1 创建来源

创建规则显式天气／场地优先。没有显式场地且“世界天气设置战斗场地”开时，世界天气标识Storm→电气、Fog→薄雾，只此两项；当前配置世代8使该开关默认开。天气映射则使用世界天气**类别**：Rain／Storm→雨、Hail→冰雹、Sandstorm→沙暴、Sun→晴，其余不自动建立；不可把类别映射与标识映射混为一张同义表。

通过默认设置入口写入默认和当前并置−1，不走普通建立时的通知链。WP11／59负责世界／地图来源，本包只消费创建瞬间的输入；之后战斗内覆盖／清除不反写世界天气。实际PBS样本含地图021 Rain,100、072 Storm,50；它们证明配置存在，不能证明本次地图事件实际发生或概率结果。

### 3.2 三层天气查询

| 层 | 结果与用途 |
| --- | --- |
| 当前存储天气 | 决定重复建立、普通招式／能力能否覆盖、计时与持续消息 |
| 战斗有效天气 | 若场上有有效无关天气／气闸能力，返回无；否则当前存储天气。压制不清存储值或暂停正期限 |
| 某成员有效天气 | 在战斗有效天气上，成员有效实用伞把晴／雨／大日照／大雨视为无；沙暴、冰雹、强风、暗影天空不在该屏蔽组 |

能力／道具有效性须按实际查询：失能通常不提供普通有效能力；胃液、中和气体等可压制，具体完整族归WP48/49。实用伞若受魔法空间等失效，不能仍套其伞效果。

不同消费者使用不同层：普通伤害天气倍率读使用者有效天气，雷电／暴风命中与抗冰冻读目标有效天气；原始天气阻止火／水伤害招使用的是战斗有效天气，不能因为用户有伞就推导整招允许。原始天气效果也不能仅由没有持续消息推断不存在。

## 4. 天气建立、覆盖、到期与压制（WP45-A/B）

### 4.1 分入口建立

| 入口 | 前门／期限／反馈 |
| --- | --- |
| 四种普通天气招式 | 当前存储为大日照／大雨／强风时失败，即使天气被压制；同种也失败。成功提交调用天气建立，固定5，不额外重复播放通用天气动画 |
| 天气核心建立 | 同当前存储值直接返回，不刷新、不通知；否则替换当前值。固定时5、非固定时−1；正期限且来源有效持有对应岩石可延至8。该入口本身不复查普通天气招式的原始天气禁止门 |
| 普通天气能力包装 | 默认不覆盖当前原始天气；同种不重设。当前配置普通天气能力固定5，旧配置可−1；原始三天气恒非普通固定期限，特殊能力可显式允许覆盖原始天气 |
| 默认设置 | 直接默认＝当前、期限−1；不是核心建立的重复／动画／通知合同 |

湿润岩石只延雨、炽热岩石只延晴、冰冷岩石只延冰雹、沙沙岩石只延沙暴到8；没有来源或道具不有效不延长。暗影天空已在状态／查询／期限中支持；普通四天气招式不包含它，完整暗影来源和模式交WP23，不据此声称有相同建立招式。

天气核心换值后通知全员检查天气形态，再检查原始天气终止。由于形态检查可走实际形态写入，不把所有天气反应一律描述为仅临时视觉；完整形态规则仍在WP21/22/49。

### 4.2 原始天气来源终止

当当前值不同于默认值时，大日照／大雨／强风分别要求场上仍有有效终结之地／始源之海／德尔塔气流；没有则清为无、给出解除消息、检查形态，并在默认天气非无时重新启动默认，期限−1。当前等于默认值时该终止检查直接不处理，因此默认原始天气不因缺少对应能力被这个门清掉。

检查出现在建立后、离场／濒死及持续能力检查等具名调用点，不是仅回合末统一检查。其他原始天气覆盖原始天气时保留的是默认来源；不会把曾经被覆盖的临时雨压回栈等待恢复。

### 4.3 天气局部回合末

正期限先减1；减至0时清当前、发对应结束反馈、检查形态，然后默认非无则建立默认。没有默认则返回，不再对刚结束的天气做本轮持续伤害；恢复了默认则继续处理**恢复后的天气**的持续反馈、能力反应和伤害。−1不递减。天气被无关天气／气闸压制仍照样递减且可显示存储天气持续反馈，但成员有效天气为无时不受相应天气伤害。

天气伤害：活着且可受该间接伤害者，沙暴／冰雹／暗影天空名义总HP/16整数商，随后HP入口保证存活时最少1；按实际扣量处理道具恢复与濒死。沙暴排除地／岩／钢、地下／水下两回合状态、对应防沙能力组与护目镜；冰雹排除冰、地下／水下、对应防冰雹能力组与护目镜；暗影天空排除暗影个体。魔法防守在共同间接伤害资格排除；完整能力家族未来复核，不能由这些例外推导全部天气均伤害。

## 5. 场地建立、有效成员、到期与直接移除（WP45-A/B）

- 核心建立同当前场地直接返回不刷新；不同则覆盖，默认固定5，可显式非固定−1；来源有效大地膜使正期限8。普通四场地招式同种失败，场地能力也按相同状态前门选择建立。核心通知按全员场地能力检查，再全员场地道具检查。
- **受场地影响**要求既非浮空又非半无敌。浮空查询先按有效黑色铁球、扎根、击落、重力判接地；否则飞行类型、未模式破坏的飘浮、有效气球、磁力飘浮、意念移物为浮空。不是只看飞行类型，也不把“接地”自动等同于受场地影响（半无敌还可拒绝）。
- 电／草／精神威力增益、薄雾龙减伤引用WP43；电防睡眠、薄雾防异常和世代≥7防混乱引用WP44；精神场地按已保存正优先级阻止对立方对受影响目标的招式，主入口WP40。青草恢复在较早回合末局部：存活、受影响且可恢复HP时总HP/16整数商，实际恢复按HP上限和最小1。
- 场地正期限在后面的场地结束段减1；到0且当前场地非无，清为无并通知场地能力。若默认非无，启动默认为−1，然后该消费者**再次**调用全员场地能力及道具检查。一次这种恢复中，能力检查调用包括“清为空”一次、“重新建立”一次、“建立之后追加”一次；道具检查为后两次。具体处理器是否产出重复副作用由WP49/50复核，不删去已发生的调用。
- **直接移除不是自然到期**：铁滚轮／世代≥8除雾的已读路径只把当前场地置无，保留期限数值，不触发上述自然到期通知／默认重启。之后正期限仍会减，但当前已为无时，不满足“非无且到0”的恢复条件。不能写成“清除后必然恢复默认场地”。铁滚轮在当前无场地时前置失败；除雾是否成功还可由其它效果决定。
- 期限1的青草在本轮较早恢复段仍可回血，稍后才到0消失；期限1的沙暴先结束再处理天气伤害。两者不可统一为“剩1时不再起效”。

## 7. 阵营／全场效果的建立与清理差异（WP45-B/C）

### 7.1 火海实际期限

固定快照有两个消费者：较早火海伤害段先减1，减成0则直接跳过伤害；存活且可受间接伤害的非火成员名义损总HP/8。后面的侧效果结束段又对仍正的火海减1，到0发结束消息。因此初始4在完整回合末没有中途终局时：**4→3（伤害）→2；下轮2→1（伤害）→0（结束消息）**。初始1会在较早段减到0、无本次伤害，后段不再给“减至0”消息。此处记录固定源码，不改成通行游戏“四次伤害”。缺少后段执行时不能套完整双递减向量。

### 7.2 当轮侧保护

戏法防守重复真失败，还需尚有另一未动招式／Shift席位；掀榻榻米要求用户本次在场计回合≤1且不是最后剩余行动，未独立以已有本侧标记拒绝。快速／广域的共同保护入口拒绝重复建立并复位保护计数；旧世代≤5还按连续保护计数抽签，世代≥6侧型免该抽签，成功仍将保护计数按配置乘3（旧为2）。完整尾清除侧旗，不等于清用户所有其它记录。

保护消费各自不同：戏法防守挡非自身的非全体变化招；广域防守挡多目标数>1且非自身，世代≥7不局限伤害招；快速防守要求招式可被保护且已保存优先级>0；掀榻榻米针对伤害招。无形拳与接触绕过适用保护组，资格总序与反馈引用WP40，不追加统一命中修正。

### 7.3 侧交换、清墙与清场

**换场**只交换13个具名记录：极光幕、光墙、白雾、彩虹、反射壁、神秘守护、火海、撒菱、湿地、顺风、毒菱、隐形岩、黏黏网。双方这组都为空才失败；其余侧记录（含幸运咒语、当轮防守旗、回声、轮唱、上次倒下回合）不交换。期限／层数原值随对应记录到另一侧，不刷新。不能按招式描述文字推成“所有22项侧效果交换”。

- 劈瓦／精神之牙类在自己的通用效果阶段清对侧光墙／反射壁／极光幕，并忽略减伤墙；能否走到该阶段仍受WP40动作结果约束。
- 屏障破坏特性入场处理清双方这三墙；完整特性触发／失效归WP49，仅此清单已读。
- 除雾可因目标侧墙／白雾／神秘守护或危害存在而继续，即使闪避不能降；世代≥6也接受对侧危害，世代≥8也接受任意非无场地。效果清目标侧上述屏障、目标侧四危害；世代≥6再清另一侧四危害；世代≥8直接把场地置无。目标闪避的查询／变化引用WP44，清理不以降阶成功为条件；不清幸运咒语、顺风或所有侧记录。
- 高速旋转：用户存活且目标未被标无效时，在全部命中后的专门效果清用户拘束、寄生种子及己方四危害；当前世代的升速是另一个附效阶段，不能把“是否升速”作为清危害前提。完整招式／反制族归WP46/47-A。

## 8. 入场危害与范围（WP45-D）

普通替换入场先消费位置恢复，再按**隐形岩→撒菱→毒菱→黏黏网**处理；随后才统一处理危害造成的濒死与入场后续（WP41）。每一步自己的资格独立，前一步道具恢复会改变后一步当前HP。危害的存在、不能对某成员生效、被吸收清除三者分开。

| 危害 | 前提与数值／变化 |
| --- | --- |
| 隐形岩 | 存活且可受间接伤害、岩类型存在、无有效厚底靴；按**基础类型相性表**对当前全部类型计算岩相性，不套WP43招式相性全部修正。相性0不伤；名义总HP×相性/8，HP入口四舍五入并按当前HP／最少1处理。浮空本身不免 |
| 撒菱 | 可受间接伤害、非浮空、无有效靴；1/2/3层分别总HP除8/6/4整数商，HP入口再处理边界 |
| 毒菱 | 存活非浮空；毒型首先吸收并将层数清0，**先于厚底靴检查**。非毒成员经无来源／无招式普通中毒查询且无有效靴，1层普通毒、2层剧毒；神秘守护的普通门须有招式，故不从侧保护名称直接推导能挡此入口 |

厚底靴是入场作用许可，不删除危害。毒型穿靴且接地仍吸毒菱；漂浮毒型不吸。受场地影响另要求非半无敌，危害的接地门不要机械换成“受场地影响”查询。

## 9. 位置、换人、Shift与延迟执行（WP45-D）

### 9.1 祈愿

建立2与创建时恢复量，不存当前HP差额；两次实际计时处理后到0，当前位置有可治成员才恢复。创建者已换下仍可由同位置继任者受益，提示按来源队伍下标取名称。到期空位、濒死、满HP或回复封锁等不能治疗时放弃本次恢复，不把计数留1等待；恢复量／来源辅助值没有在这一到期路径强制清空，计数0使它不再触发，新建立会覆盖。

### 9.2 治愈之愿／新月舞

位置通知中治愈之愿先于新月舞：前者若可恢复HP**或**原始异常非无，就调用满额HP恢复与异常治疗，再清标记；新月舞还把任一招式PP未满列为触发条件，触发则另补全PP。条件是“任一需要”，不是分别对三种写入重新查询；不要把HP资格拒绝自动推广为有异常／缺PP时绝不进行其它恢复。HP／异常／PP均经指定写入，可能改变持久个体。

无任何收益条件时，世代<8清掉标记；当前世代8保留给以后的具名位置通知。新月舞可仅为PP缺口消费，治愈之愿不因仅缺PP消费。来源自我失能不清已设位置标记。

### 9.3 延迟攻击

创建时计数3；到0时：位置无人／濒死→停止；寻找同侧且保存队伍下标对应的当前场上来源，若它恰成目标本身→停止；若来源不在场，且该队伍成员仍可战斗，则从其**当时**个体建立临时计算参与者，未复制普通完整在场特性／道具／招式状态（WP39）；无合格来源→停止。

可执行时采用所存招式、当前目标位置，以延迟攻击标记走特殊调用；保护来源先前失败记录，调用后恢复该记录，再目标濒死检查，最后清计数、招式和来源三辅助值。**早退并不执行末尾全字段清理**：计数已为0、旧辅助元数据可保留，但不再自动重试。新设置允许覆盖计数0的旧辅助记录。不是放置时把最终伤害封存；计算输入与特例仍按WP43、特殊调用按WP40。

### 9.4 位置交换

普通Shift与共同交换操作只交换占位成员、选择及WP41具名成员指向，不交换位置容器。因此祈愿／未来攻击／治愈之愿继续属于原席位；Shift本身不调用位置恢复、入场危害或完整入场特性。**交换场地（Ally Switch）招式**在同一业主且恰一名邻近盟友的资格下交换后，额外对两个位置调用位置恢复通知；仍不等于重新入场，不跑入场危害。这是不同调用者行为，不能仅凭都叫换位而合并。
