- **USE（新建项）**：名称（空且无缺省 → 放弃）→ **ID 派生**（§2）→ 性别三选 → 基础金钱 0–255（默认 30）→ 注册＋保存＋PBS写出＋创建消息＋**图形缺失提示**（训练家图缺失则空白）。 固定默认登记链且无插件适配时，输入名称用于 ID 派生和成功提示，成功登记的原始类型名为 `Unnamed`；性别和基础金钱依输入保留。随后保存类型档案，再以登记原始名刷新类型名默认语料并反写类型/训练家 PBS；文件各步成功时输出 Name 亦为 `Unnamed`，成功重编译不会恢复原输入。列表刷新读登记原始名，游戏显示再按消息表本地化，不能由原文字段保证所有语言都显示英文。已有类型通过字段契约编辑 Name 并 Yes 可保存明确给定名称；No 不提交。

- **新建（A-R03 修订）**：名称 → ID 派生（`ITEM_` 前缀系）→ **口袋选择**（口袋选择，返回 0＝放弃）→ **价格**（0–999,999——**BACK 返回 0 而非 −1**（默认值经钳制、无独立取消值）——**按 BACK 仍继续后续创建（价格 0）**；正常输入 0 同为价格 0——**口袋取消与价格 BACK 是两个不同的分支**）→ 描述（通用文本）→ 注册＋保存＋道具PBS写出＋创建与图形提示消息。 固定默认登记链且无插件适配时，成功登记的原始 Name/NamePlural 均为 `Unnamed`、Description 为 `???`；输入名仍用于 ID 与创建成功提示，口袋/价格依输入保留。保存档案与反写成功时保持这些默认文本，不能把局部输入名加s当成已保存复数。列表读登记原始名，最终显示按消息表本地化；正常重编译输出亦不恢复局部输入。无默认名的空名称或 ID 全冲突在登记前放弃；有默认名的空输入回落默认名。描述 ESC 返回旧空文本而继续创建。保存/反写失败保留已到达步骤的登记和文件前缀，不保证成功消息或整次回滚。

- **USE（已有项，A-R02 修订）**：队伍属性设置——属性表：类型（训练家类型选择）、名字（通用文本）、**版本（0–9,999）**、败北台词、**最大队伍数个宝可梦槽**（训练家个体子编辑）、**8 个道具槽**（道具选择）；**校验可达性**：**清空类型后属性返回空结果、外层立即结束该次编辑**（**不到「未选类型」消息**）；**名字空与队伍空才回校验循环**（分别「Can't 保存. No name was entered.」／「…Pokémon list is empty.」）；通过 → 形成登记记录（队伍只收有物种的槽、道具只收非空槽、保留 `PBS文件后缀`）→ 注册；**改键冲突**：**改成已存在的（类型,名字,版本）键时先 注册 覆盖目标、再删旧键——无唯一性拒绝**（对照：A 改为已有 B 的键——内存只剩新 B、旧 A 删除；外层退出 No 仍可由 `.dat` 重载恢复）；**不得借新建 ID 去重逻辑推断编辑改键也去重**；置 已修改标记。 对合法已有记录，即使未改变败北台词，父属性 Yes 且通过校验后，重新登记时原始败词即为 `...`；显式输入新败词也同样回落，尚未到档案保存。父属性 No 不发生这次登记，Cancel 回属性页；外层退出 Yes 才保存训练家档案并反写，直接外层 No 从旧训练家档案恢复原败词。三层精确对照见下表；类型/名字/版本未改时身份仍为原键，具体台词显示由消息查找消费。

- **USE（已有项）**：编辑属性定义 → 属性列表（保存提示）→ **确认保存**：字段契约 形成登记记录＋保留 suffix → **注册＋保存＋道具反写**（即时生效，无退出确认）。 打开时先读取各字段的 PBS 投影，仅未指定值且控件有默认时回填工作值；Yes 无“实际改过”门，重新登记所有字段。明确给 Name/NamePlural/Description 后 Yes 能保存这些指定文本，No 不提交；这不保证其它字段原样（见 §4.3a）。

### 4.2a 已有训练家败词的三层结果

以下独立会话采用合法 CAMPER/Liam，原登记和训练家档案的败词同为非默认 L0，类型/名字/版本及队伍有效、无插件改写。所有文件结果以相应保存/反写/重载成功为条件。

| 操作 | 训练家登记 | 训练家档案 | 训练家 PBS／类型产物 |
| --- | --- | --- | --- |
| 未改败词，父属性 No | 保持L0 | 保持L0 | 本操作未写；不撤销此前操作。 |
| 未改败词（或显式输入L1），父属性 Yes | 立即变为 `...` | 此时仍L0 | 此时未写。 |
| 父 Yes 后直接外层 Yes | `...` | 保存 `...` | 写出 `...`。 |
| 父 Yes 后直接外层 No，无中途写出 | 重载后L0 | 保持L0 | 保持原文件。 |
| 父 Yes→新建训练家流程完成新类型→名字取消→外层 No | Trainer重载后L0；新类型原始名 `Unnamed` 保留 | Trainer仍L0；嵌套只保存类型档案 | 嵌套转换已将 `...` 写入 trainers PBS，并写类型 PBS；外层No不重写或恢复这两份PBS。 |

父 Cancel 回属性编辑；清类型/空名字/空队伍按 §4.2 既有守卫，未到成功登记不能声称败词已变。登记、档案保存、PBS写出任一后段失败只限制后续结果，不回滚已完成前缀；嵌套新类型保存不等于保存 Trainer 档案。已有类型/道具的字段契约编辑正例只保证明确给定文本，物种进化与其它投影另依各自规则。

### 4.3a 道具未改字段确认的投影结果

合法道具 BP价1 在 PBS 投影中被省略为未指定值，普通有界数值控件将它回填成工作值0；两项原始份量名称未指定时各回填名称控件的 `???`。只打开属性页不会改登记或文件，然而不进入任何单字段、不作改动，BACK 后 Yes 仍重新登记这些工作值。以正常编译/装载的默认 REPEL（普通原名 Repel/Repels、价格400）为例：

| 阶段 | BP价／两项份量原文 | 普通名称/复数/描述与文件 |
| --- | --- | --- |
| 未打开 | 登记1／两项未指定 | 原字段及档案/PBS保持。 |
| 打开、工作页 | 工作值0／`???`,`???` | 登记仍1/未指定，文件未写。 |
| BACK→Yes，登记成功 | 登记0／显式 `???`,`???` | 普通名称/复数/描述保留其原投影；档案尚须保存。 |
| 档案保存成功 | 同登记 | 档案记录新值；此步不保证后续PBS成功。 |
| PBS反写成功 | BPPrice=0；两份量字段显式 `???` | 输出新值，之后读取/重编译不会回到未指定份量。 |

No 不登记、不保存；Cancel 回到工作页，若随后 No 仍不提交。BP2 原样确认保持2；显式把工作值设1，登记1而PBS省略 BPPrice。已有非空份量原文保留；显式空串也被保留，不等于未指定、不回填 `???`。未指定份量的运行显示回退普通名称/复数；显式 `???` 或空串则走各自原文的本地化读取，不保证所有语言显示同一字面。默认 SellPrice 的可空属性工作值仍为空，再登记恢复购买价整数半价，不能将所有可空数值都类推为0。

若后续BP商店实际提供该道具且没有正数买价覆盖，消费登记的新BP价0，零价兑换规则引用 [WP29 §5](../creature-rpg/wp29-shops-and-exchanges.md)。不据此推断默认商店已出售REPEL或已发生免费交易；PBS默认BP价仍1。档案成功后PBS失败可留下已登记/已保存的新值，不补事务回滚；宿主UI、经济和文件操作未运行验证。
