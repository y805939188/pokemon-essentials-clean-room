**通用合同**：编辑以目标个体、所在位置、手持状态和构造测试情境为输入；写入后调用界面单项刷新或显示消息；效果返回假（菜单继续），**Duplicate/Delete 返回真（整单关闭）**。**取消约定**：数值输入的取消值多为当前值（不写）或专门值；选择列表取消 → 无写入。**构造测试模式排除** `受限可见标记` 显式假四项：Set egg、Mystery Gift、Duplicate、Delete。**处理器后置显式图鉴登记门**：性别/物种/形态/闪光/蛋转个体在**非构造测试且非蛋**时调用处理器自身的显式登记；这不是被调用操作整条链的门。形态普通提交另按 [WP21 §4.1](../pokemon-rules/wp21-dynamic-forms-and-display.md)／[WP62 §3](../pokemon-rules/wp62-pokedex-records-regions-and-content.md) 条件登记全局玩家图鉴，不受准备标志或蛋状态抑制，详见 §6.4。

- **Species/form**：**设物种**（物种列表默认当前；不同才写＋重算＋图鉴登记门）；**设形态**（同物种形态列表——仅一个形态：提示并在当前形态非 0 时给「重置为 0？」确认；多形态：选择——**该物种自决形态时给「覆盖？」确认**（确认才写强制形态标记）；普通形态提交＋处理器后置显式图鉴登记门）；**移除形态覆盖**（清强制形态标记）。WP21 形态合同引用。 玩家/图鉴存在且处理器、重算及刷新依赖正常时，成功普通提交登记见过、按图鉴形态归一的见过形态，并只在末次记录尚空时初始化；不由此置拥有或见过蛋，也不自动写存档。准备真/假、蛋/非蛋都可沿这条底层链登记；原后置门只决定是否额外显式登记。SHELLOS0→1、目标1未见且无强制/动态/插件干扰时可隔离验证本次写入，创建已造成的记录不计作本次效果。该夹具 BACK/选同形态不执行目标提交；不推所有菜单读取无副作用，动态读取另依 WP21，显示读取亦复用该规则。单形态重置0的提交需已有非0状态，不作为默认正常样本。处理器/重算先失败可不到登记；登记写见过/形态后刷新失败不撤回前序写入。

- **性格/性别/形态/物种（两种情境）**：性格——设/重置【原】＋【战】战斗刷新后续处理；性别——同 §6.4（不可变提示；此性别处理器不显式登记图鉴）；形态（R08 修订）——形态列表；**选单 BACK 或选相同形态：无变化**；**选不同形态后先清原强制形态标记（确认前副作用），再询问自决形态覆盖**——**拒绝覆盖：不写所选形态，但旧强制标记已被清空**；**接受覆盖：写强制标记＋所选形态**【原】＋【战】form 同步（写入器写穿到普通形态提交；无在场对象时仅简化提交，无这次普通登记；有在场对象时在简化提交之后仍调用普通提交，全局玩家/图鉴存在且依赖正常便登记见过/见过形态及首写末次，不置拥有/见过蛋，不因战斗方归属或内部战斗包装门更换接收者；见 WP21 §4.1、WP62 §3）——与非战斗入口顺序不同（非战斗不预清，§6.4）；物种——【原】＋【战】物种＋战斗刷新后续处理（包含物种变化的刷新）＋**战斗显示名同步**。
