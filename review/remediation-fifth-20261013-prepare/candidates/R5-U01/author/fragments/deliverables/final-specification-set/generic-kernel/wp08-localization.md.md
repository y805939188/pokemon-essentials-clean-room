- **哈希域**：按文本规范键存储。对逆转义后的键，先去掉从每行开始处起始的连续空白段，再去掉在每行结束处结束的连续空白段；这些空白段可跨相邻空行。最后将剩余长度至少2的连续空白段折叠为一个ASCII空格。单个内部LF可以保留，不能等价改写为整串trim后把所有空白压成空格，亦不能只split/trim每行再统一join。原文值/译文值不按此键算法转换。同一有效当前语言哈希分别有A+LF+B→T和A空格B→U，无占位参数、无覆写、观察窗口处理之前：查询A+LF+LF+B或A+单LF+B均取T；A+两个ASCII空格+B取U。已有译文值含双LF时，查找原样交出双LF，不因键规范化而折叠。导入行修剪在逆转义之前、键处理在之后；碰撞后值覆盖与后续窗口换行各按自己的合同，不据这些有限输入穷尽Unicode/CRLF组合。

- 普通脚本先扫描已加载脚本归档的全部节；归档恰一节才额外扫描Data/Scripts递归列举返回的所有文件，不承诺只扫.rb，也不因目录存在就无条件扫描。插件归档存在且可读时随后扫描其中脚本，再处理公共事件和有效地图事件。普通脚本识别旧输入标记_INTL/_ISPRINTF后、左括号后的双引号首字符串片段；事件脚本识别_I的对应双引号片段。单引号不由该识别器收集，注释里的匹配文本仍可成为候选，不证明运行可达。这些名称是参考作者输入词汇，不要求未来提供同名API。
- 普通脚本片段按回车、换行、控制字符1、转义引号、双反斜线的次序解码；事件脚本只解码转义引号与双反斜线，字面反斜线n不按普通脚本路径变LF。显示文本续行在非空旧文本后以一个空格接合。非续行命令触发提交时，非句点/感叹号/问号字符后的连续空白另作规整；列表确以显示文本结束时的末尾提交不做该步。普通A双ASCII空格B在前路成为A单空格B，末路保留双空格；后续规范键可相同但登记原文值不同，不将此有限例扩为所有句读组合。#### 6.1.1 默认哈希材料的替换与追加

候选在保存默认消息前，以**默认core同域规范键集合**过滤：core存在该键即跳过，不比较原文值，也不借用当前语言材料。替换式收集重建目标game域；追加式保留旧game域再写合格新候选。跳过不是删除：旧game同键及未再收集的独有键仍可保留。地图m仅对默认core的同m桶过滤，不借用运行查找的共享桶0。缺值候选跳过；哈希空串候选可形成键，但导出跳空原文值。

| 默认输入（彼此独立） | 更新后默认game |
| --- | --- |
| core仅键A；旧game键Z；替换收集A/B | 只有B |
| 同输入但追加 | 保留Z，加入B |
| core键A；旧game有A→Old和Z；追加A/B | A→Old、Z仍在，加入B |
| 同输入但替换 | 只有B |
| core仅桶0有A、桶4无A，收集地图4的A | game[4]可加入A |

普通招式名称/描述终检是替换调用者；形态文本与普通脚本文本收集是追加调用者；公共事件桶0及非空地图桶是替换调用者。新K只有在来源门成立、不被core排除且无规范键碰撞时才成为相应默认域最终值。数组低层收集并不由这些哈希调用证明，不扩大成全部数组作者入口。超时部分收集、随后保存及其它异常前缀保持。

- 导出编码有条件：原文/译文含真实CR、LF、TAB、U+0001，或某行起始字符为左/右方括号时才进入编码；进入后将全部CR/LF/TAB/U+0001及全部左右方括号分别写为<<r>>/<<n>>/<<t>>/<<1>>/<<[>>/<<]>>。仅一个ASCII空格后接[Q]且无控制字符不触发括号保护。导入先分节再按既定转义表逆转义，不能在分节前先解码。输出条目由所选默认core/game中的非空原文条目决定，译文取作者选定目标语言材料；目标语言独有X而默认域无X时不会新增X输出。外层检查范围可包含语言材料更长的域号，不等于根本不遍历语言独有域，也不保证损坏/缺失地图域安全跳过。此条不改变游戏当前语言或先删后写、稀疏桶条件。

合格非地图SCRIPT_TEXTS单条非空非数字键K，导出/读取正常且无先行错误：译文[Q]被编码，单文件导入恢复[Q]；译文一个ASCII空格+[Q]且无控制字符不编码，分节读取在修剪/逆转义前把它识别为新节头，交付旧节时只剩K一行，**先因旧哈希节奇数拒绝**，尚未求新Q节是否合法。同负例另含真实TAB时编码门成立，括号一并保护，不再发生同一节头反例，但不承诺ASCII首空格无损。经完整编译且旧输出存在、覆盖打开成功时，拒绝前旧输出已截断，关闭不恢复；单文件解析不打开输出，二者副作用分列。
