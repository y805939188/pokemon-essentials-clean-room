## 1. 目的、范围与非目标

**目的**：定义"玩家主动使用道具"的完整边界——四类使用上下文（背包、野外、个体、战斗）的入口、资格、数量/目标选择、确认、效果、返回、关闭与消耗时机；处理器注册表的机制与覆盖目录；治疗/复活/PP、EV 与培养、经验糖果、机器/教学、进化道具与主要特殊道具族的资格与失败语义；供买卖（WP29）、树果（WP60）、捕获（WP38）、持有效果（WP50）、界面（WP66/WP67-A）引用。

**范围**（WP28 自身声明范围，extraction-plan 第 2.1 节 (a) 类）：

1. WP28-A：使用上下文分流——背包/野外/个体/战斗四类入口的可见性、资格、数量、确认、效果、返回、关闭与消耗时机。
2. WP28-B：处理器注册表——注册家族、条件注册、复制（别名）、查找顺序、无处理器/未知目标的分支归属。
3. WP28-C：主要效果族——治疗/复活/PP、EV 与培养（维生素/羽毛/降 EV 树果）、经验糖果、机器/教学、进化道具（引用 WP31）、主要特殊道具（形态/战斗用）的资格、效果、失败与消耗。
4. WP28-D：交界登记——球库存与消耗（捕获判定引用 WP38/WP40）、持有效果（WP50）、学习主规则（WP30）、形态（WP21）、容器（WP27）。
5. F08-03、F08-04 中属于 WP28 部分的状态更新。

**非目标**：

- 不定义捕获计算与战斗投球合法性的完整规则（WP38/WP40；本包只登记球的入口与消耗链）。
- 不定义被动持有效果与触发规则（WP50）；不定义战斗内时序/等待（WP42）与战斗界面完整交互（WP67-A）。
- 不定义学习/替换/遗忘/PP 增长的**主规则**（WP30 §6、WP20 §5.4；本包定义使用资格与消耗，效果引用）。
- 不定义进化条件与提交（WP31；本包定义道具入口的资格/消耗交界）。
- 不定义形态组合的完整规则（WP21）、树果种植（WP60）、邮件流程（WP64）、树果/覆盖物的收获消费（WP60）。
- 不运行游戏或参考脚本；不设计未来框架的道具效果 API。

## 2. 概念与术语

- **处理器（handler）**：按物品标识或"条件类别"注册的效果过程；同一物品可分别注册于多个使用家族。
- **处理器注册表（10 个家族）**：使用文本、背包使用、野外确认、野外直用、个体使用、个体使用上限、战斗可否使用、战斗直用、战斗对个体、战斗对场上个体（§3）。
- **条件注册（addIf）**：以"类别名 + 条件过程"注册，对任何满足条件的物品生效（样本：进化石、球、机器）；查找时在直注册未命中后按注册顺序求值。
- **复制（别名）**：把某一物品已解析的处理器复制到其它物品标识（样本：POTION→BERRYJUICE；AWAKENING→CHESTOBERRY）。
- **使用上下文**：背包（含队伍选择）、野外（大地图/快捷菜单）、个体（队伍界面）、战斗。
- **资格**：界面是否提供入口（家族存在性）+ 使用时的可生效判定（处理器返回）。
- **消耗时机**：入口层在处理器返回真后按物品消耗属性扣减（非战斗）；战斗在**登记使用时**即扣减、无效果时退回。
- **未命中分支**：无对应家族处理器（入口不显示/默认放行）与物品数据缺失（数据层失败）分开归属。

## 3. WP28-A：使用上下文分流

### 3.1 处理器注册表机制（静态核对）

| 家族 | 用途 | 查找顺序与触发 |
| --- | --- | --- |
| 使用文本 | 背包"使用"命令的自定义标签 | 直注册 -> 条件注册 |
| 背包使用 | 背包内直接使用（含机器教学）返回 0/1/2 | 直注册 -> 条件注册 |
| 野外确认 | 快捷菜单野外使用前的确认（默认真） | 无处理器视为真 |
| 野外直用 | 大地图直接使用返回真/假 | 无处理器返回"未找到"（−1） |
| 个体使用 | 对个体使用（数量, 个体, 界面）返回真/假 | 无处理器返回假 |
| 个体使用上限 | 数量选择上限（默认 1；受"一次多量"配置门控） | 取 max(结果, 1) |
| 战斗可否使用 | 战斗内资格（默认真） | 无处理器视为真 |
| 战斗直用 | 对场上/无目标使用（球、娃娃、护身） | — |
| 战斗对个体 | 对队伍成员（或招式）使用 | 无处理器返回假 |
| 战斗对场上个体 | 对场上个体使用（X 道具、笛） | 无处理器返回假 |

- 查找规则：直注册优先；未命中时按**注册顺序**对条件注册求值，首个条件为真者生效；类别名本身不参与物品匹配。
- 复制在复制时的已解析结果（含条件注册结果）到目标标识；此后两者独立。
- **无处理器归属**：背包"使用"命令仅在 背包使用/野外直用/个体使用 三者至少一个存在（或机器且有队伍）时显示（引用 WP27 §4.3）；快捷菜单登记仅要求野外直用存在（WP27 §5）；战斗内"可否使用"无处理器默认放行。
- **未知目标归属**：物品数据标识未知时由内容层处理（WP03 引用）；处理器集合中不存在的标识即未注册，无隐式兜底。

### 3.2 背包上下文

1. 命令可见性见 §3.1；"使用"文本可来自使用文本家族（样本：自行车显示"骑"/"下车"）。
2. 使用分派（按物品数据"野外使用"字段）：
   - **对个体（OnPokemon）**：队伍+盒内无可用个体（非蛋）时提示"没有宝可梦"；否则打开队伍选择（进化石先为每个成员标注"可/不可"，由 WP31 §6 的检查计算）；选择后：空个体/蛋/超级模式下的非香类 -> 跳过该次选择；数量选择（当"一次多量"开且上限家族给出 >1）；执行个体使用家族；**返回真且物品为消耗品 -> 扣减 qty 个**；背包耗尽 -> 提示"用完了最后一个"；否则提示"没有任何效果"并留在循环。
   - **野外直用/机器（Direct 或机器）**：走"背包使用"家族；机器无招或无个体 -> 提示；返回 1 -> 按消耗属性扣减 1；返回 2 -> 关闭背包（野外使用）；返回 0 -> 无事发生。
3. 返回值：0=未使用、1=已使用、2=关闭背包到野外再使用（界面据此退出，引用 WP27 §4.3）。

### 3.3 野外上下文

- 入口：快捷菜单（仅已登记且有野外直用处理器的物品，WP27 §5）与暂停菜单的登记物品使用。
- 顺序：野外确认（默认真）-> 野外直用 -> 返回真才扣减 1（消耗品）；返回假或未找到（−1）-> 提示"这里不能使用"且不消耗。
- 主要野外效果（样本）：驱虫喷雾（步数 100/200/250 + 步数计数减少；耗尽时提示并可直接选用同族另一件）、黑笛/白笛（遭遇等级或遭遇率方向，受配置）、甜蜜（群体遭遇）、离洞绳（回逃脱点；有同行者不可用；传送前取消载具；用后清除逃脱点）、圣灰（全队复活：无个体/无濒死 -> 失败；`pbFadeOutIn` 内逐个治疗；成功才消耗）、自行车（上下车资格）、钓竿/探测仪/地图/硬币盒（打开对应功能）、经验共享开关（背包内替换为"关"版本物品）。
- 登记用途限于野外快捷使用；登记/取消与图标归 WP27。

### 3.4 个体上下文（队伍界面）

- 队伍界面"使用"入口：先选物品——列表过滤为"可对个体使用"（个体使用家族存在或机器），排除超级模式非香类；机器再过滤（已掌握或不可兼容者不可选）；选择个体后执行个体使用家族（`数量`、界面对象）。
- 机器路径：确认"要教 X 吗？"-> 通用版学习入口（引用 WP30 §6.2；配方含机器标记）-> 学会才扣减（消耗品）。
- 一般路径：数量选择（同 §3.2 规则）-> 执行 -> **返回真且消耗品 -> 扣减 qty**；返回假 -> 提示不消耗。
- 训练/教学计数：**背包侧机器流程**（教学选择包装）在学会时计"机器教学"、非机器时计"导师教学"（WP06 目录）；**队伍侧机器使用路径**（直接学习入口）未定位同类计数——差异按真实调用链登记，不放大为统一契约。

### 3.5 战斗上下文

1. 战斗物品清单按物品数据的"战斗使用"字段分流：对个体/对招式（1/2）、对场上个体（3）、球（4）、无目标（5）；界面层校验对应家族存在、以及统一前置（空个体/蛋、封招状态、超级模式非香类）。
2. 资格：可否使用家族（默认真）在**登记前**求值；不通过 -> 停留在菜单。
3. **登记即扣减**：登记选择时即从背包扣减（消耗品）；无法扣减内部报错（静态断言）。
4. 执行（攻击阶段按已登记的选择分派）：对个体/对招式 -> 战斗对个体；对场上 -> 战斗对场上个体；球 -> 战斗直用（投球，引用 WP38）；无目标 -> 战斗直用；成功即清空该选择（已扣减不可回）；**失败 -> 提示"但没有效果！"/"不能在这里使用"并退回已扣减的物品**（背包无法容纳时内部报错，静态断言）。
5. 球：无目标/对敌；使用耗掉本回合全部行动（登记前后均强制"先制行动"）；战斗投球的其他合法性检查（战斗禁用球、场上有多个对方、场上个体半无敌、背包与盒子全满、抢夺球条件）登记于本包目录，**完整规则引用 WP38/WP40**。
6. 战斗使用不涉及数量选择（每次 1 个）。

## 5. WP28-C：主要效果族的资格/效果/失败/消耗

### 5.1 治疗与复活

| 族 | 资格（失败 -> "没有任何效果"，不消耗） | 效果 |
| --- | --- | --- |
| HP 回复 | 不可行动（含濒死）或 HP 已满 | 回复定值并封顶；消息含实际回复量；战斗版对场上个体走战斗恢复、对队伍个体同规则 |
| 状态治疗 | 濒死或状态不符（对症）或全治时无状态 | 清除状态；逐状态消息（样本："醒来了"/"中毒痊愈"） |
| FULLRESTORE | 濒死，或 HP 满且无状态 | HP 补满 + 清除状态；按实际分支取消息 |
| 复活 | 未濒死 | HP 恢复为**最大 HP 的一半**（向下取整，至少 1）并清除状态；MAX 版回满；药草版额外触发友好度下降 |
| 圣灰（野外） | 无个体或无濒死 | 逐个治愈全队濒死者；至少一人被治愈才消耗 |

### 5.2 PP 与 PP 成长

- ETHER 系：需先选择招式；目标招式总 PP>0 且当前 PP 未满，否则失败；回复 10/回满；ELIXIR 系对全部招式生效（总量增量为 0 才失败）。
- PPUP/PPMAX：需选择招式；招式总 PP ≤1 或提升计数已 3 -> 失败；成功提升计数 +1/直接到 3（实际 PP 按 WP20 §5.4 的派生规则体现）。
- 战斗版对队伍个体的 PP 回复需带上场个体同步（在场且未变身且招式一致时写穿，引用 WP20）。

### 5.3 EV 与培养（数值域与上限引用 WP19）

- **维生素（六种）**：每次 +10；**100 点阈值仅在世代 ≤7 生效**（世代 ≥8 配置关闭该阈值）；始终受单项 252/总量 510 钳制。数量上限=可增点数按 10 折算（含 100 点阈值与总量约束）；逐次应用，**每次实际增加触发一次"维生素"友好变化**。
- **羽毛（六种及其别名）**：每次 +1；**无 100 点阈值**；仍受 252/510 限制；每次实际增加触发"羽毛"友好变化（WP30 §7.2 引用）。
- **降 EV 树果（六种）**：每次 −10（钳 0）并按"树果"方法提升友好（每单位一次）；无友好提升空间且 EV 已 0 -> 失败；数量上限按友好提升模拟计算。
- **部分成功语义**：数量循环中**第一次**即失败 -> 整体失败（不消耗）；先成功后触限 -> 已应用部分保留、整体返回真（**按份消耗**，不补回滚）。每次应用即时重算能力。
- 薄荷：当前用于能力的性格与目标相同 -> 失败；确认（"可能影响能力"）取消 -> 失败；成功仅改"用于能力的性格"并重算（表现性格不变，WP19 引用）。
- 能力胶囊/药膏：确认取消 -> 失败；无第二/隐藏特性、已是隐藏特性或特例物种 -> 失败；成功切换特性序号（胶囊在普通特性间切换、药膏改为隐藏特性）。
- 经验糖果：`pbGainExpFromExpCandy`（引用 WP30 §5.3）：已满级或 Shadow -> "没有任何效果"（不消耗）；数量 >1 时先补"维生素"友好变化；单次经验设置流含越级学招/进化检查。上限=按单位经验折算到满级所需次数。

### 5.4 机器与教学

- TM/HM **不可消耗**（重要物品，不入背包消耗路径）；TR 为消耗品（默认按非重要物品消耗）；数据字段界定三者（§9）。
- 教学流：选择个体（队伍界面过滤：蛋/超级模式非香类不合格；机器还要求未掌握且兼容）-> 确认 -> 通用版学习（空槽直接学；满槽询问遗忘/放弃；机器且"保留旧 PP"配置时新招当前 PP 取旧招当前 PP 与总 PP 的较小值）-> **学会才扣减**并计"机器教学"统计；放弃/不可教 -> 失败不消耗。
- 背包侧机器使用（野外直用/背包使用）：无可用个体（非蛋队伍为空）-> 提示；确认"要教给宝可梦吗"-> 队伍教学选择（每个成员标注 可学/已学/不可）；某一成员学会即结束并计统计；取消 -> 返回 0 不消耗。
- 进化石：条件注册；Shadow 先拒；命中 -> 不可取消的进化提交（WP31 §6）；未命中 -> "没有任何效果"；消耗在提交后由入口层执行。

### 5.5 战斗用与特殊道具（样本）

- X 攻击系：目标已到能力阶级上限或无场上个体 -> 失败；成功提升 2 阶（配置为真）或 1 阶，并触发"战斗道具"友好变化；各档位独立注册（同族 4 档）。
- DIREHIT 系：集中于要害的计数已达标 -> 失败；MAXMUSHROOMS：六项能力均可提升才可用（逐项判定，任一可升即可）。
- 娃娃系（无目标）：野生战逃跑成功；训练家战/不可逃跑 -> 资格失败不消耗（登记前拦截）。
- 护身（无目标）：己方已处于神秘守护 -> 失败；成功设 5 回合并触发"战斗道具"友好变化。
- 笛：眠状态相关（红笛解着迷、黄笛解混乱、宝可梦之笛唤醒全场；音障特性免疫；无适用对象 -> 失败）。
- 球：资格见 §3.5；投球动作与捕获计算归 WP38/WP40。
- 形态/特殊道具（样本 GRACIDEA：物种/形态/夜/冰冻/濒死前提，成功改形态并消息）：逐项前提与形态组合细则在 WP21 完成时核对（本包登记使用入口与失败形状）。

## 6. 规则与不变量

1. **入口层消耗**：非战斗使用"处理器返回真 -> 按物品消耗属性扣减"；战斗使用"登记即扣减、失败退回"。消耗属性=非重要物品且（数据未标注时默认消耗；重要物品永不消耗）。
2. **失败不消耗**（非战斗）：资格失败/未命中/取消均不扣减；战斗失败退回；**部分成功按份消耗**（§5.3）。
3. 数量：仅"一次多量"配置开且该物品注册了上限家族时提供数量选择；否则固定 1。战斗无数量。
4. 资格与效果分离：可否使用家族（界面/战斗前置）与使用家族（实际效果）可分别注册；同一物品在不同上下文可有不同家族组合。
5. 无处理器分支：入口可见性见 §3.1；结算不隐式兜底（未注册即不可用或返回未找到）。
6. 培养语义分工：**100 点阈值只属于维生素**（且按世代）；羽毛与（战斗中）EV 获得不受其限制；**252/510 是所有 EV 写入的统一上限**（WP19 域引用）。
7. 前置分层：蛋（多数个体使用在入口或处理器拒绝；机器在入口过滤）、Shadow（进化石/糖果专用拒绝；通用学习拒绝，WP30 §6.2）、超级模式（非香类个体使用被拒）。
8. 使用不改变"物品种类"的字段（金额/数量除外）；形态类道具改形态（WP21），特性道具改特性序号，薄荷改"用于能力的性格"（WP19）。
9. 统计：机器/导师教学、驱虫喷雾计数、进化相关统计分属 WP06/两包引用。
10. 战斗物品不触发"给予持有物"路径；被动持有效果与触发规则归 WP50。

## 7. 边界与失败

- 空队伍/无可用个体：个体使用与机器入口提示；圣灰提示"没有宝可梦"。
- 蛋与超级模式：入口过滤（个体使用家族多数不处理）；香类在超级模式例外。
- 满 HP/满 PP/无状态/未濒死：对应族提示"没有任何效果"，不消耗。
- 数量边界：上限为 0（如满级糖果折算 0）时不提供选择、按 1 执行并在处理器失败；"一次多量"关 -> 永远 1。
- 部分成功：维生素/羽毛/树果的数量中间触限 -> 已应用保留、按实际应用份消耗、返回真（静态；不补回滚）。
- 战斗登记后无效果：退回物品；背包满导致无法退回 -> 内部报错（静态断言；正常路径不可达）。
- 球的使用耗掉回合全部行动；训练家战与多对手场景的资格拒绝见 §3.5（完整规则引用 WP38/WP40）。
- 进化石在不可进化时"没有任何效果"且不消耗；可进化时演出不可取消（WP31）。
- 机器：已掌握/不可兼容/蛋/Shadow 在教学各阶段有拦截；TR 消耗、TM/HM 不消耗。
- 次数耗尽/背包无该物品：结算分支不再扣减并结束循环（背包上下文）。
- 未知物品标识：内容层处理（WP03 引用）；未注册处理器=不可用（§6.5）。
