## 1. 目的与边界（A）

本包描述两种设施战斗变体相对普通战斗的行为差异：**Palace**（按性格与当前是否压半自动决定“攻击／防御／辅助”类别并自动选招，AI换人另有专门逻辑）与**Arena**（禁用主动换人、按顺序补位，第3回合起由裁判按“心、技、体”评判并在其后继续）。两种模式由设施会话进入（WP55登记战斗类型），其规则／布局由WP54的规则组合提供；本包只写变体自身的行为，不重复WP40–52的通用战斗、状态、AI与终局规则。

输入：当前战斗者的性格、HP与状态、招式槽与数据标记、选择记录、回合计数与场上轮数、双方队伍顺序。输出：自动登记的行动选择（招式或“无力”）、压半行为切换与提示、Arena的评判结果与不可逆的倒下提交、顺序补位、裁判消息与评判界面，以及统计与胜负决定（沿用WP42）。

与普通战斗的差异一律以“普通战斗／指定变体”成对表示；两变体在设施中实际以“可记录战斗”的子类运行（记录／回放主合同留WP58），本包对其行为差异的描述对两者一致。

## 2. Palace（B）

### 2.1 行动类别

每招映射到三个类别之一，优先级如下：

1. 目标为“使用者自身”的招，或功能为“忍耐蓄力后双倍返还”的招 → **防御**（注意：自身目标的变化招也先落入防御，不会因是变化招再改成辅助）。
2. 其它变化招，或功能为“物理反击”“特殊反击”的招 → **辅助**。
3. 其余（普通伤害招） → **攻击**。

### 2.2 性格概率表（默认数据）

### 2.3 压半状态

每回合末、且在战斗未结束时，对每个未倒下、尚未压半、且**当前不是睡眠**的战斗者：当当前HP**不高于整数半血（总HP整除2，含等于）**即置压半为真并播提示。同一在场期间已置真则不重复检查（期间回血也不清）；但**换入时初始化会把压半清为假（该复位不在接力保留清单内）**——换出再换入后高于半血按基准表，直到再次满足条件；冰、毒等其它状态不影响是否压半。提示按性格分为四组文本：慎重组（QUIET、BASHFUL、NAIVE、QUIRKY、HARDY、DOCILE、SERIOUS）“渴望更多”、低沉组（CAREFUL、RASH、LAX、SASSY、MILD、TIMID）“低吼”、锐利组（GENTLE、ADAMANT、HASTY、LONELY、RELAXED、NAUGHTY）“眼中闪光”、就位组（JOLLY、BOLD、BRAVE、CALM、IMPISH、MODEST）“开始顾盼”。

### 2.4 自动选招

玩家在Fight指令与AI在选招处**共用同一条自动路径**（会取代手动选招菜单与AI逐招评分）：

1. 取本战斗者性格行，按压半与否选表；抽0–99（使用AI随机入口，即平直随机，不随战斗随机种子保证复现）。
2. 依序判定类别：小于该行**攻值A**→攻击；否则小于**2A＋D**（防御边界暂存A+D、比较时再加A）→防御；否则辅助。
3. 在四个招式槽中收集**同时满足部分资格**且类别相同的槽；部分资格＝槽存在且当前PP＞0、非“讲究物锁定不符招”（有效讲究带时残留锁定不同招）、非“怨恨且本招即上次使用招”。**不检查**再演、定身、挑衅、宣告禁止（与常规可行性检查不同，属变体差异）。
4. 无合格槽→按“无力”登记（记录下标−2并以挣扎招式对象承载）；否则在合格槽间等概率抽一槽登记。登记只写“使用招式＋下标＋招式对象＋目标待选（−1）”；**不承诺随后打开常规选靶菜单**（常规选靶只出现在手选招式路径）；目标−1由执行时解析。
5. 登记通过正常入口时也照常记录（设施中为可记录战斗的写入路径，WP58）。
6. **入口差异**：玩家路径先经过常规“能否显示招式菜单”门——**安可正**或无任何常规可选招时先转常规自动选择（再演锁定招／挣扎），不到本抽样；其余情况由本自动选招取代手动菜单（不再打开手动选招菜单与选靶菜单）。AI路径在换人／用物判断后直接进入本自动选招（可在无任何部分合格槽时得到“无力”−2）。两路径抽样与登记规则相同。

### 2.5 Palace的AI换人

该变体下AI换人使用专用逻辑（普通逻辑被替换）：

- 若当前战斗者处于灭亡歌计数1 → 换人。
- 否则若**没有任何可选招**且场上轮数＞5 → 换人。
- 否则按概率：以整数百分比 h＝当前HP×100÷总HP；候选为可换上的队伍成员，取其最高占比m；基础值：h＜50时 m＜h→20，否则40；h＜25时 m＜h→30，否则50（**25以下覆盖50以下的取值**）；再加状态：睡／冻＋20、毒／烧＋10、麻痹＋15；若上一轮刚换过则−60并下限0。抽0–99小于该值才换。
- 概率分支命中且存在最佳候选（m对应成员）→登记该成员并**直接返回真**；该早返**跳过“刚换过”标记的赋值**（标记保持原值）。
- 其余情形落到后段：先把“刚换过”标记**赋值为应换与否**（灭亡歌计数1与“无招且场上轮数＞5”两早分支不经概率计算、直接为真；概率命中但无最佳候选为真；概率未命中为假），应换时再登记**首个可换上成员**并返回真；没有可换成员则返回假。
- 强制换人参数在此分支不被读取；本逻辑对强制与被动的换人判断一致处理。

## 3. Arena（C）

### 3.1 评判用累积量

每侧各持“心、技、体”累积：心分在**命令阶段**对每侧所选“使用招式”累加——**仅**功能为“守住”“挺住”“击掌奇袭”的**三个具名效果**（ProtectUser／UserEnduresFaintingThisTurn／FlinchTargetFailsIfNotUserFirstTurn）−1，其它守护类变化招**不−1**；“双反击类（物反／特反／忍耐返还）”及一切变化招0，其余伤害招＋1；换人／用物不计。技分为**当前结算槽**：每回合攻击阶段开始清0；每次出招按成功状态机**赋值（覆盖）**；**回合末只把当前槽一次加进侧累计**。“体”分在评判时以当前HP相对本次上场时HP的整数百分比计算（分母取“上场HP与1的较大者”）。

**成功状态机**（每个战斗者各一，随战斗者建立；每回合攻击阶段开始**全量清空**，含技值）：

- 出招开始时先置“失败＝假定”（状态1）；
- 招真正完成且成功时置“成功”（状态2），并把本次对所有非“无效”目标的相性倍率和写入类型修正（无目标则不改）；
- 每招结束时对**全场各战斗者**结算其状态：未被保护失败→**赋值**技−2；被保护失败→**不写**（技值保持）；成功→按类型修正**赋值**：克制＋2、一般＋1、微弱−1、无效−2。结算后只清“状态／相性／保护”。技值是**覆盖值**：同一回合多次结算以最后一次为准（＋2后再结算−1→**−1**，不是＋1）。
- 该状态机及其结算在普通战斗同样运行（非Arena专属对象）；Arena的专用性在**评判消费**这一槽值。
- **未到结算入口不补记**：整体失败会提前返回、不经过结算入口；回合末也不为这次补算（该次出招不改变技槽）。

### 3.2 命令与回合流程

- 首次命令阶段（或换人进入后首轮）先播“裁判：{0} 对 {1}，开始！”并复位计数；随后执行常规命令流程；流程结束且战斗未结束时，按本节3.1对“使用招式”累加心分。
- 回合末先执行常规回合末；未结束时把成功状态机的技值累加到侧技分，回合计数＋1；计数**未满3不评判**；满3后：先取消双方所有多回合招（“取消蓄力／连用类”的通用语义，WP40），再计算评判。
- 评判三对比项：每项**不相等时胜方2、败方0**；相等各1（心、技、“体”百分比同规则）。三项合计高者为胜、低者负、相等为平（两胜一负＝4对2；全平＝3对3）。
- 裁判界面按“心→技→体”逐项显示（含双方名、VS、总分与判定图标），并给出每项提示与总结局（含平局）文本。

### 3.3 评判后的提交与补位

- 平：双方**当前HP被直接置0**并按倒下处理（**写穿持久个体**HP；为裁判直接置零，而非普通伤害计算／受击流程；含随后升级结算）。
- 非平：败者当前HP被直接置0并倒下（同上，**写穿持久个体**）。
- 随后按顺序（而非玩家选择）补位：仅当该侧当前战斗者已倒下且其队伍索引＋1未越界，则索引＋1并以该成员的消息与替代流程上场（进入战斗回调复位全场累积与计数）；越界（该侧无后续成员）由裁判检查判出终局。评判与补位都在回合末、且战斗未结束时进行；判定先于补位。
- **主动换人**被禁止：任何一侧换人入口均返回假并给出“不能换下”提示（由队伍界面侧显示）；AI换人亦恒假。**顺序补位**是唯一换人途径。
- 计数复位只由“战斗者进入战斗／被登记为活跃”触发（含开场与每次补位），评判本身不清零；正常路径中每次评判必有至少一方倒下并补位或终局，使计数随补位复位。

## 4. 相对普通战斗的差异清单（D）
