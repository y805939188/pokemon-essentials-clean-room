## 三、WP01 必须修订项

### WP01-R01 — 本地 Git 状态、忽略文件、分支引用及项目工作区的证据范围须分开

位置：`wp01-baseline-and-evidence-scope.md@403e814c` 第 48、73、110 行；提交摘要的“工作区没有任何未提交改动”。

问题：第 48 行把 `git status --porcelain` 为空与“无本地修改、无补丁、无插件叠加”合并。普通 status 不报告 ignored 文件，而本项目的 Plugins 本身就是排除目录；仅凭该命令不能证明 Plugins 不存在或没有外加内容。文档第 73 行另报有目录枚举，应该将该证据独立绑定到“未发现 Plugins 目录”这一有限结论，而非由 Git 干净推出。

同一行“master 与 origin/master 同步”若来自本地引用比较，应写成本地分支与本地远端跟踪引用的关系，而非暗示已经查询实时远端。本轮无需 fetch 或更新基线。第 110 行的三条命令也没有明确包含两个分支引用的比较；补出实际执行记录，或者删除未被该记录支撑的表述。

参考仓库 R 的 Git 状态不能代表父级 pokemon-framework-reference 文档工作区的状态。父级本轮新增、修改文件已列明，不能用 R 的干净状态概括整棵工作区。

建议处理：
1. 分开记录固定 commit、本地 status 的实际输出、Plugins/忽略目录枚举、本地分支引用比较；记录检查时点与实际工作目录。
2. “无补丁”限定为本次固定基线下检查到的文件状态，不延伸成所有历史操作或执行过程从未写入。
3. 若既有枚举足够，只需说明证据；确需补查时仅用只读检查并保存结果，不更新/清理/启动参考工程。
4. 将摘要改成“参考仓库 R 的该次 Git 状态检查未报告改动；项目文档变化如下”。

可采用的表述模板（必须用实际结果填写）：

> 固定 commit 为……。在 R 中于……执行……得到……。独立目录检查未发现 Plugins/，因此本次调查材料未包含该目录下的插件样本；该判断不是由 git status 推出。本地 master 与已保存的 origin/master 引用……；未查询实时远端。父级文档工作区状态单独记录。

验收：每项结论有匹配的检查对象和证据，不再从 status 为空推出 ignored 内容不存在，也不要求证明与远端最新状态同步。

官方命令语义核对来源：
- `https://git-scm.com/docs/git-status`：DESCRIPTION、--ignored、Short Format。
- `https://git-scm.com/book/en/v2/Git-Branching-Remote-Branches`：remote-tracking branches 是本地记录。
