# 本轮 reviewer 实际阅读与方法

独立首审；全文哈希／blob 验证不等于全文语义核对。以下是本轮实际阅读段，不借提取方“全文已读”声明扩大审查范围。所有 reference 路径相对 `reference/pokemon-essentials/Data/Scripts/`，身份在 source-checks.json。

## 新稿与交付

- 三份新规格全文阅读；按 B01–B34、C01–C34、T01–T18 对照领域主规则引用与实际 UI 分支，重点验证可达性、写入、失败／取消、尺寸和完成前置。非运行验收。
- 本批摘要、回填回应、diff-bindings、self-checks、boundary-checks、source-identities、reading-log、new-observations；10 份回填差异及矩阵增量全文。
- 交接 prompt／status-and-inputs／handoff-checks；上一轮有限复审报告与冻结输入。旧自检只作为输入声明，不作为本轮正确性依据。
- WP25 选择／储存／寻址守卫相关段；WP62 搜索／末次形态／可列性／编号相关段；WP27 背包入口／选择／容量／存取相关段；WP28 §3.1–3.3；WP29 §3–§8 与赠品／统计场景；WP17、WP06 本批引用接口及已审身份。未重开旧包全部范围。
- 全局 report 结论与 findings 16 项 ID／标题／影响包对照；本轮新观察无同根因条目。外部报告和 findings 已另冻入 supplemental-inputs.json。没有改动全局审查输出，也未执行它的修订。

## 固定推导与排除误报

- 拼图 2×3 的末格空白／逆序数奇偶和 3×2 的列位置是固定常数手算；没有把参考转成可执行模型，没有生成／模拟棋盘。
- 对 5×1 滑块只用“合法滑动不改变非空白相对顺序”的数学不变量判断，未运行求解器。
- 商店普通球分支中的物品对象比较有共享实例比较合同，不报“对象与标识必不相等”。BP 数量半价显示是已审 WP29 保留行为，不报为新缺陷。
- Summary 的 View Pokédex 确实走完整三页，形态移动确实即时写入；没有把它们错误改成简略页／确认后才提交。
- WP23 回填中矩阵中间态有明确两段绑定；不把正确阶段身份当作过期哈希。

审查只确认报告具名事实与机械条件，不关闭 demo、媒体、宿主、插件、随机分布及最终 WP78–80 的保留范围。
