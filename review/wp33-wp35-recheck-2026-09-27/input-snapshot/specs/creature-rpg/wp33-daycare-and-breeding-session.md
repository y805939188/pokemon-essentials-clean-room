## 1. 目的、范围与非目标

**目的**：定义寄养设施（The Day Care / Nursery 同一实现）的会话行为——两个槽位的寄存/取回、对原个体的引用与治疗、兼容性输入与等级、256 步周期与产蛋概率/已有蛋状态、寄养经验与静默学招、费用报价与事件责任边界、槽位选择与领取蛋的次序；供后代生成（WP34）、孵化（WP35）、事件/调试（WP77/WP73）引用。

**范围**（WP33 自身声明范围，extraction-plan 第 2.1 节 (a) 类）：

1. WP33-A：寄养容器与槽位——2 槽、占用状态、寄存/取回动作、对原个体的处理（引用/治疗/初始等级）、槽位数据与保存/迁移。
2. WP33-B：领域工具与事件接口——静态方法目录、事件命令映射、槽位选择、费用报价与扣钱责任边界（U01）。
3. WP33-C：兼容性——资格输入（蛋组/性别/Shadow/拥有者）、等级判定与修正、等级到产蛋概率的映射。
4. WP33-D：计步与周期——每步计数、256 步周期的蛋生成检定与蛋招共享检定、寄养经验（及静默升级学招）、计数重置时机。
5. WP33-E：取蛋次序——生成、领取、队伍容量、失败点；后代具体遗传归 WP34、孵化归 WP35。
6. F09-05 中属于 WP33 部分的状态更新。

**非目标**：

- 不定义后代具体遗传/生成（WP34）；不定义蛋计数/孵化（WP35）；不定义蛋组数据的字段语义全集（WP03/WP18 引用）与图鉴（WP62）。
- 不定义事件/接待的真实流程与收费实现（材料缺失，U01）；不保证"已扣钱/退费/事务"。
- 不定义完整 UI（寄养界面若为事件侧，材料缺失）与宿主媒体。
- 不运行游戏或参考脚本；不设计未来框架的寄养 API。

## 2. 概念与术语

- **寄养设施**：两个成员的会话容器；同一实现可配置为"走步加经验"（Day Care）或"不加经验"（Nursery），由配置差异表达（§9）。
- **槽位**：容量为 1 的寄养位；记录**对原个体的引用**（非复制）与该个体的**初始等级快照**。
- **兼容性等级**：0–3 的离散值，由资格与关系输入推导；映射到每个 256 步周期的产蛋概率。
- **周期（cycle）**：每步累加计数，达到 256 步归零并执行一次"蛋生成检定"与（配置开启时）一次"蛋招共享检定"。
- **已有蛋标记**：会话级布尔；置真后在该会话内不再产生第二枚蛋，直到寄存/取回/领取（或显式重置）。
- **费用报价**：`(等级差 + 1) × 100`（等级差=当前等级−寄存时等级）；写入事件变量供事件使用；实际扣钱不在领域工具中完成（U01）。

## 3. WP33-A：寄养容器与槽位（静态核对）

### 3.1 槽位与容器

| 项 | 行为 |
| --- | --- |
| 槽数 | 固定 2（`MAX_SLOTS = 2`）；容器按槽索引访问 |
| 占用 | 空槽/占用二态；`count` = 已占用槽数 |
| 容器归属 | 玩家全局数据（`$PokemonGlobal` 内），随存档持久化（WP09 引用） |

### 3.2 寄存（`DayCare.deposit(party_index)`）

1. **先**记统计"寄存合计" +1（在任何有效性检查之前——失败尝试也计数，静态记录）。
2. 取队伍 `[party_index]`；为空 -> 报错（"队伍该索引没有宝可梦"）。
3. 按槽序寻找**第一个空槽**：
   - 找到 -> 槽位寄存：设置对原个体的引用、调用**治疗**（普通治疗入口；**对蛋直接返回**，不保证蛋恢复 HP/状态/PP——蛋例外引用 WP20）、**若为谢米则把形态重置为 0**（形态副作用登记）、记录初始等级；随后**从队伍中删除该索引**（引用移出，不复制）；复位蛋计数；返回。
   - 未找到 -> 报错（"没有位置寄存"）。
- **阶段说明**：报错前统计已 +1；成功时"移除队伍项"发生在槽位写入之后（同一步骤内，无等待）。寄存入口**没有拒绝蛋的守卫**（蛋可作为个体寄存；治疗对蛋不生效，见上）。
- **守卫分层**：寄存/取回工具只执行上述实际条件（索引存在、空槽、队伍容量）；**不检查已有蛋标记或兼容性**（两者属周期与事件接待层）。

### 3.3 取回（`DayCare.withdraw(index)`）

1. 槽位为空 -> 报错（"该槽没有宝可梦"）。
2. 队伍已满 -> 报错（"队伍没有位置"）。
3. 记统计"寄养累计升级" += 该槽等级差（等级差=当前−初始）。
4. 把槽中个体**追加到队伍末尾**；复位槽位（引用清除、初始等级归零）；复位蛋计数。
- **费用**：领域工具**不**扣钱；费用只经"报价"接口提供给事件（§5.3）；真实清算在缺失的接待事件（U01）。

### 3.4 保存与迁移

- 槽位（个体引用、初始等级）、已有蛋标记、周期计数、配置派生的两个开关均属持久数据（WP09 引用）。
- 旧存档迁移（v20→新版，静态核对）：把旧的"寄养数组"逐个旧槽迁入新容器——**每个旧槽遍历全部尚空的新槽、无"填一个后跳出"**（WP10 §4 已审反例引用，不重开 WP10）：两个新空槽与旧 A/B 时，**首个 A 填入两个新槽**（同一引用）、B 无处可写（不是自然的一对一保留）；已有新槽 `[C, 空]` 与旧 A/B 时得 `[C, A]`（被跳过的是**已占用**的新槽，不是按位置对应的旧输入；B 无槽可写）。旧"蛋步数值/布尔"迁移为"已有蛋标记"（真值判定）、旧"步数计数"迁移为周期计数；空旧槽以 50 级玛纳霏占位为迁移脚本的历史行为，仅作兼容记录。

## 4. WP33-B：领域工具与事件接口（静态目录）

### 4.1 类级工具

| 工具 | 行为摘要 |
| --- | --- |
| `count` | 已占用槽数 |
| `egg_generated?` | 是否已有可领取的蛋（会话级） |
| `reset_egg_counters` | 已有蛋标记=false、周期计数=0 |
| `get_details(index, name_var, cost_var)` | 把槽内名称与**费用报价**写入两个事件变量（变量号 ≤0 视为不写） |
| `get_level_gain(index, name_var, level_var)` | 名称与等级差写入事件变量 |
| `get_compatibility(compat_var)` | 兼容性等级（0–3）写入事件变量 |
| `choose(message, choice_var)` | 槽位选择：占用 0 -> 报错；占用 1 -> 该槽索引写入变量；占用 2 -> 菜单（两槽文本＋"取消"）；取消 -> -1，否则所选槽索引 |
| `deposit/withdraw` | 见 §3.2/§3.3（失败为报错） |
| `collect_egg` | 见 §5.2（失败为报错） |

### 4.2 事件命令映射（编译器识别，静态）

核心脚本把事件简写映射到上述工具（`pbDayCareDeposited`、`pbDayCareGetDeposited`、`pbDayCareGetLevelGain`、`pbDayCareDeposit`、`pbDayCareWithdraw`、`pbDayCareChoose`、`pbDayCareGetCompatibility`、`pbEggGenerated?`、`pbDayCareGenerateEgg`）；**实际呼叫者为地图事件，材料缺失（U01）**。调试菜单另有直接读写周期计数/已有蛋标记/`steps_to_hatch` 的入口（WP73 交界登记）。

### 4.3 与队伍/背包/统计的直接交界

- 队伍：寄存=按索引移除；取回=追加（满队拒绝）；容量语义引用 WP25。
- 背包：产蛋概率的"圆形护符"与异色重掷的"闪耀护符"都以**背包持有查询**判定（WP27 引用）。
- 统计：寄存合计、寄养累计升级（§3.2/§3.3 写入）；由 WP06 目录引用。

## 5. WP33-C/D/E：兼容性、周期与取蛋

### 5.1 兼容性判定（`compatibility`，返回 0–3）

按顺序（任一命中即 0）：

1. 占用槽数 ≠ 2 -> 0。
2. 任一个体为 **Shadow** -> 0。
3. 任一个体蛋组含 **Undiscovered** -> 0。
4. 双方都非 Ditto 蛋组 **且** 蛋组交集为空 -> 0。
5. 性别不兼容 -> 0。性别兼容规则（任一项成立即兼容）：一雌一雄（任意槽序）；一方 Ditto 蛋组、另一方非 Ditto（任意性别/无性别；Ditto+Ditto 不兼容；无性别+无性别不兼容）。
6. 否则等级 = 1 +（**同物种** ? 1 : 0）+（**拥有者编号不同** ? 1 : 0），得 1–3。

- 拥有者比较用**拥有者编号**（WP24 引用）；与"拥有者名字/语言"无关（静态核对）。
- 等级值只反映上述三项，不读取遗传/道具（Everstone 等不影响兼容等级）。

### 5.2 256 步周期与产蛋概率

- 每次"玩家迈步"事件：周期计数 +1；达到 **256** 时归零，并执行：
  1. **蛋生成检定**（仅当 无已有蛋标记 且 占用槽数=2）：兼容等级 = c；基础概率 = `[0, 20, 50, 70][c]`；若背包持有**圆形护符** -> `[0, 40, 80, 88][c]`；`rand(100) < 概率` -> 置"已有蛋标记"=真（不生成实体、不占用队伍）。
  2. **蛋招共享检定**（配置开启时；50% 概率）：见 §5.4。
- **概率是每个 256 步周期一次、单次掷值**；兼容等级 0 -> 概率 0（不会置标记）。
- 已有蛋标记置真后：后续周期**不再做蛋生成检定**（仍做蛋招共享与经验）；计数照常累计与清零。
- 复位时机：**寄存、取回、领取蛋**后复位（标记与计数同时归零）；调试入口可独立改写（WP73 交界）。

### 5.3 领取蛋（`collect_egg`）

1. 由两个占用槽生成蛋——**实际守卫仅"占用槽数=2"**（生成入口在槽数≠2 时返回空 -> 报错"无法生成蛋"）；生成入口**不重查已有蛋标记与兼容性**（两者只在周期置标记与事件接待层使用；不再泛化为"其它生成前置不满足"）。生成细节与遗传归 WP34。
2. **队伍已满 -> 报错**"队伍没有位置放蛋"。此时**生成已发生**：随机取值已消费、若病毒检定命中则感染统计已写入；失败**不**重置计数/已有蛋标记（可整理队伍后再领）——**重试会重新生成**一枚新蛋（不是复用已生成的那枚）。
3. 追加蛋到队伍末尾；复位蛋计数（标记与计数归零）。
- **次序要点**：生成（含上述副作用）-> 容量检查 -> 入队 -> 复位；失败发生在入队前（未入队），但生成副作用已发生——静态记录。

### 5.4 蛋招共享（同物种互相教学；静态）

- 条件：占用=2、**两槽物种相同**、配置"同位寄存可共享蛋招"开启、且该周期共享检定命中（50%）。
- 两个方向分别计算（供方 -> 学员）：学员**有招式空位**时，按**供方当前招式槽顺序**枚举供方招式，保留同时满足"在**学员**可接受蛋招表（其 `get_egg_moves`，含前身回溯）中、**供方已掌握**、学员尚未掌握"的项；每方向取**首项**：
  - 仅一方有候选 -> 该方向学员学会其首项（静默学习，WP20 §5.1 引用）。
  - 双方各有候选 -> **随机选一个方向**，该方向学员学会其首项（另一方本周期不学）——不是随机挑任意候选招式。
  - 学员满槽的方向无候选；**供方未掌握的接受表项不教学**；均无候选 -> 无动作。
- 接受表归属：用**学员**的表（不同形态可不同）；供方立场只决定"教什么、按供方槽序"。
- 蛋招表取值：共享教学使用带前身回溯的 `get_egg_moves`（引用 WP18；与 WP34 生成直接读**原始** `egg_moves` 的入口不同，勿混用）。本包只登记共享入口与选取次序。

### 5.5 寄养经验与静默学招

- 配置"走步加经验"开启（默认世代 ≤6 开）时：**每一步**给每个占用槽 +1 经验（不产生消息、不触发友好/进化检查）。
- 经验达到新等级时：按新等级重算能力，并**静默学习**恰好在该等级的等级招式（`learn_move`：槽满时按该接口规则顶掉第一招，WP20 §5.1 引用）；**无升级消息、无友好变化、无进化检查**（与战斗/升级辅助入口的差异登记）。
- 已达最大经验 -> 不再增加（检查发生在加值前）。
- 配置关闭（默认世代 ≥7/8）时：无走步经验；**在无其它等级写入、且无此前累积等级差的常规前提下**等级差为 0、取回报价为 100——报价本身仍按"当前等级−寄存时等级"计算，不由该开关强制归零（该个体被其它途径改级时报价随之变化）。

## 6. 规则与不变量

1. 槽位保存的是**对原个体的引用**（寄存=从队伍移出、取回=原个体返回；不产生复制），并记录初始等级快照。
2. 寄存包含**治疗调用**与"谢米形态归 0"两个副作用；**治疗对蛋直接返回**（蛋例外，WP20 引用），取回只追加与复位。
3. 兼容等级只由：占用数、Shadow、Undiscovered、共同蛋组/Ditto、性别兼容、同物种、拥有者编号差异 决定。
4. 产蛋概率按等级查表（基础/圆形护符两套），每周期一次；已有蛋标记阻止（周期层的）二次生成，不阻止经验/共享；**生成/领取工具本身不读取该标记**（静态核对）。
5. 复位（寄存/取回/领取后）同时清"已有蛋标记"与周期计数；统计不因复位清空。
6. 费用=(等级差+1)×100 仅为报价；扣钱在事件（U01）；本包不保证扣款/退款。
7. 失败均为报错式（"不应发生"或明确前置），且**统计可能已先行累加**（§3.2 第 1 步）；领取失败保留计数与标记，但**生成副作用已发生、重试重新生成**（§5.3）。
8. 走步经验入口与战斗/升级辅助入口差异：无消息、无友好、无进化检查、无"跨级逐级"演出（升级直接落点+学招）。

## 7. 边界与失败

- 空槽位取回/选择：报错；占用 0 时 `choose` 报错。
- 队伍满取回：报错且槽位保持占用（不部分写入）。
- 满槽寄存：报错；**统计已 +1**、其它无写入。
- 空输入寄存（nil 个体）：报错；统计已 +1。
- 领取蛋：占用数≠2 时生成失败报错（不部分入队）；队伍满报错且**不复位计数**（生成副作用已发生、重试重新生成）。
- 直领边界：**标记 false、兼容性 0 时直接领取仍可生成/入队/复位**（工具不重查标记/兼容性；仅事件界面层约束）——静态记录。
- 兼容等级 0：**周期层**无蛋（概率 0）；含 Shadow/Undiscovered/无共同蛋组/不兼容性别/单槽。
- 同物种+同拥有者：等级 2；异物种+同拥有者：1；异物种+异拥有者：2；同物种+异拥有者：3。
