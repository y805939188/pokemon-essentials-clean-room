## 1. 目的、范围与非目标

**目的**：描述文本如何分域、选择语言、提取/编译/载入、查找/替换和回退，以及作者翻译材料的输入输出。后续包据此判断"某段文本来自哪个域、缺译时显示什么、翻译何时生效"，而不是各自重新追踪消息系统。

**范围**（WP08 自身声明范围，extraction-plan 第 2.1 节 (a) 类）：

1. WP08-A：文本域与身份（文本域目录、数组/哈希/地图事件文本、键归一化）。
2. WP08-B：语言配置与选择（配置、选择机会、持久化、载入时机）。
3. WP08-C：消息查找与回退（查找链、占位参数与格式化）。
4. WP08-D：作者翻译工作流（文本收集、提取、编译、写回与失败副作用）。
5. F02-05 中属于 WP08 部分的状态更新。

**非目标**：

- 不复制文本语料（不输出任何具体翻译文本）。
- 不提取字体、窗口绘制与所有 UI 页面的文本呈现（归 D05/D16 领域包）。
- 不提取核心消息的二进制格式细节（加载器行为未验证）。
- 不运行游戏或任何参考脚本；不修改 `reference/`。

## 2. 概念与术语

- **文本域（MessageTypes）**：按内容类别划分的文本集合（物种名、招式名、道具名、地图事件文本等），每个域一个整数身份。
- **默认消息**：随工程编译保存的基础文本（`Data/messages_core.dat`、`Data/messages_game.dat`）。
- **语言消息**：某语言的翻译文本（`Data/messages_<片段>_core/game.dat`），按语言配置的文件名片段命名。
- **数组域 / 哈希域**：按整数索引存储的域（如物种名）与按文本键存储的域（如脚本文本、地图事件文本）。
- **回退**：查找未中时逐层下降的策略（语言消息 → 核心消息 → 原文；地图 → 共享地图 0）。
- 影响域编号 Dxx 见 module-map；证据状态五档定义见总览第 7 节。

## 3. WP08-A：文本域与身份

### 3.1 文本域目录（`S/001_Technical/003_Intl_Messages.rb:675–709`，本轮逐行阅读）

共 30 个文本域（编号保留旧提取文件兼容，不连续）：EVENT_TEXTS(0)（公共事件与地图事件文本）、SPECIES_NAMES(1)、SPECIES_CATEGORIES(2)、POKEDEX_ENTRIES(3)、SPECIES_FORM_NAMES(4)、MOVE_NAMES(5)、MOVE_DESCRIPTIONS(6)、ITEM_NAMES(7)、ITEM_NAME_PLURALS(8)、ITEM_DESCRIPTIONS(9)、ABILITY_NAMES(10)、ABILITY_DESCRIPTIONS(11)、TYPE_NAMES(12)、TRAINER_TYPE_NAMES(13)、TRAINER_NAMES(14)、FRONTIER_INTRO_SPEECHES(15)、FRONTIER_END_SPEECHES_WIN(16)、FRONTIER_END_SPEECHES_LOSE(17)、REGION_NAMES(18)、REGION_LOCATION_NAMES(19)、REGION_LOCATION_DESCRIPTIONS(20)、MAP_NAMES(21)、PHONE_MESSAGES(22)、TRAINER_SPEECHES_LOSE(23)、SCRIPT_TEXTS(24)、RIBBON_NAMES(25)、RIBBON_DESCRIPTIONS(26)、STORAGE_CREATOR_NAME(27)、ITEM_PORTION_NAMES(28)、ITEM_PORTION_NAME_PLURALS(29)、POKEMON_NICKNAMES(30)。

### 3.2 三类存储形态与键

- **数组域**：按整数索引存储（如物种名、招式名），查找按键号（id）。
- **哈希域**：按文本键存储（如脚本文本 SCRIPT_TEXTS、地图事件文本 EVENT_TEXTS），查找按键文本；键经归一化（去首尾空白、压缩连续空白，`Translation.stringToKey`，481–490 行）。
- **地图事件文本**：EVENT_TEXTS 按地图编号分桶，另有 **0 号共享桶**（公共事件文本与跨地图共用文本）；同一文本在不同地图中按各自地图桶分别登记，不预设统一字符串键。

## 4. WP08-B：语言配置与选择

- **作者配置**（WP02 词典）：`LANGUAGES` 声明候选语言列表（每条 = 显示名 + 文件名片段，对应 `Data/messages_<片段>_core/game.dat`）；默认为空（不提供候选）。
- **选择机会**（WP02 已核，行号见其附表 7.3）：启动流程在候选 ≥ 2 且无存档时提供语言选择（`001_StartGame.rb:31–33`）；载入界面在候选 ≥ 2 时显示语言菜单（`016_UI/013_UI_Load.rb:307, 337`）；调试菜单另有语言切换。
- **持久化**：选择保存在玩家系统选项中（`$PokemonSystem.language`）；文本资源按所选片段加载（`MessageTypes.load_message_files(片段)`）。
- **载入时机**：默认消息在启动早期加载（`999_Main/999_Main.rb:27`）；语言消息按需延迟加载（`delayed_load_message_files`，首次查找时）。
- **与 WP09 的交界**：语言属于**设置**（玩家选项），不属于游戏进度；设置与进度的保存/重置边界归 WP09 主规格，本文引用。

## 5. WP08-C：消息查找与回退

### 5.1 查找链（本轮逐行阅读 Translation 类，478–672 行）

| 入口 | 查找链 | 未中结果 |
| --- | --- | --- |
| `get(type, id)`（数组域） | 语言消息[type][id] → 核心消息[type][id] | 空字符串 `""` |
| `getFromHash(type, key)`（哈希域） | 语言消息[type][key] → 核心消息[type][key] | **返回原文**（键为空/nil 时也返回原文） |
| `getFromMapHash(map_id, key)`（地图事件文本） | 语言[map_id][key] → 语言[0][key]（共享桶） → 核心[map_id][key] → 核心[0][key] | 返回原文 |

- 查找**不抛异常**：未中按上表回退（原文或空串），不区分"未翻译"与"未载入消息文件"——载入失败时语言/核心消息按 nil/空数组处理，效果同为回退到原文。
- **占位参数**：`_INTL` 在取回文本后把 `{1}`、`{2}` 等占位替换为参数值（字面替换）；`_ISPRINTF` 支持 `{1:d}` 形式的格式占位（按 sprintf 求值）；`_I`/`_MAPINTL`/`_MAPISPRINTF` 为地图事件文本的对应入口（先按地图回退链取文本，再替换占位）。`_INTL`/`_ISPRINTF` 的查找本身有异常捕获：查找失败回原文。
- 真实消费者按域分别调用：内容显示名（如物种/道具 `name` → `pbGetMessageFromHash(域, real_name)`，见 WP03 数据类）、脚本文本（`_INTL`/`_ISPRINTF`）、地图事件文本（`_I`/`_MAPINTL`）——文本选择与替换发生在各消费者调用点，不是单一全局函数。

## 6. WP08-D：作者翻译工作流

### 6.1 文本收集（编译流程末段，`gather_script_and_event_texts`，7–189 行）

- 从脚本（扫描 `_INTL("…")`/`_ISPRINTF("…")` 字面量）、提取的 .rb 文件、插件脚本、公共事件与各地图事件（Show Text 101/401、Show Choices 102、内嵌脚本 355/655、条件分支 111、移动路线 209）收集可翻译文本。
- 脚本文本入 SCRIPT_TEXTS 哈希域；公共事件文本入 EVENT_TEXTS 的 0 号共享桶；地图事件文本按地图编号入各自桶（仅非空时登记）。这是编译流程（WP04）末段调用，文本收集与消息保存（`MessageTypes.save_default_messages`）随后进行。

### 6.2 提取（作者导出，`extract_text`，244–348 行）

- 从默认消息导出到 `Text_<语言>_core/` 或 `Text_<语言>_game/` 文件夹：每个域一个 .txt 文件（或每地图一个文件），每条文本两行——原文行与译文行（已有译文填译文，无则填原文）。
- **覆盖与跳过**：目标文件夹已有文件时询问是否全部替换；拒绝则中止（不写）；确认则删除旧文件后重写。默认消息文件缺失时提示未找到并返回（不写）。
- 转义：特殊字符经 `normalize_value`/`denormalize_value` 转义（`\r \n \t \x01 [ ]` 与 `<<r>> <<n>> <<t>> <<1>> <<[>> <<]>>` 互换）。

### 6.3 编译（作者导入，`compile_text`，376–472 行）

- 把 `Text_<语言>/` 下全部 .txt 编译为 `Data/messages_<语言>.dat`。
- 节识别：数字节号、MessageTypes 常量名、或 `MapNNN`（地图事件文本）；数组形态要求行数为 3 的倍数（索引/原文/译文三元组），哈希形态要求行数为偶数（键/译文二元组）；非法节名、行数不符、索引非数字均报错（`compile_text_from_file` 的显式异常）。
- 输出写入单个 .dat 文件；写后提示可能需关闭游戏才能看到变更。
- 相关通用 PBS/文件规则（发现、写回、失败）引用 WP04/WP07 主规格，本文不重复定义。

## 7. 默认行为与配置变体

- **基线默认**：`LANGUAGES = []`（无候选语言）；默认消息随启动加载；查找回退到原文；无候选时无语言菜单/选择。
- **支持但未默认启用**：多语言候选（启动选择 + 载入菜单 + 按片段加载）；地图文本按地图分桶与共享桶；作者提取/编译工作流。
- **配置/数据关联**：语言文件名片段与数据文件的对应关系（`messages_<片段>_core/game.dat`）；地图文本的地图编号依赖（缺失地图数据时地图事件文本可达性，U01）。
- **未验证组合**：多语言切换的运行效果、缺译/空译在各消费者的显示、提取/编译的真实往返、地图事件文本在缺失地图下的行为。
- 参考快照行为、官方版本预期、未来目标分开标记；本包只记录第一类。

## 8. 边界、失败与未知

- 默认/语言消息文件缺失：查找整体回退到原文（不报错；与"未翻译"不可区分）。
- 空翻译条目：哈希域键存在但值为空时的显示行为未逐消费者验证（归 UI 领域包）。
- 占位参数缺失或格式不符：`_INTL` 字面替换缺失参数时占位原样保留（`{N}` 不被替换——按替换语义推导；实际显示未运行验证）；`_ISPRINTF` 的格式异常行为未验证。
- 编译输入非法（非法节名、行数不符、索引非数字）：显式异常（作者可见错误，具体呈现归 D18 调试面）。
- 提取覆盖：拒绝替换请求时不写；确认后旧文件被删除再重写（非原子）。
- 地图事件文本在缺失地图数据下的可达性（U01）。
