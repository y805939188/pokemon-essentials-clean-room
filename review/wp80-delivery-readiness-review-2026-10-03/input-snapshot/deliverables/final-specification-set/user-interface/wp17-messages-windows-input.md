# 消息、窗口与输入行为规格（净化正文；批次 14）

分类：user-interface（消息与交互呈现）＋engine-overworld（宿主输入交界）；性质：实现独立行为规格。

本稿为净化正文的一部分：按统一交接将批准输入 WP17《消息、窗口与输入》转写为独立行为文字，不含源文件路径、行号、脚本入口名与组件类名（源定位集中登记于 `../../audit/source-traceability.md` 批次 14 条目）。窗口/组件名是参考侧取证记录，不是未来框架的 UI API。范围：消息与基础窗口（WP17-A）、选项（WP17-B）、数量输入（WP17-C）、按键与文字输入（WP17-D）、状态交界（WP17-E）。全部内容为静态证据；**无运行确认**（见 `../scope-statement.md`）。

## 1. 目的、范围与非目标

**目的**：描述通用交互的行为规则——消息文本如何进入/格式化/逐字显示/确认/关闭，选项与数量输入的来源/取消/边界，按键与文字输入的入口/编辑/确认/取消，以及这些交互与解释器/地图/输入刷新之间的状态交界。后续包据此判断「某交互何时阻塞、返回什么、取消是什么结果」，而不是各自重新追踪消息组件。

**范围**：1) 消息与基础窗口（文本进入、替换、控制标记、逐字显示、确认/暂停、窗口样式与时机；绘制标记目录见附表 [wp17-draw-text-tags](wp17-draw-text-tags.md)）；2) 选项（来源、初始选择、取消策略、结果编码、内嵌选项）；3) 数量输入（范围/位数/初值/取消值/夹限/确认与取消）；4) 按键与文字输入（按键语义、重复、文字入口/编辑/长度/删除/确认/取消）；5) 状态交界（解释器等待、地图更新、输入刷新、临时标记恢复）；6) 对应功能项中属于本包部分的状态更新。

**非目标**：不推断全部界面支持鼠标或输入法；鼠标/宿主文字事件接口存在不等于支持。不提取专门界面（队伍/背包/战斗/商店等）的领域 UI 与领域写入（相应后续包）；交易、命名后的领域写入只追踪到本包交界。不重复 WP08（本地化与占位符主规则，引用）、WP13（事件命令语义与推进，引用）、WP15（资源选择与缺失，引用具体入口）。不运行游戏或任何参考脚本；不执行输入；不设计 UI 组件类层级。

## 2. 概念与术语

- **消息窗口**：由消息窗创建入口创建的文本窗口（逐字显示、位置/皮肤可配）；创建/销毁时维护全局**消息窗显示标记**（见 §7.1）。
- **控制标记**：消息文本中以 `\` 开头的显示/行为指令（§3.2 目录）。**`\1` 是暂停控制符**（显示中暂停等待确认），不是本地化占位符——WP08 的占位符是 `{1}` 等形式（引用，勿混）。
- **绘制标记**：绘制层以 `<...>` 表示的格式指令（附表 [wp17-draw-text-tags](wp17-draw-text-tags.md)；识别集合 21 个，实际处理 19 个，pg/pog 识别但无动作）。
- **逐字显示**：按文字速度逐字出现的显示状态（忙）；确认键的行为按 §3.3 四态区分，不能笼统称「快进」。
- **宿主提供 vs 参考层定义**：输入查询（按下沿/按住/按住重复/物理键名/宿主文字串/文字输入开关/鼠标坐标与窗内判定）由宿主提供；参考层只定义按键别名（USE=C、BACK=B、ACTION=A、JUMPUP=X、JUMPDOWN=Y、SPECIAL=Z、AUX1=L、AUX2=R）与 F8 截图钩子。

## 3. WP17-A：消息与基础窗口

### 3.1 文本进入与替换

消息文本在显示前依次处理（顺序敏感）：

- `\sign[文本]` → 展开为 `\op\cl\ts[]\w[文本]`（签名窗组合）。
- `\\` → 字面反斜杠（内部 `\5`）；**`\1` → 暂停控制符**（§3.2 的 `\!` 同一字符；WP08 占位符 `{1}` 在本地化层，引用，不混用）。
- `\n[1–8]` → 角色名（兼容，存在时）；`\pn` → 玩家名；`\pm` → 格式化金钱；`\n` → 换行。
- `\[8 位十六进制]` → `<c2=...>` 绘制标记；**该 8 位输入分前后两半：前 4 位正文色、后 4 位阴影色（各 15 位 RGB）**，不是单个 RRGGBBAA 值（附表引用）。
- `\pg`/`\pog` → 按玩家性别取男/女文本色（配置引用；**这是消息层反斜杠替换，与绘制层识别但无动作的 `<pg>/<pog>` 不等同**）。
- `\b`/`\r` → 男/女文本色标记。
- `\w[皮肤名]` → 换窗口皮肤；**`\w[]`（空名）把窗口皮肤置为空**（皮肤赋值不补回默认皮肤；窗口按无皮肤状态绘制，具体输出未运行验证）。
- `\c[N]` → 皮肤色板第 N 色（按皮肤明暗取色）。
- `\v[N]` → 变量值（递归展开至无变化）。
- `\l[N]` → 行数（≥1，影响窗口高度与位置）。
- 系统消息框标记非 0 时文本前缀亮色，否则按皮肤明暗取默认色。

### 3.2 消息控制标记目录

| 标记 | 行为 |
| --- | --- |
| `\f[名]` | 显示图片窗（**直接用图片目录**） |
| `\ff[名,索引]` | 显示头像窗（**先头像目录后回退图片目录**；按**四列**切取 96×96——不保证 4×4 共 16 格，也无索引上限校验） |
| `\g` / `\cn` / `\pt` | 显示金钱/代币/战斗点小窗（goldskin 皮肤，与消息窗对角摆放） |
| `\op` | 消息窗滑入出现（0.5 秒，自屏幕外到顶/底） |
| `\cl[SE]` | 特殊关闭：播 SE 后滑出（0.5 秒） |
| `\wu` / `\wm` / `\wd` | 窗口位置上/中/下（即时重摆） |
| `\ts[N]` | 文字速度改为 N/80 秒每字（空参数为 0＝即时） |
| `\.` / `\|` | 等待 0.25 / 1 秒 |
| `\wt[N]` / `\wtnp[N]` | 等待 N/20 秒（wtnp 不暂停并自动继续） |
| `\^` | 不暂停，自动继续 |
| `\!` | 暂停点（逐字显示中暂停，等确认；与 `\1` 同控制符） |
| `\se[名:音:调]` / `\me[...]` | 播放 SE/ME（文首 SE 在显示前播放） |
| `\ch[变量,取消值,选项…]` | 内嵌选项：显示后弹选项，结果写变量（WP13 引用）。**两个字段解析规则不同**：变量号经数字字段解析（数字形式检查，**接受 0**）；取消字段经普通字段解析后转整数（**可为负数或 0，非数字文本转为 0**）。引号校验按实际拒绝条件（开引号字段后须跟逗号或结尾，否则才抛异常；仅开引号后耗尽输入不必然触发） |

### 3.3 逐字显示、确认与四态

**显示状态**：

- 逐字显示时逐字出现（忙）；文字速度为每字秒数（玩家选项映射：慢 4/80、中 2/80、快 1/80、即时 0；配置默认 2/80）。等待计数按运行时长（WP06 引用）倒计时；**计时等待有自身守卫**（等待未到期时显示更新整体挂起，到期后清零继续）。
- **暂停**：`\!`/`\1` 暂停点显示暂停箭头并等待（暂停中）；暂停箭头由专门开关控制（4 帧动画）。

**确认键（USE/BACK）按四态区分**：

| 状态 | 按 USE/BACK 的结果 |
| --- | --- |
| 显示中且**非暂停**（正文本延迟逐字出现） | 仅调用恢复显示——**不推进字符、不改速度**，显示随后仍按计时继续（**不能写成「按键立刻显全文」**） |
| 显示中且**暂停**（pausing） | 解除暂停（暂停中先播决定音），继续逐字显示 |
| 计时等待中 | 由计时守卫决定（到期自动继续；`\wtnp`/`\^` 另设自动恢复） |
| 显示完毕（且出现动画已结束） | 结束本条消息 |

- **立即推进字符是另一入口**（已有战斗消息消费者）：本包只登记该能力存在于组件层，**不把它的效果套给通用消息入口**；战斗 UI 归后续包。
- **自动继续**：`\wtnp`/`\^` 在等待计数归零后自动恢复并继续。
- **特殊关闭**：`\cl` 在消息结束后播 SE 并滑出。
- **出现/结束音效**：无起始 SE 且逐字显示时播决定音。

### 3.4 窗口样式与时机

- 皮肤：按玩家选项取在册皮肤（WP13 命令 131 引用）；窗口不透明度 255；消息窗默认底部两行（高屏三行），按行数重摆。
- 字体：Power Green 系（正文 27、小 21、窄 27；候选回退链）；系统字体经系统字体设定入口。
- 状态标记：创建消息窗置全局消息窗显示标记，销毁清除（§7.1 的入口差别）。

## 4. WP17-B：选项

- **来源**：选项数组（作者内容）；窗口自适应宽高（每列等宽，光标箭头图按皮肤明暗取色）。
- **初始选择**：默认索引参数指定初始索引。
- **结果编码**：确认（USE）→ 当前索引（0 起）。
- **取消策略**（取消项参数）：**> 0 → 取消返回该值 − 1**（相当于「第 N 项作为取消项」）；**< 0 → 取消返回该负值本身**；**＝ 0 → BACK 无效（不可取消）**。**取消不能笼统等价为 false**。
- **nil 与空数组的对照**：选项显示入口对 **nil 立即返回 0**；**空数组 [] 仍建窗并进入输入循环**——零条目不进行光标移动（移动守卫跳过），正常初始化且默认索引 0 时 **USE 返回 0**、BACK 按取消策略、未输入时继续等待。不能把 [] 与 nil 合并。
- **内嵌选项**：`\ch` 结果写变量并请求地图刷新；解释器命令的分支语义归 WP13（引用，本文不重复）。
- **带帮助选项**：随光标切换更新帮助文本；取消策略同上。
- **确认包装**：普通确认＝[Yes, No] 取消按 No（取消编码为索引 1 → false 语义）；严肃确认＝[No, Yes] 取消按 No（默认 No）。

## 5. WP17-C：数量输入

### 5.1 参数对象（数字参数族）

- **范围**：范围设定（最小, 最大）（最小 > 最大时最大＝最小）；位数设定（N）（≥1）改为位数模式——范围变为 ±（10^N − 1）；负号允许设定允许负号，否则下限夹到 0。
- **两个初值入口不同**：默认值设定设初值并**清除已设取消值**；初始值设定设初值但**保留取消值**——调用顺序影响可观察结果。
- **初值夹限**：读取初值时**夹到当前范围**（越界初值被夹限）。
- **取消值不夹限**：取消值设定设置的取消值**不做范围夹限**——取消（BACK）按原值返回（可越界、也可与合法确认值相同，调用者不能总凭数值区分取消）；未设取消值时取**夹限后的初值**。

### 5.2 数字编辑窗口

- 逐位编辑：左/右移动位光标（循环），上/下增减当前位（0–9 循环）；符号模式时首位为 +/− 切换。
- 初值写入：非数值按 0；绝对值夹到 10^位数 − 1。

### 5.3 确认与取消

- 确认（USE）：数值在范围内 → 决定音并返回该值；**越界 → 蜂鸣音并继续等待**（不返回）。范围 [3,3] 时确认只能返回 3，**但 BACK 仍返回取消值**（不夹限），「只能返回 3」不覆盖全部返回路径。
- 取消（BACK）：取消音并返回**取消值**（不夹限；未设时为夹限后的初值）。
- 返回值即结果编码（无单独「已取消」标记；取消值可与合法值相同）。
- 解释器数字入变量命令的桥接归 WP13（引用）。

## 6. WP17-D：按键与文字输入

### 6.1 按键语义与重复

- **参考层**：按键别名映射（§2）；F8 触发截图；鼠标位置查询**默认仅在鼠标位于窗口内时返回坐标**（否则空）；**显式全屏捕获参数为真可绕过该窗口内守卫**（已有调试编辑器静态调用）——接口存在不等于界面支持鼠标。
- **宿主提供**（宿主交界，未运行验证）：输入刷新；按下沿、按住、按住重复、物理键名查询、宿主文字输入串、宿主文字输入开关、鼠标坐标与窗内判定。
- **更新机会**：各交互循环的更新次序按入口不同（§7.2）；每个交互正常结束后再次输入刷新防止多余触发残留。

### 6.2 文字输入入口（按模式分列）

- **模式选择**：文字输入总入口按玩家选项文字输入方式（1＝键盘，其余＝光标）选择场景；包装入口：玩家名（显示玩家行走图）、宝可梦名（显示宝可梦图标与性别符号）、NPC 名、存储箱名（存储箱图标）。
- **长度上限不是跨模式统一保证**：**初始内容不被截短**（两种命名场景与自由文本均如此；上限设定只存上限不改既有文本），确认只查最小长度——超长初值可直接确认返回。

| 入口 | 初值 | 插入 | 确认 | 取消 |
| --- | --- | --- | --- | --- |
| 键盘命名（键盘模式场景） | 不截短 | 宿主文字串逐字插入，**超长拒绝新增** | RETURN 且长度 ≥ 最小长度时返回文本 | **ESCAPE 仅在最小长度＝0 时允许（返回空串）** |
| 光标命名（光标模式场景） | 不截短 | USE 插字符：**满长时先删末字再插入**并自动跳到 OK | OK 且长度 ≥ 最小长度时返回文本（**先播确认 SE 再判长度，不足时不退出、无蜂鸣**） | **无独立取消结果**（BACK 映射为删除，结果总是当前文本） |
| 自由文本 | 不截短 | 同键盘（超长拒绝新增） | RETURN 返回编辑后文本 | **ESCAPE 返回原输入文本（编辑作废）** |

- **光标场景其余行为**：13×5 字符网格，4 组字符集（大写/小写/变音/符号，含 ♂♀ 与符号）；SPECIAL 或模式键切组（带切换动画与音效）；BACK 删字符；**自动切小写组的判定是「当前第一组且插入后光标位置为 1」**（不是验证插入字符一定为大写字母，第一组也含数字）。
- **通用约束**：上限为字符上限（插入侧约束，见上表模式差异）；最小长度为确认下限。

### 6.3 字符编辑组件

- 字符编辑助手：按字符（非字节）计数；插入/删除守上限与光标位置（**超长插入返回假**）；密码字符仅影响显示；**设置上限不截短既有文本**。
- 键盘文本框：←/→ 移光标、退格删除、宿主文字串逐字插入。
- 多行文本框：方向键跨行移动、RETURN 插入换行、Ctrl+HOME/END 跳首尾；本包未找到默认消费者（登记为可用组件）。

### 6.4 数字/文字之外的输入行为

- 重复按键：按住重复用于数字位增减、列表移动、文本删除/光标移动（初次延迟后重复，宿主语义未运行验证）。
- **列表边缘回绕的条件**：命令窗口上/下移动在**相应按下沿成立且条目数能整除列数**时允许边缘回绕（取模循环）；**按住产生重复但非按下沿时，不等于允许回绕**；左/右不循环；JUMPUP/JUMPDOWN 翻页。

## 7. WP17-E：状态交界

### 7.1 等待与阻塞

- **解释器局部等待**：消息等待标记是**该解释器自己的**等待标记（WP13 引用）；消息命令在自身同步消息调用前后维护它——**该解释器**在消息显示期间不执行后续命令。
- **全局显示标记**：消息窗显示标记由消息窗创建/销毁维护，作为**部分入口的守卫**（如相关命令在其为真时返回假不执行）——**它不是「任何解释器的一切命令都停止」**：另一解释器获得更新机会且自身无等待时，仍可执行合法命令（如全局开关赋值）；尝试显示新文本才有入口守卫。
- 选择/数字/文字在消息显示完毕后弹出（WP13 消息命令的合并规则引用）。

### 7.2 地图更新机会（按入口）

- 场景地图微更新自身有前提：**须为地图场景且未处于淡出状态**。
- 各交互循环的调用位置不同：**数量输入循环**先微更新再更新组件；**普通选项循环**的微更新在按键出口检查之后；**自由文本编辑循环没有内建地图微更新**（只能由额外调用/传入块提供）。菜单中地图事件/公共事件的更新差别归 WP13（引用）。不能写成所有交互都有固定的共同更新顺序。

### 7.3 输入刷新与临时标记

- 每个交互正常结束后输入刷新防止触发残留传入下一交互。
- 宿主文字输入开关进入开启/退出关闭、消息窗显示标记创建置位/销毁清除——**这些清理只位于正常出口**：传入块或组件中途抛错会绕过本地关闭与释放（无统一确保保护）；外层淡出包装的确保块负责淡出状态与视口，**不负责该输入开关**。正常清理 ≠ 异常保证，局部可证后果如实登记，不保证顶层所有异常恢复。
- **资源与缺失**：皮肤/图片/图标资源按 WP15 具体入口引用（位图解析缺失返回空等），不概括为「所有缺失都返回空」。
- **抛错路径**：`\ch` 的字段解析按 §3.2 的实际拒绝条件抛异常（沿解释器异常分层，WP07/WP13 引用）；取消/失败的领域写入归相应后续包。

## 9. 边界、失败与未知

- 选项 nil → 立即返回 0；空数组 [] → 建窗循环（零条目不移动光标，USE 返回索引 0，BACK 按取消策略）。
- 数字初值越界 → 夹限；范围最小 > 最大 → 最大＝最小；确认越界 → 蜂鸣继续等待。
- 显式取消值不夹限：可与合法值相同或越界（范围 [3,3] 确认只返回 3，BACK 仍返回取消值）。
- 默认值设定清除取消值、初始值设定保留（顺序敏感）。
- 文字：初始内容不被截短（超长初值可直接确认）；键盘/自由文本超长拒绝新增，光标场景满长先删再插。
- 文字最小长度＝0 时键盘场景 ESCAPE 返回空串；最小长度 >0 时 ESCAPE 无效；光标场景 OK 长度不足时先播确认 SE 不退出（无蜂鸣）。
- `\ch` 解析：变量号接受 0；取消字段可为负/0/非数字转 0；引号校验按实际拒绝条件抛异常（WP07/WP13 引用）。
- 中断清理：文字输入开关/消息标记/组件释放只保证正常出口（异常路径绕过，§7.3）。
- 消息窗资源缺失：皮肤/图片按 WP15 入口（解析为空时窗口无图或保持现状，具体输出未运行验证）。
- 宿主输入（重复延迟、文字事件、鼠标）行为未运行验证；栈式绘制标记未闭合的跨调用残留未逐调用验证（附表引用）。
