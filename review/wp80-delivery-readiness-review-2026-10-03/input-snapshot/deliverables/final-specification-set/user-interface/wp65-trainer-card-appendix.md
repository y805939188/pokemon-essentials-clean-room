## 1. 目的与可见流程

训练家卡是暂停菜单打开的一个**只读展示场景**：把玩家身份、资源与进度汇总在一屏卡片上，玩家只能查看并返回，没有编辑、选择或分支。可见流程：暂停菜单「训练家卡」→ 开场（背景与卡面就绪后淡入）→ 只读等待循环 → 返回键退出（淡出并清理）→ 回到暂停菜单循环。

**非目标**：不定义菜单机制（WP65-D）、玩家字段语义（WP24）、图鉴登记规则（WP62）、统计字段的产生（WP06）、资源匹配规则（WP15）、本地化文本（WP08）；不提取卡面素材内容与运行表现。

## 2. 领域概念

- **场景链**：训练家卡场景入口顺序执行开场 → 只读循环 → 收尾三段，链内无分支（§3）。
- **性变资源**：背景与卡面按玩家性别取女性变体——**女性变体存在才用，否则退回默认**（§4）。
- **当前地区徽章**：徽章展示按**当前地区**（区域查询取当前地区）索引玩家的徽章数组，每地区 8 枚（§5）。
- **只读循环**：唯一的退出输入是返回键（BACK）；无 ACTION 分支（§6）。

## 3. 场景链与生命周期

| 阶段 | 行为 |
| --- | --- |
| 开场 | 视口（z=99999）→ 按性变规则取背景与卡面 → 全屏覆盖位图 → 训练家正面图（按玩家训练家类型取正面精灵——**横向对齐到 128 宽区域、底边保持 240**（放置规则见 §4），z=2）→ 绘制正面内容（§5）→ 淡入显示 |
| 只读循环 | 播放打开音效（「GUI trainer card open」）→ 逐帧更新图形/输入/场景；**BACK 触发** → 播放关闭菜单音效并退出循环 |
| 收尾 | 淡出并隐藏 → 释放精灵集合与视口 |
| 入口 | 场景入口顺序调用上述三段；WP65-D 第 50 项（训练家卡，**无条件总可见**、显示名为玩家名）打开本场景、效果返回 false——关闭后回到暂停菜单循环（WP65 对应节引用，不重述） |

## 4. 性变资源规则

- 背景：训练家卡素材目录下**女性变体 `bg_f` 存在且玩家为女性** → 用 `bg_f`；否则用默认 `bg`（**存在性由资源解析决定**，不推断变体必存在）。
- 卡面：同目录 `card_f` 存在且玩家为女性 → 用 `card_f`（经本地化文本路径取），否则用 `card`。
- 训练家正面图：按**玩家训练家类型**取正面精灵文件名（WP24 资源域引用）——**先读玩家装扮编号（缺省 0）：优先尝试 `_N` 装扮变体（训练家图目录下「类型ID_N」，N＝当前装扮编号），资源解析失败（不存在）则回退基础图（「类型ID」）**。放置规则：**横向对齐到 128 宽区域**（x＝336 −（图宽 − 128）/2）＋**底边保持 240**（y＝112 −（图高 − 128），底边＝y＋图高＝240）——**不是垂直居中**：以宽 128 高 256 位图为例，左上角为 (336, −16)（底边 240）；以 128×128 位图为例，左上角为 (336, 112)（底边同为 240）。

## 5. 正面内容

- **文本行（基色＋阴影色，左右两栏）**：Name（玩家名）、ID No.（玩家**公开号** `%05d` 格式化——WP24 公开号引用，非内部 ID）、Money（当前金钱，千分位格式化）、Pokédex（**拥有数/见过数**——WP62 计数引用）、Time（**游戏时间**：统计游戏时间秒数换算为「Nh Nm」（有小时）或「Nm」（不足一小时）——WP06 统计引用）、Started（**开始日期**：全局开始时间字段——**懒初始化**：未设置时**当场写入当前时刻再读取**，按缩写月名、日、年格式化）。
- **徽章行**：区域查询取当前地区；对 8 个槽位，**玩家徽章数组中下标 i＋地区×8 为真** → 绘制 `icon_badges` 图集中第 i 枚、第 region 行的 32×32 图标（x＝72＋i×48，y＝310）——**只展示已获得的徽章**，槽位图集按地区分行。
- **绘制时序**：文本与徽章均在开场一次绘制；只读循环中**不重绘**（无动态刷新入口）。

## 6. 输入、退出与边界

- **唯一退出输入**：BACK 触发 → 播放关闭菜单音效并退出循环；**无 ACTION/方向键分支**（只读场景，无选择、无翻页）。
- **边界与失败**：
  - 素材缺失：按资源解析结果回退（WP15 引用）——女性变体缺失时退回默认背景/卡面（§4）；不推断缺失素材的运行表现。
  - 开始时间懒写入：**读取开始日期会顺手把当前时刻写入全局**（副作用——本次展示即固定；WP09 持久归属引用）。
  - 徽章数组越界：展示循环固定 8 槽、按下标读取——不推断数组短于「地区×8＋8」时的行为（不补造守卫）。
- **不变量**：场景**只读**（不写玩家数据——除开始时间懒初始化外）；退出后全部资源释放；菜单返回路径固定（WP65 对应节）。
