# 资源匹配、资源访问及声音（净化正文；批次 3）

分类：Generic Kernel（内容→资源匹配）＋Engine/Overworld（资源访问与音频宿主）。本文件描述「数据内容 → 媒体资源」的匹配规则、资源访问层的行为（路径解析、缓存、缺失归一）与音频层的行为（四类音频、切换/暂停/恢复/记忆、地图自动播放、叫声）。全部内容为静态证据；**无运行确认**（媒体文件实际存在与播放结果未验证，资源缺口 U01——见 `../scope-statement.md`）。

## 1. 目的与范围

**目的**：回答「某内容应显示/播放什么、缺失时发生什么」，供后续实现构建资源解析与音频，而不追踪任何特定路径组织。

**范围**：① 资源身份与路径解析（图像/音频/数据文件的查找与候选扩展名）；② 内容到资源的变体选择与回退（物种图鉴/战斗图/图标/脚印/影子/蛋、训练家图、道具图标）；③ 缓存与位图访问（缓存键、引用计数、缺失处理）；④ 音频行为（BGM/BGS/ME/SE 播放/停止/淡出、暂停/恢复/记忆、地图自动播放与夜间变体、叫声、系统音效）。

**非目标**：不承诺任何具体媒体文件存在或可播放（U01）；目录命中不等于完整支持；不提取地图绘制/精灵渲染、消息/窗口/输入、HTTP/文件层失败归一（引用）、战斗内音频/图形的特殊规则（只登记共享入口）。

## 2. 概念与术语

- **资源解析**：把逻辑路径（可缺扩展名）解析为实际文件路径；图像候选扩展名为 .png/.gif（其余停用），音频候选为 .wav/.ogg/.mp3/.midi/.mid/.wma。
- **变体回退**：按内容属性（形态/性别/闪光/暗影）逐位降格查找，直到命中存在的文件或穷尽。
- **播放状态**：系统记录的「正在播放的 BGM/BGS」（含暂停位置），与实际音频输出分开——文件缺失时状态可登记但不发声。
- **夜间变体**：地图 BGM 在夜晚优先使用 `名称_n`（存在时）。

## 3. 资源身份与路径解析

### 3.1 解析层规则

- **图像解析**：输入路径去图像扩展名后，在各搜索路径下依次尝试 .png、.gif（.jpg/.jpeg/.bmp 停用）；全部未命中返回 **nil**（另一入口则回退返回原输入）。
- **音频存在性**：候选扩展名六种；音效解析固定查音效目录前缀，未命中返回 nil。
- **搜索路径**：绝对路径直接使用；相对路径沿宿主搜索路径（当前实现仅当前目录）；加密包经数据层加载检查（文件层规格引用）。存档目录按宿主系统数据目录（存档规格引用）。
- **数据文件存在性**：有加密包时以首字节读取为准，否则规范化路径后查文件系统。
- **失败归一**：资源解析层失败返回 nil（不抛异常）；文件字节读取层的失败归一（nil/空结果）按文件层规格（引用，不重复）。

### 3.2 与内容身份的衔接

- 资源文件名以内容的**符号 ID 字符串**为基名（如物种 ID、训练家类型 ID、道具 ID）；内容身份的查找/回退规则归内容身份规格，本文件只登记「身份 → 文件名」的映射与降格。

## 4. 内容到资源的变体选择与回退

### 4.1 物种图像

**通用降格（战斗图前/后、图标）**：候选因素按位降格——**闪光（闪光子目录 ↔ 普通子目录）→ 暗影（暗影后缀 ↔ 无）→ 性别（雌性后缀 ↔ 无）→ 形态（形态号后缀 ↔ 无）→ 物种（物种 ID ↔ `000`）**。按上述优先级逐项尝试所有组合（最多 32 种），返回第一个存在的文件；全部未命中返回 **nil**（位图入口随之返回 nil）。

| 资源 | 路径基 | 回退链 |
| --- | --- | --- |
| 战斗图（前/后） | 战斗图目录（前/后） | 通用降格（含闪光子目录）；nil 兜底 |
| 图标 | 图标目录 | 通用降格；nil 兜底 |
| 蛋图/蛋壳裂纹/蛋图标 | 蛋目录 | 形态 → 物种 → `000`/`000_cracks`/`000_icon`（**通用候选也经图像解析，全缺失时同样可 nil**） |
| 脚印 | 脚印目录 | 形态 → 物种；nil 兜底 |
| 影子 | 影子目录 | 形态 → 物种 → **按物种指标的 shadow_size 通用影子（`Shadow/N`）** |

- **形态前提按入口拆分**：**前图/后图/图标入口没有形态数据前置**——通用降格直接组合候选路径查找，未登记形态但基础物种图存在时仍可命中（候选穷尽才回 nil）。**蛋、脚印、影子、叫声入口先按（物种, 形态）查询形态数据**：**形态键未命中时回退基础物种键**——基础物种记录存在即返回该记录（**不返回 nil**），随后这些入口仍先尝试所请求形态的资源、再尝试基础物种资源（影子另有按指标的通用影子分支）；只有**查询整体为 nil**（基础物种也不存在）时，脚印/影子/叫声在数据守卫处返回 nil，蛋类继续走 `000` 通用候选（该候选同样经图像解析，全缺失时也可 nil）。
- **个体入口**：按个体的物种/形态/性别/闪光/暗影状态取图；物种登记了个体位图回调时对位图再做个体级修改（形态规格交界，登记入口不展开）。
- **位图访问**：战斗图/图标经动画位图访问层（图标取图后去动画），文件缺失返回 nil。

### 4.2 训练家图像

| 资源 | 路径与回退 |
| --- | --- |
| 角色图 | 角色图目录 `trainer_类型ID`；不存在返回 nil |
| 战斗前图 | 训练家图目录 `类型ID`；玩家版加 `_套装号` 后缀——**先查带套装后缀，未命中回退无后缀** |
| 战斗后图 | 训练家图目录 `类型ID_back`（玩家版先查 `_套装号_back`） |
| 城镇地图图标 | 城镇地图目录 `player_类型ID`（玩家版先查套装后缀） |

### 4.3 道具图标

- 空输入 → 道具图标目录 `back`；未知道具 → `000`（**固定兜底**）。
- 常规：`道具ID`，未命中时——机器类（HM/TM/TR）按 `machine_hm|machine_tr|machine_招式类型` 再按 `machine_招式类型`（非 TM）降格；最终回退 `000`。
- 队伍持有图标：邮件按 `icon_mail_道具ID`、其他按 `icon_item_道具ID`（队伍界面目录），未命中回退 `icon_mail`/`icon_item` 通用图。

## 5. 缓存与位图访问

- **缓存键**：路径（＋色相）为键的进程内位图缓存；命中且未被释放则复用并增引用计数。
- **引用计数**：位图包装按引用计数释放——释放减计数，计数归零且非「永不释放」才真正释放；复制得新计数 1；保留标记永不释放。
- **空文件名**：返回 32×32 空白位图（不读盘）。
- **图块切取**：图块集图块按（文件, tile_id, 色相, 宽, 高）为键缓存切片。
- **缓存清空**：场景切换时由宿主缓存层整体清理（地图拓扑规格显示层重建处的清空调用点，引用）；本文件不规定淘汰策略。
- **失败边界**：缓存层不新增失败语义——文件缺失的异常/空白结果取决于访问入口（文件层归一引用）；动画位图访问层对缺失文件按加载结果返回 nil 或抛出（未逐入口验证，列未决）。

## 6. 音频行为

### 6.1 播放入口与失败边界

- **参数解析**：字符串支持 `文件名`、`文件名:音量`、`文件名:音调` 三种形式，默认音量/音调 100；音频文件对象直接可用；音量/音调参数可覆盖。
- **调用链**：各类播放入口 → 系统层 → 兼容层 → 宿主音频直接调用，逐级回退。
- **实际播放前提**：系统层在文件**存在**（经音频存在性检查）时才实际发声；**文件缺失时 BGM/BGS 的播放状态仍被登记**（记录请求的对象克隆），但不产生音频输出。SE/ME 缺失时不播（SE 不登记状态）。
- **音量缩放**：BGM/ME 按玩家选项音乐音量、BGS/SE 按音效音量百分比缩放。
- **默认 BGM 覆盖**：设置了默认 BGM 时一切 BGM 请求改播默认曲（状态登记仍按请求）。
- **帧重置**：BGM/BGS/ME 播放或停止后做画面帧重置。

### 6.2 切换、暂停/恢复与记忆

| 行为 | 规则 |
| --- | --- |
| 停止/淡出 | 时长 > 0 走系统淡出（毫秒换算），否则立即停止；淡出/停止清空播放状态（暂停中除外，见下） |
| 暂停 | 记录当前播放位置（宿主查询失败按 0），可带淡出；暂停中随后的播放/停止/淡出**不改写已记位置** |
| 恢复 | 从记录位置继续播放并清暂停标记 |
| 记忆/回播 | 记忆记录当前播放对象（克隆），恢复回播（事件命令 247/248 引用） |
| BGS 暂停/恢复 | 按暂停标记重播（不记位置） |
| 提示切换 | 目标与当前不同（名称或音调）→ 淡出当前＋延迟提示新曲（延迟为淡出时长的 0.6 倍，单调秒计时）；相同则直接播放 |

### 6.3 地图自动播放与夜间变体

- **自动播放**：地图元数据自动 BGM/BGS 为真时按地图 BGM/BGS 播放；两种入口——直接播放（读档恢复用）与提示切换（转移用）。
- **夜间变体**：夜晚且 `名称_n` 存在时改用 `名称_n`（时间来源引用）。
- **传送淡出**（在新图自动播放执行之前的预淡出阶段）：两条差异分支**各自带门，仅名称不同不足以触发**——**BGM 分支**：当前已有 BGM 播放登记、目标图自动 BGM 开启且登记曲名与目标图解析曲名（含夜间变体）不同 → 请求 BGM 淡出 0.8 秒；**BGS 分支**：当前已有 BGS 播放登记、目标图自动 BGS 开启且登记 BGS 名与目标图 BGS 名不同 → **调用的同样是 BGM 淡出**：向宿主请求 BGM 通道淡出 800 毫秒并清空 BGM 播放登记，**本分支没有 BGS 淡出，BGS 播放登记保持**（参考快照行为，如实登记，不修参考；BGS 淡出另有独立入口，不在此分支；BGS 分支成立**不额外要求 BGM 分支成立**）。任一分支在播放登记缺失或目标对应开关关闭时均不请求淡出；两者均无播放登记时整个预淡出直接返回。前提：系统存在、无默认 BGM 覆盖（否则宿主淡出请求被跳过、状态清空仍发生）。
- **冲浪 BGM**：转移自动播放时，冲浪中且元数据登记冲浪 BGM 则改播冲浪曲（冲浪状态引用）。

### 6.4 叫声与系统音效

- **物种叫声**：叫声目录 `物种ID[_形态][后缀]`；形态未命中回退物种，再未命中返回 nil（不播放）；蛋不播放。叫声时长按文件实际时长 ÷ 音调缩放估算（ogg 解析；非 ogg 或无页返回 −1 路径）。播放失败被吞掉（不传播）。
- **系统音效**：光标/决定/取消/蜂鸣优先用系统数据登记的音效，未登记且默认文件名存在时用默认文件（音量 80）；关闭菜单音仅按默认文件存在与否。

## 7. 默认行为与配置变体

- **基线默认**：图像候选 .png/.gif；音频候选六种扩展名；物种图像按 §4.1 降格；道具/蛋有固定兜底图；BGM 按地图自动播放（含夜间变体）；音量按玩家选项缩放。
- **支持但未默认启用**：物种个体位图回调（形态规格）；默认 BGM 覆盖；系统数据登记的 UI 音效；邮件专用图标。
- **配置/数据关联**：对话/菜单窗口皮肤（事件命令 131 引用）；音乐/音效音量玩家选项；地图元数据 BGM/BGS/自动播放字段与全局元数据冲浪/骑行 BGM；系统数据的四种 UI 音效。
- **未验证组合**：任何具体媒体文件的存在与播放结果（U01）；动画位图在各缺失路径的行为；宿主音频的实际输出。

## 8. 边界、失败与未知

- 图像解析全未命中 → nil（位图入口 nil）；另一入口回退原输入。
- 形态查询与资源缺失三分：**形态键未命中但基础物种存在** → 查询回退基础记录，蛋/脚印/影子/叫声可命中基础物种资源；**查询整体为 nil**（基础物种也不存在）→ 脚印/影子/叫声在数据守卫处 nil，蛋类走 `000` 通用候选；**文件候选全未命中** → 各入口按自身解析规则回 nil（蛋的 `000` 通用候选也不例外）。前/后图/图标不受形态查询约束（按候选路径继续查找，穷尽才 nil）。
- 道具图标未知 → `000`；空输入 → `back`。
- 音频文件缺失：BGM/BGS 状态登记但不发声；SE/ME 不播；叫声 nil 不播；叫声播放异常被吞。
- 暂停位置查询失败按 0 记录；恢复时从头播放该位置之前的内容不可考（静态）。
- 空文件名的缓存位图为 32×32 空白。
- 动画位图访问层在缺失/损坏文件上的行为（未逐入口验证）。
