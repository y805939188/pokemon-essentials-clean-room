# 图鉴记录、区域与内容规则（净化正文；批次 8）

分类：Pokémon Rules（主）／Creature-RPG（获得入口交界）／User Interface（可见性接点）。本文件回答「图鉴记录哪些事实、由谁在何时写入、区域列表如何构成与解锁、各界面按什么资格显示什么」。全部内容为静态证据与数据样本；**无运行确认**（见 `../scope-statement.md`）。本文件定义图鉴操作合同；捕获判定与完整接收流程由《捕获判定与接收策略》定义，本文件只登记其写入接点（不构成反向依赖）。

## 1. 目的与可见流程

可见流程：玩家获得图鉴（标志位）→ 区域列表按解锁与「是否见过任何成员」变为可访问 → 战斗与各获得入口写入记录 → 图鉴菜单／主列表／条目页按见过/拥有与区域资格显示；条目页「栖息地」页由**遭遇表**生成区域地图要点。

边界：不定义物种/形态数据本身（《个体身份、物种与归属》/《动态形态与展示属性》）、不定义遭遇生成（遭遇规格）、不定义地图与存档（地图/《保存、启动、新游戏与继续》）；捕获公式与接收流程归《捕获判定与接收策略》；图鉴解锁剧情、图鉴授予与大多数解锁调用不在脚本内（事件侧，U01）。记录与区域规则全部为「已读静态＋数据样本」级别。

## 2. 记录字段与结构

记录存放在玩家对象的图鉴子对象内；随玩家一起存档。字段如下（「刷新可访问列表」的副作用**按入口分列**，见 §3.4——不是每次写入都刷新）：

| 字段 | 结构 | 含义与备注 |
| --- | --- | --- |
| 见过 | 集合（按**基础物种**键） | 任何登记入口置真；只增不清（无逐项清除接口；公开的整体清理入口清记录并刷新、**保留区域解锁表**，见 §3.4） |
| 拥有 | 集合（按基础物种键） | 与「见过」独立；战斗侧仅捕获流程写入（击倒对方不写拥有），获得侧多个入口直接写入（§3.2） |
| 见过形态 | 物种 → [性别2档][异色2档][形态号] 布尔表 | 性别 2 档＝雄/雌；无性别在写入时并入第 0 档（雄） |
| 见过蛋 | 集合 | 由**孵化时刻**写入（不是拿到蛋时）；无刷新副作用 |
| 末次形态 | 物种 → [性别, 形态号, 异色] | 条目页缩略图/列表行引用；登记入口只在「尚为空」时写入，另有一个总是覆盖的「最近见到」入口与一个界面浏览写入（§6） |
| 暗影拥有 | 集合 | 与「拥有」独立；由捕获流程对暗影个体附加写入 |
| 捕获计数 | 物种 → 整数 | 每次捕获＋1；缺省 0 |
| 击败计数 | 物种 → 整数 | 每次击倒对方个体＋1（战斗侧调用）；缺省 0 |
| 合成「战斗过计数」 | 查询＝击败＋捕获 | 不是独立字段；条目页展示（§6）；野生遭遇的连锁异色判定另归遭遇规格消费 |
| 区域解锁表 | 布尔数组，长度＝区域数＋1（末位＝全国） | 初始化只有索引 0 为真；解锁/锁定按区域号；越界或 −1 归到全国位 |
| 可访问列表 | 区域号数组（派生） | 重算时机**按入口分列**（§3.4：可关闭参数与不刷新入口保留）；作为玩家数据一并保存，内容以重算结果为准 |
| 全局观看状态 | 图鉴观看记录（3 项，随全局元数据保存） | 当前观看的区域号（默认：有区域则 0，否则全国 −1）；各区域「上次查看的物种索引」（长度＝区域数＋1）；搜索模式（默认数值序 0） |

计数只按**基础物种**归并：形态不产生独立条目；「已见形态数」等按形态维度单独查询（§4——其实际计数限度见 §4 末）。未知标识（查不到物种数据）的行为**按入口分列**（§3.4）：守卫族静默、登记入口失败，不能统一概括为静默忽略。

## 3. 写入入口与门

### 3.1 战斗侧（写入的是玩家训练家对象的图鉴）

| 入口 | 写入 | 门与接收者 |
| --- | --- | --- |
| 战斗包装·出场登记（对方首发与**后续每次替换出场**）与战斗中展示变化（如形态变化、幻觉类揭示等已述调用点） | 见过＋见过形态＋（首次）末次形态＝该个体的展示种/展示性别/展示形态/异色 | **内部战斗标志为真**才写；接收者＝战斗玩家对象的图鉴 |
| 战斗包装·对方倒下 | 击败计数＋1（按展示物种） | 同上有门；接收者同上 |
| 战斗包装·捕获计数 | 捕获计数＋1（按接收个体） | 同上有门；接收者同上 |
| 捕获接收流程内的**直接调用**（不经三个包装） | 未拥有时 → 拥有；提示条件通过时 → 最近见到＋条目页；暗影个体 → 暗影拥有 | **无内部战斗门**：非内部战斗若捕获队列含未拥有个体，这些字段仍会被写；接收者＝战斗玩家对象 |
| 个体形态提交（任何来源：离场处理、构造、战斗内变形等） | 登记（见过＋见过形态＋首写末次形态） | **无门**；接收者＝**全局玩家**的图鉴（与战斗玩家对象不是同一接收者；回放副本反例见回放规格） |

捕获接收在常规战斗终局执行，次序：捕获计数（包装，有门）→ 见过（包装，有门）→ 未拥有则**直接**写拥有＋（有图鉴且**物种在已解锁区域表内**时）提示「数据已添加」＋最近见到＋打开条目页 → 暗影个体**直接**写暗影拥有 → 储存。记录战斗只把「储存」覆盖为空操作，**不抑制登记队列的其余写入**；正常设施菜单不可捕获只是输入来源限制，不等于队列被直接消费时字段不写。库存与拥有次序归《捕获判定与接收策略》详述，本文件只记图鉴接点。

注意：战斗侧入口不预先判断「是否已见过」（重复即覆盖同值）；登记入口本身不对蛋状态设门，由调用方保证不登记蛋。

| 入口族 | 未知标识行为 | 键与归一 | 刷新副作用 |
| --- | --- | --- | --- |

## 4. 身份与形态规则

- **基础物种归并**：守卫族与登记入口的记录按「物种的基种」键（形态数据归一后取基种）；**末次形态直接读写按原键**（同一张表，不做归并——§3.4）。未知标识的行为**按入口分列**：守卫族查询返回假/0、写入不生效；**登记入口在数据解引用处失败**；原键直接读写不做未知检查（均见 §3.4，不作统一静默保证）。
- **形态映射**：登记时实际的「形态号」先经**图鉴展示形态**映射（形态不同则改记展示形态），再把「无命名形态」归为 0。因此记录中的形态是展示维度，不是原始形态号。
- **性别映射**（按入口分列）：登记入口写入前性别 ≥2 并入 0；「最近见到」入口保留个体原性别写入；末次形态直接写入不做归一。见过形态表只索引 0/1。
- **异色维度**：仅用于「见过形态」与「末次形态」；「见过/拥有」不区分异色。
- **末次形态语义**：初始登记入口只在键不存在或为空时写入（首个登记形态成为默认显示，键为归并后的基种）；「最近见到」入口总是覆盖（用于捕获/获得提示后展示）；界面浏览覆盖（§3.2）；直接读写按**原键**、不归并（§3.4）。查询默认 [性别 0, 形态 0, 异色假]。
- **形态查询**：按（物种，性别，形态，异色）精确或「任一异色」查询。**「已见形态数」实际只检查形态号 0/1**：实现取两组性别槽各自的长度（各为 2 个异色槽）作为循环上界，因此循环只访问形态下标 0/1——已登记的形态 2 可被精确查询命中，但**不计入**该数（§8 PD20 给 UNOWN 形态 2 具名对照）；保留此真实计数缺陷，不把参考修成理想的全部形态去重计数。展示形态的选择与命名（含无命名/单一性别形态）归《动态形态与展示属性》，本文件只消费。

## 5. 内容集合、解锁与区域

### 5.1 区域表的数据来源与结构

- **`PBS/regional_dexes.txt`**：以 `[n]` 分节（本快照两节：[0] 与 [1]，共 212 行）；节内每行是逗号分隔的物种链（多为进化族一行）；行内与行间按**出现顺序**平铺为顺序表——该顺序即区域编号次序。
- 编译语义（静态）：重复分节报错；同一区域表内物种重复报错（定位到行）；缺分节即报错；编译产物写入区域表数据文件并从缓存读取。
- 编号：区域编号＝表中位置＋1（查询得到 1 起编号，0＝「不在该表」）；**偏移设置**中的区域在展示时整体减 1（0 起）。
- 全国表没有独立存储：全国编号按物种数据遍历顺序（展示端以全国序列的索引推编号）。

### 5.2 解锁与可访问

- 解锁表初始化：仅索引 0 为真（末位全国默认锁定）。解锁/锁定接口对 −1 或越界一律作用到**全国位**。
- 可访问重算（派生；触发时机按入口分列——可关闭参数与不刷新入口见 §3.4）：
  - 若「使用当前区域」设置为开：取玩家当前地图的**区域号**（无地图默认 −1；区域号 ≥ 区域数时视作全国）；仅当该表「见过任何成员」时列入（只列一个）。
  - 若只有全国定义：全国位解锁且见过任何成员时列入全国。
  - 否则：逐区域按（解锁 ∧ 见过该区域任何成员）列入（区域在前），全国按（解锁 ∧ 见过任何成员）列在最后。
- 「见过任何成员」查询：全国＝遍历全部物种有无见过（专门分支）；区域＝对该区域表成员遍历——**成员查询返回空（负区域/缺表/空表）时此遍历失败**，见末节边界。
- 「物种在已解锁区域表内」查询：全国位解锁 → 真；否则任一已解锁区域的该物种编号 >0 → 真；否则假。空表或未知物种 → 假。
- 计数（见过/拥有）按区域：全国＝全物种（−1 专门分支，不经成员查询）；区域＝对该区域表成员逐个查集合（含未解锁区域也能算数——**计数不检查解锁**；只有可访问列表检查；**成员查询为空时计数同样失败**）。
- 空/缺表边界（按入口分列，不给参考补空值保护）：区域成员查询在负区域/缺表/空表**返回空（不是空数组）** → 数据层的区域计数与「见过任何成员」对该区域直接遍历时**失败**（不能写成计数 0/见过假）；区域编号查询对缺/空表返回 0；区域长度查询对缺表返回 0（负数区域返回全国长度）；主列表构建另有自己的空/空回退（改用全国序列，§6）——界面回退不覆盖数据层失败。

### 5.3 区域与地图数据

- 当前区域＝当前地图元数据的**城镇地图位置**首字段；无地图元数据时为 −1。
- 条目页「栖息地」页：对当前区域，按**当前遭遇版本枚举**全部遭遇表，找出含该物种的表（任意槽位）；排除带「在图鉴中隐藏遭遇」标志的地图；要求地图的城镇地图位置区域号相符；按地图的城镇地图占位（含多格形状）折算成要点；概要点还要求地图点可见（可选可见开关）。无任何点为「区域未知」空态。
- **版本枚举的具名缺陷（遭遇规格已审反例，本轮回源确认）**：枚举入口对 v>0 的回退检查使用与实际注册键不同的键形态，因此**同图 v>0 有表时 v0 表仍会被一并枚举**——同图 v0 含 X、v1 无 X 时，当前版本 v1 的栖息地仍可能被 v0 表点亮；单次 get 查询的版本优先回退正常，不受此缺陷影响。隐藏标志/区域/可见点门保持。
- 遭遇版本是全局元数据中的整数值（默认 0）；图鉴只是它的读取者——修改与语义归遭遇规格。
