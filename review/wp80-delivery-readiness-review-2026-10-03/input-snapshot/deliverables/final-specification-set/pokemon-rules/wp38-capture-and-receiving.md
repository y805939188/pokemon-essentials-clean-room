# 捕获判定与接收策略（净化正文；批次 6）

分类：Pokémon Rules（主）／Combat Requirements（战斗内接点）／Creature-RPG（接收与队伍交界）。本文件是捕获**唯一主规格**：许可、判定数学、球效果与接收策略只在本文件定义；背包、集合、图鉴与界面均引用本文件，不各自复制公式。全部内容为静态证据；**无运行确认**（见 `../scope-statement.md`；数值全部为独立常数算术，未执行捕获、未调用随机）。

## 1. 目的、分层与边界

捕获按五层理解，层与层的判定不混同：

1. **菜单许可**（选中球与目标时）：可投与否及文案。
2. **登记**：写入本轮行动选择、**即时扣除背包**、占用本轮全部行动；取消选择会把物品放回。
3. **执行**：攻击阶段在行动槽按优先级执行；**球走专用执行路径**（一般物品在执行时有复检与「无效果退回」，球没有——见 §2）。
4. **判定**：投球时点重新解析目标 → 训练家阻挡检查 → 捕获数学 → 摇晃数与结果演出；失败发生在判定层（不是「无效果」）。
5. **战后接收**：战斗终局统一处理队列——图鉴写入、昵称、入队/送盒与替换策略。

边界：野生与训练家常规战；抢夺（Shadow）只做本文件已证明的许可与接收分支，完整 Shadow/Hyper/净化生命周期归 Shadow 规格；Safari 与捕虫大会完整会话归其专门模式规格（其专用球与路径另行处理）；设施战斗不掷球（非内部战斗物品菜单被拒）。

## 2. 抛球与许可

| 层 | 检查/行为 | 失败表现 |
| --- | --- | --- |
| 菜单（球族可用性） | ①队伍满∧盒子满 → 拒；②战斗规则「禁止投球」→ 拒；③不是本轮的第一个行动 → 拒（「要专注才能瞄准」）；④目标半隐身 → 拒；⑤**未倒下对方＞1** → 拒（两只/更多文案不同）——例外：**抢夺球且训练家战** | 均只给消息、不消耗 |
| 菜单（目标） | 投球必须指定目标个体（无目标不能登记）；目标选择界面提供目标 | 不能登记 |
| 登记 | 扣背包（按「使用后消耗」类物品规则）、写入本轮选择、**占用全部行动**（登记层与菜单层两半共同保证） | 取消该选择（含返回上层）→ 物品放回背包 |
| 执行 | 攻击阶段行动槽：数据字段「对战使用＝对敌(4)」→ **专用球执行**；目标索引来自登记值，若为负取使用者自身 | 专用路径**无执行复检、无退回** |
| 投球时目标再解析 | 入口参数是**目标/候选战斗者索引**（不是投掷者索引）：索引属敌方 → 直接取该对象；索引属己方 → 取其对位敌人；目标已倒下 → 替换为其**首个存活同伴**（同伴集合只含未倒下者）；**无存活同伴 → 得到空对象，随后状态查询先失败**——达不到「无目标」提示与正常返回（该提示存在，但此前提下不可达）；正常菜单的目标选取保护与此直接触达边界分列 | 返回即结束本次投掷；**球仍已消耗**；不承诺异常路径自动退回或回滚 |
| 训练家阻挡 | 训练家战 且 非（抢夺球∧目标为暗影）→ 挡球演出＋「训练家挡下了你的球」并返回 | 同上；**不计入「失败球」统计** |
| 抢夺球身份 | 物品带「抢夺球」旗标，**或**任意球∧玩家持抢夺机器（默认无；调试可授予） | — |

要点：容量还同时作为**投球前置**（①）与**接收兜底**（§6）两层出现；登记即消耗，之后任何失败（目标丢失、训练家挡球、摇晃不足）都不自动退回。

## 3. 捕获判定数学

输入：目标个体（当前 HP、最大 HP、物种链捕获率、状态）、球、战斗上下文；「失败球」统计与演出在其外。

计算（有界、按实际取整与比较符）：

1. **短路径**：调试态按住 Ctrl → 直接得「4 摇＝捕获」（调试路径，不算正常证据）。
2. **基础率**：未显式提供时取物种捕获率。
3. **球修正前置门**：目标物种带「究极异兽」旗标 且 球不是**兽球** → 率÷10（**整数除法**，先于一切球修正）；否则应用球修正函数（未登记球 → 不变）。
4. **第一段（血量与状态）**：中间量 `m = ((3×A − 2×B) × 率) / (3×A)`（**保留浮点，不取整**），A＝目标最大 HP、B＝当前 HP；随后按**真实状态字段**乘：睡眠/冰冻 ×2.5、其它非「无」状态 ×1.5（「视为睡眠」等能力效果不影响此倍率，对照 §4 梦境球）；**唯一的取整时点在最后**：`x = ⌊m⌋`，**下限 1**。对血量式提前取整是错误（测试目录 CP02 给 110 反例对照）。
5. **必捕获**：x ≥ 255，或**无条件球**（大师球）→ 4 摇（不再掷任何随机）。
6. **第二段**：`y = ⌊65536 / (255/x)^0.1875⌋`。
7. **暴击捕获**（设置开，默认开）：拥有数分档 → 系数（＞600→5；＞450→4；＞300→3；＞150→2；＞30→1；否则 0）；持捕获护符翻倍；`c = x×系数÷12`（整数）。若 c＞0 且**一次 256 取值＜c** → 进入暴击：**一次 65536 取值＜y → 4；否则 0**（0 摇，立即脱出）。暴击入口在普通摇晃之前。
8. **普通摇晃**：最多 4 次，每次 **65536 取值＜y** 则摇数＋1；**首次不通过即停止**；结果 0–3 为脱出（四段文案），4 为捕获。

随机全部经战斗随机入口（回放规格记录域；普通战斗＝全局随机、可记录战斗＝记录序列）。数值向量见测试目录。

## 4. 球效果族与覆盖

四个处理器家族：**无条件**（1 项）、**修正基础率**（19 项）、**成功后**（2 项）、**失败后**（0 项——失败只累计「失败球」统计与演出文案；演出颜色/动画属场景媒体）。

| 球 | 家族/条件 → 修正 | 边界与更代差异 |
| --- | --- | --- |
| 大师球 | 无条件 → 真 | 先算 x 后仍返回 4 |
| 超级球 | ×1.5 | — |
| 高级球 | ×2 | — |
| 狩猎球 | ×1.5 | — |
| 竞赛球 | ×1.5 | — |
| 捕网球 | 目标具虫/水属性 → ×（3.5｜3） | 更代档（默认 3.5） |
| 潜水球 | 环境为水下 → ×3.5 | — |
| 巢穴球 | 目标等级 ≤30 → ×max（(41−等级)÷10, 1） | 31 级及以上不变 |
| 重复球 | 图鉴已拥有该物种 → ×（3.5｜3） | 更代档（默认 3.5） |
| 计时球 | ×min（1＋0.3×回合数, 4） | 回合 ≥10 → ×4 |
| 黑暗球 | 时段值 2（夜/洞）→ ×（3｜3.5） | 更代档（默认 3） |
| 先机球 | 回合数 0 → ×5 | — |
| 速度球 | 目标基础速度 ≥100 → ×4 | 先 × 后与 255 取小 |
| 等级球 | **己方场上未倒下成员**最高等级 ≥目标×4／×2／＞ → ×8／×4／×2 | 查询集合＝当前侧 0 存活场上成员（后备不计）；与 255 取小 |
| 诱饵球 | 钓鱼遭遇 → ×（5｜3） | 更代档（默认 5）；与 255 取小 |
| 沉重球 | 新档：≥3000→+30、≥2000→+20、<1000→−20、**1000..1999 不变**；旧档：≥4096→+40、≥3072→+30、≥2048→+20、**其余 −20** | **率 0 早返（保持 0）**；其余钳 1..255；边界对照见测试目录 CP10 |
| 甜蜜球 | **己方场上未倒下成员**中有同种异性别（任一方无性别不成立）→ ×8 | 查询集合同等级球（后备不计）；与 255 取小 |
| 月亮球 | 目标进化族可用月石进化 → ×4 | 与 255 取小（族级判定，非个体可立即进化） |
| 梦境球 | 目标「视为睡眠」→ ×4（「视为睡眠」含合格 KOMALA/COMATOSE——其真实状态可为「无」） | 与 §3 状态倍率分开：倍率只读真实状态；真实「无」的合格 COMATOSE 目标获 ×4，但不另获睡眠 ×2.5 |
| 兽球 | 目标为究极异兽 → ×5；否则 **÷10（整数）** | 与 §3 前置门互斥配合 |
| 精灵球/纪念球/珍贵球 | 无登记 → ×1 | 静态：数据与处理器均无额外规则 |
| 豪华球 | 无捕获修正 | 友好度增益在成长侧（球种写入后由友好度获取分支消费） |

- **成功后**：治愈球 → **治愈**（回满并恢复状态）；友谊球 → 友好度设为 150（软上限开）或 **200**（默认软上限关）。
- **更代设置**：`新式球率`（默认开，机制世代 ≥7 时）决定捕网/重复（3.5↔3）、黑暗（3↔3.5）、诱饵（5↔3）与沉重球两套体重档。
- **登记与复制的核对**：本文件登记的球即全部捕获率消费者；数据侧共有 **26 颗球**（物品旗标＝PokeBall），其中 22 颗有登记（1 无条件＋19 修正＋2 成功），4 颗无登记（默认 ×1，名单上表）。球无「复制」登记（复制仅用于非球物品处理器）——原始数据表匹配不替代本对照。

## 5. 成功后的次序与提交

4 摇成功时按固定次序执行（前序失败不进入本段）：

| # | 步骤 | 提交效果 |
| --- | --- | --- |
| 1 | 「捕获成功」消息与成功音效 | 呈现 |
| 2 | **移出战斗队伍**：清除该位、显示顺序数组重排（该位排到队尾方向） | 立即提交于战斗内数组（无回滚） |
| 3 | 经验获取（设置开，默认开）：目标置「被捕获」标 → 结算 → 清标 | 细节归战斗结果规格；本文件只记触发与时点 |
| 4 | 战斗者复位（能力/效果等清理） | 战斗内 |
| 5 | **若捕获对象所在方再无可用个体** → 决定：训练家方 → 胜 1；野生 → 捕获 4 | 终局开始（战斗随后收束） |
| 6 | 属主改写：**仅**抢夺球 → 属主设为玩家 | 其余球不改属主 |
| 7 | 球成功效果（治愈/友好度） | 个体数据 |
| 8 | 球种写入个体 | 个体数据 |
| 9 | 解除 Mega/Primal | 战斗临时状态还原 |
| 10 | 暗影个体 → 更新暗影招式（Shadow 规格域） | 个体数据 |
| 11 | 首招记录（用于回忆） | 个体数据 |
| 12 | 若物种有「按函数取形态」→ 清除强制形态 | 个体数据 |
| 13 | 离场钩子（含「战斗结束」旗标；形态离场还原与 HP 上限钳制在其内） | 个体数据 |
| 14 | 隐藏球与数据框演出；**入「待接收队列」** | 战斗内队列 |

未在此列表的项（昵称、图鉴、入队/送盒）都在**战后接收**（§6）。属主、个人值等变更不与旧缓存自动同步的提醒引用个体/属性规格；持物在捕获全程不被改动；满队替换时换出到盒子的成员按**当前持物**送盒、退出结束时的还原循环（§6 具名）。

## 6. 战后接收、容量与替换策略

战斗终局对每只待接收个体按序处理：

1. **图鉴**（图鉴规格绑定）：捕获计数＋1 →「见过」（防离场形态变化）→ 若未拥有 → 拥有＋（有图鉴且物种在已解锁区域表内）提示＋最近见到＋条目页；暗影个体 → 暗影拥有。其中捕获计数/「见过」经战斗包装（内部战斗门）、拥有/最近见到/暗影拥有为**直接写入**（不经该门；接收者与门的分列见图鉴规格）。
2. **存储**（战斗侧接收入口）：
   - 昵称询问（**暗影个体跳过**）。
   - **队伍满 且 档位 ∈{询问 0、强制 2}** → 进入选择菜单：加入队伍/送入盒子/看摘要/查看队伍；**强制档**移除「送入盒子」且不可取消；询问档取消＝送盒。选择「加入队伍」→ 从队伍中挑一名成员：离场钩子 → 剧毒计数归零 → 解除 Mega/Primal → 按**当前持物**送盒、移出队伍 → **战斗记忆数组整体左移**（初始物品、战前等级、会心与直接伤害记录）。被送盒成员的还原记录随移位/删除不再作用于它：结束时的持物还原循环只对**届时仍留在队伍**的成员按还原记录恢复。两条结果分列：「还原记录 X、当前持物已为空」的合法暂时移除状态（暂时打落路径）——留队 → 结束还原 X；**先送盒 → 保持空、退出还原循环**。永久消耗可能连还原记录一起清（记录也为空时两路径都为空）；不用普通消耗冒充该前提。
   - 正常存储（对等层）：队伍有空位 → **加入队伍**并回填「初始物品」记录（返回 −1）；否则 → **盒子**（当前盒首个空位 → 扫其它盒）。**全满兜底**：储存返回 −1 后，兜底分支随即调用一个**该对等层未定义的消息方法**——在返回原盒号**之前**即失败（固定脚本中该方法只定义在战斗/场景/特定界面类，不在默认对等层，未见重开、混入或缺方法兜底；不用真实存档验证）。因此不承诺「显示『无法再捕获』并正常返回原盒」——注释里的期望不是实际行为；确实触达此前已提交的图鉴/昵称/治疗/离场等状态**不回滚**。正常菜单的双满预检（§2①）与此直接/后段触达条件分列。
   - 送盒前若「存盒时治愈」设置开（默认关）→ 治愈（保留「可进化待触发」标记）。
3. 清空队列。**没有回滚**：图鉴与统计先于存储；容量失败面在菜单前置（①②）被拦住，兜底分支按上面具名行为执行。

档位来源：战斗字段默认「不询问」(1)；实际默认流程为——「新捕获可替换队员」设置（默认开）以选项「送盒方式」写入（选项默认 0＝手动询问）；战斗规则「强制入队」覆盖为 2。

## 7. Shadow/抢夺与具名交界

- **抢夺**（本文件证明范围）：抢夺球身份（旗标或机器）；训练家战的阻挡例外（球∧暗影目标）；成功后属主改写；暗影个体：昵称跳过、图鉴暗影拥有、暗影招式更新。**完整 Shadow/Hyper 模式/净化与恢复归 Shadow 规格**（本文件不宣称完整 Shadow）。
- 不因 Shadow 规格未做而删除上述已证分支；Shadow 规格依赖本文件已成立。
- 状态/持物/招式、容量与存储实现、背包扣除、友好度、参战上下文、经验与终局、图鉴各规格——全部按各自限定通过身份引用；物品使用与获得流程、持物还原、Safari 专用路径为对照（本文件不复制其球表）。

## 8. 失败、未决与保留

- Safari 与捕虫大会的专用球路径、费用与结束不在此；其档位注入在专用战斗中为空操作（已述）。
- Shadow 完整生命周期归 Shadow 规格；本文件只固定其捕获许可与接收分支。
- 演出（球种颜色、抖动动画时长）与消息措辞属媒体/界面呈现，未逐帧复核；不据演出推导判定。
- 捕获的「失败后效果」家族为空（0 登记）：任何「失败后附加效果」均为保留区，不据官方系列补造。
