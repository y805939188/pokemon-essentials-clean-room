# 异常状态、能力阶级与免疫（净化正文；批次 7）

分类：Pokémon Rules；Combat Requirements（状态查询、提交、写回与期限合同）。本文件规定异常与能力阶级何时能施加、如何提交、何时影响行动或数值、怎样解除，以及失败后是否改变持久状态。全部内容为静态证据；**无运行确认**（见 `../scope-statement.md`）。覆盖索引：[有界效果归属表](wp44-effect-coverage.md)（阶级文件 114 个标识逐一有归属）。

## 1. 目的与范围

可见反馈包含施加/重复/免疫/解除提示、阶级变化量对应消息和连锁反馈；动画资源与实际菜单归战斗界面规格。

自身范围：A 五种持久异常及普通/同步/瞌睡查询、写入与治疗；B 混乱、着迷、畏缩、瞌睡、剧毒累计及与本文件变化直接相关的临时记录；C 七个战斗阶级的查询/基本变化/有消息提交/特性包装/直接重写；D 已定位状态招式与阶级变化有界族；E 自身计数的实际消费者、离场/濒死/战后及计算交界。

不声称所有临时标记均由本文件定义。拘束与换出资格主规则归换人规格；作用于侧/全场/位置的屏障和期限归场域规格；多回合攻击、HP 代价/恢复完整族归《多次攻击、特殊伤害与恢复》；招式/类型/特性变更与行动控制归招式变更规格；完整特性/道具家族归《特性参与计算、免疫与有效性》、阶段触发规格、《持有物计算、触发与消耗》；完整回合末总序及终局归战斗结果规格。本文件已读取的局部消费者独立给出，不把计数本身空留。

## 2. 状态域、输入输出与写回

| 概念 | 当前值域/归属 | 写入与消费 |
| --- | --- | --- |
| 持久异常 | 无、睡眠、中毒、灼伤、麻痹、冰冻；剧毒不是第六个异常标识 | 每个个体仅一份异常字段；战斗入口的指定写入同步持久个体（《HP、状态、招式与持物》引用） |
| 异常计数 | 睡眠剩余检查数；中毒 0 为普通、正数标识剧毒 | 战斗状态/计数写入分别刷新并同步个体；只改异常为睡眠/中毒不自动重置旧计数，通用施加随后明确设置 |
| 剧毒累计 | 当前场上对象的累计次数 0..16 | 不等于持久剧毒标志；每次提交异常重置为 0，普通换入也重置 |
| 混乱 | 临时正计数；0 表示未混乱 | 独立于持久异常，可与其并存；自然解除或治疗归 0 |
| 着迷 | 来源席位；−1 表示无来源 | 使用来源指向，普通换人清理与 Shift 重映射引用换人规格 |
| 畏缩 | 本轮临时真/假 | 后段行动检查失败；本轮已动后再施加不会追回已执行动作 |
| 七种阶级 | 攻击、防御、特攻、特防、速度、命中、闪避，正常范围 −6..+6；不含 HP | 只属于战斗；不写 IV/EV/性格或持久能力值 |

「视为有状态」与原始异常字段分开：绝对睡眠的考拉可在查询中视为睡眠/有异常，而原始字段可仍是无；普通治疗查原始字段，不能据此移除该特性。指定异常写入离开睡眠时重置懒惰节拍；写入非睡眠/非中毒时把持久计数归 0，离开中毒或普通中毒条件也重置剧毒累计。直接字段拷贝、初始化与正式提交不是同一接口；不按同名词推断所有写入都带消息或守卫。

输入：目标、可缺省来源、招式及是否忽略替身、是否自施、现有异常/计数/阶级、类型、有效能力/道具、场地/天气/侧保护、模式破坏者、条款、变化量与消息许可。输出：资格真/假、实际状态/变化量、持久写回、来源/计数、变更标记和提示。展示开关不是资格许可。

## 3. 异常施加的分层入口

### 3.1 普通查询与优先序

普通施加查询依次考虑以下拒绝，命中前返回；消息许可只控制相应反馈。

1. 目标濒死；同种异常重复（除显式忽略现状）；已有其它异常（除忽略现状，或来源就是目标且有招式的自施替换路径）。
2. 替身存在且招式未忽略替身、非自施。来源为空不自动视为自施。
3. 施加冰冻而目标有效天气为晴/大日照；目标受场地影响时，电场阻止睡眠，薄雾阻止所述持久异常。
4. 睡眠且场上有人吵闹：防音可豁免，但普通路径的防音会受模式破坏者影响。
5. 类型免疫：毒/钢免中毒，来源有效腐蚀可绕过这两个类型门；火免灼伤；更多类型效果开启时电免麻痹；冰免冰冻；无类型普遍免睡眠门。类型门与攻击类型相性免疫是两套规则。
6. 不可忽略的特性免疫先查；其余自身特性/盟友特性只有自施或未模式破坏时检查，先自身再盟友。不可忽略处理器入口不先要求普通能力有效性，其具体条件由该处理器决定。
7. 神秘守护：侧计数正、非自施、**有招式来源**，且来源无穿透时拒绝。不能把它泛化到所有无招式施加。

已定点核对的特性免疫输入：花幕保护草成员；免疫/粉彩护幕抗毒；不眠/甜幕/干劲抗睡眠；叶子防守在晴/大日照抗异常；柔软抗麻痹；熔岩铠甲抗冰冻；水幕/水泡抗灼伤。不可忽略门含考拉的绝对睡眠、核心形态前的小陨星界限盾壳；盟友来源含花幕、粉彩护幕、甜幕。此清单只对应已读状态免疫处理器区间，完整有效性/复制/获得失去族交《特性参与计算、免疫与有效性》、阶段触发规格。

### 3.2 同步与瞌睡到期查询

| 入口 | 保留的门 | 与普通查询的差异 |
| --- | --- | --- |
| 同步反射（毒/灼伤/麻痹） | 未濒死、原始状态为无；薄雾场地、类型、不可忽略/自身/盟友能力、神秘守护 | 不复查替身；不以模式破坏者统一跳过免疫；神秘守护不要求招式参数；有效同步且来源非自身才触发。反射提交不再传原来源，防止递归反射；剧毒标志按被同步者当前计数传递 |
| 瞌睡到期睡眠 | 原始状态为无；电/薄雾且受场地影响；防音/吵闹；不可忽略/自身/盟友免疫；神秘守护；睡眠条款 | 不是重跑普通招式查询：没有替身或来源参数，也没有普通模式破坏者对防音/能力的例外；外层计数消费者已排除濒死 |
| 睡觉 | 先以「视为睡眠」拒绝已睡；按自身、带招式、忽略现状查询睡眠；还需治疗入口允许 | 可替换其它持久异常，仍受场地/吵闹/免疫等门；满 HP 等治疗失败不强行写睡眠。提交时请求时长 3，早起仍可减半 |
| 火焰宝珠/剧毒宝珠 | 用自身作为查询来源，无招式；通过才提交 | 自施不因替身/普通神秘守护失败；类型/特性等仍适用；提交不传反射来源，不能推出会同步自己 |

条款附加门先于上述对应查询：普通睡眠条款限制非自眠，修改睡眠条款也限制自眠；瞌睡适用任一睡眠条款；冰冻条款独立。扫描的是该侧参与队伍中非蛋的原始对应状态，未额外排除濒死。闪避条款另禁止所述影子分身/变小变化招。设施完整规则交设施规格，本文件只闭合这些实际入口追加门。

### 3.3 提交、连锁与治疗

通用异常提交**不重新调用资格查询**：写异常，再写所给计数，清剧毒累计，反馈施加动画/消息，检查状态引起的形态变化，再触发有效特性的施加反应（包括同步），再检查道具治疗、特性治疗。最后若实际仍睡眠且在逆鳞类暴走，立即清暴走及当前强制招式。不能保证提交返回时状态仍等于刚施加值。

普通招式常在失败检查时做资格、效果阶段直接提交；伤害附加异常先排除替身，再在附加阶段重新查询。复合招式可对各组件分别查询，部分有效仍成功。强制直接提交或手工写字段不能凭入口名称假定带相同免疫门。

治疗异常设置无状态，经指定写入同步计数归 0 与相关重置；消息按治疗前原始状态决定。重复对无异常调用仍执行指定写入，但没有对应五种异常的解除消息。混乱治疗只清计数；着迷治疗只清指向。道具治疗检查会排除濒死及无有效持有物（显式传入道具另分支）；特性治疗要求普通有效性。治疗和先施加后立即治愈的动作不是「从未施加」，期间反应可能已发生。

## 4. 各状态的延续与清理

| 状态/记录 | 新增与延续 | 解除/边界 |
| --- | --- | --- |
| 睡眠 | 默认时长 2、3、4 等概率；显式正时长保留；早起取一半整数下界。实际走到状态后段时先减 1，≤0 醒来，仍正且非睡眠可用招则失败 | 非每回合末自动减；更早前置失败/skip 后段不减少；睡觉请求 3，不能把存储 3 直接称阻挡 3 次行动 |
| 普通中毒/剧毒 | 提交计数 0/1，剧毒累计 0；每次毒伤局部处理中，**仅中毒计数 >0 的剧毒**先将累计＋1、最多 16，再处理毒疗或间接伤害；普通中毒不推进该累计 | 普通伤害为总 HP/8 整数商；剧毒为总 HP×累计/16 整数商；毒疗改恢复总 HP/8，剧毒时累计仍已增加；魔法防守阻止间接伤害也不阻止剧毒此前的累计推进 |
| 灼伤 | 行动不自带随机阻断；物理减伤读取《战斗类型、命中与伤害计算》 | 世代 ≥7 回合末总 HP/16，否则 /8；耐热再减半四舍五入。先前毒伤局部循环在灼伤之前；实际扣 HP 入口对存活者最少扣 1 |
| 麻痹 | 后段到达其检查时，0..99 抽取 <25 阻断；速度在当前计算中减半（世代 ≥7）或除 4，飞毛腿除外 | 治疗后后续速度查询使用新状态；回合行动队列是否重算引用命令规格，不追改已执行动作 |
| 冰冻 | 后段非自融招：抽取 <20 治愈并继续，否则失败；自融招通过此门，随后在使用阶段指定时点解冻 | 不是以每回合末 20% 解冻。命中后火招或世代 ≥6 能解冻使用者的伤害招，可治愈未被替身/无效挡住的冰冻目标；相关后置阶段须实际到达 |
| 混乱 | 普通查询拒绝濒死/已混乱、非忽略替身且非自施、世代 ≥7 薄雾且受影响、我行我素（自施或未模式破坏）、非自施的神秘守护（穿透可绕过，不要求招式存在） | 提交 2..5 等概率，触发道具/特性治疗。行动后段先 −1，≤0 解除，否则世代 ≥7 抽 <33 自伤，旧世代 <50；伤害引用《战斗类型、命中与伤害计算》混乱分支；前面睡眠等已失败不会推进混乱 |
| 着迷 | 查询要求目标与来源均存活、来源存在、尚未着迷；双方非无性别且不同性别；未模式破坏时自身芳香幕/迟钝或盟友芳香幕阻止 | 查询本身没有替身/神秘守护门；招式资格和附加入口可另阻止。提交来源指向、红线可使来源再次查询并反向着迷，然后道具/特性治疗。行动后段抽 <50 阻断；治疗归 −1 |
| 畏缩 | 提交仅在有效精神力且未模式破坏时拒绝，否则记真 | 后段检查到该真值则失败并触发畏缩反馈；完整回合末尾到达时清假；不能追回目标先前已做的行动 |
| 瞌睡 | 招式先拒绝已有正计数，再做普通睡眠查询；效果只写 2，不立即写睡眠 | 存活者在对应回合末局部 −1，减到 0 才用专用瞌睡查询；到期失败仍保持 0，不延期等待条件改善 |
| 聚气/磨砺 | 聚气已有 ≥2 失败，否则设 2；磨砺设 2 | 聚气不逐回合扣，磨砺在回合末尾正值 −1；会心消费不删除聚气（《战斗类型、命中与伤害计算》定义概率）。接力保存聚气，磨砺正值重新设 2 |
| 充电/蜷缩/变小/愤怒 | 对应阶级族另写充电 2、蜷缩真、变小真；愤怒族只置标记，受对立方击中且可升时攻击＋1 | 充电在完整回合末尾 −1；后三者各有初始化清除；愤怒在攻击阶段未选择对应函数族时清除。只列这些标记的实际消费者，不宣称所有临时标记同寿命 |

普通初始化/换人非接力：七阶级归 0，混乱、聚气、磨砺等具名记录重置；接力路径保留这些已声明项，磨砺/锁定按正值重设 2，不继承持久异常到另一只。着迷、畏缩、瞌睡、剧毒累计不在该保留组；重新初始化时清自身来源，并清场上指向该席位的着迷关系。濒死正式处理先重置临时效果，再把持久异常/计数清 0；重复濒死处理不再执行整套。普通换下不会自动治愈持久异常。战后普通善后只将中毒计数归 0 等已述处理，完整治疗/变身还原按战斗上下文规格；不能误写成战后统一消除所有异常。

亲密自愈为可选局部消费者：开关开、内部战斗、玩家拥有、存活、原始状态非无、亲密档 ≥4、非 Mega 时，回合末抽取 80..99 治愈；默认关。位置在毒/灼伤处理之前，是否已治愈会改变后面的伤害条件。完整全阶段相对顺序仍由战斗结果规格负责。

## 5. 阶级资格、提交与反射

### 5.1 查询并非变化

上升查询：濒死否；唱反调有效、未忽略且未模式破坏时转查下降；否则到 +6 否，其余可。下降查询：濒死否；未模式破坏时先唱反调转上升，再镜甲条件（来源存在、非自身、目标未到 −6）可直接报可行；普通非自降才查替身、白雾（来源穿透可绕）、目标可忽略/不可忽略防降能力、盟友防降能力；最后查 −6。

因此镜甲的查询真不保证来源能被反射下降。来源缺省视为非自施降；反射用无招式且显式禁止再次镜甲的查询，替身防护可能再次适用。不得把「是否为本方」代替「是否就是同一个体」判断自降。

### 5.2 四类提交

| 层 | 作用与返回 |
| --- | --- |
| 基本变化 | 未模式破坏时先唱反调反向，再单纯双倍；按距边界剩余量夹限。实际正变化才写阶级及本轮升/降标记；下降另写「曾降档」。返回实际量；0 不改变 |
| 带消息的普通/具名原因提交 | 唱反调和镜甲在此各自分流；基本变化实际 ≤0 返回假，不播升降成功反馈；实际 1、2、≥3 分别用不同幅度提示，可关闭动画；成功后触发得到/失去阶级特性反应 |
| 特性包装 | 主动做资格查询，并根据显示设置选普通或具名原因提交；下降可额外检查接触许可。威吓另有专用前门 |
| 直接重写/交换/复制/归零 | 依本效果操作，不经过基本升降的单纯、唱反调、镜甲与普通防降门，不因此统一触发升降反应；逐项更新方向记录，见 §7 |

普通/具名原因提交**没有统一复查濒死、替身、白雾或全套免疫**；安全的正常招式/包装调用先查询。直接调用提交与经过查询的结果不能等同。本文件不为未来框架设计这种入口，只记录参考的可观测差异。正常变化量应为正整数；请求 0 时查询可能真，提交无变化返回假；负数/非法标识不作为已保证自动修复的输入。

唱反调优先于单纯/镜甲；镜甲只有来源非自身且目标未在 −6 才反射，反射成功与否由来源资格决定，目标自身不降；显式忽略镜甲防止无限来回。模式破坏者在这些**中央查询/提交**分支关闭唱反调、单纯、镜甲及可忽略防降层；不可忽略防降层仍由对应处理器处理。它不统一关闭招式层自己的镜甲预检，具体例外见 §5.3。

威吓专用：先拒绝濒死、替身（即使唱反调也挡）；世代 ≥8 的迟钝/我行我素/精神力/胆量可阻止；之后按实际显示分支做防降/白雾等和普通资格。完整威吓遍历与获得失去特性属于阶段触发规格，此处不补造额外目标。

### 5.3 多项招式自己的镜甲预检（WP44-R02）

普通多项目标降阶与毒液陷阱，在真正逐项提交前还有一层预检：目标有效镜甲且不是使用者时，查看本族计划降低的项目中，是否至少一项「目标尚未到该项下限，并且来源能通过该项下降资格（禁止再次镜甲）」。找不到就放弃整组下降；找到才进入逐项查询/提交。这层**没有模式破坏者开关门**。来源查询仍使用实际模式破坏者状态，不能凭中央反射已关闭而省略整层预检。

只有通过这层，才回到 §5.1/§5.2 中央路径；那里模式破坏者开启会跳过镜甲反射。普通单项目标降阶不带本层，不能把多项反例推广为所有降阶均失败。毒液陷阱还先要求目标属于其预选中毒集合，计划项为攻击/特攻/速度各 −1。

具名对照（双方存活、无其它拒绝、模式破坏者开、目标有效镜甲）：目标攻击/特攻 0、来源两项 −6 时，普通双项下降的目标资格可过，但本层预检失败，双方不变；来源两项改 0 则预检过，中央不反射，目标 −1/−1、来源 0/0。单项攻击 −1 对照不套此多项预检，来源即使 −6，目标仍可按中央路径降为 −1。详见测试目录 M01–M03。

## 8. 计算交界与局部期限

- 攻防、命中/闪避的倍率由《战斗类型、命中与伤害计算》单一定义，本文件只提供阶级；速度使用当前速度先乘主能力阶级并取整数商，再收集特性、道具、顺风 ×2、湿地 ÷2、麻痹 ÷2 或 4、可选徽章 ×1.1，最终四舍五入至少 1；濒死速度查询直接 1。与换人规格逃跑直接读取当前战斗副本速度不同，不能套给逃跑。
- 正常新成员建立和非接力更换阶级归 0；接力已述范围保留。特殊直接交换/复制/变身另按各自行为，不默认归 0。
- 本轮升降标志用于妒火等消费者，到完整回合末尾清除；「曾降档」可能更早因效果检查被清，不能当持久历史。HP/异常是指定写入可持久，阶级与这些临时标记不持久。
- 所有「回合末」表述仅约束到达该局部消费者时的结果；终局提前返回、所有效果完整全序由战斗结果规格闭合。本文件已定位睡眠/混乱在使用后段递减，毒/灼伤在对应残余段，瞌睡在个人计时段，磨砺/充电/畏缩在完整尾清理段，不能统一每轮同一时点减 1。

## 9. 不变量、配置与失败

当前世代 8、更多类型效果开、新会心开、亲密效果关；混乱自伤 33%、麻痹速度半、灼伤 1/16、薄雾防混乱均按其独立配置门。状态和阶级数据的显示名、动画、图标不决定施加资格；七阶级的名录来自能力项定义，HP 排除。

正常查询拒绝不改异常/阶级；直接提交可绕过查询，且施加后连锁可立即治愈。阶级「实际 0 变化」无成功升降反馈，不保证资格查询已经返回假。普通多项目标资格即使通过，也可能在无模式破坏者豁免的招式镜甲预检处整体放弃；这与中央提交是否反射分开。部分成功不回滚已改变组件。存储异常与视为异常不同；普通换下、濒死和战后不能共用「统一清理全部状态」的规则。

来源缺省、来源失能、双方性别相同、重复施加、极值、替身、场地与自施的差异均应测试；不从一个正常入口推出所有调试/插件/强制调用同样安全。条款、能力/道具完整注册族、事件可达性、真实菜单与媒体仍保留。
