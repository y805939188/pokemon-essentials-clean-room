# 世界编辑器（地图连接/地图元数据/地形标签/遭遇/指标）行为规格（净化正文；批次 15）

分类：demo-dx（主）／engine-overworld（地图/图块组/连接/小地图）／generic-kernel（GameData 持久/编译反写交界）／user-interface（可视化画布/选择器）；性质：实现独立行为规格。

本稿为净化正文的一部分：按统一交接将批准输入 WP73-B《世界编辑器》转写为独立行为文字，不含源文件路径、行号、脚本入口名与类名（源定位集中登记于 `../../audit/source-traceability.md` 批次 15 条目）。范围：地图连接可视化编辑器、地图元数据编辑器、地形标签编辑器、遭遇编辑器（集/类型/槽三层）、指标编辑器与全量自动定位、无效图块修复的输入、校验、取消、保存与反写合同；资源关联核验与无资源边界。编辑器实现是作者行为要求的参考，不作为未来编辑器的布局或交互设计模板。全部内容为静态证据；**无运行确认**（见 `../scope-statement.md`）。

## 1. 目的、范围与非目标

**目的**：固定世界编辑器的规则合同——**每个世界/资源编辑器读什么输入、坐标/地形/遭遇/指标如何校验、取消时是否仍写入、编辑何时生效（内存/`.dat`/PBS 三层）、数据与地图/图块组资源的关联如何核验、无资源时哪些操作不可确认**。后续包据此判断「某次世界编辑实际落到了哪一层、改了哪份文件」。

**范围**：1) 地图连接可视化编辑器：画布与邻居递归摆放、增删图、拖拽、连接数据生成（邻接判定与对称去重）、保存与取消。2) 地图元数据编辑器：属性框架复用与即时落盘。3) 地形标签编辑器：图块组载入、标签设置（含自动图块整组语义）、保存与宿主提示。4) 遭遇编辑器：集/类型/槽三层编辑与退出确认。5) 指标编辑器与全量自动定位：单项定位/阴影尺寸/单体自动定位/全量自动定位的算法与落盘。6) 无效图块修复（WP72 已读全文，本稿主责其合同）：全地图扫描、有效性判定、写 0 与地图文件保存。

**非目标**：不提取内容编辑器（WP73-A 主责：训练家类型/训练家战斗/道具/物种/全局与玩家元数据/地区图鉴——本稿复用其属性框架与列表器合同并引用）；不提取动画工具（WP74）、编译器全集与文件更名/转换（WP75）；不展开遭遇/地图/地形/指标的**数据语义**（WP36/WP11/WP12/WP15/WP16 主责——本稿只固定编辑行为与文件层）。不重提取已通过规则：PBS 编译/反写（WP04）。同批待审合同不展开：属性框架与列表器（WP73-A，同批待审）、GameData 三层持久（WP73-A，同批待审）、调试入口（WP72，同批待审——含归属更正：本稿为其 WP73-B 归属的主体）。不运行编辑器/编译器/反序列化、不写 PBS/.dat/地图/图块组文件、不操作真实存档、不调整宿主界面、不设计未来编辑器布局或 API。

## 2. 概念与术语

- **三层持久模型（继承 WP73-A）**：内存 DATA/运行缓存层 → `.dat` 保存层 → 编译器反写 PBS 层。本稿各编辑器的落点：**连接**＝退出确认时保存数据写 `Data/map_connections.dat`＋反写连接＋清工厂缓存；**地图元数据**＝确认即 register＋save＋反写地图元数据；**地形标签**＝退出确认时保存数据写 `Data/Tilesets.rxdata`＋替换运行图块组数据＋**重启 RMXP 提示**；**遭遇**＝退出确认时遭遇数据保存＋反写遭遇，否则重载丢弃；**指标**＝退出确认时物种指标保存＋反写物种指标，否则重载丢弃；**修复图块**＝逐图立即保存（无总确认）。
- **小地图与画布**：小地图生成入口（WP16 引用）生成每格 4 像素的地图缩略图；连接编辑器以**网格对齐（坐标向下取整到 4 的倍数）**摆放缩略图；**画布上的图只是编辑会话内的摆放**——删掉画布上的图不删连接数据本身，连接数据由**生成算法**按当前画布重算（§3.3）。
- **连接数据形态**：原始连接为**边＋坐标**形式（`[图1, 边1, 坐标1, 图2, 边2, 坐标2]`——N/S/E/W 边经地图工厂连接存取惰性装载时换算为坐标对并**过滤尺寸为 0 的无效图**）；编辑器生成的连接为**相对坐标差**形式（`[参照图, 0, 0, 目标图, dx, dy]`，dx/dy 为缩略图坐标差除以 4——即地图格数差）。
- **邻接判定（B-R01 修订）**：坐标单位为地图格（缩略图像素差 ÷4）——**x 差等于对方图宽或己方图宽取负，或 y 差等于对方图高或己方图高取负**即视为邻接（边贴边的**单轴条件**）：**不检查另一轴重叠**——错轴也可成邻接（两张 10×10 图放在像素 (0,0) 与 (40,400)：横差满足条件即成邻接，纵向并未对齐）。**逐节点回退**：仅某图没有任何直接邻接时，才回退与（非自身的）第一个画布图建立连接——**两组各有邻居时不补跨组连接，不保证全图连通**（两对各自相邻且相互远离的图可保留两个连通分量）。
- **对称去重**：新连接与既有连接**完全相同**或**镜像对称**（两端互换且坐标差取负）时不重复添加。
- **地形标签的自动图块语义**：图块 ID < 384（每行 8、每自动图块 48）时**设置整组 48 个标签**；≥384 时设置单个标签。**TILESET_START_ID＝384**。
- **指标（metrics）**：每物种×形态的显示参数——**back_sprite [x,y]**（我方背后位）、**front_sprite [x,y]**（对方正面位）、**front_sprite_altitude**、**shadow_x**、**shadow_size**（0＝无，编号对应阴影图形）；**自有阴影图形**（按物种/形态命名的阴影图）存在时 **shadow_size 不可编辑**（§6.3）。持久于物种指标数据文件。
- **底部探测（自动定位算法，B-R08 修订）**：从位图底行向上找到**首个 alpha>0 像素**所在行（全透明位图返回 0）——bottom；非负坐标公式为**向下取整的整数除法**：**y＝（位图高 − bottom − 1）÷ 2 向下取整**（正面位再＋4；例：高 32、底部行 24 → 背面 3／正面 7；全透明高 32 → 15／19）。**缺图与透明图分开**：缺图由调用方分支处理（§7.4 矩阵）；透明图按公式退化计算。写字段按单体/全量分列（§7.4）。
- **资源关联核验**：**有资源才能确认的操作**——地形标签编辑要求图块组数据可装载（编辑器直接数据装载，WP04/WP10 边界）；指标编辑的**预览**要求对应物种/形态图形存在（缺失时预览为空——**预览回落不等于全部操作安全**：单项定位/阴影尺寸按数值编辑仍可进行，**单体自动定位直接读两位图高度——缺图可失败（与全量缺图跳过分开，不以可手改数值推断全部操作可安全完成，B-R08）**）；**自有阴影图形存在时阴影尺寸编辑被拒绝**；**无资源时**小地图/预览仅显示层回落。
- **已通过边界（必须继承，不重开）**：WP04、WP11、WP12、WP15、WP36、WP16、WP59、WP61、WP53、WP37、WP65、WP67-A/B、GR-001～016、WP23-N01。**同批待审依赖（引用其合同，不作通过结论——BATCH-R03）**：WP73-A（属性框架/列表器/三层持久/选择器）、WP72（调试入口与工具归属）——**当前身份见登记清单，不沿用 v1 短哈希**。

## 3. 地图连接可视化编辑器

### 3.1 打开与画布

- **打开**：屏幕尺寸**宽高各＋288**（临界段包裹，结束后恢复原尺寸与缩放因子）；初始图：当前图（无当前图取系统编辑图 ID，再缺省 1）居中摆放并**递归摆放全部邻居**（按既有连接偏移 ×4 递归）。
- **画布元素**：每图一个缩略图精灵（网格对齐）；选中框（红色描边跟随选中图）；底部「D: Help」提示行；帮助窗（D 键——按键清单）。
- **既有连接装载**：地图工厂连接存取（惰性、含坐标换算与无效图过滤——§2）；**克隆入会话数组**（去两端完全重复项）。

### 3.2 编辑操作

- **A 键（Add map）**：地图列表（MapLister——WP73-A 引用）选图 → 居中放入画布（网格对齐）＋置顶 → **立即重算连接数据**（§3.3）。
- **S 键（Go to map）**：选图 → **先重算当前画布连接数据**（保存当前成果入会话数组）→ 清画布 → 以新图为根重新摆放（含邻居递归）。
- **DEL 键（Delete map from canvas）**：画布图数 >1 且有选中 → 从画布移除该图（**只移出画布——连接数据不因此删除**；下次重算时被移出的图不再参与）。
- **单击**：选中（红框、置顶、标题行显示图名）＋开始拖拽（**拖拽落点同样网格对齐**）；**双击（0.5 秒内）**：打开该图的**地图元数据编辑**（§4——WP73-A 属性框架复用）。
- **拖动画布空白**：记录各图位置后整体平移（网格对齐）；**方向键**：全画布 4 像素步进平移。
- **D 键**：帮助窗（USE/BACK 关闭）。

### 3.3 连接数据生成与保存

- **生成算法（B-R01/R02 修订）**：克隆会话连接数组 → **画布少于两图时直接返回克隆**（**0/1 图分支：不执行任何删除——旧连接全部保留，包括触及画布图的**，B-R02）→ 至少两图时：**删除所有触及画布图的旧连接** → 对每个画布图求**直接连接集**（对画布内每个其它图：缩略图坐标差 ÷4 后，**x 差等于对方图宽或己方图宽取负，或 y 差等于对方图高或己方图高取负**即邻接——**单轴条件、不检查另一轴重叠**；**一个都没有时才回退连接画布首个其它图**——逐节点回退、不保证全图连通）→ 逐对生成 `[参照图, 0, 0, 本图, dx, dy]`，**经对称去重**后追加。
- **保存**：BACK → **「Save changes?」确认** → 保存数据把生成结果写入 `Data/map_connections.dat`＋反写连接＋**清工厂连接缓存**＋会话数组替换为生成结果；**不确认 → 按三种状态分开（B-R03）：连接会话数组本身不序列化；遭遇数据**只重载遭遇数据**（未保存的遭遇内存改动丢弃）；**地图元数据不重载**——双击进入并已确认保存的元数据改动**保留**（连接取消不能撤销）；共享嵌套对象（如地图尺寸数组）的未保存变化**也不由遭遇重载恢复**（与 WP73-A 的 A-R04 同步——保留这个不对称现象，不补统一事务）**；随后 **「Exit from the editor?」** 确认才退出（否则回到画布）。
- **边界**：生成只覆盖**画布上的图**——不在画布上的既有连接原样保留（克隆里未触及部分）；**不校验生成连接的图是否存在/有资源**（装载期过滤由地图工厂负责，WP11 引用）。

## 4. 地图元数据编辑器

- **顶层（B-R04 修订）**：地图元数据屏入口（实参为起始地图 ID）——地图列表（MapLister，**默认不带全局项**）循环：**正常列表只返回地图**；**选图 → 地图元数据编辑（实参为该图 ID）**。**内部 0 支路（编辑全局元数据——WP73-A 全局元数据节）存在但默认调用下无此列表结果**（B-R04 v3：起始实参只用于列表预选——入口每次先打开默认不含 GLOBAL 的 MapLister，再用列表返回值覆盖实参后才检查 0；**正常地图列表返回地图 ID、取消返回负值，直接传 0 仍先进入地图选择器**）；全局元数据的正常入口是 metadata.txt 编辑器的 [GLOBAL METADATA] 项（WP73-A 对应节）；**人工替换选择器返回 0 的对照属人工注入条件，不是普通实参可达**。
- **编辑**：图名取自地图信息；元数据不存在则**先以含该图 ID 的数据实例化**；编辑属性定义 → 属性列表（保存提示——WP73-A 引用）→ **确认保存**：schema 组哈希＋保留 `pbs_file_suffix` → **register＋save＋反写地图元数据**（即时生效，无退出确认）。
- **从连接编辑器双击进入**时同此合同（保存即时；**连接编辑器取消分支只重载遭遇——不重载地图元数据、不撤销已保存的元数据改动，共享嵌套对象的未保存变化也不恢复**（§3.3 如实登记，B-R03）。

## 5. 地形标签编辑器

- **打开**：屏幕**高 ×2**（结束后恢复）；**载入图块组数据全量**（数据装载——反序列化边界，WP04/WP10 引用）；初始图块组 1。
- **显示**：每行 8 块 ×32 像素；**首行为自动图块行**（每自动图块 48 块）；覆盖层显示**非 0 标签数字**；右侧 400% 放大当前块＋标签名（地形标签数据存在则显示 `编号: 名称`，否则只显示编号）；品红衬底。
- **导航**：方向键（repeat）逐块、**JUMPUP/JUMPDOWN 半页**、ACTION 菜单（**Go to bottom／Go to top／Change tileset**——图块组列表切换）。
- **编辑（B-R05 修订）**：USE → 标签列表（**脚本注册的标签**——本基线默认注册 ID 0–17，**不是 PBS 文件**；当前标签预选）→ 写入门比较**所选序号与旧标签 ID**——**默认连续 ID 时等效**；**自定义稀疏 ID（配置夹具）时序号与 ID 错位：可能跳过或冗余写入**（夹具例：注册 ID 0、2、5，旧值 2，选序号 2 代表 ID 5——门误判无需改变，旧值仍 2；不创建/修改 reference 配置）——写入时**自动图块（ID<384）整组 48 个同写；普通块单写**；随后刷新覆盖层。
- **保存与内存（B-R06 修订——三分支）**：BACK → **「Save changes?」确认** → **保存数据把图块组数据写回 `Data/Tilesets.rxdata`＋运行侧图块组数据整体替换为会话对象**＋消息 **「为确保更改保留，请关闭并重新打开 RPG Maker XP」**（宿主数据双份语义——WP10/WP75 边界如实登记）；**「Exit from the editor?」** 确认才退出。三分支对照：①**首次未保存**（**Save No 且 Exit Yes → 会话副本丢弃、文件/运行对象不变**（此时两者是不同对象）；**Save No 且 Exit No → 继续编辑、会话保留**——两个回答分开，B-R06 v4）；②**保存退出**（文件与运行对象同更新）；③**保存后继续再放弃**（首次保存后运行对象与会话对象是**同一对象**——继续编辑两者同变；再次 No 只是不写文件，**运行内存保留新值**：标签 A→B 保存 Yes/退出 No 继续；B→C 再保存 No/退出 Yes——**文件为 B、运行内存为 C**；关闭装配地图从运行对象取图块组、**不重载该文件**）。**宿主重启提示 ≠ 立即回滚**（只提示、不撤销）。
- **关闭**：恢复地图工厂装配、玩家居中、地图场景精灵组重建。
- **资源关联**：图块组数据来自 RMXP 工程文件（Tilesets.rxdata）——**不是 PBS/.dat 游戏数据**；标签数据**由脚本注册**（硬编码数据类——WP12 地形语义引用；**无 terrain_tags.txt 来源**，B-R05）；标签 ID 与注册数据的关联**只在显示层核验**（存在才显示名称）；**未知旧值可显示数字但不等于能任意输入**（可选集合＝已注册 ID——未注册的旧值只是显示）。

## 6. 遭遇编辑器

### 6.1 集列表

- **列表**：全部遭遇集——显示 `地图ID[(v.版本)][: 图名]`（图名缺失省略）；**[Add new encounter set]** 在首。
- **新建**：地图列表（默认图）＋版本（0–999，取消 → 放弃）→ **已存在检查**（同图同版本 → 消息拒绝）→ 注册空集（step_chances/types 空）并定位光标。
- **已有项**：**Edit**（进 §6.2）／**Copy**（目标图＋新版本——已存在检查；**深拷贝 step_chances 与 types（槽数组逐项克隆）＋保留 `pbs_file_suffix`**）／**Delete**（确认 → DATA 删除）。
- **保存**：BACK → **「Save changes?」确认** → 遭遇数据保存＋反写遭遇；**否则遭遇数据重载（整体重载丢弃——含删除）**。

### 6.2 集内编辑

- **图 ID 行／版本行**：改图或改版本——**目标（图,版本）已存在检查**（冲突 → 消息）；通过则**删旧键、改字段、按新键重新登记**。
- **类型列表**：每个遭遇类型显示 `类型 (x槽数)`；**[Add new encounter type]**——未用类型列表（全用 → 消息）；新增时**步数率默认取该类型 trigger_chance**（WP36 引用）并进 §6.3。
- **类型项**：**Edit**（§6.3）／**Copy**（目标未用类型——克隆步数率与槽数组）／**Delete**（确认 → 步数率与类型槽同删）。

### 6.3 类型内编辑

- **步数率行**：0–255（默认当前）。
- **类型行**：改为另一类型（**已被本集使用的类型排除**；当前预选）——步数率与槽**整体迁移**（旧键删除）。
- **槽列表**：每槽按遭遇槽属性格式化（`概率, 名字[_形态] (Lv.a[-b])`——WP73-A 引用）；**[Add new slot]**（缺省 `[20, 首个物种, 5, 5]`）；槽项 **Edit**（属性子编辑——**最低>最高交换**）／**Copy**（克隆插入其后）／**Delete**（确认）。
- **无总确认**：§6.2/§6.3 的改动**即时写入内存遭遇数据**——最终落盘与否由 §6.1 的退出确认决定（**不确认则全部丢弃**）。

## 7. 指标编辑器与自动定位

### 7.1 编辑器框架

- **打开**：战斗背景/双方底座/消息框位图＋双方宝可梦精灵位（战斗场景成员位引用——WP40/WP16）；物种未选时精灵隐藏。
- **物种选择**：全物种×形态列表（0 形态显示名、非 0 形态 `名字 (form N)`、字母序）；**浏览即预览**（切换即时重设精灵位图与阴影）；**BACK 取消**（清选择）、**USE 选定**。
- **主菜单**（五选项，B-R07 修订）：**Set Ally Position／Set Enemy Position／Set Shadow Size／Set Shadow Position／Auto-Position Sprites**——**仅在参数编辑返回「前进」标记为真时才按（当前＋1) mod 3 前进**（模数 3 如实登记）；各项的返回分型见 §7.2/§7.3（USE 确认不前进；阴影位置的 ACTION 被排除；自动定位不触发轮转）。
- **保存**：退出——**`metricsChanged` 且「Some metrics have been edited. Save changes?」确认** → 物种指标保存＋反写物种指标；**否则物种指标重载（整体重载丢弃全部指标改动）**。

### 7.2 单项定位（参数 0/1/3）

- 选中精灵**闪烁**；信息行显示当前坐标；**LEFT/RIGHT 调 x**（三个参数均可）；**UP/DOWN 调 y**（参数 3 不可调 y——阴影只有 x）；返回分型（B-R07）：**USE 确认（有变化才置 metricsChanged）——返回后不前进**；**ACTION 确认并前进下一项——仅参数 0/1（背面/正面位置）有效；参数 3（阴影位置）的 ACTION 被排除（不结束编辑、不前进）**；**BACK 恢复旧值**（放弃）。参数 4（自动定位）见 §7.4——**执行后返回假、不触发轮转**。

### 7.3 阴影尺寸

- **自有阴影图形检查**：按物种/形态命名的阴影图任一存在 → **「该物种有自有阴影图形，shadow_size 不可编辑」消息并返回**（拒绝）。
- 否则列出可选尺寸：**0（None）＋按编号递增探测阴影图编号存在的项**（当前预选）；**浏览即改并预览**；**USE 确认／ACTION 确认并前进／BACK 恢复旧值**。

### 7.4 单体与全量自动定位

- **单体（菜单 Auto-Position Sprites，B-R08 修订）**：**直接读取两位图高度**计算 back/front 的 y（front 再＋4）——**位图缺失会失败（不保证静默保留——与全量的缺图跳过分开）**；**写入条件：任一 y 有变化或 front_sprite_altitude 非 0**——写入字段**仅 back y、front y、altitude＝0**（**x 不改、阴影不改**）并置 metricsChanged＋刷新。
- **全量（调试菜单 Auto-set pokemon_metrics——确认「确定要重定位全部精灵？」后执行）**：**遍历全部物种×形态**（每 5 秒保活界面）；每对象按字段分列（B-R08 矩阵）：**背后位图存在才写 back_sprite＝[0, 算法 y]；正面位图存在才写 front_sprite＝[0, 算法 y＋4]**（y 算法按 §2 **向下取整**、front 再＋4；**位图缺失的对应 x/y 不写——全量缺图跳过**）；**front_sprite_altitude＝0、shadow_x＝0、shadow_size＝2 仍无条件写**（**无差别覆写**——含手工调过的值）；完成后 **物种指标保存＋反写物种指标**（立即落盘，无二次确认；等待消息窗随执行显示）。
- **资源关联（B-R08 v4）**：**全量自动定位**——位图缺失的**对应 x/y** 不写（全量缺图跳过；**front_altitude/shadow_x/shadow_size 三字段仍无条件覆写**）；透明位图按 §2 **向下取整**公式退化计算（**透明 ≠ 缺图**；底部探测对全透明位图返回 0——y 退化为 （高−1)/2 的整数除法——如实登记，不虚构资源校验）。

## 8. 无效图块修复（WP72 已读全文，本稿主责合同）

- **范围**：**全部地图**（编译器地图数据——WP75 引用）的**全部图块层**与**全部事件页图形**。
- **有效性判定（B-R09 修订——三分支）**：**仅正数 1–383** 走自动图块名检查（对应自动图块名非空才有效）；**0 与至少 384 均走通行表项是否存在**（ID 0 的表项存在——**普通空图块有效：不能把合法空白地图预测为每图都被改写**；≥384 且表项缺失才判错）（图块有效性检查——tilesets 数据引用，WP04/WP12 边界）。
- **修复**：无效图块 **写 0**（事件页图形 tile_id 同）；每图计数；**有改动的图立即调用地图数据保存入口逐图保存（无总确认）**；控制台逐图列出（图 ID/名称/错误数）。
- **完成反馈**：无错误 →「No invalid tiles were found.」；有错误 → 控制台汇总＋**「RMXP data was altered. Close RMXP now to ensure changes are applied.」**＋消息「错误数 N、跨地图数 M 已修复」＋「关闭 RPG Maker XP 以应用更改」（**宿主双份语义**——WP10/WP75 边界如实登记；执行期每 5 秒保活界面）。

## 9. 默认行为与配置变体

- **配置值（WP02 引用）**：`SCREEN_WIDTH/SCREEN_HEIGHT`（连接编辑器＋288、地形编辑器 ×2）、`GrowthRate.max_level`（遭遇槽等级范围）。
- **数据文件层**：`Data/map_connections.dat`、`Data/map_metadata.dat`（经 GameData）、`Data/Tilesets.rxdata`（**RMXP 工程文件**——WP10/WP75 边界）、`Data/species_metrics.dat`、`Data/encounters.dat`（经 GameData）、地图 `Data/MapNNN.rxdata`（修复图块——WP75 边界）。
- **宿主重启语义**：地形标签与无效图块修复均提示**关闭/重开 RMXP 以应用更改**（工程文件与运行数据双份——如实登记，不虚构热同步）。
- **未验证组合**：编辑器实际运行表现、小地图/预览/战斗背景素材存在（WP15/WP16/U01）、demo 中入口默认可达性（WP77/U01）、连接生成后的实际通行表现（WP11 主责）。

## 10. 边界、失败与未知

- **取消语义汇总**：连接——BACK 确认才序列化＋清缓存（否则**遭遇重载**——§3.3 如实登记）；地图元数据——确认即落盘；地形——BACK 确认才写 Tilesets.rxdata；**未保存直接 No 且 Exit Yes 才会话丢弃（首次未保存分支）**；**保存后运行对象与会话对象同一——继续编辑后再 No 只不写文件、运行内存保留新值**（§5 三分支，B-R06）；遭遇——BACK 确认才 save＋反写（否则 load 丢弃全部含删除）；指标——退出确认才 save＋反写（否则 load 丢弃）；修复图块——**逐图立即保存**（无取消路径）。
- **拒绝/回退**：连接——**仅某图没有任何直接邻接时才回退连接画布首个其它图**（逐节点回退——两组各有邻居时不补跨组连接，B-R01）；遭遇——同（图，版本) 存在检查（新建/复制/改图/改版/改类型）、类型全用消息；指标——自有阴影图形拒绝 shadow_size 编辑；修复——无错误只提示。
- **不校验项（如实登记）**：生成连接不验证图存在性（装载层过滤）；地形标签**可选集合＝已注册 ID**（未注册的旧值只按数字显示、不能任意输入，B-R05）；指标编辑的预览对缺图仅显示层回落（除 §7.3 具名拒绝）——**但单体自动定位直接读两位图高度：缺图可失败（与全量缺图跳过分开，B-R08——不以可手改数值推断全部操作可安全完成）**；自动定位对全透明位图按向下取整公式退化计算（透明图 ≠ 缺图）。
- **异常路径（B-R08 v4）**：**预览/列表的图形装载失败仅显示层回落（精灵位图为空）；单体自动定位直接读两位图高度——缺图可失败**（不是所有图形失败都仅显示回落，§7.4）；临界段包裹连接编辑器的屏幕尺寸变更（恢复在临界段内）；**不虚构事务回滚**——逐图保存与逐对象覆写按实际登记。
- **未知/未证**：编辑器运行表现与宿主窗口行为；素材存在（WP15/U01）；demo 入口可达性（WP77/U01）；编译器地图数据读写地图的完整合同（WP75 主责——本稿只引用调用点）；连接数据的运行时消费细节（WP11 主责）。
