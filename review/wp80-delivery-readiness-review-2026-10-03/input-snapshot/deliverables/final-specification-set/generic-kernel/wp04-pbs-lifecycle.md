# PBS 生命周期（净化正文；批次 2）

分类：Demo/Developer Experience（作者工作流）；Generic Kernel（编译机制）。本文件描述作者输入（PBS 文本）到运行数据（.dat）的可见生命周期——什么时候触发编译、哪些输入被发现与如何解析校验、按什么顺序编译、产物如何生效、哪些材料会被写回/删除/覆盖、失败时可能已经发生了什么。全部内容为静态证据；**无运行确认**（见 `../scope-statement.md`）。

## 1. 目的与范围

**目的**：回答「某数据何时生效、失败可能留下什么状态」，供后续规格引用，而不追踪任何特定编译器结构。

**范围**：① 编译触发（触发条件、调试前提、新鲜度检查、异常类别与阶段）；② 输入发现、解析校验与内容依赖（普通发现、专用入口、活跃解析路径、跨内容引用）；③ 编译产物与写回行为（.dat、PBS 写回、MapInfos、地图事件、动画、反写调用者）；④ 失败与部分状态（非原子性、删除行为、异常路径、错误定位、恢复条件）；⑤ 边界与交界。

**非目标**：不提取字段的 Pokémon 语义（归领域规格）；不提取文本提取/翻译流程、编辑器行为、事件简写转换规则全集（各归相应规格）；不验证任何编译运行的真实结果；不把候选材料当作已支持变体。

## 2. 概念与术语

- **编译**：把作者文本内容转换成运行用序列化数据（.dat）的过程；本文件特指参考实现的调试模式编译检查流程。
- **写回**：编译过程中对输入或工程材料的修改（PBS 文本改写、地图事件转换、MapInfos 登记、动画映射保存）。
- **新鲜度检查**：比较数据文件与 PBS 文件的修改时间以决定是否编译。
- **普通发现 / 专用入口**：顶层自动匹配的输入与按字段显式指定的输入（如设施名单引用）。
- **活跃解析路径**：当前实际使用的文本解析/求值函数族（分词、记录求值、值转换、枚举检查及通用/专用编译函数）；相邻标注 Unused 的旧辅助函数不是现行证据。

## 3. 编译触发

### 3.1 触发条件与调试前提

编译检查**仅在调试模式执行**（非调试直接返回，不存在普通运行的自动修复）。启动顺序：核心消息 → 插件 → 编译检查 → 游戏初始化。满足任一条件即判定编译：

| 触发条件 | 行为 |
| --- | --- |
| PBS 目录缺失 | 先创建目录、从当前数据**全量反写**全部 PBS，再判定编译（注意：这些步骤发生在数据文件清单建立**之前**，见 §6 早期边界） |
| 新地图导入 | 扫描地图数据文件，未在 MapInfos 登记的地图（**ID 999 地牢图除外**）自动登记并保存 MapInfos；有导入即判定编译 |
| 必选数据文件缺失或不可读 | 判定编译（可选文件缺失不触发；必选清单见《内容身份、注册与 schema》§4.2） |
| PBS 较新 | 任一被发现的 PBS 修改时间 ≥ 全部数据文件最新修改时间即判定编译 |
| 全量编译标志或按住 Ctrl | 直接判定编译 |
| 启动提示（配置） | 调试＋无打包标记＋`PROMPT_TO_COMPILE = true` 且**用户选择肯定项**时置全量编译标志；**拒绝提示不否决随后新鲜度等自动条件** |

### 3.2 异常类别与阶段

判定后进入编译主流程。异常按类别与发生阶段分别处理：

| 异常类别/阶段 | 行为 |
| --- | --- |
| 重置/退出类异常（任意阶段） | **原样重抛**：跳过诊断、清理与通用错误转换（含按兼容类别识别的重置类异常） |
| 其他异常（清单已建立后） | 打印异常（诊断面）→ **尝试**逐文件删除数据文件（每个文件的删除错误被忽略，不保证全部删除成功）→ Hangup 转 Reset，其余转 "Unknown exception when compiling." |
| 早期失败（PBS 缺失分支，数据文件清单建立之前） | 载入/反写失败时，清理分支面对的是**尚未建立的清单**，不能沿用普通编译中失败的完整清理预期 |
| 编译前删除 | 判定编译后、编译开始前**尝试**逐文件删除全部列出数据文件（删除错误忽略）——**不保证全部删除** |

## 4. 输入发现、解析校验与内容依赖

### 4.1 输入发现

- **普通发现**：顶层文本文件按「完全基名或基名＋下划线」匹配到数据类，最长基名优先，不递归子目录（《规则配置档案》§6.1 主规格，本文件引用）。
- **专用显式入口**：设施名单的训练家/个体字段显式指定输入文件（当前样本 10 个路径，同前）；不能据普通发现不递归就断言专用路径不访问子路径。
- **被发现不等于可成功编译**：普通发现只决定输入归属；编译前改写等固定路径操作仍直接打开固定文件（如编译前改写打开固定的 moves.txt——只有 moves_extra.txt 而缺 moves.txt 时，前者可被发现，后者按固定路径打开则失败，见 §5.2）。
- **候选材料**：备份子目录不被普通发现扫描，也无自动切换机制（《规则配置档案》§6.2 主规格）；本文件不新增切换办法。

### 4.2 活跃解析路径

以下为逐行核实的**当前活跃**文本解析/求值路径；相邻多个标注 Unused 的旧 csv 辅助函数**不是现行证据**。

**分词**：按逗号拆分；对含引号的值做重组——**只有存在后续字段时才进入内部检查区**（末字段不进入）：检查区内奇数个引号时与下一个值合并重试，整值被 `\"` 包围则去除包围标记（值切片去两端各 2 字符，即两端的反斜线 U+005C 与双引号 U+0022——它们是**真实输入字符**，不是转义层的假象）；**单值也即末字段：没有后续字段时不进入检查区，初始双引号数恰为 2 时随后的补查同样被跳过，因此包围标记与反斜线原样保留**（已核反例：`\"PokeBall\"` 单值存入即带标记文本，球标志精确匹配失败）。逐值去除首尾空白；丢弃合并产生的空值。

**记录求值**：按 schema 逐值求值：

- 首字符 `*`：重复求值直至值耗尽（重复段长度 > 1 时产出子数组数组）。
- 首字符 `^`：可重复属性（多行累加；schema 长度减一）。
- **大写类型字母＝可选**：值为空/nil 时该位为 nil（如 `vevV` 的第四位）。
- `q`：非格式化文本，整条原始记录原样取用（如图鉴描述），并终止该行求值。
- 其余按类型字母经值转换求值（《内容身份、注册与 schema》§5.1 模式表：i/u/v/x/f/b/n/s/q/m/e/y）。
- 单值 schema 返回单值，否则返回值数组。

**枚举求值**分两类来源：固定规则枚举按名称解析；内容类枚举按存在性检查校验，未定义报 "Undefined value {1} in {2}." 并附位置（具体语言模块、常量反射与类名检测的实现方式见审计）。

**属性级规则（分节 → schema 消费 → 校验 → 登记全路径）**：

- **普通重复属性后值覆盖**：同一节内非 `^` 的同名属性出现多次时，**后值覆盖前值**。
- **`^` 属性累加**：标记 `^` 的属性多行出现时**累加为列表**，不覆盖。
- **通用未知属性不被消费**：通用编译循环只按 schema 列出的键求值；语法合法但不在 schema 中的属性**不会被消费，也不触发通用未知字段错误**（不因此报错）。
- **新身份定义、重复身份、未知引用分开**：
  - **新身份定义**：一个合法、此前不存在的身份可正常登记为新记录（存在性检查只拒绝**已登记**的重复身份）。
  - **重复身份**：同一身份的第二个通用节被拒绝（"used twice"）；专用入口按其各自规则（如训练家同身份后项覆盖——《内容身份、注册与 schema》§5.2）。
  - **未知引用**：引用不存在的枚举值被通用枚举路径拒绝并提供位置；不能把「新身份未存在」误当成「未知引用」。

**条目级校验**：每个数据类编译时对转换后的条目做类特定校验（如进化方法必需参数、能力值/IV/等级范围、重复处理），随后全量终检。

### 4.3 内容依赖（知识依赖，非源码加载顺序）

从 22 项编译调用与 schema 枚举引用可见的内容知识依赖。每条边按**编译解析/校验依赖**（schema 枚举引用，编译时必须有定义）、**调度先后**（仅调用顺序，不构成校验依赖）或**运行期关联**（非编译期关系）分别标注：

| 边 | 性质 |
| --- | --- |
| Type → Move | 编译解析/校验依赖（Move 的 Type 枚举） |
| Move → Item | 编译解析/校验依赖（Item 的 Move 枚举） |
| Type/Move/Item/Ability → Species → Forms | 编译解析/校验依赖（Species 的 Types/Abilities/Moves/Items 枚举，基础与形态属性集不同） |
| Species → Forms → Metrics、ShadowPokemon、RegionalDex、Encounter | 编译解析/校验依赖（形态归属、Shadow 的 Species 引用、图鉴/遭遇的物种引用） |
| TrainerType → Trainer | 编译解析/校验依赖（训练家节的类型引用） |
| TrainerType → PlayerMetadata | 编译解析/校验依赖（TrainerType 枚举） |
| Item → Metadata.StartItemStorage | 编译解析/校验依赖（StartItemStorage 的 Item 枚举列表） |
| 固定规则类 ← 多处 | 编译解析/校验依赖（GenderRatio/GrowthRate/Stat/Nature/Evolution/Weather/Environment/Target/TerrainTag 等被作者内容枚举引用） |
| Item ↔ BerryPlant | **仅运行期关联/调度先后，不是编译枚举依赖**——BerryPlant 的 schema 无 Item 枚举（节名为普通符号、其余数值），其条目/全量校验为空；运行期关联与调度注释不能写成编译校验依赖 |

**被发现输入与后续固定路径读写的交界**：普通发现决定「哪些文本被当作哪类输入」；编译前改写（§5.2）、设施名单显式读取等固定路径操作不受发现结果影响，二者分别取证，不能以前者覆盖后者。

## 5. 编译产物与写回行为

**编译会修改材料，不是只读转换。** 当前快照可见的写回面：

### 5.1 数据文件（.dat）

- 判定编译后、编译开始前：**尝试**逐文件删除全部列出数据文件（删除错误忽略，不保证全部删除）。
- 编译中逐类保存新 .dat（各编译函数末尾保存）。
- 动画映射有变化时保存 move2anim.dat 与战斗动画集。

### 5.2 PBS 文本改写（编译前）

编译前改写对两处旧属性名自动改名：trainer_types.txt 的 `VictoryME` → `VictoryBGM`，moves.txt 的 `BaseDamage` → `Power`。机制：整文件读入，有变化才整体重写并提示「Changes made to file X」。**这是固定路径操作**（见 §4.3 的交界）。

### 5.3 地图与事件转换

- 对**全部地图**的每个事件尝试：训练家注释转换（`Battle:`/`Type:`/`Name:` 等注释编译为正式训练家事件）、道具事件转换（`item:X`/`hiddenitem:X` 命名转为道具球事件；**道具不存在则跳过不转换，也不报错**）、事件名与脚本修正、计数检查；任一变化即保存该地图与 tilesets，并逐条警告「Map X was modified and saved」。
- 公共事件做修正，有变化才保存。
- 有任何修改时警告「RMXP data was altered. Close RMXP now to ensure changes are applied.」。
- 转换规则全集归事件转换规格；本文件只登记「编译会写回地图/公共事件」的事实与边界。

### 5.4 动画映射

- 读取战斗动画集（**读取失败则新建空动画集**）。
- 扫描名为 `Move:X` / `OppMove:X` 的动画，仅当招式 X 已定义时建立映射；有变化才保存 move2anim.dat 与战斗动画集。

### 5.5 反写（全量写出与通用/专用写出）

**调用者（启动触发与主动导出分开）**：

- 启动触发：PBS 目录缺失时，编译检查先载入全部数据再全量反写（§3.1）。
- 主动导出：调试菜单可直接调用全量写出或单个分步写出——菜单 UX 归调试规格，此处只登记它是真实写入调用者。

**通用写出**：按实际条目的来源后缀分组生成输出路径（无对应条目就没有该路径），写 BOM 头与 `[节名]`＋`键 = 值`（值经记录写出转换，枚举只查已有名称）。**不承诺重建或清理全部旧输入，也不承诺逐字节往返**。

**专用写出（格式不统一为「节名＋键值」）**：连接写出写行式连接数据，并跳过地图已不存在的连接；遭遇写出写遭遇节/方式/槽的专用格式。全量写出共 **22 项内容写出调用**（不含进度输出辅助）。

## 6. 失败与部分状态

**不能默认原子性或自动恢复。**

| 阶段 | 可能已发生的变化 |
| --- | --- |
| 编译前 | 尝试逐文件删除全部列出数据文件（不保证全部删除，§3.2） |
| 编译中 | 部分 .dat 已重写；PBS 可能已被改名改写（§5.2）；MapInfos 可能已登记新地图（§3.1）；地图/公共事件可能已转换保存（§5.3）；动画映射可能已保存（§5.4） |
| 异常时 | Reset/SystemExit 原样重抛（无清理）；其他异常打印后**尝试**再次删除数据文件（不保证全部删除）；Hangup 转 Reset，其余转通用错误（§3.2） |
| 早期失败（PBS 缺失分支） | 清理分支面对尚未建立的清单，完整清理预期不成立（§3.2） |
| 失败后 | 可能存在：缺失的数据文件、部分编译的 .dat、已改写的 PBS/地图/MapInfos/动画。下次调试启动时，缺失的必选文件再次触发重编译（§3.1），但**不保证**上次失败留下的部分状态被识别或修复 |

错误定位：编译错误附位置报告（文件/节/键/行号），位置数据在编译主流程开始时重置。

## 8. 默认行为与配置变体

- **基线默认**：调试模式自动检查编译；`PROMPT_TO_COMPILE = false`（启动不询问）；Ctrl 可强制；PBS 缺失自动从数据全量反写再编译。
- **支持但未默认启用**：`PROMPT_TO_COMPILE = true` 启动询问（拒绝不否决自动条件）；外部全量编译标志；调试菜单主动导出全量/分步写出。
- **配置/数据关联**：`MECHANICS_GENERATION` 与数据集的组合边界（U03）、可选 Shadow 数据的启用（U06）保持开放。
- **未验证组合**：完整失败分支、全部转换规则组合、无 PBS 往返的真实结果、插件对编译的影响（U09）。
- 参考快照行为、官方版本预期、未来目标分开标记；本文件只记录第一类。
