## 1. 目的、范围与非目标

**目的**：描述地图身份、连接关系、局部坐标/相邻地图偏移、有效边界及相邻地图选择的行为规则——玩家如何在相邻地图间移动、地图如何被加载/卸载/恢复。后续包据此判断"某位置属于哪张地图、跨图时坐标如何换算、何时触发进入/离开"，而不是各自重新追踪地图工厂。

**范围**（WP11 自身声明范围，extraction-plan 第 2.1 节 (a) 类）：

1. WP11-A：地图身份与连接关系（地图身份、连接配置、坐标/偏移规则）。
2. WP11-B：跨图转移（边缘跨图、显式传送、重新建立/恢复）。
3. WP11-C：地图生命周期（加载/卸载、邻图、进入/离开通知、更新顺序）。
4. WP11-D：地图恢复与存档交界（引用 WP09/WP10 主规格）。
5. F04-01 中属于 WP11 部分的状态更新。

**非目标**：

- 不编造真实地图宽高、可达路线或事件存在（缺失地图数据，U01）。
- 不提取地形通行/运动/载具规则（WP12 主规格）、事件/NPC/跟随规则（WP13 主规格）。
- 不提取地图绘制/渲染细节（WP16 主规格）或地图元数据字段语义（WP11 仅引用身份与连接）。
- 不运行游戏或任何参考脚本；不修改 `reference/`。

## 2. 概念与术语

- **地图身份**：地图的整数 ID（`MapNNN.rxdata` 文件名与元数据键共用）。
- **连接（connection）**：两张地图之间的一条邻接关系，含两侧的边或坐标。
- **边（edge）**：连接端点的一种表示——方向字母（N/S/E/W，分别换算为 0/高/宽/0 坐标）或显式坐标。
- **邻图**：被加载到内存、按显示偏移摆放的相邻地图；仅保留显示范围内的邻图。
- **跨图转移**：玩家走出当前地图有效范围时，按连接换算到相邻地图的对应位置并切换当前地图。
- **重新建立（setup）**：整张地图重新加载（含事件/公共事件实例重建）；恢复用 `setMapChanged`（保留已加载地图状态）。两者区别见 WP09 主规格，本文引用其分支条件。
- 影响域编号 Dxx 见 module-map；证据状态五档定义见总览第 7 节。

## 3. WP11-A：地图身份与连接关系

### 3.1 地图身份与加载（本轮核实 `004_Game_Map.rb:39–74`、`005_Game_MapFactory.rb:7–27`）

- 地图以整数 ID 标识；`Game_Map.setup(id)` 读取 `Data/Map%03d.rxdata`，装入图块集、雾/背景配置，触发 `on_game_map_setup` 通知，并创建该图的事件与公共事件实例。
- 地图工厂持有已加载地图数组与当前图索引；`map` 按索引返回当前图（索引缺失/为空时按错误处理，30–38 行）。
- 地图有效范围：`valid?(x, y)`（0 ≤ x < 宽，0 ≤ y < 高）；`validLax?`（各向外扩 10 格，用于互动判断，134–140 行）。

### 3.2 连接配置与坐标/偏移规则（本轮核实 `005_Game_MapFactory.rb:383–496`、E34 样本）

- 连接来自 `Data/map_connections.dat`（编译产物，由 `P/map_connections.txt` 编译，WP04 生命周期引用）。每条连接为 `[A图ID, A侧边或坐标, A坐标, B图ID, B侧边或坐标, B坐标]`；**边字母换算**：N/W → 0，E → 图宽，S → 图高（`getMapEdge`，467–473 行）；也可用显式坐标。两端图尺寸为 0 的连接被忽略（397–401 行）。
- 连接按两端分别索引（双向可查，`mapsConnected?`、`eachConnectionForMap`）。
- **跨图坐标换算**：A→B 方向时，目标坐标 = `(B边坐标或B连接坐标 − A边坐标或A连接坐标) + 当前坐标`（`getNewMap`，68–91 行；`getRelativePos`，227–243 行：同图直接差值、连接则偏移差值、无连接为 [0, 0]）。目标坐标须落在目标图有效范围内才转移。
- **邻图显示偏移**：邻图按 `(偏移差 × 图块像素) + 当前图显示坐标` 摆放（`setMapsInRange`，114–140 行），仅保留显示范围（约 6 格缓冲区）内的邻图。

## 4. WP11-B：跨图转移

### 4.1 边缘跨图（`setCurrentMap`，95–112 行）

玩家移动后若不在当前图有效范围（`valid?` 为假）：

1. 按连接换算目标图与坐标（3.2）；无有效目标则不转移（坐标保持当前图外状态，通行判定见 WP12）。
2. 有目标时：触发 `on_leave_map`（`setMapChanging`）→ 切换当前图与索引 → 玩家 `moveto` 目标坐标 → 当前图更新 → 过渡音乐/画面 → 触发 `on_enter_map`（`setMapChanged`）→ 天气持续重置（20）。
3. 邻图按 3.2 规则重新摆放；随后生命周期修剪（4.2）。

### 4.2 显式传送（`Scene_Map.transfer_player`，72–101 行）

- 清除传送标记；**取消载具**（可选保留游泳状态）；音乐淡入淡出按目标图自动播放差异处理；清除桥接与阴影。
- 目标图与当前图不同 → 工厂 `setup` 重新建立（整张地图重载，事件/公共事件实例重建）；玩家 `moveto` 目标坐标并按方向转身、整姿；跟随者 `map_transfer_followers`；当前图更新；精灵集销毁重建；如有转场则播放；自动播放 BGM；帧重置；输入更新。

### 4.3 重新建立与恢复（引用 WP09 主规格）

- 读档/继续时：`magic_number` 不一致或 safesave 为真 → 重新 `setup`（缺图时调试选图/取消退出、非调试报错）；两者都不成立才 `setMapChanged`（WP09 主规格，引用）。
- 地图损坏（`events` 为 nil）：抛"地图损坏，游戏无法继续"（WP09/WP10 主规格，引用）。

## 5. WP11-C：地图生命周期

### 5.1 进入/离开与更新顺序（本轮核实）

| 时机 | 顺序（调用链） |
| --- | --- |
| 场景主循环（`Scene_Map.main`） | 创建精灵集 → 转场 → 循环：画面更新 → 输入更新 → 解释器更新 → 玩家更新 → 各图更新 → 地图生命周期更新 → 系统/画面更新 →（传送中则）传送 → 精灵集更新 → 逐帧通知 →（回标题则）标记未加载并回标题 → 输入分发（互动/菜单/快捷/调试） | `002_Scene_Map.rb:165–230` |
| 跨图 | 玩家移出边界 → 连接换算 → on_leave_map → 切图 → moveto → 图更新 → 过渡 → on_enter_map → 天气重置 | 4.1 |
| 显式传送 | 取消载具 → 音乐处理 →（图不同则）setup → moveto/转身 → 跟随者转移 → 图更新 → 精灵集重建 → 转场 → BGM → 帧重置 → 输入更新 | 4.2 |
| 生命周期修剪（`updateMapsInternal`） | 先删与当前图无连接的图，再删超出显示范围的图，并重置索引 | 361–376 行 |
| 地图损坏 | `$game_map.events` 为 nil → 抛错无法继续 | `001_StartGame.rb:98–100`（WP09 引用） |

进入/离开通知（`on_enter_map`/`on_leave_map`/`on_game_map_setup`/`on_map_or_spriteset_change`）按上表时机触发，事件订阅机制见 WP05 主规格（引用）。

### 5.2 邻图加载与卸载（3.2、4.1、5.1 交叉）

- 加载：进入当前图范围或邻图范围内时按连接与显示偏移加载（`getMap`、`setMapsInRange`）。
- 卸载：与当前图无连接或超出显示范围时被删除（`updateMapsInternal`）。
- 邻图的事件/更新按各自地图实例进行（WP13 事件规则引用）。

## 6. WP11-D：地图恢复与存档交界

- 地图工厂（map_factory）是持久值（WP09 目录），随存档保存/恢复；新游戏按起始图 ID 与坐标建立。
- 读档恢复的分支条件（magic_number/safesave）按 WP09 主规格引用；本包只定义连接/转移行为。
- 存档中地图的持久状态（map_factory 内的已加载地图与玩家位置）按 WP09 登记；跨图后地图状态保留/重建按 4.1/4.2 规则。

## 7. 默认行为与配置变体

- **基线默认**：地图按 ID 加载；连接按配置建立邻接与偏移；边缘跨图自动转移；显式传送重新建立；生命周期按连接与显示范围修剪。
- **支持但未默认启用**：调试选图入口（缺图时 `$DEBUG` 下的 `pbWarpToMap`，WP09/WP10 引用）；`NO_SIGNPOSTS`（跨指定地图对不显示地点路牌，WP02 词典）。
- **配置/数据关联**：地图连接配置（`P/map_connections.txt` 作者内容，WP04 生命周期）；地图元数据（户外/天气/音乐等，归 WP15/WP59/WP67-A 引用边界）。
- **未验证组合**：真实地图宽高与可达路线（U01）、连接偏移组合的可达性、事件在邻图的行为、完整 Demo 转移流程。
- 参考快照行为、官方版本预期、未来目标分开标记；本包只记录第一类。

## 8. 边界、失败与未知

- 无连接或目标无效：不转移（玩家停在边界外状态，通行判定归 WP12）。
- 两端图尺寸为 0 的连接：被忽略（3.2）。
- 显式传送目标图缺失：按 WP09/WP10 的缺图分支（调试选图/非调试报错）。
- 地图索引缺失/为空：按工厂错误处理（30–38 行）。
- 邻图事件在跨图后的状态保留/重建：setup 重建（4.2）与 setMapChanged 保留（WP09 引用）的区别；完整行为未验证。
