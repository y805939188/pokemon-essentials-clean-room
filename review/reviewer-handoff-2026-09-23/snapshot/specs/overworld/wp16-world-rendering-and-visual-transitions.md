## 1. 目的、范围与非目标

**目的**：描述 overworld 画面必须满足的可观察规则——地图如何被绘制（图块层/自动图块/显示偏移/邻图拼接）、角色与物品如何呈现（精灵/灌木深度/反射/阴影）、天气与屏幕效果如何叠加、场景切换时哪些可见状态保持或重建。后续包据此判断"某一帧画面由什么决定、何时刷新"，而不是各自重新追踪渲染器。

**范围**（WP16 自身声明范围，extraction-plan 第 2.1 节 (a) 类）：

1. WP16-A：地图绘制（图块层、自动图块动画、显示偏移与滚动、邻图拼接、优先级/桥/反射分层）。
2. WP16-B：角色与附属精灵（角色图/图块图、图案帧、灌木深度、反射、冲浪基点、动态阴影、日夜着色）。
3. WP16-C：天气与屏幕效果（天气类型/淡入、色调/闪烁/震动、雾/全景、计时器与图片）。
4. WP16-D：场景刷新与视觉过渡（精灵集生命周期、地图切换的可见状态、转场）。
5. F05-03、F05-04 中属于 WP16 部分的状态更新。

**非目标**：

- 不验证任何实际视觉结果、动画时序或像素输出（未运行；E11 待验证项）。
- 不保留 Tilemap/Sprite 类层级或渲染管线结构；不设计未来渲染 API。
- 不重复 WP11（拓扑/偏移/传送顺序）、WP12（地形标签语义）、WP15（资源选择与缓存）的主规则——本文只引用并登记其可见结果。
- 不提取消息/窗口/输入（WP17）、战斗内画面（战斗包）。

## 2. 概念与术语

- **图块层**：地图数据的三层（0/1/2）；每个屏幕格每层一个图块精灵。
- **自动图块**：按邻接关系选型的图块（8 个标准位 + 额外自动图块），可按帧动画。
- **显示偏移**：地图显示坐标（子像素单位，WP11 引用）决定屏幕滚动；图块网格按整格滚动 + 亚格像素偏移。
- **优先级与分层**：图块按优先级决定 Z 序；桥、反射、雾、天气、画面效果各有固定分层。
- **可见状态保持**：跨图时画面连续性依赖显示偏移与邻图拼接（WP11 引用），精灵集则销毁重建（WP11 引用）。
- 影响域编号 Dxx 见 module-map；证据状态五档定义见总览第 7 节。

## 3. WP16-A：地图绘制

### 3.1 图块精灵网格与屏幕滚动（`001_TilemapRenderer.rb` 全文，本轮逐行阅读）

- 画面维护一个**屏幕图块精灵网格**（宽 = 画面宽格数 +1、高 = 画面高格数 +1，每格 3 层），多余的行/列挂在左/上边缘外；滚动时**整格列/行循环移位**（移出的一列/行重置到另一侧并标重绘），亚格部分按像素偏移摆放。
- 滚动量来自当前图显示偏移（子像素 ÷ 4 得像素，WP11 单位引用）；亚格偏移按取模计算。
- **邻图拼接**：遍历地图工厂的全部已加载图，各图按自身显示偏移投影到网格并填充图块；未被任何图覆盖的格置空（WP11 邻图摆放/修剪引用）。地图切换时若能取得相对偏移则平移网格保持连续，否则全量重绘（WP11 连接引用）。
- **图块来源**：tile_id < 8（自动图块数）×48 为自动图块（含空白 0）；其后依次为额外大自动图块、额外单图块自动图块（EXTRA_AUTOTILES 常量表，默认空），再其后为图块集普通图块（8 列）。巨型图块集（mega texture）按列重排。
- **图块属性**：地形标签决定**反射**（shows_reflections → Z = −100）与**桥**（bridge 且玩家在桥上 → Z = 0；WP12 桥状态引用）；优先级 0 → Z = 0，其余按 `行×32 + 优先级×32 + 33` 抬升。
- **桥状态变化**：玩家桥状态改变时触发全列 Z 值更新。

### 3.2 自动图块动画

- 自动图块按帧动画：帧数 = 图宽 ÷ 32（大布局自动图块减半）；帧时长默认 5/20 秒，文件名尾部 `[N]` 可改为 N/20 秒；帧推进按系统运行时长（uptime，WP06 引用）对所有同名自动图块同步。
- 自动图块帧变化只触发对应图块的源矩形更新，不做整格重绘。

### 3.3 色调与颜色叠加

- 渲染器级 tone/color 变化时应用到全部图块精灵；画面色调（$game_screen.tone）与闪烁色（$game_screen.flash_color）经视口叠加（4.1）。

## 4. WP16-B：角色与附属精灵

### 4.1 视口分层（`007_Spriteset_Map.rb`、`006_Spriteset_Global.rb`，本轮逐行阅读）

| 视口 | Z | 内容 |
| --- | --- | --- |
| viewport0 | −100 | 全景（panorama；显示偏移的一半滚动） |
| viewport1 | 0 | 地图、事件、玩家、跟随者、雾（Z=3000）、天气（+1） |
| viewport2 | 200 | 图片（1–100 号）、计时器 |
| viewport3 | 500 | 闪烁（flash） |

### 4.2 角色精灵（`003_Sprite_Character.rb` 全文，本轮逐行阅读）

- **图块图角色**（tile_id ≥ 384）：从图块集切取（多格角色按宽高）；锚点底中。
- **图形角色**：`Graphics/Characters/名称`（WP15 资源引用），4×4 帧布局——横向 4 帧图案、纵向 4 朝向；名称含 `offset` 时锚点上移；玩家图形被缓存保留（retain，WP15 引用）。
- **灌木深度**：角色处于深草时按深度做三段渐隐裁剪（图块图与图形角色分别处理）。
- **可见性**：透明标记直接控制；名称含 `regulartone` 的事件免疫日夜着色，其余户外角色按时段着色（4.4）。
- **位置**：屏幕坐标按角色实时坐标（含移动/跳跃插值）与显示偏移计算（WP11/WP12 引用）；Z 按屏幕高度与角色高度排序。
- **动画**：角色 animation_id 非 0 时播放对应动画数据并清标记（资源缺失时行为未验证）。
- **更新机会**：事件角色仅在 `should_update?` 时更新（WP13 引用），玩家每帧更新。

### 4.3 反射、冲浪基点与动态阴影（`004_Sprite_Reflection.rb`、`005_Sprite_SurfBase.rb`、`009_Sprite_DynamicShadows.rb`）

- **反射**：玩家与名称含 `reflection`（可带数值参数）的角色有反射精灵——垂直镜像、旋转 180°、上移 2 像素硬编码偏移；Z = −50（玩家再 +1）；高度：固定参数或跟随桥状态（桥上抬高）；**静水反射**（高度 > 0 时）：深水色、不透明、不受时段着色影响（TIME_SHADING 开启时直接隐藏）；**普通反射**：半透明（3/4 × 3/4 亮度色）；`ANIMATE_REFLECTIONS` 开启且地图未标 still_reflections 时按正弦摆动。
- **冲浪基点**：玩家专属临时基点图形（上下水时使用，WP12 引用其置位/清除）。
- **动态阴影**：挂接于来源角色的阴影精灵（角度范围/最大距离/不透明度参数；超出距离不显示）；传送时清理玩家阴影（WP11 引用 `playersprite.clearShadows` 调用点）。阴影的创建者与配置未穷尽（列未决）。

### 4.4 日夜着色（`003_Overworld_Time.rb:100–126`，本轮阅读）

- `TIME_SHADING` 开启且当前图为户外（outdoor_map）时，角色与地图元素按**逐小时色调表**（24 项，小时间按分钟线性插值）着色；否则色调归零。时间来源归 WP06（引用）。
- 画面级天气色调与日夜色调分别作用于不同层（天气在天气视口，角色在地图视口）。

## 5. WP16-C：天气与屏幕效果

### 5.1 天气（`001_Overworld_Weather.rb`、`012_Weather.rb`、`001_Game_Screen.rb:13–69`，本轮阅读）

- **天气类型**：注册 9 种——None、Rain、Storm、Snow、Blizzard、Sandstorm、HeavyRain、Sun、Fog；类别归并为 Rain（含 Storm/HeavyRain）/Hail（Snow/Blizzard）/Sandstorm/Sun/Fog/None；各类型登记粒子/叠层图形与色调过程；Rain 类自动浇水树果（玩法消费者，WP46 交界登记不展开）。
- **设置语义**（屏幕 `weather(type, power, duration)`）：类型经数据注册校验（WP03 引用）；强度 power → 粒子上限 = (power+1) × 6（MAX_SPRITES 60 的十分比）；duration 保存为天气淡入标记——**正 duration 启用固定阶段淡入，duration 为 0 时立即切换**（不是实际时长数值）。
- **淡入/切换**：天气对象的 fade_in 入口只在**类型变化**时被全局精灵集调用（WP16-R02，见下条）；入口内**先判"正在淡入则返回"**，再判"类型与上限均无变化则返回"，之后才看 duration——**不是任何 duration=0 请求都能立即切换**：已有过渡在途时新请求被守卫拒绝，旧目标与当前过渡继续（屏幕保留新请求，后续全局更新按类型比较重新判断，不能写成已立刻生效，也不能写成一定永久丢弃）。通过守卫后：duration > 0 按**固定阶段时序**推进（阶段按 Graphics.delta 累积，并受旧天气 time_shift 影响——旧类型为 None +2、旧类型无叠层 +1；结束另须旧粒子不再可见）：旧粒子基础阶段 **1–3**、旧色调 0–2、旧叠层 0–1、新粒子 2–4、新色调 3–5、新叠层 4–5（相对阶段，非传入 duration 的比例）；duration 非正走立即切换分支。None 类型上限归零。
- **同类型强度变化（参考快照行为，WP16-R02）**：屏幕记录的类型与上限都会更新，但全局精灵集**仅在当前天气对象的类型与屏幕类型不同**时才调用 fade_in——同类型仅改强度时，天气对象不会再次收到新上限，可见粒子上限不能据源码保证刷新（天气对象内部的"同类型同上限则返回"分支只有被调用时才有效，不是全局消费者保证）。
- **滚动跟随**：天气视口偏移跟随地图显示偏移；跨图时按相对偏移平移天气粒子保持连续（无连接偏移则归零重置，WP11 引用）。
- **地图天气**：地图元数据的天气字段驱动的设置入口（WP15/WP59 交界，登记字段存在，消费者另见 4.x 与 WP59）。

### 5.2 雾与全景

- 雾：地图 fog 字段（名称/色相/缩放/不透明度/混合/色调/滚动速度）驱动叠加层（Z=3000）；滚动速度按运行时长持续累积（WP06 引用）；参数变化时帧重置并重设。
- 全景：地图 panorama 字段（名称/色相）驱动背景层（Z=−100，半速滚动）。

### 5.3 色调、闪烁与震动（`001_Game_Screen.rb:38–69` 及更新段）

- 画面色调：start_tone_change 按游戏时间（play_time，WP06 引用）线性插值到目标色调，作用于地图视口。
- 闪烁：start_flash 颜色透明度按时长衰减到 0，作用于闪烁视口（Z=500）。
- 震动：start_shake 按 power/speed 生成周期位移（最大位移 = power × 2.5 像素），叠加在地图视口 X 偏移。
- 上述效果由事件命令启动后立即继续执行（WP13 命令矩阵 223/224/225 引用），本包只登记其可见叠加与计时来源。

### 5.4 图片与计时器

- 图片 1–100 号（战斗内 +50，WP13 引用）在 viewport2 显示；显示/移动/旋转/色调/删除按 WP13 命令矩阵引用；旋转按速度持续（233 引用）。
- 计时器精灵按系统计时器状态显示（WP13 命令 124 引用）。

## 6. WP16-D：场景刷新与视觉过渡

- **精灵集生命周期**：地图场景创建时建全景/雾/事件精灵与全局精灵集（玩家/跟随者/天气/图片/计时器）；显式传送时**销毁重建**（WP11 引用其顺序）；同图传送同样重建；边缘切图**不重建**（画面连续依赖偏移与拼接，3.1）。
- **图块集/自动图块装载**：精灵集创建时登记引用计数，销毁时减计；引用归零才释放位图（WP15 缓存引用）。
- **转场**：事件命令 221 准备过渡（按过渡名取 `Graphics/Transitions/` 资源，WP15 引用）、222 执行（`Graphics.transition`）；显式传送链中的转场由传送标记触发（WP11 引用）；实际视觉效果未运行验证。
- **帧重置**：BGM/雾/全景等变化时做画面帧重置（WP15 引用），保证切换帧状态干净（具体宿主语义未运行验证）。
- **刷新请求**：地图 need_refresh 时事件页/精灵随更新循环刷新（WP13 引用）；渲染器 refresh 标全量重绘。

## 7. 默认行为与配置变体

- **基线默认**：标准 8 自动图块（帧 5/20 秒）；EXTRA_AUTOTILES 为空；无天气（None）；雾/全景按地图字段；日夜着色按 TIME_SHADING 与户外标记；反射按地形与名称模式。
- **支持但未默认启用**：文件名 `[N]` 自定义自动图块帧时长；EXTRA_AUTOTILES 额外自动图块表；`ANIMATE_REFLECTIONS` 反射摆动；地图 still_reflections；`regulartone` 事件名免疫着色。
- **配置/数据关联**：`SCREEN_WIDTH/SCREEN_HEIGHT`（WP02 词典）；地图元数据的 fog/panorama/still_reflections/outdoor_map 字段（WP15 引用边界）；`TIME_SHADING` 与逐小时色调表（WP02/本文登记）。
- **未验证组合**：一切实际视觉结果与动画时序（未运行）；宿主 Graphics/Audio 输出；动态阴影的全部创建者。
- 参考快照行为、官方版本预期、未来目标分开标记；本包只记录第一类。

## 8. 边界、失败与未知

- 图块资源缺失：按 WP15 资源边界（解析 nil/异常按入口），画面表现为缺图（具体输出未验证）。
- 地图切换无连接偏移：网格与天气全量重绘/重置（3.1、5.1）。
- 事件精灵在 `should_update?` 为假时不更新（画面保持上一状态）。
- 反射在 TIME_SHADING 开启且为静水反射时隐藏（着色冲突的既定处理）。
- 天气类型未注册：按数据身份校验规则（WP03 引用）抛错。
- 视觉时序（帧重置、过渡、淡入）均以静态代码登记，实际帧率/表现未验证。
