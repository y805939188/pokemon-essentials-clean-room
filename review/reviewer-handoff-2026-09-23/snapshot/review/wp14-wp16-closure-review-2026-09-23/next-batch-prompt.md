## 4. 必须回答的行为问题

- **消息和基础窗口**：文本进入、分页/换行、格式及控制标记、逐字显示、快进/确认/暂停、窗口样式和显示时机。区分本地化/占位符（WP08）与显示控制；对实际支持的控制标记建立可核对目录，不只列几个样例。
- **选项**：选项来源、初始选择、取消策略、空选项/不可选项（若存在）、结果编码与回调、隐藏或重命名等已定位变体。取消不能笼统等价为 false，需核对实际入口返回值与调用者如何解释。
- **数量输入**：最小/最大值、位数、初值与默认值、增减/夹限、确认和取消。边界如初值越界、上下限相等、空内容或其他实际可表达输入须有静态场景，不依据标准组件名称猜测。
- **按键及重复输入**：按下、触发、重复、方向键和操作映射、输入更新机会与等待时钟；区分参考层定义和宿主提供行为。鼠标坐标或文字事件接口存在不等于所有界面支持鼠标或输入法。
- **文字输入**：实际入口/模式、默认内容、长度限制、删除/光标/确认/取消、允许字符与字符计数规则。涉及 Unicode 或宿主编辑能力时，能静态证明的与材料不足的分别记录，不擅自宣称全面支持。
- **状态交界**：同步弹窗、解释器等待、地图/公共事件更新、输入刷新及临时标记恢复；正常完成、取消与抛错路径分别写。资源选择和缺失沿 WP15 的具体入口引用，不能概括为所有缺失都返回 nil。

专门界面的交易、命名后的领域写入等只追踪到本包交界；完整队伍/背包/战斗 UI 仍由相应后续包承担。可读取必要消费者以证明语义，但不顺带执行其他提取包。
