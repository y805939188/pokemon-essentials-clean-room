# 给实现侧的净化交接

本候选所有行为为静态推导 **NOT_EXECUTED**，无 Ruby/框架运行证据。独立规格复审结果另见候选外 review 目录；通过后仍由协调者决定纳入正式 clean-room。

1. 逐30项绑定见 `METHOD-BINDINGS.csv`：逻辑 integer → PBS **u**，无 i/v 例外。非空输入：-1拒绝、0→0、1→1、+1拒绝、01→1、1.0/1e2/1x拒绝；大整数没有参考安全整数上限。
2. 不为进化参数擅加 level≤max、count≥1、Location引用有效、Region目录存在、Beauty≤255 等校验。未命中不等于编译拒绝；要害记录缺席与计数0不同。
3. 版本分层：发行 v21.1 `ea7b5d56…` 只消费旧复数 Evolutions；现正式规格参考 R `8c5911e4…` 也消费单数 Evolution。R 两拼写均在条目登记前拒绝必需参数缺值；非空非法整数均在全表终检拒绝。
4. v21.1 发行 tag 的基础缺参到全表转换才异常；显式形态缺参可保留缺值通过编译，这是版本特有无效输入行为。不要将它误套到 R，也不要静默批准复制此缺陷。尾逗号空位和完全缺第三位均是缺值；复数列表内侧空文本则到整数阶段拒绝。
5. `BOUNDARY-VECTORS.csv` 有2880条带版本/入口/阶段的静态期望。字段 `integer_result_decimal_text` 是十进制文本，不能先读为 Number 再对大数做等值比较。`PARAMETER_ACCEPTED` 不承诺其它字段或整次工程编译成功。
6. JS 安全整数上限只是可选实现表示域，不是原版限制。若现方案只收安全整数，需独立登记兼容差异/表示决策；本调查不改生产或封印方案，不读取实现源码。

所有交付均为净化行为/向量/定位摘要；实现者只需读上述文件与 README，无需打开原版路径。来源根、实际commit与真实SHA-256在 `SOURCES.json`，不含原版实现片段。
