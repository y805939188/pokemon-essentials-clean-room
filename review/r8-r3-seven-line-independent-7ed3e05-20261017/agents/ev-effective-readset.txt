62: 
63: 成长调用的实际位置包括：正常使用招式在结束模式破坏者标志后、动作结束/指令/舞者之前；使用前置失败可能自伤倒下的分支；火药自伤失败分支；捕获成功且开捕获经验时；入场危害倒下时；回合末具名两个成长点；特性/道具触发的替补中也可能嵌套这些路径。成长不等于战斗已经结束。
64: 
65: 成长入口先检查野生胜利音乐条件（对方全无可战斗、本方仍有），之后才因非内部战斗或经验开关关而退出。此时不分配 EV/经验，也不清待处理参与者。

68: 
69: 先按玩家队伍段顺序处理参战/分享者：每人先 EV、再经验。然后若经验全体生效，再按段顺序给其余可战斗成员，整体提示只对这一轮的首名，个别经验消息参数另控。该对手本次处理后清参与者记录，避免再次就同一登记分配；无当前合格接收者也可清记录。伙伴只影响战斗参与与胜负，不加入这份玩家本人分配循环。

79: ## 4. 战斗经验与 EV 分配
80: 
81: ### 4.1 资格与收集
82: 
83: - 前置：内部战斗 且 战内「经验开关」为真；否则整体不分配（外部战斗模式按各自流程，登记为交界）。
84: - 遍历每个已倒下或被捕获且有过参与记录的对方个体；参与计数 = 参与列表内「仍在队、未濒死、战斗席位归属一致」的成员数——该归属是战斗内的席位/训练家分队索引（同一方持有者），不是个体原拥有者字段；原拥有者仅用于 §4.2 的「外来」倍率与队伍读取（WP18 引用）。
85: - 共享列表：仅当未启用全队时收集——未濒死且「当前持有点名物品或战斗开始时持有该物品」的队员。
86: - 有参与/共享/全队任一（且计数 > 0）时，对每名参与或共享成员：先 EV 后经验（经验消息对 Shadow 抑制）；再对全队模式下其余未濒死成员补一次 EV＋经验（补发经验消息被抑制，仅显示一次「其他宝可梦也获得了经验」）。
87: - 每个对方个体处理完后清空其参与列表。
88: 
89: ### 4.2 经验计算（按实现顺序）
90: 
91: 1. 已达最大经验：只重算能力（让新 EV 生效）后返回。
92: 2. 基础量 a = 对方等级 × 对方基础经验。
93: 3. 基础分配（所有人数除法在本步各自向下取整，受均分开关影响）：
94:    - 有共享列表且本人参与／共享：有效参与数0时，每名共享者得⌊a／共享数⌋（均分开）或a（关）；有效参与数>0且均分开时，参与资格取得⌊a／(2×参与数)⌋，共享资格取得⌊a／(2×共享数)⌋，兼任者相加两个已经截断的份额，不能先合成实数再取整。均分关时，参与者得a，否则共享者得⌊a／2⌋，兼任只取a。
95:    - 仅参与、无共享：均分开取⌊a／参与数⌋，关取a。
96:    - 仅全队、未参与：⌊a／2⌋。
97:    - **基础分配结果≤0立即返回**，早于训练家加成、缩放和资格+1；没有经验消息／写入／累计经验统计。调用者此前已经分配的EV仍保留，不回滚。外层仍要求该对方有非空参与记录；有效参与数0可以由其记录中成员已濒死等产生。
98: 4. 训练家战加成：开关开启时 ×1.5（向下取整）。
99: 5. 缩放：开时先把本步入口整数经验整除5取⌊经验/5⌋，再乘实数因子((2×对方等级+10)/(本人等级+对方等级+10))^2.5，再向下取整，参与者／共享者随后+1；关时整数经验整除7取⌊经验/7⌋，无+1。÷5前的截断不能推迟到因子乘完之后。
100: 6. 外来加成：判据 = 拥有者 ID ≠ 玩家 ID，或（拥有者语言非 0 且 ≠ 玩家语言）；倍率二选一——语言非 0 且不同 → ×1.7；否则若 ID 不同 → ×1.5；语言为 0（未知）不产生语言加成；均为向下取整（不是先 1.5 再 1.7）。
101: 7. 经验护符：检查背包（而非个体持有）→ ×3/2（向下取整）。
102: 8. 持有效果修正：向「当前持有物」查询修正值，返回负值（无物品/无相应处理器）时才回退战斗开始时持有物（有效但无处理器的物品同样走回退）；修正接口归 WP50。
103: 9. 亲密度加成（效果开且内部战斗且亲密度≥4且未Mega）：取⌊此前整数经验×6/5⌋，并置加成消息标志。每项倍率使用上一项已截断结果；经验护符⌊×3/2⌋，默认幸运蛋修正亦⌊×3/2⌋，顺序仍为护符→持物→亲密度，不合并倍率。
104: 10. 经验钳制加法得终值；实际增量 ≤ 0 → 结束（无消息、无写入）。
105: 11. 消息：「获得 N 点经验」或加成版；然后升级循环（§4.3）。
106: 12. Shadow 例外（追到实际写入者，逐字登记）：先按最大经验钳制得到实际增量；心阶段 ≤ 3 → 写入经 Shadow 的「经验赋值」覆盖——暂存经验 += 实际增量、当前经验保持不变，统计同样按实际增量累加，随后返回（不走升级循环）；心阶段 > 3 → 该分支不增加任何经验、不累加统计。完整 Shadow 生命周期（解禁/净化/折算）归 WP23 前向。

108: ### 4.3 升级循环（多级；逐级推进）
109: 
110: - 计算新等级（经验 → 等级）；若新等级小于当前等级 → 报错（不应发生）。
111: - 统计「累计获得经验」。
112: - 逐级循环：按等级边界写经验并播经验条动画；到达终点（多级已走完）→ 重算能力、刷新，结束。
113: - 每升一级：等级 +1 →（若该成员当前在场上）友好度 +「升级」增量 → 重算能力 →「升到了 Lv.N！」消息与升一级演出（前后六项数值）→ 学习该等级的招式（逐个经战斗版学习入口）。
114: - 备注：友好度「升级」变化只发生在当前在场上的成员（未上场者是经验到手但无该变化）；招式学习消息与形态复检（招式集变化后）见 §6。
