## 1. 目的、范围与非目标

**目的**：描述"数据内容 → 媒体资源"的匹配规则（物种/形态/性别/闪光/暗影、训练家/套装、道具/机器）、资源访问层的行为（路径解析、缓存、缺失归一）与音频层的行为（四类音频、切换/暂停/恢复/记忆、地图自动播放、叫声）。后续包据此判断"某内容应显示/播放什么、缺失时发生什么"，而不是各自重新追踪资源解析。

**范围**（WP15 自身声明范围，extraction-plan 第 2.1 节 (a) 类）：

1. WP15-A：资源身份与路径解析（图像/音频/数据文件的查找与候选扩展名）。
2. WP15-B：内容到资源的变体选择与回退（物种图鉴/战斗图/图标/脚印/影子/蛋、训练家图、道具图标）。
3. WP15-C：缓存与位图访问（缓存键、引用计数、缺失处理）。
4. WP15-D：音频行为（BGM/BGS/ME/SE 播放/停止/淡出、暂停/恢复/记忆、地图自动播放与夜间变体、叫声、系统音效）。
5. F02-04、F05-01、F05-02 中属于 WP15 部分的状态更新。

**非目标**：

- 不承诺任何具体媒体文件存在或可播放（资源缺口，U01）；目录命中不等于完整支持。
- 不提取地图绘制/精灵渲染（WP16 主规格）、消息/窗口/输入（WP17）、HTTP/文件层失败归一（WP07 主规格，本文引用）。
- 不提取战斗内音频/图形的特殊规则（战斗包交界，本文只登记共享入口）。
- 不运行游戏或任何参考脚本；不修改 `reference/`；不设计资源目录组织或渲染架构。

## 2. 概念与术语

- **资源解析**：把逻辑路径（可缺扩展名）解析为实际文件路径；图像候选扩展名为 .png/.gif（其余被注释），音频候选为 .wav/.ogg/.mp3/.midi/.mid/.wma。
- **变体回退**：按内容属性（形态/性别/闪光/暗影）逐位降格查找，直到命中存在的文件或穷尽。
- **播放状态**：系统记录的"正在播放的 BGM/BGS"（含暂停位置），与实际音频输出分开——文件缺失时状态可登记但不发声。
- **夜间变体**：地图 BGM 在夜晚优先使用 `名称_n`（存在时）。
- 影响域编号 Dxx 见 module-map；证据状态五档定义见总览第 7 节。

## 3. WP15-A：资源身份与路径解析（`001_FileTests.rb` 全文，本轮逐行阅读）

### 3.1 解析层规则

- **图像解析（pbResolveBitmap）**：输入路径去图像扩展名后，在各搜索路径下依次尝试 .png、.gif（.jpg/.jpeg/.bmp 被注释停用）；全部未命中返回 **nil**（`pbBitmapName` 则回退返回原输入）。
- **音频存在性（FileTest.audio_exist?）**：候选扩展名 .wav/.ogg/.mp3/.midi/.mid/.wma；SE 解析（pbResolveAudioSE）固定查 `Audio/SE/` 前缀，未命中返回 nil。
- **搜索路径（RTP）**：绝对路径直接使用；相对路径沿 RTP 搜索路径（当前实现仅 `./`）；加密包（Game.rgssad）经数据层加载检查（WP07 引用）。存档目录按宿主系统数据目录（`System.data_directory`，WP09 引用）。
- **数据文件存在性（pbRgssExists?）**：有加密包时以首字节读取为准，否则规范化路径后查文件系统。
- **失败归一**：资源解析层失败返回 nil（不抛异常）；文件字节读取层的失败归一（nil/空结果）按 WP07 主规格（引用，不重复）。

### 3.2 与内容身份的衔接

- 资源文件名以内容的**符号 ID 字符串**为基名（如物种 ID、训练家类型 ID、道具 ID）；内容身份的查找/回退规则归 WP03，本文只登记"身份 → 文件名"的映射与降格。

## 4. WP15-B：内容到资源的变体选择与回退

### 4.1 物种图像（`009_Species_files.rb` 全文，本轮逐行阅读）

**通用降格（战斗图前/后、图标）**：候选因素按位降格——**闪光（子目录 `shiny/` ↔ 普通子目录）→ 暗影（`_shadow` ↔ 无）→ 性别（`_female` ↔ 无）→ 形态（`_形态号` ↔ 无）→ 物种（物种 ID ↔ `000`）**。按上述优先级逐项尝试所有组合（最多 32 种），返回第一个存在的文件；全部未命中返回 **nil**（位图入口随之返回 nil）。

| 资源 | 路径基 | 回退链 |
| --- | --- | --- |
| 战斗图（前/后） | `Graphics/Pokemon/Front\|Back/` | 通用降格（含闪光子目录）；nil 兜底 |
| 图标 | `Graphics/Pokemon/Icons/` | 通用降格；nil 兜底 |
| 蛋图/蛋壳裂纹/蛋图标 | `Graphics/Pokemon/Eggs/` | 形态 → 物种 → `000`/`000_cracks`/`000_icon`（**固定兜底，不回 nil**） |
| 脚印 | `Graphics/Pokemon/Footprints/` | 形态 → 物种；nil 兜底 |
| 影子 | `Graphics/Pokemon/Shadow/` | 形态 → 物种 → **按物种指标的 shadow_size 通用影子（`Shadow/N`）** |

- **形态前提按入口拆分**（WP15-R01 修订）：**前图/后图/图标入口没有形态数据前置**——通用降格直接组合候选路径查找，未登记形态但基础物种图存在时仍可命中（候选穷尽才回 nil）。**蛋、脚印、影子、叫声入口先按（物种, 形态）取形态数据**（WP03 引用）：形态数据缺失时——蛋类回退 `000` 固定兜底，脚印/影子/叫声返回 nil。
- **个体入口**：按个体的物种/形态/性别/闪光/暗影状态取图；物种登记了 alterBitmap 回调时对位图再做个体级修改（WP21 交界，登记入口不展开）。
- **位图访问**：战斗图/图标经动画位图访问层（AnimatedBitmap；图标取图后去动画），文件缺失返回 nil。

### 4.2 训练家图像（`014_TrainerType.rb:60–95`，本轮阅读）

| 资源 | 路径与回退 |
| --- | --- |
| 角色图（charset） | `Graphics/Characters/trainer_类型ID`；不存在返回 nil |
| 战斗前图 | `Graphics/Trainers/类型ID`；玩家版加 `_套装号` 后缀——**先查带套装后缀，未命中回退无后缀**（check_file 的逐候选语义） |
| 战斗后图 | `Graphics/Trainers/类型ID_back`（玩家版先查 `_套装号_back`） |
| 城镇地图图标 | `Graphics/UI/Town Map/player_类型ID`（玩家版先查套装后缀） |

### 4.3 道具图标（`006_Item.rb:74–107`，本轮阅读）

- 空输入 → `Graphics/Items/back`；未知道具 → `Graphics/Items/000`（**固定兜底**）。
- 常规：`Graphics/Items/道具ID`，未命中时——机器类（HM/TM/TR）按 `machine_hm|machine_tr|machine_招式类型` 再按 `machine_招式类型`（非 TM）降格；最终回退 `Graphics/Items/000`。
- 队伍持有图标：邮件按 `icon_mail_道具ID`、其他按 `icon_item_道具ID`（`Graphics/UI/Party/`），未命中回退 `icon_mail`/`icon_item` 通用图。

## 5. WP15-C：缓存与位图访问（`001_RPG_Cache.rb` 全文，本轮逐行阅读）

- **缓存键**：路径（+色相）为键的进程内位图缓存；命中且未被释放则复用并增引用计数。
- **引用计数**：位图包装按引用计数释放——dispose 减计数，计数归零且非"永不释放"才真正释放；copy 得新计数 1；`retain` 标记永不释放。
- **空文件名**：返回 32×32 空白位图（不读盘）。
- **图块切取**：图块集图块按 (文件, tile_id, 色相, 宽, 高) 为键缓存切片。
- **缓存清空**：场景切换时由宿主缓存层整体清理（WP11 精灵集重建处的 `RPG::Cache.clear` 调用点，引用）；本包不规定淘汰策略。
- **失败边界**：缓存层不新增失败语义——文件缺失的异常/空白结果取决于访问入口（WP07 文件层归一引用）；动画位图访问层对缺失文件按加载结果返回 nil 或抛出（未逐入口验证，列未决）。

## 6. WP15-D：音频行为

### 6.1 播放入口与失败边界（`002_Audio_Play.rb` 全文、`002_Game_System.rb:44–250`，本轮逐行阅读）

- **参数解析**：字符串支持 `文件名`、`文件名:音量`、`文件名:音量:音调` 三种形式，默认音量/音调 100；RPG::AudioFile 直接可用；音量/音调参数可覆盖。
- **调用链**：`pbBGMPlay/pbMEPlay/pbBGSPlay/pbSEPlay` → 系统层（`$game_system`）→ 兼容层（RPG::BGM 等）→ 宿主 Audio 直接调用，逐级回退。
- **实际播放前提**：系统层在文件**存在**（`Audio/BGM|ME|BGS|SE/名称` 经音频存在性检查）时才实际发声；**文件缺失时 BGM/BGS 的播放状态仍被登记**（playing_bgm/playing_bgs 记录请求的对象克隆），但不产生音频输出。SE/ME 缺失时不播（SE 不登记状态）。
- **音量缩放**：BGM/ME 按玩家选项 `bgmvolume`、BGS/SE 按 `sevolume` 百分比缩放（WP02/选项数据引用）。
- **默认 BGM 覆盖**：设置了 `@defaultBGM` 时一切 BGM 请求改播默认曲（状态登记仍按请求）。
- **帧重置**：BGM/BGS/ME 播放或停止后做画面帧重置。

### 6.2 切换、暂停/恢复与记忆

| 行为 | 规则 |
| --- | --- |
| 停止/淡出 | `pbBGMFade/pbBGSStop(time)`：time > 0 走系统淡出（毫秒换算），否则立即停止；淡出/停止清空播放状态（暂停中除外，见下） |
| 暂停 | `bgm_pause(fadetime)`：记录当前播放位置（host 查询失败按 0），可带淡出；暂停中随后的播放/停止/淡出**不改写已记位置** |
| 恢复 | `bgm_resume(bgm)`：从记录位置继续播放并清暂停标记 |
| 记忆/回播 | `bgm_memorize/bgs_memorize` 记录当前播放对象（克隆），`bgm_restore/bgs_restore` 回播（WP13 命令 247/248 引用） |
| BGS 暂停/恢复 | `bgs_pause/bgs_resume` 按暂停标记重播（不记位置） |
| 提示切换（pbCueBGM） | 目标与当前不同（名称或音调）→ 淡出当前 + 延迟提示新曲（延迟为淡出时长的 0.6 倍，uptime 计时，WP06 引用）；相同则直接播放 |

### 6.3 地图自动播放与夜间变体（`004_Game_Map.rb:108–135`、`002_Scene_Map.rb:56–70`、`001_Overworld.rb:403–435`）

- **自动播放**：地图元数据 `autoplay_bgm/autoplay_bgs` 为真时按地图 BGM/BGS 播放；两种入口——`autoplay`（直接播放，读档恢复用）与 `autoplayAsCue`（提示切换，转移用，WP11 引用其调用点）。
- **夜间变体**：夜晚且 `Audio/BGM/名称_n` 存在时改用 `名称_n`（WP06 时间来源引用）。
- **传送淡出**（autofade）：传送时若新旧地图 BGM（含夜间变体）不同名则淡出 0.8 秒；BGS 不同名同样淡出（WP11 引用其时机）。
- **冲浪 BGM**：转移自动播放时，冲浪中且元数据登记 surf_BGM 则改播冲浪曲（WP12 状态引用）。

### 6.4 叫声与系统音效（`009_Species_files.rb:183–244`、`002_Audio_Play.rb:237–278`）

- **物种叫声**：`Cries/物种ID[_形态][后缀]`（`Audio/SE/Cries/` 下）；形态未命中回退物种，再未命中返回 nil（不播放）；蛋不播放。叫声时长按文件实际时长 ÷ 音调缩放估算（ogg 解析；非 ogg 或无页返回 −1 路径）。播放失败被 rescue 吞掉（不传播）。
- **系统音效**：光标/决定/取消/蜂鸣优先用系统数据登记的 SE（`$data_system`），未登记且默认文件名（`GUI sel cursor` 等）存在时用默认文件（音量 80）；关闭菜单音仅按默认文件存在与否。

## 7. 默认行为与配置变体

- **基线默认**：图像候选 .png/.gif；音频候选六种扩展名；物种图像按 4.1 降格；道具/蛋有固定兜底图；BGM 按地图自动播放（含夜间变体）；音量按玩家选项缩放。
- **支持但未默认启用**：物种 alterBitmap 个体级图像修改（WP21）；默认 BGM 覆盖；系统数据登记的 UI 音效；邮件专用图标。
- **配置/数据关联**：`SPEECH_WINDOWSKINS`（WP13 命令 131 引用）；`bgmvolume/sevolume` 玩家选项；地图元数据 BGM/BGS/autoplay 字段与全局元数据 surf_BGM/bicycle_BGM（WP12 引用）；系统数据的四种 UI SE。
- **未验证组合**：任何具体媒体文件的存在与播放结果（U01）；动画位图在各缺失路径的行为；宿主 Audio 的实际输出（MKXP 宿主，E11 待验证项引用）。
- 参考快照行为、官方版本预期、未来目标分开标记；本包只记录第一类。

## 8. 边界、失败与未知

- 图像解析全未命中 → nil（位图入口 nil）；`pbBitmapName` 回退原输入。
- 形态数据缺失：**仅约束蛋/脚印/影子/叫声入口**（蛋回退 `000` 固定兜底，脚印/影子/叫声 nil）；**前/后图/图标入口不受此前提限制**（按候选路径继续查找，穷尽才 nil）。
- 道具图标未知 → `Graphics/Items/000`；空输入 → `Graphics/Items/back`。
- 音频文件缺失：BGM/BGS 状态登记但不发声；SE/ME 不播；叫声 nil 不播；叫声播放异常被吞。
- 暂停位置查询失败按 0 记录；恢复时从头播放该位置之前的内容不可考（静态）。
- 空文件名的缓存位图为 32×32 空白。
- 动画位图访问层在缺失/损坏文件上的行为（未逐入口验证）。
