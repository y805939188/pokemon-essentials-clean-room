# 隔离验证预先声明

目的：用原参考函数区分翻译重复键/重复节是拒绝、替换整节还是逐项合并；区分普通占位参数是否逐字插入。只验证选定纯文本路径，不验证宿主、UI、全量编译、默认语料或文件导出。

计划命令：`ruby validation/reference-probe.rb`，工作目录为本 M01；Ruby 2.6.10p210（2022-04-12，universal.arm64e-darwin25）。Python 3.14.0 仅记录命令、版本、时间、退出码与 JSON 输出。

加载固定 R 的 `Data/Scripts/021_Compiler/001_Compiler.rb` 和 `Data/Scripts/001_Technical/003_Intl_Messages.rb`，直接调用其中已定义函数，不复制函数实现，不执行 Compiler.main、Translator.compile_text 或任何宿主入口。辅助桩仅提供 nil/空判断和常量查询；不覆写被测编译、归一、查找、占位函数。短夹具不到画面更新阈值，不提供图形或存档桩。

输入：本目录内自建的非地图 24 号文本域夹具，分别为互异键、同键、空白归一碰撞、同形态重复节、稀疏数组同索引和异形态重复节。占位以无当前译文的原文 `X{1}Y` 为输入，普通值 Q 对照两个真实字符 U+005C/U+0026，以及 U+005C/U+0031。地图对应入口另以地图 5 检查；格式化入口以字符串格式作对照。

可区分输出：逐项合并时早节独有键保留而冲突键取后值；归一碰撞只剩一个规范键；形态冲突可异常而不回滚已装入前节；占位参数若受替换表达式解释则反斜线特殊组合不以原字面保留。

副作用：仅在 `M01/validation/` 创建自制输入和 JSON 结果，在当前进程建立数据对象。原参考以绝对路径读取；不写 reference、正式规格、存档或消息 .dat，不访问网络，不使用账户。异常由夹具捕获成结果记录，不把它改成参考成功。
