  145 ### 4.2 数据输入与约束（三层分开）
  146 
  147 - **PBS 文本**：地图元数据字段 `Weather = <天气id>,<概率>`；天气 id 必须存在；概率按「正整数或 0」格式校验——**编译器不设上限**（>100 语义＝恒真）。
  148 - **编辑器**：属性选择器**可**选 :None、也**可**取消——**两者的属性设置都返回 nil**（编辑缓冲值变为 nil、以「-」展示）；概率为 0–100 的数字选择。该 nil 只是**编辑值**：仅当属性列表最终由**外层保存**路径提交时，才用编辑缓冲重建并登记地图元数据；外层不保存（取消属性列表）→ 原记录保留。因此「选 None」并保存后等价于**清除该字段**（无天气），**不是「保留原值」**。
  149 - **运行时判定**：进入地图时以 0–99 抽样 < 概率才采用该天气，否则保持 :None——概率 0 → 不可能；100 → 必中；缺失字段 → :None。
  150 
  151 ### 4.3 应用管线（进入地图时）
  152 
  153 1. 仅在**旧地图存在且与当前不同**（真实转移）时触发；同图刷新不重掷。
  154 2. 默认新天气＝:None；若当前地图元数据有天气且以 0–99 抽样 < 概率 → 取该类型。
  155 3. **与当前世界天气类型相同则跳过**（不产生渐入/重置；同类型仅改强度不会经显示层刷新，见 §4.5）。
  156 4. 否则局部写类型、power9（强度60）、duration0。真实连接边缘跨图在进入通知后另写duration20，显示后读正值并选择既有固定渐变；显式跨图转移重建显示且无这次连接后写时保持0。因此局部0不等于任意换图最终立即。正在渐变时守卫阻止打断，类型相同/旧图0等跳过门保留；20不是20秒。
  157 - 天气意图（类型/强度/时长）只存在于屏幕状态；显示层每帧只在意图**类型** ≠ 显示类型时启动渐入——**意图强度/参数的单独变化不会触发该显示刷新**。
  158 - **无自动过期**：世界天气一旦设定，**没有计时器使其自行结束**；改变只能来自下一次转移（重掷）或事件命令（§4.4）。
  159 
  160 ### 4.4 事件命令入口
  161 
  162 - 解释器命令 236（设定天气效果）：参数＝（类型, power, duration）→ 直接写天气意图；power 0–9 映射意图强度 `(p＋1)×6`（6–60）。**duration 的语义按消费者实际行为登记**：`＝0` 走立即切换；**正数只用于「选择渐入路径」**——正值大小**不参与**渐入计时（渐入按显示层的固定分段时间线推进，§4.5），**名义结束阈值与 duration 数值无关**（None→非 None 对照下名义约 3 秒）。命令可在任意地图使用、不看元数据、不重掷概率（事件责任）。
  163 - 调试菜单可读写战斗天气（战斗环境规格；与本节世界天气不同源）。

  165 ### 4.5 显示层（行为摘要，非渲染实现）
  166 
  167 - **渐入由类型差异触发**：仅当意图类型 ≠ 显示类型才渐入；同一类型仅改意图强度时该路径不被调用，**显示强度不随之更新**（静态边界；不对 0/9 做算术映射代替消费者效果）。
  168 - **固定分段时间线**：渐入按固定分界常量推进（旧平铺淡出→旧色调段→旧粒子衰减→新粒子/新色调/新平铺的固定先后），**正值 duration 不改变各段长度**；渐入**结束还要求旧粒子全部不可见**（等待旧粒子自然消亡），「名义结束时间」以分段常量与起始天气偏移（0/1/2 段）推算——None→非 None 对照下名义约 3 秒；实际帧边界保留（运行未决）。
  169 - 每帧：粒子系统上限 60；粒子按数据速率移动、出界重置（雨/雪按方向从屏幕右/上重生）；平铺层在旧色调段后换层且随摄像机原点滚动（跨地图连接有偏移）；雨的水花索引特殊。
  170 - 风暴闪光、太阳脉冲、雪摆动和水花按§4.1参数与特殊更新；雾只覆盖平铺层，既有固定渐变阶段保持。
  171 - 世界天气显示随地图摄像机坐标更新偏移；不规定实例数或对象归属。

  229 ### 5.4 返回值、异常与取消（分阶段登记；不给统一全域保证）
  230 
  231 **返回值形式（静态分类）**：
  232 
  233 1. **显式布尔**：直接工具（砍树/潜水/冲浪/力量/头槌/碎石/瀑布/飞行检查）在资格失败/取消/拒绝路径返回 `false`，正常执行路径返回 `true`。
  234 2. **无值（nil）**：甜味在**世界天气 ≠ :None** 时**无值返回**（阻塞分支没有返回值）；正常无遭遇时以消息结束、亦无显式布尔。
  235 3. **内部末值（非固定布尔）**：**HEADBUTT的界面效果不保证固定布尔返回**，其返回即回调最后表达式的值（随分支可能是消息调用结果或统计数值等）；**SWEETSCENT的界面效果固定返回 `true`**（即使内部被天气阻挡）；**FLY 执行响应在目的地原本存在且内部工具正常返回时忽略该返回值**（外层仍 `true`）；异常不属于正常返回，不能据此补造外层 true。入口直接传递效果返回结果。
  236 4. **异常**：**HEADBUTT 摇树效果在「执行时再次取面向事件仍为空」时直接访问其坐标——抛异常**，没有安全失败消息；此前统计可能已＋1。
