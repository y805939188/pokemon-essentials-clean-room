It seeks the stream to zero through 692cc0, invokes the service +0x08 initial parser, then accepts the reported scaler types 0xa56b6264, 0x74727565, 0xa56c7374, 0x00010000 or 0x00020000. Other types return 2. It sets face flag 0x800. Negative face index returns after the initial parser/type guard. Otherwise service +0x10 performs the next initialization and its error propagates.

The initializer then checks complete family-name rules and three-table fingerprints to set flag 0x2000. A leading six-uppercase-letter plus-sign subset prefix can be skipped for the name test. Every one of twenty fixed 20-byte patterns is considered by the called string-search helper: cpop, DFGirl-W6-WIN-BF, DFGothic-EB, DFGyoSho-Lt, DFHei, DFHSGothic-W5, DFHSMincho-W3, DFHSMincho-W7, DFKaiSho-SB, DFKaiShu, DFKai-SB, DFMing, DLC, HuaTianKaiTi?, HuaTianSongTi?, Ming(for ISO10646), MingLiU, MingMedium, PMingLiU, MingLi43. Without a name match, it visits the entire SFNT table directory, marking the presence of cvt, fpgm and prep. It considers all 31 fixed fingerprint rows, each containing checksum/length for those three tables. Matching length is required first; when needed it seeks/reads complete table content and computes a 32-bit sum of four-byte words with trailing bytes shifted into high-order positions. Read failures do not become successful matching checksums. Absent tables can match only their zero-length components. A row counter reaching three sets flag 0x2000. All 31 rows, including their six exact integers, are retained in native-font-driver-contribution.json and were read. This is actual program predicate data, not a hash substitute for reading font programs. It does not certify the service's runtime field population.

The routine requests hdmx through face +0x2a0. A successfully found table longer than seven bytes is read through 692ec0; its big-endian record count must be 1..255, and normalized record size must equal the rounded glyph-count-based stride. It allocates a pointer array, records only records fitting the actual table end, sorts those pointers through 80b218/699f20, and stores table length/count/stride. Invalid/unsupported header shape releases the reached frame and zeroes table count. Allocation/read errors follow their explicit return paths; this is not a universal malformed-font acceptance claim.

When the tested face flags or incremental interface require glyph processing, absence of incremental data causes glyf lookup and location handling. Missing-table low byte 0x8e is treated specially by setting glyf length zero; other errors propagate. A loca lookup failure returns 0x90. The loca length is capped according to short/long format to 0x20000/0x40000, derives count by shifting by 1/2, and compares it with glyph count plus one. If too short it examines following table offsets or stream remainder; sufficient room extends the requested frame/count, otherwise glyph count is reduced to the available count minus one. It then reads the frame and propagates the specified read results. This is the complete local range policy; downstream frame/stream helpers remain OPEN.

It calls 69bd80, accepting zero or low byte 0x8e at the written gate, then separately looks up and reads all fpgm and prep bytes into face +0x3b8/+0x3c8 with their +0x3b0/+0x3c0 lengths. Missing lookup clears that program pointer/length; the frame-read low byte 0x8e is tolerated at those explicit sites, while other errors return. The program bytes are requested/stored here, not interpreted by this function. Later fixed-strike/loca logic counts nonempty glyphs through 699e30; a single nonempty glyph at index zero, or another single glyph whose queried name equals exact ".notdef", can clear scalable flag 1. Other counts preserve it.

If the high face-index component and face flag 0x100 require it, 6a1bd0 runs and errors propagate, then 6a6630 is requested.
