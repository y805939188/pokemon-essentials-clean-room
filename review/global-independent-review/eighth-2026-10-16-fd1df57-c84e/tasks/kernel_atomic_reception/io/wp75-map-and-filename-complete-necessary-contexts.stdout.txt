## 9. 文本命令规范化（D-2；Show Text 处理；R11 修订）

按源内实际先后次序执行四个子规则（组合删除范围见 §9.1，不承诺全内容保留）：

1. **格式码规范化**：仅当**行首为反斜杠且码后随空白**才处理——`\B `→`\b`（**空白一并被删除**），`\R `→`\r`，`\PG `→`\pg`，`\POG `→`\pog`，`\G `→`\G`，`\CN `→`\CN`（大小写不敏感匹配、归一为小写或大写形式按源登记）。**裸码无后随空白不改**（`\B` 后无空格 → 不动）；**已小写但码后有空白也会变化**（`\pg x` → `\pgx`，空白被吃掉）。
2. **4 行窗口**：从第 2 行起数，每数到第 4 的续行改为新文本命令首行——9 行文本在**第 5、9 行（一基）**拆分（窗口 4/4/1）。
3. **短首行合并**：首行长度 1–20、**不含 `\n`**、且有续行 → 把第 2 行以 `\n` 并入首行、删除第 2 行、重审本条——**并入后首行已含 `\n`，同一短行规则不再满足**——**只并一次**（第三条行保持为续行，不连锁）。
4. **跨命令断句**：本命令 ≥3 行且下一条也是文本命令，且本命令末行**不含** `.,!?;-"` 结尾字符且**不含反斜杠或 `<`（任何位置）→ 在合并全文中找最后的句读点（优先 `. `/`.\n`/`!`/`?`，找不到退 `, `/`,\n`）；找到则在该点切分：**前半保留为本命令**（多行），**尾段作为新的文本命令（首行＋续行）放到原下一条文本之前**，**原下一条文本被降为续行、内容保留**（不丢弃）；无句读点则不动。
- 每条规则只在实际变化时记变更；命令数/缩进按源行为保持。

### 9.1 分页与断句的组合删除范围（B20-C027）

四行分页先把原第5、第9行的命令类型改成新文本首行，但本轮已统计的行数仍为9。紧随其后的断句规则只拼接到遇见的首个新首行，即原1–4行，却按旧计数删除原1–9行；因此分页与断句组合时会丢失原5–9行，不能从孤立规则推导所有文本都保留。

精确静态夹具：同缩进的9行消息，第一行是长于20字符的 `A sufficiently long opening sentence. Tail`，其余依次 `L2`..`L9`，各续行无反斜杠、`<`与末尾句读；之后紧接独立首行 `Following message.`、最后终止命令。短首行合并门不命中；分页改原5/9类型；断句由末行L9无句读且后有独立文本而启动。实际合并串仅为第一行、L2、L3、L4（以实际换行连接），在第一行句点切分，保留前句和尾段Tail/L2/L3/L4、删除原1–9，原5–9消失；紧接的 `Following message.` 内容保留，第一次断句产物中被降为续行接尾段。游标接着处理新尾段：Tail、L2、L3、L4、Following共5条，分页把Following重新升为首行；短首行规则将Tail与L2合为含字面`\n`的一个首行，再次访问不重复合并，尾段没有可切句读，不再断句。整轮最终命令顺序为：首行 `A sufficiently long opening sentence.`、首行 `Tail\nL2`、续行 `L3`、续行 `L4`、首行 `Following message.`、终止命令。原5–9依然丢失；不得把暂时降续行当整轮最终类型。既定同缩进不改变。

反向对照：保持9行而把原末行改成以句点结尾，断句门不启动，分页4/4/1保留全内容；或移除后续文本命令，亦不启动断句。原CV-M15安全9行窗口案例和CV-M17三行断句案例仍各自有效，不能把本组合损失推广为它们也丢文。本条为静态推导，未执行转换器、事件解释器或行为向量。

- **移动的真实语义（R17 修订——本地复制后删除，不是原子重命名）**：本仓库的文件移动＝先复制（**读完全部源内容 → 目标已存在则先删除 → 重建并写入目标**）＋**删除源**。逐点后果：**目标已存在时先被删除**（不比较内容、不再询问）；**重建/写入目标失败** → 源尚在，但**原目标可能已丢失或只剩部分内容**；**删除源失败** → 可能留下新旧两份。**阶段 1 任一异常都会中止整个更新、阶段 2 引用更新不再执行**（无兜底、无回滚）。目录不存在则阶段 1 返回假（无动作、无警告）。

- **汇总**：阶段 1 有更名 → 一条更名警告；阶段 2 每图一条记录警告；有任一记录 → 追加「RMXP 数据已被改动，请立即关闭 RMXP」警告；**全无变化 → 无任何警告**（只有完成提示）。
- **重跑**：已更名的文件与引用不再命中（幂等）；阶段 2 不检查目标文件是否存在（如实登记——引用同步不做资源校验）。

module FilenameUpdater
  module_function

  def readDirectoryFiles(directory, formats)
    files = []
    Dir.chdir(directory) do
      formats.each do |format|
        Dir.glob(format) { |f| files.push(f) }
      end
    end
    return files
  end

  def rename_berry_plant_charsets
    src_dir = "Graphics/Characters/"
    return false if !FileTest.directory?(src_dir)
    Console.echo_li(_INTL("Renaming berry tree charsets..."))
    ret = false
    # generates a list of all graphic files
    files = readDirectoryFiles(src_dir, ["berrytree*.png"])
    # starts automatic renaming
    files.each_with_index do |file, i|
      next if file[/^berrytree_/]
      next if ["berrytreewet", "berrytreedamp", "berrytreedry", "berrytreeplanted"].include?(file.split(".")[0])
      new_file = file.gsub("berrytree", "berrytree_")
      File.move(src_dir + file, src_dir + new_file)
      ret = true
    end
    Console.echo_done(true)
    return ret
  end

  def update_berry_tree_event_charsets
    ret = []
    mapData = Compiler::MapData.new
    t = System.uptime
    Graphics.update
    Console.echo_li(_INTL("Checking {1} maps for used berry tree charsets...", mapData.mapinfos.keys.length))
    idx = 0
    mapData.mapinfos.keys.sort.each do |id|
      echo "." if idx % 20 == 0
      idx += 1
      Graphics.update if idx % 250 == 0
      map = mapData.getMap(id)
      next if !map || !mapData.mapinfos[id]
      changed = false
      map.events.each_key do |key|
        if System.uptime - t >= 5
          t += 5
          Graphics.update
        end
        map.events[key].pages.each do |page|
          next if nil_or_empty?(page.graphic.character_name)
          char_name = page.graphic.character_name
          next if !char_name[/^berrytree[^_]+/]
          next if ["berrytreewet", "berrytreedamp", "berrytreedry", "berrytreeplanted"].include?(char_name.split(".")[0])
          new_file = page.graphic.character_name.gsub("berrytree", "berrytree_")
          page.graphic.character_name = new_file
          changed = true
        end
      end
      next if !changed
      mapData.saveMap(id)
      ret.push(_INTL("Map {1}: '{2}' was modified and saved.", id, mapData.mapinfos[id].name))
    end
    Console.echo_done(true)
    return ret
  end

  def rename_files
    Console.echo_h1(_INTL("Updating file names and locations"))
    change_record = []
    # Add underscore to berry plant charsets
    if rename_berry_plant_charsets
      Console.echo_warn(_INTL("Berry plant charset files were renamed."))
    end
    change_record += update_berry_tree_event_charsets
    # Warn if any map data has been changed
    if !change_record.empty?
      change_record.each { |msg| Console.echo_warn(msg) }
      Console.echo_warn(_INTL("RMXP data was altered. Close RMXP now to ensure changes are applied."))
    end
    echoln ""
    Console.echo_h2(_INTL("Finished updating file names and locations"), text: :green)
  end
end
