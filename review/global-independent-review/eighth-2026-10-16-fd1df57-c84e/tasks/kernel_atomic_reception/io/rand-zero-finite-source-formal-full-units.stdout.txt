class << Kernel
  alias oldRand rand unless method_defined?(:oldRand)
  def rand(a = nil, b = nil)
    if a.is_a?(Range)
      lo = a.min
      hi = a.max
      return lo + oldRand(hi - lo + 1)
    elsif a.is_a?(Numeric)
      if b.is_a?(Numeric)
        return a + oldRand(b - a + 1)
      else
        return oldRand(a)
      end
    elsif a.nil?
      return oldRand(b)
    end
    return oldRand

# 时间、随机、计步与统计（净化正文；批次 4）

分类：Generic Kernel（横切计量）。本文件定义横切计量边界——哪些系统由现实时间、运行时长、帧/更新周期还是步数推动；随机输入在哪些入口、以什么形式（普通随机/显式种子/记录序列）进入系统；统计字段如何产生、累加、重置和保存。除明确列出的第四审查限定历史隔离回执外，正文与向量为静态证据；**本次无新增行为执行，宿主/Demo未执行**（见 `../scope-statement.md`；历史回执仅支持其注明的输入、版本与观察点）。

## 1. 目的与范围

**目的**：回答「某规则由什么输入驱动、能否重现」，供后续规格引用，而不追踪任何特定时钟或随机实现。

**范围**：① 时间与计时来源（现实时间、运行时长、游戏时间、帧/更新周期）及消费者推进方式；② 计步与统计（计步机制、统计字段族、更新点、持久化）；③ 随机入口与种子（普通随机、显式种子、记录/回放）；④ 保存/恢复交界与可重现性。

**非目标**：不提取领域规则（地牢算法、繁殖/遭遇概率、设施回放、世界天气与树果、步数效果全集、电话业务全集，各归相应领域规格）；不提取保存生命周期与迁移细则（归《保存、启动、新游戏与继续》《迁移、失败与恢复》，本文件只登记交界）；不宣称存在统一、可注入、全局可重放的随机服务；不保证相同种子跨语言/随机数实现产生相同结果。

## 2. 概念与术语

- **现实时间**：宿主提供的真实时钟，驱动昼夜、日历、树果、电话、彩票等。
- **运行时长**：进程已运行秒数，驱动帧计时、等待、切换、部分比赛计时。
- **游戏时间**：累计游玩秒数（统计记录的 play_time 字段），在锚点存在时惰性累加，持久化保存。
- **帧增量**：逐帧推进的更新与每帧更新事件及其增量扣减。
- **普通随机**：标准库随机调用（无显式种子）；取值范围可由调用参数静态确定的以参数为准，跨系统/跨实现重放不可证。
- **显式种子**：指定输入决定随机序列的种子（地牢生成、彩票日期种子）。
- **记录/回放**：战斗记录保存随机数序列，回放按序列取用而非重新随机。

## 5. 随机入口与种子

### 5.1 随机入口/消费者族目录

- 标准随机调用形式的文本命中数百处（口径与数字见审计）——**文本命中不是随机入口全集，也不等于调用可达**。
- 集合抽样/乱序形式：文本命中数十处，例如寄养遗传多处抽样、地牢生成抽样/乱序。
- 取值范围可由调用参数静态确定（如「20–39 的均匀抽样 × 60」为 20–39 分钟区间）；**跨系统/跨实现重放不可证**（相同种子在不同语言与随机数实现中不保证相同结果）。
- 显式种子仅 **3 处**：
  1. **地牢生成**：种子优先级＝参数种子 > 待播种子（全局元数据的 dungeon_rng_seed 字段）> 新生成种子；随后按选定种子重播全局随机序列。
  2. **彩票**：按「日＋月×2⁵＋年×2⁹」播种——**号码按日期确定**；取号后无参重播种。
  3. 无其他显式播种使用点。

#### 5.1.1 普通随机作者参数分派

在给定底层整数随机源可按正上界产生合法偏移的前提下：

| 首参/次参 | 实际请求与正常输出域 |
| --- | --- |
| 两个有限有序整数a≤b | 请求宽度b−a+1，再加a，闭区间[a,b]；5/7配偏移0/1/2返回5/6/7，5/5只能5 |
| 整数区间首参 | 用该区间实际最小/最大成员决定闭整数域，忽略次参；5...8与5..7均为5/6/7 |
| 数值首参、非数值次参 | 委托原单上界抽样；正整数5为0..4 |
| 空首参 | 委托次参；空/7与原单上界7请求相同 |
| 其它类型首参（如文本“5”） | 无参抽样请求，忽略次参，不把文本解析为5；文本“5”/1不因此强制返回0 |

区间首参即使给次参仍取自身域。电话20...40保持20–39、钓鱼5..10保持5–10；两数值分支没有固定核心默认调用证明，不称为全游戏统一入口。浮点、反向/空/无界/非数值区间及错误类型的原生接受/异常不补造统一拒绝。此为给定偏移的静态向量，不保证跨语言随机序列或统计分布；显式种子、录像与跨次有状态选择仍分别按原合同。
