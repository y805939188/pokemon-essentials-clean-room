## 16. 边界、失败与未知汇总

1. 调试门：新地图导入仅调试模式；启动检查仅调试模式，默认 Compile data 菜单由调试入口门保护；共享内容阶段自身不再检查调试标志，直接调用不套默认菜单可达结论；菜单更名需确认。
2. 无变化路径：导入 0 张、转换 0 命中、更名 0 文件——都不写文件、各有既定消息或静默返回；往返守卫是**数量启发式**（提取 <10 拒绝、合并 >10 拒绝、**恰 10 两边放行**、合并产物 ≤10 节可再次合并覆盖，§12.1/§12.2）。
3. 识别不误判不保证：门/通道/柜台/mart/护士均为启发式（WP61 识别边界继承）；`SellItem` 只认**注释首行内大小写敏感的括号形式**（`SellItem(POTION,200)`（ASCII括号/逗号；合法名/非负价格），非锚定、冒号形/小写/负价不命中）且道具已注册才改写；道具球名需道具已注册。
4. 文本级替换的边界：**35 对**＋2 正则非语法分析（旧式变量读取**后随**赋值/比较运算符不动——运算符跟在读取之后才受保护（读取位于比较符左侧），读取为右操作数仍替换）；可逃/可败判定是文本包含；逗号切分器不处理转义引号。
5. 破坏性写入如实登记：提取前清空整个散文件树（原归档有备份）；合并直接覆盖归档不备份；更名＝**本地复制后删除**（目标先删再写——目标可能先丢或部分、源删除失败留两份、阶段 1 异常阻断阶段 2）；地图写回容错吞异常（保存失败不报告）；编译驱动无整体兜底（异常中止、已写不回滚）；**一次编译不保证达不变状态**（旧训练家起式空分支二轮才补、治疗残留与单命令持续插入、门路径 b 副作用，§8.2/§8.4/§7.2）。
6. 停用/不可达：玩家转移处理的大停用块、通道补设的唯一调用点、事件 ID 工具的无效实现、townmapgen 的引号处理停用代码。单节档案装载器另属当前可读的条件入口：兼容未加密宿主到达唯一 Main，目录可枚举且所选 .rb 可读、先前依赖正常时，末尾请求发现并求值散文件（§12.4）；静态可达不等于实际宿主启动或加载成功。
7. 训练家检查副作用：类型不存在可触发编辑器新建（编译期、调试下）；缺训练家三回答（建/不建/不再问）——「不再问」只影响本次编译进程；**2 条 Battle: 时第二个版本不被检查**（≥3 才逐个查再战）；**非调试或已「不再问」时本调用链直接返回**（底层缺失入口的非调试异常是该入口自身合同，不经本路径产生）。
8. **demo 素材可得性与缺口（静态身份；运行未验证）**：`Data/` 仅含 `Scripts/`、`Scripts.rxdata`、`messages_core.dat`——无 `Map*.rxdata`/`MapInfos.rxdata`/`System.rxdata`/`Tilesets.rxdata`/`CommonEvents.rxdata`（地图数据访问层无法构造，全部地图类转换在 demo 不可运行）；`Graphics/` 整体缺失（berrytree、Town Map 目录及默认区域底图 `Graphics/UI/Town Map/mapRegion0.png` 均无）。根目录 `knownpoint.bmp`／`selpoint.bmp` 均可读、受 Git 跟踪，BMP 头部为 8×8，精确身份见 §13.3；二者不属于 `Graphics/` 缺项。demo 地图/事件内容可达性归 WP77，底图补交、浏览器/宿主兼容性和全部实际运行表现保持未知。
9. 宿主/环境相关未知：两个 Ruby 脚本的实际运行环境（README 要求本机 Ruby）；extendtext 的实际效果；townmapgen 在不同浏览器的行为；开关注册槽满返回 1 的后续影响。

module GameData
  class Evolution
    attr_reader :id
    attr_reader :real_name
    attr_reader :parameter
    attr_reader :any_level_up   # false means parameter is the minimum level
    attr_reader :level_up_proc
    attr_reader :use_item_proc
    attr_reader :on_trade_proc
    attr_reader :after_battle_proc
    attr_reader :event_proc
    attr_reader :after_evolution_proc

    DATA = {}

    extend ClassMethodsSymbols
    include InstanceMethods

    def self.load; end
    def self.save; end

    def initialize(hash)
      @id                   = hash[:id]
      @real_name            = hash[:id].to_s      || "Unnamed"
      @parameter            = hash[:parameter]
      @any_level_up         = hash[:any_level_up] || false
      @level_up_proc        = hash[:level_up_proc]
      @use_item_proc        = hash[:use_item_proc]
      @on_trade_proc        = hash[:on_trade_proc]
      @after_battle_proc    = hash[:after_battle_proc]
      @event_proc           = hash[:event_proc]
      @after_evolution_proc = hash[:after_evolution_proc]
    end

    alias name real_name

    def call_level_up(*args)
      return (@level_up_proc) ? @level_up_proc.call(*args) : nil
    end

    def call_use_item(*args)
      return (@use_item_proc) ? @use_item_proc.call(*args) : nil
    end

    def call_on_trade(*args)
      return (@on_trade_proc) ? @on_trade_proc.call(*args) : nil
    end

    def call_after_battle(*args)
      return (@after_battle_proc) ? @after_battle_proc.call(*args) : nil
    end

    def call_event(*args)
      return (@event_proc) ? @event_proc.call(*args) : nil
    end

    def call_after_evolution(*args)
      @after_evolution_proc&.call(*args)
    end
  end
