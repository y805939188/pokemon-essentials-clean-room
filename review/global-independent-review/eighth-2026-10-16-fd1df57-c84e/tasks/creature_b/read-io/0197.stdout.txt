00632 #===============================================================================
00633 # Evolution methods that are triggered by an event
00634 # Each event has its own number, which is the value of the parameter as defined
00635 # in pokemon.txt/pokemon_forms.txt. It is also 'number' in def pbEvolutionEvent,
00636 # which triggers evolution checks for a particular event number. 'value' in an
00637 # event_proc is the number of the evolution event currently being triggered.
00638 # Evolutions caused by different events should have different numbers. Used
00639 # event numbers are:
00640 #   1: Kubfu -> Urshifu
00641 #   2: Galarian Yamask -> Runerigus
00642 # These used event numbers are only used in pokemon.txt/pokemon_forms.txt and in
00643 # map events that call pbEvolutionEvent, so they are relatively easy to change
00644 # if you need to (no script changes are required). However, you could just
00645 # ignore them instead if you don't want to use them.
00646 #===============================================================================
00647 def pbEvolutionEvent(number)
00648   return if !$player
00649   $player.able_party.each do |pkmn|
00650     pkmn.trigger_event_evolution(number)
00651   end
00652 end
