00731 #===============================================================================
00732 # Regional forms
00733 # This code is for determining the form of a Pokémon in an egg created at the
00734 # Day Care, where that Pokémon's species has regional forms. The regional form
00735 # chosen depends on the region in which the egg was produced (not where it
00736 # hatches).
00737 #===============================================================================
00738 
00739 # The code in this proc assumes that the appropriate regional form for a Pokémon
00740 # is equal to the region's number. This may not be true in your game.
00741 # Note that this proc only produces a non-zero form number if the species has a
00742 # defined form with that number, which means it can be used for both Alolan and
00743 # Galarian forms separately (and for Meowth which has both).
00744 MultipleForms.register(:RATTATA, {
00745   "getFormOnEggCreation" => proc { |pkmn|
00746     if $game_map
00747       map_pos = $game_map.metadata&.town_map_position
00748       next map_pos[0] if map_pos &&
00749                          GameData::Species.get_species_form(pkmn.species, map_pos[0]).form == map_pos[0]
00750     end
00751     next 0
00752   }
00753 })
