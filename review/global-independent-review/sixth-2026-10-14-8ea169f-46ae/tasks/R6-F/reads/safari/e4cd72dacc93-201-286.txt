207: ### 7.3 名次与查询
208: 
209: - **名次表写入**：排序后**追加**前三名到名次表（**追加不是覆盖**——重复判奖时累加，每次 3 条；每条＝[参赛者下标（玩家为 −1）, 物种, 分数]）。
210: - **玩家名次**：**只扫描名次表前三条**——首条玩家（下标 −1）的位置（0/1/2），否则 3（未上榜）。
211: - **名次信息查询（实参＝名次位）**：**按调用者传入位置直接取条目，不局限于前三条**（重复判奖产生第二批记录后，位置 3 可读出第二批首名的名字/物种名/分数；**位置越界（如总数之外）在读取处失败**）——变量 1＝玩家名（下标 −1 时）或对手名、变量 2＝物种名、变量 3＝分数；**名次表为空时同样在读取处失败**（事件前置；先写状态再失败位置，§10）。**玩家名次与信息查询是两个范围不同的查询**（玩家名次永远只看前三条；不推断 demo 实际会查询第二批）。
212: - **结算次序回顾**（§5.2）：拼队 → 存储保留个体 → 获胜统计（玩家名次为榜首）→ 清字段 → 上次比赛时间——**真实奖励事件未知就保留**（demo/U01/demo 规格）。

214: ## 8. 公共交界、UI、保存与 demo 配置
215: 
216: ### 8.1 事件注册/调用次序（按目录加载序）
217: 
218: - **公开开战覆盖（覆盖竞争）**：漫游 → **Safari** → **捕虫**——三者都以 handled 空为门；**Safari 区域内漫游条目满足其全部门时，漫游覆盖先生效（产生漫游战斗而非 Safari 战斗）**；漫游门不成立才落到 Safari/捕虫覆盖。
219: - **遭遇选择钩子（物种层）**：漫游替换（先）→ 雷达连锁（后）——两个钩子都**不设 Safari/捕虫模式门**：Safari/捕虫区域内漫游可替换物种（25% 门等全过时）、雷达钩子对非摇动草遭遇一律取消连锁（WP37 引用）。
220: - **个体创建通知（生成层）**：按文件内注册序——闪光开关 → **Safari/捕虫 IV 重摇**（Safari 或捕虫区域内时：**若无任一 IV 达到上限，全部主属性 IV 重随机，至多 4 次，提前命中上限即停；发生重摇才重算能力值**）→ 传说/幻之/究极异兽保底 3 满 IV → 地图旗标等级缩放。两个模式入口的生成入口都会触发该链；**判奖的对手个体不走此链**（§7.2）。
221: - **换图**：漫游推进 → 雷达取消 → **Safari 区域外清空** → **捕虫结束后清理**。
222: - **离图**：**捕虫越界中断**（§5.5）。
223: - **可转移步进**：毒伤 → **Safari 计步**——handled 门串联；Safari 计步触发转移时当步不再做遭遇判定（§3.3）。
224: - **帧更新**：病毒/低电量/BGM → **捕虫倒计时**。
225: - **地图/精灵集变更**：暗度/位置窗 → **捕虫定时器显示**。
226: - **开始战斗通知**：**捕虫入口显式触发**（§6.1）；**Safari 入口不触发**（§4.1）。
227: - **野生战斗结束通知**：**两个模式入口都在结果写回后显式触发一次**（雷达连锁钩子消费；**触发点在球尽回起点/判奖转移之后**——回调发生时 Safari 会话可能已将会话决定置 1 且玩家已回起点、捕虫可能已完成判奖与转移，不套 WP37 每条正常路径结论）。

229: ### 8.2 雷达与两种模式的静态关系
230: 
231: - 雷达许可门只看地形/遭遇表/骑车/调试/电量（WP37 引用）——**无 Safari/捕虫模式门**；连锁数据是暂态字段。
232: - 连锁存在时：漫游替换跳过（其自身门）；雷达钩子对非摇动草遭遇取消连锁；Safari/捕虫覆盖在开战覆盖层照常发生（handled 空时）——**连锁中的遭遇在两种模式区域内被模式战斗接管，随后模式入口的野生结束通知更新或取消连锁**（**结果可达性按模式分列**：Safari 普通四命令只产生 0/2/3/4——可达的增链输入是捕获结果 4；捕虫经普通战斗流程可产生击败 1 与捕获 4；人工直接注入结果 1 属人工夹具、并非 Safari 核心产出；非击败/捕获结果 → 取消；重摇/消息按 WP37 合同——且先回起点换图可能已取消连锁，§8.1）。

234: ### 8.3 UI 与用户流程
235: 
236: - **暂停菜单信息行**：**Safari**——配置步数 >0 时显示「步数：剩余/上限＋球数」，**配置步数 ≤0 时只显示球数**；**捕虫**——有保留个体时显示「已捕获：物种＋等级＋预算」，否则「未捕获＋预算」。
237: - **主动退出**：暂停菜单「退出」（Safari，仅区域内出现）→ 确认 → 结束菜单场景、会话决定置 1、回起点（**确认才执行；取消返回菜单**）；「退出比赛」（捕虫）→ 确认 → 结束菜单场景、开始判奖（**主动退出捕虫＝进入判奖，不是中断**）。
238: - **背包**：捕虫进行中**不可用**（菜单出现条件：不在捕虫会话中）；Safari 中可用（但战斗内无背包——§4.2）。
239: - **保存**：**两种模式进行中均不可用**（菜单出现条件：系统允许保存、且不在 Safari 会话中、且不在捕虫会话中——三个行为条件分列）。
240: - **调试入口**（调试不混进默认用户流程）：「Safari 与捕虫大会」——**Safari**：步数编辑（0–99999，**仅配置步数 >0 时可编**）、Safari 球数编辑（0–99999）；**捕虫**：剩余时间编辑（按分钟 0–99999，**仅限时严格为正时可编——限时为 0 或负数都不可编：非正时该项显示「无限」、选择不进入编辑**；可编时改写计时起点并同步已存在的定时器显示）、Sport 球数编辑。**调试显示「无限」（非正限时）与地图定时器的 00:00（负限时）是两个入口的不同行为**（§5.3），不把显示门、到期门和编辑门合并。调试把球数/步数改为 0 后的后续判定走各自正常门。

242: ### 8.4 保存与持久边界
243: 
244: - **持久（全局元数据，随存档保存）**：两个会话对象整体（「特殊战斗模式」字段组）。**但模式进行中保存入口不可用（§8.3）——正常流程能落盘的只有未开始/已结束态**；上次比赛时间、统计字段（`safari_pokemon_caught`、`most_captures_per_safari_game`、`bug_contest_count`、`bug_contest_wins`）随存档。
245: - **运行时刻值与落盘分开**：计时起点（单调时钟）、定时器显示、战斗内预算/因子是运行态——保存/载入对这些基准的实际语义未逐项验证（静态保留）。
246: - **版本转换**：当前转换集中**无 Safari/捕虫相关转换**——普通载入不涉及两会话对象的格式迁移（《迁移、失败与恢复》不重开）。
247: - **demo 可达性保留**：接待/判奖/奖励/费用/参赛日期事件的实际地图接点与调用链归 U01/demo 规格；脚本提供入口不等于默认事件确实调用。

256: ## 9. 默认行为与配置变体
257: 
258: - **Safari 默认**：步数 600；球数为接待事件实参；区域＝起点接待图 ∪ SafariMap 旗标图；计步到 0/球数 ≤0/主动退出 → 会话决定置 1 并回起点；离开区域 → 清空。
259: - **Safari 配置变体**：`SAFARI_STEPS = 0` → 不计步（暂停只显示球数）；**`SAFARI_STEPS < 0` → 第一步即结束**（真实分支，§3.3）。
260: - **捕虫默认**：限时 1200 秒；球数为接待事件实参；对手 5 名（8 名名单去重抽取）；队伍缩为 1 员；判奖＝时限到/球尽/退出/败平/越界中断（中断不判）。
261: - **捕虫配置变体**：`BUG_CONTEST_TIME = 0` → 不到期、不显示定时器；**`BUG_CONTEST_TIME < 0` → 显示 00:00 且永不到期**（真实分支，§5.3）。
262: - **未验证组合**：素材/逐帧实测（U01/素材保留）、宿主随机源实际序列、demo 事件编排（U01/demo 规格）、保存/载入后单调时钟基准语义。

264: ## 10. 边界、失败与未知
265: 
266: - **Safari 边界**：回起点非地图场景 → 不转移（会话决定已写）；起点为空（人工/异常前置）→ 读取起点字段处失败；球数人工 0/负 → 战斗回合末/战斗后球尽分支照常判定；覆盖钩子 handled 已处理 → Safari 不接管（保留原处理结果）。
267: - **捕虫「先写状态再失败」位置（人工/事件/变体前置，逐个列出）**：①参赛下标**未设置（空）→ 开始入口在按下标读取队伍成员处失败**（预算/inProgress/计时器/名次表清空已写，缩队未发生）；**正数越界 → 读取得空值、开始入口照常完成**（当前队伍含一个空成员；后续空成员消费者的错误不预先移到选员处，不设原参考没有的校验/回滚）；②**未判奖就结束（含越界中断）→ 拼队完成后在名次查询处失败**——会话字段未清、上次比赛时间未写；③判奖点未设置（为空）→ 开始判奖在判分写名次后、读取判奖点处失败（地图场景时）；④判奖时比赛图集全无有效遭遇类型 → 异常（会话决定已置 1）；⑤对手抽中遭遇表空候选 → 异常；⑥名次表为空时信息查询/玩家名次 → 读取处失败；⑦最终接收的联合容量门：**队伍满且存储满 → 两条消息并早退**（本次接收无新增图鉴/昵称/存储写入、不回滚战斗阶段记录、不失败返回）；**仅箱满而队伍有位 → 入队**。
268: - **重复判奖**：败/平黑屏回退判一次、随后预算为 0 分支再判一次（名次表追加）；同一判奖入口被重复调用也追加——**名次表只追加不覆盖**；**玩家名次只扫描前三条；信息查询按传入位置取条目、可读追加后的后续条目（位置越界才失败）**（不推断 demo 实际查询第二批）。
269: - **共同边界**：覆盖路径不经核心开战——battle_rules 等暂态字段的清理按各自生命周期处理（不虚构清理保证）；战斗中异常中断（脚本错误）时字段清理未逐项验证；demo 可达性具名保留（U01/demo 规格）。
270: - **未知/未证**：定时器在菜单/战斗内流逝与恢复显示的全部宿主行为；保存/载入后计时起点与 24 小时墙钟的实际语义；素材存在与播放（U01/素材保留）；奖励/费用/接待话术事件（U01/demo 规格）。
