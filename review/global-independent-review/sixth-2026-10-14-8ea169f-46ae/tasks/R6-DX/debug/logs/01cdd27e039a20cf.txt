117: ## 6. 队伍组建与迭代（D）
118: 
119: ### 6.1 重复判定（D-1）
120: 
121: - 物种不同 → 必不重复。同种时两判据：
122:   - **招式判据**：四个招式位**按槽位原序**（含空位占位）逐项相等即重复，不去空位或排序；比较是**槽位序敏感**的。
123:   - **属性判据**：道具、性格、全部主能力 EV 值逐项相等即重复。
124: - 判据间为「或」：任一成立即视为重复。
125: 
126: ### 6.2 补充与同种上限（D-2；补充目标 ≠ 容量上限）
127: 
128: - **补充**：**池不足 20 才反复生成候选**、仅当不与池中任何成员重复才入池——**20 是补充目标而非容量上限**：已有大池不截断，种子填充与退休成员回池均可令其超过 20（§6.4）。候选无限重试，无进度上限登记。
129: - **去重**：顺序扫描，重复者丢弃；**同种成员超过 10 时删除该种最早成员**（先进先出顶出）——同种上限 10 **仅在显式去重阶段生效**（按重复判据之外的纯物种计数），其它阶段不受此限。
130: 
131: ### 6.3 队伍取样（D-3）
132: 
133: - 从池中按建议数量（生成阶段使用**设为 2 的规则副本**——每次取出 2 只，§6.4）**逐个随机抽取并即从池中删除**（池被消耗）；组成后过**该规则副本**的团队合法校验，不过则**重新抽取**（无迭代上限；池随每次尝试净消耗——耗尽早于满足时的行为无保护，如实登记）。
134: - 新队伍：评级以活动变体初值 1500/350/0.9开始（§7.4），历史空、累计已结算场次 0。
135: 
136: ### 6.4 生成主流程（D-4）
137: 
138: - **规则阶段切换**：开始即把规则**复制副本并把队伍数量设为 2**——**候选、组队与模拟全程使用该副本**；**11 轮结束后恢复原挑战规则**，**分层与训练家分配重新按原规则消费**（最终合法性、建议等级、可组队要求均按原规则；数量 2 不是全流程不变量）。规则副本经构造保留数量与三类规则、最小数量按副本自身语义（WP54 引用）；**建议等级随规则数据而异**——普通杯赛规则下副本与原规则一致，独立自定义规则（如带总等级限制的子集规则）下二者可不同，不套用杯赛必然不变的结论。
139: - 从检查点读池与队伍库（缺失/异常 → 空）。
140: - **种子填充**：队伍库 <10 且既有宝可梦表（§8.1 查询）非空 → 逐条按**副本**建议等级、个体值 31 实例化，合法者入池（可使池超过 20，；随后 §6.2 去重）。
141: - **常量**：队伍库**补齐目标 600**（非始终成立的上限，见下）、高分线 65、低分线 40、**迭代 11 轮**。
142: - **阈值计数**：以下 80／250 场均取同一队伍的可见累计 C＋h；成功结算把待结算场数转入 C，不因清空历史归零。正常写成的结算后队伍库检查点保留该累计；继续读取同一检查点且没有队伍替换、外部修改或新对局时，下一轮仍按该场数扫描。新队伍的 C、h 才从 0 开始；实际中断后的恢复粒度仍未验证。
143: - 每轮迭代：
144:   1. **写池检查点**；进度消息「Generating teams (i of 11)」。
145:   2. 逐队伍扫描（先补充池至 20）：评分 <65 且累计场次 ≥80 → **替换为新队**；成员数 <2 → 替换；**下标 ≥600 → 删除**；累计场次 ≥250 → **退休**（成员回池后替换）；评分 <40 → 替换。五支按序互斥（首命中支生效——各支以更早分支不成立为前提）。**删除后游标仍前进**：被删位置后移入的队伍**本轮被跳过**——例：602 支均不满足前两支替换条件的队伍，下标 600 删除一支后游标越过，本轮可留下 601 支；**不能承诺任何检查点的库长不超过 600**（超额队伍也可能先命中低分/场次替换支而非删除支）。
146:   3. **写队伍库检查点**；队伍库补至 600（每队建前补充池）。
147:   4. **写池检查点**；按评分降序排；进度消息「Simulating battles (i of 11)」。
148:   5. 模拟（§7）：每个发起位置**无条件抽 5 次对手、只用最后一次**——第 5 次仍为自身则本轮跳过（**前四次抽到的有效对手不被采用**；库长 600 时跳过概率为单次 1/600，不是五连自对的概率）；对局双方**都**记录场次，故每队本轮新增场数不固定；**续战门取全库历史场次的整数平均 <12**（不是每队都达到 12）→ 全员续战；达到 → 全员评级结算并清历史（§7.4）后本轮收束；按评分降序、**写队伍库检查点**。
149: - 11 轮后：池清空；队伍库**升序**遍历，**评分 >65** 的队伍成员全部入池（升序遍历＋条件跳过，不提前终止）；去重；「Writing results」；**恢复原规则**后**分层**（§6.5）；进入训练家池（§8）。

151: ### 6.5 分层（D-5）
152: 
153: - 九层限制器（带约束构造，规则入参未用，如实登记）：T0＝BST 0–500 非传说；T1＝BST 380–500 非传说；T2–T5＝BST 400–555 非传说（四层同构）；T6＝BST 580–680 **仅传说**；T7＝BST 500–680 非传说；T8＝BST 580–680 **不限**。
154: - **传说判定**：无性别且蛋群含「未发现」即传说（非传说限制取反即仅传说；取反包装为通用取反）。可入层集合示例：BST 300 非传说 → 仅 T0；BST 590 非传说 → T7 与 T8；BST 590 传说 → T6 与 T8。

172: 
173: - 双方评分先**乘 0.15 并取整**（四舍五入）——后续同分裁决使用的也是这两个**取整后**的值：原始评分 50 与 51 都变为 8。

175: - 胜负：分高者胜；**总分相同 → 比较两个取整后的缩放评分**，高者胜；缩放评分也相同 → 结果 5（记平局支）——原始评分不同但缩放值同、总分同 → **平局**。

177: ### 7.4 评级数学（E-4；独立完整定义）
178: 
179: 活动评级为 Glicko-2 **变体**，初值 R₀＝1500、D₀＝350、σ₀＝0.9。以下数学按独立变量给出，不调用或移植参考实现：
180: 
181: - **尺度**：归一化 rating₂＝(R−1500)÷173.7178、deviation₂＝D÷173.7178；**波动率 σ 以其原值（0.9）直接参与归一化域运算**（不做尺度换算，如实直述——空历史例：σ＝0.9 与归一化偏差平方相加后开方，换回时乘 173.7178）。
182: - **对局记录**：每条记录保存**记录当时**的对手评级 Rⱼ 与偏差 Dⱼ（快照）；之后逐队结算不回改这些值。结果 sⱼ∈{胜 1、负 0、平 −1}。
183: - **g/e 因子**：gⱼ＝1÷√(1＋3·(Dⱼ÷173.7178)²÷π²)；eⱼ＝1÷(1＋exp(−gⱼ·(rating₂−(Rⱼ−1500)÷173.7178)))。
184: - **方差**：v＝1÷Σⱼ(gⱼ²·eⱼ·(1−eⱼ))——**全部记录（含平局）参与**。
185: - **改进和**：Δ＝Σⱼ(sⱼ≠−1) gⱼ·(sⱼ−eⱼ)——**平局记录不进入改进和**（不等同按 0.5 计分）。
186: - **波动率更新**：改进量 **i₀＝Δ·v**（改进和先乘方差，与 Δ 本身分开）；a＝ln σ²（σ 为**本次更新前**的波动率）；τ＝1.2。**每次非空历史更新的迭代初始值 x₀＝a**（即本次更新前波动率平方的自然对数——**0.9 只属于固定示例，不是每次固定输入**）。以 x 为当前近似做牛顿迭代，每步：d＝(φ²＋v)＋eˣ（φ＝更新前 deviation₂）；i＝i₀÷d；**两项迭代量** h₁＝−(x−a)÷τ² − ½·eˣ·i²、h₂＝−1÷τ² − ½·eˣ·(φ²＋v)÷d² ＋ v·eˣ·(φ²＋v−eˣ)÷d³；**下一近似 x ← x − h₁÷h₂**；**至多 100 次**、步长绝对值 <10⁻⁶ 即停；σ′＝e^(x÷2)。**固定算术核对**：双方 R1500/D350、σ＝0.9——g≈0.6690694126、e＝0.5、v≈8.9354749036、初始近似 x₀＝a≈−0.2107210313。**一场平局**：Δ＝0 → i₀＝0 → 初始近似处 h₁＝0、h₂≈−0.6885384548 → **步进为 0、立即保持 σ′＝0.9**。**一场胜局**：Δ≈0.3345347063、i₀≈2.9892264725、i≈0.2165362337 → h₁≈−0.0189896159、h₂≈−0.6885384548 → **步进≈0.0275796011**、下一近似 x₁≈−0.2383006324（一步固定算术，非全程收敛值）。
187: - **偏差与评级更新（消费新值）**：t＝φ²＋**σ′²**（新波动率）；deviation₂′＝1÷√(1÷t＋1÷v)；rating₂′＝rating₂＋(deviation₂′)²·Δ（新偏差）；换回 R′＝1500＋173.7178·rating₂′、D′＝173.7178·deviation₂′。
188: - **空历史**：不更新评级/波动率，仅膨胀偏差 deviation₂′＝√(φ²＋σ²)——固定向量：D＝350、σ＝0.9 → D′≈**383.332855**。
189: - **展示分数（胜率百分数）按偏差分轨**：D >100 → Smogon 式（对手基准 1500/350：s＝√(100000＋D²＋350²)、g＝10^((1500−R)×0.79÷s)、胜率＝1÷(1＋g)×100）；D ≤100 → GLIXARE 式（sqr＝√(15.905694331435×(D²＋221781.21786254))、指数 inner＝(1500−R)×π÷sqr、胜率＝(10000÷(1＋10^inner)＋0.5)÷100）——**展示缓存随评级/偏差变更失效**。
190: - **场次结算与守恒**：前提为合法队伍、有效的已结算累计 C、评级数据及有限历史，本次评级更新正常完成并清空历史，期间没有队伍替换、外部修改或新对局。设结算前当前历史为 n 场；评级更新成功、历史清空后，把这 n 场并入已结算累计，得 **C′＝C＋n、h′＝0**。因此同一队伍的可见累计结算前为 C＋n，结算后仍为 C′＋h′＝C＋n，不减少、不重复累计；空历史的场次增量为 0（偏差膨胀仍按上条）。不是把清空后的 0 场作为本次已结算数量。
191: - **失败阶段**：在上述有效累计已存在的前提下，若评级更新在清空历史之前抛错，则历史清空及本次场次累计均未完成；原待结算历史和已结算累计仍在。评级更新可能已经修改部分评级字段，不承诺评级全字段事务回滚、外层正常收束或下一检查点写出必达；无效数据、外部修改及真实宿主异常表现不由正常结算不变量覆盖。
192: - **备选 Elo**：**仅定义、生成流程无引用**——初值 1600、K＝16、胜率 1÷(1＋10^((R−1600)÷400))；其非空更新在取得当前对局信息处失败，无法完成更新——属**未使用定义的静态缺陷**，如实登记、**不承诺其为可用更新算法**；与活动评级明确分开。
