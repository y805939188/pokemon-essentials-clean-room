15: ## 2. 概念与术语
16: 
17: - **调试标志与运行内标志分层**：调试标志由宿主环境给定（测试运行语义；WP01/WP07 引用），是全部调试入口的总门；运行内标志是**运行中可切换的内部标志**——当前静态范围内唯一的写入者是调试菜单的战斗日志开关（§8.1），读取者是日志模块（与调试标志共同门）与异常打印长度选择。**两者独立**：入口可见性只看调试标志；日志输出要求两者同真。
18: - **菜单注册与可用筛选**：命令按可识别选项登记名称、父级、说明、条件及动作；**可用筛选**按排序键（缺省按注册序号）排序、逐个执行条件（无条件的调试主菜单注册项不设条件——调试门在**入口调用侧**，不在注册项上）；名称可为取值过程或静态文本。**`受限可见标记` 三态**：未设置（空）／显式真／显式假——**受限模式只排除显式假**（未设置与显式真都保留），§3.2。
19: - **命令菜单列表框架**：层级菜单——每个命令记录父级；列表给出当前层命令名；可下钻判定；取父级返回父层 ID 及当前层在父层中的下标（用于返回时恢复光标）；描述缺省回落「<No description available>」。**返回父级**（BACK 且存在父级：取消音效＋切回父层＋光标恢复到该层在父级中的位置）与**根取消**（BACK 且无父级：整体退出）分开；**效果返回值关闭语义**——个体调试菜单中效果返回真即退出整个调试菜单（复制/删除用此关闭）；地图调试菜单中地图传送项特殊——效果返回真才关菜单（先清理自身窗口/视口再转移，§4.1）。
20: - **原个体与战斗当前两层（R07 修订）**：战斗内编辑同时面对**原个体对象**（队伍/盒子中的持久数据）与**战斗当前状态**（在场派生层）。**写入器写穿**：在场对象的 **HP、状态、状态计数、道具、等级、形态**的写入器会**同步写回原个体**（状态写入器还重置相关计数并刷新场景——WP40 引用）；**战斗特性、能力阶段、能力值、类型、效果、Mega 配额等是战斗层**（不写回原个体）。各命令**按名选择写哪一层**（§7.4 逐项）；不存在「改了原个体就自动同步战斗层」或反向的通用保证；退出战斗调试后由战斗命令阶段执行一串**刷新后续处理**（§7.6），仅这些具名后续处理，不虚构全面重同步。**持久性推论**：写穿层的改动落在持久对象上（战后保留——WP39 生命周期引用）；战斗层改动随战斗结束消散。
21: - **情境筛选**：战斗个体调试菜单的命令带 原个体专用／在场专用／两种情境 用途——有在场对象时排除 原个体专用，无在场对象时排除 在场专用（在场成员与不在场队伍个体看到的命令集不同，§7.4）。
22: - **构造测试 ≠ 沙盒**：测试战斗走正常生成/战斗/捕获/结算入口（WP36/WP39/WP42 引用）——其真实副作用（图鉴登记、经验、拾取、传播、统计等）按正常规则成立；调试侧只负责候选构造与规则输入（可败、遭遇类型清空、人数布局）。
23: - **观察与修改分列**：仅展示（速度顺序、成员/队伍信息、效果当前值、寄养/漫游状态行）与写入（数值/开关/对象编辑）分开登记；观察行的「当前值」是读取时刻快照，不承诺实时刷新（各界面按自身刷新时机）。
24: - **持久归属分层**：**临时战斗态**（在场层与战斗设置——**按字段分层（R07 v3）：写穿层字段（HP/状态/状态计数/道具/等级/形态）落在持久个体上、按其后续正常生命周期演化（WP39/WP42 引用）；仅战斗层字段（战斗特性/能力阶段/能力值/类型/效果/Mega 配额等）随战斗结束消散——不声称所有在场编辑都消散**）；**运行中持久对象**（全局元数据/玩家/背包/存储/开关/变量/地图运行态上的改动——随存档保存的部分按 WP09 归属，其中临时字段为运行临时）；**显式文件写出**（动画导入导出、修复图块写地图文件、PBS 生成、编译、日志追加——各自的立即落盘语义按条登记）。**调试改变值 ≠ 正常事件调用 ≠ 会话重新初始化**；菜单效果完成后**不自动落盘存档**（保存由正常保存入口负责，WP09/WP10）。
25: - **已通过边界（必须继承，不重开）**：WP61（野外被动与回程——含 Pokérus 调试三动作合同与净化室惰性取用）、WP53（Safari/捕虫）、WP37（漫游）、WP23（Shadow/净化）、WP36/WP39/WP42/WP38（遭遇/战斗上下文/终局/捕获副作用）、WP24～WP28（玩家/存储/背包）、WP30（友好数值）、WP33/WP34/WP35（寄养/育种/孵化）、WP59（时间/场地）、WP64（Mystery Gift）、WP65（载入/暂停 UI 框架）、WP67-A/B、GR-001～016、WP23-N01。

45: ### 3.2 可见性三态与菜单交互
46: 
47: - **完整 vs 受限**：调试菜单的显示全部形参——为假时**只排除 `受限可见标记` 显式假**的条目；未设置（基线中 PBS 编辑器、其它编辑器、文件选项等菜单节点）与显式真（基线中无）都保留。**基线显式假的条目**：Field options…、Battle options…、Pokémon options…、Item options…、Player options… 五个顶层分组节点（其子项随父级不可达而整体不可见——可见性沿父级链，不是逐条打标）。
48: - **个体调试菜单的构造测试模式**：构造测试标志为真时同样**只排除 `受限可见标记` 显式假**——基线显式假的个体条目：**Set egg、Mystery Gift、Duplicate、Delete**（构造测试时这四项不出现；§6）。
49: - **交互合同（按菜单家族区分，R02 修订）**：USE——有子菜单则下钻（决定音效、光标归零）；无子菜单则调用效果；BACK——有父级返回父级（取消音效、光标恢复到当前层在父级中的下标）；无父级退出。**描述求值时机**：命令清单（含描述过程的求值）在**进入菜单时收集一次**——**下钻/返回父层只切换当前层与窗口命令名，不重新运行描述过程**（R02 v3 对照：进入一次菜单后往返层级，动态描述依赖值变化不触发重新求值）；光标移动只用已存文本刷新描述行，**不随光标移动重新求值**。**退出清理按家族分开**：地图调试菜单根退出带关菜单音效＋**淡出**＋释放窗口/视口；战斗调试菜单根退出为关菜单音效＋释放（**不走相同淡出链**）；特殊传送的整体关闭属于地图菜单（§4.1）。开关/变量页是**独立子屏幕**（§4.2——BACK 关闭子屏幕回到菜单，不算菜单内层级）。
50: - **命令返回值何时关闭菜单（R02 v3）**：**地图调试菜单**——普通效果返回值被忽略（菜单继续）；**仅地图传送项**（**仅存在于地图菜单**）的效果返回真时整体返回（其效果内部先完成自身窗口/视口清理与转移准备，§4.1）；**战斗调试菜单——普通效果返回值均被忽略，无特殊传送分支**。**个体调试菜单**——效果返回真即退出（基线中 Duplicate/Delete 返回真：编辑完成后整单关闭并回到底层界面）；取消在顶层且无父级时退出。
51: - **根取消不留副作用**：菜单框架本身不写游戏状态；所有状态写入都在各效果内（§4～§8 逐项）。

53: ## 4. WP72-B：世界情境与会话状态控制
54: 
55: ### 4.1 地图传送
56: 
57: - **目标选择**：地图选择列表默认定位在**默认图**（当前图 ID；无当前图时取系统编辑图 ID；再缺省 0）；取消 → 返回假（菜单继续、无写入）。
58: - **落点查找**：对目标图**最多 100 次随机尝试**——取随机坐标，要求严格可通行（含朝向 0 的通行判定与玩家占用语义，WP12 引用）且该格无非穿透且有图形的事件阻挡；**100 次失败则回退为一组纯随机坐标**（**不保证可通行**——不补安全落点保证）。
59: - **转移分支**：**当前是地图场景**——写转移参数（新图/落点/朝下）并调用玩家转移（正常转移链，WP11 引用）；**非地图场景**——取消载具、用地图工厂装配目标图、玩家落位朝下、地图更新与自动播放（音乐/BGS）。两分支最后都**请求地图刷新**；效果返回真——**调试菜单整体关闭**（先淡出、释放消息窗/精灵组/视口再执行转移）。
60: - **有界边界**：不补「异常回滚」或「必定成功换图」承诺；传送与正常事件传送共用底层，会话状态（跟随者/载具/临时标志）按正常规则演化，调试侧不额外复位。
61: 
62: ### 4.2 开关与变量（独立子屏幕，模式 0/1）
63: 
64: - **开关页（模式 0）**：列出系统开关名表全部条目（名表长度−1）。前缀只识别行首小写 ASCII `s:`（冒号 U+003A），全角 `s：` 不进入表达式分支。取前缀后的原表达式，以左圆括号、左方括号、等号、小于号、大于号、英文句点或 ASCII 空格为分隔字符取得首片段，去其两端空白，再只移除开头的一个感叹号 `!`；这只用于资格判断，获准时仍求值完整原表达式，不求值处理后的片段。首片段的首字符是英文字母时：大写起始仅在该完整片段是已存在的兼容常量名称时许可；常量不存在或常量名称查询失败均不许可。小写起始仅在该完整名称不是事件命令解释器方法、也不是地图事件方法时许可；这两个方法名称查询的局部失败按未命中处理。首字符非英文字母则许可。未获许可不求值、显示空值标记 [-]；许可后的求值仅将参考语言 StandardError 及其子类范围内的运行时错误局部回落空值、显示 [-]；成功真/假显示绿色 ON/红色 OFF。SyntaxError 等不在该捕获范围的求值错误从局部绘制传播，不能预期 [-]。资格前处理不受这个求值救援保护：仅 `s:` 没有首片段，在去空白时局部 NoMethodError；`s:!` 去除感叹号后没有首字符，在后续字母判断时局部 NoMethodError，均早于求值、不能当作 [-]。真实宿主如何收口未验证。USE 只翻转当前 ID 的原始开关，随后立即重绘页面并按上述规则重新求值，重绘正常返回后才请求地图刷新；不编辑表达式文字。 合法名表和当前地图、原始开关1为假：许可的非字母表达式读取同ID时 USE 后原槽真、显示 OFF→ON；许可的独立常量真表达式前后均 ON。另设许可表达式只读取初始为假的地图刷新请求标记：USE 的即时重绘仍显示 OFF，之后标记才变真，不把请求后的值倒用于该次重绘。已存在的大写常量首片段获准、不存在的大写常量首片段拒绝；不属于两类事件方法的小写首片段获准，任一事件方法名称首片段拒绝；拒绝例显示 [-] 而不求值。首片段为 `!true` 时去一个 ! 后按 true 判断资格，但求值原 `!true` 得假；静态相邻对照：`s:1/0` 的首片段非字母起始，完整整数除零求值产生可局部捕获的 ZeroDivisionError，回落 [-]；`s:1+1=2` 在等号处分割，首片段 `1+1` 的首字符非字母而获准，但仍求值完整 `1+1=2`，发生局部捕获范围外的 SyntaxError，向外传播而非 [-]。若该失败发生在USE后的即时重绘，原槽已翻转、后续地图刷新请求尚未到达；宿主异常画面、恢复和进程结局均未知，未执行这两个表达式。同字面全角 `s：` 按普通原槽假显示 OFF；仅 `s:` 与 `s:!` 各发生上述未捕获前处理局部失败。
65: - **变量页（模式 1）**：列出系统变量名表，空值显示「__」。LEFT/RIGHT数值±1（空先归0、夹±99,999,999）。USE按当前类型进入数值（最多8位/负号/同范围）或文本（250字符），其它类型不编辑。ACTION 按互斥顺序处理：0→空字符串，空字符串→0，其它数值→0，其它字符串→空字符串，其它类型不变；随后先重绘变量页，再请求地图刷新。连续两次从0得空串再0，从7得0再空串，从非空文字得空串再0；随后 USE 按当前类型进入数值或文本输入。LEFT/RIGHT及普通数值USE的分支先完成写值与刷新请求，再重绘，与ACTION的顺序分开。普通文本USE也先返回并写值、请求地图刷新，再重绘页面。
66: - **开关/变量上限**：包装类读写均限 **ID ≤ 5000**（读越界得 假/0，写越界忽略）。

131: ### 6.1 HP/异常/治疗/濒死/Pokérus
132: 
133: - **Set HP**：蛋 → 提示；范围 **0–当前最大 HP**、默认当前值，不同才写入并刷新（**可为 0**——与战斗内版分开，§7.4）。
134: - **Set status**：蛋/已濒死 → 提示；当前状态显示（睡眠带剩余回合）；**治愈**（清状态）；**赋予**：睡眠先问回合数（**0–9**、默认 3——**选 0 视为取消；按 BACK 返回默认 3，仍赋予睡眠 3 回合（无独立取消值，R03）**），随后写状态与计数（毒不细分剧毒——计数写 0，与战斗内剧毒编辑分开）。
135: - **Fully heal**：蛋 → 提示；**个体完整治疗**（WP61 合同）＋消息。
136: - **Make fainted**：蛋 → 提示；HP 写 0（**不走濒死流程**——不写友好、不触发失能链，WP20/WP61 引用）。
137: - **Set Pokérus（WP61 已通过三动作合同，继承不扩写）**：显示菌株/期限/阶段；**随机赋予**（走正常赋予入口——**已治愈仍拒绝、统计按正常规则**）；**改为不传染**（仅字段为正：保留菌株清期限 → 阶段 2）；**清除病毒**（字段清零 → 阶段 0）。**无任意菌株/天数数值输入**。
138: 
139: ### 6.2 等级/经验/EV/IV/个人 ID/友好/华丽
140: 
141: - **Set level**：蛋 → 提示；1–最大级、默认当前；不同才写——**写等级＋重算能力值**（WP19 引用）＋刷新。
142: - **Set Exp**：蛋/满级 → 提示；范围**当前级下限～下一级下限 −1**；不同才写并重算。
143: - **EV/IV/个人 ID**：EV单项上限为总额减其它项之和、再与单项上限取小，默认及取消值为当前值与此上限较小者；不同才写并重算。IV单项0–31，默认及取消为当前值，不同才写并重算；显示觉醒力量类型、威力、IV合计/最大合计及百分比，随机全体各项独立取0–31并重算。 设总额上限为 T、单项上限为 S（固定默认 T=510、S=252）。普通随机全体先均匀选整数目标 [0,T)，默认0–509；最大随机全体目标为 T，默认510。两者先把六项清0，再在剩余目标大于0时均匀随机选六项之一；该项已达S则不抽增量、重选。否则均匀抽整数1～floor(S/4)，默认1–63，先夹到剩余目标，再夹到该项距S的余量；增量为0则重试，正增量加到该项并从剩余目标扣除，直到余量0，随后重算；战斗内另按§7.4同步在场层。目标0时清零后不进入分配循环。目标整数均匀不表示最终六维分布均匀，实际随机序列未观察。 合法32位个人ID显示为 `0x` 前缀加8位大写十六进制，不足8位前补0；ID1为 `0x00000001`，ID10为 `0x0000000A`。随机ID先抽低16位、再抽高16位，各一次取0～65,535，合成32位后重算并刷新。
144: - **友好**：0–255 默认当前（数值规则 WP30）。**华丽六维**（Beauty/Cool/Cute/Smart/Tough/Sheen）：各 0–255 默认当前、写入＋刷新（字段 WP19 引用）。

146: ### 6.3 招式/PP/初始招式
147: 
148: - **Teach move**：选择后走正常学招；调试开启仍拒Shadow，只能越过普通蛋门。合法非Shadow未满容量可学，满容量走遗忘询问链（WP31/WP17），选择取消无写入，完成后刷新。战斗内独立入口见§7.4。
149: - **Forget move**：从当前招式中选（显示 PP）→ 按下标遗忘＋消息（**无「最后一招」拦截的额外描述**——按实际入口合同，WP19 引用）。
150: - **Reset moves**：**无确认**，直接按野生应有招式重置＋消息（WP19/WP36 引用；与战斗版的确认要求不同，§7.4）。
151: - **Set move PP**：逐招式（**遇空招式位停止列举**）——PP 无限 → 提示；否则**设 PP**（0–当前总 PP）、**补满**、**设 PP Up**（0–3；写入后 PP 超新总值则钳到总值）；**Restore all PP**（全体恢复，WP61 治疗合同引用）。
152: - **Reset initial moves**：把当前招式**记录为初始招式**＋消息（初始招式字段 WP19/WP31 引用）。

154: ### 6.4 物品/特性/性格/性别/物种/形态
155: 
156: - **Set item**：**改**（道具列表默认当前；不同才写——**邮件道具同时新建默认邮件**（文本「Text」、署名玩家名））；**移除**（有道具才清——**同时清邮件**）。
157: - **Set ability**：显示当前解析特性与特性位；**设可能特性**按 [WP19 §3.4](../pokemon-rules/wp19-attributes-ability-and-stats.md) 的完整候选序列逐对列出，任何索引 ≥2 均带 (H)，包括第三自然项；索引冲突项均保留。正常选择只写所选特性位并清缓存，不直接赋显示身份；取消不写，刷新后的解析仍按 WP19，显示名可以与实际身份不同。**设任意特性**从全特性列表直接写身份、不改特性位；**重置**清特性位和特性，恢复按个体 ID 的自然解析。
158: - **Set nature**：性格列表（带 ±能力变化标注）当前预选；**设**（写性格）；**重置**（清性格——恢复自然性格，WP19/WP30 引用）。
159: - **Set gender**：单性别/无性别 → 提示；**男/女**（走性别写入入口——不可变时给「无法改变」消息，WP19 引用）；**重置**（清性别——恢复自然性别）；每次操作后按 §6 门做图鉴登记。
160: - **Species/form**：**设物种**（物种列表默认当前；不同才写＋重算＋图鉴登记门）；**设形态**（同物种形态列表——仅一个形态：提示并在当前形态非 0 时给「重置为 0？」确认；多形态：选择——**该物种自决形态时给「覆盖？」确认**（确认才写强制形态标记）；普通形态提交＋处理器后置显式图鉴登记门）；**移除形态覆盖**（清强制形态标记）。WP21 形态合同引用。 玩家/图鉴存在且处理器、重算及刷新依赖正常时，成功普通提交登记见过、按图鉴形态归一的见过形态，并只在末次记录尚空时初始化；不由此置拥有或见过蛋，也不自动写存档。准备真/假、蛋/非蛋都可沿这条底层链登记；原后置门只决定是否额外显式登记。SHELLOS0→1、目标1未见且无强制/动态/插件干扰时可隔离验证本次写入，创建已造成的记录不计作本次效果。该夹具 BACK/选同形态不执行目标提交；不推所有菜单读取无副作用，动态读取另依 WP21，显示读取亦复用该规则。单形态重置0的提交需已有非0状态，不作为默认正常样本。处理器/重算先失败可不到登记；登记写见过/形态后刷新失败不撤回前序写入。
