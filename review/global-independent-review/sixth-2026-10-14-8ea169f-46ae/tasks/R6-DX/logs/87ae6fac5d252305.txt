1: # 世界编辑器（地图连接/地图元数据/地形标签/遭遇/指标）行为规格（净化正文；批次 15）
2: 
3: 分类：demo-dx（主）／engine-overworld（地图/图块组/连接/小地图）／generic-kernel（登记、档案与文本编译交界）／user-interface（可视化画布/选择器）；性质：实现独立行为规格。
4: 
5: 本稿为净化正文的一部分：按统一交接将批准输入 WP73-B《世界编辑器》转写为独立行为文字，不含源文件路径、行号、脚本入口名与类名（源定位集中登记于 `../../audit/source-traceability.md` 批次 15 条目）。范围：地图连接可视化编辑器、地图元数据编辑器、地形标签编辑器、遭遇编辑器（集/类型/槽三层）、指标编辑器与全量自动定位、无效图块修复的输入、校验、取消、保存与反写合同；资源关联核验与无资源边界。编辑器实现是作者行为要求的参考，不作为未来编辑器的布局或交互设计模板。全部内容为静态证据；**无运行确认**（见 `../scope-statement.md`）。
6: 
7: ## 1. 目的、范围与非目标
8: 
9: **目的**：固定世界编辑器的规则合同——**每个编辑器读什么输入、坐标/地形/遭遇/指标如何校验、取消时是否仍写入、登记/档案/PBS 与当前消费者何时变化、数据与地图/图块组资源的关联如何核验、无资源时哪些操作不可确认**。后续包据此判断「某次编辑改了哪些文件，哪些读取方仍使用先前状态」。
10: 
11: **范围**：1) 地图连接可视化编辑器：画布与邻居递归摆放、增删图、拖拽、连接数据生成（邻接判定与对称去重）、保存与取消。2) 地图元数据编辑器：属性框架复用与即时落盘。3) 地形标签编辑器：图块组载入、标签设置（含自动图块整组语义）、保存与宿主提示。4) 遭遇编辑器：集/类型/槽三层编辑与退出确认。5) 指标编辑器与全量自动定位：单项定位/阴影尺寸/单体自动定位/全量自动定位的算法与落盘。6) 无效图块修复（WP72 入口引用，本稿主责其合同）：全地图扫描、有效性判定、写 0 与地图文件保存。
12: 
13: **非目标**：内容编辑器由 WP73-A 主责（训练家类型/训练家战斗/道具/物种/全局与玩家元数据/地区图鉴——本稿复用属性编辑与列表选择的行为合同）；动画工具归 WP74，编译器全集与文件更名/转换归 WP75。遭遇/地图/地形/指标的数据语义分别归 WP36/WP11/WP12/WP15/WP16；本稿固定编辑操作及保存、生效边界，并继承 WP04 的 PBS 编译/反写合同。WP73-A 的属性框架与选择器、WP72 的调试入口均为引用范围，不据此作其通过结论。不运行编辑器/编译器/反序列化、不写 PBS/.dat/地图/图块组文件、不操作真实存档、不调整宿主界面、不设计未来编辑器布局或 API。
14: 
15: ## 2. 概念与术语
16: 
17: - **登记、文件与消费者**：登记数据、保存的 `.dat` 档案和反写的 PBS 是分别变化的状态，当前地图遭遇快照及已有战斗布局还须单列，不能概括为保存即热更新。**连接**＝退出确认时保存 `Data/map_connections.dat`、随后反写连接并清连接缓存；**地图元数据**＝确认属性后更新登记、保存档案、反写地图元数据；**地形标签**＝退出确认时写 `Data/Tilesets.rxdata` 并使运行图块组与会话共享当前内容，提示重启 RMXP；**遭遇**＝退出确认时先保存档案再反写 PBS，否则从档案重载登记（§6.4–§6.5）；**指标**＝有确认的指标改动且同意保存时先保存档案，随后按保存时记录集合选择 PBS 路径，否则重载登记（§7.5）；**修复图块**＝逐图立即保存，无总确认。文件顺序不构成总事务或消费者刷新保证。
18: - **小地图与画布**：小地图生成入口（WP16 引用）生成每格 4 像素的地图缩略图；连接编辑器以**网格对齐（坐标向下取整到 4 的倍数）**摆放缩略图；**画布上的图只是编辑会话内的摆放**——删掉画布上的图不删连接数据本身，连接数据由**生成算法**按当前画布重算（§3.3）。
19: - **连接数据形态**：原始连接为**边＋坐标**形式（`[图1, 边1, 坐标1, 图2, 边2, 坐标2]`——N/S/E/W 边经地图连接存取惰性装载时换算为坐标对并**过滤尺寸为 0 的无效图**）；编辑器生成的连接为**相对坐标差**形式（`[参照图, 0, 0, 目标图, dx, dy]`，dx/dy 为缩略图坐标差除以 4——即地图格数差）。
20: - **邻接判定**：坐标单位为地图格（缩略图像素差 ÷4）——**x 差等于对方图宽或己方图宽取负，或 y 差等于对方图高或己方图高取负**即视为邻接（边贴边的**单轴条件**）：**不检查另一轴重叠**——错轴也可成邻接（两张 10×10 图放在像素 (0,0) 与 (40,400)：横差满足条件即成邻接，纵向并未对齐）。**逐节点回退**：仅某图没有任何直接邻接时，才回退与（非自身的）第一个画布图建立连接——**两组各有邻居时不补跨组连接，不保证全图连通**（两对各自相邻且相互远离的图可保留两个连通分量）。
21: - **对称去重**：新连接与既有连接**完全相同**或**镜像对称**（两端互换且坐标差取负）时不重复添加。
22: - **地形标签的自动图块语义**：图块 ID < 384（每行 8、每自动图块 48）时**设置整组 48 个标签**；≥384 时设置单个标签。384 是两种图块处理的分界。
23: - **指标**：每物种×形态的显示参数——背面位置、正面位置、正面高度、阴影横移、阴影大小（0＝无，编号对应阴影图形）；PBS 对应数据名为 `BackSprite`、`FrontSprite`、`FrontSpriteAltitude`、`ShadowX`、`ShadowSize`，位置各含 x/y。**自有阴影图形**（按物种/形态命名）存在时，阴影大小不可编辑（§7.3）。档案为 `Data/species_metrics.dat`；查询可先惰性建立非零形态指标并带空来源后缀，输出路径／已有布局的消费边界见 §7.5。
24: - **底部探测（自动定位算法）**：从位图底行向上找到**首个 alpha>0 像素**所在行（全透明位图返回 0）——bottom；非负坐标公式为**向下取整的整数除法**：**y＝（位图高 − bottom − 1）÷ 2 向下取整**（正面位再＋4；例：高 32、底部行 24 → 背面 3／正面 7；全透明高 32 → 15／19）。**缺图与透明图分开**：缺图由调用方分支处理（§7.4 矩阵）；透明图按公式退化计算。写字段按单体/全量分列（§7.4）。
25: - **资源关联核验**：**有资源才能确认的操作**——地形标签编辑要求图块组数据可装载（编辑器直接数据装载，WP04/WP10 边界）；指标编辑的**预览**要求对应物种/形态图形存在（缺失时预览为空——**预览回落不等于全部操作安全**：单项定位/阴影尺寸按数值编辑仍可进行，**单体自动定位直接读两位图高度——缺图可失败（与全量缺图跳过分开，不以可手改数值推断全部操作可安全完成）**）；**自有阴影图形存在时阴影尺寸编辑被拒绝**；**无资源时**小地图/预览仅显示层回落。
26: - **已通过边界（必须继承，不重开）**：WP04、WP11、WP12、WP15、WP36、WP16、WP59、WP61、WP53、WP37、WP65、WP67-A/B、GR-001～016、WP23-N01。**同批待审依赖（引用其合同，不作通过结论）**：WP73-A（属性框架/列表器/登记、档案与文本持久/选择器）、WP72（调试入口与工具归属）——**当前身份见登记清单，不沿用 v1 短哈希**。

28: ## 3. 地图连接可视化编辑器
29: 
30: ### 3.1 打开与画布
31: 
32: - **打开**：屏幕尺寸**宽高各＋288**（临界段包裹，结束后恢复原尺寸与缩放因子）；初始图：当前图（无当前图取系统编辑图 ID，再缺省 1）居中摆放并**递归摆放全部邻居**（按既有连接偏移 ×4 递归）。
33: - **画布元素**：每图一个缩略图精灵（网格对齐）；选中框（红色描边跟随选中图）；底部「D: Help」提示行；帮助窗（D 键——按键清单）。
34: - **既有连接装载**：既有连接按需载入，含坐标换算与无效图过滤（§2）；编辑会话取得独立副本，并去除两端完全重复项。
35: 
36: ### 3.2 编辑操作
37: 
38: - **A 键（Add map）**：地图列表（WP73-A 引用）选图 → 居中放入画布（网格对齐）＋置顶 → **立即重算连接数据**（§3.3）。
39: - **S 键（Go to map）**：选图 → **先重算当前画布连接数据**（保存当前成果为会话连接）→ 清画布 → 以新图为根重新摆放（含邻居递归）。
40: - **DEL 键（Delete map from canvas）**：画布图数 >1 且有选中 → 从画布移除该图（**只移出画布——连接数据不因此删除**；下次重算时被移出的图不再参与）。
41: - **单击**：选中（红框、置顶、标题行显示图名）＋开始拖拽（**拖拽落点同样网格对齐**）；**双击（0.5 秒内）**：打开该图的**地图元数据编辑**（§4——WP73-A 属性框架复用）。
42: - **拖动画布空白**：记录各图位置后整体平移（网格对齐）；**方向键**：全画布 4 像素步进平移。
43: - **D 键**：帮助窗（USE/BACK 关闭）。
44: 
45: ### 3.3 连接数据生成与保存
46: 
47: - **生成算法**：先取会话连接的独立副本；**画布少于两图时直接保留该副本**（0/1 图分支不执行任何删除，旧连接全保留，包括触及画布图的连接）。至少两图时，删除所有触及当前画布图的旧连接；对每个画布图与每个其它画布图，按缩略图坐标差 ÷4 求直接邻接：**x 差等于对方图宽或己方图宽取负，或 y 差等于对方图高或己方图高取负**即邻接，**不检查另一轴重叠**。某图没有任何直接邻接时才回退连接画布首个其它图；不保证全图连通。按 `[参照图, 0, 0, 本图, dx, dy]` 的连接数据形式生成结果，完全相同或镜像对称的连接只保留一次。
48: - **保存**：BACK → **「Save changes?」确认** → 把生成结果写入 `Data/map_connections.dat`、反写连接、清连接缓存，并使会话后续使用该生成结果。**不确认时分三种状态**：连接会话成果不落盘；只从档案重载遭遇登记（未保存遭遇改动丢弃，当前地图遭遇快照不重装——§6.5）；地图元数据不重载，双击进入并已确认保存的元数据改动保留。共享嵌套内容（如地图尺寸）的未保存变化也不由遭遇重载恢复，不能补成统一事务。随后 **「Exit from the editor?」** 确认才退出，否则回到画布。
49: - **边界**：生成只覆盖**画布上的图**——未触及画布图的既有连接原样保留；**不校验生成连接的图是否存在/有资源**（装载期过滤归 WP11 的连接读取合同）。
50: 
51: ## 4. 地图元数据编辑器
52: 
53: - **顶层**：起始地图 ID 仅用于地图列表预选；默认列表不带 GLOBAL 项，正常结果只返回地图，取消返回负值。选图后编辑该图元数据。内部存在全局元数据支路，但直接传 0 仍先进入地图选择器，普通实参不能由此绕过列表；**人工替换选择器结果为 0 属人工注入条件**。全局元数据正常入口是 metadata.txt 编辑器的 [GLOBAL METADATA] 项（WP73-A 引用）。
54: - **编辑**：图名取自地图信息；元数据不存在时先建立含该地图 ID 的初始记录。按属性列表编辑，**确认保存**后，将确认后的属性与原来源文件后缀登记为该图元数据，再保存档案并反写地图元数据；该保存无额外退出确认。嵌套属性的共享变化与父页是否保存分开（WP73-A 引用）。
55: - **从连接编辑器双击进入**时同此合同（保存即时）；连接取消只重载遭遇登记，不重载地图元数据、不撤销已保存元数据，共享嵌套内容的未保存变化也不恢复（§3.3）。
56: 
57: ## 5. 地形标签编辑器
58: 
59: - **打开**：屏幕**高 ×2**（结束后恢复）；**载入图块组数据全量**（数据装载——反序列化边界，WP04/WP10 引用）；初始图块组 1。
60: - **显示**：每行 8 块 ×32 像素；**首行为自动图块行**（每自动图块 48 块）；覆盖层显示**非 0 标签数字**；右侧 400% 放大当前块＋标签名（地形标签数据存在则显示 `编号: 名称`，否则只显示编号）；品红衬底。
61: - **导航**：方向键（repeat）逐块、**JUMPUP/JUMPDOWN 半页**、ACTION 菜单（**Go to bottom／Go to top／Change tileset**——图块组列表切换）。
62: - **编辑**：USE → 标签列表（**脚本注册的标签**——本基线默认注册 ID 0–17，**不是 PBS 文件**；当前标签预选）→ 写入门比较**所选序号与旧标签 ID**——**默认连续 ID 时等效**；**自定义稀疏 ID（配置夹具）时序号与 ID 错位：可能跳过或冗余写入**（夹具例：注册 ID 0、2、5，旧值 2，选序号 2 代表 ID 5——门误判无需改变，旧值仍 2；不创建/修改 reference 配置）——写入时**自动图块（ID<384）整组 48 个同写；普通块单写**；随后刷新覆盖层。
63: - **保存与内存**：BACK → **「Save changes?」确认** → 把会话图块组数据写回 `Data/Tilesets.rxdata`，运行图块组改为与会话共享当前可变内容，并提示 **「为确保更改保留，请关闭并重新打开 RPG Maker XP」**（宿主数据双份语义——WP10/WP75 边界）。随后 **「Exit from the editor?」** 确认才退出。①首次未保存：Save No＋Exit Yes 丢弃会话，文件/运行数据不变；Save No＋Exit No 继续编辑、会话保留。②保存退出：文件与运行数据同更新。③保存后继续再放弃：后续会话编辑也改变共享的运行内容，再次 No 只是不写文件、不重载；标签 A→B 保存 Yes/退出 No，再 B→C 保存 No/退出 Yes，**文件 B、运行内存 C**。关闭时装配地图仍从运行数据取图块组，不重载文件。**宿主重启提示不立即撤销更改**。
64: - **关闭**：恢复地图装配、玩家居中、地图显示重建。
65: - **资源关联**：图块组来自 RMXP 工程文件 `Data/Tilesets.rxdata`，不是 PBS/.dat 游戏数据；可选地形标签来自已注册目录（WP12 引用），**没有 terrain_tags.txt 来源**。标签 ID 与名称只在显示时核验：存在才显示名称；未知旧值可显示数字，但可选集合仍是已注册 ID，不能由此任意输入。
66: 
67: ## 6. 遭遇编辑器
68: 
69: ### 6.1 集列表
70: 
71: - **列表**：全部遭遇集——显示 `地图ID[(v.版本)][: 图名]`（图名缺失省略）；**[Add new encounter set]** 在首。
72: - **新建**：地图列表（默认图）＋版本（0–999，取消 → 放弃）→ **已存在检查**（同图同版本 → 消息拒绝）→ 注册步数率与类型槽均为空的集，并定位光标。
73: - **已有项**：**Edit**（§6.2）／**Copy**（目标图＋新版本，冲突拒绝；逐项复制全部步数率，但只为含槽的类型建立目标类型并复制各槽内容，使源集与副本后续编辑独立，保留来源文件后缀）／**Delete**（确认 → 删除登记中的该集）。
74: - **整集复制的空类型边界**：正常新增类型后不加槽直接 BACK，可使源集保留该类型并显示 `类型 (x0)`（§6.2）。整集 Copy 不为这样的零槽类型建立目标类型条目，仍复制它的步数率，源集不变。静态对照：合法源集（图 5，版本 0）仅有 Land 零槽、Land 步数率 21，复制至未占用的（图 7，版本 1），无插件或外部修改；目标登记保留来源后缀与 Land 率 21，类型列表没有 Land，打开目标可再次新增 Land（新增列表按类型条目判定已用，不按残留步数率）。这是合法编辑边界；有一个合法槽的 Land 正例仍保留类型和独立槽副本。复制本身只登记，尚未退出总保存门时档案与 PBS 不写；退出 No 从原档案重载，若原档案无目标集，则该未保存副本消失（§6.5）。此处结果来自静态推导，未执行编辑器，不据此推定真实遇敌差异或选择未来兼容政策。
75: - **保存**：BACK → **「Save changes?」确认** → 先保存遭遇档案，再反写遭遇 PBS；否则从档案整体重载登记，含恢复删除。两分支均不重装当前地图快照。合法 0 的文件结果见 §6.4，登记与消费者的状态见 §6.5。
76: 
77: ### 6.2 集内编辑
78: 
79: - **图 ID 行／版本行**：改图或改版本——目标（图,版本）冲突时消息拒绝；通过后不再以旧组合登记，改以新组合登记。这里编辑的是遭遇集标识，**并非全局当前遭遇版本的写入**，不因此刷新当前地图（§6.5）。
