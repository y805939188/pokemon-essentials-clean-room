632	#===============================================================================
633	# Evolution methods that are triggered by an event
634	# Each event has its own number, which is the value of the parameter as defined
635	# in pokemon.txt/pokemon_forms.txt. It is also 'number' in def pbEvolutionEvent,
636	# which triggers evolution checks for a particular event number. 'value' in an
637	# event_proc is the number of the evolution event currently being triggered.
638	# Evolutions caused by different events should have different numbers. Used
639	# event numbers are:
640	#   1: Kubfu -> Urshifu
641	#   2: Galarian Yamask -> Runerigus
642	# These used event numbers are only used in pokemon.txt/pokemon_forms.txt and in
643	# map events that call pbEvolutionEvent, so they are relatively easy to change
644	# if you need to (no script changes are required). However, you could just
645	# ignore them instead if you don't want to use them.
646	#===============================================================================
647	def pbEvolutionEvent(number)
648	  return if !$player
649	  $player.able_party.each do |pkmn|
650	    pkmn.trigger_event_evolution(number)
651	  end
652	end
