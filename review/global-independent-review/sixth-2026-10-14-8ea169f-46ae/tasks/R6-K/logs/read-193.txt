147	### 4.4 双打判定
148	
149	- 强制单打标记 → 假；Safari 中 → 假；有伙伴训练家 → 真；可战斗成员数 ≤ 1 → 假；脚下地形标记「双打遭遇」 → 30% → 真；否则假。

151	### 4.5 步进入口全程
152	
153	1. 前置早退链：可战斗成员数 = 0 → 返回；机会判定（§3.4）为假 → 返回；类型为空或触发（§4.2）为假 → 返回。早退不一定到达末尾的 force_single 复位（静态边界）。
154	2. 写临时字段 encounter_type；选择候选（§5.1）；触发「野生物种已选择」钩子。
155	3. 允许判定（§4.3）为真时：需要双打则再选第二候选（并再触发选择钩子）→ 发起野生战斗（候选[, 第二候选]，可覆盖 = true）；调用正常返回后（不取决于战斗启动的布尔结果）清 encounter_type、置临时标记 encounter_triggered = true——该标记的直接消费者是同次普通移动入口的移动门（WP12：为真时跳过本次移动/触碰/碰撞，末尾清标记；GR-011）。
156	4. 无论结果：临时字段 force_single_battle = false。
157	- 若允许判定为假（如驱虫剂挡住）：encounter_type 保留（不清理）——静态边界记录。
158	- 强制移动/地图解释器运行时：普通步进入口在计数与事件链之前分流（转「步进」通知后返回），不走通常的步数增量和迈步处理器链——遭遇链不会以本次步进为输入。

162	## 5. 候选选择与等级
163	
164	### 5.1 当前地图选择（类型， 掷取次数 = 1）
165	
166	1. 类型校验、取表；空表 → 空。
167	2. 偏好过滤（「首非蛋成员」特性）：引火 → 火（需扩展配置+类型存在+50%）、收获 → 草（同前）、避雷针 → 电（同前）、磁力 → 钢（类型存在+50%，不看扩展配置）、静电 → 电（类型存在+50%，不看扩展配置）、引水 → 水（需扩展配置+存在+50%）；命中则筛出含该属性的槽位（筛空则不筛，保留原表）。
168	3. 按权重降序排序；总权重 = Σ 权重。
169	4. 掷取：做指定次数的 0 至（总权重−1）均匀抽样，取最大值（多次掷提升稀有槽命中）；沿排序表用该值递减定位槽位。
170	5. 等级：区间 [最低， 最高] 均匀抽样（含端点）；随后首非蛋成员特性为 HUSTLE（活力）、PRESSURE（压迫感）或 VITALSPIRIT（干劲）时 → 50% 取最高等级；GUTS（毅力）不在此集合、不消耗该能力百分掷；地图级黑白哨新效果——降等级：等级 − 1..4 抽样 钳制 ≥ 1；升等级：等级 + 1..4 抽样 钳制 ≤ 最大等级（降优先）。

178	## 6. 个体生成与修正（物种， 等级， 漫游 = 假）
179	
180	1. 以物种+等级创建个体（WP18–WP21 创建默认与派生引用）。
181	2. 持有物：读取物种的野生持有物三档；基础概率 [50, 5, 1]；首非蛋成员复眼/超幸运（后者需扩展配置）→ [60, 20, 5]；若三档同物 → 恒取第一档；按掷值落档后从该档随机采一枚。
182	3. 闪光重掷：次数 = 背包持有闪耀护符 ? +2 : 0；若启用按对战次数提高闪率配置——按图鉴「对战次数」分档（< 50 → 0；50–99 概率 15‰ 加 1；100–199 概率 20‰ 加 2；200–299 概率 25‰ 加 3；300–499 概率 30‰ 加 4；≥ 500 概率 30‰ 加 5）；次数 > 0 时循环：已闪光停止，否则清闪光缓存并重掷个体号（与蛋的重掷同构，WP34 引用）。
183	4. 病毒：0–65535 抽样 < 病毒概率 → 给予（毒株随机 1–15，统计 +1；WP61 前向）。
184	5. 性别/性格倾向（「首非蛋成员」，允许濒死）：迷人身躯且目标非单性别——首成员为雄性：2/3 强制雌性、其余 1/3 强制雄性；首成员为雌性：2/3 强制雄性、其余 1/3 强制雌性；首成员无性别：不执行这两种赋值（分支列表完整，非「不命中则保留默认」）。同步（非漫游个体；需扩展配置或另掷 50%）→ 性格 = 首成员性格（改写已派生缓存，WP19 引用）。
185	6. 记录初始形态（形态函数存在时），触发「野生个体已创建」钩子（示例目录见 §6.1）。
186	7. 返回个体（未入队；开战由调用方发起）。

199	### 6.2 队伍平衡等级（独立数学合同）
200	
201	输入为传入队伍的全部成员等级 l₁..lₙ，包含蛋与濒死成员，不先按可战斗资格过滤；最大等级记为 M（默认100）。空输入或等级和 S=0 时直接返回1（零等级和为人工输入边界）。否则 μ=S/n，人口标准差 σ=√(Σ(lᵢ−μ)²/n)，初始占比 pᵢ=lᵢ/S。权重按占比分段：pᵢ<0.5 时 wᵢ=max(pᵢ−σ/M,0.001)，pᵢ≥0.5 时 wᵢ=min(pᵢ＋σ/M,0.999)。以 W=Σwᵢ 归一，加权均值 a=Σ(lᵢwᵢ)/W；将 a 四舍五入到整数（正数半值向上），先限制不低于1，再加2并限制不超过 M：平衡等级=min(max(round(a),1)＋2,M)。
202	
203	固定静态对照：M100、[5,5] → σ0、权重各0.5、平衡等级7，示例缩放7−4＋0..4 → 3..7；[10,50] → σ20、权重0.001/0.999、加权49.96→50→52，缩放48..52。空队伍→1；人工[0,0]→1；[100,100]→100（加2后上限约束）。此处集中提供可供 WP77 等消费者引用的数学规则，未修改其责任文件或执行算术/行为向量。

207	## 7. 开战交接与状态生命周期（按入口分列）
208	
209	- 禁用开关：encounter_disabled 只在触发检查（§4.2 第 1 步）读取——登录的主动请求路径不读它，也不调用机会/驱虫剂允许判定。各族对照：碎石请求先过触发检查（因此受禁用影响）；摇树/甜味/钓鱼的主动请求不受该开关约束（静态边界；钓鱼引用遵循本节，不复写）。
210	- 临时字段 encounter_type：步进入口在开战前写入；清理只在开战调用正常返回后执行（不取决于战斗启动的布尔结果）；允许判定拒绝时保留（§4.5）。
211	- 主动请求包装（类型， 仅单打 = true）（钓鱼/摇树/碎石/甜味调用）：
212	  1. 写 encounter_type；选第一候选；触发物种钩子。
213	  2. 第一候选为空 → 返回 false（类型值保留、原 force_single 不复位——静态边界）。
214	  3. 不强制单打且双打条件成立 → 选第二候选（再触发钩子）；第二候选为空 → 返回 false（同上保留）。
215	  4. 否则发起野生战斗（候选[, 第二候选]，可覆盖 = true）；调用正常返回后清 encounter_type、复位 force_single_battle、返回 true（即使战斗启动返回假，也执行清理并返回真）。
216	  - 甜味以「仅单打 = false」调用（可双打），其余为单打默认。
217	- 临时标记 encounter_triggered：仅用于当次标记——生产端仅为步进/转向检查链在开战调用正常返回后的置真步骤（§4.5）；主动请求包装本身不写该标记：其开战调用正常返回后只清 encounter_type、复位 force_single_battle 并返回 true——初始标记为假时包装返回后仍为假；原值为真且无其他写入时，包装也不会自行清掉（GR-011 v2）。直接消费者为同次普通移动入口的移动门（WP12：为真时跳过该次移动/触碰/碰撞并在方法末尾清标记）；独立转向默认路径在通知后清标记，步后入口在其自身末尾清标记。
218	- 临时字段 force_single_battle：正常路径复位；更早的前置拒绝不一定到达复位点（§4.5 第 1 步）；漫游/雷达设置（WP37 引用）。
219	- 生命周期终态（按入口分列；早退，静态）：
220	  - 步进触发检查假 → 无写入（§4.5 第 1 步早退；不下探后续分支）。
221	  - 主动请求包装：第一或第二候选为空 → 返回 false，已写类型与原 force_single 保留；开战调用正常返回（含战斗启动返回假）→ 清类型、force_single = false、返回 true。
222	  - 步进入口：已到达允许拒绝阶段 → 已写类型保留，但方法末尾仍执行 force_single = false；开战调用正常返回 → 清类型、置 encounter_triggered、force_single = false（不套用主动请求包装的 true 返回合同；该路径没有主动请求的成功布尔保证）。
223	  - 更早的步进前置拒绝按 §4.5 第 1 步早退前提，不泛化为「所有拒绝都清理」。
224	- 两入口不共用同一张终态表；「正常返回后清理」不等于「战斗成功后清理」。
225	- 战斗启动本身（阵容、规则、环境）归 WP39/WP45/WP53 前向；本规格只固定「已发起调用」与上述临时状态；调用 ≠ 实际战斗成功。

229	## 8. 规则与不变量
230	
231	1. 数据键「地图×版本」、版本查询回退 0、重复定义编译错误；每表类型独立、步骤概率缺省来自类型目录。
232	2. 步进触发的三道前置门（可战斗成员/机会判定/类型非空）+ 概率门（§4.2）；主动请求入口按各族自己的前置（不经机会判定与概率门）。
233	3. 类型选择严格「已定义才选」；时段细分优先于 Day/Night 基础，night 未定义回退基础；无表不选。
234	4. 概率链的修正按固定顺序应用（累加折算与自行车在地图级与道具/特性修正之前）；清除累加器发生在：步数重置入口（冲浪起止/战斗交界）、驱虫剂挡下、驱虫剂活动时未中；装图/版本装载保留累加器；累加只在「步进触发且经宽限后常规掷未中」发生（宽限放大掷拒绝不累加）。
235	5. 闪光/病毒/性别/性格等生成期修正不改候选选择；选择期修正（偏好过滤/哨）不改生成期概率。
236	6. 双打判定的优先次序：强制单打 > Safari > 伙伴（真） > 成员数（假门） > 地形 30%。
237	7. encounter_type 生命周期与清理按 §7；拒绝路径保留值。
238	8. 所有等级取整为整数区间均匀（含端点）；偏好过滤失败不产生空表（保留原表）。

240	## 9. 边界与失败
241	
242	- 无表/空表按阶段区分：冲浪使机会判定为真，即使无任何表；随后 Water 类型为空则步进拒绝。非冲浪、无 land/contest/cave 非空表时机会为假。仅 BugContest 非空且允许陆地遭遇的非冰地形、大会进行中 → 机会真、类型 BugContest；不预设后续概率通过。请求自己的类型无表才无法选候选；无 land/cave/water 不排除独立合法 OldRod 表（正常开战调用返回时主动包装返回真）。
243	- 禁用：encounter_disabled 只在触发检查层否决（含雷达：直通位于禁用检查之后）；主动请求路径不受该开关约束（§7）。
244	- 强制移动/地图解释器运行时：普通步进在计数前分流，本次步进不进入遭遇链（§4.5）。
245	- 调试模式+Ctrl：仅抑制触发（搭配调试穿透移动，WP12 引用）。
246	- 驱虫剂挡住：允许判定拒绝后累加器清零；encounter_type 保留（§7）。
247	- 候选空：主动请求包装早退——类型保留、原 force_single 不复位（§7 终态表）。
248	- 版本回退：支持版本回退的数据读取在当前版本表缺失时落到版本 0；版本号异值且必要上下文存在时装载当前地图表；枚举反例见 §3.1（不传播到单次查询）。
249	- 宽限：放大掷拒绝不累加；宽限通过、常规掷失败才累加（§4.2）；概率被修到 0 → 阈值 0 → 放大掷必假。
250	- 偏好过滤后空表：保留原表（过滤无效，不影响可得性）。
251	- 等级钳制：哨效果钳制到 1..100（升等级上限 = 最大等级）；区间取整含端点（单等级行 min = max）。
252	- 双打第二择空：主动请求包装返回假、不开战（第一候选不消耗，状态保留见 §7）。
253	- 真实地图编排、概率分布抽样验证与开战集成：运行未决（U01/运行范围）。
