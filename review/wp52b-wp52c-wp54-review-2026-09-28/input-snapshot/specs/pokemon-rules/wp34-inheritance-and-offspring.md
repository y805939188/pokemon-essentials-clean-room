## 1. 目的、范围与非目标

**目的**：定义"由两名寄养个体生成一枚蛋"的全部行为——亲本归一与角色、后代物种/形态确定、蛋的基础字段、Nature/特性/招式/IV/球/异色/病毒等继承或生成通道、确定性顺序与随机通道的输入/候选/概率；供孵化（WP35）、寄养（WP33）、事件赠蛋（WP26 交界）引用。

**范围**（WP34 自身声明范围，extraction-plan 第 2.1 节 (a) 类）：

1. WP34-A：亲本归一——性别/Ditto 的槽序交换与"物种亲本/招式提供方"角色定义。
2. WP34-B：后代物种——前身回溯与熏香门、后代替换采样、地区形态生成钩子。
3. WP34-C：基础蛋创建——等级/名称/孵化步数/来源文本/友好/特殊形态重置。
4. WP34-D：继承通道——形态、Nature、特性、招式、IV、球、异色重掷、病毒；各自的输入、候选、抽取/去重/顺序与互斥。
5. WP34-E：生成顺序与随机独立性——一次生成的固定次序、随机通道清单与组合边界。
6. F09-06 中属于 WP34 部分的状态更新。

**非目标**：

- 不定义寄养会话、周期、兼容性与领取（WP33 引用）；不定义蛋的计步/孵化/命名演出（WP35）。
- 不重定义 IV/Nature/异色/特性的派生公式与域（WP19 引用）、招式槽/学习接口（WP20 引用）、形态处理器（WP21 引用）。
- 不定义蛋组/熏香/后代等数据字段的全集语义（WP03/WP18 引用）；不展开配置插件组合（U09）。
- 不运行游戏或参考生成器；不设计未来框架的遗传 API。

## 2. 概念与术语

- **亲本归一**：把传入的两名个体调整为"母/父"角色（**单次交换、不复查**——结果**不保证**"母非雄/父非雌"，Ditto 边界见 §3.1/§9.3）；归一后的"母/父"是**通道分派角色名**，不等于最终生物性别。
- **物种亲本**：决定蛋基础物种的一方——若"母"为 Ditto 蛋组则取父，否则取母（§3.2）。
- **族内标志（in_family）**：亲本是否"能产出该后代物种"（按家族/后代关系判定）；影响形态继承、球继承与特定招式（§3.3）。
- **前身回溯**：把物种沿前身条目回到最初阶段；携带熏香门（§4.1）。
- **后代替换（offspring）**：物种数据登记的候选后代列表；非空时**随机采样**替换确定结果（§4.2）。
- **抽取/重掷**：随机通道分两类——从固定候选集合无放回或可重复采样（Nature/IV 项/父母值/球），与"检定+至多重掷 N 次"的异色重掷（§10）。

## 3. WP34-A：亲本归一与角色（静态核对）

### 3.1 槽序交换规则

传入两槽个体后，**当且仅当**满足以下任一条件时交换两方：① "母"为雄性；② "父"为雌性；③ "母"为无性别。交换后不重复检查（单次交换）。

| 槽序示例 | 交换 | 归一后（母 / 父） |
| --- | --- | --- |
| ♀ / ♂ | 否 | ♀ / ♂ |
| ♂ / ♀ | 是 | ♀ / ♂ |
| ♂ / Ditto | 是（母为雄性） | Ditto / ♂ |
| Ditto / ♀ | 是（母为无性别） | ♀ / Ditto |
| Ditto / ♂ | 是（母为无性别） | ♂ / Ditto |
| ♂ / ♂ 或 ♀ / ♀（不兼容对） | 至多一次交换 | 不保证归一；常规门控在 WP33 周期层已确认、事件接待仍待 U01（见下注） |

> 表的边界记录：**单次交换不复查**，"母/父"只是后续通道的角色名，**不保证最终生物性别**——例如 Ditto/♂ 交换后"母"仍为雄性；Ditto/♀ 也发生交换（两种槽序归一后同为 ♀/Ditto，不是"不交换"）。共同等级招式要求**双方（含 Ditto）都掌握**；机器与两路蛋招的性别门控后果见 §9.3。**生成/领取领域工具自身不重查兼容性**（WP33 §5.3）；"不兼容对"的豁免在 WP33 的**周期置标记层已确认**；**事件接待实际守卫仍待 U01**，静态边界记录。

### 3.2 物种亲本与招式提供方

- `mother_ditto`＝"母"方蛋组含 Ditto；`father_ditto` 同理。
- **物种亲本** = `mother_ditto ? 父 : 母`（Ditto 不提供物种；无 Ditto 时由母提供）。
- **招式提供方**（归一补正）：`move_father = father_ditto ? 母 : 父`、`move_mother = father_ditto ? 父 : 母`；即"父为 Ditto"时，招式通道的"父方"落到母方对象上、而"母方"落到 Ditto 上（其后果见 §9 边界）。
- **特性通道的非 Ditto 方** = `mother_ditto ? 父 : 母`。

### 3.3 族内标志

对**母**与**父**分别计算"该亲本是否与蛋的后代物种同族"（家族集合或后代列表包含关系）；两个布尔标志用于：形态继承（§5）、球的候选（§9）、Volt Tackle 的持球前提（§8）。

## 4. WP34-B：后代物种

### 4.1 前身回溯与熏香门

从**物种亲本**的物种出发，沿前身条目回溯并递归：

- 对每个前身：若该前身物种登记了**熏香**，则只有**两亲本中任一方当前持有该熏香**时才继续回溯到它；否则停在当前阶段。
- 未登记熏香的前身可直接回溯。
- 结果＝基础蛋物种。**数据样本（修正）**：PICHU 未登记熏香——PIKACHU/RAICHU 为物种亲本时，**有无海之熏香均得 PICHU**；SEAINCENSE（海之熏香）登记在 **AZURILL**——MARILL/AZUMARILL 为物种亲本时，无熏香得 MARILL、任一亲本持有时得 AZURILL（深链的其余前提相同）。

### 4.2 后代替换采样

取得基础物种后，读取**该物种**登记的后代列表：

- 列表为空 -> 结果即该物种；
- 列表非空 -> 从列表中**等概率采样一项**（可重复项按其登记次数计）。

数据样本：NIDORANfE/NIDORANmA 互为后代（双方列表相同）；VOLBEAT/ILLUMISE 同理；MANAPHY 的后代列表为 PHIONE（单元素 -> 恒为 PHIONE）。

### 4.3 地区形态生成钩子（形态预处理）

创建蛋时调用一次"蛋创建形态钩子"（WP21 的形态机制引用）：

- 对登记的 18 个地区形态物种（**1 个登记源＋17 个经复制共享的目标**：RATTATA、SANDSHREW、VULPIX、DIGLETT、MEOWTH、GEODUDE、GRIMER、PONYTA、FARFETCHD、CORSOLA、ZIGZAGOON、DARUMAKA、YAMASK、STUNFISK、SLOWPOKE、ARTICUNO、ZAPDOS、MOLTRES）：**当前地图的城镇地图区域编号**若存在对应形态号则取该形态号，否则 0。
- 结果写入蛋形态（后续形态继承可覆写，§5）。
- **区域来源**＝蛋**产生地**（非孵化地）；钩子结果与登记形态号一致性的数据假设按注释登记（数据责任）。

## 5. WP34-C/D：基础蛋与形态/特性继承

### 5.1 基础蛋字段（生成时写入）

| 字段 | 值 |
| --- | --- |
| 物种 | §4 结果 |
| 等级 | 配置"蛋等级"（当前 1） |
| 名称 | "Egg"（固定文本；孵化时清空并重命名，WP35） |
| 孵化步数 | 该物种数据的孵化步数值 |
| 来源文本 | "Day-Care Couple" |
| 初始友好度 | 120 |
| 形态 | SINISTEA 强制 0（特殊重置）；随后地区形态钩子（§4.3） |
| 其它字段 | 由创建默认产生：**真正抽样**——每项 IV 独立随机 0–31、个体号随机；**确定性派生**——性别/Nature/特性索引/异色等由初始随机输入（个体号、拥有者等）按规则派生，**按首次访问求值并缓存**（WP18 §4.1、WP19 §3.2–3.5 引用；**Nature 在创建末尾的算能力路径已求值并缓存**——§9.10）；拥有者=玩家；获得方式/地点/时间为创建默认；招式=该等级默认可学招式（`withMoves` 默认开启） |

### 5.2 形态继承（在地区钩子与特殊重置之后执行）

1. **母系形态**：若**物种亲本**的物种带"形态随母继承"标志（数据样本：BURMY、SHELLOS、BASCULIN、FLABEBE、PUMPKABOO、ORICORIO 等）-> 蛋形态 = 物种亲本的当前形态。
2. **永石覆写**：按 `[母, 父]` 顺序遍历，**首个**满足"族内标志为真 且 该亲本物种带'永石随形继承'标志 且 该亲本持有不变之石"的亲本 -> 蛋形态 = 该亲本当前形态并终止遍历（数据样本：OBSTAGOON/PERRSERKER/CURSOLA 等的 `DefaultForm_N,InheritFormWithEverStone` 行）。

### 5.3 Nature（配置：无独立开关）

- 候选列表＝持有**不变之石**的亲本的当前 Nature（母持有加一项、父持有加一项；两者均持有则两项）。
- 列表为空 -> **不覆写**（蛋保持**创建末尾已求值并缓存的 Nature**——该值由创建时初始个体号派生；异色重掷换个体号**不**使其失效，§8.2/§9.10）。
- 非空 -> **等概率采样一项**覆写。

### 5.4 特性（世代 6+ 模型；静态）

- 取**非 Ditto 方**亲本：若其当前特性为隐藏特性 -> `rand(100) < 60` 时蛋特性索引＝该亲本索引；否则不覆写。
- 否则（普通特性）：`rand(100) < 80` -> 蛋索引＝该亲本索引；否则蛋索引＝**另一普通特性的索引**（该亲本索引的"另一个"，按两普通特性互斥语义；索引回退语义引用 WP19 §3.4）。
- 索引派生与"当前是否隐藏"的判定引用 WP19 §3.4（蛋索引未求值时按首次访问的派生规则求值）。

## 6. WP34-G：招式继承（来源、顺序与去重）

### 6.1 来源通道（合并为一个列表后统一处理）

"父方/母方"指 §3.2 的**招式提供方角色**（`move_father`/`move_mother`，Ditto 时发生"落到母对象/父对象"的补正）；等级招式与 Volt Tackle 用**原始两亲本**门控（见各行）。除 Volt Tackle 外，各蛋招/机器通道的**性别门控为"非雌性"或"雌性"**，其在 Ditto 配对下的后果见 §9.3。

1. **等级招式（双方共有）**：蛋物种等级学习表中，**两亲本（含 Ditto）都掌握**且**该条目的等级 > 蛋等级**（蛋等级=1，即 L1 招式被跳过）的招式；按学习表顺序。
2. **机器招式（仅世代 ≤5 配置；招式提供方补正后的"父方"）**：遍历物品目录中带"招式"字段的物品（TM/TR/HM 等）按**目录顺序**；该"父方"掌握该招式**且非雌性**、且蛋可兼容 -> 加入。
3. **蛋招式（"父方"通道）**：蛋物种**原始 `egg_moves` 列表**（不经前身回溯；与 WP33 §5.4 共享教学使用的 `get_egg_moves` 不同）中"父方"掌握的全部项——**仅当"父方"非雌性**（含无性别非 Ditto；Ditto 配对后果见 §9.3）。
4. **蛋招式（"母方"通道，仅世代 ≥6 配置）**：同上但取"母方"，**仅当"母方"为雌性**（Ditto 配对后果见 §9.3）。
5. **Volt Tackle 特例**：蛋物种为**皮丘**且招式存在且（原始父族内标志真且父持电气球）或（原始母族内标志真且母持电气球）-> 追加该招式（不受上述性别门控影响）。

### 6.2 去重与槽位

- **去重保后**：同一招式出现多次时保留**最后**一次的位置（等价于逆序去重再逆序）。
- **保留最后 4 项**：去重后若超过招式槽上限（4），只学习**列表末尾**的 4 项（丢弃靠前的）。
- 逐个静默学习（`learn_move`：已掌握则移到末尾；空槽追加；满槽顶掉第一招，WP20 §5.1 引用）。
- **顺序敏感性**：去重与截断都按生成列表顺序进行；改变来源顺序或去重方向会改变最终配招（WP20 §5.1 的"移到最后"再介入顺序）。

## 7. WP34-H：IV 继承（三项/五项 + 力量道具）

1. **数量**：默认继承 **3 项**；世代 ≥6 **且任一亲本持有"羁绊之绳"** -> **5 项**。
2. **力量道具通道**：六件力量道具按固定顺序各绑定一项能力（负重→HP、护腕→攻击、腰带→防御、镜片→特攻、束带→特防、脚镯→速度）。逐亲本：**按该固定顺序取首个持有的力量道具**并为对应能力登记该亲本的该项 IV 值。对每个被覆盖的能力：**等概率取一名持有该道具亲本的值**覆写；该能力项从"待继承池"移除；继承数量 −1（**每个能力项只消耗一次**，双方同项不重复消耗）。
3. **其余继承**：从剩余能力项中**无放回采样**"继承数量"个**不同项**；每项的值从**两亲本该项 IV 中等概率二选一**覆写。
4. 未覆写项保留创建默认（随机 0–31）；期望/边界算术见 §10.2。

## 8. WP34-I/J：球、异色与病毒（收尾通道）

### 8.1 球继承

- 候选＝**族内标志为真**的亲本的当前球（族内 Ditto 通常为假，见 §3.3）。
- **剔除**大师球与庆典球（不可继承）。
- 候选非空 -> **等概率采样一枚**覆写蛋的球；空 -> 保留创建默认（普通球）。
- 参考实现把 NIDORAN♂/♀ 与 VOLBEAT/ILLUMISE 视为同族（可互传球）——与部分官方世代不同，按现状登记。

### 8.2 异色重掷（Masuda + 闪耀护符；世代 ≥8 为 6 次）

1. **重掷次数**：两亲本**拥有者语言不同**（**读取双方拥有者**，与是否 Ditto 无关） -> +6（世代 ≥8）或 +5（世代 ≤7）；背包持有**闪耀护符** -> +2；否则 0。
2. 次数为 0 -> 不重掷：**不读取也不清**普通异色缓存（其后首次读取按创建时个体号判定，WP19 §3.3 引用）。
3. 否则循环至多"次数"轮，**读取发生在每轮开头**：先读当前普通异色（已为异色 -> **提前停止**，缓存为 true）；未命中才把**普通异色缓存**置空并**重新随机个体号**（两个 16 位拼接）——新个体号要等**下一轮开头**才可能被该循环读取。**用尽次数退出时，末次新个体号尚未被读取，普通异色缓存为空**；正常收尾（病毒/能力重算）不补做该判定——其后的首次读取按最终个体号计算（含此后才发生的 owner 重写等场景；时点对照见 §13.2）。**重掷不重新派生其它缓存**（如 Nature 保留创建时已求值结果；未求值的字段在后续首次访问时按最终个体号求值——§9.10）。
4. 首先生成（创建时）的个体号在 N≥1 时由**第一轮开头**读取参与；随后为至多 N 次重掷——**不是"仅最后一次生效"**；参考注释记载官方世代 8 存在的"跳过首次生成"差异在本实现中**不存在**（本实现蛋的异色概率在世代 8 机制下略高，按现状登记）。循环结束时**不保证**所有派生字段都已重算/求值（缓存状态按访问时点）。

### 8.3 病毒与收尾

- `rand(65536) < 病毒概率（当前 3）` -> 赋予 Pokérus（随机毒株 1–15；感染时长由毒株派生；"感染合计"统计 +1；域与恢复细则归 WP61 前向）。
- 生成结束：重算能力（基于最终 IV/等级等）。
- **返回**：一枚**未入队**的蛋对象（是否入队由 WP33 的领取/守卫决定；生成成功≠已领取）。

## 9. 规则与不变量

1. 一次生成内通道次序固定：归一 -> 物种 -> 基础蛋 -> 形态（母系/永石）-> Nature -> 特性 -> 招式 -> IV -> 球 -> 异色 -> 病毒 -> 重算。
2. 各通道的输入与时机如上：**真正抽样**（每项 IV、个体号、各 rand 检查）与**确定性派生**（性别/Nature/特性索引/异色——由个体号/拥有者等输入派生、按访问求值并缓存）区分；**条件化抽取次数**（异色重掷按"已异色提前停止"、力量道具按持有集合）决定实际掷值数——不是"无条件各自再抽一次、互不共享"的泛化。
3. **Ditto 边界**（静态，单次交换后）：Ditto 不提供物种（`mother_ditto ? 父 : 母`）。招式通道按"招式提供方"与性别门控的实际结果（共同等级招式仍要求**双方都掌握**、含 Ditto）：

   | 初始槽序 | 单次处理后（母/父） | 非 Ditto 亲本的蛋招/机器提供方通道 |
   | --- | --- | --- |
   | ♀ / Ditto | ♀ / Ditto | 两条性别门均不接纳该雌性 → 不进入 |
   | Ditto / ♀ | ♀ / Ditto（发生交换） | 不进入（同上） |
   | ♂ / Ditto | Ditto / ♂ | 可进入（非雌性提供方通道） |
   | Ditto / ♂ | ♂ / Ditto | 可进入（提供方补正后仍走该通道） |
   | 无性别非 Ditto / Ditto | Ditto / 无性别（发生交换） | 可进入（非雌性） |

   ♀+Ditto 两种槽序在普通蛋招/机器通道均不产生教学（本快照现状，不按官方印象修正）；Volt Tackle 特例不受门控；异色语言比较仍**读取双方拥有者**、子代拥有者来自创建默认——不泛称"由非 Ditto 方承担语种"。
4. 形态：地区钩子 -> 母系标志 -> 永石覆写（首个命中）三层顺序；结果可为同一值（无操作）。
5. Nature 只在存在至少一块不变之石时覆写；特性只在非 Ditto 方为隐藏时可能不覆写（60% 失败即保持默认）。
6. 招式去重保后、截断保尾；满槽学习按 WP20 §5.1 再干预顺序。
7. IV：力量道具先覆盖（每项一次），再采样剩余项；总和约束/上限标记不在本包（WP19 域引用）。
8. 球：族内候选、剔除两球、等概率采样。
9. 异色：重掷"提前停止"特性使实际波动小于名义次数；个体号每轮重新随机（两个 16 位拼接），**读取在轮首——末次换号可能不被该循环读取（缓存可能为空）**（§8.2 步 3）。
10. 生成**不主动重写亲本**的遗传字段（两个槽位个体不被写入；等级差/经验动作属 WP33）；但**读取可能填充亲本侧的派生缓存**（如访问特性/Nature 时）——不是"无任何副作用"的强保证。

## 10. 边界与失败

- 直接调用且非兼容对：不拒绝生成（归一单次；物种仍按 §3.2/§4 计算）——常规门控在 **WP33 的周期置标记层已确认；事件接待实际守卫仍待 U01**（生成/领取工具自身不重查），静态边界记录。
- 熏香：仅当前身**登记了熏香**时该门生效（任一方取得即通过）；样本：SEAINCENSE 在 AZURILL（MARILL 系无熏香 → MARILL）；PICHU 未登记熏香（PIKACHU 系有无熏香恒 → PICHU）。
- Ditto 招式通道对照（数据样本：PICHU 的 FAKEOUT；非 Ditto 亲本掌握、Ditto 未掌握、排除创建默认/共同等级/机器/Volt Tackle 等来源）：♂PIKACHU+Ditto 槽序 → 该蛋招进入候选与截断（§6）；♀PIKACHU+Ditto 槽序 → 不进入（§9.3）。
- 蛋物种无蛋招且前身也无 -> 蛋招通道为空表。
- 招式来源全空 -> 蛋只有创建默认的 L1 招式。
- 去重/截断：超过 4 项只留末尾 4 项（靠前项丢弃）；重复项只保留最后一次的位置。
- 力量道具：双方同项 -> 随机一方值、仅扣 1 次数量；数量不足（理论边界）按剩余池采样，不补足。
- 特性索引回退：按已审 WP19 §3.4（单一普通特性**不是**畸形数据；本包不重开上游）。
- 球：候选被剔除后为空 -> 普通球（无覆写）；族内标志全假 -> 无候选。
- 异色：重掷过程中如果首轮已为异色立即停止（重掷数用不满）。
- 病毒：概率 3/65536；不触发则不修改。
- 随机抽取的实现顺序敏感；本包给出候选/次数/互斥，不预言具体输出。
