## 1. 目的、范围与非目标

**目的**：固定漫游宝可梦与 Poké Radar 的规则合同——**状态有哪些、何时初始化与推进、何时可遇见或被替换、战斗结果如何写回、连锁如何开始/继续/中断、哪些入口取消哪些状态**。后续包据此判断"某漫游条目何时出现、某草丛摇动意味着什么、某战斗结束后连锁还在不在"，而不是各自重新追踪两份主文件。

**范围**（WP37 自身声明范围，extraction-plan 第 2.1 节 (a) 类）：

1. WP37-A：漫游配置、状态与初始化——条目身份、启用开关、路线图、当前位置、未生成/已有持续个体/已终结、终结是否捕获、本次待用的遭遇选择、再次遇见限制；持久与暂态分列；首次/惰性/重复进入的写入。
2. WP37-B：漫游位置推进与可遇见判定——地图进入通知的真实触发条件（名字比较）、推进算法（邻接/额外随机候选/空候选）、可遇见判定的全部门（再次遇见限制、伙伴、雷达状态、25% 门、位置与同名同区域、方式允许）。
3. WP37-C：漫游遭遇替换与跨战斗存续——替换钩子所在位置、首次生成与复用持久个体、强制单打与下一战 BGM、各战斗结果对状态/终结原因/再次遇见限制的影响、重置入口的实际条件。
4. WP37-D：雷达使用、充能与摇动草丛——许可门的真实顺序（地形/遭遇表/骑车/调试/电量）、使用与连锁数据保留、四环几何与有效性、普通/剧烈/闪光表现与概率、无有效草丛、计步充能条件。
5. WP37-E：雷达候选、闪光与连锁延续——雷达专属表与普通表回退、权重与等级、连锁继续概率的完整输入、三件事分开（草丛成为闪光/个体标闪光/连锁继续）、延续失败的有限改选、战后更新。
6. WP37-F：取消、事件顺序、保存与跨域边界——全部取消调用者及各自清理范围、漫游与雷达钩子的注册/调用次序、持久全局记录与临时状态分列、demo 可达性保留。

**非目标**：

- 不定义普通遭遇算法（候选层/触发率/双打/Repel，WP36 主规格）、战斗终局与结算（WP42）、捕获接收（WP38）、逃离许可（WP41）、创建/覆盖入口通用合同（WP39）、钓鱼（WP60）、场地招式（WP59）。
- 不定义个体生成全部修饰（WP36/WP19 主规格；本包只登记漫游/雷达特有分支）。
- 不运行游戏/战斗/UI、不操作真实存档、不播放音频、不调整宿主界面、不编译/转换、不设计未来 API 或把参考类组织当作未来模块。

## 2. 概念与术语

- **漫游条目（roamer entry）**：配置数组的一条——`[物种, 等级, 开关编号, 遭遇方式, 战斗 BGM(可选), 专属路线图(可选)]`；**配置存在不等于 demo 中开关已被打开**（开关状态是运行时数据，U01）。
- **漫游状态（持久，全局元数据）**：`roamPokemon[i]`（**nil=未生成/已重置；宝可梦对象=已有持续个体；true=已终结**）、`roamPokemonCaught[i]`（终结原因：true=被捕获、false=被击败）、`roamPosition[i]`（当前所在地图 ID）、`roamedAlready`（当前地图上已遇到过漫游的标记）、`roamEncounter`（本次待用的漫游选择；战斗中清空）、`pokeradarBattery`（雷达剩余充能步数）。**持久 ≠ 已落盘**——落盘只经保存流程（WP09）。
- **暂态**：`roamer_index_for_encounter`（本次待遇条目下标）、`poke_radar_data`（连锁数据：[物种, 等级, 连锁数, 摇动草列表, 上次捕获标记]）、`force_single_battle`（强制单打标记）——均在临时对象上，不随存档持久。
- **路线图（area map hash）**：键=地图 ID、值=可推进到的地图 ID 数组；单条目有专属图时覆盖全局图（`pbRoamingAreas`）。默认全局图 9 张地图全连通（见 §9）。
- **惰性初始化**：`roamPosition[i]` 为 nil 时，各消费点（推进、可遇见判定）就地从该条目路线图的键中随机取一个写入——**首次初始化没有独立入口**。
- **雷达连锁（chain）**：`poke_radar_data` 存在即连锁中（chain count >0 时数据[2]>0）；**草丛成为闪光（摇动草的稀有度=2）、生成个体标闪光（生成钩子按格赋值）、连锁继续（概率判定）是三件事**。
- **取消（cancel）**：清空 `poke_radar_data`（临时连锁）的统称；**各取消调用者只清临时连锁，不动电量/统计/最长纪录**——除非另行注明。
- **已通过边界（必须继承，不重开）**：**GR-011（已关闭）**——步进、转向、主动请求是不同入口；主动请求包装本身不写遭遇触发标记，普通移动转向和独立转向的清理也不同；**GR-013（已关闭）**——WP42 与 WP41 的参战标记及正常终局合同按当前已批准字节引用。本包不为漫游/雷达补"所有请求统一写标记"的规则。
- 影响域编号 Dxx 见 module-map；证据状态五档定义见总览第 7 节。

## 3. WP37-A：漫游配置、状态与初始化

### 3.1 条目与路线图配置（`001_Settings.rb:175–213`）

- **条目结构**：`ROAMING_SPECIES[i] = [species, level, switch, method, bgm, areas?]`——物种标识、等级、Game Switch 编号（**>0 时开关为 ON 才漫游/可遇见**；≤0 恒启用）、遭遇方式（0=草地/洞穴步行/冲浪（陆地类+水）、1=草地/洞穴步行（陆地类）、2=冲浪（水）、3=钓鱼、4=水基（冲浪+钓鱼））、战斗 BGM（可选，非空才写下一战 BGM）、专属路线图（可选，覆盖全局 `ROAMING_AREAS`）。
- **默认数据样本**：LATIAS（Lv.30、开关 53、方式 0、"Battle roaming"）、LATIOS（同前）、KYOGRE（Lv.40、开关 54、方式 2、无 BGM、专属 4 图路线）、ENTEI（Lv.40、开关 55、方式 1）。全局 `ROAMING_AREAS` 为 9 张地图的全连通邻接表。
- **遭遇方式与当前遭遇类型的映射**（`pbRoamingMethodAllowed`）：按当前地图实际遭遇类型的类别判定（land/cave/water/fishing；捕虫大会不属任一）。**方式配置是数据、当前类型是运行时状态**——两者按上表匹配，不按注释推定。

### 3.2 状态机与初始化

- **状态三分**：**未生成**（`roamPokemon[i]` 为 nil——尚无持续个体；重置后也回到此态）、**已有持续个体**（宝可梦对象——首次遭遇时生成并复用）、**已终结**（`true`——被击败或被捕获后；`roamPokemonCaught[i]` 记录终结原因）。
- **初始化路径**：`roamPokemon`/`roamPokemonCaught` 数组惰性创建；`roamPosition` 惰性创建并按物种存在的条目随机填图（`pbRoamPokemon`），或单条目惰性填图（`pbRoamPokemonOne`/遭遇判定处）；**不存在"建档式"首次初始化入口**——所有首次写入都是就地惰性完成。
- **重置入口的实际条件**（`pbResetAllRoamers`）：逐条目检查——**仅当 `roamPokemon[i]==true`（已终结）且 `roamPokemonCaught[i]` 为真（被捕获）时才把条目置 nil（恢复为未生成、可再遇）**；**被击败未捕获的条目（终结且原因为 false）不被动**。**注释与实现不一致**（注释称重置"被击败未被捕获"的漫游，实现门却是"已终结且已捕获"——按实现如实登记，不按注释概括成"全部复活"或"全部清空"）。当前基线**无正常脚本调用者**（调试/事件潜在调用归 U01；不据此断言功能不存在）。
- **辅助入口 `pbRandomRoam(index)`**：把指定条目位置随机重置为其路线图中的任一图（无正常调用者，单列）。

## 4. WP37-B：漫游位置推进与可遇见判定

### 4.1 地图进入通知与推进（`005_Overworld_RoamingPokemon.rb:44–103`）

- **触发条件（on_enter_map）**：比较**旧地图名与当前地图名**（经地图信息表解析）——**同名则完全不推进**（不换图、不清 `roamedAlready`）；**不同名才全体推进并清 `roamedAlready`**。**同名但不同地图 ID 的两张图不触发推进**（按名字比较，不按 ID；跨区域同名亦同此规则——与可遇见判定的"同名同区域"分开，见 §4.2）。
- **全体推进（pbRoamPokemon）**：先惰性初始化位置（§3.2），再逐条目推进。
- **单条推进（pbRoamPokemonOne）**：开关关闭（>0 且 OFF）或物种不存在 → 不动；取路线图键集（**键集为空 → 直接返回**）；当前图缺失 → 惰性随机填图；取当前图的邻接表——**当前图不在路线图键中（邻接表为 nil）→ 直接返回、不推进**；邻接候选全部入列；**1/32 概率额外加入一个全图随机候选（可与邻接候选重复——重复项按入选次数加权）**；从候选中随机选一写入位置。

### 4.2 可遇见判定（`005_Overworld_RoamingPokemon.rb:135–186`；`003_Overworld_WildEncounters.rb:340–373`）

- **替换钩子位置**：普通遭遇选择钩子（`on_wild_species_chosen`）上注册——**在雷达连锁钩子之前执行**（注册次序：012_Overworld 先于 013_Items；§8）。每次触发先清 `roamer_index_for_encounter`。
- **前置门（任一不满足 → 保留普通遭遇）**：`roamedAlready`（本图已遇）；伙伴在场；**雷达连锁数据存在**；**75% 概率跳过（即 25% 通过）**。
- **逐条目门**：物种存在；开关启用；**未终结**（`roamPokemon[i] != true`）；位置（惰性初始化）；**位置判定**——在当前地图，或**同名同区域**（该位置的城镇图区域与当前区域相同 **且** 按 ID 解析的图名等于当前图名——两个条件同时成立，缺元数据或区域不一致即排除）；**遭遇方式允许**（§3.1 映射）。全部通过 → 候选 `[条目下标, 物种, 等级, BGM]`。
- **选择与写入**：候选空 → 保留普通遭遇；否则**随机取一候选**：写 `roamEncounter`（本次待用选择）、`roamer_index_for_encounter`、**下一战 BGM**（仅当条目配置了非空 BGM）、**强制单打标记**、并把遭遇的物种/等级替换为该条目。
- **双打抑制**：强制单打标记使双打判定为否（`have_double_wild_battle?` 引用）——漫游/雷达替换遭遇恒为单打。

## 5. WP37-C：漫游遭遇替换与跨战斗存续

### 5.1 覆盖开战与持久个体（`005_Overworld_RoamingPokemon.rb:188–228`；`001_Overworld_BattleStarting.rb:354–373`）

- **覆盖钩子（on_calling_wild_battle）**：公开开战包装在单一敌方且允许覆盖时触发；**已被其它钩子处理（handled 非空）→ 不动**；无待用漫游选择 → 不动；否则把处理结果设为漫游战斗的返回。**正常替换链**：步进/主动请求 → 普通候选 → 漫游钩子替换（§4.2）→ 公开包装 → 覆盖钩子 → 漫游战斗。**被其它钩子先处理、提前拒绝、异常未到清理点不与正常返回合并**（handled 机制如实登记）。
- **首次生成 vs 复用**：条目尚无持续个体时生成——`pbGenerateWildPokemon(物种, 等级, true)`（WP36 引用：野外道具、闪光重抽、Pokérus、性别/性格修饰照常；**isRoamer=true 只跳过 Synchronize 性格复制**）；**已有持续个体则复用同一对象**。
- **持续范围**：**同一对象跨战斗保留 HP、状态、招式/PP 等全部个体状态**——战斗离场处理只复位形态与超限 HP（WP42/WP20 引用），**不治疗**；击败/捕获前再次遇到的就是带伤/带状态的同一个体。首次生成后身份（个人 ID、闪光、道具）固定复用。
- **战斗规则**：强制单打 + `roamerFlees`（总是逃跑规则，WP41 引用——对手每回合尝试逃跑）。
- **结果写回**（`decision` 引用 WP42）：**击败（1）或捕获（4）→ 条目终结**（`roamPokemon[i]=true`、`roamPokemonCaught[i]=(decision==4)`）；**所有结果**都清 `roamEncounter`、置 `roamedAlready=true`、清暂态下标；随后显式触发战斗结束钩子（`on_wild_battle_end`，参数=物种/等级/结果——**雷达连锁钩子在此消费**，§7）；**返回 `decision != 2 && decision != 5`**（玩家失败/平局为 false，其余为 true）。
- **逃离（3）/玩家失败（2）/平局（5）/中止（0）**：条目**不终结**（持续个体保留全部状态）、本图 `roamedAlready=true`（当天本图不再触发漫游判定）、待用选择清空。战斗结果编号、外层布尔返回、是否实际开战、是否提交终结记录是**四种不同输出**（§5.1 的返回布尔≠终结记录）。
- **触发次序**：漫游战斗直接调核心开战（不经公开包装的战后钩子）→ 自身在结果写回后显式触发一次战斗结束钩子——**每条漫游战斗路径只触发一次**（§8 次序）。

## 6. WP37-D：雷达使用、充能与摇动草丛

### 6.1 许可门与使用（`005_Item_PokeRadar.rb:18–58`）

- **许可门的真实顺序**：①**地形**——当前格必须是"陆地野外遭遇＋显示草丛摇动"的地形（否则"Can't use that here."）；②**普通陆地遭遇表**——当前地图未定义陆地类遭遇（忽略捕虫大会）→"Can't use that here."；③**骑车** →"Can't use that while on a bicycle."；④**调试直通**（$DEBUG 且按 CTRL）→ 直接放行；⑤**电量**——剩余充能 >0 →"The battery has run dry!\n…还需 {N} 步"拒绝。**不能把调试绕过推广到全部前置门**（调试只在④越过⑤，①②③仍在前面拦截）。
- **使用**：统计雷达使用数 +1；**连锁数据惰性初始化（已有连锁数据则保留——再次使用不清连锁）**；上次捕获标记重置为 false；**电量写 50**；执行摇草（§6.2）；返回 true。
- **道具入口分开**：场外使用入口（UseInField）→ 直接执行 `pbUsePokeRadar`；背包入口（UseFromBag）→ **预检（`pbCanUsePokeRadar?`）通过才返回 2**（袋内预检与实际场外执行分开；背包侧不执行摇草）。POKERADAR 为重要道具（口袋 8，PBS 数据样本）。
- **计步充能**（on_player_step_taken）：**仅当电量 >0 且无连锁数据时**每步 −1（**连锁存在期间不计步充能**——`poke_radar_data` 存在即不递减）；随后**当前格地形失效（非陆地遭遇/不显示摇草）即取消连锁**（§8）。

### 6.2 摇动草丛（`005_Item_PokeRadar.rb:60–111`）

- **四环几何**：以玩家为中心的第 i 环（i=0..3，内到外）各随机取 1 格——环为边长 (2i+3) 的正方形边框：上边段（含左上起点）、左右边段、下边段，按 `rand((i+1)×8)` 在边框格中均匀抽取（独立坐标例：i=0 时共 8 格、边长 3 的正方形边框）。**出图或地形无效（非陆地遭遇/不显示摇草）的格直接跳过**——每环至多 1 格，总数 0～4。
- **稀有度**：每格 25% 为剧烈（1）、否则普通（0）；**连锁存在时**（连锁数 >0）额外判定闪光（2）：概率分母 `v = max(65536/SHINY_POKEMON_CHANCE − min(连锁数, 40)×200, 200)`，再取 `v = ceil(65536 / v)`，以 `rand(65536) < v` 判定（SHINY_POKEMON_CHANCE 默认 16 → 基线分母 4096；连锁 ≥40 时分母到下限 200、概率 ceil(65536/200)=328/65536≈0.5%）。**连锁长度只影响闪光摇草概率，不影响环几何**。
- **无有效草丛**：四格全无效 →（`showmessage` 为真时）"The grassy patch remained quiet..." → **取消连锁**。
- **表现**：按稀有度播对应摇动动画（普通/剧烈/闪光动画 ID 取自配置，默认 1/5/6——WP15 引用，素材存在性未证）→ 写入摇动草列表（连锁数据中）→ 等待 0.5 秒。

## 7. WP37-E：雷达候选、闪光与连锁延续

### 7.1 候选选择（`005_Item_PokeRadar.rb:123–156, 161–208`）

- **非连锁开始使用（连锁数 =0）**：`pbPokeRadarGetEncounter(rarity)`——**只有剧烈/闪光草（rarity>0）才查雷达专属表**：当前地图+遭遇版本的 `:PokeRadar` 表存在且**通过步概率门（`rand(100) < 步概率`）**→ 按权重随机一条、等级在范围内随机；**未命中步概率门、表不存在或表为空 → 回退普通表**：`choose_wild_pokemon(当前类型, rarity+1)`（WP36 引用：重抽次数 = 稀有度+1——普通草 1 次、剧烈 2 次、闪光 3 次，多次取最大值偏向稀有项）。**雷达专属选择与普通重抽不是同一算法，不混用**。
- **连锁中的遭遇（连锁数 >0，在摇动草上）**：先取该格稀有度 → **继续判定**：`chain_chance = 58 + 环号×10 + min(连锁数, 40)/4（整除）+（上次捕获 ? 10 : 0）`——**闪光草（稀有度=2）必定继续**；否则 `rand(100) < chain_chance` 才继续（概率可超 100——按实际比较规则，超界即恒真）。继续：遭遇=连锁数据的物种/等级、强制单打。
- **延续失败的有限改选**：判定失败 → **至多 100 次从普通表重抽、要求物种与连锁不同**——**改到不同物种 → 断链（取消连锁数据）**；**100 次后仍同物种且同等级 → 无法断链、继续连锁（强制单打）**。**不能把"尝试改选"写成"必定改成不同物种"**；物种相同但等级不同的重抽结果**算已改选**（判等只看物种与等级同时相等才视为未改选）——候选缺失（表为空返回 nil）时按改选失败处理（同无法断链分支的逻辑路径，如实登记有限输入边界）。

### 7.2 闪光三件事（`005_Item_PokeRadar.rb:84–90, 210–221`）

1. **草丛成为闪光**：摇草时按 §6.2 概率把该格稀有度标为 2（显示闪光摇动动画）。
2. **生成个体标闪光**：生成钩子（`on_wild_pokemon_created`）——**玩家站在稀有度=2 的摇动草上**时把生成的个体标为闪光（个体持久属性；发生在生成阶段，WP36/WP19 引用）。
3. **连锁继续**：稀有度=2 的摇动草使继续判定**必定通过**（§7.1）——三者分别负责显示、个体属性与连锁走向，不互相推出。

### 7.3 战后更新（`005_Item_PokeRadar.rb:223–237`）

- **战斗结束钩子（on_wild_battle_end）**：连锁数据存在且结果为**击败（1）或捕获（4）** → 连锁数据更新：物种/等级 = 本次战斗的物种/等级、**连锁数 +1**、最长连锁统计取大、**上次捕获标记 =（decision==4）**；随后**静默重摇草丛**（不显示"remained quiet"消息——但若重摇无有效草丛仍取消连锁，§6.2）。
- **其它结果（逃离/失败/平局/中止）或无连锁数据** → **取消连锁**（清空临时数据）。
- **刷新草丛与增链的次序**：先更新连锁数据与统计，再重摇——重摇使用更新后的连锁数计算闪光概率（§6.2）。

- **同一候选钩子（on_wild_species_chosen）**：漫游替换钩子**先**（012_Overworld 注册序）、雷达连锁钩子**后**（013_Items 注册序）——漫游钩子含"雷达连锁数据存在则跳过"门；雷达钩子对非摇动草遭遇一律取消连锁。两个钩子对同一遭遇的修改按此次序生效；**不把文件名排序直接当成完成的时序证据**（本次序以注册点所在目录与全 Scripts 检索核对）。

### 8.3 保存与持久边界

- **持久（全局元数据，随存档保存，WP09 引用）**：`roamPokemon`（含持续个体对象——保存转换在载入时更新其标记数据）、`roamPokemonCaught`、`roamPosition`、`roamedAlready`、`roamEncounter`（虽为"本次待用"但字段在全局元数据上——**战斗中即清空，保存只能存到其当前值**）、`pokeradarBattery`。
- **不持久（临时对象）**：`poke_radar_data`（连锁全部内容）、`roamer_index_for_encounter`、`force_single_battle`。**保存并不天然保存全部连锁**——连锁在保存/载入后不存在；**不把内存字段变化写成已经落盘**（没有运行存档恢复，只写静态可证的持久边界）。

## 10. 边界、失败与未知

- **空路线/缺当前位置**：路线图键集为空 → 单条推进直接返回；当前图不在键中（邻接表 nil）→ 不推进；无邻接候选时不写位置（§4.1）。
- **无可遇见条目**：开关全关/全终结/位置全不匹配/方式全不允许 → 候选空、保留普通遭遇（§4.2）。
- **同名换图不推进**：同名不同 ID 的换图既不推进也不清 `roamedAlready`（§4.1）；可遇见判定另有"同名同区域"通道（§4.2）。
- **首次即终结后**：被击败未捕获的条目在当前基线**没有正常复活路径**（重置入口只覆盖已捕获条目且无正常调用者，§3.2）。
- **改选失败**：100 次重抽仍同物种同等级 → 继续连锁（§7.1）；雷达专属表步概率门未命中/无表 → 普通表回退（§7.1）。
- **战后重摇无有效草丛**：静默取消连锁（§7.3）。
- **覆盖竞争**：`on_calling_wild_battle` 已被处理时漫游不再覆盖（§5.1）；异常未到清理点时 `roamEncounter`/暂态下标的残留按字段生命周期处理（§8.3，不虚构清理保证）。
- **未证的异常清理**：战斗中异常中断（脚本错误）时暂态字段与强制单打标记的清理未逐项验证；demo 可达性具名保留（U01/WP77）。
