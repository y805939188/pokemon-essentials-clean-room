# WP17 附表：绘制文本标记目录

本附表是 [wp17-messages-windows-input](wp17-messages-windows-input.md) 的取证附件（WP17-A 验收物，2026-09-23 按 WP17-R01 新增）。
范围为固定基线 `S/007_Objects and windows/010_DrawText.rb` 的格式化文本标记：识别集合（`FORMATREGEXP`，75 行）与处理分支（436–549 行）。标记只作行为定位，不是未来框架的格式 API；不复制处理函数。

**识别与处理是两个集合**：识别集合 21 个名字（`c c2 c3 o fn br fs i b r pg pog u s icon img ac ar al outln outln2`，均可带 `/` 结束标记）；其中 **pg、pog 被识别但在绘制层无对应动作**（不能与消息层的反斜杠性别色 `\b`/`\r` 等同）；其余 19 个有显式处理分支。

## 1. 颜色与不透明度

| 标记 | 参数 | 可见效果 | 开闭/恢复 | 边界 |
| --- | --- | --- | --- | --- |
| `<c=X>` | 颜色值 | 后续文本正文色变为 X（阴影不变） | 颜色栈；`</c>` 弹栈恢复 | 参数按 `Color.new_from_rgb` 解析：8 位=32 位 RGBA、6 位=24 位 RGB、4 位=15 位 RGB（每分量 5 位左移 3）、1–2 位=色板号 |
| `<c2=XXXXXXXX>` | 8 位输入 | **前 4 位为正文色、后 4 位为阴影色**（各 15 位 RGB） | 颜色栈；`</c2>` 弹栈 | 不是单个 RRGGBBAA 值；消息层 `\[8hex]` 即转写为本标记（正文/阴影各半） |
| `<c3=A,B>` | 两个颜色值，逗号分隔 | 正文/阴影分别设为 A/B | 颜色栈；`</c3>` 弹栈 | **空分量保留上一颜色**（只改给定的分量） |
| `<o=N>` | 整数 | 后续文本不透明度改为 N | 不透明度栈；`</o>` 弹栈 | 非数字按 0 |

## 2. 字形与字体

| 标记 | 参数 | 可见效果 | 开闭/恢复 | 边界 |
| --- | --- | --- | --- | --- |
| `<b>` | 无 | 加粗计数 +1 | `</b>` −1 | 计数制，嵌套累加 |
| `<i>` | 无 | 斜体计数 +1 | `</i>` −1 | 同上；中文斜体为宿主绘制行为（未运行验证） |
| `<u>` | 无 | 下划线计数 +1 | `</u>` −1 | 同上 |
| `<s>` | 无 | 删除线计数 +1 | `</s>` −1 | 同上 |
| `<outln>` | 无 | 描边计数 +1 | `</outln>` −1 | 同上 |
| `<outln2>` | 无 | 第二描边计数 +1 | `</outln2>` −1 | 同上 |
| `<fs=N>` | 整数 | 字号改为 N | 字号栈；`</fs>` 弹栈并立即应用 | 非数字按 0 |
| `<fn=名>` | 字体名 | 字体改为指定名 | 字体名栈；`</fn>` 弹栈并立即应用 | **字体不存在时回退 "Arial"** |

## 3. 对齐与换行

| 标记 | 参数 | 可见效果 | 开闭/恢复 | 边界 |
| --- | --- | --- | --- | --- |
| `<ar>` | 无 | 右对齐（对齐栈压 1） | `</ar>` 弹栈 | 行中已有内容时先换行 |
| `<al>` | 无 | 左对齐（对齐栈压 0） | `</al>` 弹栈 | 同上 |
| `<ac>` | 无 | 居中对齐（对齐栈压 2） | `</ac>` 弹栈 | 同上 |
| `<br>` | 无 | 换行 | 无（即时） | `</br>` 无效果 |
| `<r>` | 无 | 本行剩余内容右对齐 | 无（即时，作用于当前行） | 记录当前行为右对齐段 |

## 4. 图像

| 标记 | 参数 | 可见效果 | 开闭/恢复 | 边界 |
| --- | --- | --- | --- | --- |
| `<icon=名>` | 图标名 | 在该位置绘制 `Graphics/Icons/名` | 无（即时） | 资源缺失按 WP15 图像解析入口（未运行验证具体输出） |
| `<img=路径\|x\|y\|w\|h>` | 路径与可选源矩形 | 在该位置绘制图片（可按源矩形截取） | 无（即时） | 参数以 `\|` 分隔；缺省源矩形为整图；资源缺失同上 |

## 5. 识别但无动作

| 标记 | 状态 |
| --- | --- |
| `<pg>` / `<pog>` | 被 FORMATREGEXP 识别，但绘制层无处理分支（无可见效果）；消息层的 `\pg`/`\pog` 是另一套反斜杠替换（WP17 主文档 3.1），二者不等同 |

## 6. 口径与静态场景

- 本表按固定源码逐项核对识别正则与处理分支，非 AST 分析；各标记的完整排版结果（换行算法、对齐测量）以绘制函数整体为准，不在本表展开。
- 栈式标记（颜色/不透明度/字号/字体名/对齐）在文本结束时未闭合不会自动弹栈（按绘制调用为单位，下一次调用重新初始化；未逐调用验证残留，列主文档未决）。
