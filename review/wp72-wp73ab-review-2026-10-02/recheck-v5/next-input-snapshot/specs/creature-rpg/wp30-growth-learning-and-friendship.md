## 1. 目的、范围与非目标

**目的**：定义成长主规则——成长曲线与等级↔经验换算的**目录与边界**、战斗经验/EV 的分配与修正、等级设置/经验设置辅助流的提交语义、招式的学习/满槽替换/放弃/遗忘/重学，以及友好度（含由友谊派生的"亲密度"）的变化入口与上下限；供进化（WP31/WP32）、道具效果（WP28）、战斗收尾（WP42）、寄养（WP33）引用。

**范围**（WP30 自身声明范围，extraction-plan 第 2.1 节 (a) 类）：

1. WP30-A：成长曲线——六条曲线的数学描述、边界与换算函数（含反向换算与钳制）。
2. WP30-B：战斗经验与 EV 分配——资格、参与/共享/全队、外来、修正次序、消息与升级循环。
3. WP30-C：等级/经验设置辅助流（道具/调试用）——钳制、早退、差异窗、新招与进化检查。
4. WP30-D：学习/替换/放弃/遗忘/重学的接口差异与提交结果。
5. WP30-E：友好度存储与变化（方法表、修正、软上限）、亲密度派生与消费登记。
6. F09-01、F09-02 中属于 WP30 部分的状态更新。

**非目标**：

- 不重复 WP19 的等级↔经验**接口语义**（域、缓存、异常分支引用）；本包定义曲线**目录**与成长流程。
- 不定义进化的条件与提交（WP31/WP32；本包只登记升级/换级后的检查调用点）。
- 不定义道具的效果/消耗（WP28）与持有效果（WP50）、球的捕获修正（WP38）；不定义 Shadow 暂存与恢复细则（WP23，逐项登记交界）。
- 不定义战斗内的等待/时序与当前参战状态更新（WP42）与亲密的战斗效果（WP40/43）；不定义界面渲染细节（WP66）。
- 不运行游戏或参考脚本；不设计未来框架的成长 API。

## 2. 概念与术语

- **成长曲线**：一组"等级 -> 该等级最小经验"的登记数据（等级表）＋越界补充公式；提供最大等级、最大经验、经验钳制加法与"经验 -> 等级"反向换算。
- **参与（participation）**：战斗中被记录为对阵某方个体的队伍索引；分配经验/EV 时按"仍在队、未濒死、**战斗席位归属一致**"计数（席位归属＝战斗内分队索引，**非个体原拥有者**）。**共享（Exp Share）**：持有点名物品（或战斗开始时持有过）的未濒死队员。**全队（Exp All）**：玩家功能标记或背包有对应物品时，全队未濒死成员都分得。
- **外来（outsider）**：经验判据＝拥有者 ID 与玩家不同，或拥有者语言非 0 且与玩家不同；倍率**二选一**（1.7 语言差异 / 1.5 仅 ID 差异；语言 0 无语言加成）；字段与所有权规则引用 WP18 §6.4。
- **满槽替换**：招式数已达上限时以新招式**对象**替换所选槽（全新当前/总 PP）；与"直接改招标识"的保留语义区分（引用 WP20 §5.4、WP21 §4.2）。
- **友好度（happiness）**：0–255 的持久值；变化按"方法 × 当前值档位"取值，再按场景修正（地图/球/道具/软上限）。
- **亲密度（affection）**：由友好度档位派生的 0–5 值（不是独立持久字段）；高亲密度在开启效果时增强经验并在战斗内生效（后者归战斗包）。
- **重学列表**：等级学习表中"等级 ≤ 当前等级且当前未掌握"的招式；开启配置时再前置"最初招式记录"中未掌握项。

## 3. WP30-A：成长曲线（`001_GrowthRate.rb` 全文）

### 3.1 接口函数（行为）

| 函数 | 行为 | 边界 |
| --- | --- | --- |
| 最大等级 | 配置值（当前 100；机制上可变，编译期调用需容错） | — |
| 该等级最小经验 | **先按最大等级钳制**；等级小于表长（101，含索引 0）时查表，否则用**登记公式**；等级为空/≤0 -> **返回错误对象**（调用方当作数值使用才失败） | 请求等级超过最大等级先被钳制（默认 max=100 时请求 101 仍按 L100 计算） |
| 最大经验 | 最大等级的最小经验 | — |
| 经验加法 | 加法结果钳到 `[0, 最大经验]`（辅助入口语义；**原始经验 setter 不钳制**——见 §8 不变量 1 与已审 WP19 §4.2） | — |
| 经验 -> 等级 | **经验为空/负：诊断文本引用未定义名称，在文本求值阶段即名称解析失败（不返回错误对象）**；≥ 最大经验 -> 最大等级；否则取首个"经验 < 该等级最小经验"的等级减一 | 与 WP19 §4.2 的缓存接口配套（写入经验清除等级缓存）；与等级一侧"返回错误对象"分列 |

### 3.2 曲线目录（六条；等级表为准、公式为表外补充）

> 表中 `n` 为等级；除法按整数除法（向下取整）语义记录；锚点值为等级表样本（静态核对）。

| 曲线 | 数学描述 | 锚点（L1 / L50 / L100） |
| --- | --- | --- |
| Medium（=Medium Fast） | `n³` | 0 / 125,000 / 1,000,000 |
| Fast | `⌊4n³/5⌋` | 0 / 100,000 / 800,000 |
| Slow | `⌊5n³/4⌋` | 0 / 156,250 / 1,250,000 |
| Parabolic（=Medium Slow） | `⌊6n³/5⌋ − 15n² + 100n − 140` | 0 / 117,360 / 1,059,860 |
| Erratic | 分段：`n≤50`：`⌊n³(100−n)/50⌋`；`51≤n≤68`：`⌊n³(150−n)/100⌋`；`69≤n≤98`：`⌊n³·⌊(1911−10n)/3⌋/500⌋`；`n≥99`：`⌊n³(160−n)/100⌋` | 0 / 125,000 / 600,000 |
| Fluctuating | 分段：`n≤15`：`⌊n³(24+⌊(n+1)/3⌋)/50⌋`；`16≤n≤35`：`⌊n³(14+n)/50⌋`；`n≥36`：`⌊n³(32+⌊n/2⌋)/50⌋` | 0 / 142,500 / 1,640,000 |

- **表内权威 vs 表外登记公式（分开）**：六条曲线的等级表长度为 101（含索引 0）；**先按最大等级钳制**，等级小于表长时用表值（本轮 600 个表值已由独立算术核对；L1 按表值特例）；**表外使用各曲线注册的公式**——Erratic 与 Fluctuating 的注册公式**不同于**上表分段数学描述的延续：
  - Erratic 表外：`⌊(n⁴ + 2000n³)/3500⌋`（与表内分段不是同一函数）；
  - Fluctuating 表外：`⌊((n³ + ⌊n/2⌋ + 32) × 4) / (100 + n)⌋`。
- **边界向量（独立算术）**：默认最大等级 100 时，请求等级 101 先钳到 100（按表值）；若把最大等级显式改为 101，则 L101 分别为 Erratic = **618,474**、Fluctuating = **20,505**——"表内分段继续外推"的 607,877 / 1,689,693 均不成立。Fluctuating 在 L100→L101 明显**非单调**（1,640,000 → 20,505）；按参考快照现状登记，不修参考、不作为设计建议；表外完整运行后果仍未决。
- 反向换算示例（自有算术）：Medium 上 `0 -> 1`、`1,000,000 -> 100`、`999,999 -> 99`；Fast 上 `800,000 -> 100`、`799,999 -> 99`。

## 4. WP30-B：战斗经验与 EV 分配（`003_Battle_ExpAndMoveLearning.rb` 全文）

### 4.1 资格与收集（`pbGainExp`）

- 前置：内部战斗 且 战内"经验开关"为真；否则整体不分配（外部战斗模式按各自流程，登记为交界）。
- 遍历每个**已倒下或被捕获**且有过参与记录的对方个体；参与计数=参与列表内"仍在队、未濒死、**战斗席位归属一致**"的成员数——该归属是**战斗内的席位/训练家分队索引**（同一方持有者），**不是个体原拥有者字段**；原拥有者仅用于 §4.2 的"外来"倍率与队伍读取（WP18 引用）。
- 共享列表：仅当未启用全队时收集——未濒死且"当前持有点名物品或战斗开始时持有该物品"的队员。
- 有参与/共享/全队任一（且计数>0）时，对每名参与或共享成员：先 EV 后经验（经验消息对 Shadow 抑制）；再对全队模式下其余未濒死成员补一次 EV＋经验（补发经验消息被抑制，仅显示一次"其他宝可梦也获得了经验"）。
- 每个对方个体处理完后清空其参与列表。

### 4.2 经验计算（`pbGainExpOne`，按实现顺序）

1. 已达最大经验：只重算能力（让新 EV 生效）后返回。
2. 基础量 `a = 对方等级 × 对方基础经验`。
3. 基础分配（四种组合，受"参与者均分"开关影响）：
   - 有共享列表且本人是参与或共享者：无参与者时 `a`（均分开关时按共享人数均分；否则每人全额）；有参与者时——**均分开关：两项份额按资格分别取得**（**参与份额仅参与者取得、共享份额仅共享者取得；兼任两项者才相加**：`a/(2×参与数)`＋`a/(2×共享数)`）；**非均分：按"参与优先"二选一**——参与得全额 `a`、否则共享得 `a/2`（**同时参与且共享者只取参与全额，不叠加共享半额**）。
   - 仅参与、无共享：`a`（均分开关时按参与数均分，否则全额）。
   - 仅全队（未参与）：`a/2`。
4. 训练家战加成：开关开启时 `×1.5`（向下取整）。
5. 缩放（开关开启）：`÷5` -> 等级调整因子 `((2×对方等级+10)/(本人等级+对方等级+10))^2.5` -> 向下取整；**参与者/共享者再 +1**。开关关闭：`÷7`（无 +1）。
6. 外来加成：**判据=拥有者 ID≠玩家 ID，或（拥有者语言非 0 且≠玩家语言）**；倍率**二选一**——语言非 0 且不同 -> `×1.7`；否则若 ID 不同 -> `×1.5`；**语言为 0（未知）不产生语言加成**；均为向下取整（不是先 1.5 再 1.7）。
7. 经验护符：检查**背包**（而非个体持有）-> `×3/2`（向下取整）。
8. 持有效果修正：向"当前持有物"查询修正值，**返回负值（无物品/无相应处理器）时才回退战斗开始时持有物**（有效但无处理器的物品同样走回退）；修正接口归 WP50。
9. 亲密度加成（效果开关开启且内部战斗且亲密度 ≥4 且未 Mega）：`×6/5`；并置"加成消息"标志。
10. 经验钳制加法得终值；实际增量 ≤0 -> 结束（无消息、无写入）。
11. 消息："获得 N 点经验"或加成版；然后升级循环（§4.3）。
12. Shadow 例外（追到实际写入者，逐字登记）：**先按最大经验钳制得到实际增量**；心阶段 ≤3 -> 写入经 Shadow 的"经验赋值"覆盖——**暂存经验 += 实际增量、当前经验保持不变**，统计同样按实际增量累加，随后返回（**不走升级循环**）；心阶段 >3 -> 该分支**不增加任何经验、不累加统计**。完整 Shadow 生命周期（解禁/净化/折算）归 WP23 前向。

### 4.3 升级循环（多级；逐级推进）

- 计算新等级（经验 -> 等级）；若新等级小于当前等级 -> **报错**（不应发生）。
- 统计"累计获得经验"。
- 逐级循环：按等级边界写经验并播经验条动画；到达终点（多级已走完）-> 重算能力、刷新，结束。
- 每升一级：等级+1 -> （若该成员当前在场上）**友好度 +"升级"增量** -> 重算能力 -> "升到了 Lv.N！"消息与升一级演出（前后六项数值）-> **学习该等级的招式**（逐个经战斗版学习入口）。
- 备注：友好度"升级"变化只发生在**当前在场上**的成员（未上场者是经验到手但无该变化）；招式学习消息与形态复检（招式集变化后）见 §6。

### 4.4 EV 分配（`pbGainEVsOne`）

- 来源=对方物种的 EV 产出表（内容数据）；先按持有效果修正接口——"当前持有物"查询**返回否（无此处理器）时回退**"战斗开始时持有物"（WP50）。
- 病毒（Pokérus 阶段 ≥1，含已治愈）：产出全部 `×2`。
- Shadow 且心阶段 ≤3 且存在"暂存 EV"：增量写入**暂存 EV**，上限同时计入已暂存值（单项上限与总量上限均含暂存）——暂存/恢复细则归 WP23。
- 其他：逐项写入 `clamp(0, 单项上限 − 已有点数)` 且再 `clamp(0, 总量上限 − 已有点数合计)`；单项上限 252、总量上限 510（域归 WP19）。
- 本函数不触发能力重算；重算发生在升级循环/已达上限分支。

## 5. WP30-C：等级/经验设置辅助（`001_Item_Utilities.rb`；道具/调试共用）

### 5.1 等级设置（`pbChangeLevel`）

1. 目标等级钳到 `[1, 最大等级]`；与当前相同 -> 提示"等级没有变化"并返回。
2. 记忆六项能力与最大 HP -> 写入等级 -> 重算。
3. 升级且物种基础 HP 恰为 1 时，把当前 HP 置 1（静态特例）。
4. 降级：提示"下降到 Lv.N"＋六项差异窗（下行）；**无**友好度变化、无新招、无进化检查。
5. 升级：友好度 +"维生素"增量；提示"升到了 Lv.N"＋六项差异窗（上行）；学习跨越区间内的等级招式（`旧等级 < 招式等级 ≤ 新等级`）；**检查升级进化**（交互式提交，条件/流程归 WP31/WP32）。

### 5.2 经验设置（`pbChangeExp`）

1. 目标经验钳到 `[0, 最大经验]`；相同 -> 提示并返回。
2. 降经验分支：写经验、重算；等级未变则返回（无提示外差异）；等级下降 -> "下降到"＋差异窗（**无**友好度/新招/进化）。
3. 升经验分支：写经验 -> 友好度 +"维生素"增量 -> 重算；等级未变则返回；等级上升 -> "升到了"＋差异窗 -> 学习跨越区间的招式 -> **检查升级进化**。

### 5.3 经验道具（`pbGainExpFromExpCandy`）

- 前置：已满级或 Shadow -> "没有任何效果"、返回 false（不消耗由调用方处理）。
- 数量 >1 时先补 `数量−1` 次"维生素"友好度（随后经验设置自身再触发 1 次，共 `数量` 次）。
- 以"当前经验 + 单次经验×数量"走经验设置流（钳制/早退/差异窗/新招/进化检查同上）；返回 true。

## 6. WP30-D：学习、满槽替换、遗忘与重学

### 6.1 战斗版学习（`pbLearnMove`，战斗文件）

- 已掌握 -> 直接返回；有空槽 -> 学会（消息＋上场对象同步＋招式集变化后形态复检）。
- 满槽 -> "想学但已有 N 个招式" -> 确认是否遗忘：遗忘选择（战斗队伍界面）返回槽位 >=0 -> 该槽替换为**新招式对象**（全新当前/总 PP）、上场对象同步、演出消息（忘记旧招、学会新招）、形态复检；放弃 -> 确认"放弃学习"后结束（不学习）。无蛋/Shadow 前置（战斗内不出现蛋）。

### 6.2 通用版学习（`pbLearnMove`，道具/通用）

- 前置：空个体 false；**蛋**（非调试）与 **Shadow** 拒绝并提示；`ignore_if_known` 控制"已掌握"时是否提示——两者均返回 false（已掌握不重复学习）。
- 有空槽 -> 学会（消息＋音效），返回 true。
- 满槽 -> 确认遗忘：遗忘选择（摘要界面）返回槽位 >=0 -> 替换为新招式对象；**机器教学且"保留旧 PP"配置开启（仅某一世代的配置）时**：新招当前 PP 取 `min(旧招当前 PP, 新招总 PP)`；随后三条消息（演出/忘记/学会）；**机器教学**时追加"机器"友好度增量；返回 true。放弃 -> "没有学会"，false。

### 6.3 遗忘与重学

- **遗忘选择**：两组学习入口都通过界面选择要遗忘的槽位（战斗内=战斗队伍界面；通用=摘要界面）；返回 -1 表示取消（触发"放弃学习"确认）。

  - 蛋或 Shadow -> 空列表（界面不可教）。
  - 教学走通用版学习（可能触发满槽替换/放弃）；**三层取消分开**：① 拒绝"教这个招式"或内层学招返回 false（含满槽放弃）-> **回到重学选择循环**（不退出）；② 列表取消但拒绝退出确认 -> 继续循环；③ 列表取消且确认退出 -> 整体返回 false、统计不变。**成功教学才计"提醒教学"统计并返回 true**。

## 8. 规则与不变量

1. 六条曲线的等级 1 最小经验均为 0；**先按最大等级钳制**、等级小于表长时以表为权威、表外按各曲线登记公式（Erratic/Fluctuating 与表内分段不同，见 §3.2）；加法与显式设置类辅助钳到 `[0, 最大经验]`——**原始经验 setter 不钳制**（非 Shadow 直写原值并失效等级缓存，WP19 §4.2 引用）。
2. 经验写入路径分列：原始 setter（不钳制）/钳制加法（辅助加法）/显式设置（先钳制）；升级由经验反算并逐级应用；`新等级 < 当前等级` 视为不应发生（报错）。
3. 战斗分配先 EV 后经验；EV 写入不立即重算（重算随升级循环或"已达上限"分支）；经验消息对 Shadow 抑制；Shadow 的提交按 §4.2 第 12 步（实际增量入暂存、当前经验不变；心阶段 >3 不增加），全生命周期归 WP23 前向。
4. 修正次序固定：基础分配 -> 训练家加成 -> 缩放（内含参与者 +1）-> 外来 -> 护符 -> 持有物 -> 亲密度 -> 钳制（§4.2 顺序）。
5. 满槽替换一律生成**新招式对象**（全新 PP）；"保留旧 PP"仅存在于"机器教学且配置开启"的窄分支；"机器"友好度增量仅在机器教学时发生。
6. 学习入口的拒绝前置：通用版拒绝蛋/Shadow；重学列表对蛋/Shadow 为空；战斗版无该前置（战斗内不出现蛋）。
7. 重学列表顺序：开启配置时"最初招式（未掌握）"前置，其后为等级学习表项；均去重、均要求未掌握。
8. 友好度变化=方法增量（档位表）→正值修正（地图/球/道具/软上限）→钳制；软上限只作用于正值且不作用于降 EV 树果；亲密度是纯派生值。
9. 升级触发的友好度变化需要"该成员当前在场上"；等级设置辅助的升级/增经验使用"维生素"方法（数值不同源）。
10. 升级/增经验路径的招式学习与进化检查仅在**等级实际上升**时发生；降级/降经验不发生。

## 9. 边界与失败

- 曲线接口（两行分列）：**等级**空/≤0 -> 返回**错误对象**（调用方当作数值使用才失败）；**经验**空/负 -> 诊断文本引用未定义名称，在**文本求值阶段即名称解析失败**（**不返回错误对象**）。均按参考快照登记、不修参考；WP19 §4.2 引用。
- 经验增量 ≤0（例如全被缩放下取整清零或被钳制）：静默结束（无消息）。
- 多级跳升：逐级演出/计算/学习（每级一次），招式为"新等级恰好命中"的列表项。
- 降级：无友好度/新招/进化；六项差异窗为负值形态。
- 达到最大等级后：战斗经验路径只重算能力；经验道具"没有任何效果"（稀有糖果在特定配置下仍可用于触发升级进化——道具侧登记，WP28/31 交界）。
- 满槽学习：拒绝遗忘或放弃 -> 个体与招式集不变（无部分提交）；替换提交为原子步（单槽替换＋PP 新值）。
- Shadow：实际增量（**先经最大经验钳制**）在提交时进入暂存经验、当前经验不变、统计按实际增量；心阶段 >3 该分支不增加经验/统计；解禁/净化/折算细则归 WP23（§4.2 第 12 步、§4.4）。
- 步数友好度的步数计数与"每 128 步"来源引用 WP06；计数器为持久全局值（引用 WP09）。
