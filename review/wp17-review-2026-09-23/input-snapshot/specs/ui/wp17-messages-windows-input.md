## 1. 目的、范围与非目标

**目的**：描述通用交互的行为规则——消息文本如何进入/格式化/逐字显示/快进/确认/关闭，选项与数量输入的来源/取消/边界，按键与文字输入的入口/编辑/确认/取消，以及这些交互与解释器/地图/输入刷新之间的状态交界。后续包据此判断"某交互何时阻塞、返回什么、取消是什么结果"，而不是各自重新追踪消息组件。

**范围**（WP17 自身声明范围，extraction-plan 第 2.1 节 (a) 类）：

1. WP17-A：消息与基础窗口（文本进入、替换、控制标记、逐字显示、快进/确认/暂停、窗口样式与时机）。
2. WP17-B：选项（来源、初始选择、取消策略、结果编码、内嵌选项）。
3. WP17-C：数量输入（范围/位数/初值/取消值/夹限/确认与取消）。
4. WP17-D：按键与文字输入（按键语义、重复、文字入口/编辑/长度/删除/确认/取消）。
5. WP17-E：状态交界（解释器等待、地图更新、输入刷新、临时标记恢复）。
6. F05-05、F05-06 中属于 WP17 部分的状态更新。

**非目标**：

- 不推断全部界面支持鼠标或输入法；鼠标/宿主文字事件接口存在不等于支持（8/11 节如实登记）。
- 不提取专门界面（队伍/背包/战斗/商店等）的领域 UI 与领域写入（相应后续包）；交易、命名后的领域写入只追踪到本包交界。
- 不重复 WP08（本地化与占位符主规则，引用）、WP13（事件命令语义与推进，引用）、WP15（资源选择与缺失，引用具体入口）。
- 不运行游戏或任何参考脚本；不执行输入；不修改 `reference/`；不设计 UI 组件类层级。

## 2. 概念与术语

- **消息窗口**：由 `pbCreateMessageWindow` 创建的文本窗口（逐字显示、位置/皮肤可配）；创建/销毁时维护 `message_window_showing` 标记（WP13 解释器等待引用）。
- **控制标记**：消息文本中以 `\` 开头的显示/行为指令（本文目录化）；与 WP08 的本地化占位符（`\1` 参数）分层——本地化替换先行，本文只登记显示控制。
- **绘制标记**：绘制层以 `<...>` 表示的格式指令（颜色/对齐/图标等）。
- **逐字显示（letterbyletter）**：按 textspeed 逐字出现的显示状态（busy）；确认键可快进到暂停点或结束。
- **宿主提供 vs 参考层定义**：`Input.trigger?/repeat?/press?/triggerex?/repeatex?/gets/text_input/mouse_*` 由宿主（MKXP）提供；参考层只定义按键别名（USE=C、BACK=B、ACTION=A、JUMPUP=X、JUMPDOWN=Y、SPECIAL=Z、AUX1=L、AUX2=R）与 F8 截图钩子。
- 影响域编号 Dxx 见 module-map；证据状态五档定义见总览第 7 节。

## 3. WP17-A：消息与基础窗口

### 3.1 文本进入与替换（`011_Messages.rb:405–476`，本轮逐行阅读）

消息文本在显示前依次处理（顺序敏感）：

- `\sign[文本]` → 展开为 `\op\cl\ts[]\w[文本]`（签名窗组合）。
- `\\` → 字面反斜杠（内部 `\5`）；`\1` → 本地化参数（WP08 引用）。
- `\n[1–8]` → RMXP 角色名（兼容，存在时）；`\pn` → 玩家名；`\pm` → 格式化金钱；`\n` → 换行。
- `\[8 位十六进制]` → `<c2=RRGGBBAA>` 颜色绘制标记。
- `\pg`/`\pog` → 按玩家性别取男/女文本色（`MALE/FEMALE_TEXT_MAIN_COLOR`，配置引用）。
- `\b`/`\r` → 男/女文本色标记。
- `\w[皮肤名]` → 换窗口皮肤（空名恢复默认；WP15 资源入口引用）。
- `\c[N]` → 皮肤色板第 N 色（按皮肤明暗取色）。
- `\v[N]` → 变量值（递归展开至无变化）。
- `\l[N]` → 行数（≥1，影响窗口高度与位置）。
- 系统消息框（message_frame）非 0 时文本前缀亮色，否则按皮肤明暗取默认色。

### 3.2 消息控制标记目录（`011_Messages.rb:478–680`，本轮逐项核对）

| 标记 | 行为 |
| --- | --- |
| `\f[名]` / `\ff[名,索引]` | 显示图片/头像窗（Faces 后回退 Pictures；4×4 索引取 96×96；动画帧更新） |
| `\g` / `\cn` / `\pt` | 显示金钱/代币/战斗点小窗（goldskin 皮肤，与消息窗对角摆放） |
| `\op` | 消息窗滑入出现（0.5 秒，自屏幕外到顶/底） |
| `\cl[SE]` | 特殊关闭：播 SE 后滑出（0.5 秒） |
| `\wu` / `\wm` / `\wd` | 窗口位置上/中/下（即时重摆） |
| `\ts[N]` | 文字速度改为 N/80 秒每字（空参数为 0=即时） |
| `\.` / `\|` | 等待 0.25 / 1 秒 |
| `\wt[N]` / `\wtnp[N]` | 等待 N/20 秒（wtnp 不暂停并自动继续） |
| `\^` | 不暂停，自动继续 |
| `\!` | 暂停点（逐字显示中暂停，等确认） |
| `\se[名:音:调]` / `\me[...]` | 播放 SE/ME（文首 SE 在显示前播放） |
| `\ch[变量,取消值,选项…]` | 内嵌选项：显示后弹选项，结果写变量（WP13 引用） |

### 3.3 逐字显示、快进与确认（`005_SpriteWindow_text.rb:160–215, 360–445`、`011_Messages.rb:559–654`）

- **显示状态**：`letterbyletter` 时逐字出现（busy）；`textspeed` 为每字秒数（玩家选项映射：慢 4/80、中 2/80、快 1/80、即时 0；配置默认 2/80）。`waitcount` 按运行时长（uptime，WP06 引用）倒计时。
- **暂停**：`\!` 暂停点显示暂停箭头并等待；`startPause/stopPause` 控制暂停箭头（4 帧动画）。
- **快进/确认**：USE 或 BACK——显示中（busy）则快进（暂停中先播决定音再恢复）；显示完毕则结束本条消息。
- **自动继续**：`\wtnp`/`\^` 在 waitcount 归零后自动恢复并继续。
- **特殊关闭**：`\cl` 在消息结束后播 SE 并滑出。
- **出现/结束音效**：无起始 SE 且逐字显示时播决定音。

### 3.4 窗口样式与时机

- 皮肤：`pbGetSpeechFrame`（玩家选项 textskin 对应在册皮肤，WP13 命令 131 引用）；`WINDOW_OPACITY = 255`；消息窗默认底部两行（高屏三行），`pbRepositionMessageWindow` 按行数重摆。
- 字体：Power Green 系（正文 27、小 21、窄 27；`pbTryFonts` 回退链）；系统字体经 `pbSetSystemFont`。
- 状态标记：创建消息窗置 `message_window_showing`（WP13 解释器消息等待引用），销毁清除。

## 4. WP17-B：选项（`011_Messages.rb:721–802`，本轮逐行阅读）

- **来源**：选项数组（作者内容）；窗口自适应宽高（每列等宽，光标箭头图按皮肤明暗取色）。
- **初始选择**：`defaultCmd` 指定初始索引。
- **结果编码**：确认（USE）→ 当前索引（0 起）。
- **取消策略**（`cmdIfCancel`）：**> 0 → 取消返回 cmdIfCancel − 1**（相当于"第 N 项作为取消项"）；**< 0 → 取消返回该负值本身**；**= 0 → BACK 无效（不可取消）**。**取消不能笼统等价为 false**。
- **空选项**：`pbShowCommands` 对 nil 输入返回 0；空数组的行为未逐路径验证（列未决）。
- **内嵌选项**：`\ch` 结果写变量并请求地图刷新；解释器命令 102/402/403 的分支语义归 WP13（引用，本文不重复）。
- **带帮助选项**（`pbShowCommandsWithHelp`）：随光标切换更新帮助文本；取消策略同上。
- **确认包装**：`pbConfirmMessage` = [Yes, No] 取消按 No（返回 2 → 结果 1 → false 语义）；`pbConfirmMessageSerious` = [No, Yes] 取消按 No（默认 No）。

## 5. WP17-C：数量输入（`011_Messages.rb:55–206`、`005_SpriteWindow_text.rb:624–730`）

### 5.1 参数对象（ChooseNumberParams）

- **范围**：`setRange(min, max)`（min > max 时 max = min）；`setMaxDigits(N)`（≥1）改为位数模式——范围变为 ±(10^N − 1)；`setNegativesAllowed` 允许负号，否则下限夹到 0。
- **初值**：`setDefaultValue/setInitialValue`；读取时**夹到当前范围**（越界初值被夹限）。
- **取消值**：`setCancelValue`；未设时取**夹限后的初值**。

### 5.2 数字编辑窗口（Window_InputNumberPokemon）

- 逐位编辑：左/右移动位光标（循环），上/下增减当前位（0–9 循环）；符号模式时首位为 +/− 切换。
- 初值写入：非数值按 0；绝对值夹到 10^位数 − 1。

### 5.3 确认与取消（pbChooseNumber）

- 确认（USE）：数值在范围内 → 决定音并返回该值；**越界 → 蜂鸣音并继续等待**（不返回）。
- 取消（BACK）：取消音并返回**取消值**（未设取消值时为夹限后的初值）。
- 返回值即结果编码（无单独"已取消"标记；调用者以取消值区分）。
- 解释器命令 103 的桥接（数字入变量）归 WP13（引用）。

## 6. WP17-D：按键与文字输入

### 6.1 按键语义与重复（`001_Technical/004_Input.rb`、宿主层）

- **参考层**：按键别名映射（第 2 节）；F8 触发截图；`Mouse.getMousePos` 仅在鼠标位于窗口内时返回坐标（否则 nil）。
- **宿主提供**（MKXP 交界，未运行验证）：`Input.update` 刷新；`trigger?`（按下沿）、`press?`（按住）、`repeat?`（按住重复）、`triggerex?/repeatex?`（物理键名）、`Input.gets`（宿主文字输入串）、`Input.text_input=`（开关宿主文字输入）、`mouse_x/mouse_y/mouse_in_window`。
- **更新机会**：交互循环按帧 `Graphics.update → Input.update → 组件更新 → 场景微更新`（`pbUpdateSceneMap` 保持地图侧活动；结束后再次 `Input.update` 防止多余触发残留）。

### 6.2 文字输入入口（`025_UI_TextEntry.rb` 全文，本轮逐行阅读）

- **模式选择**：`pbEnterText` 按玩家选项 `textinput`（1=键盘，其余=光标）选择场景；包装入口：`pbEnterPlayerName`（显示玩家行走图）、`pbEnterPokemonName`（显示宝可梦图标与性别符号）、`pbEnterNPCName`、`pbEnterBoxName`（存储箱图标）。
- **键盘场景（PokemonEntryScene）**：宿主文字输入开启（`Input.text_input = true`）；`Input.gets` 逐字插入；←/→ 移光标；Backspace 删除；**ESCAPE 仅在 minlength = 0 时允许（返回空串）**；RETURN 在长度 ≥ minlength 时确认返回文本。
- **光标场景（PokemonEntryScene2）**：13×5 字符网格，4 组字符集（大写/小写/变音/符号，含 ♂♀ 与emoji 类符号）；SPECIAL 或模式键切组（带切换动画与音效）；USE 插字符（满长时先删末尾再插并自动跳到 OK）；BACK 删字符；**首字母大写后自动切小写组**；OK 在长度 ≥ minlength 时确认；**无独立取消结果**（取消键映射为删除；结果总是当前文本）。
- **通用约束**：`maxlength` 字符上限（插入拒绝）；`minlength` 确认下限（不足时键盘场景 RETURN 无效、光标场景 OK 无效/蜂鸣）。

### 6.3 自由文本框（`012_TextEntry.rb`、`011_Messages.rb:821–859`）

- `pbFreeText`/`pbMessageFreeText`：行内文本框——`Input.text_input` 开启；**ESCAPE 返回原输入文本（未修改）**，RETURN 返回编辑后文本；`maxlength` 上限；`passwordChar` 掩码显示。
- 字符编辑助手（CharacterEntryHelper）：按字符（非字节）计数；插入/删除守 max 与光标位置；密码字符仅影响显示。
- 多行文本框（Window_MultilineTextEntry）：方向键跨行移动、RETURN 插入换行、Ctrl+HOME/END 跳首尾；本包未找到默认消费者（登记为可用组件）。

### 6.4 数字/文字之外的输入行为

- 重复按键：`Input.repeat?` 用于数字位增减、列表移动、文本删除/光标移动（初次延迟后重复，宿主语义未运行验证）。
- 方向/操作映射：命令窗口按列循环（上/下越界时按列数取模循环；左/右不循环）；JUMPUP/JUMPDOWN 翻页。

## 7. WP17-E：状态交界

- **解释器等待**：消息显示中解释器不执行命令（`message_window_showing`/`message_waiting`，WP13 引用）；选择/数字/文字在消息显示完毕后弹出（WP13 命令 101 的合并规则引用）。
- **地图/公共事件更新**：交互循环内 `pbUpdateSceneMap` 保持地图侧微更新（菜单中地图事件/公共事件的更新差别归 WP13 引用）。
- **输入刷新**：每个交互结束后 `Input.update` 防止触发残留传入下一交互。
- **临时标记恢复**：`message_window_showing` 创建置位/销毁清除；`Input.text_input` 进入开启/退出关闭（含异常路径——本包未见异常专用处理，按正常路径登记）。
- **资源与缺失**：皮肤/图片/图标资源按 WP15 具体入口引用（pbResolveBitmap 缺失 nil 等），不概括为"所有缺失都返回 nil"。
- **抛错路径**：`\ch` 的 CSV 解析对非正整数/引号错误抛异常（沿解释器异常分层，WP07/WP13 引用）；取消/失败的领域写入归相应后续包。

## 8. 默认行为与配置变体

- **基线默认**：逐字显示、速度中（2/80 秒每字）、窗口底部、皮肤按玩家选项、选项可取消按 cmdIfCancel、数字无符号下限 0、文字输入按玩家选项（默认光标场景）。
- **支持但未默认启用**：键盘文字输入（textinput=1）、`\w` 换肤、`message_frame` 系统消息框、密码掩码、多行文本组件、鼠标查询。
- **配置/数据关联**：`SPEECH_WINDOWSKINS`、`WINDOW_OPACITY`、字体三档、`MALE/FEMALE_TEXT_MAIN_COLOR`、`TEXT_SPEED`（WP02 词典）；玩家选项 textspeed/textinput/textskin（WP24 交界）；系统 UI 音效（WP15 引用）。
- **未验证组合**：任何真实窗口/宿主输入观察（未运行）；空选项数组行为；鼠标在各界面的实际支持面；变音/符号字符集的完整收录差异。
- 参考快照行为、官方版本预期、未来目标分开标记；本包只记录第一类。

## 9. 边界、失败与未知

- 空命令输入（nil）→ 返回 0；空数组未逐路径验证。
- 数字初值越界 → 夹限；范围 min > max → max = min；上下限相等 → 只能返回该值。
- 数字确认越界 → 蜂鸣继续等待；取消返回取消值（未设时为夹限后初值）。
- 文字 minlength = 0 时键盘场景 ESCAPE 返回空串；minlength > 0 时 ESCAPE 无效。
- 自由文本 ESCAPE 返回**原文**（编辑作废）；RETURN 返回编辑结果。
- `\ch` 的变量/取消值非正整数或引号错误 → 抛异常（WP07/WP13 引用）。
- 消息窗资源缺失：皮肤/图片按 WP15 入口（解析 nil 时窗口无图或保持现状，具体输出未运行验证）。
- 宿主输入（重复延迟、文字事件、鼠标）行为未运行验证。

| 普通消息与等待 | 显示一条消息，用户不按 | 逐字显示至结束；解释器在显示期间不执行后续命令 |
| 快进 | 显示中按 USE | 快进至暂停点或全文；随后再按结束本条 |
| 选项确认 | pbMessage("...", ["A","B"], 0, 默认 1) 按 USE | 返回当前索引（默认从 1 起） |
| 选项取消（正值） | cmdIfCancel=2，按 BACK | 返回 1（第二项作为取消项） |
| 选项取消（负值） | cmdIfCancel=-1，按 BACK | 返回 -1（负值本身） |
| 选项不可取消 | cmdIfCancel=0，按 BACK | 无效果（等待 USE） |
| 空命令 | pbShowCommands(nil) | 返回 0 |
| 数字上下限 | setRange(1, 5)、初值 9、USE | 初值夹到 5；范围内确认返回该值 |
| 数字越界确认 | 当前值 6、范围 [1,5]，按 USE | 蜂鸣并继续等待（不返回） |
| 数字取消默认 | 未设取消值、初值 9 夹到 5，按 BACK | 返回 5（夹限后的初值） |
| 上下限相等 | setRange(3, 3) | 只能返回 3 |
| 位数模式 | setMaxDigits(2)、允许负号 | 范围 ±99；初值 −150 夹到 −99 |
| 文字长度上限 | maxlength=7，输入第 8 字 | 插入被拒绝（蜂鸣或无效，按场景） |
| 文字删除/光标 | 键盘场景：输入后 Backspace/←→ | 删除光标前字符/移动光标（repeat 重复） |
| 键盘场景取消 | minlength=0，按 ESCAPE | 返回空串；minlength>0 时 ESCAPE 无效 |
| 光标场景确认 | 输入 3 字（minlength=1）选 OK | 返回当前文本；首字母大写后已自动切小写组 |
| 自由文本取消 | 编辑后按 ESCAPE | 返回原文（编辑作废） |
| 内嵌选项 | 文本含 `\ch[3,2,是,否]` | 显示后弹选项，结果写变量 3 并请求地图刷新 |
| 特殊关闭 | 文本含 `\cl[SE名]` | 消息结束后播 SE 并滑出 |
