# WP62 — 图鉴记录、区域与内容规则

状态：**ReviewPending（A～F：记录字段与结构、写入入口与门、身份与形态规则、内容集合／解锁／区域、展示与可见性、获取入口矩阵与次序；2026-09-29首稿，尚未外审）**。2026-09-29首稿；F15-01子范围，Pokémon Rules（主）／Creature-RPG（获得入口交界）／User Interface（可见性接点）。只读基线 `8c5911e4a4b07b07e832e4bb0d5d8859e88b4a9b`，没有编译PBS、没有运行UI／捕获／事件／解释器；缺地图事件不补造解锁剧情。记录与可见性以固定快照为准，不套用官方系列常识。WP62定义图鉴操作合同；捕获判定与完整接收流程由WP38定义，本包只登记其写入接点（不构成反向依赖）。源码名只用于审计定位。

## 1. 目的与可见流程（A）

本包回答“图鉴记录哪些事实、由谁在何时写入、区域列表如何构成与解锁、各界面按什么资格显示什么”。可见流程：玩家获得图鉴（标志位）→ 区域列表按解锁与“是否见过任何成员”变为可访问 → 战斗与各获得入口写入记录 → 图鉴菜单／主列表／条目页按见过／拥有与区域资格显示；条目页“栖息地”页由**遭遇表**生成区域地图要点。

边界：不定义物种／形态数据本身（WP18／WP21）、不定义遭遇生成（WP36）、不定义地图与存档（WP11／WP09）；捕获公式与接收流程归WP38；图鉴解锁剧情、图鉴授予与大多数解锁调用不在脚本内（事件侧，U01）。记录与区域规则全部为“已读静态＋数据样本”级别。

## 2. 记录字段与结构（B）

记录存放在玩家对象的图鉴子对象内；随玩家一起存档。字段如下（写入即含“刷新可访问列表”的副作用，除注明外）：

| 字段 | 结构 | 含义与备注 |
| --- | --- | --- |
| 见过 | 集合（按**基础物种**键） | 任何登记入口置真；只增不清（无逐项清除接口；整体清空仅随图鉴重建） |
| 拥有 | 集合（按基础物种键） | 与“见过”独立；战斗侧仅捕获流程写入（击倒对方不写拥有），获得侧多个入口直接写入（§3.2） |
| 见过形态 | 物种 → [性别2档][异色2档][形态号] 布尔表 | 性别2档＝雄／雌；无性别在写入时并入第0档（雄） |
| 见过蛋 | 集合 | 由**孵化时刻**写入（不是拿到蛋时）；无刷新副作用 |
| 末次形态 | 物种 → [性别, 形态号, 异色] | 条目页缩略图／列表行引用；登记入口只在“尚为空”时写入，另有一个总是覆盖的“最近见到”入口与一个界面浏览写入（§6） |
| 暗影拥有 | 集合 | 与“拥有”独立；由捕获流程对暗影个体附加写入 |
| 捕获计数 | 物种 → 整数 | 每次捕获＋1；缺省0 |
| 击败计数 | 物种 → 整数 | 每次击倒对方个体＋1（战斗侧调用）；缺省0 |
| 合成“战斗过计数” | 查询＝击败＋捕获 | 不是独立字段；条目页展示（§6）；野生遭遇的连锁异色判定另归WP36消费 |
| 区域解锁表 | 布尔数组，长度＝区域数＋1（末位＝全国） | 初始化只有索引0为真；解锁／锁定按区域号；越界或-1归到全国位 |
| 可访问列表 | 区域号数组（派生） | 每次记录写入后重算（§5.2）；作为玩家数据一并保存，内容以重算结果为准 |
| 全局观看状态 | 图鉴观看记录（3项，随全局元数据保存） | 当前观看的区域号（默认：有区域则0，否则全国-1）；各区域“上次查看的物种索引”（长度＝区域数＋1）；搜索模式（默认数值序0） |

计数只按**基础物种**归并：形态不产生独立条目；“seen_forms_count”等按形态维度单独查询（§3）。所有写入均对“未知物种（数据不存在）”静默忽略（见§3）。

## 3. 写入入口与门（C）

### 3.1 战斗侧（写入的是玩家训练家对象的图鉴）

| 入口 | 写入 | 门 |
| --- | --- | --- |
| 战斗开始时对方出场（野生） | 见过＋见过形态＋（首次）末次形态＝该个体的展示种／展示性别／展示形态／异色 | **内部战斗标志为真**才写；设施挑战等“非内部战斗”不写 |
| 战斗中的展示变化（如形态变化、幻觉类揭示等已述调用点） | 同上（按展示属性） | 同上 |
| 对方倒下 | 击败计数＋1（按展示物种） | 同上 |
| 捕获接收（战斗结束流程） | 捕获计数＋1、见过（按接收个体）、如未拥有则→拥有＋（有图鉴且**物种在已解锁区域表内**时）提示“数据已添加”＋最近见到写入＋打开条目页；暗影个体附加→暗影拥有 | 该流程在常规战斗终局执行（战斗侧登记自带内部战斗旗门，设施等非内部战斗不可达）；其库存与拥有次序归WP38详述，本包只记图鉴接点 |

注意：战斗侧入口不预先判断“是否已见过”（重复即覆盖同值）；登记入口本身不对蛋状态设门，由调用方保证不登记蛋。

### 3.2 获得侧

| 入口 | 写入次序（静态） |
| --- | --- |
| 赠送／脚本交换等“加入队伍或盒子”的主路径 | 先做容量检查（箱子已满→直接失败**且不写任何图鉴字段**）→ 见过＋拥有 →登记形态（可选参数控制）→ （新物种且有图鉴且区域资格通过且“更常显示”设置开）提示＋最近见到＋条目页 → 昵称／存放 |
| 静默加入（礼物、神秘礼物等使用） | 容量检查 → 登记＋拥有（不单独写见过；登记内含）→ 无提示路径（神秘礼物自行追加提示块） |
| 孵化 | 孵化动画后：登记（见过＋形态＋首写末次形态）→ 拥有 → 写“见过蛋” → （同上式提示条件）最近见到＋条目页 → 昵称 |
| 进化（含分裂式复制个体） | 变更物种后：登记（新物种）→ 拥有 →（同上式提示条件）最近见到＋条目页 |
| 交换 | 换得个体处理开始：登记＋拥有 → 交换演出 → （同上式提示条件）最近见到＋条目页 → 末了检查交换进化（其写入并入“进化”行） |
| 蛋生成 | **不写图鉴**（蛋的“见过蛋”在孵化时写） |
| 界面上浏览形态 | 条目页形态浏览会**写入“末次形态”**（覆盖）；这是唯一的“查看即写”路径 |

“提示条件”完整形式＝“更常显示新物种条目”设置开 ∧ 此前未拥有 ∧ 玩家有图鉴 ∧ 物种在已解锁区域表内；捕获流程的提示省略第一个条件（总是按其余条件提示）。提示块内次序固定：消息→最近见到→条目页。

### 3.3 其它入口

- 调试工具：按性别／异色组合批量登记、直接置拥有、解锁／锁定图鉴、翻转“拥有图鉴”标志、刷新可访问列表——均为调试范围，不作为正常流程证据。
- 事件侧：图鉴授予、解锁调用在脚本内**没有正常调用者**（保持U01）；相关剧情与见证事件不在本包。

## 4. 身份与形态规则（C 续）

- **基础物种归并**：一切记录按“物种的基种”键（形态数据归一后取基种）；未知标识（查不到物种数据）在查询与写入处都静默失败（查询返回假／0／空，写入不生效）。
- **形态映射**：登记时实际的“形态号”先经**图鉴展示形态**映射（形态不同则改记展示形态），再把“无命名形态”归为0。因此记录中的形态是展示维度，不是原始形态号。
- **性别映射**：写入前性别2（无性别）并入0；见过形态表只索引0／1。
- **异色维度**：仅用于“见过形态”与“末次形态”；“见过／拥有”不区分异色。
- **末次形态语义**：初始登记入口只在键不存在或为空时写入（首个登记形态成为默认显示）；“最近见到”入口总是覆盖（用于捕获／获得提示后展示）；界面浏览覆盖（§3.2）。查询默认 [性别0, 形态0, 异色假]。
- **形态查询**：按（物种，性别，形态，异色）精确或“任一异色”查询；按物种计“已见形态数”＝存在任一性别／异色标记的形态号个数。展示形态的选择与命名（含无命名／单一性别形态）归WP21，本包只消费。

## 5. 内容集合、解锁与区域（D）

### 5.1 区域表的数据来源与结构

- `PBS/regional_dexes.txt`：以 `[n]` 分节（本快照两节：[0]与[1]，共212行）；节内每行是逗号分隔的物种链（多为进化族一行）；行内与行间按**出现顺序**平铺为顺序表——该顺序即区域编号次序。
- 编译语义（静态）：重复分节报错；同一区域表内物种重复报错（定位到行）；缺分节即报错；编译产物写入区域表数据文件并从缓存读取。
- 编号：区域编号＝表中位置＋1（查询得到1起编号，0＝“不在该表”）；**偏移设置**中的区域在展示时整体减1（0起）。
- 全国表没有独立存储：全国编号按物种数据遍历顺序（展示端以全国序列的索引推编号）。

### 5.2 解锁与可访问

- 解锁表初始化：仅索引0为真（末位全国默认锁定）。解锁／锁定接口对-1或越界一律作用到**全国位**。
- 可访问重算（每次记录写入后的派生）：
  - 若“使用当前区域”设置为开：取玩家当前地图的**区域号**（无地图默认-1；区域号≥区域数时视作全国）；仅当该表“见过任何成员”时列入（只列一个）。
  - 若只有全国定义：全国位解锁且见过任何成员时列入全国。
  - 否则：逐区域按（解锁 ∧ 见过该区域任何成员）列入（区域在前），全国按（解锁 ∧ 见过任何成员）列在最后。
- “见过任何成员”查询：全国＝遍历全部物种有无见过；区域＝该区域表成员有无见过。
- “物种在已解锁区域表内”查询：全国位解锁→真；否则任一已解锁区域的该物种编号＞0→真；否则假。空表或未知物种→假。
- 计数（见过／拥有）按区域：全国＝全物种；区域＝该区域表成员逐个查集合（含未解锁区域也能算数——**计数不检查解锁**；只有可访问列表检查）。
- 空／缺表边界：区域号无表或表为空→成员列表查询为空；计数为0；主列表显示时回退到全国序列（§6）。

### 5.3 区域与地图数据

- 当前区域＝当前地图元数据的**城镇地图位置**首字段；无地图元数据时为-1。
- 条目页“栖息地”页：对当前区域，遍历**当前遭遇版本**的全部遭遇表，找出含该物种的表（任意槽位）；排除带“在图鉴中隐藏遭遇”标志的地图；要求地图的城镇地图位置区域号相符；按地图的城镇地图占位（含多格形状）折算成要点；概要点还要求地图点可见（可选可见开关）。无任何点为“区域未知”空态。
- 遭遇版本是全局元数据中的整数值（默认0）；图鉴只是它的读取者——修改与语义归WP36。

## 6. 展示与可见性（E）

| 消费者 | 资格与规则 |
| --- | --- |
| 暂停菜单入口 | 条件＝有图鉴 ∧ 可访问列表非空；“使用当前区域”开→直接开主列表；可访问恰一个→自动选定该区域并开；多个→先开区域选择菜单 |
| 区域选择菜单 | 每行＝区域名＋（见过数, 拥有数, 区域长度）；两枚“全见过／全拥有”标记分别以见过数≥长度、拥有数≥长度点亮；选择后设为当前观看区域并进入主列表；末行为“Exit” |
| 主列表 | 行来源＝该区域顺序表（空则全国全物种）；行按搜索模式过滤：数值序＝不过滤（未见行显示“----------”且无图标）、首字母序＝仅曾见、高度／体重排序＝仅拥有；行图标：拥有→拥有图标、仅见→见过图标、未见→无；编号＝位置＋1（偏移表区域整体减1）；行名与体型等字段取“末次形态”的形态数据；确认键仅在“曾见”行打开条目（未见行不可进入） |
| 主列表搜索 | 维度：排序、名字（逐字符多选）、属性（两个）、身高／体重区间、颜色、形状、重置／开始；名字、颜色、形状筛选要求曾见，属性与身高／体重筛选要求拥有；结果一律再剔除未见物种；结束后复位为数值序 |
| 主列表排序 | 数值序／首字母序／最高最矮最重最轻；每个区域独立记住“上次查看的物种索引”（全局观看状态） |
| 条目页 | 编号≤0显示“???”；“拥有”决定信息深度：拥有→类别、身高体重、图鉴文本、足迹、拥有图标、属性图标；仅见→类别“????? Pokémon”、身高体重为占位、无文本／足迹；信息页可切换显示“战斗过计数”（击败＋捕获）；条目页内前后移动跳过未见物种；形态列表按“见过形态”逐（性别×形态）门控（除非“显示全部形态”设置开）、无命名与非常规形态不列；浏览形态时写入末次形态 |
| 摘要画面 | “图鉴编号”行：全国解锁→全国序列编号（偏移表减1）；否则取第一个已解锁区域编号＞0者；都没有→“???” |
| 存档画面 | 有图鉴时显示“拥有数／见过数”（全国口径） |
| 战斗场景 | 捕获流程的条目页展示（§3.1）；“图鉴中隐藏遭遇”标志只影响栖息地页 |
| 全局统计 | “已捕获总数”＝全物种捕获计数求和（存档界面与统计消费者） |

主列表在数值序下可停留于未见行，但确认键不打开条目（仅曾见可进）；条目页内部前后移动亦跳过未见物种。
